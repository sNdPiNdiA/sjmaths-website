Chapter 6 Core Formula Sheet

Quick-glance formula revision for examination and numerical problem-solving:

  • $$a_n = a + (n-1)d$$
  • $$S_n = \frac{n}{2}[2a + (n-1)d] = \frac{n}{2}(a + l)$$
  • $$\text{AM of } a \text{ and } b = \frac{a + b}{2}$$
  • $$a_n = ar^{n-1}$$
  • $$S_n = \frac{a(r^n - 1)}{r - 1} \; (r > 1) = \frac{a(1 - r^n)}{1 - r} \; (r < 1)$$
  • $$S_\infty = \frac{a}{1 - r} \quad (|r| < 1), \quad \text{GM} = \sqrt{ab}$$
  • $$\frac{a+b}{2} \ge \sqrt{ab} \quad (a, b > 0)$$
  • $$\text{Equality holds if and only if } a = b$$
  • $$V_n = V_0(1 - r)^n \text{ (Depreciation)}$$
  • $$P_n = P_0(1 + r)^n \text{ (Growth)}$$
