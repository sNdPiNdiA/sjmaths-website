Define Combination

Master the concept of Combinations in CBSE Class 11 Applied Mathematics. Learn formulas, properties, and step-by-step solutions for board exam success.

Definition of Combination

A combination is a selection of objects from a given set where the order of selection does not matter. Unlike permutations, where arrangement is key, combinations focus solely on the grouping of items. If we have n distinct objects, the number of ways to select r objects is denoted by nCr or C(n, r).

nCr = n! / (r! · (n − r)!)
Example: Solved Example: Calculate 5C2
Show Step-by-Step Solution

Step 1: Identify n=5 and r=2.
Step 2: Apply formula 5! / (2! · (5 − 2)!).
Step 3: Calculate 120 / (2 · 6) = 120 / 12.
Answer: 10

Fundamental Properties

Combinations follow specific algebraic identities that simplify complex calculations. Key properties include the symmetry property and the Pascal identity. These allow for efficient computation when n or r values are large.

nCr = nC(n − r)
Example: Solved Example: Verify 10C8 = 10C2
Show Step-by-Step Solution

Step 1: Calculate 10C8 = 10! / (8! · 2!) = (10 · 9) / 2 = 45.
Step 2: Calculate 10C2 = 10! / (2! · 8!) = (10 · 9) / 2 = 45.
Answer: Both equal 45.

Selection Constraints

When selecting items, constraints such as 'at least one' or 'excluding specific items' often arise. These are handled by subtracting the unwanted cases from the total possible combinations. This logical approach is essential for solving word problems.

nCr + nC(r − 1) = (n + 1)Cr
Example: Solved Example: Find 6C3 + 6C2
Show Step-by-Step Solution

Step 1: Use Pascal identity (n+1)Cr where n=6, r=3.
Step 2: Result is 7C3.
Step 3: 7C3 = (7 · 6 · 5) / (3 · 2 · 1) = 35.
Answer: 35

Section D: Long Answer Questions

1

hardA box contains 5 red balls and 6 blue balls. In how many ways can we select 4 balls such that: (i) Exactly 2 are red? (ii) At least 2 are red?

Show Answer & Solution

Step 1: Total balls = 11. Select 4.
Step 2: For (i), select 2 red from 5 and 2 blue from 6.
Step 3: 5C2 · 6C2 = 10 · 15 = 150.
Step 4: For (ii), cases are (2R, 2B), (3R, 1B), (4R, 0B).
Step 5: (5C2·6C2) + (5C3·6C1) + (5C4·6C0) = 150 + (10·6) + (5·1) = 150 + 60 + 5 = 215.

2

very hardProve that nCr + nC(r-1) = (n+1)Cr using the factorial definition and find the value for n=9, r=4.

Show Answer & Solution

Step 1: Write n!/(r!(n-r)!) + n!/((r-1)!(n-r+1)!).
Step 2: Factor out n! / ((r-1)!(n-r)!).
Step 3: Simplify the remaining fraction to (n-r+1+r) / (r(n-r+1)).
Step 4: Result is (n+1)! / (r!(n+1-r)!).
Step 5: For n=9, r=4, 10C4 = (10 · 9 · 8 · 7) / (4 · 3 · 2 · 1) = 210.

Section E: Case-Based Question

★

Case Study: A sports club has 10 members. They need to form a team of 4 players for a tournament. Additionally, they must select a captain and a vice-captain from the chosen 4.

Sub-question 1: (i) In how many ways can the 4 players be chosen from 10? (ii) Once chosen, in how many ways can the captain and vice-captain be selected from the 4?

Show Solution

(i) 10C4 = (10 · 9 · 8 · 7) / (4 · 3 · 2 · 1) = 210. (ii) From 4, select 2 for specific roles: 4P2 = 4 · 3 = 12.

Sub-question 2: If one specific member must be in the team, how many ways can the 4-player team be formed?

Show Solution

If 1 is fixed, we need to choose 3 more from the remaining 9. 9C3 = (9 · 8 · 7) / (3 · 2 · 1) = 84.
