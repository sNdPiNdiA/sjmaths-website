Meaning of Dispersion in a Data Set

Master the meaning of dispersion in CBSE Class 11 Applied Mathematics. Learn to measure data variability with clear examples, formulas, and exercises.

Concept of Dispersion

Dispersion refers to the extent to which values in a data set are spread around a central tendency, such as the mean or median. While measures of central tendency provide a single representative value, dispersion quantifies the reliability and consistency of that average. For example, if two classes have the same mean score of 70, the class with lower dispersion has more students scoring near 70.

Range = Maximum Value − Minimum Value
Example: Solved Example: Calculate the Range
Show Step-by-Step Solution

Step 1: Identify the data set: {12, 15, 22, 28, 35}.
Step 2: Find the maximum value (35) and minimum value (12).
Step 3: Apply the formula: Range = 35 − 12 = 23.
Answer: The range of the data set is 23.

Absolute vs Relative Measures

Absolute measures of dispersion are expressed in the same units as the original data, such as kilograms or rupees, making them unsuitable for comparing different data sets. Relative measures, known as coefficients, are unit-free ratios that allow for the comparison of variability between two distinct data sets. A coefficient of dispersion is calculated by dividing the absolute measure by a central value.

Coefficient of Range = (Max − Min) / (Max + Min)
Example: Solved Example: Find Coefficient of Range
Show Step-by-Step Solution

Step 1: Given data: {10, 20, 30, 40, 50}.
Step 2: Max = 50, Min = 10.
Step 3: Coefficient = (50 − 10) / (50 + 10) = 40 / 60 = 0.67.
Answer: The coefficient of range is 0.67.

Properties of Dispersion

A good measure of dispersion should be rigidly defined, easy to calculate, and based on all observations in the data set. It should also be capable of further algebraic treatment and remain unaffected by sampling fluctuations. Dispersion is zero only when all observations in the data set are identical.

σ² = Σ(xᵢ − μ)² / N
Example: Solved Example: Verify Dispersion Property
Show Step-by-Step Solution

Step 1: Data set: {5, 5, 5}.
Step 2: Mean (μ) = (5+5+5)/3 = 5.
Step 3: Dispersion = Σ(5-5)²/3 = 0.
Answer: Since all values are identical, the dispersion is 0.

mediumGiven data set A = {5, 10, 15, 20, 25}: (i) Find the range. (ii) Find the coefficient of range. (iii) If each value is multiplied by 2, find the new range.

Show Answer & Solution

(i) Range = 25 − 5 = 20.
(ii) Coeff = 20 / (25 + 5) = 20 / 30 = 0.67.
(iii) New set {10, 20, 30, 40, 50}, Range = 50 − 10 = 40.

mediumGiven data set B = {100, 120, 140, 160}: (i) Find the mean. (ii) Find the range. (iii) Find the sum of deviations from the mean.

Show Answer & Solution

(i) Mean = (100+120+140+160)/4 = 520/4 = 130.
(ii) Range = 160 − 100 = 60.
(iii) Sum of deviations = (100-130) + (120-130) + (140-130) + (160-130) = -30 - 10 + 10 + 30 = 0.

Section D: Long Answer Questions

1

hardA data set contains 5 values: {10, 15, x, 25, 30}. If the range is 25, find the possible values of x and calculate the coefficient of range for each case.

Show Answer & Solution

Step 1: Identify Max and Min. Max=30, Min=10. Range = 30-10=20.
Step 2: Since the given range is 25, the range must be Max-Min=25.
Step 3: If x is the new max, x-10=25 ⟹ x=35. If x is the new min, 30-x=25 ⟹ x=5.
Step 4: Case 1: {10, 15, 35, 25, 30}, Coeff = 25/(35+10) = 25/45 = 0.56.
Step 5: Case 2: {10, 15, 5, 25, 30}, Coeff = 25/(30+5) = 25/35 = 0.71.

2

very hardConsider two data sets: A = {10, 20, 30} and B = {100, 200, 300}. (i) Calculate the range for both. (ii) Calculate the coefficient of range for both. (iii) Compare the dispersion.

Show Answer & Solution

Step 1: Range A = 30-10 = 20. Range B = 300-100 = 200.
Step 2: Coeff A = 20/(30+10) = 20/40 = 0.5.
Step 3: Coeff B = 200/(300+100) = 200/400 = 0.5.
Step 4: Compare absolute measures: Range B > Range A.
Step 5: Compare relative measures: Coeff A = Coeff B. Conclusion: Relative dispersion is identical despite different scales.

Case Study: A small shop records daily sales for 5 days: ₹500, ₹700, ₹600, ₹900, ₹800.

Sub-question 1: (i) Find the range of sales. (ii) Calculate the coefficient of range.

Show Solution

(i) Max=900, Min=500. Range = 900-500 = 400.
(ii) Coeff = 400/(900+500) = 400/1400 = 0.286.

Sub-question 2: If sales increase by ₹100 each day, verify if the coefficient of range changes.

Show Solution

New set: {600, 800, 700, 1000, 900}. New Range = 1000-600 = 400. New Coeff = 400/(1000+600) = 400/1600 = 0.25. The coefficient changes because the denominator (Max+Min) changes.
