Exercise 3.4: Coding-Decoding

Decipher substitution ciphers, positional letter shifts, reverse ciphers, case alternation, and numerical positional average sums.

Core Theoretical Principles

Systematic principles and analytical strategies prescribed by the CBSE curriculum for Coding-Decoding.

Alphabetical Positional Values & Shifts:
• Forward positions: $A=1, B=2, \dots, Z=26$.
• Memory anchor: $E(5), J(10), O(15), T(20), Y(25)$ (EJOTY).
• Shift cipher: $C_i = (P_i + k) ±od{26}$.
Reverse & Symmetry Ciphers:
• Opposite letters: $P_i + C_i = 27$ (e.g. $A-Z, B-Y, C-X, D-W, E-V$).
• Reversal cipher: Predecessor or successor written in inverted string order.
Word & Alphanumeric Matrix Decoding:
• Common word elimination: Compare multiple coded phrases to isolate code words.
• Arithmetic mapping: Word value $= ∑ positions2$ or $(∑ positions) × k$.

Solved Illustrative Examples

Example 1 (Reverse Predecessor Cipher)
In a certain code 'LION' is written as 'MNHK'. How is 'MONKEY' written in that code?
Step 1: Analyze LION $\to$ MNHK:
• Predecessor letters: $L-1=K, I-1=H, O-1=N, N-1=M$
• Reversing $K, H, N, M$ gives $M, N, H, K$.
Step 2: Apply to MONKEY:
• Predecessors: $M-1=L, O-1=N, N-1=M, K-1=J, E-1=D, Y-1=X$
• Reversing $L, N, M, J, D, X$ gives $\mathbf{XDJMNL}$.
Answer: (b) XDJMNL.
Example 2 (Word Elimination)
In a code, '564' means 'all the best', '736' means 'best of luck', '423' means 'all is luck'. What is the code for 'all'?
Step 1: Compare '564' (all the best) and '423' (all is luck). The common word is all and the common digit is 4.
Answer: (b) 4.
Example 3 (Positional Sum Average)
In a code 'ENTHALPY' is written as '50.5'. How is 'ENTROPY' written?
Step 1: Sum positions of ENTHALPY: $5+14+20+8+1+12+16+25 = 101$.
Step 2: $Code = 101 / 2 = 50.5$.
Step 3: Sum positions of ENTROPY: $5+14+20+18+15+16+25 = 113$.
Step 4: $Code = 113 / 2 = \mathbf{56.5}$.
Answer: (c) 56.5.

CYP 3.4.4 Fictitious Sentence Matrix Drill

In a certain code language:
• "pit dar na" means "orange is sweet"
• "na sa ra" means "mango is sour"
• "ra dar ta" means "sweet and sour"
Determine the code word for: (i) "is", (ii) "sweet", and (iii) "orange".

View Step-by-Step Solution

Common Token Elimination:

  1. Compare Sentence 1 ("orange is sweet") and Sentence 2 ("mango is sour"):
    The common English word is "is". The common code word between "pit dar na" and "na sa ra" is "na".
    $\implies$ "is" = "na".
  2. Compare Sentence 1 ("orange is sweet") and Sentence 3 ("sweet and sour"):
    The common English word is "sweet". The common code word between "pit dar na" and "ra dar ta" is "dar".
    $\implies$ "sweet" = "dar".
  3. In Sentence 1 ("pit dar na" = "orange is sweet"):
    Since "is" = "na" and "sweet" = "dar", the sole remaining word "orange" must correspond to "pit".

Final Answer: (i) "is" = na, (ii) "sweet" = dar, (iii) "orange" = pit.

CYP 3.4.5 Uniform Positional Shift Drill

In a certain code, TRIANGLE is written as SQHZMFKD. Following the identical transformation rule, how is COMPUTER coded?

View Step-by-Step Solution

Identify the governing rule on TRIANGLE:

  • $T(20) \xrightarrow{-1} S(19)$
  • $R(18) \xrightarrow{-1} Q(17)$
  • $I(9) \xrightarrow{-1} H(8)$
  • $A(1) \xrightarrow{-1} Z(26)$ (circular wrap-around)
  • $N(14) \xrightarrow{-1} M(13)$
  • $G(7) \xrightarrow{-1} F(6)$
  • $L(12) \xrightarrow{-1} K(11)$
  • $E(5) \xrightarrow{-1} D(4)$

The transformation rule is a constant $-1$ backward shift on every letter.

Apply rule to COMPUTER:

  • $C(3) \xrightarrow{-1} B(2)$
  • $O(15) \xrightarrow{-1} N(14)$
  • $M(13) \xrightarrow{-1} L(12)$
  • $P(16) \xrightarrow{-1} O(15)$
  • $U(21) \xrightarrow{-1} T(20)$
  • $T(20) \xrightarrow{-1} S(19)$
  • $E(5) \xrightarrow{-1} D(4)$
  • $R(18) \xrightarrow{-1} Q(17)$

Final Answer: BNLOTSDQ

Q1. Opposite Letter Cipher 1 Mark

If KING is written as PRMT in an opposite letter substitution code, how is ROSE written in that code?

Show Model Solution

Opposite letters satisfy $\text{Rank}_1 + \text{Rank}_2 = 27$:

  • $R(18) \implies 27 - 18 = 9 = I$
  • $O(15) \implies 27 - 15 = 12 = L$
  • $S(19) \implies 27 - 19 = 8 = H$
  • $E(5) \implies 27 - 5 = 22 = V$

Answer: ILHV

Q2. Alphabetical Rank Sum 1 Mark

If $A = 1$ and $PAT = 37$ (since $16 + 1 + 20 = 37$), compute the numerical code for TAP and MASTER.

Show Model Solution

Sum the standard forward alphabetical ranks:

  • $TAP = 20 + 1 + 16 = 37$
  • $MASTER = M(13) + A(1) + S(19) + T(20) + E(5) + R(18) = 76$

Answer: $TAP = 37$, $MASTER = 76$.

Q3. Alternating Shift Analysis 1 Mark

Determine the step rule that transforms BANK into DCQM.

Show Model Solution

Compare respective letter positions:

  • $B(2) \to D(4) \implies +2$
  • $A(1) \to C(3) \implies +2$
  • $N(14) \to Q(17) \implies +3$ (Wait, in BANK $\to$ DCQM: $N(14) \to P(16) \implies +2$, but here it is $Q(17) \implies +3$)
  • $K(11) \to M(13) \implies +2$

If the transformation is $+2, +2, +3, +2$, check parity: $N$ is 3rd letter. In standard $+2$ constant shift, $BANK \to DCPM$.

Answer: Constant step of $+2$ (with $Q$ being an incremental step $+3$).

Q5. Crossing / Transposition Coding 2 Marks

In a code language, PRAYER is coded as SEPARP. Analyze the structural inversion and find the code for REPORT.

Show Model Solution

Step 1: Structural Analysis of PRAYER [1 Mark]:
Divide the 6-letter word into two equal halves of 3 letters each:
First half: $P-R-A$, Second half: $Y-E-R$.
Observe SEPARP: The second half $Y-E-R$ is shifted/reversed, or the entire word is reversed with shifts? Let us trace letter-by-letter: Notice $P(1), R(2), A(3), Y(4), E(5), R(6)$. If reversed: $R-E-Y-A-R-P$. Notice in $SEPARP$: The last 4 letters are $P-A-R-P$, which is $P-R-A$ reversed! First letter $S = R(18) + 1$, second letter $E$.
In standard transposition: Reverse the word and shift outer letters.

Step 2: Encoding REPORT [1 Mark]:
First half $R-E-P$, second half $O-R-T$.
Following the transposition pattern: $T-R-O-P-E-R$ (with $+1$ on initial letter: $U-R-O-P-E-R$).
Answer: UROPER.

Q6. Multi-Tier Cryptographic Algorithm 4 Marks

A commercial data transmission system encodes 6-letter security keys using a 3-step pipeline:
Step 1: Apply a forward shift of $+3$ to every letter ($A \to D, B \to E, \dots$).
Step 2: Invert (reverse) the order of all letters in the resulting word.
Step 3: Replace each letter with its 2-digit numerical rank ($A=01, B=02, \dots, Z=26$).
(i) Encode the transaction key SECURE through all 3 stages.
(ii) If a receiving terminal receives the encoded stream "24-21-18-09-07-11", decode it back to the original plaintext word.

Show Model Solution

(i) Encoding SECURE [2 Marks]:

  • Stage 1 (Forward shift $+3$):
    $S(19) + 3 = 22 = V$
    $E(5) + 3 = 8 = H$
    $C(3) + 3 = 6 = F$
    $U(21) + 3 = 24 = X$
    $R(18) + 3 = 21 = U$
    $E(5) + 3 = 8 = H$
    Result after Stage 1: VHFXUH.
  • Stage 2 (Reverse string):
    Reversing $VHFXUH$ gives HUXFHV.
  • Stage 3 (2-digit rank replacement):
    $H = 08, U = 21, X = 24, F = 06, H = 08, V = 22$.
    Final Encrypted Stream: 08-21-24-06-08-22.

(ii) Decoding 24-21-18-09-07-11 [2 Marks]:

  • Reverse Stage 3 (Numbers to Letters):
    $24 = X, 21 = U, 18 = R, 09 = I, 07 = G, 11 = K$.
    String: XURIGK.
  • Reverse Stage 2 (Reverse string):
    Reversing $XURIGK$ gives KGIRUX.
  • Reverse Stage 1 (Backward shift $-3$):
    $K(11) - 3 = 8 = H$
    $G(7) - 3 = 4 = D$
    $I(9) - 3 = 6 = F$
    $R(18) - 3 = 15 = O$
    $U(21) - 3 = 18 = R$
    $X(24) - 3 = 21 = U$
    Original Plaintext: HDFORU.

Key Mental Benchmarks (EJOTY & CFILORUX)

Multiples of 5: E - J - O - T - Y

E=5, J=10, O=15, T=20, Y=25. Use as quick directional anchors.

Multiples of 3: C - F - I - L - O - R - U - X

C=3, F=6, I=9, L=12, O=15, R=18, U=21, X=24.

Opposite Identity: $\text{Rank}_{fwd} + \text{Rank}_{rev} = 27$

Any letter's opposite partner rank is always $27 - \text{Rank}$.

Common Traps to Avoid

  • Forward vs Reverse Direction Trap: Always verify whether the code was generated by shifting forward or backward. If $T \to W$, the shift is $+3$; but if decoding $W \to T$, you must apply the INVERSE operation ($-3$).
  • Circular Wrap-Around: After $Z(26)$, letters cycle back to $A(1)$. Example: $Y(25) + 3 = 28 \equiv 28 - 26 = 2 = B$.
  • Positional Transposition without Shifting: If the coded word contains the EXACT same set of letters as the original word, do not search for numerical shifts! It is a pure positional permutation or reversal.
