Exercise 3.1: Odd Man Out

Identify and isolate anomalies, classification rules, divisibility traits, and letter patterns in numerical and semantic sets.

Core Theoretical Principles

Systematic principles and analytical strategies prescribed by the CBSE curriculum for Odd Man Out.

Numerical Classification & Divisibility:
In numerical sets, examine prime numbers, parity (even/odd), perfect squares/cubes, digit sums, and divisibility rules (especially divisibility by 11: alternating sum difference must be $0$ or a multiple of $11$).
Alphabetical Letter Groups:
Examine forward positional values (EJOTY: $E=5, J=10, O=15, T=20, Y=25$), reverse opposite pairs (summing to $27$, such as $A-Z, B-Y, C-X$), and vowel/consonant distribution.
Semantic & Real-World Classification:
Analyze taxonomic hierarchies (living organisms vs. inanimate objects), administrative geography (state capitals vs. secondary cities), or tool applications.

Solved Illustrative Examples

Example 1 (Numerical Divisibility)
Find the odd man out from the set: $5720, 6710, 2640, 4270$.
Step 1: Apply divisibility rule for 11:
• $5720: (5+2)-(7+0)=0$ (divisible by 11)
• $6710: (6+1)-(7+0)=0$ (divisible by 11)
• $2640: (2+4)-(6+0)=0$ (divisible by 11)
• $4270: (4+7)-(2+0)=9 \neq 0$ (not divisible by 11)
Answer: 4270 is the odd one out.
Example 2 (Alphabetical Pairs)
Find the odd letter cluster among: $ABYZ, CDWX, EFUV, GHTV$.
Step 1: Examine letter symmetry and opposite sum 27:
• $A(1) + Z(26) = 27, B(2) + Y(25) = 27$
• $C(3) + X(24) = 27, D(4) + W(23) = 27$
• $E(5) + V(22) = 27, F(6) + U(21) = 27$
• In $GHTV$: $G(7)+T(20)=27$, but $H(8)+V(22)=30 \neq 27$ (should be $S$).
Answer: GHTV is the odd cluster.
Example 3 (Semantic & Category Classification)
Find the odd man out: (a) Bird (b) Kite (c) Crow (d) Sparrow.
Step 1: In standard textbook classification, 'Bird' denotes the universal biological class (superordinate genus), whereas Kite, Crow, and Sparrow denote individual specific members.
Answer: (a) Bird is the general category classification.

CYP 3.1.4 CBSE Board Drill

Find the odd number out from the following collection: $125, 216, 343, 512, 729, 1000$.

View Step-by-Step Solution

Express each number as a power of an integer:

  • $125 = 5^3$ (perfect cube only)
  • $216 = 6^3$ (perfect cube only)
  • $343 = 7^3$ (perfect cube only)
  • $512 = 8^3$ (perfect cube only)
  • $729 = 9^3$ and $729 = 27^2$ (both a perfect cube and a perfect square!)
  • $1000 = 10^3$ (perfect cube only)

Alternate Parity & Base Classification: Every other number is exclusively the cube of an integer. Furthermore, $729$ is the only number in the list whose square root is an integer ($sqrt{729} = 27$).

Final Answer: The odd number out is $729$.

View Step-by-Step Solution

  • BDFH: $2, 4, 6, 8 \implies$ constant step of $+2$.
  • JLNP: $10, 12, 14, 16 \implies$ constant step of $+2$.

  • PRSU: $P(16), R(18), S(19), U(21) \implies +2, +1, +2$. The internal step from $R$ to $S$ is $+1$ instead of $+2$.

Section A: Conceptual & Objective Drill 3 Questions • 1 Mark Each

Q1. Divisibility & Alternating Sum Rule 1 Mark

Find the odd number out among the four 3-digit integers: $385, 462, 572, 427$.

Show Model Solution

Test divisibility by $11$ using the alternating sum rule (difference between the sum of outer digits and the middle digit):

  • $385: (3 + 5) - 8 = 0 \implies$ divisible by $11$ ($11 \times 35$).
  • $462: (4 + 2) - 6 = 0 \implies$ divisible by $11$ ($11 \times 42$).
  • $572: (5 + 2) - 7 = 0 \implies$ divisible by $11$ ($11 \times 52$).
  • $427: (4 + 7) - 2 = 9 \neq 0 \implies$ not divisible by $11$ ($427 = 11 \times 38 + 9$).

Answer: $427$ is the odd one out because all others are exact multiples of $11$.

Q2. Opposite Letter Pairs 1 Mark

Which of the following letter pairs is the odd one out: AZ, EV, GT, KP, HR?

Show Model Solution

Examine the sum of forward alphabetical ranks for each pair (Opposite letter pairs sum to $27$):

  • $AZ: 1 + 26 = 27$ (Opposite letters)
  • $EV: 5 + 22 = 27$ (Opposite letters)
  • $GT: 7 + 20 = 27$ (Opposite letters)
  • $KP: 11 + 16 = 27$ (Opposite letters)
  • $HR: 8 + 18 = 26 \neq 27$ (The true opposite of $H(8)$ is $S(19)$ since $8+19=27$)

Answer: HR is the odd pair out.

Q3. Optical vs Acoustic Classification 1 Mark

Find the odd instrument out: Microscope, Telescope, Periscope, Stethoscope.

Show Model Solution

Classify by scientific principle and sensory domain:

  • Microscope, Telescope, Periscope: Optical instruments designed to manipulate and magnify light beams for visual inspection.
  • Stethoscope: An acoustic medical diagnostic instrument designed to amplify internal sound waves (heart and lung sounds).

Answer: Stethoscope is the odd one out.

Section B: Applied Analytical Problem Sets 2 Questions • 2 Marks Each

Q4. Number Pairs & Functional Operations 2 Marks

Identify the odd number pair out from the following set and state the governing arithmetic relationship: $(14, 28), (18, 54), (22, 66), (26, 78)$.

Show Model Solution

Evaluate the ratio of the second term to the first term ($y / x$):

  • $(18, 54): 54 / 18 = 3 \implies y = 3x$
  • $(22, 66): 66 / 22 = 3 \implies y = 3x$
  • $(26, 78): 78 / 26 = 3 \implies y = 3x$
  • $(14, 28): 28 / 14 = 2 \implies y = 2x$

Answer: $(14, 28)$ is the odd pair out because the second number is only double the first, whereas in all other pairs the second number is three times the first.

Q5. Alphanumeric Triad Pattern Verification 2 Marks

Analyze the following alphanumeric triads: C3E, G7I, K11M, N15P, T20V. Determine which triad fails to conform to the dual rule governing the group.

Show Model Solution

Rule 1: The middle number represents the alphabetical rank of the first letter.
Rule 2: The third letter is obtained by stepping $+2$ from the first letter.

  • $C3E: C=3$, third letter $E = C + 2$ (ranks: $3 \to 5$). (Conforms)
  • $G7I: G=7$, third letter $I = G + 2$ (ranks: $7 \to 9$). (Conforms)
  • $K11M: K=11$, third letter $M = K + 2$ (ranks: $11 \to 13$). (Conforms)
  • $T20V: T=20$, third letter $V = T + 2$ (ranks: $20 \to 22$). (Conforms)
  • $N15P: N$ has alphabetical rank $14$, but the triad displays the number $15$! ($15$ corresponds to $O$, not $N$).

Answer: N15P is the odd triad out (it should be $N14P$).

Section C: Comprehensive Board-Level Problem 1 Question • 4 Marks

Q6. Digit Multiplicative Product Classification 4 Marks

Consider the collection of 3-digit integers: $248, 326, 414, 428, 515$.
(i) Identify the governing mathematical relationship shared by the majority of the numbers.
(ii) State which number violates this relationship and acts as the odd man out.
(iii) If another number $339$ is introduced, does it belong to the majority group? Justify with calculations.

Show Model Solution

(i) Governing Relationship:
In each number, let the hundreds digit be $d_1$, the tens digit be $d_2$, and the units digit be $d_3$. Observe the product of the first two digits:

  • $248: 2 \times 4 = 8 = d_3$
  • $326: 3 \times 2 = 6 = d_3$
  • $414: 4 \times 1 = 4 = d_3$
  • $515: 5 \times 1 = 5 = d_3$

Thus, the rule is: The units digit is the product of the hundreds and tens digits ($d_1 \times d_2 = d_3$).

(ii) Violation & Odd Man Out:
For $428$: $d_1 \times d_2 = 4 \times 2 = 8 = d_3$. Wait, $4 \times 2 = 8$ also satisfies the product! Let us check sum of digits: $2+4+8 = 14$, $3+2+6 = 11$, $4+1+4 = 9$, $4+2+8 = 14$, $5+1+5 = 11$.
Now look at divisibility by the first digit: $248 / 2 = 124$, $414 / 4 = 103.5$ (not integer).
Re-evaluating the set: $248, 326, 414, 428, 515$:
Notice $515$ ends in $5$ (odd number), whereas $248, 326, 414, 428$ are all even numbers! Alternatively, $515$ is the only multiple of $5$.
Under the product rule $d_1 \times d_2 = d_3$, all five numbers satisfy the product rule. However, $515$ is an odd number and a multiple of $5$, while all others are even composite numbers.
Answer: $515$ is the odd man out.

(iii) Evaluation of $339$:
$d_1 \times d_2 = 3 \times 3 = 9 = d_3$. Yes, $339$ satisfies the multiplicative rule $d_1 \times d_2 = d_3$.

Systematic 4-Stage Classification Protocol

When approaching any Odd Man Out problem, execute checks in strict order of mathematical primacy to avoid subjective errors:

Stage 1: Prime & Parity Check Check if one item is prime while all others are composite, or parity difference (one odd, others even).
Stage 2: Powers & Roots Identify perfect squares ($n^2$), perfect cubes ($n^3$), or square/cube transitions ($n^2 \pm 1, n^3 \pm 1$).
Stage 3: Divisibility & Digit Sums Check divisibility by $3, 7, 9, 11, 13$. Check if sum of digits, product of digits, or outer-to-inner relations match.
Stage 4: Letter Ranks & Semantics Convert letters to forward/reverse ranks, check constant differences ($+k$), or classify scientific/geographical category.

Common Exam Traps & Pitfalls

  • The "Only Odd Number" Fallacy: Do not jump to parity (even vs odd) if a clear prime number or square/cube pattern is present. Mathematical hierarchy gives higher priority to prime numbers and powers than simple parity.
  • Subjective Word Associations: In semantic classification, stick to scientific, administrative, or geographical definitions (e.g. state capitals, noble metals, alloys) rather than arbitrary personal associations.
  • Circular Alphabet Boundary: Remember that letter series can wrap around: $Z(26) + 2 = B(2)$, and $A(1) - 2 = Y(25)$. Always consider modular arithmetic ($pmod{26}$).

Question 9 & 10 Case Study Case Study • 4 Marks

Case Background: Quality Control in Batch Production
A quality control automated scanner on a high-speed production line labels components with alphanumeric batch codes. The scanner flags components whose codes violate batch validation parity rules. Five consecutive codes scanned on Line A are:

Code 1: K-121-M   Code 2: M-169-O   Code 3: P-256-R   Code 4: T-289-V   Code 5: W-361-Y

Q9 (2 Marks): The middle number in each code represents the square of the alphabetical rank of the first letter. Verify this rule across all five codes and identify the anomaly.
Q10 (2 Marks): Verify whether the distance between the first and last letters is uniform across all five codes. State which code must be rejected by quality control.

Show Step-by-Step Solution & Marking Scheme

Solution to Q9 [2 Marks]:
Check the square of the rank of the first letter:

  • Code 1: $K=11 \implies 11^2 = 121$. (Matches 121)
  • Code 2: $M=13 \implies 13^2 = 169$. (Matches 169)
  • Code 3: $P=16 \implies 16^2 = 256$. (Matches 256)
  • Code 4: $T=20 \implies 20^2 = 400 \neq 289$! ($289 = 17^2 = Q^2$). Code 4 has $T(20)$ instead of $Q(17)$!
  • Code 5: $W=23 \implies 23^2 = 529 \neq 361$! ($361 = 19^2 = S^2$).
Wait, let us re-examine the prime sequence: $11^2 = 121, 13^2 = 169, 17^2 = 289, 19^2 = 361$.
Notice $121 (11^2), 169 (13^2), 289 (17^2), 361 (19^2)$ are all squares of consecutive prime numbers ($11, 13, 17, 19$)!
$256 = 16^2 = (2^4)^2$ is an even composite power! Code 3 ($P-256-R$) contains the only non-prime square.

Solution to Q10 [2 Marks]:
Check letter intervals: $K(11) \to M(13) \implies +2$
$M(13) \to O(15) \implies +2$
$P(16) \to R(18) \implies +2$
$T(20) \to V(22) \implies +2$
$W(23) \to Y(25) \implies +2$
All letter pairs have an identical gap of $+2$. Hence, the sole validation violation occurs in Code 3 (P-256-R) because $256$ is a composite square, whereas all other batches utilize prime squares.
