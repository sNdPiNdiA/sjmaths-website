Chapter 3 Core Formula Sheet

Quick-glance formula revision for examination and numerical problem-solving:

  • $$\text{Statement: A declarative sentence which is either strictly true or strictly false, but not both.}$$
  • $$\text{Compound Statement: Formed by combining two or more simple statements using logical connectives.}$$
  • $$p \land q \text{ is True only when both } p \text{ and } q \text{ are True}$$
  • $$p \lor q \text{ is False only when both } p \text{ and } q \text{ are False}$$
  • $$p \rightarrow q \equiv \sim p \lor q \text{ (False only when } T \rightarrow F\text{)}$$
  • $$p \leftrightarrow q \text{ is True when } p \text{ and } q \text{ have identical truth values}$$
  • $$\text{Tautology: A statement pattern that is true for all possible truth values (T).}$$
  • $$\text{Contradiction: A statement pattern that is false for all possible truth values (F).}$$
  • $$\sim(p \land q) \equiv \sim p \lor \sim q, \quad \sim(p \lor q) \equiv \sim p \land \sim q$$
  • $$\sim(p \rightarrow q) \equiv p \land \sim q$$
