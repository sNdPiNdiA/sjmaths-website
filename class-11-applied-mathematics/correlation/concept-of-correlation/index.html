Concept of Correlation

Master the Concept of Correlation for CBSE Class 11 Applied Mathematics. Learn Pearson's r, scatter diagrams, and interpretation with solved examples.

Definition of Correlation

Correlation is a statistical measure that expresses the extent to which two variables are linearly related. It quantifies the strength and direction of the association between two quantitative variables, such as height and weight or advertising spend and sales. The value of the correlation coefficient, denoted by r, always lies in the closed interval [-1, 1].

r = Σ((xᵢ − x̄)(yᵢ − ȳ)) / √Σ(xᵢ − x̄)²Σ(yᵢ − ȳ)²

Step 2: Observe that as X increases, Y increases.
Step 3: Conclude that the correlation is positive, implying r > 0.
Answer: Positive Correlation.

Properties of Correlation Coefficient

The correlation coefficient r is a unit-free measure, meaning it remains unchanged by a change of origin or scale. If r = 1, there is a perfect positive linear relationship; if r = -1, there is a perfect negative linear relationship. If r = 0, the variables are uncorrelated, indicating no linear relationship exists between them.

r(aX + b, cY + d) = sign(a)·sign(c)·r(X, Y)

Interpretation of Scatter Diagrams

A scatter diagram is a graphical representation of bivariate data where each pair (xᵢ, yᵢ) is plotted as a point on a Cartesian plane. The pattern of these points reveals the nature of the correlation. A tight cluster around a line indicates a strong correlation, while a dispersed cloud indicates a weak correlation.

easyIf the covariance between X and Y is 12, and σₓ = 4, σᵧ = 5, find r.

Show Answer

✔ Correct: A

r = Cov(X, Y) / (σₓ·σᵧ) = 12 / (4·5) = 12 / 20 = 0.6.

3

mediumGiven Σ(xᵢ - x̄)(yᵢ - ȳ) = 50, Σ(xᵢ - x̄)² = 100, Σ(yᵢ - ȳ)² = 64, find r.

Show Answer

✔ Correct: A

r = 50 / √(100·64) = 50 / (10·8) = 50 / 80 = 0.625.

4

mediumIf r(X, Y) = 0.6, what is r(-2X + 3, 4Y - 1)?

Show Answer

✔ Correct: B

The sign of the coefficient changes because the coefficient of X is negative (-2) and Y is positive (4). Thus, r = -1·1·0.6 = -0.6.

5

hardIf n=10, Σx=30, Σy=40, Σxy=150, Σx²=120, Σy²=200, find r.

Show Answer

✔ Correct: A

Calculate x̄=3, ȳ=4. Numerator = Σxy - n·x̄·ȳ = 150 - 10(3)(4) = 30. Denominator = √((120 - 10·3²)(200 - 10·4²)) = √(30·40) = √1200 ≈ 34.6. r = 30/34.6 ≈ 0.86 (re-evaluating: 30/√(30*40) = 30/√(1200) = 30/34.64 = 0.86). Correcting calculation: 30/√(30*40) = 0.866. Choice A is closest.

6

hardIf the regression line is Y = 0.5X + 2 and the variance of X is 16, variance of Y is 9, find r.

Show Answer

✔ Correct: A

bᵧₓ = r·(σᵧ/σₓ). 0.5 = r·(3/4). r = 0.5·(4/3) = 2/3 ≈ 0.66.

7

very hardIf Σ(xᵢ - x̄)² = 200, Σ(yᵢ - ȳ)² = 128, and Σ(xᵢ - x̄)(yᵢ - ȳ) = 140, find the coefficient of determination r².

Show Answer

✔ Correct: A

r = 140 / √(200·128) = 140 / √(25600) = 140 / 160 = 0.875. r² = (0.875)² = 0.765625.

Section C: Short Answer Questions

1

mediumGiven X = {1, 2, 3, 4, 5} and Y = {2, 4, 5, 4, 5}. Find: (i) Mean of X and Y (ii) Covariance (iii) Correlation coefficient r.

Show Answer & Solution

(i) x̄ = 15/5 = 3; ȳ = 20/5 = 4.
(ii) Σ(x-x̄)(y-ȳ) = (-2)(-2) + (-1)(0) + (0)(1) + (1)(0) + (2)(1) = 4 + 0 + 0 + 0 + 2 = 6. Cov = 6/5 = 1.2.
(iii) Σ(x-x̄)² = 4+1+0+1+4 = 10. Σ(y-ȳ)² = 4+0+1+0+1 = 6. r = 1.2 / √(10·6/25) = 1.2 / √(2.4) = 1.2 / 1.549 = 0.77.

2

mediumGiven n=10, Σx=50, Σy=60, Σx²=300, Σy²=400, Σxy=320. Find: (i) x̄ and ȳ (ii) σₓ and σᵧ (iii) r.

Show Answer & Solution

(i) x̄ = 50/10 = 5; ȳ = 60/10 = 6.
(ii) σₓ² = 300/10 - 5² = 30-25=5, σₓ=√5 ≈ 2.23. σᵧ² = 400/10 - 6² = 40-36=4, σᵧ=2.
(iii) Cov = 320/10 - 5·6 = 32-30=2. r = 2 / (√5·2) = 1/√5 ≈ 0.447.

3

hardIf r = 0.8, σₓ = 3, σᵧ = 2. Find: (i) Cov(X, Y) (ii) r for (X+5, Y-2) (iii) r for (2X, 3Y).

Show Answer & Solution

(i) Cov = r·σₓ·σᵧ = 0.8·3·2 = 4.8.
(ii) Changing origin does not affect r, so r = 0.8.
(iii) Scaling does not affect r, so r = 0.8.

Section D: Long Answer Questions

1

hardCalculate the correlation coefficient for the following data: X: 10, 20, 30, 40, 50; Y: 12, 18, 25, 30, 35.

Show Answer & Solution

Step 1: x̄ = 150/5 = 30; ȳ = 120/5 = 24.
Step 2: Deviations (x-x̄): -20, -10, 0, 10, 20; (y-ȳ): -12, -6, 1, 6, 11.
Step 3: Products (x-x̄)(y-ȳ): 240, 60, 0, 60, 220. Sum = 580.
Step 4: Squares Σ(x-x̄)² = 400+100+0+100+400 = 1000. Σ(y-ȳ)² = 144+36+1+36+121 = 338.
Step 5: r = 580 / √(1000·338) = 580 / 581.37 = 0.997.

2

very hardGiven two variables X and Y with n=20, Σx=100, Σy=120, Σx²=600, Σy²=800, Σxy=650. Find the correlation coefficient and interpret the result.

Show Answer & Solution

Step 1: x̄ = 100/20 = 5; ȳ = 120/20 = 6.
Step 2: Cov(X, Y) = (Σxy/n) - x̄ȳ = (650/20) - (5·6) = 32.5 - 30 = 2.5.
Step 3: σₓ² = (600/20) - 5² = 30 - 25 = 5. σₓ = √5 ≈ 2.236.
Step 4: σᵧ² = (800/20) - 6² = 40 - 36 = 4. σᵧ = 2.
Step 5: r = 2.5 / (2.236·2) = 2.5 / 4.472 = 0.559. Interpretation: Moderate positive correlation.

Section E: Case-Based Question

★

Case Study: A retail store tracks the number of customers (X) and daily sales in thousands (Y) for 5 days: (10, 2), (15, 3), (20, 5), (25, 6), (30, 9).

Sub-question 1: (i) Find the mean of X and Y. (ii) Calculate the covariance.

Show Solution

(i) x̄ = (10+15+20+25+30)/5 = 100/5 = 20. ȳ = (2+3+5+6+9)/5 = 25/5 = 5.
(ii) Σ(x-x̄)(y-ȳ) = (-10)(-3) + (-5)(-2) + (0)(0) + (5)(1) + (10)(4) = 30 + 10 + 0 + 5 + 40 = 85. Cov = 85/5 = 17.

Sub-question 2: Calculate the correlation coefficient r.

Show Solution

Σ(x-x̄)² = 100+25+0+25+100 = 250. Σ(y-ȳ)² = 9+4+0+1+16 = 30. r = 85 / √(250·30) = 85 / √(7500) = 85 / 86.6 = 0.98.
