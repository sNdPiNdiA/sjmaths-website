Standard Equation of a Circle

A circle is the locus of a point which moves in a plane such that its distance from a fixed point (center) is always constant (radius). The standard form of a circle with center (h, k) and radius r is derived from the distance formula. This equation is fundamental for solving problems involving circular paths or boundaries.

(x − h)² + (y − k)² = r²
Example: Solved Example: Find the equation of a circle
Show Step-by-Step Solution

Step 1: Identify center (h, k) = (2, -3) and radius r = 5.
Step 2: Substitute into (x - h)² + (y - k)² = r².
Step 3: (x - 2)² + (y + 3)² = 25.
Answer: x² + y² - 4x + 6y - 12 = 0.

General Equation of a Circle

The general form represents a circle when the coefficients of x² and y² are equal and there is no xy term. By completing the square, we can transform the general equation into the standard form to identify the center and radius. This is essential for analyzing circular motion or geometric constraints.

x² + y² + 2gx + 2fy + c = 0
Example: Solved Example: Find center and radius
Show Step-by-Step Solution

Step 1: Given x² + y² + 4x - 6y - 3 = 0.
Step 2: Compare with 2g = 4 and 2f = -6, so g = 2, f = -3.
Step 3: Center is (-g, -f) = (-2, 3). Radius is √(g² + f² - c) = √(4 + 9 + 3) = 4.
Answer: Center (-2, 3), Radius 4.

Circle Passing Through Three Points

To find the equation of a circle passing through three non-collinear points, we substitute each point (x, y) into the general equation x² + y² + 2gx + 2fy + c = 0. This results in a system of three linear equations in variables g, f, and c. Solving this system allows us to define the unique circle passing through these points.

x² + y² + 2gx + 2fy + c = 0
Example: Solved Example: Circle through (0,0), (2,0), (0,2)
Show Step-by-Step Solution

Step 1: (0,0) gives c = 0.
Step 2: (2,0) gives 4 + 4g = 0 → g = -1.
Step 3: (0,2) gives 4 + 4f = 0 → f = -1.
Answer: x² + y² - 2x - 2y = 0.

mediumGiven the circle x² + y² - 4x - 6y - 12 = 0, find: (i) The center (ii) The radius (iii) The circumference.

mediumA circle has center (1, 2) and passes through (4, 6). Find: (i) The radius (ii) The equation (iii) Does (5, 5) lie on the circle?

Show Answer & Solution

(i) r = √((4-1)² + (6-2)²) = √(3² + 4²) = 5.
(ii) (x-1)² + (y-2)² = 25.
(iii) (5-1)² + (5-2)² = 4² + 3² = 25. Yes, it lies on the circle.

Section D: Long Answer Questions

1

hardFind the equation of the circle passing through the points A(1, 2), B(3, 4), and C(5, -6).

Show Answer & Solution

Step 1: Use general equation x² + y² + 2gx + 2fy + c = 0.
Step 2: For (1, 2): 1 + 4 + 2g + 4f + c = 0 → 2g + 4f + c = -5.
Step 3: For (3, 4): 9 + 16 + 6g + 8f + c = 0 → 6g + 8f + c = -25.
Step 4: For (5, -6): 25 + 36 + 10g - 12f + c = 0 → 10g - 12f + c = -61.
Step 5: Solve the system: Subtracting eq1 from eq2: 4g + 4f = -20 → g + f = -5. Subtracting eq2 from eq3: 4g - 20f = -36 → g - 5f = -9. Solving gives f = -1, g = -4. Then c = 7. Equation: x² + y² - 8x - 2y + 7 = 0.

2

very hardA circle is concentric with x² + y² - 4x + 6y - 12 = 0 and passes through the point (-1, 2). Find its equation.

Show Answer & Solution

Step 1: Find the center of the given circle: x² - 4x + y² + 6y = 12. Complete the square: (x-2)² - 4 + (y+3)² - 9 = 12 → (x-2)² + (y+3)² = 25. Center is (2, -3).
Step 2: The required circle is concentric, so its center is also (2, -3).
Step 3: The circle passes through (-1, 2). Find r²: r² = (-1 - 2)² + (2 - (-3))² = (-3)² + 5² = 9 + 25 = 34.
Step 4: Write the equation: (x - 2)² + (y + 3)² = 34.
Step 5: Expand: x² - 4x + 4 + y² + 6y + 9 = 34 → x² + y² - 4x + 6y - 21 = 0.

Section E: Case-Based Question

★

Case Study: A circular park is represented by the equation x² + y² - 10x - 8y + 37 = 0. A fountain is located at the center of the park. A walking path is constructed along the boundary of the park.

Sub-question 1: (i) Find the coordinates of the fountain. (ii) Calculate the radius of the park.

Show Solution

(i) x² - 10x + y² - 8y = -37. (x-5)² - 25 + (y-4)² - 16 = -37. (x-5)² + (y-4)² = 4. Center is (5, 4).
(ii) r² = 4, so r = 2 units.

Sub-question 2: If a new statue is placed at (5, 6), determine if it is inside, outside, or on the boundary of the park.

Show Solution

Distance from center (5, 4) to (5, 6) is √((5-5)² + (6-4)²) = √0 + 4 = 2. Since the distance equals the radius (2), the statue is on the boundary.
