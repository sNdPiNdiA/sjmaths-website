Domain, Range and Codomain of a Given Function

Master Domain, Range, and Codomain in CBSE Class 11 Applied Mathematics. Learn to identify function mappings with step-by-step solved examples.

Definition of Domain, Codomain, and Range

A function f: A → B is a relation where every element in set A has exactly one image in set B. The set A is called the domain, and set B is the codomain. The set of all actual images of elements of A in B is called the range.

Range(f) = {f(x) | x ∈ Domain(f)} ⊆ Codomain(f)
Example: Solved Example: Identify components of f: {1, 2, 3} → {2, 4, 6, 8} where f(x) = 2x
Show Step-by-Step Solution

Step 1: Domain is the input set {1, 2, 3}.
Step 2: Codomain is the target set {2, 4, 6, 8}.
Step 3: Calculate images: f(1)=2, f(2)=4, f(3)=6. Range is {2, 4, 6}.
Answer: Domain={1, 2, 3}, Codomain={2, 4, 6, 8}, Range={2, 4, 6}.

Finding Domain of Algebraic Functions

For real-valued functions, the domain is the set of all real numbers for which the expression is defined. We must exclude values that cause division by zero or result in the square root of a negative number.

f(x) = 1/g(x) ⟹ g(x) ≠ 0; f(x) = √g(x) ⟹ g(x) ≥ 0
Example: Solved Example: Find domain of f(x) = 1/(x - 5)
Show Step-by-Step Solution

Step 1: The denominator cannot be zero.
Step 2: Set x - 5 = 0 ⟹ x = 5.
Step 3: Exclude 5 from the set of real numbers.
Answer: Domain = R - {5}.

Determining Range of Functions

The range is the set of output values y = f(x) for all x in the domain. For simple functions, we express x in terms of y and find the values of y for which x is defined.

y = f(x) ⟹ x = f⁻¹(y)
Example: Solved Example: Find range of f(x) = 2x + 3 for x ∈ {0, 1, 2}
Show Step-by-Step Solution

Step 1: Substitute x=0: f(0)=3.
Step 2: Substitute x=1: f(1)=5.
Step 3: Substitute x=2: f(2)=7.
Answer: Range = {3, 5, 7}.

Section C: Short Answer Questions

1

mediumGiven f(x) = 2x + 5, find: (i) f(0) (ii) f(-2) (iii) The value of x if f(x) = 15.

Show Answer & Solution

(i) f(0) = 2(0)+5 = 5.
(ii) f(-2) = 2(-2)+5 = -4+5 = 1.
(iii) 2x+5 = 15 ⟹ 2x = 10 ⟹ x = 5.

2

mediumGiven f(x) = x² - 1, find: (i) f(3) (ii) f(-3) (iii) The domain if the range is {0, 3, 8}.

Show Answer & Solution

(i) f(3) = 3²-1 = 8.
(ii) f(-3) = (-3)²-1 = 8.
(iii) x²-1=0 ⟹ x=±1; x²-1=3 ⟹ x=±2; x²-1=8 ⟹ x=±3. Domain={±1, ±2, ±3}.

3

hardGiven f(x) = 1/(x - 2), find: (i) f(3) (ii) f(0) (iii) The value of x that is not in the domain.

Show Answer & Solution

(i) f(3) = 1/(3-2) = 1.
(ii) f(0) = 1/(0-2) = -0.5.
(iii) Denominator x-2=0 ⟹ x=2 is not in the domain.

Section D: Long Answer Questions

1

hardLet f(x) = 3x + 4. If the domain is { -2, -1, 0, 1, 2 }, (i) Find the range. (ii) Is this function a mapping from the domain to the set of integers? (iii) If the codomain is { -2, 1, 4, 7, 10 }, verify if the function is onto.

Show Answer & Solution

Step 1: Calculate f(-2)=3(-2)+4 = -2.
Step 2: Calculate f(-1)=3(-1)+4 = 1.
Step 3: Calculate f(0)=3(0)+4 = 4.
Step 4: Calculate f(1)=3(1)+4 = 7.
Step 5: Calculate f(2)=3(2)+4 = 10.
Answer: (i) Range = {-2, 1, 4, 7, 10}. (ii) Yes, all outputs are integers. (iii) Yes, Range = Codomain, so it is onto.

2

very hardConsider f(x) = x² + 2. (i) Find the domain if the range is {2, 3, 6, 11}. (ii) If the codomain is {0, 1, 2, 3, 6, 11}, identify the range. (iii) Determine if the function is one-to-one for the domain found in (i).

Show Answer & Solution

Step 1: Set x²+2=2 ⟹ x=0.
Step 2: Set x²+2=3 ⟹ x=±1.

Step 4: Set x²+2=11 ⟹ x=±3.
Step 5: Domain is {0, 1, -1, 2, -2, 3, -3}. Range is {2, 3, 6, 11}. It is not one-to-one because f(1)=f(-1)=3.

Section E: Case-Based Question

★

Case Study: A small business sells handmade pens. The cost function is C(x) = 50 + 10x, where x is the number of pens produced (x ∈ {1, 2, 3, 4, 5}).

Sub-question 1: (i) Find the range of the cost function. (ii) If the company sells each pen for ₹20, find the profit function P(x) = Revenue - Cost.

Show Solution

(i) f(1)=60, f(2)=70, f(3)=80, f(4)=90, f(5)=100. Range={60, 70, 80, 90, 100}. (ii) Revenue R(x)=20x. P(x)=20x-(50+10x)=10x-50.

Sub-question 2: Using the profit function, find the domain for which the company makes a profit (P(x) > 0).

Show Solution

10x-50 > 0 ⟹ 10x > 50 ⟹ x > 5. Since x is in {1, 2, 3, 4, 5}, there is no value in the current domain where the company makes a profit.
