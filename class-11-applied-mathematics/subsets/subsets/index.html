Definition of a Subset

A set A is said to be a subset of set B if every element of A is also an element of B. We denote this as A ⊆ B, which is read as A is a subset of B. If there exists at least one element in B that is not in A, then A is a proper subset of B, denoted as A ⊂ B.

A ⊆ B ⟺ (∀x ∈ A ⟹ x ∈ B)
Example: Solved Example: Identify Subsets
Show Step-by-Step Solution

Step 1: Let A = {1, 2} and B = {1, 2, 3}.
Step 2: Check if 1 ∈ A implies 1 ∈ B (Yes).
Step 3: Check if 2 ∈ A implies 2 ∈ B (Yes).
Answer: Since all elements of A are in B, A ⊆ B.

Power Set and Cardinality

The power set of a set A, denoted by P(A), is the set of all possible subsets of A. If a set A has n elements, then the number of elements in the power set P(A) is 2ⁿ. This formula is fundamental for determining the total number of subsets for any finite set.

n(P(A)) = 2ⁿ
Example: Solved Example: Calculate Power Set
Show Step-by-Step Solution

Step 1: Let A = {a, b}. Here n = 2.
Step 2: Use formula 2² = 4.
Step 3: List subsets: ∅, {a}, {b}, {a, b}.
Answer: P(A) = {∅, {a}, {b}, {a, b}}, total 4 subsets.

Intervals as Subsets of R

Intervals are specific types of subsets of real numbers. An open interval (a, b) consists of all real numbers between a and b, excluding the endpoints, while a closed interval [a, b] includes the endpoints. These are essential for representing solution sets in inequalities.

(a, b) = {x : a < x < b} and [a, b] = {x : a ≤ x ≤ b}
Example: Solved Example: Convert Inequality to Interval
Show Step-by-Step Solution

Step 1: Given inequality: 2 ≤ x < 5.
Step 2: Identify boundaries: 2 is included, 5 is excluded.
Step 3: Write in interval notation.
Answer: [2, 5).

Section D: Long Answer Questions

1

hardIn a survey of 50 students, 30 like Mathematics (M) and 25 like Physics (P). If 10 students like both, find: (i) Number of students who like only Math (ii) Only Physics (iii) At least one subject (iv) Neither subject (v) Verify n(M ∪ P) = n(M) + n(P) - n(M ∩ P).

Show Answer & Solution

Step 1: Given n(U)=50, n(M)=30, n(P)=25, n(M ∩ P)=10.
Step 2: Only Math = n(M) - n(M ∩ P) = 30 - 10 = 20.
Step 3: Only Physics = n(P) - n(M ∩ P) = 25 - 10 = 15.
Step 4: At least one = 20 + 15 + 10 = 45.
Step 5: Neither = 50 - 45 = 5. Verification: 30 + 25 - 10 = 45. Correct.

2

very hardLet A = {1, 2, 3}, B = {3, 4, 5}, C = {5, 6, 7}. Calculate: (i) A ∪ B (ii) (A ∪ B) ∪ C (iii) A ∩ B (iv) (A ∩ B) ∩ C (v) Verify if (A ∪ B) ∪ C = A ∪ (B ∪ C).

Show Answer & Solution

Step 1: A ∪ B = {1, 2, 3, 4, 5}.
Step 2: (A ∪ B) ∪ C = {1, 2, 3, 4, 5, 6, 7}.
Step 3: A ∩ B = {3}.
Step 4: (A ∩ B) ∩ C = {3} ∩ {5, 6, 7} = ∅.
Step 5: B ∪ C = {3, 4, 5, 6, 7}, so A ∪ (B ∪ C) = {1, 2, 3, 4, 5, 6, 7}. Since both sides equal {1, 2, 3, 4, 5, 6, 7}, the associative property is verified.

Section E: Case-Based Question

★

Case Study: A local club has 60 members. 40 members play Cricket, 30 members play Hockey, and 15 members play both sports.

Sub-question 1: (i) How many members play only Cricket? (ii) How many play only Hockey?

Show Solution

(i) Only Cricket = 40 - 15 = 25. (ii) Only Hockey = 30 - 15 = 15.

Sub-question 2: (i) How many members play at least one sport? (ii) How many members play neither?

Show Solution

(i) At least one = 25 + 15 + 15 = 55. (ii) Neither = 60 - 55 = 5.
