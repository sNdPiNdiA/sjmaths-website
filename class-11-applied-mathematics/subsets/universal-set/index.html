Universal Set

Master the concept of Universal Sets in CBSE Class 11 Applied Mathematics with detailed theory, solved examples, and practice problems.

Definition of Universal Set

A Universal Set is a set that contains all the elements under consideration for a particular context or problem. It is typically denoted by the symbol U. Every other set in the given context is a subset of the universal set.

U = {x | x ∈ S for all sets S in the context}
Example: Solved Example: Identifying U
Show Step-by-Step Solution

Step 1: Consider sets A = {1, 2, 3} and B = {3, 4, 5}.
Step 2: Identify all unique elements present in both sets.
Step 3: Define U = {1, 2, 3, 4, 5}.
Answer: U = {1, 2, 3, 4, 5}

Key Properties of Universal Sets

The universal set acts as the parent set for all subsets in a specific discussion. For any set A, the complement of A, denoted as A', is defined as U - A. The union of any set A with its complement A' always results in the universal set U.

A ∪ A' = U
Example: Solved Example: Verifying A ∪ A'
Show Step-by-Step Solution

Step 1: Let U = {1, 2, 3, 4, 5, 6} and A = {1, 2, 3}.
Step 2: Find A' = U - A = {4, 5, 6}.
Step 3: Calculate A ∪ A' = {1, 2, 3} ∪ {4, 5, 6} = {1, 2, 3, 4, 5, 6}.
Answer: A ∪ A' = U

Universal Set in Venn Diagrams

In a Venn diagram, the universal set is represented by a rectangle. All other subsets are represented by circles drawn inside this rectangle. The region inside the rectangle but outside the circles represents the elements of U that are not in the subsets.

n(U) = n(A) + n(A')
Example: Solved Example: Calculating n(A')
Show Step-by-Step Solution

Step 1: Given n(U) = 50 and n(A) = 20.
Step 2: Use the formula n(A') = n(U) - n(A).
Step 3: n(A') = 50 - 20 = 30.
Answer: n(A') = 30

1

Assertion (A): If U = {1, 2, 3} and A = {1, 2}, then A' = {3}.
Reason (R): The complement of a set A with respect to U is the set of elements in U that are not in A.

Choose the correct option:
(A) Both A and R are true and R is the correct explanation of A.
(B) Both A and R are true but R is not the correct explanation of A.
(C) A is true but R is false.
(D) A is false but R is true.

Show Answer

✔ Correct: A

Both assertion and reason are true, and the reason correctly explains the assertion.

2

Assertion (A): For any set A ⊆ U, A ∩ A' = U.
Reason (R): The intersection of a set and its complement is always the empty set.

Choose the correct option:
(A) Both A and R are true and R is the correct explanation of A.
(B) Both A and R are true but R is not the correct explanation of A.
(C) A is true but R is false.
(D) A is false but R is true.

Show Answer

✔ Correct: D

Assertion is false because A ∩ A' = ∅, not U. Reason is true.

hardIn a survey of 50 people, 30 like tea, 25 like coffee, and 10 like both. Find: (i) How many like only tea? (ii) How many like only coffee? (iii) How many like neither? (iv) Verify n(U) = n(T ∪ C) + n((T ∪ C)'). (v) Calculate n((T ∩ C)').

Show Answer & Solution

Step 1: Given n(U)=50, n(T)=30, n(C)=25, n(T ∩ C)=10.

Step 4: n(T ∪ C) = 20 + 15 + 10 = 45. Neither = 50 - 45 = 5.
Step 5: n((T ∩ C)') = 50 - 10 = 40.

Section E: Case-Based Question

★

Case Study: A school library tracks 100 students. 60 students borrowed a Science book, 40 borrowed a Math book, and 20 borrowed both. Let U be the set of all students, S be the set of Science borrowers, and M be the set of Math borrowers.

Sub-question 1: (i) Find the number of students who borrowed only Science books. (ii) Find the number of students who borrowed neither.

Show Solution

(i) Only Science = n(S) - n(S ∩ M) = 60 - 20 = 40. (ii) n(S ∪ M) = 60 + 40 - 20 = 80. Neither = 100 - 80 = 20.

Sub-question 2: If 10 students who borrowed neither are now added to the Math group, find the new n(M') and n(S ∩ M).

Show Solution

New n(M) = 40 + 10 = 50. New n(M') = 100 - 50 = 50. New n(S ∩ M) = 20 + 10 = 30.
