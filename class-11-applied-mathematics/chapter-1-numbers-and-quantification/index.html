Chapter 1 Core Formula Sheet

High-Yield Summary

Quick-glance formula revision for examination and numerical problem-solving:

  • $$Value = \sum_{i=0}^{n} d_i \times 2^i \text{ where } d_i \in \{0, 1\}$$
  • $$1 + 1 = 10_2 \text{ (Sum: 0, Carry: 1)}$$
  • $$2^0=1, 2^1=2, 2^2=4, 2^3=8, 2^4=16, 2^5=32$$
  • $$a^m \cdot a^n = a^{m+n}$$
  • $$\frac{a^m}{a^n} = a^{m-n}$$
  • $$(a^m)^n = a^{mn}$$
  • $$a^{-n} = \frac{1}{a^n}, \quad a^{1/n} = \sqrt[n]{a}$$
  • $$a^0 = 1 \quad (a \ne 0)$$
  • $$\log_b(xy) = \log_b x + \log_b y$$
  • $$\log_b\left(\frac{x}{y}\right) = \log_b x - \log_b y$$
  • $$\log_b(x^k) = k \log_b x$$
  • $$\log_b a = \frac{\log_c a}{\log_c b}, \quad \log_b 1 = 0, \; \log_b b = 1$$
  • $$\text{Characteristic } + \text{ Mantissa} = \log_{10} N$$
  • $$\text{Units, Tens, Hundreds, Thousands, Ten Thousands, Lakhs, Crores}$$
  • $$1 \text{ Lakh} = 10^5, \quad 1 \text{ Crore} = 10^7, \quad 1 \text{ Arab} = 10^9$$

1 Mark Each
Question 1 MCQ • 1 Mark

$6561^{0.14} \times 6561^{0.11} = ?$

(a) 16
(b) 9
(c) 4
(d) 1
Show Step-by-Step Solution
Step 1: By the product law of indices: $a^m \cdot a^n = a^{m+n}$.
$6561^{0.14} \times 6561^{0.11} = 6561^{0.14 + 0.11} = 6561^{0.25} = 6561^{1/4}$.
Step 2: Express 6561 as a prime power: $6561 = 3^8$.
$(3^8)^{1/4} = 3^{8/4} = 3^2 = 9$.
Correct Option: (b) 9
Question 2 MCQ • 1 Mark

$\log_5(0) = ?$

(a) Not Defined
(b) 5
(c) 0
(d) 1
Show Step-by-Step Solution
By definition of logarithm: $\log_b N = x \iff b^x = N$. For any real base $b > 0$, $b^x > 0$ for all real $x$. There is no real power of 5 that produces 0. Hence $\log_5(0)$ is Not Defined.
Correct Option: (a) Not Defined
Question 3 MCQ • 1 Mark

If $(\sqrt{3})^n = 6561$, then $(n)^{1/2} = ?$

(a) 64
(b) $64\sqrt{3}$
(c) $16\sqrt{3}$
(d) 4
Show Step-by-Step Solution
$(\sqrt{3})^n = (3^{1/2})^n = 3^{n/2}$.
Since $6561 = 3^8$, equating exponents gives $\frac{n}{2} = 8 \implies n = 16$.
Then $(n)^{1/2} = \sqrt{16} = \mathbf{4}$.
Correct Option: (d) 4
Question 4 MCQ • 1 Mark

If $5^x \times 2^3 = 36$, then $5^{(x+1)} = ?$

(a) 22
(b) 21
(c) 20.5
(d) 22.5
Show Step-by-Step Solution
$5^x \times 8 = 36 \implies 5^x = \frac{36}{8} = 4.5$.
Now $5^{x+1} = 5^x \times 5^1 = 4.5 \times 5 = \mathbf{22.5}$.
Correct Option: (d) 22.5
Question 5 MCQ • 1 Mark

$36^{120} = (36 \times x)^{40}$. What is the value of $x$?

(a) 44
(b) 62
(c) 64
(d) 1296
Show Step-by-Step Solution
Rewrite LHS: $36^{120} = (36^3)^{40}$.
So $(36^3)^{40} = (36 \times x)^{40} \implies 36^3 = 36 \times x \implies x = 36^2 = \mathbf{1296}$.
Correct Option: (d) 1296
Question 6 MCQ • 1 Mark

$(6561)^{1/2} + (6561)^{1/4} + (6561)^{1/8} = ?$

(a) 98
(b) 86
(c) 93
(d) 81
Show Step-by-Step Solution
• $(6561)^{1/2} = \sqrt{6561} = 81$
• $(6561)^{1/4} = \sqrt{81} = 9$
• $(6561)^{1/8} = \sqrt{9} = 3$
Sum $= 81 + 9 + 3 = \mathbf{93}$.
Correct Option: (c) 93
Question 7 MCQ • 1 Mark

Which of the following statements is not correct?

(a) $\log(2 \times 4 \times 6) = \log 2 + \log 4 + \log 6$
(b) $\log_5 1 = 0$
(c) $\log(3 + 4) = \log(3 \times 4)$
(d) $\log_5 5 = 1$
Show Step-by-Step Solution
$\log(3+4) = \log 7$, while $\log(3 \times 4) = \log 12 \ne \log 7$. Logarithms do not distribute across addition.
Correct Option: (c)
Question 8 MCQ • 1 Mark

If $5^{(a+b)} = 5 \times 25 \times 125$, what is $(a+b)^2$?

(a) 12
(b) 16
(c) 34
(d) 36
Show Step-by-Step Solution
$5 \times 25 \times 125 = 5^1 \times 5^2 \times 5^3 = 5^{1+2+3} = 5^6$.
Equating bases: $a+b = 6$. Therefore $(a+b)^2 = 6^2 = \mathbf{36}$.
Correct Option: (d) 36
Question 9 MCQ • 1 Mark

What is the value of $(7^{-14} - 7^{-15})$?

(a) $6 \times 7^{-15}$
(b) $6 \times 7^{-14}$
(c) $7 \times 7^{-15}$
(d) $7 \times 7^{-14}$
Show Step-by-Step Solution
Factor out the smaller power $7^{-15}$:
$7^{-14} - 7^{-15} = 7^{-15}(7^1 - 1) = \mathbf{6 \times 7^{-15}}$.
Correct Option: (a) $6 \times 7^{-15}$
Question 10 MCQ • 1 Mark

If $3^{(n+4)} - 3^{(n+2)} = 8$, what is the value of $n$?

(a) 0
(b) -1
(c) -2
(d) 2
Show Step-by-Step Solution
$3^{n+2}(3^2 - 1) = 8 \implies 3^{n+2}(8) = 8 \implies 3^{n+2} = 1 = 3^0$.
$n + 2 = 0 \implies \mathbf{n = -2}$.
Correct Option: (c) -2
Question 11 MCQ • 1 Mark

If $2^x = \sqrt[10]{1024}$, what is the value of $x$?

(a) None of these
(b) $-7/10$
(c) $10/7$
(d) $7/10$
Show Step-by-Step Solution
$\sqrt[10]{1024} = (2^{10})^{1/10} = 2^1 = 2$.
$2^x = 2^1 \implies x = 1$. Since $x = 1$ is not in (b), (c), or (d):
Correct Option: (a) None of these
Question 12 MCQ • 1 Mark

Evaluate: $[3^{-2} - 5^{-2}]^{1/2} = ?$

(a) 15/4
(b) 4/15
(c) 7/4
(d) 4/7
Show Step-by-Step Solution
$3^{-2} = \frac{1}{9}$ and $5^{-2} = \frac{1}{25}$.
$3^{-2} - 5^{-2} = \frac{1}{9} - \frac{1}{25} = \frac{25 - 9}{225} = \frac{16}{225}$.
$[3^{-2} - 5^{-2}]^{1/2} = \sqrt{\frac{16}{225}} = \mathbf{\frac{4}{15}}$.
Correct Option: (b) 4/15

Question 13 5 Sub-parts

Convert the following decimal numbers to binary notation:
(i) 4,   (ii) 49,   (iii) 267,   (iv) 1024,   (v) 4103.

Show Step-by-Step Solution
• (i) 4: $4 = 2^2 \implies \mathbf{(100)_2}$
• (ii) 49: $49 = 32 + 16 + 1 = 2^5 + 2^4 + 2^0 \implies \mathbf{(110001)_2}$
• (iii) 267: $267 = 256 + 8 + 2 + 1 = 2^8 + 2^3 + 2^1 + 2^0 \implies \mathbf{(100001011)_2}$
• (iv) 1024: $1024 = 2^{10} \implies \mathbf{(10000000000)_2}$
• (v) 4103: $4103 = 4096 + 7 = 2^{12} + 2^2 + 2^1 + 2^0 \implies \mathbf{(1000000000111)_2}$
Question 14 4 Sub-parts

Convert the following binary numbers to decimal numbers:
(i) $(1000)_2$,   (ii) $(11001)_2$,   (iii) $(1110101)_2$,   (iv) $(10011001)_2$.

Show Step-by-Step Solution
• (i) $(1000)_2$: $1 \times 2^3 = \mathbf{8}$
• (ii) $(11001)_2$: $16 + 8 + 1 = \mathbf{25}$
• (iii) $(1110101)_2$: $64 + 32 + 16 + 4 + 1 = \mathbf{117}$
• (iv) $(10011001)_2$: $128 + 16 + 8 + 1 = \mathbf{153}$
Question 15 5 Sub-parts

Convert the following exponential statements to logarithmic form:
(i) $10^3 = 1000$
(ii) $10^{-2} = .01$
(iii) $(0.2)^3 = .008$
(iv) $4^{-2} = 1/16$
(v) $(81)^{3/4} = 27$

Show Step-by-Step Solution
By the equivalence $b^x = N \iff \log_b N = x$:
• (i) $10^3 = 1000 \implies \mathbf{\log_{10} 1000 = 3}$
• (ii) $10^{-2} = 0.01 \implies \mathbf{\log_{10}(0.01) = -2}$
• (iii) $(0.2)^3 = 0.008 \implies \mathbf{\log_{0.2}(0.008) = 3}$
• (iv) $4^{-2} = 1/16 \implies \mathbf{\log_4(1/16) = -2}$
• (v) $(81)^{3/4} = 27 \implies \mathbf{\log_{81} 27 = 3/4}$
Question 16 5 Sub-parts

Convert the following logarithmic statements to exponential form:
(i) $\log_2 2 = 1$
(ii) $\log_5(1/5) = -1$
(iii) $\log_{10}(0.001) = -3$
(iv) $\log_{27} 9 = 2/3$
(v) $\log_4 1 = 0$

Show Step-by-Step Solution
By the rule $\log_b N = x \iff b^x = N$:
• (i) $\log_2 2 = 1 \implies \mathbf{2^1 = 2}$
• (ii) $\log_5(1/5) = -1 \implies \mathbf{5^{-1} = 1/5}$
• (iii) $\log_{10}(0.001) = -3 \implies \mathbf{10^{-3} = 0.001}$
• (iv) $\log_{27} 9 = 2/3 \implies \mathbf{27^{2/3} = 9}$
• (v) $\log_4 1 = 0 \implies \mathbf{4^0 = 1}$

Question 17 Solve for x • 4 Sub-parts

Solve for $x$ in each of the following equations:
(i) $\log_3 x = 2$
(ii) $\log_{0.2}(x + 1) = -2$
(iii) $\log_2(x^2 - 1) = 3$
(iv) $\log_{10}(x - 10) = 1$

Show Step-by-Step Solution
• (i) $\log_3 x = 2$: $x = 3^2 = \mathbf{9}$

• (ii) $\log_{0.2}(x + 1) = -2$: $x + 1 = (0.2)^{-2} = \left(\frac{1}{5}\right)^{-2} = 5^2 = 25 \implies x = 25 - 1 = \mathbf{24}$

• (iii) $\log_2(x^2 - 1) = 3$: $x^2 - 1 = 2^3 = 8 \implies x^2 = 9 \implies \mathbf{x = \pm 3}$

• (iv) $\log_{10}(x - 10) = 1$: $x - 10 = 10^1 = 10 \implies \mathbf{x = 20}$

Find the characteristic of the logarithm of each of the following numbers:

Question 21 Antilog Evaluation

Using the Antilogarithm table, find $x$ if:
(i) $\log x = 1.5647$
(ii) $\log x = 2.9031$
(iii) $\log x = 2.4567$
(iv) $\log x = -2.1304$

Show Step-by-Step Solution
• (i) $\text{Antilog}(1.5647)$: Mantissa $0.5647 \to 3670$. Char $= 1 \implies$ decimal after 2 digits: $\mathbf{36.70}$
• (ii) $\text{Antilog}(2.9031)$: Mantissa $0.9031 \to 8000$. Char $= 2 \implies$ decimal after 3 digits: $\mathbf{800.0}$
• (iii) $\text{Antilog}(2.4567)$: Mantissa $0.4567 \to 2862$. Char $= 2 \implies$ decimal after 3 digits: $\mathbf{286.2}$
• (iv) $\log x = -2.1304$: Convert negative log: $-2.1304 = -3 + (1 - 0.1304) = \bar{3}.8696$.
Mantissa $0.8696 \to 7406$. Char $= \bar{3} \implies$ prefix two zeros after decimal: $\mathbf{0.007406}$.

Part 5: Advanced Exponent & Logarithm Problems (Q22 – Q34)

3 – 4 Marks Each
Question 22 Simplification • 3 Marks

Simplify: $\left(\frac{x^a}{x^b}\right)^{a+b} \left(\frac{x^b}{x^c}\right)^{b+c} \left(\frac{x^c}{x^a}\right)^{c+a}$.

Show Step-by-Step Solution
Apply quotient law $\frac{x^a}{x^b} = x^{a-b}$:
$=(x^{a-b})^{a+b} \cdot (x^{b-c})^{b+c} \cdot (x^{c-a})^{c+a}$
$=x^{(a-b)(a+b)} \cdot x^{(b-c)(b+c)} \cdot x^{(c-a)(c+a)}$
$=x^{a^2 - b^2} \cdot x^{b^2 - c^2} \cdot x^{c^2 - a^2}$
$=x^{(a^2 - b^2) + (b^2 - c^2) + (c^2 - a^2)} = x^0 = \mathbf{1}$.
Question 23 System of Exponentials • 3 Marks

If $7^{(x-y)} = 343$ and $7^{(x+y)} = 16807$, what is the value of $x$?

Show Step-by-Step Solution
Since $343 = 7^3$, we have $7^{x-y} = 7^3 \implies x - y = 3$ … (1)
Since $16807 = 7^5$, we have $7^{x+y} = 7^5 \implies x + y = 5$ … (2)
Adding equations (1) and (2):
$2x = 8 \implies \mathbf{x = 4}$ (and $y = 1$).
Question 24 Calculations • 3 Marks

(a) $(0.04)^{-2.5} = ?$      (b) $(6)^{6.5} \times (36)^{4.5} \div (216)^{4.5} = (6)^?$

Show Step-by-Step Solution
• (a): $(0.04)^{-2.5} = \left(\frac{4}{100}\right)^{-5/2} = \left(\frac{1}{25}\right)^{-5/2} = (5^{-2})^{-5/2} = 5^{(-2) \times (-5/2)} = 5^5 = \mathbf{3125}$.

• (b): In base 6:
$(6)^{6.5} \times (6^2)^{4.5} \div (6^3)^{4.5} = 6^{6.5} \times 6^9 \div 6^{13.5} = 6^{6.5 + 9 - 13.5} = 6^2 = 36$.
The unknown power is $\mathbf{2}$.
Question 25 Number Theory Exponents • 3 Marks

If $m$ and $n$ are whole numbers and $m^n = 196$, what is the value of $(m - 3)^{(n+1)}$?

Show Step-by-Step Solution
$196 = 14^2$. Thus $m = 14$ and $n = 2$.
$(m - 3)^{n+1} = (14 - 3)^{2+1} = 11^3 = \mathbf{1331}$.
Question 26 Single Logarithm • 3 Marks

Express as a single logarithm:
(a) $\log(75/16) - 2\log(5/9) + \log(32/243)$
(b) $2\log(15/18) - \log(25/162) + \log(4/9)$

Show Step-by-Step Solution
• (a): $\log\left(\frac{75}{16}\right) - \log\left(\frac{25}{81}\right) + \log\left(\frac{32}{243}\right) = \log\left[\frac{75}{16} \times \frac{81}{25} \times \frac{32}{243}\right] = \log\left[3 \times 81 \times \frac{2}{243}\right] = \log\left[\frac{243 \times 2}{243}\right] = \mathbf{\log 2}$.

• (b): $\log\left(\frac{225}{324}\right) - \log\left(\frac{25}{162}\right) + \log\left(\frac{4}{9}\right) = \log\left[\frac{225}{324} \times \frac{162}{25} \times \frac{4}{9}\right] = \log\left[9 \times \frac{1}{2} \times \frac{4}{9}\right] = \mathbf{\log 2}$.
Question 27 Algebraic Substitution • 3 Marks

If $\log x = m + n$ and $\log y = m - n$, express the value of $\log(10x/y^2)$ in terms of $m$ and $n$.

Show Step-by-Step Solution
$\log\left(\frac{10x}{y^2}\right) = \log 10 + \log x - 2\log y$
$= 1 + (m + n) - 2(m - n)$
$= 1 + m + n - 2m + 2n = \mathbf{1 - m + 3n}$.
Question 28 Base Change Equation • 3 Marks

Solve for $x$: $\log_2 x + \log_4 x + \log_{16} x = \frac{21}{4}$.

Show Step-by-Step Solution
Express all terms in base 2 using $\log_{b^k} x = \frac{1}{k}\log_b x$:
$\log_2 x + \frac{1}{2}\log_2 x + \frac{1}{4}\log_2 x = \frac{21}{4}$
$\left(1 + \frac{1}{2} + \frac{1}{4}\right)\log_2 x = \frac{21}{4} \implies \frac{7}{4}\log_2 x = \frac{21}{4}$
$\log_2 x = 3 \implies x = 2^3 = \mathbf{8}$.
Question 29 Algebraic Proof • 4 Marks

Simplify:
(a) $\left(\frac{x^p}{x^q}\right)^{q+r-p} \left(\frac{x^q}{x^r}\right)^{r+p-q} \left(\frac{x^r}{x^p}\right)^{p+q-r}$
(b) $\frac{1}{1 + x^{q-p} + x^{r-p}} + \frac{1}{1 + x^{p-q} + x^{r-q}} + \frac{1}{1 + x^{p-r} + x^{q-r}}$

Show Step-by-Step Solution
• (a): Exponent for the 1st term: $(p - q)(q + r - p) = pq + pr - p^2 - q^2 - qr + pq = 2pq + pr - qr - p^2 - q^2$.
Summing cyclically across all three terms yields 0:
$x^0 = \mathbf{1}$.

• (b): Multiply numerator and denominator of 1st fraction by $x^p$, 2nd by $x^q$, 3rd by $x^r$:
$\frac{x^p}{x^p + x^q + x^r} + \frac{x^q}{x^q + x^p + x^r} + \frac{x^r}{x^r + x^p + x^q} = \frac{x^p + x^q + x^r}{x^p + x^q + x^r} = \mathbf{1}$.
Question 30 Classic CBSE Proof • 4 Marks

If $2^x = 3^y = 12^z$, prove that $x = \frac{2yz}{y - z}$.

Show Step-by-Step Solution
Step 1: Let $2^x = 3^y = 12^z = k$.
Then $2 = k^{1/x}$, $3 = k^{1/y}$, and $12 = k^{1/z}$.
Step 2: Note that $12 = 2^2 \times 3$. Substitute in terms of $k$:
$k^{1/z} = (k^{1/x})^2 \cdot k^{1/y} = k^{2/x + 1/y}$
Step 3: Equate exponents:
$\frac{1}{z} = \frac{2}{x} + \frac{1}{y} \implies \frac{2}{x} = \frac{1}{z} - \frac{1}{y} = \frac{y - z}{yz}$
Taking reciprocals: $\frac{x}{2} = \frac{yz}{y - z} \implies \mathbf{x = \frac{2yz}{y - z}}$. (Hence Proved)
Question 31 Simplification • 3 Marks

Simplify: $\frac{(1024)^n \times 4^{2n+1}}{16^n \times 4^{n-1}}$.

Show Step-by-Step Solution
Convert all terms to base 2 ($1024 = 2^{10}$, $16 = 2^4$, $4 = 2^2$):
• Numerator: $(2^{10})^n \times (2^2)^{2n+1} = 2^{10n} \times 2^{4n+2} = 2^{14n+2}$
• Denominator: $(2^4)^n \times (2^2)^{n-1} = 2^{4n} \times 2^{2n-2} = 2^{6n-2}$
• Quotient: $2^{(14n+2) - (6n-2)} = 2^{8n+4} = (2^4)^{2n+1} = \mathbf{16^{2n+1} \text{ or } 4^{4n+2}}$.
Question 32 Exponent Relationship • 3 Marks

If $(ab)^{x-y} = (ba)^{y-x}$, what is the value of $(x - y)$?

Show Step-by-Step Solution
Since $ba = ab$, $(ab)^{x-y} = (ab)^{-(x-y)} = \frac{1}{(ab)^{x-y}}$.
$[(ab)^{x-y}]^2 = 1 \implies (ab)^{2(x-y)} = (ab)^0$.
For any $ab \ne 1$, $2(x - y) = 0 \implies \mathbf{x - y = 0}$ (i.e. $x = y$).
Question 33 Equation System • 3 Marks

If $100^{0.20} = x$, $10^{0.60} = y$, and $x^z = y^2$, what is the value of $z$?

Show Step-by-Step Solution
$x = (10^2)^{0.20} = 10^{0.40}$.
$y^2 = (10^{0.60})^2 = 10^{1.20}$.
Now $x^z = (10^{0.40})^z = 10^{0.40z}$.
Equating powers of 10: $0.40z = 1.20 \implies z = \frac{1.20}{0.40} = \mathbf{3}$.
Question 34 Log Table Numerical • 4 Marks

Evaluate the following expressions using log tables:
(i) $\frac{(2.463)^3 \times (72.42)^{1/2}}{(34.59)^5}$      (ii) $\sqrt{\frac{(238.2)^2 \times 86.34}{92.3}}$

Show Step-by-Step Solution
• (i): Let $N = \frac{(2.463)^3 \times (72.42)^{1/2}}{(34.59)^5}$.
$\log N = 3\log(2.463) + \frac{1}{2}\log(72.42) - 5\log(34.59)$
$= 3(0.3915) + \frac{1}{2}(1.8598) - 5(1.5389) = 1.1745 + 0.9299 - 7.6945 = -5.5901 = \bar{6}.4099$.
$N = \text{Antilog}(\bar{6}.4099) = \mathbf{2.570 \times 10^{-6}}$.

• (ii): Let $K = \sqrt{\frac{(238.2)^2 \times 86.34}{92.3}}$.
$\log K = \frac{1}{2}[2\log(238.2) + \log(86.34) - \log(92.3)]$
$= \frac{1}{2}[2(2.3770) + 1.9362 - 1.9652] = \frac{1}{2}[4.7540 - 0.0290] = \frac{1}{2}[4.7250] = 2.3625$.
$K = \text{Antilog}(2.3625) = \mathbf{230.4}$.

Part 6: Case Study Question (Q35)

CBSE Real-Life Modeling • 4 Marks
Question 35: Case Study 4 Marks Total
Case Background: Let the population of the world in $t$ years after 2010 be given by the formula: $$P = 4.7(1.02)^t \quad \text{billions}$$

(i) [2 Marks]: Calculate the total population of the world in the year 2029 to the nearest million.

Show Solution for (i)
$t = 2029 - 2010 = 19$ years.
$P = 4.7(1.02)^{19}$.
Taking logs: $\log P = \log 4.7 + 19\log(1.02) = 0.6721 + 19(0.0086) = 0.6721 + 0.1634 = 0.8355$.
$P = \text{Antilog}(0.8355) \approx 6.847\text{ billion} = \mathbf{6,847\text{ million}}$.

(ii) [2 Marks]: Find the year in which the population will be double the population of 2020.

Show Solution for (ii)
At year 2020 ($t_1 = 10$), population is $P_{2020} = 4.7(1.02)^{10}$.
We need $P_t = 2 \times P_{2020} \implies 4.7(1.02)^t = 2 \times 4.7(1.02)^{10}$.
Dividing both sides: $(1.02)^{t-10} = 2$.
Taking log: $(t - 10)\log(1.02) = \log 2 \implies t - 10 = \frac{\log 2}{\log 1.02} = \frac{0.30103}{0.00860} \approx 35\text{ years}$.
The year will be $2020 + 35 = \mathbf{2055}$.

Part 7: Reasoning & Assertion Questions (Q1 – Q5)

CBSE Exam Pattern
Standard Directions:
(a) Both A and R are true, and R is the correct explanation of A.
(b) Both A and R are true, but R is not the correct explanation of A.
(c) A is true, but R is false.
(d) A is false, but R is true.
Assertion-Reason 1 1 Mark

Assertion (A): $\log(x^2 - 9) = \log(x - 3) + \log(x + 3)$ is valid for all real values of $x \ne \pm 3$.
Reason (R): The logarithm of a product equals the sum of logarithms.

Show Answer & Explanation
Answer: (d) A is false, but R is true.
Explanation: Reason R is a true property: $\log(MN) = \log M + \log N$ for $M, N > 0$.
However, Assertion A is false because for $x \in (-3, 3)$, $x^2 - 9 < 0$ so LHS is undefined. Furthermore, for $x < -3$, both $x - 3 < 0$ and $x + 3 < 0$, making the terms on the RHS undefined individually in real numbers. Thus equality does NOT hold for all $x \ne \pm 3$, only for $x > 3$.
Assertion-Reason 2 1 Mark

Assertion (A): $a^{p+q} \cdot a^{p-q} = a^{2p}$.
Reason (R): When powers having the same base are multiplied, the exponents are added.

Show Answer & Explanation
Answer: (a) Both A and R are true, and R is the correct explanation of A.
Explanation: By product law $a^m \cdot a^n = a^{m+n}$, we have $a^{(p+q) + (p-q)} = a^{2p}$.
Assertion-Reason 3 1 Mark

Assertion (A): If $\log x + \log y = 0$, then $xy = 1$.
Reason (R): $\log(xy) = \log x + \log y$.

Show Answer & Explanation
Answer: (a) Both A and R are true, and R is the correct explanation of A.
Explanation: $\log(xy) = \log x + \log y = 0 \implies xy = 10^0 = 1$.
Assertion-Reason 4 1 Mark

Assertion (A): The decimal number 13 is represented as 1101 in the binary system.
Reason (R): Binary representation is formed by expressing a number as a sum of powers of 2.

Show Answer & Explanation
Answer: (a) Both A and R are true, and R is the correct explanation of A.
Explanation: $13 = 8 + 4 + 1 = 2^3 + 2^2 + 2^0 = (1101)_2$.
Assertion-Reason 5 1 Mark

Assertion (A): If $\log(\log x)$ is defined, then $x > 1$.
Reason (R): The argument of every logarithm must be strictly positive.

Show Answer & Explanation
Answer: (a) Both A and R are true, and R is the correct explanation of A.
Explanation: For $\log(\log x)$ to be defined, the argument $\log x$ must be strictly positive, i.e., $\log x > 0 \implies x > 10^0 \implies x > 1$.
