Limit of a Function

Master the concept of Limits in CBSE Class 11 Applied Mathematics. Learn to evaluate limits of algebraic functions with step-by-step NCERT-style solutions.

Concept of a Limit

A limit describes the value that a function approaches as the input approaches a specific point. We write this as lim x→a f(x) = L, meaning that as x gets closer to a, f(x) gets arbitrarily close to L. It is important to note that the function does not need to be defined at x = a for the limit to exist.

lim x→a f(x) = L
Example: Solved Example: Evaluate lim x→2 (x² + 3)
Show Step-by-Step Solution

Step 1: Identify the function f(x) = x² + 3 and the point a = 2.
Step 2: Substitute x = 2 directly into the expression.
Step 3: Calculate (2)² + 3 = 4 + 3 = 7.
Answer: 7

Algebra of Limits

Limits follow specific algebraic rules that allow us to simplify complex expressions. If lim x→a f(x) = L and lim x→a g(x) = M, then the limit of the sum, difference, product, and quotient can be calculated individually. These properties are essential for solving polynomial and rational functions.

lim x→a [f(x) ± g(x)] = lim x→a f(x) ± lim x→a g(x)
Example: Solved Example: Evaluate lim x→3 (2x + x²)
Show Step-by-Step Solution

Step 1: Apply the sum property: lim x→3 2x + lim x→3 x².
Step 2: Calculate individual limits: 2(3) = 6 and (3)² = 9.
Step 3: Add the results: 6 + 9 = 15.
Answer: 15

Limits of Rational Functions

For rational functions of the form f(x)/g(x), if direct substitution leads to 0/0, we must factorize the numerator and denominator. By canceling common factors, we remove the discontinuity and evaluate the limit. This technique is vital for handling indeterminate forms.

lim x→a [P(x)/Q(x)] = lim x→a [(x-a)R(x) / (x-a)S(x)] = R(a)/S(a)
Example: Solved Example: Evaluate lim x→1 (x² - 1)/(x - 1)
Show Step-by-Step Solution

Step 1: Factorize x² - 1 as (x - 1)(x + 1).
Step 2: Simplify the expression to (x + 1).
Step 3: Substitute x = 1 to get 1 + 1 = 2.
Answer: 2

1

Assertion (A): lim x→2 (x² - 4)/(x - 2) = 4.
Reason (R): The limit of a rational function at a point where the denominator is zero can be found by canceling common factors.

Choose the correct option:
(A) Both A and R are true and R is the correct explanation of A.
(B) Both A and R are true but R is not the correct explanation of A.
(C) A is true but R is false.
(D) A is false but R is true.

Show Answer

✔ Correct: A

Both are true. The limit is indeed 4, and the method of canceling factors is the standard procedure for 0/0 forms.

2

Assertion (A): lim x→0 (1/x) exists.
Reason (R): A limit exists if the function approaches a finite value.

Choose the correct option:
(A) Both A and R are true and R is the correct explanation of A.

Section D: Long Answer Questions

1

hardEvaluate lim x→2 (x³ - 8)/(x² - 4) step-by-step.

Show Answer & Solution

Step 1: Identify the indeterminate form 0/0.
Step 2: Factorize numerator: x³ - 2³ = (x-2)(x² + 2x + 4).
Step 3: Factorize denominator: x² - 2² = (x-2)(x+2).
Step 4: Cancel common factor (x-2) to get (x² + 2x + 4)/(x + 2).
Step 5: Substitute x=2: (4 + 4 + 4)/(2 + 2) = 12/4 = 3.

2

very hardEvaluate lim x→1 (x² + x - 2)/(x² - 1) step-by-step.

Show Answer & Solution

Step 1: Check for indeterminate form: (1+1-2)/(1-1) = 0/0.
Step 2: Factorize numerator: x² + x - 2 = (x+2)(x-1).
Step 3: Factorize denominator: x² - 1 = (x+1)(x-1).
Step 4: Cancel (x-1) to get (x+2)/(x+1).
Step 5: Substitute x=1: (1+2)/(1+1) = 3/2 = 1.5.

Section E: Case-Based Question

Case Study: A factory produces components where the cost function C(x) in hundreds of rupees is given by C(x) = (x² - 25)/(x - 5), where x is the number of units produced in thousands. The factory manager wants to analyze the cost trend as production approaches 5000 units (x=5).

Sub-question 1: (i) Calculate the value of the cost function at x=4. (ii) Find the limit of the cost function as x approaches 5.

Show Solution

(i) C(4) = (16-25)/(4-5) = -9/-1 = 9. (ii) lim x→5 (x-5)(x+5)/(x-5) = lim x→5 (x+5) = 10.

Sub-question 2: If the production cost is defined as 10 when x=5, is the function continuous at x=5?

Show Solution

Since lim x→5 C(x) = 10 and C(5) = 10, the function is continuous at x=5.
