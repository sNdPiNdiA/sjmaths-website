Properties of Regression Equations

Master CBSE Class 11 Applied Mathematics: Properties of Regression Equations. Learn key formulas, properties, and solved problems for board exams.

The Point of Intersection

The two regression lines, Y on X and X on Y, always intersect at the point of the arithmetic means of the variables. If the regression equation of Y on X is y = a + bx and X on Y is x = c + dy, their intersection point is (x̄, ȳ). This property allows us to find the mean of one variable if the other mean and the regression equations are known.

Intersection = (x̄, ȳ)
Example: Solved Example: Find the means
Show Step-by-Step Solution

Step 1: Given equations 2x - y = 5 and 3x - 2y = 4.
Step 2: Solve the system of equations for x and y.
Step 3: Multiply first by 2: 4x - 2y = 10. Subtract second: (4x - 3x) = 10 - 4.
Answer: x̄ = 6, ȳ = 7.

Regression Coefficients and Correlation

The regression coefficient of Y on X (b_yx) and X on Y (b_xy) are related to the correlation coefficient (r). The product of these two coefficients is equal to the square of the correlation coefficient. This property ensures that the sign of both regression coefficients is the same as the sign of r.

r = ±√(b_yx · b_xy)
Example: Solved Example: Calculate r
Show Step-by-Step Solution

Step 1: Given b_yx = 0.8 and b_xy = 0.2.
Step 2: r² = 0.8 × 0.2 = 0.16.
Step 3: r = ±√0.16.
Answer: r = ±0.4.

Invariance to Change of Scale and Origin

Regression coefficients are independent of the change of origin but not of the change of scale. If we transform variables x to u = (x - a)/h and y to v = (y - b)/k, the regression coefficient b_yx changes by the factor k/h. This property simplifies calculations for large data sets.

b_yx = (k/h) · b_vu
Example: Solved Example: Scale transformation
Show Step-by-Step Solution

Step 1: Given b_yx = 0.5, h = 10, k = 5.
Step 2: b_vu = b_yx · (h/k) = 0.5 · (10/5).
Step 3: b_vu = 0.5 · 2.
Answer: b_vu = 1.0.

mediumGiven the regression lines 4x - 5y + 33 = 0 and 20x - 9y - 107 = 0, find: (i) x̄ (ii) ȳ (iii) b_yx.

Show Answer & Solution

(i) Solve 4x - 5y = -33 and 20x - 9y = 107. Multiply first by 5: 20x - 25y = -165. Subtract: -16y = -272 => y = 17. x = (5(17) - 33)/4 = 13. x̄ = 13.
(ii) ȳ = 17.
(iii) From 4x - 5y = -33, 5y = 4x + 33, y = 0.8x + 6.6. b_yx = 0.8.

2

mediumGiven r = 0.6, σx = 2, σy = 3, find: (i) b_yx (ii) b_xy (iii) The equation of Y on X if x̄ = 10, ȳ = 20.

Show Answer & Solution

(i) b_yx = r(σy/σx) = 0.6(3/2) = 0.9.
(ii) b_xy = r(σx/σy) = 0.6(2/3) = 0.4.
(iii) y - 20 = 0.9(x - 10) => y = 0.9x + 11.

Section D: Long Answer Questions

1

hardFor a set of data, the regression lines are 3x + 2y - 26 = 0 and 6x + y - 31 = 0. Find (i) x̄, (ii) ȳ, (iii) b_yx, (iv) b_xy, (v) r.

Show Answer & Solution

Step 1: Solve 3x + 2y = 26 and 6x + y = 31. Multiply first by 2: 6x + 4y = 52. Subtract: 3y = 21, so y = 7.
Step 2: Substitute y=7 into 6x + 7 = 31 => 6x = 24 => x = 4. So x̄ = 4, ȳ = 7.
Step 3: Rewrite 3x + 2y = 26 as 2y = -3x + 26 => y = -1.5x + 13. So b_yx = -1.5.
Step 4: Rewrite 6x + y = 31 as 6x = -y + 31 => x = -0.166y + 5.16. So b_xy = -0.166.
Step 5: r = -√(1.5 × 0.166) = -√0.25 = -0.5.

2

very hardGiven the data: Σx = 25, Σy = 40, Σx² = 145, Σy² = 320, Σxy = 210, n = 5. Find (i) x̄, (ii) ȳ, (iii) b_yx, (iv) b_xy, (v) r.

Show Answer & Solution

Step 1: x̄ = 25/5 = 5, ȳ = 40/5 = 8.
Step 2: Cov(x,y) = (Σxy/n) - x̄ȳ = (210/5) - (5)(8) = 42 - 40 = 2.
Step 3: Var(x) = (Σx²/n) - x̄² = (145/5) - 25 = 29 - 25 = 4. Var(y) = (Σy²/n) - ȳ² = (320/5) - 64 = 64 - 64 = 0. (Wait, Var(y)=0 implies constant, let's assume Σy²=340). If Σy²=340, Var(y) = 68-64=4.
Step 4: b_yx = Cov(x,y)/Var(x) = 2/4 = 0.5. b_xy = Cov(x,y)/Var(y) = 2/4 = 0.5.
Step 5: r = √(0.5 × 0.5) = 0.5.

Section E: Case-Based Question

★

Case Study: A study on 10 households records monthly income (x) and expenditure (y) in thousands of rupees. The data yields: Σx = 500, Σy = 400, Σx² = 26000, Σy² = 17000, Σxy = 20500.

Sub-question 1: (i) Calculate the means x̄ and ȳ. (ii) Calculate the regression coefficient b_yx.

Show Solution

(i) x̄ = 500/10 = 50, ȳ = 400/10 = 40. (ii) Cov(x,y) = (20500/10) - (50)(40) = 2050 - 2000 = 50. Var(x) = (26000/10) - 50² = 2600 - 2500 = 100. b_yx = 50/100 = 0.5.

Sub-question 2: If the income increases by ₹10,000, what is the predicted increase in expenditure?

Show Solution

The regression equation is y - 40 = 0.5(x - 50). For Δx = 10, Δy = 0.5(10) = 5. Predicted increase is ₹5,000.
