Regression Coefficients

Master Regression Coefficients for CBSE Class 11 Applied Mathematics. Learn properties, formulas, and step-by-step solutions for board exam success.

Definition of Regression Coefficients

Regression coefficients, denoted by bxy and byx, measure the average change in one variable for a unit change in the other. The coefficient bxy represents the slope of the regression line of y on x, while byx represents the slope of the regression line of x on y. These coefficients are essential for predicting values in bivariate data sets.

bxy = r · (σy / σx) and byx = r · (σx / σy)
Example: Solved Example: Calculate Regression Coefficients
Show Step-by-Step Solution

Step 1: Given r = 0.8, σx = 2, σy = 3.
Step 2: Calculate bxy = 0.8 · (3 / 2) = 1.2.
Step 3: Calculate byx = 0.8 · (2 / 3) = 0.533.
Answer: bxy = 1.2, byx = 0.533

Properties of Regression Coefficients

Regression coefficients possess unique properties: they share the same sign as the correlation coefficient r. Furthermore, the arithmetic mean of the two regression coefficients is always greater than or equal to the correlation coefficient. If one coefficient is greater than 1, the other must be less than 1.

(bxy + byx) / 2 ≥ r
Example: Solved Example: Verify Property
Show Step-by-Step Solution

Step 1: Given bxy = 1.6 and byx = 0.4.
Step 2: Calculate arithmetic mean = (1.6 + 0.4) / 2 = 1.0.
Step 3: Since r = √(bxy · byx) = √(1.6 · 0.4) = √0.64 = 0.8.
Answer: 1.0 ≥ 0.8, property verified.

Relationship with Correlation Coefficient

The correlation coefficient r is the geometric mean of the two regression coefficients. This relationship allows us to determine the strength and direction of the linear relationship between two variables. It is important to note that regression coefficients are independent of change of origin but not of scale.

r = ±√(bxy · byx)
Example: Solved Example: Find r
Show Step-by-Step Solution

Step 1: Given bxy = 0.9 and byx = 0.4.
Step 2: r = √(0.9 · 0.4) = √0.36.
Step 3: r = 0.6.
Answer: r = 0.6

Section C: Short Answer Questions

1

mediumGiven bxy = 0.6 and byx = 0.4. Find: (i) Correlation coefficient r (ii) If σx = 2, find σy (iii) If σy = 3, find σx.

Show Answer & Solution

(i) r = √(0.6 · 0.4) = √0.24 = 0.49.
(ii) bxy = r(σy/σx) ⟹ 0.6 = 0.49(σy/2) ⟹ σy = 2.45.
(iii) byx = r(σx/σy) ⟹ 0.4 = 0.49(σx/3) ⟹ σx = 2.45.

mediumGiven the regression equation y = 0.5x + 2 and x = 0.8y + 3. Find: (i) bxy (ii) byx (iii) r.

Show Answer & Solution

(i) bxy = 0.5.
(ii) byx = 0.8.
(iii) r = √(0.5 · 0.8) = √0.4 = 0.632.

3

hardGiven Σ(x-x̄)² = 100, Σ(y-ȳ)² = 144, and Σ(x-x̄)(y-ȳ) = 80. Find: (i) bxy (ii) byx (iii) r.

Show Answer & Solution

(i) bxy = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)² = 80/100 = 0.8.
(ii) byx = Σ(x-x̄)(y-ȳ) / Σ(y-ȳ)² = 80/144 = 0.55.
(iii) r = √(0.8 · 0.55) = √0.44 = 0.66.

1

hardFor a bivariate data set, the means are x̄ = 20, ȳ = 30, variances are σx² = 9, σy² = 16, and r = 0.6. Find the two regression lines.

Show Answer & Solution

Step 1: Identify bxy = r(σy/σx) = 0.6(4/3) = 0.8.
Step 2: Identify byx = r(σx/σy) = 0.6(3/4) = 0.45.
Step 3: Line y on x: (y - 30) = 0.8(x - 20) ⟹ y = 0.8x + 14.
Step 4: Line x on y: (x - 20) = 0.45(y - 30) ⟹ x = 0.45y + 6.5.
Step 5: Final equations are y = 0.8x + 14 and x = 0.45y + 6.5.

very hardGiven the regression lines 8x - 10y + 66 = 0 and 40x - 18y = 214. Find: (i) Mean of x, (ii) Mean of y, (iii) bxy, (iv) byx, (v) r.

Show Answer & Solution

Step 1: Solve 8x - 10y = -66 and 40x - 18y = 214. Multiply first by 5: 40x - 50y = -330. Subtracting: 32y = 544 ⟹ y = 17.

Section E: Case-Based Question

★

Case Study: A study on the relationship between advertising expenditure (x in thousands) and sales (y in thousands) for 10 months shows: Σx = 120, Σy = 150, Σx² = 1500, Σy² = 2300, Σxy = 1800.

Sub-question 1: (i) Calculate the regression coefficient bxy.

Show Solution

x̄ = 12, ȳ = 15. Cov(x,y) = (Σxy/n) - x̄ȳ = (1800/10) - (12·15) = 180 - 180 = 0. Var(x) = (Σx²/n) - x̄² = 150 - 144 = 6. bxy = Cov(x,y)/Var(x) = 0/6 = 0.

Sub-question 2: (ii) Calculate the regression coefficient byx.

Show Solution

Var(y) = (Σy²/n) - ȳ² = 230 - 225 = 5. byx = Cov(x,y)/Var(y) = 0/5 = 0.
