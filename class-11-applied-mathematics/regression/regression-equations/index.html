Regression Equations

Master Regression Equations for CBSE Class 11 Applied Mathematics. Learn to calculate regression lines, coefficients, and predictions with solved examples.

Concept of Regression Lines

Regression analysis is a statistical method used to estimate the relationship between a dependent variable and one or more independent variables. The regression line of Y on X is given by Y = a + bX, where b is the regression coefficient representing the slope. This line minimizes the sum of squared vertical deviations between the observed data points and the fitted line.

Y - ȳ = bᵧₓ(X - x̄)
Example: Solved Example: Finding the Regression Line
Show Step-by-Step Solution

Step 1: Given x̄ = 10, ȳ = 20, bᵧₓ = 0.5.
Step 2: Substitute into Y - 20 = 0.5(X - 10).
Step 3: Simplify to Y = 0.5X + 15.
Answer: The regression equation is Y = 0.5X + 15.

Regression Coefficients

The regression coefficient bᵧₓ indicates the change in Y for a unit change in X. It is calculated using the covariance of X and Y and the variance of X. The relationship between the correlation coefficient r and regression coefficients is r = ±√(bᵧₓ · bₓᵧ).

bᵧₓ = Cov(X, Y) / σₓ²
Example: Solved Example: Calculate bᵧₓ
Show Step-by-Step Solution

Step 1: Given Cov(X, Y) = 12 and σₓ² = 4.
Step 2: Apply bᵧₓ = 12 / 4.
Step 3: Calculate bᵧₓ = 3.
Answer: The regression coefficient bᵧₓ is 3.

Properties of Regression Lines

Both regression lines of Y on X and X on Y intersect at the point (x̄, ȳ). The regression coefficients are independent of the change of origin but not of the change of scale. If r = 0, the regression lines are perpendicular to each other.

bᵧₓ = r(σᵧ / σₓ)
Example: Solved Example: Verify Intersection
Show Step-by-Step Solution

Step 1: Given lines 2X - Y = 1 and X - 2Y = -4.
Step 2: Solve the system: Y = 2X - 1 and X - 2(2X - 1) = -4.
Step 3: X - 4X + 2 = -4 ⟹ -3X = -6 ⟹ X = 2, Y = 3.
Answer: The point of intersection (x̄, ȳ) is (2, 3).

Section A: Multiple Choice Questions (MCQs)

1

easyIf bᵧₓ = 0.8 and bₓᵧ = 0.2, the value of correlation coefficient r is:

Show Answer

✔ Correct: B

r = √(bᵧₓ · bₓᵧ) = √(0.8 · 0.2) = √0.16 = 0.4.

2

easyIf x̄ = 5, ȳ = 10, and bᵧₓ = 2, the regression equation of Y on X is:

Show Answer

✔ Correct: A

Y - 10 = 2(X - 5) ⟹ Y - 10 = 2X - 10 ⟹ Y = 2X.

3

mediumGiven Σ(x - x̄)² = 20 and Σ(x - x̄)(y - ȳ) = 30, the value of bᵧₓ is:

Show Answer

✔ Correct: B

bᵧₓ = Σ(x - x̄)(y - ȳ) / Σ(x - x̄)² = 30 / 20 = 1.5.

4

mediumIf the regression lines are 3X + 2Y = 10 and 2X + 3Y = 15, the mean x̄ is:

Show Answer

✔ Correct: A

Solve 3X + 2Y = 10 and 2X + 3Y = 15. Multiply first by 3 and second by 2: 9X + 6Y = 30 and 4X + 6Y = 30. Subtracting gives 5X = 0, so X = 0.

5

hardIf σₓ = 3, σᵧ = 4, and r = 0.75, the regression coefficient bᵧₓ is:

Show Answer

✔ Correct: B

bᵧₓ = r(σᵧ / σₓ) = 0.75 · (4 / 3) = 0.75 · 1.333 = 1.0.

6

hardIf the regression equation is Y = 0.5X + 10, what is the predicted value of Y when X = 20?

Show Answer

✔ Correct: B

Y = 0.5(20) + 10 = 10 + 10 = 20.

7

very hardIf bᵧₓ = -1.2 and bₓᵧ = -0.3, the correlation coefficient r is:

Show Answer

✔ Correct: B

r = -√(bᵧₓ · bₓᵧ) = -√((-1.2) · (-0.3)) = -√0.36 = -0.6.

Section C: Short Answer Questions

1

mediumGiven x̄ = 20, ȳ = 30, σₓ = 4, σᵧ = 6, and r = 0.8. Find: (i) bᵧₓ (ii) bₓᵧ (iii) Regression equation of Y on X.

Show Answer & Solution

(i) bᵧₓ = 0.8 · (6 / 4) = 1.2
(ii) bₓᵧ = 0.8 · (4 / 6) = 0.533
(iii) Y - 30 = 1.2(X - 20) ⟹ Y = 1.2X + 6

2

mediumGiven two lines: 4X - 5Y + 33 = 0 and 20X - 9Y - 107 = 0. Find: (i) x̄ (ii) ȳ (iii) bᵧₓ (assuming 4X-5Y+33=0 is Y on X).

Show Answer & Solution

(i) Solving 4X - 5Y = -33 and 20X - 9Y = 107 gives X = 13.
(ii) Y = (4(13) + 33) / 5 = 17.
(iii) 5Y = 4X + 33 ⟹ Y = 0.8X + 6.6, so bᵧₓ = 0.8.

3

hardGiven Σx = 15, Σy = 20, Σxy = 70, Σx² = 55, n = 5. Find: (i) x̄ and ȳ (ii) Cov(X, Y) (iii) bᵧₓ.

Show Answer & Solution

(i) x̄ = 15/5 = 3, ȳ = 20/5 = 4.
(ii) Cov(X, Y) = (Σxy/n) - x̄ȳ = (70/5) - (3 · 4) = 14 - 12 = 2.
(iii) σₓ² = (Σx²/n) - x̄² = (55/5) - 3² = 11 - 9 = 2. bᵧₓ = 2 / 2 = 1.

Section D: Long Answer Questions

1

hardFor a data set with n=10, Σx=50, Σy=60, Σx²=300, Σy²=400, Σxy=320. Find the regression equation of Y on X.

Show Answer & Solution

Step 1: Calculate means: x̄ = 50/10 = 5, ȳ = 60/10 = 6.
Step 2: Calculate Cov(X, Y) = (Σxy/n) - x̄ȳ = (320/10) - (5 · 6) = 32 - 30 = 2.
Step 3: Calculate σₓ² = (Σx²/n) - x̄² = (300/10) - 5² = 30 - 25 = 5.
Step 4: Calculate bᵧₓ = Cov(X, Y) / σₓ² = 2 / 5 = 0.4.
Step 5: Form equation: Y - 6 = 0.4(X - 5) ⟹ Y = 0.4X + 4.

2

very hardGiven two regression lines 2X - Y + 1 = 0 and 3X - 2Y + 7 = 0. Find (i) x̄, ȳ (ii) bᵧₓ (iii) bₓᵧ (iv) r (v) σᵧ if σₓ = 3.

Show Answer & Solution

Step 1: Solve 2X - Y = -1 and 3X - 2Y = -7. Multiplying first by 2: 4X - 2Y = -2. Subtracting: X = -5, Y = -9. So x̄ = -5, ȳ = -9.
Step 2: Assume 2X - Y + 1 = 0 is Y on X: Y = 2X + 1, so bᵧₓ = 2.
Step 3: Assume 3X - 2Y + 7 = 0 is X on Y: 3X = 2Y - 7, X = (2/3)Y - 7/3, so bₓᵧ = 2/3.
Step 4: r = √(2 · 2/3) = √(4/3) = 1.15 (Wait, r > 1, so assumption is wrong).
Step 5: Correct assumption: 3X - 2Y + 7 = 0 is Y on X: Y = 1.5X + 3.5 (bᵧₓ = 1.5). 2X - Y + 1 = 0 is X on Y: X = 0.5Y - 0.5 (bₓᵧ = 0.5). r = √(1.5 · 0.5) = √0.75 = 0.866. σᵧ = bᵧₓ · σₓ / r = 1.5 · 3 / 0.866 = 5.19.

Section E: Case-Based Question

★

Case Study: A study on the relationship between advertising expenditure (X in thousands) and sales (Y in thousands) for a company over 5 months yielded: X = [2, 4, 5, 6, 8] and Y = [10, 12, 15, 18, 20].

Sub-question 1: (i) Calculate x̄ and ȳ. (ii) Find the regression coefficient bᵧₓ.

Show Solution

(i) x̄ = (2+4+5+6+8)/5 = 25/5 = 5. ȳ = (10+12+15+18+20)/5 = 75/5 = 15.
(ii) Σ(x-x̄)² = 9+1+0+1+9 = 20. Σ(x-x̄)(y-ȳ) = (-3)(-5) + (-1)(-3) + (0)(0) + (1)(3) + (3)(5) = 15+3+0+3+15 = 36. bᵧₓ = 36/20 = 1.8.

Sub-question 2: Predict the sales (Y) if advertising expenditure (X) is 10 thousand.

Show Solution

Equation: Y - 15 = 1.8(X - 5) ⟹ Y = 1.8X - 9 + 15 ⟹ Y = 1.8X + 6. For X = 10, Y = 1.8(10) + 6 = 18 + 6 = 24 thousand.
