Introduction to Linear Regression

Regression analysis is a statistical method used to model the relationship between a dependent variable (y) and one or more independent variables (x). In simple linear regression, we assume a linear relationship represented by the line y = a + bx. This line minimizes the sum of the squares of the vertical deviations between each data point and the fitted line.

y = a + bx
Example: Solved Example: Identify the slope
Show Step-by-Step Solution

Step 1: Given the equation y = 2.5 + 0.8x.
Step 2: Compare with y = a + bx.
Step 3: The intercept a = 2.5 and the slope b = 0.8.
Answer: The slope is 0.8.

Calculating Regression Coefficients

To find the best-fit line, we calculate the slope (b) and the intercept (a) using the method of least squares. The slope b represents the change in y for a unit change in x, while the intercept a is the value of y when x is zero. These parameters are derived from the means and variances of the datasets.

b = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)²
Example: Solved Example: Calculate b
Show Step-by-Step Solution

Step 1: Given Σ(x-x̄)(y-ȳ) = 40 and Σ(x-x̄)² = 50.
Step 2: Apply b = 40 / 50.
Step 3: b = 0.8.
Answer: The regression coefficient b is 0.8.

Predictive Modeling

Once the regression equation is established, it can be used to predict the value of y for any given value of x within the observed range. This predictive power makes regression a vital tool in economics and business forecasting. Accuracy depends on the strength of the correlation between the variables.

ŷ = a + bx
Example: Solved Example: Predict y
Show Step-by-Step Solution

Step 1: Given y = 2 + 0.5x and x = 10.
Step 2: Substitute x = 10 into the equation: y = 2 + 0.5(10).
Step 3: y = 2 + 5 = 7.
Answer: The predicted value is 7.

mediumGiven Σ(x-x̄)(y-ȳ) = 60 and Σ(x-x̄)² = 20, find the regression coefficient b.

Show Answer

✔ Correct: C

b = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)² = 60 / 20 = 3.

4

mediumIf the mean of x is 5 and the mean of y is 10, and b = 2, find the intercept 'a'.

Show Answer

✔ Correct: A

ȳ = a + b(x̄) → 10 = a + 2(5) → 10 = a + 10 → a = 0.

5

hardFor data points (1, 2) and (3, 6), find the slope 'b' of the regression line.

Show Answer

✔ Correct: B

Slope b = (y₂ - y₁) / (x₂ - x₁) = (6 - 2) / (3 - 1) = 4 / 2 = 2.

6

hardIf b = 0.5, x̄ = 10, ȳ = 20, find the predicted y when x = 20.

Show Answer

✔ Correct: A

a = ȳ - bx̄ = 20 - 0.5(10) = 15. Equation: y = 15 + 0.5x. For x = 20, y = 15 + 0.5(20) = 25.

7

very hardIf Σx = 15, Σy = 20, Σxy = 70, Σx² = 55, n = 5, find the slope b.

Show Answer

✔ Correct: B

x̄ = 3, ȳ = 4. b = [nΣxy - ΣxΣy] / [nΣx² - (Σx)²] = [5(70) - 15(20)] / [5(55) - 15²] = [350 - 300] / [275 - 225] = 50 / 50 = 1.2.

Section C: Short Answer Questions

1

mediumGiven the data: x = {2, 4, 6}, y = {3, 7, 11}. Find: (i) x̄ and ȳ (ii) The slope b (iii) The intercept a.

Show Answer & Solution

(i) x̄ = (2+4+6)/3 = 4; ȳ = (3+7+11)/3 = 7.
(ii) b = Σ(x-x̄)(y-ȳ) / Σ(x-x̄)² = [(-2)(-4) + (0)(0) + (2)(4)] / [(-2)² + 0² + 2²] = (8+0+8)/(4+0+4) = 16/8 = 2.
(iii) a = ȳ - bx̄ = 7 - 2(4) = -1.

2

mediumGiven regression equation y = 5 + 0.5x. Find: (i) Predicted y when x = 10 (ii) Predicted y when x = 20 (iii) The change in y if x increases by 10.

Show Answer & Solution

(i) y = 5 + 0.5(10) = 10.
(ii) y = 5 + 0.5(20) = 15.
(iii) Change = 0.5 * 10 = 5.

3

hardGiven Σx = 20, Σy = 30, Σxy = 130, Σx² = 90, n = 5. Find: (i) x̄ and ȳ (ii) Slope b (iii) Equation of the line.

Show Answer & Solution

(i) x̄ = 20/5 = 4; ȳ = 30/5 = 6.
(ii) b = [5(130) - 20(30)] / [5(90) - 20²] = [650 - 600] / [450 - 400] = 50/50 = 1.
(iii) a = 6 - 1(4) = 2. Equation: y = 2 + x.

Section D: Long Answer Questions

1

hardA study on study hours (x) and test scores (y) yielded: x = {1, 2, 3, 4, 5}, y = {2, 4, 5, 4, 5}. Find the regression line y = a + bx.

Show Answer & Solution

Step 1: Calculate means: x̄ = 15/5 = 3, ȳ = 20/5 = 4.
Step 2: Calculate Σ(x-x̄)(y-ȳ): (-2)(-2) + (-1)(0) + (0)(1) + (1)(0) + (2)(1) = 4 + 0 + 0 + 0 + 2 = 6.
Step 3: Calculate Σ(x-x̄)²: (-2)² + (-1)² + 0² + 1² + 2² = 4 + 1 + 0 + 1 + 4 = 10.
Step 4: Calculate b = 6/10 = 0.6.
Step 5: Calculate a = 4 - 0.6(3) = 4 - 1.8 = 2.2. Equation: y = 2.2 + 0.6x.

2

very hardFor a dataset with n=4, Σx=10, Σy=12, Σx²=30, Σxy=34. Find the regression line and predict y for x=6.

Show Answer & Solution

Step 1: Find means: x̄ = 10/4 = 2.5, ȳ = 12/4 = 3.
Step 2: Use formula b = [nΣxy - ΣxΣy] / [nΣx² - (Σx)²].
Step 3: b = [4(34) - 10(12)] / [4(30) - 10²] = [136 - 120] / [120 - 100] = 16/20 = 0.8.
Step 4: Find a = ȳ - bx̄ = 3 - 0.8(2.5) = 3 - 2 = 1.
Step 5: Equation is y = 1 + 0.8x. For x = 6, y = 1 + 0.8(6) = 1 + 4.8 = 5.8.

Section E: Case-Based Question

★

Case Study: A small startup tracks its monthly advertising spend (x in thousands) and sales revenue (y in thousands) for 5 months: (x, y) = (1, 2), (2, 3), (3, 5), (4, 4), (5, 6).

Sub-question 1: (i) Calculate the mean of x and y. (ii) Calculate the slope b.

Show Solution

(i) x̄ = (1+2+3+4+5)/5 = 3. ȳ = (2+3+5+4+6)/5 = 4.
(ii) Σ(x-x̄)(y-ȳ) = (-2)(-2) + (-1)(-1) + (0)(1) + (1)(0) + (2)(2) = 4+1+0+0+4 = 9. Σ(x-x̄)² = 4+1+0+1+4 = 10. b = 9/10 = 0.9.

Sub-question 2: Find the regression equation and predict revenue for an advertising spend of 6 thousand.

Show Solution

a = ȳ - bx̄ = 4 - 0.9(3) = 4 - 2.7 = 1.3. Equation: y = 1.3 + 0.9x. For x = 6, y = 1.3 + 0.9(6) = 1.3 + 5.4 = 6.7 thousand.
