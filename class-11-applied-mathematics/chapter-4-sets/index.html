Chapter 4 Core Formula Sheet

Quick-glance formula revision for examination and numerical problem-solving:

  • $$\text{Roster Form: } A = \{2, 4, 6, 8\}$$
  • $$\text{Set-builder Form: } A = \{x : x = 2n, n \in \mathbb{N}, 1 \le n \le 4\}$$
  • $$\text{Empty Set: } n(\emptyset) = 0$$
  • $$\text{Equal Sets: } A = B \iff (x \in A \iff x \in B)$$
  • $$\text{Equivalent Sets: } A \sim B \iff n(A) = n(B)$$
  • $$A \subseteq B \iff (x \in A \implies x \in B)$$
  • $$n(P(A)) = 2^n \text{ where } n = n(A)$$
  • $$[a, b] = \{x \in \mathbb{R} : a \le x \le b\}, \quad (a, b) = \{x \in \mathbb{R} : a < x < b\}$$
  • $$A \cup B = \{x : x \in A \text{ or } x \in B\}$$
  • $$A \cap B = \{x : x \in A \text{ and } x \in B\}$$
  • $$A - B = \{x : x \in A \text{ and } x \notin B\}$$
  • $$(A \cup B)' = A' \cap B', \quad (A \cap B)' = A' \cup B'$$
  • $$n(A \cup B) = n(A) + n(B) - n(A \cap B)$$
  • $$n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C)$$
