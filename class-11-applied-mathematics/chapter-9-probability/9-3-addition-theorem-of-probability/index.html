9.3 Addition Theorem of Probability: General Additivity, Mutual Exclusivity, and De Morgan's Rules

In Applied Mathematics, operations management, and multi-risk underwriting, events frequently overlap. When calculating the probability that a financial portfolio experiences credit default OR liquidity shortfall, simple addition causes double counting. The Addition Theorem of Probability provides the exact algebraic adjustment.

Fundamental Formulae & Theorems

1. Two-Event Addition Theorem

For any two arbitrary events \(A\) and \(B\) associated with a sample space \(S\):

\[ P(A \cup B) = P(A) + P(B) - P(A \cap B) \]

Mutually Exclusive Case: If \(A \cap B = \emptyset\), then \(P(A \cap B) = 0\), yielding: \[ P(A \cup B) = P(A) + P(B) \]

2. Essential Set-Theoretic Probability Corollaries

  • Probability of "Only \(A\)" (Event \(A\) but not \(B\)): \[ P(A - B) = P(A \cap B') = P(A) - P(A \cap B) \]
  • Probability of "Only \(B\)" (Event \(B\) but not \(A\)): \[ P(B - A) = P(B \cap A') = P(B) - P(A \cap B) \]
  • Probability of "Exactly One" of the Two Events (Symmetric Difference): \[ P(\text{Exactly 1}) = P(A \Delta B) = P(A \cap B') + P(B \cap A') = P(A) + P(B) - 2P(A \cap B) = P(A \cup B) - P(A \cap B) \]
  • Probability of "Neither \(A\) nor \(B\)" (De Morgan's First Law): \[ P(A' \cap B') = P((A \cup B)') = 1 - P(A \cup B) \]
  • Probability that "At Least One Event Does Not Occur" (De Morgan's Second Law): \[ P(A' \cup B') = P((A \cap B)') = 1 - P(A \cap B) \]

3. Three-Event Addition Theorem

For any three events \(A, B, C\):

\[ P(A \cup B \cup C) = P(A) + P(B) + P(C) - P(A \cap B) - P(B \cap C) - P(C \cap A) + P(A \cap B \cap C) \]

Comprehensive Applied Example: Student Placement Assessment

Scenario: Two students, Amit and Priya, appear for an investment banking placement interview. The probability that Amit is selected is \(P(A) = 0.5\), the probability that Priya is selected is \(P(B) = 0.6\), and the probability that both are selected is \(P(A \cap B) = 0.3\).

Find the probability that:

  1. At least one of them is selected.
  2. Only Amit is selected.
  3. Exactly one of them is selected.
  4. Neither of them is selected.

Solution:

  1. At least one is selected: \[ P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.5 + 0.6 - 0.3 = 0.80. \]
  2. Only Amit is selected (\(A\) but not \(B\)): \[ P(A \cap B') = P(A) - P(A \cap B) = 0.5 - 0.3 = 0.20. \]
  3. Exactly one of them is selected: \[ P(\text{Exactly 1}) = P(A \cup B) - P(A \cap B) = 0.80 - 0.30 = 0.50. \] Verification via components: \(P(A \cap B') + P(B \cap A') = (0.5 - 0.3) + (0.6 - 0.3) = 0.2 + 0.3 = 0.50\). Matches!
  4. Neither is selected: \[ P(A' \cap B') = 1 - P(A \cup B) = 1 - 0.80 = 0.20. \]

Problem 1 (Consistency and Probability Bounds)

Given \(P(A) = 0.5\), \(P(B) = 0.6\), and \(P(A \cup B) = 0.8\). Find:

  1. \(P(A \cap B)\)
  2. \(P(A' \cap B')\)
  3. \(P(A' \cup B')\)
  4. \(P(A' \cap B)\)
View Step-by-Step Solution

Solution:

  • (a) \(P(A \cap B)\): \[ P(A \cap B) = P(A) + P(B) - P(A \cup B) = 0.5 + 0.6 - 0.8 = 0.3. \]
  • (b) \(P(A' \cap B')\): \[ P(A' \cap B') = 1 - P(A \cup B) = 1 - 0.8 = 0.2. \]
  • (c) \(P(A' \cup B')\): \[ P(A' \cup B') = 1 - P(A \cap B) = 1 - 0.3 = 0.7. \]
  • (d) \(P(A' \cap B)\): \[ P(A' \cap B) = P(B) - P(A \cap B) = 0.6 - 0.3 = 0.3. \]

Problem 2 (Card Deck Addition Theorem)

A card is drawn from a well-shuffled pack of 52 cards. What is the probability that it is either a Heart or an Ace?

View Step-by-Step Solution

Solution:

Let \(H\) be the event of drawing a Heart and \(A\) be the event of drawing an Ace.

  • \(P(H) = \frac{13}{52}\)
  • \(P(A) = \frac{4}{52}\)
  • \(H \cap A\) is the Ace of Hearts: \(P(H \cap A) = \frac{1}{52}\)
By the Addition Theorem: \[ P(H \cup A) = P(H) + P(A) - P(H \cap A) = \frac{13}{52} + \frac{4}{52} - \frac{1}{52} = \frac{16}{52} = \frac{4}{13}. \] Answer: \(\frac{4}{13}\).

Quick Revision & Formula Cheat Sheet

Two-Event Formulas

  • \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)
  • \(P(A \cap B') = P(A) - P(A \cap B)\)
  • \(P(\text{Exactly 1}) = P(A) + P(B) - 2P(A \cap B)\)
  • \(P(\text{Neither}) = 1 - P(A \cup B)\)

De Morgan's Laws

  • \((A \cup B)' = A' \cap B'\)
  • \((A \cap B)' = A' \cup B'\)
  • \(P(A' \cup B') = 1 - P(A \cap B)\)
  • \(P(A' \cap B') = 1 - P(A \cup B)\)

Bounding Inequalities

  • \(P(A \cap B) \ge P(A) + P(B) - 1\) (Bonferroni's Inequality)
  • \(P(A \cup B) \le P(A) + P(B)\) (Boole's Inequality)
