Procedure of finding logarithm and antilogarithms of given number

A comprehensive guide to finding logarithms and antilogarithms for CBSE Class 11 Applied Mathematics, covering characteristics, mantissas, and interpolation.

The Structure of a Logarithm

A logarithm of a number x to a base 10 is expressed as log10(x) = y. It consists of two parts: the Characteristic (the integer part, representing the magnitude) and the Mantissa (the decimal part, which is always positive and found using log tables).

log10(x) = Characteristic + Mantissa
Example 1: Find the logarithm of 456.7
Show Step-by-Step Solution

• Step 1: Determine the characteristic. Since 456.7 > 1, the number of digits before the decimal is 3. Characteristic = 3 - 1 = 2.
• Step 2: Look up the mantissa in the log table. Find the row for '45', column '6', which is 6589. Add the mean difference for '7', which is 7.
• Step 3: 6589 + 7 = 6596. Therefore, mantissa is .6596.

Answer: log10(456.7) = 2.6596

Procedure for Antilogarithms

Antilogarithm is the inverse process of finding a logarithm. If log x = y, then x = antilog(y). To find the antilog, we focus only on the decimal part (mantissa) in the antilog table and use the characteristic to determine the decimal point position.

If characteristic is 'n', decimal point is placed after (n + 1) digits from the left.
Example 1: Find the antilog of 2.7218
Show Step-by-Step Solution

• Step 1: Identify the characteristic (2) and the mantissa (.7218).
• Step 2: Look for .72 in the row and 1 in the column of the antilog table, which gives 5260. Add the mean difference for 8, which is 10.
• Step 3: 5260 + 10 = 5270. Since the characteristic is 2, the decimal point is placed after 2+1=3 digits.
• Step 4: The number is 527.0

Answer: antilog(2.7218) = 527.0

✔ Correct: A

The antilog of the mantissa determines the digits. Looking up 0.6532 in an antilog table gives the sequence 4500. With characteristic 2, the number is 450.0. The mantissa itself refers to 4.500.

Show Answer

✔ Correct: A

log10(5 x 10^-3) = log10(5) + log10(10^-3) = 0.6990 - 3 = -2.3010.

Section C: Short Answer Questions

1

Find the value of log10(25) given log10(2) = 0.3010.

Show Answer & Solution

log10(25) = log10(5^2) = 2 * log10(10/2) = 2 * (log10(10) - log10(2)) = 2 * (1 - 0.3010) = 2 * 0.6990 = 1.3980.

2

Find the number whose logarithm is 3.4771.

Show Answer & Solution

The number x = antilog(3.4771). Antilog of .4771 is 3.000. Characteristic 3 implies x = 3.000 * 10^3 = 3000.

Section D: Long Answer Questions

1

Calculate the value of (24.56 * 0.034) / 1.25 using logarithms.

Show Answer & Solution

Let x = (24.56 * 0.034) / 1.25. Take log on both sides: log x = log 24.56 + log 0.034 - log 1.25. log 24.56 ≈ 1.3902. log 0.034 = log(3.4 * 10^-2) ≈ 0.5315 - 2 = -1.4685. log 1.25 ≈ 0.0969. log x = 1.3902 - 1.4685 - 0.0969 = -0.1752. This is -1 + 0.8248 = 1.8248 bar. Antilog(0.8248) ≈ 6.68. x = 6.68 * 10^-1 = 0.668.

2

Find the value of (0.005)^4.

Show Answer & Solution

Let y = (0.005)^4. Take log: log y = 4 * log(0.005). log 0.005 = log(5 * 10^-3) = log 5 - 3 = 0.6990 - 3 = -2.3010. log y = 4 * (-2.3010) = -9.2040. To convert to standard form: -9.2040 = -10 + 0.7960 = 10 bar .7960. Antilog(0.7960) ≈ 6.25. y = 6.25 * 10^-10.

Section E: Case-Based Questions

1

Case Study: In financial mathematics, the formula A = P(1 + r/n)^nt is used to calculate compound interest. To solve for t when A, P, r, and n are known, logarithms are employed. Consider A = 2000, P = 1000, r = 0.10, and n = 1 (compounded annually). The equation becomes 2000 = 1000(1.1)^t, which simplifies to 2 = (1.1)^t.

Sub-question 1: Write the logarithmic form of the equation 2 = (1.1)^t.

Show Solution

Taking log10 on both sides: log10(2) = t * log10(1.1).

Sub-question 2: Calculate the approximate value of t using log10(2) = 0.3010 and log10(1.1) = 0.0414.

Show Solution

t = log10(2) / log10(1.1) = 0.3010 / 0.0414 ≈ 7.27 years.
