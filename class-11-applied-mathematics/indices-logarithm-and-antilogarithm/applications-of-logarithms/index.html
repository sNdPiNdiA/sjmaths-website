Applications of logarithms

Logarithms in Compound Interest and Depreciation

Logarithms are primarily used to solve for time (n) or rate (r) in problems involving compound interest or depreciation, where the variable is present in the exponent. Given the formula A = P(1 + r/100)^n, applying logarithms allows us to convert the exponential relationship into a linear one, making calculation simpler using log tables or calculators.

A = P(1 + r)^n => log(A) = log(P) + n * log(1 + r)
Example 1: In how many years will an amount of Rs 5000 grow to Rs 7500 at 10% per annum compounded annually?
Show Step-by-Step Solution

• Identify the formula: A = P(1 + r)^n. Here, A=7500, P=5000, r=0.10.
• Substitute values: 7500 = 5000(1.1)^n.
• Divide by 5000: 1.5 = (1.1)^n.
• Take natural logarithm (ln) on both sides: ln(1.5) = n * ln(1.1).
• Solve for n: n = ln(1.5) / ln(1.1) approx 0.4055 / 0.0953.
• Calculate the final value: n = 4.25 years.

Answer: The amount will grow in approximately 4.25 years.

Logarithmic Differentiation and Exponential Equations

When solving equations where the variable is in the exponent, we utilize the property that log(a^b) = b * log(a). This property effectively 'brings down' the exponent, transforming complex exponential equations into simpler algebraic equations that can be solved using standard linear or quadratic methods.

If a^x = b, then x * log(a) = log(b), therefore x = log(b) / log(a)
Example 1: Solve for x: 3^(x+1) = 5^x.
Show Step-by-Step Solution

• Take log on both sides: log(3^(x+1)) = log(5^x).
• Apply the power rule: (x + 1) * log(3) = x * log(5).
• Expand the expression: x*log(3) + log(3) = x*log(5).
• Isolate x: x(log(5) - log(3)) = log(3).
• Final form: x = log(3) / (log(5) - log(3)).

Answer: x = log(3) / log(5/3) which is approximately 2.15.

1

If log(base 10) 2 = 0.3010, then the value of log(base 10) 5 is:

Show Answer

✔ Correct: A

log(5) = log(10/2) = log(10) - log(2) = 1 - 0.3010 = 0.6990.

2

The value of x in log(base 3) (x + 5) = 2 is:

Show Answer

✔ Correct: A

x + 5 = 3^2 = 9, so x = 9 - 5 = 4.

3

Which of the following is equivalent to 2log(x) + 3log(y)?

Show Answer

✔ Correct: A

Using log properties, 2log(x) + 3log(y) = log(x^2) + log(y^3) = log(x^2 * y^3).

Section C: Short Answer Questions

1

Find the value of x if log(base 2) x + log(base 2) (x-2) = 3.

Show Answer & Solution

log(base 2) [x(x-2)] = 3 implies x^2 - 2x = 2^3 = 8. Thus x^2 - 2x - 8 = 0. Solving (x-4)(x+2)=0 gives x=4 (rejecting x=-2 as log of negative is undefined).

2

Simplify: log(base 10) (25) + 2log(base 10) (4) - log(base 10) (4).

Show Answer & Solution

log(25) + log(4^2) - log(4) = log(25 * 16 / 4) = log(25 * 4) = log(100) = log(10^2) = 2.

Section D: Long Answer Questions

1

Prove that 1 / (log(base ab) x) + 1 / (log(base bc) x) + 1 / (log(base ca) x) = 2 / (log(base abc) x).

Show Answer & Solution

Using the change of base formula 1/log(base a) b = log(base b) a, the LHS becomes log(base x) ab + log(base x) bc + log(base x) ca. This equals log(base x) (ab * bc * ca) = log(base x) (a^2 b^2 c^2) = log(base x) (abc)^2 = 2 log(base x) abc. Converting back gives 2 / log(base abc) x.

2

Solve for x: (log(base x) 10)^2 + (log(base x) 100) = 3.

Show Answer & Solution

Let y = log(base x) 10. Then log(base x) 100 = 2log(base x) 10 = 2y. The equation becomes y^2 + 2y - 3 = 0. Factorising: (y+3)(y-1) = 0. So y = 1 or y = -3. If y = 1, log(base x) 10 = 1 => x = 10. If y = -3, log(base x) 10 = -3 => x^-3 = 10 => x^3 = 1/10 => x = cube root of 0.1.

Section E: Case-Based Questions

1

Case Study: In a laboratory experiment, the population of a bacterial culture grows according to the formula P(t) = P(0) * 10^(kt), where P(t) is the population at time t (hours), P(0) is the initial population, and k is a constant.

Sub-question 1: Express t in terms of P(t), P(0), and k using logarithms.

Show Solution

P(t)/P(0) = 10^(kt). Taking log base 10 on both sides: log(P(t)/P(0)) = kt. Therefore, t = (1/k) * log(P(t)/P(0)).

Sub-question 2: If the initial population is 100, k is 0.1, find the time t when population becomes 10,000.

Show Solution

10,000 = 100 * 10^(0.1 * t) => 100 = 10^(0.1 * t). Since 100 = 10^2, then 2 = 0.1 * t, which means t = 20 hours.
