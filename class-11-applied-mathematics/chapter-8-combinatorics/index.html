Chapter 8 Core Formula Sheet

Quick-glance formula revision for examination and numerical problem-solving:

  • $$\text{Multiplication Principle: } m \times n \text{ ways to perform sequential tasks}$$
  • $$\text{Addition Principle: } m + n \text{ ways to perform alternative tasks}$$
  • $$n! = n \times (n-1) \times (n-2) \times \dots \times 1$$
  • $$0! = 1, \quad 1! = 1, \quad n! = n \cdot (n-1)!$$
  • $$^nP_r = \frac{n!}{(n-r)!}, \quad ^nP_n = n!$$
  • $$\text{With identical items: } \frac{n!}{p! \, q! \, r!}$$
  • $$\text{Circular Permutations: } (n-1)!$$
  • $$^nC_r = \frac{n!}{r!(n-r)!} = \frac{^nP_r}{r!}$$
  • $$^nC_r = \,^nC_{n-r}, \quad ^nC_0 = \,^nC_n = 1$$
  • $$^nC_r + \,^nC_{r-1} = \,^{n+1}C_r$$
  • $$\text{Lines from } n \text{ points: } ^nC_2, \; \text{Triangles: } ^nC_3$$
