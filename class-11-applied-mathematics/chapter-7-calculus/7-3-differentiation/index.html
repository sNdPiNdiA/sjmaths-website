7.3 Differentiation: First Principles, Geometric Slopes, and Rates of Change

In Applied Mathematics, corporate financial modeling, and engineering dynamics, the derivative quantifies instantaneous sensitivity: how rapidly an output metric (revenue, cost, production volume) responds to an infinitesimal change in an input variable. Geometrically, it defines the exact slope of the tangent line to a curve.

Mathematical Definition & The First Principle (Delta Method)

  • Definition of Derivative: Let \(f(x)\) be a real-valued function defined on an open interval. The derivative of \(f\) at \(x\), denoted by \(f'(x)\) or \(\frac{df}{dx}\), is defined as the limit: \[ f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} \] provided this limit exists finitely.
  • Derivative at a Specific Point \(x = c\): \[ f'(c) = \lim_{h \to 0} \frac{f(c + h) - f(c)}{h} = \lim_{x \to c} \frac{f(x) - f(c)}{x - c} \]
  • Geometric Interpretation: The difference quotient \(\frac{f(x + h) - f(x)}{h}\) represents the slope of the secant line connecting points \(P(x, f(x))\) and \(Q(x + h, f(x + h))\). As \(h \to 0\), point \(Q\) travels along the curve toward \(P\), and the secant line approaches the tangent line at \(P\). \[ \text{Slope of Tangent at } (x_0, y_0) = m = f'(x_0) = \left. \frac{dy}{dx} \right|_{x = x_0} \]
  • One-Sided Derivatives (Differentiability Test): A function is differentiable at \(x = c\) if and only if its Left-Hand Derivative (LHD) equals its Right-Hand Derivative (RHD): \[ \text{LHD} = f'(c^-) = \lim_{h \to 0^+} \frac{f(c - h) - f(c)}{-h} \] \[ \text{RHD} = f'(c^+) = \lim_{h \to 0^+} \frac{f(c + h) - f(c)}{h} \] \[ f \text{ is differentiable at } c \iff \text{LHD} = \text{RHD} \]
  • The Fundamental Differentiability-Continuity Theorem: \[ \textbf{Differentiability} \implies \textbf{Continuity} \] If \(f(x)\) is differentiable at \(x = c\), then it is necessarily continuous at \(x = c\). Caution: The converse is FALSE. Continuity does not guarantee differentiability.

Standard First Principles Derivations (CBSE Delta Method)

Function \(f(x)\) Algebraic Step via First Principle Derivative \(f'(x)\)
Constant \(f(x) = c\) \(\lim_{h \to 0} \frac{c - c}{h} = \lim_{h \to 0} 0\) \(0\)
Power \(f(x) = x^n\) Binomial expansion of \((x + h)^n = x^n + n x^{n-1}h + \dots\) \(n x^{n-1}\)
Square Root \(f(x) = \sqrt{x}\) Rationalize: \(\frac{\sqrt{x+h} - \sqrt{x}}{h} \times \frac{\sqrt{x+h} + \sqrt{x}}{\sqrt{x+h} + \sqrt{x}}\) \(\frac{1}{2\sqrt{x}}\)
Reciprocal \(f(x) = \frac{1}{x}\) Common denominator: \(\frac{x - (x+h)}{h x (x+h)} = \frac{-1}{x(x+h)}\) \(-\frac{1}{x^2}\)

Classic Example: The Non-Differentiable Continuous Function

Problem: Show that \(f(x) = |x|\) is continuous at \(x = 0\), but not differentiable at \(x = 0\).

Part 1: Proof of Continuity:

  • \(f(0) = |0| = 0\)
  • \(\lim_{x \to 0^-} |x| = \lim_{x \to 0^-} (-x) = 0\)
  • \(\lim_{x \to 0^+} |x| = \lim_{x \to 0^+} (x) = 0\)
Since \(\text{LHL} = \text{RHL} = f(0) = 0\), \(f(x)\) is continuous at \(x = 0\).

Part 2: Test of Differentiability at \(x = 0\):

  • Left-Hand Derivative (LHD): \[ \text{LHD} = \lim_{h \to 0^+} \frac{f(0 - h) - f(0)}{-h} = \lim_{h \to 0^+} \frac{|-h| - 0}{-h} = \lim_{h \to 0^+} \frac{h}{-h} = -1. \]
  • Right-Hand Derivative (RHD): \[ \text{RHD} = \lim_{h \to 0^+} \frac{f(0 + h) - f(0)}{h} = \lim_{h \to 0^+} \frac{|h| - 0}{h} = \lim_{h \to 0^+} \frac{h}{h} = 1. \]

Since \(\text{LHD} = -1 \neq 1 = \text{RHD}\), the derivative at \(x = 0\) does not exist.

Geometric Meaning: The curve has a sharp corner (v-notch) at the origin with no unique tangent slope.

Problem 1 (First Principles: Radical Function)

Find the derivative of \(f(x) = \sqrt{2x + 1}\) from first principles.

View Step-by-Step Solution

Solution:

\[ f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} = \lim_{h \to 0} \frac{\sqrt{2(x + h) + 1} - \sqrt{2x + 1}}{h} \] Multiply numerator and denominator by the conjugate \(\sqrt{2x + 2h + 1} + \sqrt{2x + 1}\): \[ = \lim_{h \to 0} \frac{(2x + 2h + 1) - (2x + 1)}{h (\sqrt{2x + 2h + 1} + \sqrt{2x + 1})} \] \[ = \lim_{h \to 0} \frac{2h}{h (\sqrt{2x + 2h + 1} + \sqrt{2x + 1})} \] Cancel the non-zero \(h\): \[ = \lim_{h \to 0} \frac{2}{\sqrt{2x + 2h + 1} + \sqrt{2x + 1}} = \frac{2}{2\sqrt{2x + 1}} = \frac{1}{\sqrt{2x + 1}}. \] Answer: \(f'(x) = \frac{1}{\sqrt{2x + 1}}\).

Problem 2 (Instantaneous Speed vs Average Speed)

A delivery vehicle's displacement in kilometers after \(t\) hours is given by \(s(t) = 40t + 5t^2\).

  1. Find the average speed of the vehicle between \(t = 2\) and \(t = 4\) hours.
  2. Find the instantaneous speed at exactly \(t = 3\) hours using differentiation.
View Step-by-Step Solution

Solution:

Part (a): Average Speed:

\[ s(2) = 40(2) + 5(2^2) = 80 + 20 = 100 \text{ km} \] \[ s(4) = 40(4) + 5(4^2) = 160 + 80 = 240 \text{ km} \] \[ v_{\text{avg}} = \frac{s(4) - s(2)}{4 - 2} = \frac{240 - 100}{2} = \frac{140}{2} = 70 \text{ km/h.} \]

Part (b): Instantaneous Speed at \(t = 3\):

\[ v(t) = s'(t) = \frac{d}{dt}(40t + 5t^2) = 40 + 10t \] \[ v(3) = 40 + 10(3) = 40 + 30 = 70 \text{ km/h.} \]

Problem 3 (Slope of Tangent to a Cost Curve)

A firm's total production cost is modeled by \(C(x) = 2x^2 + 15x + 50\), where \(x\) is units produced. Find the slope of the cost curve when 10 units are produced.

View Step-by-Step Solution

Solution:

The slope of the curve at any output \(x\) is given by the derivative \(C'(x)\):

\[ C'(x) = \frac{d}{dx}(2x^2 + 15x + 50) = 4x + 15 \] At \(x = 10\): \[ C'(10) = 4(10) + 15 = 40 + 15 = 55. \] Answer: The slope of the tangent line is 55 (representing marginal cost ₹55/unit).

Quick Revision & Formula Cheat Sheet

First Principle Definition

  • \(f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h}\)
  • \(f'(c) = \lim_{x \to c} \frac{f(x) - f(c)}{x - c}\)
  • Geometrically: Slope of tangent \(m = f'(x_0)\)
  • Physically: Instantaneous rate of change

Standard First Principle Derivatives

  • \(\frac{d}{dx}(c) = 0\)
  • \(\frac{d}{dx}(x^n) = n x^{n-1}\)
  • \(\frac{d}{dx}(\sqrt{x}) = \frac{1}{2\sqrt{x}}\)
  • \(\frac{d}{dx}\left(\frac{1}{x}\right) = -\frac{1}{x^2}\)

Differentiability Core Facts

  • Differentiable \(\implies\) Continuous
  • Continuous does NOT imply Differentiable
  • Sharp corners, vertical tangents, and breaks lack derivatives
  • Differentiable \(\iff \text{LHD} = \text{RHD}\)
