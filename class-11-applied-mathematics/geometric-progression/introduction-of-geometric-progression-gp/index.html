Introduction to Geometric Progression (GP)

Master Geometric Progressions for CBSE Class 11 Applied Mathematics. Learn formulas, common ratios, and solve step-by-step problems with ease.

Definition of Geometric Progression

A Geometric Progression (GP) is a sequence of non-zero numbers where each term after the first is obtained by multiplying the previous term by a fixed, non-zero constant called the common ratio. If the first term is a and the common ratio is r, the sequence is represented as a, ar, ar², ar³, .... This progression is fundamental in modeling exponential growth and decay in finance and population studies.

aₙ = a·rⁿ⁻¹
Example: Solved Example: Identify the GP
Show Step-by-Step Solution

Step 1: Given sequence 3, 6, 12, 24.
Step 2: Check ratio r = 6/3 = 2 and 12/6 = 2.
Step 3: Since the ratio is constant, it is a GP.
Answer: First term a=3, common ratio r=2.

Finding the n-th Term

The n-th term of a GP allows us to calculate any specific value in the sequence without listing all preceding terms. By substituting the first term a, the common ratio r, and the position n into the standard formula, we can determine the magnitude of any term. This is particularly useful in calculating compound interest or depreciating asset values over time.

aₙ = a·rⁿ⁻¹
Example: Solved Example: Find the 6th term
Show Step-by-Step Solution

Step 1: Given a=2, r=3, n=6.
Step 2: Apply formula a₆ = 2·3⁶⁻¹.
Step 3: Calculate 3⁵ = 243.
Step 4: a₆ = 2·243 = 486.
Answer: 486.

Properties of Common Ratio

The common ratio r is determined by dividing any term by its preceding term, i.e., r = aₙ/aₙ₋₁. If r > 1, the terms increase in magnitude; if 0 < r < 1, the terms decrease; and if r is negative, the terms alternate in sign. Understanding these properties is essential for analyzing the behavior of sequences in applied mathematics.

r = aₙ / aₙ₋₁
Example: Solved Example: Find r for 100, -50, 25
Show Step-by-Step Solution

Step 1: Identify consecutive terms: a₁=100, a₂=-50.
Step 2: Calculate r = -50/100.
Step 3: Simplify the fraction.
Answer: r = -0.5.

Section D: Long Answer Questions

1

hardA machine depreciates in value such that its value at the end of each year is 80% of its value at the beginning of the year. If the initial cost is ₹1,00,000, find the value at the end of 5 years.

Show Answer & Solution

Step 1: Identify a = 100000 and r = 0.8.
Step 2: The value at the end of year n is given by a·rⁿ.
Step 3: For end of 5 years, we need a₆ = a·r⁵.
Step 4: a₆ = 100000·(0.8)⁵.
Step 5: 0.8⁵ = 0.32768.
Step 6: 100000·0.32768 = ₹32,768.

2

very hardIn a GP, the sum of the first two terms is 4 and the fifth term is 4 times the third term. Find the first term and the common ratio.

Show Answer & Solution

Step 1: a + ar = 4 ⟹ a(1+r) = 4.
Step 2: a₅ = 4·a₃ ⟹ ar⁴ = 4·ar².
Step 3: Since a≠0, r⁴ = 4r² ⟹ r² = 4 (assuming r≠0).
Step 4: r = 2 or r = -2.
Step 5: If r=2, a(1+2)=4 ⟹ 3a=4 ⟹ a=4/3.
Step 6: If r=-2, a(1-2)=4 ⟹ -a=4 ⟹ a=-4.

Section E: Case-Based Question

★

Case Study: A viral social media post is shared by 5 people in the first hour. Each of these 5 people shares it with 5 more people in the next hour, and this pattern continues. The number of new shares each hour forms a GP: 5, 25, 125, ...

Sub-question 1: (i) Find the number of new shares in the 5th hour. (ii) Calculate the common ratio.

Show Solution

(i) a=5, r=5. a₅ = 5·5⁴ = 5·625 = 3125. (ii) r = 25/5 = 5.

Sub-question 2: If the pattern continues, in which hour will the new shares exceed 10,000?

Show Solution

aₙ = 5·5ⁿ⁻¹ = 5ⁿ. We need 5ⁿ > 10000. 5⁵ = 3125, 5⁶ = 15625. Thus, in the 6th hour.
