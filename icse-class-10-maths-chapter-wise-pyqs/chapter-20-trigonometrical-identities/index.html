20. Trigonometrical Identities Previous Year Questions

Core Formula: sin²θ + cos²θ = 1, 1 + tan²θ = sec²θ, 1 + cot²θ = cosec²θ

CISCE Examiner Observation & Common Deduction Pitfall

Convert compound terms into sin and cos when stuck. Work strictly on one side (L.H.S.) until R.H.S. is reached.

ICSE 2026 Board Q4(i) Identity Proof
3 Marks
Prove the following identity:
[sinθ / (1 + cosθ)] + [(1 + cosθ) / sinθ] = 2 cosecθ
View Verified Solution & Marking
L.H.S. Take common denominator = sinθ(1 + cosθ):
[sin²θ + (1 + cosθ)²] / [sinθ(1 + cosθ)] [1 Mark]
= [sin²θ + 1 + 2cosθ + cos²θ] / [sinθ(1 + cosθ)]
Since sin²θ + cos²θ = 1:
= [1 + 1 + 2cosθ] / [sinθ(1 + cosθ)] = [2 + 2cosθ] / [sinθ(1 + cosθ)] [1 Mark]
= 2(1 + cosθ) / [sinθ(1 + cosθ)] = 2 / sinθ = 2 cosecθ = R.H.S. Hence Proved. [1 Mark]
ICSE 2025 Board Q1(x) Multiple Choice Question
1 Mark
Assertion (A): If sin²A + sin A = 1 then cos⁴A + cos²A = 1.
Reason (R): 1 − sin²A = cos²A.
(a) (A) is true, (R) is false
(b) (A) is false, (R) is true
(c) Both (A) and (R) true, (R) is correct reason
(d) Both true, (R) is incorrect reason
View Official Marking Scheme Solution
From sin²A + sin A = 1 ⇒ sin A = 1 − sin²A = cos²A. Squaring gives sin²A = cos⁴A ⇒ 1 − cos²A = cos⁴A ⇒ cos⁴A + cos²A = 1. Both statements true and Reason is correct justification. [1 Mark]
ICSE 2025 Board Q4(iii) Trigonometric Identities Proof
4 Marks
Prove that: [(cot A + tan A − 1)(sin A + cos A)] / (sin³A + cos³A) = sec A · csc A.
View Official Marking Scheme Solution
Denominator: sin³A + cos³A = (sin A + cos A)(sin²A − sin A cos A + cos²A) = (sin A + cos A)(1 − sin A cos A). [1.5 Marks]
Numerator factor: cot A + tan A − 1 = (cos A/sin A + sin A/cos A) − 1 = (1 / sin A cos A) − 1 = (1 − sin A cos A) / (sin A cos A). [1.5 Marks]
Cancelling (sin A + cos A)(1 − sin A cos A) gives 1 / (sin A cos A) = sec A · csc A = RHS. Hence Proved. [1 Mark]
ICSE 2024 Board Q1(xi) Multiple Choice Question
1 Mark
Statement 1: sin2θ + cos2θ = 1
Statement 2: cosec2θ + cot2θ = 1
Which of the following is valid?
(a) only 1
(b) only 2
(c) both 1 and 2
(d) neither 1 nor 2
View Official Marking Scheme Solution
Correct Option: (a) only 1
sin2θ + cos2θ = 1 is valid. The second is invalid because cosec2θ − cot2θ = 1. [1 Mark]
ICSE 2024 Board Q3(i) Trigonometry • Algebraic Factoring & Identity
4 Marks
Factorize: sin3θ + cos3θ.
Hence prove: [ (sin3θ + cos3θ) / (sinθ + cosθ) ] + sinθ cosθ = 1.
View Official Marking Scheme Solution
sin3θ + cos3θ = (sinθ + cosθ)(sin2θ − sinθcosθ + cos2θ) = (sinθ + cosθ)(1 − sinθcosθ). [2 Marks]
LHS = [ (sinθ+cosθ)(1−sinθcosθ) / (sinθ+cosθ) ] + sinθcosθ = (1 − sinθcosθ) + sinθcosθ = 1 = RHS. [2 Marks]
ICSE 2023 Board Q1(viii) Multiple Choice Question
1 Mark
$(1 + \sin A)(1 - \sin A)$ is equal to:
(a) $\mathrm{cosec}^2 A$
(b) $\sin^2 A$
(c) $\sec^2 A$
(d) $\cos^2 A$
View Verified Solution & Marking
Using identity $(a + b)(a - b) = a^2 - b^2$:
$(1 + \sin A)(1 - \sin A) = 1 - \sin^2 A$.
Using fundamental Pythagorean identity $\sin^2 A + \cos^2 A = 1 \implies 1 - \sin^2 A = \cos^2 A$.
Correct Option: (d) [1 Mark]
ICSE 2023 Board Q3(ii) Prove Trigonometrical Identity
4 Marks
Prove the following identity: $$(\sin^2 \theta - 1)(\tan^2 \theta + 1) + 1 = 0$$
View Verified Solution & Marking
Step 1 State standard Pythagorean identities:
$\sin^2 \theta + \cos^2 \theta = 1 \implies \sin^2 \theta - 1 = -\cos^2 \theta$.1 Mark
$1 + \tan^2 \theta = \sec^2 \theta$.1 Mark
Step 2 Substitute into LHS:
$\text{LHS} = (-\cos^2 \theta)(\sec^2 \theta) + 1$.1 Mark
Step 3 Since $\sec \theta = \frac{1}{\cos \theta}$, $\cos^2 \theta \cdot \sec^2 \theta = 1$:
$\text{LHS} = -(1) + 1 = 0 = \text{RHS}$.
Hence Proved!1 Mark
