05. Quadratic Equations in One Variable Previous Year Questions

Core Formula: x = [−b ± √(b² − 4ac)] / (2a), D = b² − 4ac

CISCE Examiner Observation & Common Deduction Pitfall

For word problems, rejection of negative root must be stated with a clear reason (e.g. speed, time, length cannot be negative).

ICSE 2026 Board Q1(ix) Multiple Choice Question
1 Mark
The roots of the quadratic equation 3x² − 4√3x + 4 = 0 are:
(a) Real and equal
(b) Real and distinct
(c) Imaginary / No real roots
(d) Rational and distinct
View Verified Solution & Marking
Correct Option: (a) Real and equal
Discriminant a = 3, b = −4√3, c = 4.
D = b² − 4ac = (−4√3)² − 4(3)(4) = 48 − 48 = 0.
Since D = 0, the roots are real and equal.
ICSE 2026 Board Q5(iii) Long Answer
4 Marks
Solve the following quadratic equation using substitution:
2[x / (x + 1)]² − 5[x / (x + 1)] + 2 = 0, x ≠ −1
View Verified Solution & Marking
Substitution Let y = x / (x + 1).
Equation becomes: 2y² − 5y + 2 = 0. [1 Mark]
Factorising: 2y² − 4y − y + 2 = 0 ⇒ 2y(y − 2) − 1(y − 2) = 0.
⇒ (2y − 1)(y − 2) = 0 ⇒ y = 1/2 or y = 2. [1 Mark]

Case 1 x / (x + 1) = 1/2 ⇒ 2x = x + 1 ⇒ x = 1. [1 Mark]
Case 2 x / (x + 1) = 2 ⇒ x = 2x + 2 ⇒ x = −2. [1 Mark]
Solution set: x ∈ {1, −2}.
ICSE 2026 Board Q6(iii) Word Problem (Speed & Distance)
4 Marks
A train travels a distance of 360 km at a uniform speed. If the speed had been 5 km/h more, it would have taken 48 minutes less for the journey. Find the original speed of the train.
View Verified Solution & Marking
Equation Setup Let original speed = x km/h. Distance = 360 km.
Original time = 360/x hours. Increased speed = (x + 5) km/h, New time = 360/(x + 5) hours.
Time difference = 48 minutes = 48/60 = 4/5 hours.
⇒ 360/x − 360/(x + 5) = 4/5. [1 Mark]

Algebra 360 [ (x + 5 − x) / (x(x + 5)) ] = 4/5
⇒ 360 × 5 / [x² + 5x] = 4/5 ⇒ 1,800 / [x² + 5x] = 4/5
⇒ 4(x² + 5x) = 9,000 ⇒ x² + 5x − 2,250 = 0. [1 Mark]

Factorisation (x + 50)(x − 45) = 0. [1 Mark]
Since speed cannot be negative, x ≠ −50 ⇒ x = 45 km/h. [1 Mark]
ICSE 2025 Board Q1(i) Multiple Choice Question
1 Mark
The given quadratic equation 3x² + √7x + 2 = 0 has:
(a) two equal real roots
(b) two distinct real roots
(c) more than two real roots
(d) no real roots
View Official Marking Scheme Solution
Discriminant D = b² − 4ac = (√7)² − 4(3)(2) = 7 − 24 = −17.
Since D < 0, the equation has no real roots. [1 Mark]
ICSE 2025 Board Q2(i) Quadratic Formula (3 Sig Figs)
4 Marks
Solve the following quadratic equation 2x² − 5x − 4 = 0. Give your answer correct to three significant figures. (Use mathematical tables for this question)
View Official Marking Scheme Solution
a = 2, b = −5, c = −4.
x = [−b ± √(b² − 4ac)] / 2a = [5 ± √((-5)² − 4(2)(−4))] / 4 = [5 ± √(25 + 32)] / 4 = [5 ± √57] / 4. [2 Marks]
From tables: √57 ≈ 7.550.
x1 = (5 + 7.550) / 4 = 12.550 / 4 = 3.1375 ⇒ 3.14 (3 sig figs). [1 Mark]
x2 = (5 − 7.550) / 4 = −2.550 / 4 = −0.6375 ⇒ −0.638 (or −0.637). [1 Mark]
ICSE 2025 Board Q8(iii) Quadratic Equation Word Problem
4 Marks
Mr. and Mrs. Das were travelling by car from Delhi to Kasauli for a holiday. Distance between Delhi and Kasauli is approximately 350 km (via NH 152D). Due to heavy rain they had to slow down. The average speed of the car was reduced by 20 km/hr and time of the journey increased by 2 hours. Find:
(a) the original speed of the car.
(b) with the reduced speed, the number of hours they took to reach their destination.
View Official Marking Scheme Solution
Let original speed = x km/hr. Reduced speed = (x − 20) km/hr.
Time difference: 350 / (x − 20) − 350 / x = 2. [1.5 Marks]
350 [ x − (x − 20) ] / [ x(x − 20) ] = 2 ⇒ 350(20) = 2(x² − 20x) ⇒ x² − 20x − 3500 = 0.
(x − 70)(x + 50) = 0 ⇒ Since speed > 0, x = 70 km/hr.
(a) Original speed = 70 km/hr. [1.5 Marks]
(b) Reduced speed = 70 − 20 = 50 km/hr. Time taken = 350 / 50 = 7 hours. [1 Mark]
ICSE 2024 Board Q1(iii) Multiple Choice Question
1 Mark
The roots of the quadratic equation px2 − qx + r = 0 are real and equal if:
(a) p2 = 4qr
(b) q2 = 4pr
(c) −q2 = 4pr
(d) p2 > 4qr
View Official Marking Scheme Solution
Correct Option: (b) q2 = 4pr
Discriminant D = B2 − 4AC = 0 for real and equal roots.
(−q)2 − 4(p)(r) = 0 ⇒ q2 = 4pr. [1 Mark]
ICSE 2024 Board Q6(i) Algebra • Quadratic Equations
3 Marks
Solve the following quadratic equation for x and give your answer correct to three significant figures:
2x2 − 10x + 5 = 0
View Official Marking Scheme Solution
a = 2, b = −10, c = 5. Discriminant D = (−10)2 − 4(2)(5) = 100 − 40 = 60.
√60 = 7.7460. [1 Mark]
x = [10 ± 7.746] / 4
x1 = 17.746 / 4 = 4.4365 ≈ 4.44 (3 sig fig). [1 Mark]
x2 = 2.254 / 4 = 0.5635 ≈ 0.564 (3 sig fig). [1 Mark]
ICSE 2023 Board Q1(v) Multiple Choice Question
1 Mark
If 3 is a root of the quadratic equation $x^2 - px + 3 = 0$, then $p$ is equal to:
(a) 4
(b) 3
(c) 5
(d) 2
View Verified Solution & Marking
Since 3 is a root of the equation, it must satisfy $x^2 - px + 3 = 0$:
$3^2 - p(3) + 3 = 0 \implies 9 - 3p + 3 = 0 \implies 12 - 3p = 0 \implies 3p = 12 \implies p = 4$.
Correct Option: (a) [1 Mark]
ICSE 2023 Board Q3(i) Quadratic Formula (Correct to One Decimal Place)
4 Marks
Solve the following quadratic equation: $x^2 + 4x - 8 = 0$.
Give your answer correct to one decimal place. (Use mathematical tables if necessary.)
View Verified Solution & Marking
Step 1 Comparing with $ax^2 + bx + c = 0$: $a = 1, b = 4, c = -8$.
Discriminant $D = b^2 - 4ac = 4^2 - 4(1)(-8) = 16 + 32 = 48$.1 Mark
Step 2 Applying quadratic formula $x = \frac{-b \pm \sqrt{D}}{2a}$:
$x = \frac{-4 \pm \sqrt{48}}{2(1)} = \frac{-4 \pm 4\sqrt{3}}{2} = -2 \pm 2\sqrt{3}$.1 Mark
Step 3 Taking $\sqrt{3} \approx 1.732$ (or $\sqrt{48} \approx 6.928$):
$x_1 = -2 + 2(1.732) = -2 + 3.464 = 1.464 \approx \mathbf{1.5}$1 Mark
$x_2 = -2 - 2(1.732) = -2 - 3.464 = -5.464 \approx \mathbf{-5.5}$
Answers: $x = 1.5$ or $x = -5.5$.1 Mark
ICSE 2023 Board Q7(ii) Quadratic Equation Word Problem (Speed, Distance, Time)
3 Marks
A man covers a distance of 100 km, travelling with a uniform speed of $x\text{ km/hr}$. Had the speed been 5 km/hr more, it would have taken 1 hour less. Find $x$, the original speed.
View Verified Solution & Marking
Step 1 Set up time expressions:
Initial time $t_1 = \frac{100}{x}\text{ hours}$.
Increased speed time $t_2 = \frac{100}{x + 5}\text{ hours}$.1 Mark

Step 2 According to given condition $t_1 - t_2 = 1$:
$\frac{100}{x} - \frac{100}{x + 5} = 1$
$100\left(\frac{x + 5 - x}{x(x + 5)}\right) = 1 \implies \frac{500}{x^2 + 5x} = 1$
$x^2 + 5x - 500 = 0$.1 Mark

Step 3 Solve quadratic equation:
$(x + 25)(x - 20) = 0 \implies x = 20$ or $x = -25$.
Since speed cannot be negative, $x = 20$.
Original speed = 20 km/hr.1 Mark
