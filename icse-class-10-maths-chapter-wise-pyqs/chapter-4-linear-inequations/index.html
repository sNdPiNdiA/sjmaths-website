04. Linear Inequations (in One Variable) Previous Year Questions

Core Formula: Reverse inequality sign when multiplying or dividing by a negative number

CISCE Examiner Observation & Common Deduction Pitfall

Candidates forget to check replacement set. If x ∈ W or Z, do not draw a continuous solid line; plot discrete dots only.

ICSE 2026 Board Q9(i) Short Answer & Number Line
3 Marks
Solve the following inequation, write the solution set and represent it on the real number line:
−1 < (2x − 3)/3 − x/5 ≤ 1, x ∈ R
Solution set on the real number line: open circle at −1 and solid dot at 1
View Verified Solution & Marking
Algebraic Simplification Common denominator of (3, 5) = 15.
(2x − 3)/3 − x/5 = [5(2x − 3) − 3x] / 15 = (10x − 15 − 3x) / 15 = (7x − 15) / 15.
Inequality: −1 < (7x − 15)/15 ≤ 1.
Multiply through by 15: −15 < 7x − 15 ≤ 15.
Add 15 to all sides: 0 < 7x ≤ 30.
Divide by 7: 0 < x ≤ 30/7 (4.28). [2 Marks]

Number Line Solution set: { x : 0 < x ≤ 30/7, x ∈ R }.
Represented on real line with an open circle at 0 and a solid filled dot at 30/7 (≈ 4.3) with a darkened line between them. [1 Mark]
ICSE 2025 Board Q1(xiv) Multiple Choice Question
1 Mark
The solution set for 0 < −x/3 < 2, x ∈ Z is:
(a) {−5, −4, −3, −2, −1}
(b) {−6, −5, −4, −3, −2, −1}
(c) {−5, −4, −3, −2, −1, 0}
(d) {−6, −5, −4, −3, −2, −1, 0}
View Official Marking Scheme Solution
Multiply by −3 (reversing inequality signs): 0 > x > −6 ⇔ −6 < x < 0. Since x ∈ Z (integers), the solution set is {−5, −4, −3, −2, −1}. [1 Mark]
ICSE 2025 Board Q4(i) Linear Inequations on Real Number Line
3 Marks
Solve the following inequation, write the solution set and represent it on the real number line:
2x − 5/3 < 3x/5 + 10 ≤ 4x/5 + 11; x ∈ R.
View Official Marking Scheme Solution
Part 1: 2x − 5/3 < 3x/5 + 10 ⇒ 30x − 25 < 9x + 150 ⇒ 21x < 175 ⇒ x < 25/3 (8⅓). [1 Mark]
Part 2: 3x/5 + 10 ≤ 4x/5 + 11 ⇒ 3x + 50 ≤ 4x + 55 ⇒ x ≥ −5. [1 Mark]
Combined Solution Set: {x : −5 ≤ x < 25/3, x ∈ R}.
Number Line Representation: A solid darkened circle at −5, heavy line shaded continuously up to 25/3 (8.33), with a hollow open circle at 25/3. [1 Mark]
ICSE 2024 Board Q7(ii) Algebra • Linear Inequations
3 Marks
Solve the following inequation, write down the solution set and represent it on the real number line:
−3 + x ≤ 7x/2 + 2 < 8 + 2x,   x ∈ I
View Official Marking Scheme Solution
Part 1: −3 + x ≤ 7x/2 + 2 ⇒ −6 + 2x ≤ 7x + 4 ⇒ 5x ≥ −10 ⇒ x ≥ −2. [1 Mark]
Part 2: 7x/2 + 2 < 8 + 2x ⇒ 7x + 4 < 16 + 4x ⇒ 3x < 12 ⇒ x < 4. [1 Mark]
Combining: −2 ≤ x < 4. Since x ∈ I:
Solution Set = {−2, −1, 0, 1, 2, 3}. Correct solid dots plotted on number line. [1 Mark]
ICSE 2023 Board Q1(xv) Multiple Choice Question
1 Mark
The solution set for the inequation $2x + 4 \le 14, x \in W$ is:
(a) {1, 2, 3, 4, 5}
(b) {0, 1, 2, 3, 4, 5}
(c) {1, 2, 3, 4}
(d) {0, 1, 2, 3, 4}
View Verified Solution & Marking
$2x + 4 \le 14 \implies 2x \le 10 \implies x \le 5$.
Since $x \in W$ (set of whole numbers, which starts from 0):
Solution set = $\{0, 1, 2, 3, 4, 5\}$.
Correct Option: (b) [1 Mark]
ICSE 2023 Board Q5(ii) Double Linear Inequation & Real Number Line
3 Marks
Solve the following inequation. Write down the solution set and represent it on the real number line: $$-5(x - 9) \ge 17 - 9x > x + 2, \quad x \in R$$
Figure: Solution set $[-7, 1.5)$ on real number line with solid dot at $-7$ and open ring at $1.5$
View Verified Solution & Marking
Part 1 Split into two simultaneous inequations:
Left part: $-5(x - 9) \ge 17 - 9x$
$-5x + 45 \ge 17 - 9x \implies -5x + 9x \ge 17 - 45 \implies 4x \ge -28 \implies x \ge -7$.1 Mark

Right part: $17 - 9x > x + 2$
$-9x - x > 2 - 17 \implies -10x > -15 \implies x < \frac{15}{10} = 1.5$.1 Mark

Part 2 Combining solutions for $x \in R$:
$$-7 \le x < 1.5$$ Solution Set: $\{x : -7 \le x < 1.5, x \in R\}$.
Number Line: Closed dot at $-7$, thick bold segment up to $1.5$, hollow circle at $1.5$.1 Mark
