04. Linear Inequations (in One Variable) Previous Year Questions

Core Formula: Reverse inequality sign when multiplying or dividing by a negative number

CISCE Examiner Observation & Common Deduction Pitfall

Candidates forget to check replacement set. If x ∈ W or Z, do not draw a continuous solid line; plot discrete dots only.

ICSE 2026 Board Q1 Short Answer & Number Line
3 Marks
Solve the following inequation, write the solution set and represent it on the real number line:
−1 < (2x − 3)/3 − x/5 ≤ 1, x ∈ R
View Verified Solution & Marking
Solution set on the real number line: open circle at −1 and solid dot at 1
Algebraic Simplification Common denominator of (3, 5) = 15.
(2x − 3)/3 − x/5 = [5(2x − 3) − 3x] / 15 = (10x − 15 − 3x) / 15 = (7x − 15) / 15.
Inequality: −1 < (7x − 15)/15 ≤ 1.
Multiply through by 15: −15 < 7x − 15 ≤ 15.
Add 15 to all sides: 0 < 7x ≤ 30.
Divide by 7: 0 < x ≤ 30/7 (4.28). [2 Marks]

Number Line Solution set: { x : 0 < x ≤ 30/7, x ∈ R }.
Represented on real line with an open circle at 0 and a solid filled dot at 30/7 (≈ 4.3) with a darkened line between them. [1 Mark]

The solution set for 0 < −x/3 < 2, x ∈ Z is:
(a) {−5, −4, −3, −2, −1}
(b) {−6, −5, −4, −3, −2, −1}
(c) {−5, −4, −3, −2, −1, 0}
(d) {−6, −5, −4, −3, −2, −1, 0}
View Verified Solution & Marking
Multiply by −3 (reversing inequality signs): 0 > x > −6 ⇔ −6 < x < 0. Since x ∈ Z (integers), the solution set is {−5, −4, −3, −2, −1}. [1 Mark]
ICSE 2025 Board Q3 Linear Inequations on Real Number Line
3 Marks
Solve the following inequation, write the solution set and represent it on the real number line:
2x − 5/3 < 3x/5 + 10 ≤ 4x/5 + 11; x ∈ R.
View Verified Solution & Marking
Part 1: 2x − 5/3 < 3x/5 + 10 ⇒ 30x − 25 < 9x + 150 ⇒ 21x < 175 ⇒ x < 25/3 (8⅓). [1 Mark]
Part 2: 3x/5 + 10 ≤ 4x/5 + 11 ⇒ 3x + 50 ≤ 4x + 55 ⇒ x ≥ −5. [1 Mark]
Combined Solution Set: {x : −5 ≤ x < 25/3, x ∈ R}.
Number Line Representation: A solid darkened circle at −5, heavy line shaded continuously up to 25/3 (8.33), with a hollow open circle at 25/3. [1 Mark]
ICSE 2024 Board Q4 Algebra • Linear Inequations
3 Marks
Solve the following inequation, write down the solution set and represent it on the real number line:
−3 + x ≤ 7x/2 + 2 < 8 + 2x,   x ∈ I
View Verified Solution & Marking
Part 1: −3 + x ≤ 7x/2 + 2 ⇒ −6 + 2x ≤ 7x + 4 ⇒ 5x ≥ −10 ⇒ x ≥ −2. [1 Mark]
Part 2: 7x/2 + 2 < 8 + 2x ⇒ 7x + 4 < 16 + 4x ⇒ 3x < 12 ⇒ x < 4. [1 Mark]
Combining: −2 ≤ x < 4. Since x ∈ I:
Solution Set = {−2, −1, 0, 1, 2, 3}. Correct solid dots plotted on number line. [1 Mark]
ICSE 2023 Board Q5 Multiple Choice Question
1 Mark
The solution set for the inequation $2x + 4 \le 14, x \in W$ is:
(a) {1, 2, 3, 4, 5}
(b) {0, 1, 2, 3, 4, 5}
(c) {1, 2, 3, 4}
(d) {0, 1, 2, 3, 4}
View Verified Solution & Marking
$2x + 4 \le 14 \implies 2x \le 10 \implies x \le 5$.
Since $x \in W$ (set of whole numbers, which starts from 0):
Solution set = $\{0, 1, 2, 3, 4, 5\}$.
Correct Option: (b) [1 Mark]
ICSE 2023 Board Q6 Double Linear Inequation & Real Number Line
3 Marks
Solve the following inequation. Write down the solution set and represent it on the real number line: $$-5(x - 9) \ge 17 - 9x > x + 2, \quad x \in R$$
View Verified Solution & Marking
Figure: Solution set $[-7, 1.5)$ on real number line with solid dot at $-7$ and open ring at $1.5$
Part 1 Split into two simultaneous inequations:
Left part: $-5(x - 9) \ge 17 - 9x$
$-5x + 45 \ge 17 - 9x \implies -5x + 9x \ge 17 - 45 \implies 4x \ge -28 \implies x \ge -7$.1 Mark

Right part: $17 - 9x > x + 2$
$-9x - x > 2 - 17 \implies -10x > -15 \implies x < \frac{15}{10} = 1.5$.1 Mark

Part 2 Combining solutions for $x \in R$:
$$-7 \le x < 1.5$$ Solution Set: $\{x : -7 \le x < 1.5, x \in R\}$.
Number Line: Closed dot at $-7$, thick bold segment up to $1.5$, hollow circle at $1.5$.1 Mark
ICSE 2020 Board Q7 Linear Inequation on Real Number Line
3 Marks
Solve the following inequation and represent the solution set on the number line: $$\frac{3x}{5} + 2 < x + 4 \le \frac{x}{2} + 5, \quad x \in \mathbb{R}$$
View Verified Solution & Marking
Figure: Solution set $(-5, 2]$ on the real number line
Part 1 $\frac{3x}{5} + 2 < x + 4 \implies 2 - 4 < x - \frac{3x}{5} \implies -2 < \frac{2x}{5} \implies -10 < 2x \implies \mathbf{x > -5}$. [1 Mark]
Part 2 $x + 4 \le \frac{x}{2} + 5 \implies x - \frac{x}{2} \le 5 - 4 \implies \frac{x}{2} \le 1 \implies \mathbf{x \le 2}$. [1 Mark]
Step 3 Combining both parts: $-5 < x \le 2, \quad x \in \mathbb{R}$.
Solution set $= \{x : -5 < x \le 2, x \in \mathbb{R}\}$. Correct plot with hollow circle at $-5$ and solid dot at $2$. [1 Mark]
ICSE 2019 Board Q8 Linear Inequation on Real Number Line
3 Marks
Solve the following inequation and write down the solution set: $$11x - 4 < 15x + 4 \le 13x + 14, \quad x \in W$$ Represent the solution on a real number line.
View Verified Solution & Marking
Vector Diagram: Representation of discrete whole number solution set on real number line
Step 1 Split the inequation into two linear parts:
Part 1: $11x - 4 < 15x + 4$
$\implies -4 - 4 < 15x - 11x \implies -8 < 4x \implies x > -2$. [1 Mark]
Part 2: $15x + 4 \le 13x + 14$
$\implies 15x - 13x \le 14 - 4 \implies 2x \le 10 \implies x \le 5$. [1 Mark]
Step 2 Combine inequalities: $-2 < x \le 5$.
Since $x \in W$ (set of whole numbers $\{0, 1, 2, 3, \dots\}$):
Solution Set: $\{0, 1, 2, 3, 4, 5\}$.
Step 3 Graph the discrete elements with solid dark dots on the real number line at $0, 1, 2, 3, 4, 5$. [1 Mark]
ICSE 2026 Imp Q9 Real Inequation: Solution Set & Number Line
3 Marks
Solve the following inequation, write the solution set and represent it on the real number line: $$3x + \frac{14}{3} > \frac{4x}{3} - 2 \ge 3x - 4, \quad x \in \mathbb{R}$$
View Verified Solution & Marking
Vector Diagram: Real interval solution on number line with hollow circle at -4 and solid dot at 1.2
Step 1 Solve linear inequation in two parts:
Part 1: $3x + \frac{14}{3} > \frac{4x}{3} - 2$
$\implies 3x - \frac{4x}{3} > -2 - \frac{14}{3} \implies \frac{5x}{3} > -\frac{20}{3} \implies 5x > -20 \implies x > -4$. [1 Mark]
Part 2: $\frac{4x}{3} - 2 \ge 3x - 4$
$\implies -2 + 4 \ge 3x - \frac{4x}{3} \implies 2 \ge \frac{5x}{3} \implies 5x \le 6 \implies x \le \frac{6}{5} = 1.2$. [1 Mark]
Step 2 Combine inequalities:
$\mathbf{\text{Solution Set: } \{x : x \in \mathbb{R}, -4 < x \le 1.2\}}$.
Graph with open circle at $-4$, filled solid dot at $1.2$, and thickened segment between them. [1 Mark]
ICSE 2018 Board Q10 Linear Inequation on Number Line
3 Marks
Solve the following inequation, write down the solution set and represent it on the real number line: $$-2 + 10x \le 13x + 10 < 24 + 10x, \quad x \in \mathbb{Z}$$
View Verified Solution & Marking
Part 1 First inequality:
$$-2 + 10x \le 13x + 10 \implies -2 - 10 \le 13x - 10x$$ $$-12 \le 3x \implies x \ge -4$$ [1 Mark]
Part 2 Second inequality:
$$13x + 10 < 24 + 10x \implies 13x - 10x < 24 - 10$$ $$3x < 14 \implies x < \frac{14}{3} \approx 4.67$$ [1 Mark]
Solution Set Combining both: $-4 \le x < \frac{14}{3}$.
Since $x \in \mathbb{Z}$ (integers):
$$\text{Solution Set} = \mathbf{\{-4, -3, -2, -1, 0, 1, 2, 3, 4\}}$$ [0.5 Mark]
Number line Represented by solid darkened dots on integers from $-4$ to $4$ inclusive. [0.5 Mark]
Answer: Solution Set $= \{-4, -3, -2, -1, 0, 1, 2, 3, 4\}$.
ICSE 2017 Board Q11 Inequation Representation on Number Line
3 Marks
Solve the following inequation and represent the solution set on a number line: $$-8\frac{1}{2} < -\frac{1}{2} - 4x \le 7\frac{1}{2}, \quad x \in I$$
View Verified Solution & Marking
Step 1 Add $\frac{1}{2}$ throughout the inequation:
$$-8.5 + 0.5 < -4x \le 7.5 + 0.5 \implies -8 < -4x \le 8$$ [1 Mark]
Step 2 Divide throughout by $-4$ (reversing the inequality signs):
$$\frac{-8}{-4} > x \ge \frac{8}{-4} \implies 2 > x \ge -2 \iff -2 \le x < 2$$ [1 Mark]
Step 3: Solution Set Since $x \in I$ (integers):
$$\text{Solution Set} = \mathbf{\{-2, -1, 0, 1\}}$$ [0.5 Mark]
Represented by solid filled dots on $-2, -1, 0, 1$ on the number line. [0.5 Mark]
Answer: Solution Set $= \{-2, -1, 0, 1\}$.
