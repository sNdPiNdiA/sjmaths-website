What this chapter is teaching

A linear equation in two variables describes infinitely many ordered pairs. On a graph, those solutions form one straight line. A pair of equations can be understood by comparing their lines or by solving them algebraically.

1Linear equation in two variables

The standard form is ax + by + c = 0, where a, b and c are real numbers and a and b are not both zero.

  • a is the coefficient of x, b is the coefficient of y and c is the constant term.
  • Move all terms to one side before identifying a, b and c.
  • Examples: 5x = 3y becomes 5x − 3y + 0 = 0; x = 8 becomes x + 0y − 8 = 0.
  • A statement must be translated according to the meaning of the variables. If t is a notebook cost and p is a pen cost, notebook twice pen means t = 2p.

2Solutions and the graph of one equation

An ordered pair (x, y) is a solution of an equation when substituting x and y makes the equation true.

  • A linear equation in two variables usually has infinitely many solutions.
  • Choose a value of x, substitute it and calculate y. Each resulting pair is a solution.
  • Plot the ordered pairs and join them with a straight line. Every point on the line is a solution, and every solution lies on the line.
  • The graph passes through the origin only when the constant term is zero.

3Slope and intercept

For a line through (x₁, y₁) and (x₂, y₂), slope is the change in y divided by the change in x.

  • Slope m = (y₂ − y₁)/(x₂ − x₁) = rise/run.
  • Positive slope means the line rises from left to right; negative slope means it falls.
  • In y = mx + d, m is the slope and d is the y-intercept.
  • The y-intercept is the point (0, d), where the line cuts the y-axis.
  • A steeper ramp has a greater absolute value of slope.

4Pairs of linear equations

Two equations in x and y are represented by two lines. Their common solution is the ordered pair that lies on both lines.

  • Intersecting lines have one common point, so the pair has a unique solution.
  • Parallel lines never meet, so the pair has no solution.
  • Coincident lines lie on top of each other, so every point on the line is a solution.
  • Solve algebraically by substitution or elimination; solve graphically by finding the intersection.
Ratio test: For a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0, unequal a₁/a₂ and b₁/b₂ gives one solution. If a₁/a₂ = b₁/b₂ ≠ c₁/c₂, there is no solution. If all three ratios are equal, there are infinitely many solutions.

When variables can take only selected values

A linear equation has a straight-line graph when every real value in its allowed range is considered. In some situations, only certain values make sense—for example, a whole number of completed kilometres. Then plot only the allowed ordered pairs; do not join the points unless intermediate values are allowed too.

Solved example: a taxi charges ₹40 as a fixed fee and ₹12 for each completed kilometre.
  1. Let x be the number of completed kilometres and y the fare in rupees.
  2. Fixed fee = 40 and distance charge = 12x, so y = 12x + 40.
  3. If x is restricted to 0, 1, 2, 3 or 4, calculate the allowed values:

Worked graphical solution of a pair

Each equation gives a line. The ordered pair at their intersection satisfies both equations.

  1. For y = x + 1, make a table: when x = 0, 2, 4, y = 1, 3, 5.
  2. For y = 5 − x, make a table: when x = 0, 2, 4, y = 5, 3, 1.
  3. Plot each set of points and draw both straight lines.
  4. Read their intersection from the graph: (2, 3).
  5. Check: 3 = 2 + 1 and 3 = 5 − 2.
Answer: The pair has the unique solution x = 2, y = 3.

Consistency: does a pair have a solution?

A pair is consistent if it has at least one common solution. It is inconsistent if it has no common solution.

  • Intersecting lines: one solution, so the pair is consistent and independent.
  • Coincident lines: infinitely many solutions, so the pair is consistent and dependent.
  • Distinct parallel lines: no solution, so the pair is inconsistent.
Solved examples using the ratio test.
  1. Unique solution: x + y = 5 and x − y = 1 have different coefficient ratios for x and y (1/1 ≠ 1/(−1)). Add the equations: 2x = 6, so x = 3. Substitute in x + y = 5: y = 2. The pair is consistent and independent.
  2. No solution: Write the equations as x + y − 5 = 0 and 2x + 2y − 12 = 0. The x- and y-coefficient ratios are 1/2, but the constant ratio is 5/12. The lines are distinct and parallel, so the pair is inconsistent.
  3. Infinitely many solutions: Write x + y − 5 = 0 and 2x + 2y − 10 = 0. All coefficient ratios equal 1/2, so the equations describe the same line. The pair is consistent and dependent.

Algebraic methods: complete solved examples

Substitution: solve 2x + y = 7 and x − y = 2.
  1. From x − y = 2, make x the subject: x = y + 2.
  2. Substitute in 2x + y = 7: 2(y + 2) + y = 7.
  3. Simplify: 3y + 4 = 7, so 3y = 3 and y = 1.
  4. Substitute y = 1 into x = y + 2: x = 3.
  5. Check: 2(3) + 1 = 7 and 3 − 1 = 2.
Answer: (x, y) = (3, 1).
Elimination: solve 2x + 3y = 13 and 3x − 2y = 0.
  1. Multiply the first equation by 2: 4x + 6y = 26.
  2. Multiply the second equation by 3: 9x − 6y = 0.
  3. Add the equations to eliminate y: 13x = 26, so x = 2.
  4. Substitute x = 2 into 3x − 2y = 0: 6 − 2y = 0, so y = 3.
  5. Check: 2(2) + 3(3) = 13 and 3(2) − 2(3) = 0.
Answer: (x, y) = (2, 3).

Model a daily-life situation and interpret the answer

Situation: Two notebooks and one pen cost ₹110. One notebook and two pens cost ₹100. Find the price of each item.

  1. Let n be the price of one notebook in rupees and p be the price of one pen in rupees.
  2. Translate the first purchase: 2n + p = 110.
  3. Translate the second purchase: n + 2p = 100.
  4. Multiply the second equation by 2: 2n + 4p = 200.
  5. Subtract 2n + p = 110: 3p = 90, so p = 30.
  6. Substitute p = 30 into n + 2p = 100: n + 60 = 100, so n = 40.
  7. Check the purchases: 2(40) + 30 = 110 and 40 + 2(30) = 100.
Conclusion: One notebook costs ₹40 and one pen costs ₹30. Both prices are positive and satisfy the original situation, so the result is sensible.

1Write a linear equation in two variables in which a = 3, b = 0 and c = −1/5.
Answer / method
Step 1: Substitute a = 3, b = 0 and c = −1/5 in ax + by + c = 0. Step 2: 3x + 0y − 1/5 = 0. Conclusion: 3x − 1/5 = 0 is the required linear equation in two variables.
2Complete the table after expressing y − 15 = √2x, 3y − 2x = 0, 5x = 3y, x = 8 and 3y = 1 in standard form. Give the coefficient of x, coefficient of y and constant term.
Answer / method
Step 1: Put all terms on the left side. Step 2: y − 15 = √2x becomes √2x − y + 15 = 0, so a = √2, b = −1, c = 15. Step 3: 3y − 2x = 0 becomes −2x + 3y + 0 = 0, so a = −2, b = 3, c = 0. Step 4: 5x = 3y becomes 5x − 3y + 0 = 0, so a = 5, b = −3, c = 0. Step 5: x = 8 becomes x + 0y − 8 = 0, so a = 1, b = 0, c = −8. Step 6: 3y = 1 becomes 0x + 3y − 1 = 0, so a = 0, b = 3, c = −1.
3(i) The cost of a notebook is twice the cost of a pen. If a pen costs ₹p and a notebook costs ₹t, Charlie wrote t = 2p, whereas Meera wrote p = 2t. Which representation is correct? (ii) Two Indian batsmen together scored 176 runs. If their scores are x and y, is x + y = 176 correct?
Answer / method
Step 1: Let pen cost = ₹p and notebook cost = ₹t. Step 2: Notebook cost is twice pen cost, so t = 2p. Conclusion for (i): Charlie is correct; p = 2t reverses the meaning. Step 3: If the two scores are x and y, their total is x + y. Step 4: The total is 176, so x + y = 176. Conclusion for (ii): Manisha's representation is correct.

Exercise Set 13.2 — Solutions

Solutions, graphs, quadrants and equivalent equations.

1Verify if the ordered pair (4, 3) is a solution of 5x − 6y = 2. Explain your reasoning.
Answer / method
Step 1: Substitute x = 4 and y = 3 into 5x − 6y. Step 2: 5(4) − 6(3) = 20 − 18 = 2. Step 3: The result equals the right side, 2. Conclusion: (4, 3) is a solution.
2Find any two solutions for each equation: (i) 7x − 3y = 21. (ii) 2x + 3y = 5.
Answer / method
Step 1: For 7x − 3y = 21, choose x = 3. Then 21 − 3y = 21, so y = 0. One solution is (3, 0). Step 2: Choose x = 0. Then −3y = 21, so y = −7. Another solution is (0, −7). Step 3: For 2x + 3y = 5, choose x = 1. Then 2 + 3y = 5, so y = 1. One solution is (1, 1). Step 4: Choose x = 4. Then 8 + 3y = 5, so y = −1. Another solution is (4, −1). Step 5: Substitution verifies all four ordered pairs.
3In 2mx + 3y = 7 and 4x + ny = −10, m and n are unknown. If (2, −1) is the solution of both equations, find m and n.
Answer / method
Step 1: Substitute (2, −1) in 2mx + 3y = 7. Step 2: 2m(2) + 3(−1) = 7, so 4m − 3 = 7. Step 3: 4m = 10, hence m = 5/2. Step 4: Substitute (2, −1) in 4x + ny = −10. Step 5: 4(2) + n(−1) = −10, so 8 − n = −10. Step 6: n = 18.
4Find two solutions in different quadrants for each: (i) 5x + 3y = 7, (ii) 5x − 3y = 7, (iii) −5x + 3y = 7, (iv) −5x − 3y = 7. Identify the quadrants and verify by graphing.
Answer / method
Step 1: Choose convenient x-values and calculate y. Step 2: (i) 5x + 3y = 7. With x = 1, y = 2/3, which is in Quadrant I. With x = 2, y = −1, which is in Quadrant IV. Step 3: (ii) 5x − 3y = 7. With x = 1, y = −2/3, which is in Quadrant IV. With x = 2, y = 1, which is in Quadrant I. Step 4: (iii) −5x + 3y = 7. With x = −1, y = 2/3, which is in Quadrant II. With x = 1, y = 4, which is in Quadrant I. Step 5: (iv) −5x − 3y = 7. With x = −1, y = −2/3, which is in Quadrant III. With x = 1, y = −4, which is in Quadrant IV. Step 6: Plot each pair and join the two points. The resulting straight line verifies the equation.
5For the graph of 3x − 7y = 21, does C(2, 3) lie on the line? Does it satisfy the equation? Can a point not on the line satisfy the equation?
Answer / method
Step 1: Substitute C(2, 3) in 3x − 7y = 21. Step 2: 3(2) − 7(3) = 6 − 21 = −15. Step 3: Since −15 ≠ 21, C does not satisfy the equation and does not lie on the line. Conclusion: a point not on the graph cannot satisfy the equation, because the graph contains exactly all the solutions.
6State True or False and justify: (i) a linear equation in two variables has only one solution; (ii) its graph always passes through the origin; (iii) it can never have rational solutions; (iv) x = 3 is valid; (v) 2x + 3y = 7 has infinitely many solutions; (vi) (1, 2) solves 2x + 3y = 7.
Answer / method
Step 1: (i) False. Choose x freely and calculate y; normally infinitely many ordered pairs result. Step 2: (ii) False. The graph passes through (0, 0) only when the constant term is zero. Step 3: (iii) False. For example, 2x + 3y = 7 has the rational solution (2, 1). Step 4: (iv) True. x = 3 can be written as x + 0y − 3 = 0. Step 5: (v) True. One equation in two variables has infinitely many solutions when it is a valid linear equation. Step 6: (vi) False. 2(1) + 3(2) = 8, not 7.
7(i) Compare the solutions of 3x + 4y = 7 and 6x + 8y = 14. (ii) Show that ax + by = c and kax + kby = kc, where k ≠ 0, have the same solutions.
Answer / method
Step 1: 6x + 8y = 14 is exactly 2(3x + 4y = 7). Step 2: Multiplying an equation by a non-zero number does not change its solutions. Conclusion for (i): both equations have the same set of solutions. Step 3: If ax + by = c, multiply every term by k, where k ≠ 0. Step 4: The result is kax + kby = kc. Step 5: Dividing the second equation by k returns the first equation. Conclusion for (ii): the two equations have exactly the same solutions.

1Three ski hills have rises and runs: A: 60 m and 70 m; B: 60 m and 110 m; C: 80 m and 100 m. Rank them from least to greatest steepness.
Answer / method
Step 1: Slope = rise/run. Step 2: A: slope = 60/70 = 6/7 ≈ 0.857. Step 3: B: slope = 60/110 = 6/11 ≈ 0.545. Step 4: C: slope = 80/100 = 4/5 = 0.8. Conclusion: least to greatest steepness is B, C, A.

Answer / method

Making pairs of linear equations from everyday situations.

1A movie ticket costs ₹x and a snack box costs ₹y. On one day, 2 tickets and 3 snack boxes cost ₹850; on another day, 4 tickets and 1 snack box cost ₹1100. Frame the pair.
Answer / method
Step 1: Let one ticket cost ₹x and one snack box cost ₹y. Step 2: First day: 2 tickets and 3 boxes cost 850, so 2x + 3y = 850. Step 3: Second day: 4 tickets and 1 box cost 1100, so 4x + y = 1100. Conclusion: the pair is 2x + 3y = 850 and 4x + y = 1100.

Answer / method
Step 1: Let fixed taxi charge be ₹x and charge per kilometre be ₹y. Step 2: Sahil's fare gives x + 6y = 122. Step 3: Meena's fare gives x + 8y = 160. Conclusion: the pair is x + 6y = 122 and x + 8y = 160.

Answer / method
Step 1: Let adult tickets be x and child tickets be y. Step 2: Total people: x + y = 200. Step 3: Total amount: 150x + 100y = 25000. Conclusion: the pair is x + y = 200 and 150x + 100y = 25000.

1For the graph y = 3x through (0, 0) and (2, 6): (i) identify the slope; (ii) identify the y-intercept; (iii) for a water tank following this graph, find height after 5 minutes and time for height 21 cm; (iv) test (4, 10); (v) find the intersection with x = 3.
Answer / method
Step 1: For y = 3x, use the two points (0, 0) and (2, 6). Step 2: Slope = (6 − 0)/(2 − 0) = 6/2 = 3. Step 3: Comparing y = mx + c with y = 3x gives m = 3 and c = 0. The y-intercept is (0, 0), showing the line passes through the origin. Step 4: Water after 5 minutes: y = 3(5) = 15 cm. Step 5: For height 21 cm, 21 = 3x, so x = 7 minutes. Step 6: At (4, 10), 3x = 12, not 10. Therefore the point is not on the line. Step 7: On x = 3, y = 3(3) = 9. The intersection is (3, 9).
2For F = (9/5)C + 32: (i) draw the Celsius–Fahrenheit graph; (ii) find F at 30°C; (iii) find C at 95°F; (iv) find F at 0°C and C at 0°F; (v) find a temperature numerically equal in both scales.
Answer / method
Step 1: Use F = (9/5)C + 32 and choose Celsius values for a table: (0,32), (10,50), (20,68), (30,86). Plot these points and join them. Step 2: At C = 30, F = (9/5)(30) + 32 = 54 + 32 = 86°F. Step 3: At F = 95, 95 = (9/5)C + 32, so 63 = (9/5)C and C = 35°C. Step 4: At C = 0, F = 32°F. At F = 0, 0 = (9/5)C + 32, so C = −160/9°C, approximately −17.78°C. Step 5: For the same numerical value, let F = C. Then C = (9/5)C + 32, so −4C/5 = 32 and C = −40. Therefore F = C = −40°.

5Give a formula for the x-intercept of y = mx + c.
Answer / method
Step 1: At the x-intercept, y = 0. Step 2: Put y = 0 in y = mx + c: 0 = mx + c. Step 3: mx = −c, so x = −c/m, provided m ≠ 0. Conclusion: x-intercept = (−c/m, 0).
6Plan A costs ₹50 monthly plus ₹0.20 per minute. Plan B costs ₹30 monthly plus ₹0.30 per minute. When is each plan cheaper, and when are they equal?
Answer / method
Step 1: Let monthly minutes be t. Plan A costs 50 + 0.20t. Plan B costs 30 + 0.30t. Step 2: Plan A is cheaper when 50 + 0.20t < 30 + 0.30t. Thus 20 < 0.10t, so t > 200. Step 3: Plan B is cheaper when t < 200. Step 4: At equality, 50 + 0.20t = 30 + 0.30t, so t = 200. Conclusion: Plan B is cheaper below 200 minutes, both cost the same at 200 minutes, and Plan A is cheaper above 200 minutes.
7How many lines exist that (i) have a given slope? (ii) have a given slope and pass through a given point?
Answer / method
Step 1: Fix a slope m. Changing the y-intercept gives y = mx + c for different values of c. Conclusion for (i): infinitely many lines have a given slope. Step 2: If the slope and one point are fixed, the y-intercept is fixed by substituting the point in y = mx + c. Conclusion for (ii): exactly one line has a given slope and passes through a given point.
8For what values of p does 4x + py + 8 = 0 and 2x + 2y + 2 = 0 have a unique solution?
Answer / method
Step 1: The equations are 4x + py + 8 = 0 and 2x + 2y + 2 = 0. Step 2: The coefficient ratios are a₁/a₂ = 4/2 = 2 and b₁/b₂ = p/2. Step 3: A unique solution requires unequal coefficient ratios. Step 4: 2 ≠ p/2, so p ≠ 4. Conclusion: the pair has a unique solution for every p except p = 4.
9Find a and b so that (a + b)x − 2by = 5a + 2b + 1 and 3x − y = 14 have infinitely many solutions.
Answer / method
Step 1: For infinitely many solutions, all coefficient ratios must be equal. Step 2: (a+b)/3 = (−2b)/(−1) = 2b. Hence a + b = 6b, so a = 5b. Step 3: Also (5a + 2b + 1)/14 = 2b, so 5a + 2b + 1 = 28b. Step 4: Substitute a = 5b: 25b + 2b + 1 = 28b, so b = 1. Step 5: a = 5b = 5. Conclusion: a = 5 and b = 1.
10Find k so that x + 2y = 3 and (k − 1)x + (k + 1)y = k + 3 represent coincident lines.
Answer / method
Step 1: For coincident lines, (k−1)/1 = (k+1)/2 = (k+3)/3. Step 2: Equate the first two ratios: 2(k−1) = k + 1, so k = 3. Step 3: Check the third ratio: when k = 3, (k−1) = 2, (k+1)/2 = 2 and (k+3)/3 = 2. Conclusion: k = 3.
11(i) Robot 1 starts at the origin and moves 3 right, 4 up repeatedly. Robot 2 starts at (10, 0) and moves 1 right, 2 up repeatedly. Do their paths intersect? (ii) Robot 1 starts at (3, 0) and moves 5 right, 5 up. Robot 2 starts at (7, 0) and moves 5 right, 3 down. Do their paths intersect?
Answer / method
Step 1: Robot 1 moves 3 right and 4 up, so its path has slope 4/3 and passes through (0,0): y = 4x/3. Step 2: Robot 2 moves 1 right and 2 up, so its path has slope 2 and passes through (10,0): y = 2x − 20. Step 3: Equate the paths: 4x/3 = 2x − 20. Thus 4x = 6x − 60, so x = 30 and y = 40. Conclusion for (i): the paths intersect at (30, 40). Step 4: For (ii), Robot 1 has y = x − 3. Robot 2 has slope −3/5 through (7,0), so y = −3x/5 + 21/5. Step 5: Equating gives x − 3 = −3x/5 + 21/5, so x = 9/2 and y = 3/2. Step 6: This point has x = 4.5, which is before Robot 2's starting x-coordinate 7. Therefore the infinite lines meet there, but the forward paths traced by the robots do not intersect.
*12Jacob's watch reads a minutes after two o'clock. Fifteen minutes later it reads b minutes after three o'clock, and a is six times b. What time was the second reading?
Answer / method
Step 1: The first reading is 2:a, so the second reading 15 minutes later must cross 3 o'clock. Therefore a = b + 45. Step 2: Given a = 6b. Step 3: 6b = b + 45, so 5b = 45 and b = 9. Step 4: a = 6(9) = 54. Conclusion: the second reading was 3:09.
*13The digits of a two-digit number add to 15. Interchanging the digits increases the number by 9. Find the number.
Answer / method
Step 1: Let the tens digit be a and units digit be b. Step 2: a + b = 15. Step 3: Reversed number exceeds the original by 9: 10b + a = 10a + b + 9. Step 4: 9b − 9a = 9, so b − a = 1. Step 5: Adding a + b = 15 and b − a = 1 gives 2b = 16, so b = 8 and a = 7. Conclusion: the number is 78.
*14In cyclic quadrilateral ABCD, ∠A = (x + 7)°, ∠B = (y + 8)°, ∠C = (3y + 23)° and ∠D = (4x + 12)°. Find all four angles.
Answer / method
Step 1: Opposite angles of a cyclic quadrilateral are supplementary. Step 2: (x + 7) + (3y + 23) = 180 gives x + 3y = 150. Step 3: (y + 8) + (4x + 12) = 180 gives 4x + y = 160. Step 4: From 4x + y = 160, y = 160 − 4x. Substitute: x + 3(160 − 4x) = 150. Step 5: −11x = −330, so x = 30 and y = 40. Step 6: ∠A = 37°, ∠B = 48°, ∠C = 143° and ∠D = 132°.
*15A train takes 6 hours less for a distance when its speed is increased by 6 km/h, and 6 hours more when speed is decreased by 4 km/h. Find distance and original speed.
Answer / method
Step 1: Let original speed be v km/h and original time be t hours. Distance d = vt. Step 2: Increased speed gives d = (v + 6)(t − 6). Expanding and comparing with vt gives t − v = 6. Step 3: Decreased speed gives d = (v − 4)(t + 6). Comparing with vt gives 3v − 2t = 12. Step 4: Substitute t = v + 6 into 3v − 2t = 12: 3v − 2(v + 6) = 12. Step 5: v = 24 km/h and t = 30 hours. Step 6: Distance d = vt = 24 × 30 = 720 km. Conclusion: original speed is 24 km/h and distance is 720 km.
*16A father's age equals the sum of the ages of his four children. After 20 years, the children's age sum will be twice the father's age. Find the father's age.
Answer / method
Step 1: Let father's present age be F and the sum of the children's present ages be S. Step 2: Given F = S. Step 3: After 20 years, father is F + 20 and the four children together are S + 80. Step 4: Given S + 80 = 2(F + 20). Step 5: Substitute S = F: F + 80 = 2F + 40, so F = 40. Conclusion: the father is 40 years old. The four children's present ages together total 40 years.
