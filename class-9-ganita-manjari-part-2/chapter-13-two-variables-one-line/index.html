1Linear Equations in Two Variables & Standard Form

Radha stops at a fruit cart. The price tags say that mangoes cost ₹60 per kg and bananas cost ₹50 per kg. She buys x kg of mangoes and y kg of bananas, paying ₹280 in total. This situation is modeled by the linear equation:

60x + 50y = 280

Both sides represent the exact same quantity: the total cost in rupees. This is a linear equation in two variables.

Standard Form of a Linear Equation in Two Variables

Any equation that can be expressed in the form:

ax + by + c = 0

where a, b, c are real numbers, and a and b are not both zero (a² + b² ≠ 0), is called a linear equation in two variables in standard form. Here a is the coefficient of x, b is the coefficient of y, and c is the constant term.

  • Clearing Fractions: Coefficients can be fractions. For example, ¼x + (3 / 5)y - ½ = 0 can be multiplied by the LCM 20 to clear denominators, giving 5x + 12y - 10 = 0.
  • Single-Variable Equations as Special Cases: Equations like 4x + 7 = 0 are special cases of two variables with b = 0: 4x + 0y + 7 = 0. Similarly, 3y = 5 is 0x + 3y - 5 = 0.
Solved Example 1 (Page 86) — Expressing Equations in Standard Form:
  1. (i) 5x + 2y = 2.7: Rewrite as 5x + 2y - 2.7 = 0 &implies a = 5, b = 2, c = -2.7. (Alternatively, -5x - 2y + 2.7 = 0).
  2. (ii) (x / 2) - 4 = (3 / 2)y: Rewrite as ½x - (3 / 2)y - 4 = 0 &implies a = ½, b = -(3 / 2), c = -4. (Or multiply by 2: x - 3y - 8 = 0).
  3. (iii) 4 = 1.5x - 1.3y: Rewrite as 1.5x - 1.3y - 4 = 0 &implies a = 1.5, b = -1.3, c = -4.
  4. (iv) 3y = 5: Rewrite as 0x + 3y - 5 = 0 &implies a = 0, b = 3, c = -5.

2Algebraic Meaning of Solutions & The Infinite Solution Set

A solution of a linear equation in two variables is an ordered pair of real numbers (u, v) such that substituting x = u and y = v satisfies the equation (makes LHS = RHS).

Consider 3x + 2y = 12:

  • (2, 3) is a solution because 3(2) + 2(3) = 6 + 6 = 12.
  • (4, 0) is a solution because 3(4) + 2(0) = 12 + 0 = 12.
  • (1, 3) is not a solution because 3(1) + 2(3) = 9 ≠ 12.
Why Every Linear Equation in Two Variables Has Infinitely Many Solutions:
Express y explicitly in terms of x: y = -(3 / 2)x + 6. For every chosen real value of x, there is a corresponding real value of y. Hence, there are infinitely many solutions!
Think and Reflect (Page 88): Testing the pairs for 3x + 2y = 12:
  • (1, 9/2): 3(1) + 2(9/2) = 3 + 9 = 12 &implies Solution.
  • (0, 6): 3(0) + 2(6) = 12 &implies Solution (y-intercept).
  • (4, 1): 3(4) + 2(1) = 14 ≠ 12 &implies Not a solution.
  • (1/2, 21/4): 3(1/2) + 2(21/4) = 3/2 + 21/2 = 24/2 = 12 &implies Solution.
Solved Example 4 (Page 92) — Finding Unknown Parameters:

If (-3, 4) is a solution of both 3ax + 4y = -2 and 2x + by = 14, find a and b:

  1. Substitute x = -3, y = 4 into equation 1: 3a(-3) + 4(4) = -2 ⇒ -9a + 16 = -2 ⇒ -9a = -18 ⇒ a = 2.
  2. Substitute x = -3, y = 4 into equation 2: 2(-3) + b(4) = 14 ⇒ -6 + 4b = 14 ⇒ 4b = 20 ⇒ b = 5.
Think and Reflect (Page 92) — The Origin Condition (c = 0):

Ranju, Farhan, Toshi, and Meena's mathematical deduction:

In standard form ax + by + c = 0, substituting the origin (0, 0) gives a(0) + b(0) + c = 0 ⇒ c = 0.
Theorem: A straight line passes through the origin (0, 0) if and only if its constant term c = 0.
Special cases: x = 0 (a=1, b=0, c=0) is the equation of the y-axis; y = 0 (a=0, b=1, c=0) is the equation of the x-axis.

3Geometric Visualisation & Graphing One Line

The geometric graph of a linear equation in two variables is always a straight line. The fundamental connection between algebra and geometry is:

Point on Line &implies SolutionEvery point (x, y) lying on the line is an algebraic solution of the equation.
Solution &implies Point on LineEvery algebraic solution (x, y) corresponds to a coordinate point lying on the straight line.
The Intercept Method for Plotting a Line:
  • Set x = 0 to find where the line crosses the y-axis (y-intercept).
  • Set y = 0 to find where the line crosses the x-axis (x-intercept).
  • Join the two points with a straightedge and extend in both directions.
Solved Example 2 (Page 89–90) — Graph of 2x + y = 7:
  1. Set x = 0 ⇒ y = 7 ⇒ A(0, 7).
  2. Set y = 0 ⇒ 2x = 7 ⇒ x = 3.5 ⇒ B(3.5, 0).
  3. Plotting the line reveals further integer solutions: (1, 5), (2, 3), (3, 1), (4, -1).
Solved Example 3 (Page 90–91) — Intercept vs. Origin Graphs:
  • (i) 4x + 3y = 12: x = 0 ⇒ y = 4 ((0, 4)); y = 0 ⇒ x = 3 ((3, 0)). Graph passes through (0, 4) and (3, 0).
  • (ii) 2x + 5y = 0: Since c = 0, it passes through (0, 0). A second point is found by setting x = 5 ⇒ 2(5) + 5y = 0 ⇒ y = -2 ⇒ (5, -2). Another point is (1, -0.4).

4Understanding Slope & The Slope-Intercept Form (y = mx + d)

In mathematics, the steepness of a line is called its slope or gradient (m). It is the ratio of vertical change (Rise) to horizontal change (Run):

m = (Rise / Run) = (y_2 - y_1 / x_2 - x_1)
Solved Examples 5 & 6 (Page 97–98) — Slope Calculations:
  • Example 5: Line through A(-1, 0), B(1, 2), C(4, 5). Using B and C: m = (5 - 2 / 4 - 1) = (3 / 3) = 1.
  • Example 6 (Order Invariance): Line through A(-4, 5) and B(-1, 2):
    Taking A to B: m = (2 - 5 / -1 - (-4)) = (-3 / 3) = -1.
    Taking B to A: m = (5 - 2 / -4 - (-1)) = (3 / -3) = -1.
    Key Fact: The slope is strictly independent of the order of the two chosen points!

Mathematical Proof 1: Why m in y = mx + d Represents the Slope

  1. Let A(x_1, y_1) and B(x_2, y_2) be any two distinct points on the line y = mx + d.
  2. Since both points satisfy the equation: y_1 = mx_1 + d and y_2 = mx_2 + d.
  3. Subtracting the two equations gives the Rise:
    y_2 - y_1 = (mx_2 + d) - (mx_1 + d) = mx_2 - mx_1 = m(x_2 - x_1)
  4. Dividing by the Run (x_2 - x_1) (with x_2 ≠ x_1):
    (y_2 - y_1 / x_2 - x_1) = (m(x_2 - x_1) / x_2 - x_1) = m
  5. Hence, the coefficient m in y = mx + d identically equals the geometric slope between any two points on the line! Q.E.D.
Converting Standard Form to Slope-Intercept Form:
For ax + by + c = 0 with b ≠ 0:
by = -ax - c ⇒ y = (-(a / b))x + (-(c / b))
Therefore, the slope is m = -a/b and the y-intercept is d = -c/b (crossing at (0, -c/b)).
Example: 5x + y = 3 ⇒ y = -5x + 3. Slope m = -5 (down 5 units for every 1 unit right), y-intercept (0, 3).

The Four Geometric Cases of Slope

Positive Slope (m > 0)Slants upwards from left to right. As x increases, y increases (e.g. y = 2x + 1).
Negative Slope (m < 0)Slants downwards from left to right. As x increases, y decreases (e.g. y = -3x + 4).
Zero Slope (m = 0)Horizontal line parallel to the x-axis. y is constant (e.g. y = 5).
Undefined SlopeVertical line parallel to the y-axis (x = 2). Run is 0, division by zero is undefined!

5Pairs of Linear Equations & Real-World Modeling

When two unknown quantities are subject to two simultaneous conditions, we obtain a pair of linear equations in two variables (a system of linear equations):

a_1 x + b_1 y + c_1 = 0 and a_2 x + b_2 y + c_2 = 0
  • Rakesh's Puzzle (p. 104): Two numbers have sum 25 and difference 11:
    x + y = 25 and x - y = 11 ⇒ x = 18, y = 7.
  • Science Exhibition Tickets (p. 104): Group A pays ₹600 for 2 adult and 3 child tickets; Group B pays ₹700 for 3 adult and 2 child tickets:
    2x + 3y = 600 and 3x + 2y = 700.

6Algebraic Methods: Substitution & Elimination

To solve a pair of linear equations, we reduce the two equations in two variables to a single linear equation in one variable.

Method 1: Substitution Method

Solved Example 7 (Page 106–107) — Substitution: Solve 7x - 15y = 2 … (1) and x + 2y = 3 … (2):
  1. Step 1: From equation (2), express x in terms of y: x = 3 - 2y … (3).
  2. Step 2: Substitute (3) into equation (1):
    7(3 - 2y) - 15y = 2 ⇒ 21 - 14y - 15y = 2 ⇒ -29y = -19 ⇒ y = 19/29.
  3. Step 3: Substitute y back into (3):
    x = 3 - 2((19 / 29)) = (87 - 38 / 29) = 49/29.
Solved Example 8 (Page 107) — Triangle Angles: Two angles of a triangle are x^° and y^° with y = 4x, and the third angle is 50^°:
x + y + 50 = 180 ⇒ x + 4x = 130 ⇒ 5x = 130 ⇒ x = 26^°, y = 104^°.

Method 2: Elimination Method

Solved Example 9 (Page 108) — Monthly Incomes & Expenditures: Incomes ratio is 9 : 7 (9x, 7x) and expenditures ratio is 4 : 3 (4y, 3y). Each saves ₹2000 per month:
  1. 9x - 4y = 2000 … (1) and 7x - 3y = 2000 … (2).
  2. Multiply (1) by 3 and (2) by 4 to equalize coefficients of y:
    27x - 12y = 6000 … (3)
    28x - 12y = 8000 … (4)
  3. Subtract (3) from (4): (28x - 27x) - (-12y - (-12y)) = 8000 - 6000 ⇒ x = 2000.
  4. Substitute x = 2000 into (1): 9(2000) - 4y = 2000 ⇒ 4y = 16000 ⇒ y = 4000.
  5. Answer: Monthly incomes are 9(2000) = ₹18,000 and 7(2000) = ₹14,000.
Solved Example 10 (Page 109) — Reversible Two-Digit Number: Sum of a two-digit number and its reverse is 66, and digits differ by 2:
  1. Let number be 10x + y. Reversed number is 10y + x.
  2. (10x + y) + (10y + x) = 66 ⇒ 11(x + y) = 66 ⇒ x + y = 6 … (1).
  3. Digits differ by 2: x - y = 2 … (2).
  4. Adding (1) and (2): 2x = 8 ⇒ x = 4. Then y = 2.
  5. Answer: The number is 42 (or 24).

Ratios: a_1/a_2 = 1/2, b_1/b_2 = 2/4 = 1/2, c_1/c_2 = -4/-12 = 1/3.

Solved Example 13 (Page 115–116) — Coincident Lines (Infinitely Many Solutions): Romila buys 2 erasers and 3 sheets for ₹9 (2x + 3y = 9); Sonali buys 4 erasers and 6 sheets for ₹18 (4x + 6y = 18).
Ratios: a_1/a_2 = 2/4 = 1/2, b_1/b_2 = 3/6 = 1/2, c_1/c_2 = -9/-18 = 1/2.
The graphs coincide as the exact same line. Infinitely many solutions.

Mathematical Proof 2: Two Lines with Equal Slopes are Parallel

  1. Let two lines be L_1: y = mx + d_1 and L_2: y = mx + d_2 with d_1 ≠ d_2.
  2. Suppose for contradiction that L_1 and L_2 intersect at point (x_0, y_0).
  3. Then y_0 = mx_0 + d_1 and y_0 = mx_0 + d_2 ⇒ mx_0 + d_1 = mx_0 + d_2.
  4. Subtracting mx_0 from both sides gives d_1 = d_2, which directly contradicts d_1 ≠ d_2!
  5. Therefore, no intersection point can exist. The lines are strictly parallel. Q.E.D.

9A Pinch of History & Mahāvīrāchārya's Problem

Solving systems of linear equations is one of mathematics’ oldest disciplines:

  • Babylonia (c. 2000 BCE): Cuneiform tablets show problems involving areas and sums of two unknown lengths.
  • Ancient China (c. 200 BCE): The classic Nine Chapters on the Mathematical Art (Jiuzhang Suanshu) devotes chapter 8, fangcheng (“rectangular arrays”), to solving linear systems using columns of counting rods on a board — an algorithm identical to Gaussian elimination, developed 1,800 years before Gauss!
  • India (c. 500–850 CE): Āryabhaṭa (499 CE) and Brahmagupta (628 CE) formulated systematic methods for linear systems in multiple unknowns.
Mahāvīrāchārya's Problem (c. 850 CE, Gaṇita Sāra Saṅgraha) — Exercise 13.5 Q7:

“The price of 9 citrons and 7 fragrant wood-apples taken together is 107; and the price of 7 citrons and 9 fragrant wood-apples taken together is 101. O mathematician, tell me quickly the price of each!”

  1. Equations: 9x + 7y = 107 … (1) and 7x + 9y = 101 … (2).
  2. Mahāvīrāchārya's Symmetric Shortcut: Notice that the coefficients of x and y are interchanged!
  3. Step 1 — Add both equations:
    16x + 16y = 208 ⇒ x + y = (208 / 16) = 13 … (3)
  4. Step 2 — Subtract equation (2) from (1):
    2x - 2y = 6 ⇒ x - y = 3 … (4)
  5. Step 3 — Add (3) and (4):
    2x = 16 ⇒ x = 8. Then y = 13 - 8 = 5.
  6. Answer: Each citron costs ₹8, and each fragrant wood-apple costs ₹5!

10Chapter Summary — Key Principles

  • ax + by + c = 0 (a, b not both zero) represents a straight line with infinitely many solutions (x, y).
  • The line cuts the axes at (0, -c/b) (y-intercept) and (-c/a, 0) (x-intercept).
  • Slope m = (y_2 - y_1 / x_2 - x_1) = -a/b. In y = mx + d, m is the slope and d is the y-intercept.
  • A system of two equations has:
    • A unique solution if a_1/a_2 ≠ b_1/b_2 (intersecting lines).
    • Infinitely many solutions if a_1/a_2 = b_1/b_2 = c_1/c_2 (coincident lines).
    • No solution if a_1/a_2 = b_1/b_2 ≠ c_1/c_2 (parallel lines).
  • Two algebraic methods — Substitution and Elimination — solve any solvable system directly.

Solutions, graphs, quadrants and equivalent equations.

1Verify if the ordered pair (4, 3) is a solution of 5x − 6y = 2. Explain your reasoning.
Answer / method
Step 1: Substitute x = 4 and y = 3 into 5x − 6y. Step 2: 5(4) − 6(3) = 20 − 18 = 2. Step 3: The result equals the right side, 2. Conclusion: (4, 3) is a solution.
2Find any two solutions for each equation: (i) 7x − 3y = 21. (ii) 2x + 3y = 5.
Answer / method
Step 1: For 7x − 3y = 21, choose x = 3. Then 21 − 3y = 21, so y = 0. One solution is (3, 0). Step 2: Choose x = 0. Then −3y = 21, so y = −7. Another solution is (0, −7). Step 3: For 2x + 3y = 5, choose x = 1. Then 2 + 3y = 5, so y = 1. One solution is (1, 1). Step 4: Choose x = 4. Then 8 + 3y = 5, so y = −1. Another solution is (4, −1). Step 5: Substitution verifies all four ordered pairs.
3In 2mx + 3y = 7 and 4x + ny = −10, m and n are unknown. If (2, −1) is the solution of both equations, find m and n.
Answer / method
Step 1: Substitute (2, −1) in 2mx + 3y = 7. Step 2: 2m(2) + 3(−1) = 7, so 4m − 3 = 7. Step 3: 4m = 10, hence m = 5/2. Step 4: Substitute (2, −1) in 4x + ny = −10. Step 5: 4(2) + n(−1) = −10, so 8 − n = −10. Step 6: n = 18.
4Find two solutions in different quadrants for each: (i) 5x + 3y = 7, (ii) 5x − 3y = 7, (iii) −5x + 3y = 7, (iv) −5x − 3y = 7. Identify the quadrants and verify by graphing.
Answer / method
Step 1: Choose convenient x-values and calculate y. Step 2: (i) 5x + 3y = 7. With x = 1, y = 2/3, which is in Quadrant I. With x = 2, y = −1, which is in Quadrant IV. Step 3: (ii) 5x − 3y = 7. With x = 1, y = −2/3, which is in Quadrant IV. With x = 2, y = 1, which is in Quadrant I. Step 4: (iii) −5x + 3y = 7. With x = −1, y = 2/3, which is in Quadrant II. With x = 1, y = 4, which is in Quadrant I. Step 5: (iv) −5x − 3y = 7. With x = −1, y = −2/3, which is in Quadrant III. With x = 1, y = −4, which is in Quadrant IV. Step 6: Plot each pair and join the two points. The resulting straight line verifies the equation.
5For the graph of 3x − 7y = 21, does C(2, 3) lie on the line? Does it satisfy the equation? Can a point not on the line satisfy the equation?
Answer / method
Step 1: Substitute C(2, 3) in 3x − 7y = 21. Step 2: 3(2) − 7(3) = 6 − 21 = −15. Step 3: Since −15 ≠ 21, C does not satisfy the equation and does not lie on the line. Conclusion: a point not on the graph cannot satisfy the equation, because the graph contains exactly all the solutions.
6State True or False and justify: (i) a linear equation in two variables has only one solution; (ii) its graph always passes through the origin; (iii) it can never have rational solutions; (iv) x = 3 is valid; (v) 2x + 3y = 7 has infinitely many solutions; (vi) (1, 2) solves 2x + 3y = 7.
Answer / method
Step 1: (i) False. Choose x freely and calculate y; normally infinitely many ordered pairs result. Step 2: (ii) False. The graph passes through (0, 0) only when the constant term is zero. Step 3: (iii) False. For example, 2x + 3y = 7 has the rational solution (2, 1). Step 4: (iv) True. x = 3 can be written as x + 0y − 3 = 0. Step 5: (v) True. One equation in two variables has infinitely many solutions when it is a valid linear equation. Step 6: (vi) False. 2(1) + 3(2) = 8, not 7.
7(i) Compare the solutions of 3x + 4y = 7 and 6x + 8y = 14. (ii) Show that ax + by = c and kax + kby = kc, where k ≠ 0, have the same solutions.
Answer / method
Step 1: 6x + 8y = 14 is exactly 2(3x + 4y = 7). Step 2: Multiplying an equation by a non-zero number does not change its solutions. Conclusion for (i): both equations have the same set of solutions. Step 3: If ax + by = c, multiply every term by k, where k ≠ 0. Step 4: The result is kax + kby = kc. Step 5: Dividing the second equation by k returns the first equation. Conclusion for (ii): the two equations have exactly the same solutions.

1Three ski hills have rises and runs: A: 60 m and 70 m; B: 60 m and 110 m; C: 80 m and 100 m. Rank them from least to greatest steepness.
