1. CPU Architecture & Execution 1. CPU वास्तुकला, घटक एवं रजिस्टर्स

ALU • CU • Registers
Core Internal CPU Elements CPU के मुख्य आंतरिक घटक
ALU (Arithmetic & Logic) CU (Control Unit / Traffic Cop) PC (Program Counter) IR (Instruction Register) AC (Accumulator) MAR & MDR (Memory Registers) Clock Speed (GHz / MHz)
Functional Operations & Machine Cycle कार्यात्मक संचालन एवं मशीन चक्र
  • Arithmetic Logic Unit (ALU): Performs fundamental arithmetic (+, -, *, /) and logical comparisons (AND, OR, NOT, =, <, >); results stored in Accumulator. अंकगणितीय एवं तार्किक इकाई (ALU): मूलभूत अंकगणित (+, -, *, /) तथा तार्किक तुलनाएं (AND, OR, NOT, =, <, >) निष्पादित करती है; परिणाम एक्युमुलेटर में जाते हैं।
  • Control Unit (CU - "Brain/Supervisor"): Directs the entire computer operation, fetches instructions, decodes opcodes, generates control signals, and manages timing. कंट्रोल यूनिट (CU - "कंप्यूटर का प्रबंधक"): कंप्यूटर के समस्त कार्यों का समन्वय करती है; निर्देशों को फेच करना, डिकोड करना तथा कंट्रोल सिग्नल जारी करना इसका कार्य है।
  • CPU Registers (Fastest Memory): High-speed temporary memory inside the CPU. Program Counter (PC): holds memory address of the NEXT instruction to execute. Instruction Register (IR): holds current instruction being decoded. MAR: holds memory address to read/write. MDR/MBR: holds actual data word read from/written to memory. CPU रजिस्टर्स (तीव्रतम मेमोरी): CPU के भीतर अति-उच्च गति की अस्थायी मेमोरी। PC: निष्पादित होने वाले अगले निर्देश का पता रखता है। IR: वर्तमान निर्देश को रखता है। MAR: मेमोरी पता तथा MDR: मेमोरी से पढ़ा या लिखा जाने वाला वास्तविक डेटा रखता है।
  • Machine Cycle (Instruction Cycle): Fetch (from RAM to CPU) -> Decode (by CU) -> Execute (by ALU) -> Store (result written to register/RAM). Controlled by system clock. मशीन चक्र (निर्देश चक्र): फेच (मेमोरी से निर्देश लाना) -> डिकोड (CU द्वारा अर्थ समझना) -> एक्ज़ीक्यूट (ALU द्वारा निष्पादन) -> स्टोर (परिणाम संचयन)।
UPSSSC Top Note: Program Counter (PC) stores the address of the NEXT instruction to be executed; registers are the fastest memory in a computer system! UPSSSC मुख्य बिंदु: प्रोग्राम काउंटर (PC) निष्पादित होने वाले अगले निर्देश का पता रखता है; कंप्यूटर में सबसे तेज गति वाली मेमोरी 'रजिस्टर्स' होती है!

2. Motherboard, Buses & Firmware 2. मदरबोर्ड, सिस्टम बस एवं फर्मवेयर

BIOS • UEFI • CMOS
Components & Bus Architecture प्रमुख घटक एवं बस वास्तुकला
Address Bus (Unidirectional) Data Bus (Bidirectional) Control Bus (Control & Timing) Northbridge (RAM & PCIe GPU) Southbridge (SATA, USB, Audio) BIOS / POST (Firmware) UEFI / GPT (Modern Standard) CMOS RAM (CR2032 Battery)
Key Operations & Standards प्रमुख प्रक्रियाएं एवं मानक
  • System Bus: Group of parallel electronic pathways. Address Bus: Unidirectional from CPU to memory/IO; bus width determines max memory capacity (e.g. 32-bit = 2^32 = 4 GB, 64-bit = 16 Exabytes). Data Bus: Bidirectional; width defines word length (32-bit, 64-bit). Control Bus: Coordinates read/write pulses and interrupts. सिस्टम बस: समानांतर विद्युत पथों का समूह। एड्रेस बस: CPU से मेमोरी की ओर एकदिशीय; चौड़ाई अधिकतम मेमोरी क्षमता तय करती है (32-बिट = 4 GB, 64-बिट = 16 EB)। डेटा बस: द्विदिशीय, डेटा ले जाती है। कंट्रोल बस: रीड/राइट व इंटरप्ट सिग्नल।
  • BIOS & POST: Basic Input/Output System stored in ROM/EEPROM; executes POST (Power-On Self-Test) upon boot to verify keyboard, RAM, and storage; invokes bootstrap loader to load OS kernel into RAM. BIOS एवं POST: ROM में स्थायी फर्मवेयर; कंप्यूटर ऑन होते ही POST (पावर-ऑन सेल्फ-टेस्ट) चलाकर हार्डवेयर जांचता है और बूटस्ट्रैप लोडर द्वारा OS को रैम में लोड कराता है।
  • BIOS vs UEFI: Legacy BIOS uses 16-bit real mode and MBR partition scheme (max 2 TB drive, max 4 primary partitions). Modern UEFI uses 32/64-bit code, graphical interface, Secure Boot, and GPT partition scheme (>2 TB drives, up to 128 partitions). BIOS बनाम UEFI: पुराना BIOS 16-बिट तथा MBR (अधिकतम 2 TB, 4 पार्टिशन) का उपयोग करता है। आधुनिक UEFI 64-बिट, सुरक्षित बूट (Secure Boot) तथा GPT (>2 TB, 128 पार्टिशन) सपोर्ट करता है।
  • CMOS Chip: Low-power volatile RAM powered by a coin-cell battery (CR2032) that keeps track of real-time clock (RTC), date, time, and custom hardware boot configuration when PC is powered off. CMOS चिप: CR2032 सेल बैटरी द्वारा संचालित वोलेटाइल रैम, जो कंप्यूटर बंद होने पर भी सिस्टम की तारीख, समय व बायोस सेटिंग्स को सुरक्षित रखती है।
UPSSSC Top Note: POST is performed by BIOS; Address Bus is unidirectional while Data Bus is bidirectional; CR2032 battery powers the CMOS chip. UPSSSC मुख्य बिंदु: POST परीक्षण BIOS द्वारा किया जाता है; एड्रेस बस एकदिशीय व डेटा बस द्विदिशीय होती है; CMOS चिप को CR2032 बैटरी से ऊर्जा मिलती है।

3. Primary Memory & Cache 3. प्राथमिक मेमोरी (रैम/रोम) एवं कैश

SRAM • DRAM • ROM
Memory Types & Classifications मेमोरी के प्रकार एवं श्रेणियां
RAM (Volatile Read/Write) SRAM (Flip-Flop / No Refresh) DRAM (Capacitor / Needs Refresh) Cache (L1, L2, L3) ROM (Non-Volatile Permanent) PROM / EPROM / EEPROM Flash Memory
Structural & Operational Contrasts संरचनात्मक एवं कार्यात्मक विभेद
  • RAM (Random Access Memory): Primary working memory of computer; volatile (loses data when power is turned off); allows both read and write operations directly to any memory cell in constant time. रैम (RAM): कंप्यूटर की मुख्य कार्यशील मेमोरी; वोलेटाइल (विद्युत जाते ही डेटा नष्ट); इसमें किसी भी सेल से समान समय में डेटा पढ़ा व लिखा जा सकता है।
  • SRAM vs DRAM: SRAM (Static RAM): Uses 4-6 transistors/flip-flops per bit; very fast (1-10 ns), does NOT require periodic electric refreshing, expensive; used for CPU Cache (L1, L2, L3). DRAM (Dynamic RAM): Uses 1 transistor + 1 capacitor per bit; charge leaks and REQUIRES periodic refreshing thousands of times per second; slower (50-70 ns), cheaper, high density; used for Main System RAM (DDR4, DDR5). SRAM बनाम DRAM: SRAM: फ्लिप-फ्लॉप पर आधारित, रीफ्रेश करने की आवश्यकता नहीं, अति-तीव्र, महंगी; CPU कैश में प्रयुक्त। DRAM: कैपेसिटर पर आधारित, लगातार रीफ्रेशिंग अनिवार्य, सस्ती, सघन; मुख्य सिस्टम रैम में प्रयुक्त (DDR4, DDR5)।
  • Cache Memory: Small, high-speed buffer located between CPU and RAM to bridge speed mismatch. L1 Cache (fastest, smallest, inside core), L2 Cache (larger, per-core), L3 Cache (shared across all cores). Principle of Locality: Temporal & Spatial. कैश मेमोरी: CPU और रैम के बीच गति असंतुलन दूर करने वाली तीव्र बफर मेमोरी। L1 (तीव्रतम, कोर के भीतर), L2 (प्रत्येक कोर हेतु), L3 (सभी कोर द्वारा साझा)। लोकैलिटी सिद्धांत पर कार्य।
  • ROM (Read Only Memory): Non-volatile permanent memory; retains data without power. Types: PROM: Programmable once using PROM burner. EPROM: Erased by Ultraviolet (UV) light exposure through quartz window. EEPROM: Erased and rewritten electrically byte-by-byte (used in modern flash BIOS chips). रोम (ROM): गैर-वाष्पशील (स्थायी) मेमोरी; बिजली जाने पर डेटा सुरक्षित रहता है। PROM: केवल एक बार प्रोग्राम करने योग्य। EPROM: पराबैंगनी (UV) किरणों द्वारा मिटाई जाने वाली। EEPROM: विद्युत पल्स द्वारा बाइट-दर-बाइट मिटाई और पुनर्लिखित होने वाली।
UPSSSC Top Note: DRAM requires periodic refreshing; SRAM does not; EPROM is erased by UV light; Cache memory sits directly between CPU and RAM! UPSSSC मुख्य बिंदु: DRAM को निरंतर रीफ्रेश करने की आवश्यकता होती है; EPROM को पराबैंगनी (UV) किरणों से मिटाया जाता है; कैश मेमोरी CPU और RAM के मध्य स्थित होती है!

4. Secondary & Tertiary Storage 4. द्वितीयक एवं बाह्य स्टोरेज उपकरण

HDD • SSD • Optical • Tape
Storage Media & Capacities स्टोरेज माध्यम एवं उनकी क्षमताएं
HDD (Magnetic Platter, RPM) SSD (NAND Flash, NVMe/SATA) CD-ROM (700 MB, Infrared 780nm) DVD (4.7 GB / 8.5 GB, Red 650nm) Blu-ray (25 GB / 50 GB, Blue 405nm) Floppy Disk (1.44 MB, 3.5-inch) Magnetic Tape (Sequential Access)
Key Mechanics & Speed Comparisons प्रमुख यांत्रिकी एवं गति तुलना
  • Hard Disk Drive (HDD): Magnetic storage using spinning platters coated with magnetic material. Data organized into concentric Tracks, divided into Sectors (512 bytes or 4KB Advanced Format), aligned vertically across platters as Cylinders. Speed measured in RPM (5400/7200 RPM); Access Time = Seek Time (head positioning) + Rotational Latency (platter spin) + Transfer Rate. हार्ड डिस्क ड्राइव (HDD): चुंबकीय स्टोरेज; डेटा संकेंद्रित ट्रैक्स (Tracks) एवं सेक्टर्स (Sectors - 512B/4KB) में विभाजित होता है; सभी प्लेटर्स के समान ट्रैक मिलकर सिलेंडर (Cylinder) बनाते हैं। स्पिंडल गति 5400/7200 RPM।
  • Solid-State Drive (SSD): Non-volatile NAND flash memory with no moving parts; shock resistant, silent, consumes less power. SATA SSD (max ~550 MB/s) vs NVMe M.2 PCIe SSD (up to 7000+ MB/s, directly connects to PCIe bus). सॉलिड-स्टेट ड्राइव (SSD): बिना किसी यांत्रिक गतिमान भाग वाली NAND फ्लैश मेमोरी; शांत, शॉक-प्रूफ व तीव्र। SATA SSD (~550 MB/s) की तुलना में NVMe M.2 SSD (7000+ MB/s) अत्यधिक तेज है।
  • Optical Storage Comparison: CD: 700 MB, 780 nm infrared laser. DVD: 4.7 GB (single-layer) / 8.5 GB (dual-layer), 650 nm red laser. Blu-ray Disc (BD): 25 GB (single-layer) / 50 GB (dual-layer) up to 100 GB (BD-XL), 405 nm blue-violet laser (shorter wavelength allows tighter pits). ऑप्टिकल स्टोरेज तुलना: CD: 700 MB (780 nm इंफ्रारेड लेजर)। DVD: 4.7 GB / 8.5 GB (650 nm लाल लेजर)। ब्लू-रे डिस्क: 25 GB / 50 GB (405 nm नीली-बैंगनी लेजर, छोटी तरंगदैर्ध्य से अधिक डेटा घनत्व)।
  • Direct vs Sequential Access: Magnetic Tape is Sequential Access (must wind past earlier records; ideal for low-cost enterprise archival). HDD, SSD, and Optical discs are Direct/Random Access (can jump directly to any address). प्रत्यक्ष बनाम क्रमिक एक्सेस: मैग्नेटिक टेप क्रमिक एक्सेस (Sequential Access) माध्यम है (डेटा तक पहुँचने हेतु आगे की टेप घुमानी पड़ती है; दीर्घकालिक बैकअप हेतु उपयोगी)। HDD और SSD डायरेक्ट/रैंडम एक्सेस माध्यम हैं।
UPSSSC Top Note: Standard 3.5-inch floppy capacity is 1.44 MB; standard CD capacity is 700 MB; standard single-layer DVD is 4.7 GB; Blu-ray uses 405 nm blue-violet laser! UPSSSC मुख्य बिंदु: 3.5 इंच फ्लॉपी डिस्क क्षमता 1.44 MB; CD की 700 MB; सिंगल-लेयर DVD की 4.7 GB; तथा ब्लू-रे में 405 nm नीली-बैंगनी लेजर प्रयुक्त होती है!

5. Software Classification & Translators 5. सॉफ्टवेयर वर्गीकरण एवं भाषा अनुवादक

System • App • Compilers
Software Categories & Utilities सॉफ्टवेयर की श्रेणियां एवं यूटिलिटीज
System Software (OS & Drivers) Application Software (End-User) Utility Software (Antivirus, Defrag) Assembler (Assembly to Machine) Compiler (Entire Code to Object) Interpreter (Line-by-Line Execution) Linker & Loader
Translator Mechanics & Differences अनुवादक प्रक्रिया एवं मुख्य अंतर
  • System vs Application Software: System Software manages computer hardware and system resources (OS, Device Drivers, Utilities). Application Software solves specific user tasks (MS Word, Excel, VLC player, Photoshop). सिस्टम बनाम एप्लिकेशन सॉफ्टवेयर: सिस्टम सॉफ्टवेयर हार्डवेयर और आंतरिक संसाधनों का प्रबंधन करता है (OS, ड्राइवर, यूटिलिटीज)। एप्लिकेशन सॉफ्टवेयर उपयोगकर्ता के विशिष्ट कार्य करता है (वर्ड, एक्सेल, ब्राउज़र)।
  • Assembler: Translates low-level Assembly Language mnemonic instructions (ADD, SUB, MOV) into machine code (binary 0 and 1). असेंबलर: निम्नस्तरीय असेंबली भाषा के निमोनिक कोड (ADD, MOV, SUB) को मशीनी भाषा (बाइनरी 0 व 1) में परिवर्तित करता है।
  • Compiler: Translates entire High-Level Language program at once into machine code (object module); creates standalone executable (.exe); execution is very fast; displays all syntax errors together at the end. Examples: C, C++, Rust. कंपाइलर: संपूर्ण उच्चस्तरीय प्रोग्राम का एक ही बार में मशीनी कोड (ऑब्जेक्ट कोड) में अनुवाद करता है; स्वतंत्र .exe फाइल बनाता है; तीव्र निष्पादन; अंत में सभी त्रुटियां एक साथ दिखाता है (C, C++)।
  • Interpreter: Translates and executes High-Level code line-by-line; stops immediately on encountering first error; slower execution; requires interpreter during every run. Examples: Python, JavaScript, Ruby. इंटरप्रेटर: उच्चस्तरीय प्रोग्राम का पंक्ति-दर-पंक्ति (लाइन-बाय-लाइन) अनुवाद व निष्पादन करता है; पहली त्रुटि पर रुक जाता है; निष्पादन धीमा; प्रत्येक बार अनुवादक की आवश्यकता (Python, JavaScript)।
  • Linker & Loader: Linker: Combines multiple compiled object files and external system libraries into a single executable (.exe). Loader: Loads the executable from secondary storage into main RAM and initializes CPU registers for execution. लिंकर एवं लोडर: लिंकर: विभिन्न कंपाइल किए गए ऑब्जेक्ट मॉड्यूल्स व लाइब्रेरी फाइलों को जोड़कर एक निष्पादन योग्य (.exe) फाइल बनाता है। लोडर: उस .exe फाइल को सेकेंडरी स्टोरेज से RAM में लोड कर निष्पादन शुरू कराता है।
UPSSSC Top Note: Compiler translates entire source code at once; Interpreter translates line-by-line; Linker combines object modules into executable; Loader puts program into RAM! UPSSSC मुख्य बिंदु: कंपाइलर पूरे प्रोग्राम को एक साथ अनुवादित करता है; इंटरप्रेटर लाइन-बाय-लाइन करता है; लिंकर ऑब्जेक्ट फाइलों को जोड़ता है तथा लोडर प्रोग्राम को RAM में लोड करता है!

6. Software Licensing & Ecosystem 6. सॉफ्टवेयर लाइसेंसिंग एवं कानूनी अधिकार

FOSS • Proprietary • Freeware
Licensing Models & Legal Types लाइसेंस मॉडल एवं विधिक प्रकार
Proprietary (Closed Source, Paid) Open Source (FOSS, Free Access) GNU GPL (Copyleft License) Freeware (Free Cost, Closed Code) Shareware (Trialware e.g. 30 days) Public Domain (No Copyright) Firmware (Hardcoded in ROM)
Licensing Details & Government Policies लाइसेंस विवरण एवं सरकारी नीतियां
  • Proprietary / Closed Source: Source code is protected under copyright and kept secret by vendor; user only buys a license to use the compiled software. Examples: Microsoft Windows, MS Office, Adobe Photoshop. प्रोप्राइटरी (क्लोज्ड सोर्स): स्रोत कोड (Source Code) गोपनीय व कॉपीराइट सुरक्षित होता है; उपयोगकर्ता केवल उपयोग का लाइसेंस खरीदता है। उदाहरण: Windows, MS Office, Photoshop।
  • Free and Open Source Software (FOSS): Source code is freely accessible, inspectable, modifiable, and redistributable. Initiated by Richard Stallman (GNU Project, 1983) and Linus Torvalds (Linux, 1991). Licenses: GNU GPL, MIT, Apache 2.0. 1. Computer Hardware Architecture: CPU, Motherboard & System Bus 1. कंप्यूटर हार्डवेयर वास्तुकला: सीपीयू, मदरबोर्ड एवं सिस्टम बस
  • Central Processing Unit (CPU / Microprocessor):
    • Termed the "Brain of the Computer". Responsible for fetching, decoding, executing, and storing instructions.
    • Arithmetic Logic Unit (ALU): Performs fundamental arithmetic (+, -, *, /) and logical decisions (AND, OR, NOT, comparisons >, <, =).
    • Control Unit (CU): The "Nerve Center / Traffic Cop" of the CPU; coordinates operations of all hardware units by issuing electrical timing signals; contains the Instruction Decoder.
    • Internal Registers: High-speed micro-storage locations inside the CPU:
      • Program Counter (PC): Holds the memory address of the next instruction to be fetched and executed.
      • Instruction Register (IR): Holds the current instruction being decoded and executed.
      • Memory Address Register (MAR): Holds the memory address currently being read from or written to.
      • Memory Buffer / Data Register (MBR / MDR): Holds the actual data contents read from or to be written to memory.
      • Accumulator (AC): Directly stores intermediate arithmetic and logical results.
    • Machine Cycle (मशीन चक्र): Four fundamental steps: Fetch → Decode → Execute → Store. Instruction Fetch + Decode = I-Time; Execute + Store = E-Time.
    • Clock Speed (क्लॉक स्पीड): Internal crystal oscillator generating pulses per second; measured in Megahertz (MHz) and Gigahertz (GHz) (1 GHz = 10^9 clock cycles/sec).     सेंट्रल प्रोसेसिंग यूनिट (CPU / माइक्रोप्रोसेसर):
    • इसे "कंप्यूटर का मस्तिष्क" कहा जाता है। यह निर्देशों को प्राप्त (Fetch), व्याख्या (Decode), निष्पादित (Execute) और सुरक्षित (Store) करता है।
    • अंकगणितीय एवं तार्किक इकाई (ALU): सभी गणितीय संक्रियाएं (+, -, *, /) एवं तार्किक निर्णय (AND, OR, NOT, तुलना >, <, =) करता है।
    • कंट्रोल यूनिट (CU): CPU का "तंत्रिका तंत्र / ट्रैफिक पुलिस"; हार्डवेयर घटकों के कार्यों का समन्वय करता है; इसमें इंस्ट्रक्शन डिकोडर होता है।
    • आंतरिक रजिस्टर्स (Internal Registers): सीपीयू के भीतर स्थित तीव्रतम मेमोरी सेल:
      • प्रोग्राम काउंटर (PC): निष्पादित होने वाले अगले निर्देश का मेमोरी पता सुरक्षित रखता है।
      • इंस्ट्रक्शन रजिस्टर (IR): वर्तमान में निष्पादित हो रहे निर्देश को रखता है।
      • मेमोरी एड्रेस रजिस्टर (MAR): उस मेमोरी लोकेशन का पता रखता है जिसे पढ़ा या लिखा जाना है।
      • मेमोरी डेटा रजिस्टर (MDR / MBR): मेमोरी से पढ़े गए अथवा लिखे जाने वाले वास्तविक डेटा को रखता है।
      • एक्युमुलेटर (AC): ALU के मध्यवर्ती गणना परिणामों को संग्रहीत करता है।
    • मशीन साइकिल (Machine Cycle): चार चरण: फेच (Fetch) → डिकोड (Decode) → एग्जीक्यूट (Execute) → स्टोर (Store)।
    • क्लॉक स्पीड: सीपीयू की गति का मापक; गीगाहर्ट्ज (GHz) और मेगाहर्ट्ज (MHz) में मापा जाता है।
  • Motherboard & Chipset Architecture:
    • Motherboard (Mainboard / System Board): Main printed circuit board (PCB) connecting all components.
    • Chipset: Micro-controller hub managing communication:
      • Northbridge (Host Bridge): Connects high-speed components: CPU, Main RAM, and high-speed PCIe graphics cards. (In modern CPUs, Northbridge functions are integrated directly into the processor die).
      • Southbridge (I/O Controller Hub): Connects slower peripheral buses: SATA drives, USB ports, BIOS, Audio, PCI slots, Ethernet.
    • BIOS & UEFI: BIOS (Basic Input/Output System) is firmware stored in ROM/EEPROM on motherboard; modern systems use UEFI (Unified Extensible Firmware Interface) supporting GUID Partition Table (GPT) and drives >2 TB.
    • POST (Power-On Self-Test): Diagnostic routine executed by BIOS upon startup to test hardware components (RAM, keyboard, drives). Single short beep indicates successful test.
    • CMOS (Complementary Metal-Oxide Semiconductor) & Battery: Volatile memory chip powered by a small coin-cell lithium battery (CR2032); retains system time, date, and hardware configuration when the computer is turned off.
    • Booting Process:
      • Cold Booting (Hard Boot): Turning on the computer from a completely powered-off state using the physical power switch.
      • Warm Booting (Soft Boot): Restarting an already running computer without turning off main power (via OS Restart or shortcut Ctrl + Alt + Delete).     मदरबोर्ड एवं चिपसेट वास्तुकला:
    • मदरबोर्ड (सिस्टम बोर्ड): कंप्यूटर का मुख्य सर्किट बोर्ड, जो सभी आंतरिक व बाह्य घटकों को आपस में जोड़ता है।
    • चिपसेट: डेटा प्रवाह का नियंत्रण केंद्र:
      • नॉर्थब्रिज (Northbridge): उच्च-गति घटकों (CPU, RAM, PCIe ग्राफिक्स कार्ड) के बीच तीव्र संचार संभालता है।
      • साउथब्रिज (Southbridge): अपेक्षाकृत धीमी परिधीय युक्तियों (SATA हार्ड ड्राइव, USB पोर्ट, ऑडियो, BIOS चिप) को जोड़ता है।
    • BIOS एवं UEFI: BIOS (बेसिक इनपुट/आउटपुट सिस्टम) मदरबोर्ड की ROM/EEPROM चिप में स्थायी रूप से लिखा फर्मवेयर है; आधुनिक सिस्टम UEFI का प्रयोग करते हैं जो 2 TB से बड़े डिस्क को बूट कर सकता है।
    • POST (पावर-ऑन सेल्फ-टेस्ट): कंप्यूटर ऑन होते ही BIOS द्वारा हार्डवेयर (रैम, कीबोर्ड आदि) की कार्यक्षमता जांचने वाला डायग्नोस्टिक परीक्षण।
    • CMOS एवं बैटरी: मदरबोर्ड पर CR2032 लिथियम सेल द्वारा संचालित छोटी मेमोरी, जो कंप्यूटर बंद रहने पर भी वास्तविक समय, दिनांक व BIOS सेटिंग्स सुरक्षित रखती है।
    • बूटिंग (Booting):
      • कोल्ड बूट (Cold Boot): पावर स्विच दबाकर पूर्णतः बंद कंप्यूटर को चालू करना।
      • वार्म बूट (Warm Boot): पहले से चालू कंप्यूटर को बिना मुख्य पावर काटे रीस्टार्ट करना (शॉर्टकट: Ctrl + Alt + Delete)।
  • System Bus (सिस्टम बस):
    • Data Bus (द्विदिशी / Bidirectional): Transfers actual binary data between CPU, memory, and devices. Bus width (e.g., 32-bit, 64-bit) determines data throughput per cycle.
    • Address Bus (एकदिशी / Unidirectional): Carries memory addresses generated solely by the CPU to identify target locations. A 32-bit address bus can access 2^32 bytes = 4 Gigabytes (GB) of RAM. A 64-bit bus can access 16 Exabytes.
    • Control Bus (नियंत्रण बस): Carries read/write, interrupt, acknowledge, and synchronization clock signals.     सिस्टम बस (System Bus):
    • डेटा बस (द्विदिशी): सीपीयू, मेमोरी और इनपुट/आउटपुट के बीच वास्तविक डेटा का आदान-प्रदान करती है (चौड़ाई: 32-बिट या 64-बिट)।
    • एड्रेस बस (एकदिशी): केवल सीपीयू द्वारा उत्पन्न मेमोरी पते को मेमोरी या पोर्ट्स तक ले जाती है (32-बिट एड्रेस बस अधिकतम 4 GB रैम को एड्रेस कर सकती है)।
    • कंट्रोल बस: रीड, राइट, इंटरप्ट एवं क्लॉक सिग्नल प्रसारित करती है।
2. Memory Hierarchy: Registers, Cache, RAM, ROM & Secondary Storage 2. मेमोरी पदानुक्रम: रजिस्टर्स, कैश, रैम, रोम एवं द्वितीयक स्टोरेज
  • Memory Hierarchy Principles:
    • As we move from top (Registers) to bottom (Secondary Storage): Speed decreases, Capacity increases, and Cost per bit decreases.
    • Hierarchy Order: CPU Registers > Cache Memory (L1 > L2 > L3) > Primary RAM > SSD > HDD > Optical / Tape Storage.     मेमोरी पदानुक्रम के नियम:
    • शीर्ष (रजिस्टर) से तल (सेकेंडरी स्टोरेज) की ओर जाने पर: गति घटती है, भंडारण क्षमता बढ़ती है, तथा प्रति बिट लागत घटती है।
    • गति का घटता क्रम: रजिस्टर्स > कैश मेमोरी (L1 > L2 > L3) > प्राथमिक रैम (RAM) > सॉलिड स्टेट ड्राइव (SSD) > हार्ड डिस्क (HDD) > ऑप्टिकल डिस्क/टेप।
  • Primary / Main Memory (प्राथमिक मेमोरी):
    • Random Access Memory (RAM): Volatile (अस्थायी); loses all data immediately when power is turned off; read/write accessible.
      • SRAM (Static RAM): Uses 4 to 6 flip-flop transistors per cell; faster, requires no periodic refreshing; highly expensive; used in Cache Memory.
      • DRAM (Dynamic RAM): Uses 1 transistor and 1 capacitor per cell; capacitor leaks charge and requires continuous electrical refreshing thousands of times per second; cheaper, high density; used in Main System RAM (DDR4, DDR5).
    • Read Only Memory (ROM): Non-Volatile (स्थायी); retains firmware/BIOS instructions even when power is turned off; primarily read-only.
      • PROM (Programmable ROM): Manufactured blank; can be programmed by the user only once using a PROM burner (fuse burning).
      • EPROM (Erasable Programmable ROM): Can be erased by exposing the quartz window to intense Ultraviolet (UV) light for 20-30 minutes, then reprogrammed.
      • EEPROM (Electrically Erasable Programmable ROM): Can be erased and rewritten electrically byte-by-byte without removing it from the motherboard; foundation of modern Flash Memory.     प्राथमिक / मुख्य मेमोरी (Primary Memory):
    • रैम (RAM - रैंडम एक्सेस मेमोरी): परिवर्तनशील / अस्थायी (Volatile); बिजली जाते ही सारा डेटा नष्ट हो जाता है; पढ़ने व लिखने दोनों योग्य।
      • SRAM (स्टैटिक रैम): फ्लिप-फ्लॉप ट्रांजिस्टरों से निर्मित; अत्यधिक तीव्र, इसे बार-बार रिफ्रेश करने की आवश्यकता नहीं होती; कैश मेमोरी में प्रयुक्त।
      • DRAM (डायनामिक रैम): कैपेसिटर व ट्रांजिस्टर पर आधारित; कैपेसिटर डिस्चार्ज होता है अतः इसे प्रति सेकंड हजारों बार रिफ्रेश (Refresh) करना पड़ता है; मुख्य कंप्यूटर रैम में प्रयुक्त।
    • रोम (ROM - रीड ओनली मेमोरी): अपरिवर्तनशील / स्थायी (Non-Volatile); बिजली कटने पर भी डेटा सुरक्षित रहता है; BIOS प्रोग्राम रखने हेतु प्रयुक्त।
      • PROM: केवल एक बार प्रोग्राम किया जा सकता है।
      • EPROM: पराबैंगनी किरणों (UV Light) के संपर्क में रखकर डेटा मिटाया और पुनः लिखा जा सकता है।
      • EEPROM: विद्युत पल्स द्वारा बाइट-दर-बाइट मिटाया और पुनः लिखा जा सकता है; पेन ड्राइव एवं फ्लैश मेमोरी का आधार।
  • Cache Memory & Virtual Memory:
    • Cache Memory: Extremely high-speed buffer memory placed between CPU and Main RAM to bridge the speed mismatch; holds frequently and recently used instructions.
      • L1 Cache: Smallest (32-128 KB), fastest, built directly into the CPU core.
      • L2 Cache: Medium size (256 KB - 1 MB), dedicated to each core.
      • L3 Cache: Largest (8 - 64+ MB), shared among all CPU cores.
    • Virtual Memory: An OS memory management illusion where a section of Secondary Storage (HDD/SSD) is utilized as an extension of physical RAM. Managed via Paging (fixed-size blocks). When requested data is missing in physical RAM, a Page Fault occurs, causing the OS to swap pages between RAM and disk.     कैश मेमोरी एवं वर्चुअल मेमोरी:
    • कैश मेमोरी: सीपीयू और मुख्य रैम के बीच गति के अंतर को पाटने हेतु प्रयुक्त तीव्रतम बफर मेमोरी; बार-बार प्रयुक्त निर्देशों को रखती है। L1 (कोर में), L2 (प्रति कोर), और L3 (साझा) कैश।
    • वर्चुअल मेमोरी (Virtual Memory): ऑपरेटिंग सिस्टम की एक तकनीक जिसके द्वारा हार्ड डिस्क या एसएसडी के एक भाग को अस्थायी रैम की तरह प्रयुक्त किया जाता है, जिससे भौतिक रैम से बड़े प्रोग्राम भी चल सकते हैं। इसे पेजिंग (Paging) द्वारा प्रबंधित किया जाता है; जब मांगा गया पेज रैम में नहीं होता, तो उसे पेज फॉल्ट (Page Fault) कहते हैं।
  • Secondary Storage Technologies:
    • Magnetic Storage: Hard Disk Drive (HDD - tracks, sectors, cylinders, read/write head, speed measured in RPM: 5400/7200 RPM), Magnetic Tape (sequential access).
    • Optical Storage: Read/written using laser beams:
      • Compact Disc (CD): 700 MB capacity (Red laser 780 nm).
      • Digital Versatile Disc (DVD): 4.7 GB (single-layer) to 8.5 GB (dual-layer) (Red laser 650 nm).
      • Blu-ray Disc (BD): 25 GB (single-layer) to 50 GB (dual-layer) (Blue-violet laser 405 nm).
    • Solid State Storage: Solid State Drive (SSD), USB Flash Drive, MicroSD cards (use NAND Flash EEPROM memory; no moving mechanical parts, shock resistant, 5-10x faster than HDD).     द्वितीयक स्टोरेज प्रौद्योगिकियां:
    • मैग्नेटिक स्टोरेज: हार्ड डिस्क ड्राइव (HDD - ट्रैक्स, सेक्टर्स और सिलिंडर्स में विभाजित; घूर्णन गति 5400/7200 RPM में मापी जाती है), मैग्नेटिक टेप (सीक्वेंशियल एक्सेस)।
    • ऑप्टिकल स्टोरेज (लेजर आधारित):
      • सीडी (CD): 700 MB क्षमता (लाल लेजर 780 nm)।
      • डीवीडी (DVD): 4.7 GB (सिंगल लेयर) से 8.5 GB (ड्यूल लेयर) (लाल लेजर 650 nm)।
      • ब्लू-रे डिस्क (Blu-ray): 25 GB से 50 GB क्षमता (नीली-बैंगनी लेजर 405 nm)।
    • सॉलिड स्टेट स्टोरेज (SSD / पेन ड्राइव): NAND फ्लैश मेमोरी आधारित; कोई चलायमान यांत्रिक पुर्जा नहीं होता, अत्यधिक तीव्र और टिकाऊ।
3. Software Classification: System, Application, Utility & Licensing 3. सॉफ्टवेयर वर्गीकरण: सिस्टम, एप्लीकेशन, यूटिलिटी एवं लाइसेंसिंग
  • 1. System Software (सिस्टम सॉफ्टवेयर):
    • Low-level software that manages computer hardware, resources, and provides a platform for application software.
    • Operating System (OS): Resource manager (CPU, memory, files, I/O); e.g., Windows, Linux, macOS, Android.
    • Device Drivers: Specialized software modules that enable the OS to communicate with physical peripheral hardware (printer drivers, graphics drivers).
    • Language Translators: Compilers, Interpreters, Assemblers.
    • Linker & Loader: System utilities essential for program execution.     1. सिस्टम सॉफ्टवेयर:
    • कंप्यूटर के हार्डवेयर और आंतरिक संसाधनों का प्रबंधन करने वाला तथा एप्लीकेशन सॉफ्टवेयर को मंच प्रदान करने वाला सॉफ्टवेयर।
    • ऑपरेटिंग सिस्टम (OS): विंडोज, लिनक्स, यूनिक्स, मैकओएस, एंड्रॉइड।

4. Language Translators: Assembler, Compiler, Interpreter, Linker & Loader 4. भाषा अनुवादक: असेंबलर, कंपाइलर, इंटरप्रेटर, लिंकर एवं लोडर
  • Assembler (असेंबलर):
    • System software that translates low-level Assembly Language mnemonic instructions (such as MOV, ADD, SUB, JMP) directly into binary Machine Code (0 and 1).     असेंबलर (Assembler):
    • वह भाषा अनुवादक जो निम्न-स्तरीय असेंबली भाषा के निमोनिक कोड (जैसे ADD, SUB, MOV) को सीधे बाइनरी मशीन भाषा (0 और 1) में परिवर्तित करता है।
  • Compiler (कंपाइलर):
    • Translates the entire source program written in High-Level Language (HLL) into target Machine/Object code (.obj) all at once in a single pass.
    • Detects syntax errors and displays a complete list of errors after scanning the whole file.
    • Execution speed of compiled code is extremely fast. Languages: C, C++, COBOL, Pascal, Go, Rust.     कंपाइलर (Compiler):
    • उच्च-स्तरीय भाषा (HLL) में लिखे संपूर्ण प्रोग्राम को एक ही बार में मशीन / ऑब्जेक्ट कोड में अनुवादित करता है।
    • संपूर्ण प्रोग्राम को पढ़ने के पश्चात सभी सिंटैक्स त्रुटियों की सूची एक साथ प्रदर्शित करता है।
    • प्रोग्राम का निष्पादन अत्यंत तीव्र होता है। उदाहरण: C, C++, फोरट्रान।
  • Interpreter (इंटरप्रेटर):
    • Translates and executes high-level source code line-by-line sequentially.
    • If an error occurs on any line, execution immediately halts, making debugging very easy.
    • Does NOT generate a separate standalone object file (.obj); execution is slower as translation repeats each run. Languages: Python, JavaScript, Ruby, PHP, BASIC.     इंटरप्रेटर (Interpreter):
    • उच्च-स्तरीय भाषा के सोर्स कोड को एक-एक पंक्ति करके (लाइन-बाय-लाइन) पढ़ता और तुरंत निष्पादित करता है।
    • किसी पंक्ति में त्रुटि मिलते ही निष्पादन तुरंत रुक जाता है, जिससे डिबगिंग सरल होती है।
    • यह कोई स्थायी ऑब्जेक्ट कोड फाइल नहीं बनाता; गति अपेक्षाकृत धीमी होती है। उदाहरण: पायथन, जावास्क्रिप्ट, बेसिक।
  • Linker and Loader (लिंकर एवं लोडर):
    • Linker (लिंकर): Takes one or more object code files (.obj) generated by compiler/assembler, links required system library functions, and combines them into a single executable file (.exe in Windows).
    • Loader (लोडर): System utility that copies the executable program from secondary storage (HDD/SSD) into main RAM, allocates memory addresses, and hands over control to the CPU for execution.     लिंकर एवं लोडर (Linker & Loader):
    • लिंकर: कंपाइलर द्वारा निर्मित विभिन्न ऑब्जेक्ट फाइलों (.obj) तथा सिस्टम लाइब्रेरी कोड को आपस में जोड़कर एक स्वतंत्र निष्पादन योग्य फाइल (.exe) बनाता है।
    • लोडर: निष्पादन योग्य प्रोग्राम को सेकेंडरी डिस्क से उठाकर मुख्य मेमोरी (RAM) में लोड करता है और सीपीयू को निष्पादन हेतु सौंपता है।
