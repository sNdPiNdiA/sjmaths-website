1. IPv4 Architecture & Classes 1. IPv4 संरचना एवं 5 वर्ग (Classes)

32-Bit • 4 Octets • 4.3 Billion
IPv4 Classes & Ranges IPv4 के वर्ग एवं उनकी रेंज
32-Bit Address (4 Octets, Dotted Decimal) Class A: 1 – 126 (Mask 255.0.0.0, Very Large) Loopback: 127.0.0.1 (Internal Self-Test) Class B: 128 – 191 (Mask 255.255.0.0, Medium) Class C: 192 – 223 (Mask 255.255.255.0, Small) Class D: 224 – 239 (Multicast Groups) Class E: 240 – 255 (Experimental/Research)
Class Breakdown & Octet Mechanics वर्ग विभाजन एवं ऑक्टेट कार्यप्रणाली
  • IPv4 Address Structure: 32-bit binary number expressed as 4 decimal octets separated by dots (0-255 each, e.g. 192.168.1.1). Total theoretical address space: $2^{32} pprox 4,294,967,296$ (~4.29 billion addresses). IPv4 संरचना: 32-बिट बाइनरी संख्या जिसे 4 दशमलव ऑक्टेट्स में बिंदुओं द्वारा लिखा जाता है (0 से 255 प्रत्येक, उदा. 192.168.1.1)। कुल सैद्धांतिक क्षमता: $2^{32} pprox 4.29$ अरब पते।
  • Classful IP Allocation: Class A (1-126): Leading bit `0`; 126 networks, 16.7 million hosts each. Loopback (127.x.x.x): 127.0.0.1 reserved for localhost internal diagnostics. Class B (128-191): Leading bits `10`; 65,534 hosts each. Class C (192-223): Leading bits `110`; 254 hosts each. Class D (224-239): Multicasting (no subnet mask). Class E (240-255): Research/Experimental. वर्गवार विभाजन: क्लास A (1-126): अति विशाल नेटवर्क। लूपबैक (127.0.0.1): कंप्यूटर की स्वयं की जांच हेतु आरक्षित। क्लास B (128-191): मध्यम नेटवर्क (65,534 होस्ट)। क्लास C (192-223): छोटे नेटवर्क (254 होस्ट)। क्लास D (224-239): मल्टीकास्टिंग। क्लास E (240-255): अनुसंधान हेतु।
UPSSSC Top Note: IPv4 has 32 bits divided into 4 octets; Class D is reserved for Multicasting; 127.0.0.1 is the Loopback/localhost address! UPSSSC मुख्य बिंदु: IPv4 में 32 बिट्स होते हैं जो 4 ऑक्टेट्स में बंटे होते हैं; क्लास D 'मल्टीकास्टिंग' हेतु आरक्षित है; 127.0.0.1 लूपबैक (Localhost) पता है!

2. Private IPs, Public IPs & NAT 2. प्राइवेट IP, पब्लिक IP एवं NAT प्रणाली

RFC 1918 • 192.168.x.x • NAT
Private Ranges (RFC 1918) प्राइवेट IP रेंज (RFC 1918)
Class A Private: 10.0.0.0 – 10.255.255.255 (/8) Class B Private: 172.16.0.0 – 172.31.255.255 (/12) Class C Private: 192.168.0.0 – 192.168.255.255 (/16) APIPA Range: 169.254.0.0 – 169.254.255.255 (/16) NAT: Network Address Translation
Public vs Private Mechanics & Address Translation पब्लिक बनाम प्राइवेट कार्यप्रणाली एवं NAT
  • Public vs Private IP Addresses: Public IPs: Globally unique, assigned by ISP/IANA, directly routable across the worldwide Internet. Private IPs (RFC 1918): Reserved for internal local home/office LANs; non-routable on the public Internet; reusable across billions of private networks without conflict. पब्लिक बनाम प्राइवेट IP: पब्लिक IP: विश्व में अद्वितीय, ISP द्वारा प्रदत्त, इंटरनेट पर सीधे खोजने योग्य। प्राइवेट IP (RFC 1918): घरेलू व कार्यालयी LAN हेतु आरक्षित; इंटरनेट पर सीधे नहीं जा सकते; अरबों नेटवर्कों में पुनः उपयोग संभव।
  • Network Address Translation (NAT): Router technology that maps hundreds of internal private IP devices onto a single external public IP using unique port numbers (Port Address Translation / PAT), conserving scarce IPv4 addresses. नेटवर्क एड्रेस ट्रांसलेशन (NAT): घर के दर्जनों उपकरणों के प्राइवेट IP पतों को राउटर पर केवल एक पब्लिक IP पते में बदलता है, जिससे करोड़ों IPv4 पतों की बचत होती है।
  • APIPA (Automatic Private IP Addressing): Automatically self-assigned by Windows client (169.254.x.x) when DHCP server fails to respond, allowing local subnet communication without Internet access. APIPA (169.254.x.x): जब कंप्यूटर को नेटवर्क पर DHCP सर्वर से IP नहीं मिल पाता, तो विंडोज स्वतः 169.254.x.x रेंज का IP चुन लेता है।
UPSSSC Top Note: 192.168.x.x and 10.x.x.x are Private IP addresses; APIPA assigns 169.254.x.x when DHCP is unavailable; NAT maps private IPs to a public IP! UPSSSC मुख्य बिंदु: 192.168.x.x व 10.x.x.x प्राइवेट IP पते हैं; DHCP न मिलने पर APIPA द्वारा 169.254.x.x मिलता है; NAT प्राइवेट को पब्लिक IP में बदलता है!

3. CIDR & Subnetting Math 3. CIDR सबनेटिंग एवं होस्ट गणना

Slash /24 • 2^h - 2 Formula
CIDR Prefixes & Usable Hosts CIDR प्रीफिक्स एवं प्रयोग योग्य होस्ट
CIDR (Classless Inter-Domain Routing, 1993) /24 Prefix: 254 Hosts (Mask 255.255.255.0) /25 Prefix: 126 Hosts (Mask 255.255.255.128) /26 Prefix: 62 Hosts (Mask 255.255.255.192) /28 Prefix: 14 Hosts (Mask 255.255.255.240) /30 Prefix: 2 Hosts (Point-to-Point Routers) Formula: 2^h - 2 Usable Hosts
Subnet Mask Logic & Host Calculation Formula सबनेट मास्क तर्क एवं होस्ट गणना सूत्र
  • CIDR Notation (RFC 1519, 1993): Replaced rigid classful boundaries with variable prefix length notation (e.g. 192.168.1.0/24 where /24 specifies that the first 24 bits are Network portion, leaving 8 bits for Hosts). CIDR पद्धति (1993): क्लास आधारित सीमाओं को समाप्त कर स्लैश नोटेशन (उदा. /24) दिया, जहाँ /24 का अर्थ है कि पहले 24 बिट्स नेटवर्क के हैं और शेष 8 बिट्स होस्ट के।
  • Mathematical Host Formula ($2^h - 2$): In any subnet with $h$ host bits, the total usable host IP addresses is strictly $2^h - 2$. Two addresses are deducted because: 1. First address (all host bits 0) is the Network ID. 2. Last address (all host bits 1) is the Broadcast Address. Example for /24: $2^8 - 2 = 256 - 2 = 254$ usable hosts. होस्ट गणना का सूत्र ($2^h - 2$): $h$ होस्ट बिट्स वाले सबनेट में कुल प्रयोग योग्य कंप्यूटरों की संख्या $2^h - 2$ होती है। 2 घटाने का कारण: पहला पता (सभी 0) = नेटवर्क ID; अंतिम पता (सभी 1) = ब्रॉडकास्ट पता। /24 हेतु: $2^8 - 2 = 254$ होस्ट।
UPSSSC Top Note: In a /24 subnet, total usable host addresses is 254 (formula: 2^h - 2); the first address is Network ID and the last address is Broadcast ID! UPSSSC मुख्य बिंदु: /24 सबनेट में प्रयोग योग्य होस्ट की संख्या 254 होती है ($2^h - 2$ सूत्र); पहला पता नेटवर्क ID और अंतिम पता ब्रॉडकास्ट ID होता है!

4. IPv6 Architecture & Notation 4. IPv6 वास्तुकला एवं हेक्साडेसिमल संकेतन

128-Bit • 8 Quartets • 3.4x10^38
IPv6 Specs & Compression Rules IPv6 विनिर्देश एवं संपीड़न नियम
128-Bit Length (4x Longer than IPv4) 8 Hex Quartets (Colon Separated) 3.4 x 10^38 Addresses (Undecillion) Omit Leading Zeros (:0042: -> :42:) Double Colon (::) (Compress Zeros Once) Loopback: ::1 (IPv6 Localhost) Built-in IPsec (Network Layer Security)
IPv6 Advantages & Zero Compression IPv6 के लाभ एवं शून्य संपीड़न के नियम
  • IPv6 Specifications: 128-bit address represented as 8 quartets of 4 hexadecimal digits separated by colons (e.g. 2001:0db8:85a3:0000:0000:8a2e:0370:7334). Total addresses = $2^{128} pprox 3.4 imes 10^{38}$. Solves IPv4 exhaustion forever. IPv6 विनिर्देश: 128-बिट पता जो 8 हेक्साडेसिमल खंडों में कोलन (:) द्वारा अलग किया जाता है (उदा. 2001:0db8:...)। कुल पते = $2^{128} pprox 3.4 imes 10^{38}$। IPv4 की कमी को सदा हेतु समाप्त करता है।
  • Compression Rules: Rule 1: Leading zeros in any quartet can be omitted (:0db8: becomes :db8:). Rule 2: One contiguous run of consecutive all-zero quartets can be replaced by double colon :: (e.g. 2001:db8::8a2e:370:7334). :: can appear only ONCE in an address! संपीड़न (छोटा करने) के नियम: नियम 1: प्रत्येक खंड के शुरुआती शून्य हटाए जा सकते हैं (:0042: का :42:)। नियम 2: लगातार शून्य वाले खंडों को डबल कोलन :: द्वारा केवल एक बार संक्षिप्त किया जा सकता है।
  • Architectural Advantages: Eliminates need for NAT, provides native end-to-end IPsec encryption, simplified fixed 40-byte base header, eliminates broadcasts (uses multicast/anycast), and supports Stateless Address Autoconfiguration (SLAAC). वास्तुकला लाभ: NAT की आवश्यकता समाप्त, इन-बिल्ट IPsec सुरक्षा, निश्चित 40-बाइट हेडर, ब्रॉडकास्ट के स्थान पर मल्टीकास्ट व एनीकास्ट, तथा स्वतः कॉन्फ़िगरेशन (SLAAC)।
UPSSSC Top Note: IPv6 has 128 bits (16 bytes); loopback address in IPv6 is ::1; double colon (::) can only be used once in an IPv6 address! UPSSSC मुख्य बिंदु: IPv6 में 128 बिट्स (16 बाइट्स) होते हैं; IPv6 में लूपबैक पता '::1' है; डबल कोलन (::) का प्रयोग पते में केवल एक बार हो सकता है!

5. Supporting Network Protocols 5. सहायक नेटवर्क प्रोटोकॉल: DHCP, DNS, ARP

DORA • DNS Port 53 • ARP MAC
Protocols & Port Numbers प्रोटोकॉल एवं पोर्ट नंबर
DHCP (DORA Process, UDP 67/68) DNS (Domain to IP, Port 53) ARP (Logical IP -> Physical MAC) RARP (Physical MAC -> Logical IP) ICMP (Ping & Traceroute Diagnostics)
Protocol Mechanics: DORA & Name Resolution प्रोटोकॉल कार्यप्रणाली: DORA एवं नाम समाधान
  • DHCP & DORA Process: Dynamic Host Configuration Protocol automatically assigns IP address, subnet mask, default gateway, and DNS servers to client devices. 4-Step DORA Handshake: Discover (broadcast) -> Offer (from server) -> Request (from client) -> Acknowledge (confirmation). Operates over UDP ports 67 (server) and 68 (client). DHCP एवं DORA प्रक्रिया: कंप्यूटर को स्वतः IP पता देने वाली सेवा। DORA के 4 चरण: Discover (खोज) -> Offer (प्रस्ताव) -> Request (अनुरोध) -> Acknowledge (स्वीकृति)। UDP पोर्ट 67 व 68।
  • DNS (Domain Name System, Port 53): Known as the "Phonebook of the Internet" (Paul Mockapetris, 1983). Translates user-friendly domain names (e.g. upsssc.gov.in) into numerical IP addresses. Common records: A (IPv4 address), AAAA (IPv6 address), CNAME (canonical alias), MX (mail server). DNS (डोमेन नेम सिस्टम - पोर्ट 53): इंटरनेट की फोनबुक (पॉल मोकापेट्रिस 1983); डोमेन नामों (upsssc.gov.in) को संख्यात्मक IP पते में बदलता है। A रिकॉर्ड = IPv4, AAAA रिकॉर्ड = IPv6।
  • ARP vs ICMP: ARP (Address Resolution Protocol): Resolves known Logical IP address into unknown 48-bit physical hardware MAC address on local network broadcast. ICMP: Reports network delivery errors and provides network diagnostics (powers ping and traceroute). ARP बनाम ICMP: ARP: ज्ञात IP पते से उपकरण का भौतिक MAC पता खोजता है। ICMP: नेटवर्क कनेक्टिविटी जांचने (Ping व Traceroute कमांड) हेतु प्रयुक्त।
UPSSSC Top Note: DHCP assigns IP addresses using the DORA process; DNS resolves domain names to IP over port 53; ARP translates IP addresses to MAC addresses! UPSSSC मुख्य बिंदु: DHCP DORA प्रक्रिया द्वारा IP पता देता है; DNS पोर्ट 53 पर डोमेन नाम को IP में बदलता है; ARP IP पते को MAC पते में परिवर्तित करता है!

6. IP vs MAC & India IPv6 Rank 6. लॉजिकल IP बनाम MAC एवं भारत में IPv6

48-Bit MAC • #1 Global IPv6
Hardware vs Software Addressing हार्डवेयर बनाम सॉफ्टवेयर एड्रेसिंग
MAC Address (48-Bit / 6 Octets / 12 Hex) OUI Prefix (First 24 Bits, Manufacturer) NIC Specific (Last 24 Bits, Serial No) Physical vs Logical (Permanent vs Configurable) India Global Rank #1 (>80% IPv6 Adoption)
MAC Address Anatomy & India's Global IPv6 Rank MAC पता संरचना एवं भारत की वैश्विक IPv6 स्थिति
  • MAC Address Architecture: 48-bit (6 bytes / 12 hex digits) hardware address burned permanently into ROM of Network Interface Card (NIC). Format: 00:1A:2B:3C:4D:5E. First 24 bits (3 bytes): Organizationally Unique Identifier (OUI) assigned to manufacturer by IEEE. Last 24 bits (3 bytes): Unique device serial number. MAC पते की संरचना: 48-बिट (6 बाइट्स / 12 हेक्साडेसिमल अंक) भौतिक पता जो NIC कार्ड के ROM में स्थायी रूप से दर्ज होता है। प्रथम 24 बिट्स: निर्माता कंपनी का OUI कोड। अंतिम 24 बिट्स: विशिष्ट उपकरण सीरियल नंबर।
  • Logical IP vs Physical MAC: IP Address (Layer 3) is logical, software-configurable, and changes with geographic network location. MAC Address (Layer 2) is physical, immutable, and remains constant regardless of which network the device joins. IP बनाम MAC तुलना: IP पता (लेयर 3) सॉफ्टवेयर आधारित व परिवर्तनीय है (स्थान बदलने पर बदल जाता है)। MAC पता (लेयर 2) हार्डवेयर आधारित व स्थायी है (कभी नहीं बदलता)।
  • India's Global IPv6 Leadership: India ranks #1 in the world in IPv6 adoption (over 80% user adoption rate tracked by Google and APNIC), driven by Reliance Jio 4G/5G, Digital India initiatives, and National IPv6 Deployment Roadmaps by DoT. भारत की वैश्विक IPv6 में प्रथम रैंक: 80% से अधिक IPv6 अंगीकरण के साथ भारत विश्व में पहले स्थान पर है (रिलायंस जियो व डिजिटल इंडिया की महत्वपूर्ण भूमिका)।
UPSSSC Top Note: MAC Address has 48 bits (6 bytes) in hexadecimal; the first 24 bits represent the OUI; India ranks #1 globally in IPv6 adoption! UPSSSC मुख्य बिंदु: MAC पते में 48 बिट्स (6 बाइट्स) हेक्साडेसिमल में होते हैं; प्रथम 24 बिट्स OUI दर्शाते हैं; IPv6 अपनाने में भारत विश्व में प्रथम स्थान पर है!

3. Essential Supporting Protocols (DHCP, DNS, ARP, NAT) & MAC Address 3. आवश्यक सहायक प्रोटोकॉल (DHCP, DNS, ARP, NAT) एवं MAC एड्रेस
  • DHCP (Dynamic Host Configuration Protocol - Port 67 Server, Port 68 Client):
    • Automatically assigns dynamic IP addresses, subnet masks, default gateways, and DNS server IPs to devices joining a network.
    • DORA Process:
      1. D - Discover: Client broadcasts looking for a DHCP server.
      2. O - Offer: Server broadcasts offering an available IP address.
      3. R - Request: Client formally requests to lease the offered IP.
      4. A - Acknowledge: Server acknowledges and confirms the lease duration.     DHCP (डायनेमिक होस्ट कॉन्फ़िगरेशन प्रोटोकॉल):
    • नेटवर्क से जुड़ने वाले नए कंप्यूटरों को स्वतः डायनेमिक IP पता, सबनेट मास्क व गेटवे प्रदान करता है।
    • DORA प्रक्रिया: 1. Discover (खोजना) → 2. Offer (प्रस्ताव) → 3. Request (अनुरोध) → 4. Acknowledge (स्वीकृति)।
  • DNS (Domain Name System - Port 53 UDP/TCP):
    • The "Phonebook of the Internet". Translates human-friendly domain names (e.g., sjmaths.com) into machine-readable IP addresses (e.g., 104.21.55.12).     DNS (डोमेन नेम सिस्टम):
    • इंटरनेट की "फोन डायरेक्टरी"। मानव द्वारा पढ़े जाने वाले वेब पते (sjmaths.com) को संख्यात्मक IP पते में बदलता है।
  • ARP (Address Resolution Protocol) & RARP:
    • ARP (Layer 2/3): Resolves a known logical 32-bit IP address into a physical 48-bit MAC address so frames can be delivered across a local network.
    • RARP (Reverse ARP): Resolves a physical MAC address to obtain an IP address (mostly replaced by DHCP).     ARP (एड्रेस रेजोल्यूशन प्रोटोकॉल) एवं RARP:
    • ARP: ज्ञात IP पते के संगत भौतिक MAC एड्रेस का पता लगाता है।
    • RARP: भौतिक MAC पते से संबंधित IP पते का पता लगाता है।
  • NAT (Network Address Translation):
    • Implemented on routers and firewalls. Translates multiple private, non-routable IP addresses on a local LAN into a single public, globally routable IP address when sending traffic to the Internet.
    • Major technology that prevented early exhaustion of IPv4 addresses.     NAT (नेटवर्क एड्रेस ट्रांसलेशन):
    • स्थानीय नेटवर्क (LAN) के कई प्राइवेट IP पतों को इंटरनेट पर केवल एक पब्लिक IP पते के माध्यम से जोड़ता है।
    • इसने IPv4 पतों की कमी को दूर करने में क्रांतिकारी भूमिका निभाई।
  • IP Address vs MAC Address (Physical vs Logical):
    • MAC Address (Media Access Control): 48-bit (6 bytes) permanent hardware address burned into the Network Interface Card (NIC) ROM. Formatted as 12 hexadecimal digits (e.g., 00:1A:2B:3C:4D:5E). First 24 bits are the OUI (Organizationally Unique Identifier) identifying the manufacturer; last 24 bits are device serial.
    • IP Address: Logical software address assigned dynamically or statically, changing when moving to different networks.     IP एड्रेस बनाम MAC एड्रेस:
    • MAC एड्रेस: 48-बिट (6 बाइट) का स्थायी भौतिक पता जो नेटवर्क कार्ड (NIC) की ROM में दर्ज होता है (उदा. 00:1A:2B:3C:4D:5E)। प्रथम 24 बिट निर्माता कंपनी (OUI) की पहचान होती है।
    • IP एड्रेस: लॉजिकल सॉफ्टवेयर पता जो नेटवर्क बदलने पर बदल जाता है।
