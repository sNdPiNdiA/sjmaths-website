1. ML Foundations & Pipeline 1. ML सैद्धांतिक आधार एवं संपूर्ण जीवन चक्र

Samuel 1959 • Mitchell 1997
Founders & Pipeline Stages संस्थापक एवं पाइपलाइन चरण
Arthur Samuel (1959, Checkers) Tom Mitchell (E, T, P Framework) Data Cleaning (Imputation/Outliers) Feature Scaling (MinMax/Standard) Train-Test Split (80:20 / 70:30) Hyperparameter Tuning (GridSearchCV) MLOps & Drift
Pioneering Definitions & 6-Step Pipeline प्रमुख परिभाषाएं एवं 6-चरणीय पाइपलाइन
  • Arthur Samuel (1959): Coined the term "Machine Learning" while developing an IBM computer program to play checkers; defined it as "the field of study that gives computers the ability to learn without being explicitly programmed". आर्थर सैमुअल (1959): चेकर्स (शतरंज जैसा खेल) खेलने वाला प्रोग्राम बनाते समय "मशीन लर्निंग" शब्द गढ़ा; परिभाषा दी: "कंप्यूटरों को बिना स्पष्ट प्रोग्रामिंग के स्वतः सीखने की क्षमता प्रदान करना"।
  • Tom Mitchell's Mathematical Formulation (1997): A computer program learns from experience $E$ with respect to task $T$ and performance measure $P$, if its performance at task $T$, as measured by $P$, improves with experience $E$. टॉम मिशेल का गणितीय सूत्र (1997): कोई प्रोग्राम कार्य $T$ के संबंध में अनुभव $E$ से सीखता है यदि कार्य $T$ में उसका प्रदर्शन $P$, अनुभव $E$ के साथ बेहतर होता जाता है।
  • The 6-Step ML Lifecycle: 1. Problem Formulation & Data Collection -> 2. Data Preprocessing (handling nulls, scaling) -> 3. Feature Engineering (encoding, PCA) -> 4. Model Training -> 5. Hyperparameter Tuning -> 6. Evaluation & Deployment. ML का 6-चरणीय जीवन चक्र: 1. डेटा संग्रह -> 2. डेटा प्रीप्रोसेसिंग (रिक्त मान व आउटलायर हटाना) -> 3. फीचर इंजीनियरिंग -> 4. मॉडल प्रशिक्षण -> 5. हाइपरपैरामीटर ट्यूनिंग -> 6. मूल्यांकन व परिनियोजन (Deployment)।
UPSSSC Top Note: Arthur Samuel coined "Machine Learning" in 1959; Tom Mitchell defined ML formally through E (Experience), T (Task), and P (Performance)! UPSSSC मुख्य बिंदु: 1959 में आर्थर सैमुअल ने 'मशीन लर्निंग' शब्द गढ़ा; टॉम मिशेल ने इसे E (अनुभव), T (कार्य) व P (प्रदर्शन) द्वारा औपचारिक रूप से परिभाषित किया!

2. Supervised Learning 2. सुपरवाइज्ड लर्निंग: रिग्रेशन एवं क्लासिफिकेशन

Labeled Data • Regression • SVM
Core Supervised Algorithms प्रमुख सुपरवाइज्ड एल्गोरिदम
Linear Regression (Continuous, OLS) Ridge & Lasso (L2 / L1 Regularization) Logistic Regression (Sigmoid Function) Decision Trees (Entropy / Gini) SVM (Support Vector Machines, Margin) KNN (K-Nearest Neighbors, Lazy Learner) Naive Bayes (Bayes Theorem Probability)
Regression vs Classification Mechanics रिग्रेशन बनाम क्लासिफिकेशन कार्यप्रणाली
  • Supervised Learning Definition: Learning algorithm trained on labeled input-output pairs $(X, y)$ to predict outcomes for unseen test data. Divided into Regression (continuous output e.g. house price, temperature) and Classification (discrete categorical output e.g. spam/not spam, benign/malignant). सुपरवाइज्ड लर्निंग परिभाषा: लेबलयुक्त डेटा $(X, y)$ पर प्रशिक्षित मॉडल। रिग्रेशन: सतत संख्यात्मक आउटपुट का अनुमान (उदा. मकान की कीमत, तापमान)। क्लासिफिकेशन: असतत श्रेणियों में विभाजन (उदा. स्पैम या नॉन-स्पैम)।
  • Key Classification Algorithms: Logistic Regression: Uses Sigmoid function $\sigma(z) = rac{1}{1 + e^{-z}}$ to map real values to probability between 0 and 1. SVM: Finds the optimal decision hyperplane that maximizes margin between closest data points (Support Vectors); uses Kernel trick for non-linear boundaries. Naive Bayes: Calculates conditional probability assuming feature independence. प्रमुख वर्गीकरण एल्गोरिदम: लॉजिस्टिक्स रिग्रेशन: सिग्मॉइड फलन द्वारा 0 और 1 के बीच प्रायिकता देता है। SVM: सपोर्ट वेक्टर्स के बीच अधिकतम मार्जिन वाला हाइपरप्लेन खोजता है। नाइव बेयस: बेयस प्रमेय पर आधारित प्रायिकता मॉडल।
UPSSSC Top Note: Logistic Regression is a Classification algorithm (not regression); KNN is called a "Lazy Learner"; Naive Bayes assumes conditional feature independence! UPSSSC मुख्य बिंदु: लॉजिस्टिक्स रिग्रेशन वास्तव में एक क्लासिफिकेशन एल्गोरिदम है; KNN को 'लेज़ी लर्नर' कहा जाता है; नाइव बेयस सभी चरों को स्वतंत्र मानता है!

3. Unsupervised Learning 3. अनसुपरवाइज्ड लर्निंग: क्लस्टरिंग एवं डायमेंशनलिटी

Unlabeled • K-Means • PCA
Clustering & Reduction Techniques क्लस्टरिंग एवं आयाम न्यूनीकरण तकनीकें
K-Means Clustering (Centroids & Elbow) Hierarchical Clustering (Dendrograms) DBSCAN (Density Based Spatial) PCA (Principal Component Analysis) t-SNE & UMAP (Manifold Visualization) Apriori (Market Basket Analysis)
Unsupervised Mechanics & Algorithms अनसुपरवाइज्ड कार्यप्रणाली एवं तकनीक
  • Unsupervised Learning Definition: Discovers hidden structures, inherent patterns, or groupings within unlabeled data without any predefined target labels or supervisor feedback. अनसुपरवाइज्ड लर्निंग: बिना किसी लेबलयुक्त उत्तर या पर्यवेक्षक के, डेटा में अंतर्निहित पैटर्न, समानताएं और प्राकृतिक समूह (क्लस्टर) खोजना।
  • K-Means Clustering: Partitions data into $K$ distinct clusters by minimizing sum of squared distances to cluster centroids. Optimal number of clusters $K$ determined using the Elbow Method (inertia plot). K-मीन्स क्लस्टरिंग: डेटा को $K$ समूहों में सेंट्रॉइड्स के आधार पर बांटता है। उपयुक्त $K$ का मान एल्बो मेथड (Elbow Method) ग्राफ द्वारा तय होता है।
  • Principal Component Analysis (PCA): Dimensionality reduction technique that transforms large number of correlated variables into a smaller set of orthogonal, uncorrelated variables called Principal Components, capturing maximum variance using eigenvectors. प्रिंसिपल कंपोनेंट एनालिसिस (PCA): अत्यधिक चरों (हाई डायमेंशन) को कम चरों में बदलना; आइगेनवेक्टर्स द्वारा अधिकतम विचरण (Variance) को संरक्षित रखता है।
UPSSSC Top Note: K-Means requires specifying K in advance; Elbow Method finds optimal K; PCA is an unsupervised dimensionality reduction method! UPSSSC मुख्य बिंदु: K-मीन्स में K का मान पहले से देना होता है; एल्बो विधि द्वारा श्रेष्ठ K चुना जाता है; PCA आयाम घटाने (डायमेंशनलिटी रिडक्शन) की मुख्य तकनीक है!

4. Ensemble & Reinforcement Learning 4. एन्सेम्बल मेथड्स एवं रीइन्फोर्समेंट लर्निंग

Bagging • Boosting • Q-Learning
Ensemble Models & RL Concepts एन्सेम्बल मॉडल्स एवं RL संकल्पनाएं
Bagging (Bootstrap Aggregation) Random Forest (Leo Breiman, 2001) Boosting (Sequential Error Correction) AdaBoost & XGBoost (High Performance) Agent & Environment (Action, State, Reward) Markov Decision Process (MDP) Q-Learning (Bellman Equation)
Ensemble Techniques & RL Mechanics एन्सेम्बल तकनीक एवं RL की कार्यप्रणाली
  • Bagging vs Boosting: Bagging (Bootstrap Aggregating): Trains multiple base learners in parallel on bootstrap sample subsets; reduces variance (e.g. Random Forest). Boosting: Trains models sequentially where each new model focuses on instances misclassified by earlier models; reduces bias (e.g. AdaBoost, Gradient Boosting, XGBoost). बैगिंग बनाम बूस्टिंग: बैगिंग: स्वतंत्र मॉडल समानांतर में चलाकर वेरिएंस घटाता है (रैंडम फॉरेस्ट)। बूस्टिंग: क्रमिक रूप से मॉडल चलाता है जहाँ प्रत्येक अगला मॉडल पिछली गलतियों को सुधारता है; बायस घटाता है (XGBoost, AdaBoost)।
  • Reinforcement Learning (RL): Trial-and-error learning paradigm where an Agent interacts with an Environment, performs Actions ($A$), observes resulting States ($S$), and receives scalar Rewards ($R$) to maximize cumulative future reward (Bellman Equation, Q-Learning). Used in AlphaGo and autonomous driving. रीइन्फोर्समेंट लर्निंग (RL): 'प्रयास एवं त्रुटि' आधारित अधिगम; एक एजेंट अपने पर्यावरण में कार्य (Action) करता है, और बदले में पुरस्कार (Reward) या दंड प्राप्त कर अपनी रणनीति सुधारता है (Q-लर्निंग)।
UPSSSC Top Note: Random Forest is based on Bagging (parallel trees); XGBoost is based on Boosting (sequential correction); Q-Learning is a Reinforcement Learning algorithm! UPSSSC मुख्य बिंदु: रैंडम फॉरेस्ट 'बैगिंग' पर आधारित है; XGBoost 'बूस्टिंग' पर आधारित है; Q-लर्निंग रीइन्फोर्समेंट लर्निंग का प्रमुख एल्गोरिदम है!

5. Bias-Variance & Evaluation Metrics 5. बायस-वेरिएंस ट्रेडऑफ एवं मॉडल मूल्यांकन

Underfitting • Overfitting • F1-Score
Evaluation Metrics & Curves मूल्यांकन मानक एवं मैट्रिक्स
Confusion Matrix (TP, TN, FP, FN) Accuracy (Overall Correct) Precision (TP / TP+FP) Recall / Sensitivity (TP / TP+FN) F1-Score (Harmonic Mean of P & R) ROC-AUC (True vs False Positive) K-Fold Cross Validation
Overfitting vs Underfitting Mechanics ओवरफिटिंग बनाम अंडरफिटिंग कार्यप्रणाली
  • Bias-Variance Tradeoff: High Bias (Underfitting): Model is too simple to capture underlying trend; performs poorly on BOTH training and test data. High Variance (Overfitting): Model is overly complex; memorizes training noise; performs exceptionally on training data but fails miserably on unseen test data. बायस-वेरिएंस ट्रेडऑफ: उच्च बायस (अंडरफिटिंग): मॉडल इतना सरल है कि डेटा का पैटर्न समझ नहीं पाता (ट्रेनिंग व टेस्ट दोनों में खराब परिणाम)। उच्च वेरिएंस (ओवरफिटिंग): मॉडल ट्रेनिंग डेटा को रट लेता है (ट्रेनिंग में 100% सही लेकिन नए डेटा पर पूरी तरह फेल)।
  • Confusion Matrix Metrics: Precision: Measures exactness $ rac{TP}{TP + FP}$ (crucial when false positives are costly, e.g. spam filter). Recall (Sensitivity): Measures completeness $ rac{TP}{TP + FN}$ (crucial when false negatives are dangerous, e.g. cancer detection). F1-Score: Harmonic mean of Precision and Recall: $ rac{2 imes P imes R}{P + R}$. कन्फ्यूजन मैट्रिक्स मानक: प्रिसिजन (परिशुद्धता): $ rac{TP}{TP + FP}$ (स्पैम जांच में उपयोगी)। रिकॉल (संवेदनशीलता): $ rac{TP}{TP + FN}$ (कैंसर या बीमारी जांच में अनिवार्य)। F1-स्कोर: प्रिसिजन और रिकॉल का हरात्मक माध्य (Harmonic Mean)।
UPSSSC Top Note: Overfitting means high variance and low bias; F1-score is the Harmonic Mean of Precision and Recall; K-Fold Cross Validation prevents overfitting! UPSSSC मुख्य बिंदु: ओवरफिटिंग का अर्थ उच्च वेरिएंस व निम्न बायस है; F1-स्कोर प्रिसिजन व रिकॉल का हरात्मक माध्य है; K-फोल्ड क्रॉस वैलिडेशन ओवरफिटिंग रोकता है!

1. Foundational Concepts of Machine Learning 1. मशीन लर्निंग की मूलभूत अवधारणाएं
  • Definition of Machine Learning:
    • A subset of Artificial Intelligence (AI) that provides systems the ability to automatically learn and improve from experience without being explicitly programmed.
    • Coined in 1959 by Arthur Samuel (IBM scientist who built a self-learning Checkers program).
    • Tom Mitchell's Formal Definition (1997): "A computer program is said to learn from experience E with respect to some class of tasks T and performance measure P, if its performance at tasks in T, as measured by P, improves with experience E."     मशीन लर्निंग की परिभाषा:
    • आर्टिफिशियल इंटेलिजेंस (AI) का वह उप-क्षेत्र जो कंप्यूटर को बिना स्पष्ट रूप से प्रोग्राम किए, पिछले अनुभवों (डेटा) से स्वतः सीखने और सुधार करने की क्षमता प्रदान करता है।
    • 1959 में आर्थर सैमुअल (IBM) द्वारा 'मशीन लर्निंग' शब्द प्रतिपादित किया गया (इन्होंने चेकर्स गेम खेलने वाला प्रोग्राम बनाया था)।
    • टॉम मिशेल (1997) की परिभाषा: यदि किसी कार्य T पर अनुभव E के साथ प्रणाली का प्रदर्शन माप P सुधरता है, तो वह प्रणाली मशीन लर्निंग करती है।
  • Traditional Programming vs Machine Learning:
    • Traditional Programming: Data + Program (Rules written by Human) → Computer → Output.
    • Machine Learning: Data + Output (Desired Results) → Computer → Model / Rules (Automatically learned algorithm).     पारंपरिक प्रोग्रामिंग बनाम मशीन लर्निंग:
    • पारंपरिक प्रोग्रामिंग: डेटा + नियम (प्रोग्रामर द्वारा लिखित कोड) → कंप्यूटर → आउटपुट।
    • मशीन लर्निंग: डेटा + अपेक्षित आउटपुट → कंप्यूटर → मॉडल/नियम (कंप्यूटर स्वयं सीखता है)।
  • Machine Learning Workflow Lifecycle:
    • 1. Data Collection: Gathering raw structured or unstructured data.
    • 2. Data Cleaning & Preprocessing: Handling missing values, outliers, encoding categorical variables, normalization/scaling.
    • 3. Feature Engineering: Selecting and transforming relevant variables for prediction.
    • 4. Model Training: Splitting data into Training Set (typically 70-80%) and Testing Set (20-30%).
    • 5. Evaluation & Hyperparameter Tuning: Testing on unseen data and optimizing parameters.
    • 6. Deployment & Monitoring: Integrating model into production APIs.     मशीन लर्निंग का कार्यचक्र:
    • 1. डेटा संग्रहण: कच्चा डेटा एकत्र करना।
    • 2. डेटा प्री-प्रोसेसिंग: मिसिंग वैल्यू भरना, आउटलायर्स हटाना, स्केलिंग करना।
    • 3. फीचर इंजीनियरिंग: सबसे महत्वपूर्ण चर/विशेषताओं का चयन करना।
    • 4. मॉडल ट्रेनिंग: डेटा को ट्रेनिंग (70-80%) और टेस्टिंग (20-30%) में बांटकर मॉडल सिखाना।
    • 5. मॉडल मूल्यांकन: नए डेटा पर प्रदर्शन मापना और ट्यूनिंग करना।

3. Model Evaluation Metrics, Confusion Matrix & Errors 3. मॉडल मूल्यांकन मानक, कन्फ्यूजन मैट्रिक्स एवं त्रुटियां
  • Confusion Matrix (वर्गीकरण मैट्रिक्स):
    • A $2 imes 2$ table used to evaluate the performance of a classification model:
      • True Positive (TP): Positive correctly predicted as Positive.
      • True Negative (TN): Negative correctly predicted as Negative.
      • False Positive (FP - Type I Error): Negative wrongly predicted as Positive (e.g., normal email marked as spam).
      • False Negative (FN - Type II Error): Positive wrongly predicted as Negative (e.g., diseased patient diagnosed as healthy - highly critical error).     कन्फ्यूजन मैट्रिक्स (Confusion Matrix):
    • वर्गीकरण मॉडल के प्रदर्शन को मापने वाली तालिका:
      • ट्रू पॉजिटिव (TP): सही रूप से पहचाना गया पॉजिटिव।
      • ट्रू नेगेटिव (TN): सही रूप से पहचाना गया नेगेटिव।
      • फाल्स पॉजिटिव (FP - टाइप I त्रुटि): गलत रूप से पॉजिटिव बताना (जैसे निर्दोष मेल को स्पैम घोषित करना)।
      • फाल्स नेगेटिव (FN - टाइप II त्रुटि): बीमारी होने पर भी नेगेटिव बताना (सबसे घातक त्रुटि)।
  • Core Performance Metrics:
    • Accuracy: $ rac{TP + TN}{TP + TN + FP + FN}$ (Total correct predictions over all predictions).
    • Precision: $ rac{TP}{TP + FP}$ (Out of all positive predictions, how many were actually positive).
    • Recall (Sensitivity): $ rac{TP}{TP + FN}$ (Out of all actual positives, how many were correctly detected).
    • F1-Score: The Harmonic Mean of Precision and Recall: $2 imes rac{ ext{Precision} imes ext{Recall}}{ ext{Precision} + ext{Recall}}$. Ideal for imbalanced datasets.     प्रमुख मूल्यांकन मानक:
    • सटीकता (Accuracy): कुल सही अनुमान / कुल परीक्षण मामले।
    • प्रिसिजन (Precision): मॉडल द्वारा बताए गए कुल पॉजिटिव में से कितने वास्तव में सही थे।
    • रिकॉल (Recall / संवेदनशीलता): वास्तविक पॉजिटिव मामलों में से मॉडल कितने पकड़ पाया।
    • F1-स्कोर: प्रिसिजन और रिकॉल का हरात्मक माध्य (Harmonic Mean); असंतुलित डेटासेट में सर्वश्रेष्ठ मापक।
  • Overfitting vs Underfitting (Bias-Variance Dilemma):
    • Underfitting (High Bias): Model is too simplistic; fails to capture patterns in training data and performs poorly on both training and test data.
    • Overfitting (High Variance): Model is overly complex; memorizes noise in training data. Performs exceptionally well on training set but poorly on new/unseen test data.
    • Remedies for Overfitting: Cross-validation ($k$-fold), Regularization ($L_1$ Lasso, $L_2$ Ridge), pruning decision trees, dropout, gathering more training data.     ओवरफिटिंग बनाम अंडरफिटिंग (बायस-वेरिएंस द्वंद्व):
    • अंडरफिटिंग (उच्च बायस): मॉडल बहुत सरल है; वह ट्रेनिंग डेटा के पैटर्न को भी नहीं सीख पाता (दोनों में खराब प्रदर्शन)।
    • ओवरफिटिंग (उच्च विचरण): मॉडल बहुत जटिल है; उसने ट्रेनिंग डेटा को रट लिया है। ट्रेनिंग में 100% अंक लाता है किंतु नए डेटा पर फेल हो जाता है।
    • ओवरफिटिंग रोकने के उपाय: $k$-फोल्ड क्रॉस वैलिडेशन, रेगुलराइजेशन ($L_1$ लासो, $L_2$ रिज), डिसिजन ट्री की प्रूनिंग (कटाई), अधिक डेटा जोड़ना।
