Section Breaks: Essential for applying different page numbering or headers/footers in different chapters. अलाइनमेंट एवं ब्रेक्स: चार अलाइनमेंट: लेफ्ट (Ctrl+L), सेंटर (Ctrl+E), राइट (Ctrl+R), जस्टिफाई (Ctrl+J)। पेज ब्रेक का शॉर्टकट Ctrl+Enter है। अलग-अलग हेडर हेतु सेक्शन ब्रेक जरूरी है।

  • The Three Components of Mail Merge: Feature located in Mailings Tab for mass personalized documents (admit cards, appointment letters). Requires: 1. UPSSSC Top Note: F7 is the shortcut for Spelling & Grammar; Shift+F7 opens Thesaurus; Mail Merge combines a Main Document with a Data Source! UPSSSC मुख्य बिंदु: स्पेलिंग जांच का शॉर्टकट F7 है; थिसॉरस (पर्यायवाची) का शॉर्टकट Shift+F7 है; मेल मर्ज में मुख्य डॉक्यूमेंट को डेटा सोर्स से जोड़ा जाता है!

4. MS Excel Grid Dimensions 4. एमएस एक्सेल ग्रिड संरचना एवं सीमाएं

1,048,576 Rows • 16,384 Cols (XFD)
Excel Grid Specs (2007-365) एक्सेल ग्रिड विनिर्देश (2007 से 365)
Total Rows: 1,048,576 (2^20) Total Columns: 16,384 (2^14, Last Col: XFD) Legacy Grid: 65,536 Rows x 256 Cols (IV) Name Box: Active Cell Reference (e.g. A1) Formula Bar: Cell Contents / Equation Zoom Limits: Min 10% to Max 400%
Grid Dimensions & Navigation Elements ग्रिड विनिर्देश एवं नेविगेशन घटक
  • Grid Capacity (Excel 2007-Present): Each worksheet contains exactly 1,048,576 rows ($2^{20}$, numbered 1 to 1048576) and 16,384 columns ($2^{14}$, lettered A to Z, AA to ZZ... ending at column XFD). In legacy Excel 97-2003 (.xls), grid was 65,536 rows by 256 columns (ending at IV). एक्सेल ग्रिड क्षमता: आधुनिक एक्सेल में प्रत्येक शीट में ठीक 10,48,576 पंक्तियाँ (Rows) तथा 16,384 स्तंभ (Columns) होते हैं। अंतिम कॉलम का नाम XFD है। पुराने एक्सेल (97-2003) में 65,536 पंक्तियाँ व 256 कॉलम (IV) थे।
  • Name Box vs Formula Bar: Name Box: Box on left side of formula bar showing address of active cell (e.g. C10). Formula Bar: Displays the actual formula or text stored within the active cell. Excel zoom range is 10% to 400% (unlike Word's 500%). नेम बॉक्स बनाम फॉर्मूला बार: नेम बॉक्स: वर्तमान सक्रिय सेल का पता (उदा. A1, C10) प्रदर्शित करता है। फॉर्मूला बार: सेल में टाइप किया गया वास्तविक फॉर्मूला या टेक्स्ट दिखाता है। एक्सेल ज़ूम सीमा 10% से 400% है।
UPSSSC Top Note: Modern MS Excel has 1,048,576 rows and 16,384 columns (last column is XFD); Name Box displays the active cell address; Excel maximum zoom is 400%! UPSSSC मुख्य बिंदु: आधुनिक एक्सेल में 10,48,576 पंक्तियाँ और 16,384 कॉलम होते हैं (अंतिम कॉलम XFD है); नेम बॉक्स सक्रिय सेल का पता दिखाता है; अधिकतम ज़ूम 400% है!

5. Formulas & Cell Referencing 5. फॉर्मूला, सेल संदर्भ ($) एवं त्रुटि कोड

Equals (=) • F4 Dollar • #DIV/0!
Referencing & Error Messages सेल संदर्भ एवं सामान्य त्रुटि संदेश
Starts With = (Equals Sign Mandatory) Relative Reference: =A1+B1 (Shifts on Copy) Absolute Reference: =$A$1+$B$1 (F4 Dollar Locked) Mixed Reference: =$A1 or =A$1 ##### Error: Column Too Narrow #DIV/0! Error: Division by Zero #VALUE! Error: Wrong Argument Type
Cell Reference Types & Error Meanings सेल संदर्भ के प्रकार एवं त्रुटियों का अर्थ
  • Three Cell Referencing Modes: Every formula begins with =. Relative Referencing (default, e.g. =A1): References adjust automatically when dragged/copied. Absolute Referencing (e.g. =$A$1): Dollar sign ($) locks row and column; does NOT change when copied (toggled with F4 key). Mixed Referencing: Either row or column locked (=$A1 or =A$1). सेल संदर्भ के तीन प्रकार: फॉर्मूला सदैव = से शुरू होता है। रिलेटिव: कॉपी करने पर स्वतः बदलता है (=A1)। एब्सोल्यूट (Absolute): डॉलर चिह्न ($) द्वारा पंक्ति व कॉलम लॉक; कभी नहीं बदलता (=$A$1); F4 कुंजी से डॉलर लगता है। मिश्रित: केवल एक लॉक ($A1 या A$1)।
  • Common Excel Error Codes: #####: Column is too narrow to display the number/date. #DIV/0!: Formula attempts to divide by zero or an empty cell. #NAME?: Formula uses an unrecognized function name or unquoted text. #VALUE!: Incorrect data type used in mathematical calculation. #REF!: Cell referenced by formula was deleted. एक्सेल के सामान्य त्रुटि संदेश: #####: कॉलम चौड़ाई संख्या दिखाने हेतु बहुत संकरी है। #DIV/0!: शून्य से भाग देने की त्रुटि। #NAME?: फॉर्मूले में फंक्शन की स्पेलिंग गलत है। #VALUE!: गलत डेटा प्रकार। #REF!: संदर्भित सेल डिलीट हो चुकी है।
UPSSSC Top Note: All Excel formulas MUST begin with equals (=); F4 toggles absolute dollar reference ($A$1); ##### means column width is too narrow! UPSSSC मुख्य बिंदु: एक्सेल में सभी फॉर्मूले बराबर (=) से शुरू होते हैं; F4 कुंजी से एब्सोल्यूट ($A$1) लॉक लगता है; ##### का अर्थ कॉलम की चौड़ाई कम होना है!

1. MS Word: Architecture, Text Formatting & Key Features 1. MS Word: वास्तुकला, टेक्स्ट फॉर्मेटिंग एवं महत्वपूर्ण विशेषताएं
  • File Specifications & Default Settings:
    • File Extension: .docx (XML-based format introduced in Word 2007; older versions used .doc). Macro-enabled template is .dotm.
    • Default Font: Calibri (11 pt) in Word 2007-2021; Aptos in modern Microsoft 365.
    • Font Size Limits: Dropdown menu lists sizes from 8 to 72 pt. Can be manually set anywhere from 1 to 1638 pt.
    • Zoom Slider Range: Minimum zoom is 10%; Maximum zoom is 500% (default 100%).     फाइल विनिर्देश एवं डिफ़ॉल्ट सेटिंग्स:
    • फाइल एक्सटेंशन: .docx (Word 2007 से XML आधारित; पुराने संस्करणों में .doc था)।
    • डिफ़ॉल्ट फॉन्ट: कैलिबरी (Calibri 11 pt) या एप्टोस (Aptos)।
    • फॉन्ट आकार सीमा: ड्रॉपडाउन मेनू में 8 से 72 pt; मैनुअल रूप से 1 से 1638 pt तक सेट किया जा सकता है।
    • ज़ूम स्लाइडर सीमा: न्यूनतम 10% से अधिकतम 500% (डिफ़ॉल्ट 100%)।
  • Paragraph Alignment & Formatting:
    • Left Align (Ctrl + L): Aligns text against left margin (Default in English).
    • Center Align (Ctrl + E): Centers text between margins (used for titles).
    • Right Align (Ctrl + R): Aligns text against right margin.
    • Justify (Ctrl + J): Distributes text evenly between left and right margins, creating clean flush edges on both sides (used in books/newspapers).
    • Line Spacing: Single (Ctrl + 1), Double (Ctrl + 2), 1.5 Lines (Ctrl + 5).
    • Case Conversion (Shift + F3): Toggles between Sentence case, lowercase, and UPPERCASE.
    • Subscript (Ctrl + =): Lowers character below baseline (e.g., $H_2O$).
    • Superscript (Ctrl + Shift + +): Raises character above baseline (e.g., $X^2$).     पैराग्राफ संरेखण (Alignment) एवं फॉर्मेटिंग:
    • बायाँ अलाइन (Ctrl + L): टेक्स्ट को बायीं ओर संरेखित करता है (डिफ़ॉल्ट)।
    • सेंटर अलाइन (Ctrl + E): टेक्स्ट को ठीक बीच में लाता है (शीर्षक हेतु)।
    • दायाँ अलाइन (Ctrl + R): टेक्स्ट को दायीं ओर संरेखित करता है।
    • जस्टिफाई (Ctrl + J): टेक्स्ट को दोनों ओर (बाएं व दाएं) एक समान चौड़ाई में फैलाता है (किताबों/समाचार पत्रों में)।
    • लाइन स्पेसिंग: 1.0 (Ctrl + 1), 2.0 (Ctrl + 2), 1.5 (Ctrl + 5)।
    • सबस्क्रिप्ट (Ctrl + =): अक्षर को नीचे की ओर लिखना (जैसे $H_2O$)।
    • सुपरस्क्रिप्ट (Ctrl + Shift + +): अक्षर को घात/ऊपर लिखना (जैसे $X^2$)।
  • High-Yield Advanced Word Features:
    • Mail Merge (मेल मर्ज): Generates mass personalized letters, certificates, or envelopes by combining a Main Document with an external Data Source (Excel spreadsheet or Access database) to produce individual Merged Documents.
    • Drop Cap (ड्रॉप कैप): Formats the first letter of a paragraph as a large decorative capital letter. Two positions: Dropped (within text) or In Margin. Default lines dropped = 3; Maximum lines = 10.
    • Thesaurus (थिसॉरस - Shift + F7): Built-in dictionary providing synonyms and antonyms for selected words.
    • Spelling & Grammar Check: Shortcut is F7. Red squiggly line indicates Spelling error; Blue/Green squiggly line indicates Grammar error.     MS Word की महत्वपूर्ण उन्नत विशेषताएं:
    • मेल मर्ज (Mail Merge): एक ही प्रारूप वाले पत्र को सैकड़ों लोगों के अलग-अलग नाम/पते के साथ एक क्लिक में तैयार करना (मुख्य दस्तावेज + डेटा स्रोत = विलय दस्तावेज)।
    • ड्रॉप कैप (Drop Cap): पैराग्राफ के पहले अक्षर को बहुत बड़ा सजावटी बनाना। डिफ़ॉल्ट पंक्तियाँ = 3; अधिकतम पंक्तियाँ = 10।
    • थिसॉरस (Shift + F7): शब्दों के पर्यायवाची (Synonyms) एवं विलोम शब्द खोजने वाला शब्दकोश।

Cell Referencing Modes (F4 Toggle Key): सेल संदर्भ के तीन प्रकार (F4 शॉर्टकट कुंजी द्वारा):

  • Relative Reference (सापेक्ष संदर्भ - e.g., A1): The default mode. When a formula containing relative references is copied down or across, the row and column coordinates adjust automatically relative to the new position. सापेक्ष संदर्भ (Relative): डिफ़ॉल्ट रूप। फॉर्मूला कॉपी करने पर सेल का पता नए स्थान के अनुसार स्वतः बदल जाता है (उदा. =A1+B1 को नीचे खींचने पर =A2+B2 बन जाएगा)।
  • Absolute Reference (निरपेक्ष संदर्भ - e.g., $A$1): Uses the dollar sign ($) before both column letter and row number. Locks the cell completely; coordinates never change when formula is copied. Press F4 while editing to toggle. निरपेक्ष संदर्भ (Absolute): डॉलर चिन्ह $ द्वारा कॉलम और पंक्ति दोनों को लॉक कर दिया जाता है (उदा. $A$1)। फॉर्मूला कॉपी करने पर यह पता कभी नहीं बदलता। F4 दबाकर डॉलर चिन्ह लगाया जाता है।
  • Mixed Reference (मिश्रित संदर्भ - e.g., $A1 or A$1): Either only the column is locked ($A1) or only the row is locked (A$1). मिश्रित संदर्भ (Mixed): या तो केवल कॉलम लॉक होता है ($A1) या केवल पंक्ति लॉक होती है (A$1)।

Common Excel Formula Error Messages: एक्सेल के सामान्य फॉर्मूला त्रुटि कोड (Error Codes):

  • ##### : The column is not wide enough to display the number, or negative date/time is encountered. (Fix: Double-click column header boundary to auto-fit width). ##### : कॉलम की चौड़ाई संख्या दिखाने के लिए कम पड़ रही है (कॉलम को चौड़ा करें)।
  • #DIV/0! : The formula attempts to divide a number by zero or by an empty cell. #DIV/0! : किसी संख्या को शून्य (0) से भाग देने का प्रयास किया गया है।
  • #NAME? : Excel does not recognize text in the formula (typically misspelled function name, e.g. =SMM(A1:A5) instead of =SUM). #NAME? : फंक्शन के नाम की वर्तनी गलत है (जैसे SUM की जगह SMM लिख दिया गया हो)।
  • #VALUE! : The formula has wrong type of argument (e.g., attempting mathematical addition on a text cell: =A1 + "Apple"). #VALUE! : गलत डेटा प्रकार (जैसे संख्या में टेक्स्ट जोड़ने का प्रयास)।
