💡 Core Concepts: The Building Blocks of Averages

1. Arithmetic Mean (Simple Average)

Definition: The sum of a set of values divided by the number of values in the set.

Explanation: This is the most common and intuitive type of average. It represents the central tendency of a dataset, essentially finding the value that each item would have if the total quantity were distributed equally among all items.

Intuition: Imagine you have 3 friends with 10, 20, and 30 chocolates respectively. If they pool all their chocolates and then redistribute them equally, each friend would get 20 chocolates. That's the arithmetic mean!

Important Observations:

  • It's sensitive to extreme values (outliers).
  • Can be a non-integer even if all data points are integers.
  • If each number in a set is increased/decreased by 'k', the average also increases/decreases by 'k'.
  • If each number in a set is multiplied/divided by 'k', the average also gets multiplied/divided by 'k'.

Memory Tip: "Equal Sharing" average. Sum it up, then divide by how many there are!

Common Mistake: Forgetting to divide by the total count, or dividing by an incorrect count.

Mini Example: Find the arithmetic mean of 15, 25, 30, and 10.

Solution: $$(15 + 25 + 30 + 10) / 4 = 80 / 4 = 20$$

2. Weighted Average

Definition: An average where each value in the dataset is multiplied by a certain weight (or importance/frequency) before summing them up and dividing by the sum of the weights.

Explanation: Weighted average is used when different items or groups contribute unequally to the total. For instance, in calculating your final grade, different exams or assignments might have different weightage. Or, when calculating the average price of different batches of an item with varying quantities.

Intuition: Think of your school report card. Your final exam (e.g., 50% weight) contributes much more to your final grade than a minor quiz (e.g., 10% weight). The weighted average reflects this differential importance.

Important Observations:

  • If all weights are equal, the weighted average reduces to the arithmetic mean.
  • The weights can be quantities, frequencies, percentages, or any measure of importance.
  • The sum of weights is crucial for the denominator.

Memory Tip: "Importance-adjusted" average. Each value gets a 'say' proportional to its weight.

Common Mistake: Dividing by the count of items instead of the sum of the weights.

Mini Example: A store sells 10 kg of rice at ₹50/kg and 20 kg of rice at ₹60/kg. Find the weighted average price per kg.

Solution: $$ (10 \times 50 + 20 \times 60) / (10 + 20) = (500 + 1200) / 30 = 1700 / 30 = ₹56.67 \text{/kg} $$

3. Combined Average (Average of Averages)

Definition: The average of two or more groups, where each group has its own average and a specific number of elements (size).

Explanation: This is a special case of weighted average. When you combine several groups, each with its own average and count of members, to find the overall average of all members across all groups, you must consider the size of each group. Simply averaging the individual group averages would be incorrect unless the group sizes are equal.

Intuition: Imagine Class A has an average height of 160 cm (40 students), and Class B has an average height of 150 cm (20 students). To find the average height of all students from both classes, you can't just take \((160+150)/2\). You need to account for the fact that Class A has more students.

Important Observations:

  • Always calculate the total sum of all observations and divide by the total count of all observations.
  • This is effectively a weighted average where the "weights" are the number of elements in each group.

Memory Tip: "Total sum over total count" for combined groups. Think of it as a grand weighted average!

Common Mistake: Simply averaging the individual averages without accounting for the number of items in each group.

Mini Example: Group 1 has 5 members with an average score of 20. Group 2 has 10 members with an average score of 30. Find the combined average score.

Solution: $$ (5 \times 20 + 10 \times 30) / (5 + 10) = (100 + 300) / 15 = 400 / 15 \approx 26.67 $$

📏 Rules & Properties: Manipulating Averages

1. Effect of Adding/Removing a Value on Average

Explanation:

  • If a new value equal to the current average is added to or removed from a set, the average remains unchanged.
  • If a new value greater than the current average is added, the average increases.
  • If a new value less than the current average is added, the average decreases.
  • Conversely, if a value greater than the current average is removed, the average decreases.
  • And if a value less than the current average is removed, the average increases.

Reason: The average acts like a balance point. Adding a value exactly at the balance point keeps it balanced. Adding a heavier value shifts the balance point up, and a lighter value shifts it down. Removing a value has the opposite effect.

Shortcut: For competitive exams, use the "Deviation Method". Calculate the net deviation from the existing average (or an assumed average) and distribute it among the new total number of observations.

Exception: If the initial count is zero or one, the concept might behave differently or be undefined. (e.g., adding to an empty set changes the average from undefined to the new value).

Example: The average age of 5 students is 15 years.
a) If a new student aged 15 joins, the average remains 15. (Total sum $5 \times 15 + 15 = 90$. New count 6. Avg = $90/6 = 15$).
b) If a new student aged 20 joins, the average increases. (Total sum $5 \times 15 + 20 = 95$. New count 6. Avg = $95/6 \approx 15.83$).

2. Effect of Operations on All Values in a Set

Explanation: If each value in a set is uniformly increased/decreased by 'k', or multiplied/divided by 'k', the average of the set also undergoes the same operation.

Reason: The average is a representative value of the set. When all elements shift or scale uniformly, their central point (the average) shifts or scales in the same manner.

Shortcut: Don't recalculate the entire sum. Just apply the operation directly to the existing average.

Example: The average of 5 numbers is 20.

  • If each number is increased by 3, the new average is $20 + 3 = 23$.
  • If each number is decreased by 2, the new average is $20 - 2 = 18$.
  • If each number is multiplied by 4, the new average is $20 \times 4 = 80$.
  • If each number is divided by 5, the new average is $20 / 5 = 4$.

📐 Formula Box: Your Toolkit for Averages

1. Arithmetic Mean (Simple Average)

$$ \text{Average (Mean)} = \frac{\text{Sum of all observations}}{\text{Total number of observations}} \quad \text{or} \quad \frac{\sum_{i=1}^{n} x_i}{n} $$

Meaning: The equal distribution value across all items.

Variables: \(x_i\) = individual observation, \(n\) = total number of observations.

When to use: When all items contribute equally or have the same importance.

When NOT to use: When items have different importance, frequency, or quantity (use Weighted Average).

Memory Trick: "Add 'em up, then divide by count!"

2. Weighted Average

$$ \text{Weighted Average} = \frac{\text{Sum of (weight } \times \text{ value)}}{\text{Sum of all weights}} \quad \text{or} \quad \frac{\sum_{i=1}^{n} (w_i \times x_i)}{\sum_{i=1}^{n} w_i} $$

Meaning: An average that accounts for the varying importance or quantity of each item.

Variables: \(x_i\) = value of the \(i\)-th item/group, \(w_i\) = weight of the \(i\)-th item/group (e.g., quantity, importance, frequency).

When to use: When items/groups have different levels of importance, frequency, or quantity.

When NOT to use: For simple, unweighted averages (use Arithmetic Mean).

Memory Trick: "Weighted sum over sum of weights!"

3. Combined Average (for Two Groups)

$$ \text{Combined Average} = \frac{(n_1 \times Avg_1) + (n_2 \times Avg_2)}{n_1 + n_2} $$

Meaning: The overall average when two groups, each with its own size and average, are merged. (This formula extends for more than two groups).

Variables: \(n_1, n_2\) = number of elements in Group 1 & Group 2; \(Avg_1, Avg_2\) = average of Group 1 & Group 2.

When to use: When combining two or more groups, each with its own size and average, to find the overall average.

When NOT to use: For simple averages within a single group, or if you don't know the size of each group.

Memory Trick: "Total sum (total product of count and average) divided by total count." This is essentially a weighted average where counts are the weights.

🧠 Solved Examples: From Basics to Exam Level

Easy

Example 1: Arithmetic Mean

The marks obtained by 5 students in a test are 65, 70, 85, 60, and 75. Find their average marks.

View Step-by-Step Solution

Step 1: Identify the values and count.

Values (\(x_i\)): 65, 70, 85, 60, 75

Number of students (\(n\)): 5

Step 2: Calculate the sum of all values.

$$ \text{Sum} = 65 + 70 + 85 + 60 + 75 = 355 $$

Step 3: Apply the Arithmetic Mean formula.

$$ \text{Average} = \frac{\text{Sum}}{\text{Count}} = \frac{355}{5} = 71 $$

Answer: The average marks obtained by the students is 71.

Medium

Example 2: Weighted Average

A student's scores in three subjects are: Mathematics (85 marks, weight 3), Science (70 marks, weight 2), and English (60 marks, weight 1). Calculate the student's overall weighted average score.

View Step-by-Step Solution

Step 1: List values and their corresponding weights.

  • Mathematics: Value \(x_1 = 85\), Weight \(w_1 = 3\)
  • Science: Value \(x_2 = 70\), Weight \(w_2 = 2\)
  • English: Value \(x_3 = 60\), Weight \(w_3 = 1\)

Step 2: Calculate the sum of (weight × value) for each subject.

  • Math: \(3 \times 85 = 255\)
  • Science: \(2 \times 70 = 140\)
  • English: \(1 \times 60 = 60\)

Total Weighted Sum = \(255 + 140 + 60 = 455\)

Step 3: Calculate the sum of all weights.

Sum of Weights = \(3 + 2 + 1 = 6\)

Step 4: Apply the Weighted Average formula.

$$ \text{Weighted Average} = \frac{\text{Total Weighted Sum}}{\text{Sum of Weights}} = \frac{455}{6} \approx 75.83 $$

Answer: The student's overall weighted average score is approximately 75.83.

Hard

Example 3: Combined Average with Unknown Quantity

The average age of 15 boys in a class is 12 years. The average age of 10 girls in the same class is 11 years. Find the average age of the entire class.

View Step-by-Step Solution

Method 1: Using the Combined Average Formula

Step 1: Identify the given data for each group.

  • Boys: \(n_1 = 15\), \(Avg_1 = 12\) years
  • Girls: \(n_2 = 10\), \(Avg_2 = 11\) years

Step 2: Calculate the total sum of ages for each group.

  • Total age of boys = \(n_1 \times Avg_1 = 15 \times 12 = 180\) years
  • Total age of girls = \(n_2 \times Avg_2 = 10 \times 11 = 110\) years

Step 3: Calculate the total sum of ages for the entire class.

Total sum = \(180 + 110 = 290\) years

Step 4: Calculate the total number of students in the class.

Total students = \(n_1 + n_2 = 15 + 10 = 25\)

Step 5: Apply the Combined Average formula.

$$ \text{Combined Average} = \frac{\text{Total Sum}}{\text{Total Students}} = \frac{290}{25} = 11.6 \text{ years} $$

Method 2: Using the Deviation Method (Advanced Shortcut)

Step 1: Choose an assumed average. Let's choose the lowest average, which is 11 years (girls' average).

Step 2: Calculate the deviation of each group's average from the assumed average.

  • Girls: Average = 11. Deviation from assumed average = \(11 - 11 = 0\).
  • Boys: Average = 12. Deviation from assumed average = \(12 - 11 = +1\).

Step 3: Calculate the total deviation.

  • Girls' total deviation = \(10 \times 0 = 0\)
  • Boys' total deviation = \(15 \times (+1) = +15\)

Total Net Deviation = \(0 + 15 = +15\)

Step 4: Distribute the total deviation among all students.

Total students = \(15 + 10 = 25\)

Average deviation per student = \(15 / 25 = 0.6\)

Step 5: Calculate the combined average.

Combined Average = Assumed Average + Average deviation per student

$$ \text{Combined Average} = 11 + 0.6 = 11.6 \text{ years} $$

Answer: The average age of the entire class is 11.6 years.

Exam Level (SSC CGL Tier-1)

Example 4: Missing Value & Average

The average score of a cricketer in 10 matches is 55 runs. In the next three matches, he scores 60, 75, and 'X' runs respectively. If his new average after 13 matches becomes 60, find the value of 'X'.

View Step-by-Step Solution

Method 1: Using Total Sum

Step 1: Calculate the total runs in the first 10 matches.

Total runs (10 matches) = Average × Number of matches = \(55 \times 10 = 550\) runs.

Step 2: Calculate the new total number of matches and the new overall average.

New number of matches = \(10 + 3 = 13\)

New overall average = 60 runs

Step 3: Calculate the total runs after 13 matches.

New total runs (13 matches) = New Average × New Number of matches = \(60 \times 13 = 780\) runs.

Step 4: Set up an equation to find X.

Total runs (13 matches) = Total runs (first 10 matches) + Runs in 11th match + Runs in 12th match + Runs in 13th match

$$ 780 = 550 + 60 + 75 + X $$

$$ 780 = 685 + X $$

Step 5: Solve for X.

$$ X = 780 - 685 = 95 $$

Answer: The value of 'X' is 95 runs.

Method 2: Using Deviation Method (Advanced)

Step 1: Identify the initial average and the target average.

Initial average (10 matches) = 55

Target average (13 matches) = 60

Step 2: Calculate the total increase in average for the initial 10 matches.

Each of the first 10 matches needs to increase its score by \(60 - 55 = 5\) runs to reach the new average of 60.

Total increase needed from the first 10 matches = \(10 \times 5 = 50\) runs.

Step 3: Consider the scores of the new matches (60, 75, X).

For these 3 matches, their scores need to contribute to the new average of 60.

  • 11th match score: 60. Deviation from new average (60) = \(60 - 60 = 0\).
  • 12th match score: 75. Deviation from new average (60) = \(75 - 60 = +15\).
  • 13th match score: X. Deviation from new average (60) = \((X - 60)\).

Step 4: Set the total deviation to zero (or balance the deviations).

The total deviation from the new average (60) must be zero when considering all 13 matches.

Net deviation from previous matches + deviations from new matches = 0

$$ (\text{Contribution from initial 10 matches}) + (0) + (15) + (X - 60) = 0 $$

The "contribution" from initial 10 matches is the deficit needed to bring their average up to 60. This deficit is \(10 \times (55 - 60) = 10 \times (-5) = -50\).

So, the equation becomes:

$$ -50 + 0 + 15 + (X - 60) = 0 $$

$$ -35 + X - 60 = 0 $$

$$ X - 95 = 0 $$

$$ X = 95 $$

Answer: The value of 'X' is 95 runs.

⚡ Exam Tricks & Shortcuts: Boost Your Speed!

1. The Deviation Method (The King of Averages!)

This method is incredibly powerful for problems involving adding/removing items or combining groups. Instead of calculating sums, you work with deviations from an assumed average.

How it works:
1. Choose an "assumed average" (often one of the given averages or a round number close to them).
2. Calculate the deviation of each observation/group's average from this assumed average.
3. Multiply each deviation by its frequency/count to get total deviation for that group.
4. Sum up all total deviations to find the net deviation.
5. Divide the net deviation by the total number of observations/items.
6. Add this result to your assumed average to get the actual average.

Example (from Solved Example 3): 15 boys (avg 12), 10 girls (avg 11).
Assumed Average = 11 (girls' avg).
Boys: 15 students, average 12. Deviation = \(12 - 11 = +1\). Total deviation for boys = \(15 \times (+1) = +15\).
Girls: 10 students, average 11. Deviation = \(11 - 11 = 0\). Total deviation for girls = \(10 \times 0 = 0\).
Net Total Deviation = \(+15 + 0 = +15\).
Total students = \(15 + 10 = 25\).
Average deviation per student = \(+15 / 25 = +0.6\).
Combined Average = Assumed Average + Average deviation = \(11 + 0.6 = 11.6\).

Why it's fast: It minimizes large multiplication and keeps numbers small, reducing calculation errors.

2. Allegation or Mixture Method (For Two Groups)

This technique is a visual shortcut, especially useful for combined average problems involving two groups. It's often used in mixtures, but it's fundamentally about weighted averages.

How it works:
1. Place the individual averages of the two groups on the left and right.
2. Place the combined average in the center.
3. Subtract diagonally to find the differences, which represent the ratio of the quantities (weights) of the two groups.
$$\begin{array}{ccc} \text{Avg}_1 & & \text{Avg}_2 \\ & \searrow & \swarrow \\ & \text{Combined Avg} & \\ & \nearrow & \nwarrow \\ |\text{Combined Avg} - \text{Avg}_2| & : & |\text{Avg}_1 - \text{Combined Avg}| \end{array}$$ The ratio found is \(\text{Quantity}_1 : \text{Quantity}_2\).

Example (from Solved Example 3): 15 boys (avg 12), 10 girls (avg 11). Combined average 11.6.
$$\begin{array}{ccc} \text{Boys (12)} & & \text{Girls (11)} \\ & \searrow & \swarrow \\ & 11.6 & \\ & \nearrow & \nwarrow \\ |11.6 - 11| & : & |12 - 11.6| \\ 0.6 & : & 0.4 \end{array}$$ Ratio of Boys : Girls = \(0.6 : 0.4 = 6 : 4 = 3 : 2\).
This means if there are 3 parts boys, there are 2 parts girls. Total parts = 5.
Given total boys = 15, total girls = 10. Ratio \(15:10 = 3:2\). The method matches perfectly! This can be used to find one of the quantities or averages if others are given.

Why it's fast: It's a visual and quick way to find ratios or missing values in combined average problems.

3. Mental Math for Small Sets

For small sets of numbers, try to quickly find a central value and adjust. E.g., for 10, 12, 18, 20. Assume average is 15.
Deviations: \(10-15 = -5\), \(12-15 = -3\), \(18-15 = +3\), \(20-15 = +5\).
Net deviation = \(-5 - 3 + 3 + 5 = 0\).
So, the actual average is 15 + (0/4) = 15.
This works perfectly when deviations balance out easily.

⚠️ Common Mistakes & Pitfalls: Learn to Avoid Them!

1. Simply Averaging Averages

Mistake: When combining groups, calculating \( (Avg_1 + Avg_2) / 2 \) instead of using the weighted average formula.

How to Avoid: Always remember that unless the number of items/members in each group is identical, you cannot simply average their averages. Use the Combined Average formula (which is a weighted average).

2. Confusing Weight with Quantity/Count

Mistake: In weighted average problems, sometimes students might incorrectly use counts as weights when specific "weights" are provided, or vice-versa.

How to Avoid: Carefully read the problem statement. Understand what constitutes the "weight" – is it frequency, importance factor, or the actual quantity of items?

3. Calculation Errors (Arithmetic Blunders)

Mistake: Basic addition, subtraction, multiplication, or division errors, especially with large numbers or decimals.

How to Avoid: Practice mental math. Use estimation to check if your answer is in the right ballpark. In exams, double-check your calculations, especially the sum and the total count/sum of weights.

4. Misinterpreting "Average Speed"

Mistake: Assuming average speed for two equal distances (or times) is simply the average of the two speeds. (e.g., traveling to a place at 40 km/h and returning at 60 km/h, average speed is NOT 50 km/h).

How to Avoid: Average speed is calculated as \(\text{Total Distance} / \text{Total Time}\). This is a harmonic mean concept, but for exam purposes, stick to the basic definition. This is a common trap in Time, Speed & Distance problems. (For equal distance: \(2xy / (x+y)\), for equal time: \((x+y)/2\)).

5. Not Understanding the Impact of Outliers

Mistake: Failing to recognize that a single extremely high or low value (outlier) can drastically skew the arithmetic mean.

How to Avoid: While arithmetic mean is standard, be aware of its limitations. In complex scenarios, other measures like median might be more appropriate, but for competitive exams, just be prepared for problems where one value significantly changes the average.

📌 Summary: Averages at a Glance

  • Arithmetic Mean: \(\text{Sum} / \text{Count}\). Simple average, equal importance to all values.
  • Weighted Average: \(\sum (w_i \times x_i) / \sum w_i\). Used when values have different "importance" or "quantity."
  • Combined Average: \(\text{Total Sum} / \text{Total Count}\). Essential for finding the average of merged groups; essentially a weighted average where group sizes are weights.
  • Key Rules: Adding/removing an average value keeps average same. Uniform operations (add/sub/mul/div) on all values apply directly to the average.
  • Tricks: Deviation Method and Allegation Method are powerful shortcuts for speed and accuracy.

🚀 Quick Revision Box: Your Averages Cheatsheet

1. Arithmetic Mean:

$$ \text{Avg} = \frac{\text{Total Sum}}{\text{Total Count}} $$

2. Weighted Average:

$$ \text{W.Avg} = \frac{(w_1 x_1 + w_2 x_2 + \dots)}{(w_1 + w_2 + \dots)} $$

3. Combined Average:

$$ \text{Comb. Avg} = \frac{(n_1 Avg_1 + n_2 Avg_2)}{(n_1 + n_2)} $$

4. Effect of Adding/Removing 'k': Average \(\pm k\).

5. Effect of Multiplying/Dividing by 'k': Average \(\times k\) / \(\div k\).

6. Deviation Method: Assumed Avg + \(\frac{\text{Net Deviation}}{\text{Total Count}}\).

7. Allegation Method: For 2 groups, visually find ratio of quantities using differences from combined average.
