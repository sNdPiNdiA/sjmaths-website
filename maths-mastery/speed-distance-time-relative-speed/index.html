Speed, Distance, Time & Relative Speed (Average Speed)

Medium Difficulty 25-30 Mins Read High Exam Weightage Updated 2026

📘 Introduction

  • Time, Speed & Distance (TSD) is a fundamental topic in competitive exams, forming the base for many other concepts like Trains, Boats & Streams.
  • This microtopic focuses on the core relationship between Speed, Distance, and Time, along with crucial unit conversions and the concept of Average Speed, including scenarios where relative motion might be involved.
  • Mastering these basics is vital for solving a wide range of problems efficiently across SSC, Banking, Railway, and State PCS exams.

🎯 Learning Objectives

  • Define and understand the core relationship between Speed, Distance, and Time.
  • Proficiently perform unit conversions between km/hr and m/s.
  • Calculate Average Speed for various journey types (equal distances, equal times, general case).
  • Apply basic Relative Speed concepts in conjunction with average speed problems.
  • Utilize shortcuts and tricks to solve TSD problems quickly and accurately.

📝 Prerequisites

  • Basic Arithmetic: Addition, subtraction, multiplication, division, fractions, and decimals.
  • Algebra: Solving simple linear equations.
  • Ratio & Proportion: Understanding direct and inverse proportionality (beneficial for advanced problem-solving).

💡 Core Concepts

Speed, Distance & Time

  • Definition: These are three interrelated quantities describing motion.
  • Intuition:
    • Distance (D): How far an object travels.
    • Speed (S): How fast an object travels (distance covered per unit time).
    • Time (T): Duration for which the object travels.
  • Key Observation: If any two are known, the third can be found.
  • Memory Tip: Think of a heart: "D" is at the top point, "S" and "T" at the bottom points. `D = S \times T`.
  • Mini Example: If a car travels 100 km in 2 hours, its speed is $100 \text{ km} / 2 \text{ hours} = 50 \text{ km/hr}$.

Units & Conversions

  • Definition: Standard units for TSD. Consistency in units is crucial for correct calculations.
  • Intuition: Different problems use different units, requiring conversion to match.
  • Key Observation: The most common conversion is between km/hr and m/s.
  • Memory Tip: To go from a BIG unit (km/hr) to a small unit (m/s), multiply by a SMALL fraction (5/18). To go from a SMALL unit (m/s) to a BIG unit (km/hr), multiply by a BIG fraction (18/5).
Conversion Rule Example
km/hr to m/s Multiply by $5/18$ $36 \text{ km/hr} = 36 \times \frac{5}{18} = 10 \text{ m/s}$
m/s to km/hr Multiply by $18/5$ $15 \text{ m/s} = 15 \times \frac{18}{5} = 54 \text{ km/hr}$

Average Speed

  • Definition: The overall speed of an object over an entire journey, considering varying speeds and times. It's NOT simply the average of individual speeds.
  • Intuition: It tells us what constant speed would be needed to cover the total distance in the total time taken.
  • Key Observation: Always use the formula: Average Speed = Total Distance / Total Time.
  • Memory Tip: Think of the 'grand total' – total distance divided by total time.
  • Mini Example: A car travels 100 km at 50 km/hr and then 50 km at 25 km/hr. Total Distance = $100 + 50 = 150 \text{ km}$. Time 1 = $100/50 = 2 \text{ hrs}$. Time 2 = $50/25 = 2 \text{ hrs}$. Total Time = $2 + 2 = 4 \text{ hrs}$. Average Speed = $150/4 = 37.5 \text{ km/hr}$.

Relative Speed (Basic Introduction)

  • Definition: The speed of one object with respect to another. While this microtopic focuses on average speed, understanding relative motion helps in specific problem types.
  • Intuition: How quickly two objects approach or move away from each other.
  • Key Observation: Speeds add up when objects move towards or away from each other, and subtract when they move in the same direction. This concept is fundamental to problems involving meeting/crossing, which sometimes implicitly factor into average speed considerations over a full journey.
  • Memory Tip: "Opposite Add, Same Subtract" (OASS).
  • Mini Example: Car A moves at 60 km/hr and Car B at 40 km/hr.
    • If they move in the same direction: Relative Speed = $60 - 40 = 20 \text{ km/hr}$.
    • If they move in opposite directions: Relative Speed = $60 + 40 = 100 \text{ km/hr}$.

📏 Rules & Properties

Inverse Proportionality (Distance Constant)

  • Explanation: If the distance is constant, Speed is inversely proportional to Time. \(S \propto \frac{1}{T}\). If speed increases, time decreases.
  • Reason: Since \(D = S \times T\), if D is fixed, \(S = D/T\). So, $S_1 T_1 = S_2 T_2$.
  • Shortcut: If speed ratio is $S_1:S_2$, then time ratio for same distance is $T_1:T_2 = 1/S_1:1/S_2 = S_2:S_1$.
  • Example: If a person increases speed by 25% (ratio 4:5), time taken for the same journey will decrease in ratio 5:4.

Direct Proportionality (Time Constant)

  • Explanation: If the time is constant, Speed is directly proportional to Distance. \(S \propto D\). If speed increases, distance covered increases.
  • Reason: Since \(D = S \times T\), if T is fixed, \(D = S \times T\). So, \(D_1/S_1 = D_2/S_2\).
  • Shortcut: If speed ratio is $S_1:S_2$, then distance covered in same time is $D_1:D_2 = S_1:S_2$.
  • Example: If a car doubles its speed, it will cover double the distance in the same amount of time.

Average Speed (Equal Distances) - Harmonic Mean

  • Explanation: When a journey is covered in two or more parts of equal distance but at different speeds.
  • Reason: The general average speed formula \(\frac{\text{Total Distance}}{\text{Total Time}}\) simplifies to a harmonic mean.
  • Shortcut:
    • For 2 equal distances at speeds \(S_1, S_2\): \(\text{Avg Speed} = \frac{2S_1S_2}{S_1+S_2}\).
    • For 3 equal distances at speeds \(S_1, S_2, S_3\): \(\text{Avg Speed} = \frac{3S_1S_2S_3}{S_1S_2 + S_2S_3 + S_3S_1}\).
  • Example: A man travels from A to B at 20 km/hr and returns from B to A at 30 km/hr. Average Speed = \(\frac{2 \times 20 \times 30}{20 + 30} = \frac{1200}{50} = 24 \text{ km/hr}\).

Average Speed (Equal Times) - Arithmetic Mean

  • Explanation: When a journey is covered in two or more parts for equal durations of time but at different speeds.
  • Reason: The general average speed formula \(\frac{\text{Total Distance}}{\text{Total Time}}\) simplifies to an arithmetic mean.
  • Shortcut: For 'n' equal time intervals with speeds \(S_1, S_2, \dots, S_n\): \(\text{Avg Speed} = \frac{S_1 + S_2 + \dots + S_n}{n}\).
  • Example: A car travels for 2 hours at 40 km/hr and for another 2 hours at 60 km/hr. Average Speed = \(\frac{40 + 60}{2} = \frac{100}{2} = 50 \text{ km/hr}\).

📐 Formula Box

1. Fundamental Relationship

$$ D = S \times T $$
  • Meaning: Distance is the product of Speed and Time.
  • Variables: D = Distance, S = Speed, T = Time.
  • When to use: To find any one quantity when the other two are known.
  • Memory Trick: The D-S-T triangle. Put D at the top, S and T at the bottom. Cover the variable you need to find.
$$ S = \frac{D}{T} $$ $$ T = \frac{D}{S} $$

2. Unit Conversions

$$ \text{km/hr to m/s: } \text{Value (km/hr)} \times \frac{5}{18} $$ $$ \text{m/s to km/hr: } \text{Value (m/s)} \times \frac{18}{5} $$
  • Meaning: Conversion factors for common units.
  • Variables: Values in km/hr or m/s.
  • When to use: Ensure all quantities are in consistent units before calculation.
  • Memory Trick: \(5/18\) for smaller unit (m/s), \(18/5\) for larger unit (km/hr).

3. General Average Speed

$$ \text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}} $$
  • Meaning: The overall rate of travel for an entire journey.
  • Variables: Total Distance = Sum of all distances traveled; Total Time = Sum of all times taken.
  • When to use: Always applicable for average speed calculations. This is the primary definition.
  • Memory Trick: "Distance over Time" for average.

4. Average Speed (Equal Distances)

$$ \text{For 2 equal distances at speeds } S_1, S_2: \text{ Avg Speed} = \frac{2S_1S_2}{S_1+S_2} $$ $$ \text{For 3 equal distances at speeds } S_1, S_2, S_3: \text{ Avg Speed} = \frac{3S_1S_2S_3}{S_1S_2 + S_2S_3 + S_3S_1} $$
  • Meaning: Special cases where distances covered at different speeds are identical.
  • Variables: \(S_1, S_2, S_3\) are the speeds for each segment.
  • When to use: When the problem explicitly states or implies equal distances for different speed segments (e.g., A to B and back to A).
  • When NOT to use: When distances are unequal or times are equal.
  • Memory Trick: \(2S_1S_2/(S_1+S_2)\) is a common pattern for "return" journeys.

5. Average Speed (Equal Times)

$$ \text{For n equal time intervals at speeds } S_1, S_2, \dots, S_n: \text{ Avg Speed} = \frac{S_1 + S_2 + \dots + S_n}{n} $$
  • Meaning: When an object travels at different speeds for identical durations.
  • Variables: \(S_1, S_2, \dots, S_n\) are the speeds for each time segment. 'n' is the number of segments.
  • When to use: When the problem states or implies equal time intervals for different speed segments.
  • When NOT to use: When times are unequal or distances are equal.
  • Memory Trick: Simple arithmetic mean of speeds when times are equal.

6. Relative Speed (Basic)

$$ \text{Objects moving in SAME direction: } S_{\text{relative}} = |S_1 - S_2| $$ $$ \text{Objects moving in OPPOSITE direction: } S_{\text{relative}} = S_1 + S_2 $$
  • Meaning: The speed at which objects approach or recede from each other.
  • Variables: \(S_1, S_2\) are the individual speeds of the objects.
  • When to use: To calculate how quickly distance changes between two moving objects. Useful in understanding scenarios that might lead to average speed problems (e.g., A and B travel towards each other, then one continues).
  • When NOT to use: For direct calculation of *average speed* of a single object, unless the relative motion is part of a larger average speed problem framework.
  • Memory Trick: Opposite Add, Same Subtract (OASS).

🧠 Solved Examples

Easy

Example 1: Basic S, D, T

A car travels a distance of 180 km in 4 hours. What is its speed?
View Step-by-Step Solution

Given:

  • Distance (D) = 180 km
  • Time (T) = 4 hours

Step 1: Identify the formula.

We need to find Speed (S), so use $S = \frac{D}{T}$.

Step 2: Substitute values and calculate.

$$ S = \frac{180 \text{ km}}{4 \text{ hours}} = 45 \text{ km/hr} $$

Answer: The speed of the car is 45 km/hr.

Medium

Example 2: Unit Conversion & Time Calculation

A train is moving at a speed of 90 km/hr. How much time will it take to cover a distance of 500 meters?
View Step-by-Step Solution

Given:

  • Speed (S) = 90 km/hr
  • Distance (D) = 500 meters

Step 1: Ensure consistent units.

Convert Speed from km/hr to m/s, as distance is in meters.

$$ S = 90 \text{ km/hr} \times \frac{5}{18} = 5 \times 5 = 25 \text{ m/s} $$

Step 2: Identify the formula for Time.

We need to find Time (T), so use $T = \frac{D}{S}$.

Step 3: Substitute values and calculate.

$$ T = \frac{500 \text{ m}}{25 \text{ m/s}} = 20 \text{ seconds} $$

Answer: The train will take 20 seconds to cover 500 meters.

Hard

Example 3: Average Speed (Equal Distances)

A man travels from point A to B at 40 km/hr and returns from B to A at 60 km/hr. What is his average speed for the entire journey?
View Step-by-Step Solution

Given:

  • Speed from A to B ($S_1$) = 40 km/hr
  • Speed from B to A ($S_2$) = 60 km/hr

Step 1: Recognize the scenario.

The man travels the same distance (A to B and B to A) at two different speeds. This is a case of equal distances.

Step 2: Apply the shortcut formula for two equal distances.

$$ \text{Average Speed} = \frac{2S_1S_2}{S_1+S_2} $$

Step 3: Substitute values and calculate.

$$ \text{Average Speed} = \frac{2 \times 40 \times 60}{40 + 60} = \frac{4800}{100} = 48 \text{ km/hr} $$

Alternative (General Method):

Step 1: Assume a convenient distance.

Let the distance from A to B be D. We can take D as the LCM of 40 and 60, which is 120 km. Total Distance = D (A to B) + D (B to A) = $120 + 120 = 240 \text{ km}$.

Step 2: Calculate time for each segment.

  • Time A to B ($T_1$) = Distance / Speed = $120 / 40 = 3 \text{ hours}$.
  • Time B to A ($T_2$) = Distance / Speed = $120 / 60 = 2 \text{ hours}$.

Step 3: Calculate Total Time.

Total Time = $T_1 + T_2 = 3 + 2 = 5 \text{ hours}$.

Step 4: Calculate Average Speed.

$$ \text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}} = \frac{240 \text{ km}}{5 \text{ hours}} = 48 \text{ km/hr} $$

Answer: The average speed for the entire journey is 48 km/hr.

Exam Level

Example 4: Average Speed (Mixed Scenario) - SSC CGL Tier-I

A train travels the first 100 km at a speed of 50 km/hr, the next 200 km at 40 km/hr, and the final 150 km at 30 km/hr. Find the average speed of the train for the entire journey.
View Step-by-Step Solution

Given:

  • Segment 1: $D_1 = 100 \text{ km}$, $S_1 = 50 \text{ km/hr}$
  • Segment 2: $D_2 = 200 \text{ km}$, $S_2 = 40 \text{ km/hr}$
  • Segment 3: $D_3 = 150 \text{ km}$, $S_3 = 30 \text{ km/hr}$

Step 1: Calculate Total Distance.

Total Distance = $D_1 + D_2 + D_3 = 100 + 200 + 150 = 450 \text{ km}$.

Step 2: Calculate Time for each segment.

  • $T_1 = D_1 / S_1 = 100 / 50 = 2 \text{ hours}$.
  • $T_2 = D_2 / S_2 = 200 / 40 = 5 \text{ hours}$.
  • $T_3 = D_3 / S_3 = 150 / 30 = 5 \text{ hours}$.

Step 3: Calculate Total Time.

Total Time = $T_1 + T_2 + T_3 = 2 + 5 + 5 = 12 \text{ hours}$.

Step 4: Calculate Average Speed using the general formula.

$$ \text{Average Speed} = \frac{\text{Total Distance}}{\text{Total Time}} = \frac{450 \text{ km}}{12 \text{ hours}} $$

$$ \text{Average Speed} = \frac{150}{4} = \frac{75}{2} = 37.5 \text{ km/hr} $$

Answer: The average speed of the train for the entire journey is 37.5 km/hr.

⚡ Exam Tricks & Shortcuts

1. LCM Method for Distance (When Distance is Unknown)

  • When to use: For average speed problems where distances are equal or proportional, but the actual distance is not given (e.g., A to B and B to A).
  • Trick: Assume the distance to be the LCM (Least Common Multiple) of the given speeds. This makes time calculations integer values, simplifying arithmetic.
  • Example: A car travels at 20 km/hr for some distance and returns at 30 km/hr. Find average speed.
    • LCM of 20 and 30 is 60. Assume D = 60 km.
    • Time to go = $60/20 = 3$ hrs.
    • Time to return = $60/30 = 2$ hrs.
    • Total Distance = $60+60 = 120$ km.
    • Total Time = $3+2 = 5$ hrs.
    • Average Speed = $120/5 = 24$ km/hr.

2. Ratio Method (Distance Constant)

  • When to use: When distance is constant, and speed changes, impacting time.
  • Trick: If speed ratio is \(S_1:S_2\), then time ratio for the same distance is \(T_1:T_2 = S_2:S_1\). Use this to find changes in time or original time.
  • Example: A man reduces his speed to 3/4th of his original speed and reaches his destination 20 minutes late. Find his usual time.
    • Speed ratio \(S_{usual}:S_{new} = 1 : 3/4 = 4:3\).
    • Time ratio \(T_{usual}:T_{new} = 3:4\).
    • Difference in time units = $4-3 = 1$ unit.
    • 1 unit = 20 minutes.
    • Usual time (3 units) = $3 \times 20 = 60$ minutes.

3. Shortcut for 2 Speeds and Fixed Total Time (Relative Speed implication)

  • When to use: When two objects travel for the same total time, but at different speeds or in different directions, and you need to find distances or overall movement. Or, if total time is fixed for a round trip with different speeds.
  • Trick: If an object travels for total time 'T' with speed \(S_1\) for time \(t_1\) and speed \(S_2\) for time \(t_2\), where \(t_1 + t_2 = T\), then Total Distance = \(S_1 t_1 + S_2 t_2\). This is not a 'trick' but a direct application. However, often problems frame it as two people moving for a fixed total time, meeting or crossing.
  • Example: A person travels for 3 hours. For the first 1.5 hours, they travel at 50 km/hr. For the next 1.5 hours, they travel at 70 km/hr.
    • This is an Equal Time scenario. Average Speed = $(50+70)/2 = 60$ km/hr.
    • Total Distance = Average Speed * Total Time = $60 \times 3 = 180$ km.
    This highlights that when times are equal, the average speed is simple, which then can be used to find total distance easily.

⚠️ Common Mistakes & Pitfalls

1. Incorrect Unit Conversions

  • Mistake: Forgetting to convert units (e.g., using km/hr with meters, or hours with seconds).
  • Avoidance: Always check units at the beginning of the problem. Convert all values to a consistent system (e.g., m/s or km/hr) before calculation. Double-check multiplication factors (5/18 or 18/5).

2. Averaging Speeds Directly

  • Mistake: Calculating average speed as a simple arithmetic mean of individual speeds (e.g., $(S_1+S_2)/2$) when distances are not equal or times are not equal.
  • Avoidance: Remember the golden rule: Average Speed = Total Distance / Total Time. Only use the arithmetic mean shortcut when times are explicitly equal.

3. Confusing Total Distance with Single Segment Distance

  • Mistake: In problems like "A to B and back to A", using only 'D' as total distance instead of '2D'.
  • Avoidance: Clearly define total distance for the entire journey. For a round trip, if distance one way is 'D', total distance is '2D'.

4. Not Accounting for Rest Time/Stoppages

  • Mistake: In problems involving stoppages, only considering 'running time' for calculations when 'total journey time' is required, or vice-versa.
  • Avoidance: Differentiate between 'speed without stoppage' and 'speed with stoppage'. The latter incorporates rest time into overall journey duration.

📌 Summary

  • Speed, Distance, Time (S, D, T) are interconnected: \(D = S \times T\).
  • Unit Conversion: \(1 \text{ km/hr} = \frac{5}{18} \text{ m/s}\) and \(1 \text{ m/s} = \frac{18}{5} \text{ km/hr}\).
  • Average Speed: Always calculate as \(\frac{\text{Total Distance}}{\text{Total Time}}\).
  • Special Cases for Average Speed:
    • Equal Distances (\(S_1, S_2\)): \(\frac{2S_1S_2}{S_1+S_2}\) (Harmonic Mean).
    • Equal Times (\(S_1, S_2\)): \(\frac{S_1+S_2}{2}\) (Arithmetic Mean).
  • Relative Speed (Basic): Speeds add in opposite directions, subtract in same direction.
  • Proportionality:
    • D constant: \(S \propto \frac{1}{T}\) (\(S_1:S_2 \implies T_2:T_1\)).
    • T constant: \(S \propto D\).
    • S constant: \(D \propto T\).

✅ Key Takeaways

  • Always start by ensuring consistent units (all km/hr or all m/s).
  • The universal formula for average speed is Total Distance / Total Time. Learn this first, then the shortcuts.
  • Recognize scenarios of equal distances (e.g., return journey) or equal times to apply specific average speed formulas.
  • For problems without explicit distances, assume a distance using the LCM method to simplify calculations.
  • Practice ratio-based problems for a deeper understanding of speed-time proportionality.
