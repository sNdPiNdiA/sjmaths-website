Time-based Mixtures in Work Problems

Medium Difficulty 25-30 Mins Read High Exam Weightage Updated 2026

📘 Introduction to Time-based Mixtures in Work Problems

This microtopic extends basic Time & Work by introducing dynamic scenarios where the number of workers, their efficiency, or their working hours change over time. It involves understanding how work progresses when individuals or groups join, leave, or alternate tasks.

  • Exam Relevance: A highly frequent and scoring topic in exams like SSC CGL/CHSL/MTS/CPO/GD, Railway NTPC/Group D, Banking IBPS PO/Clerk/RRB, CDS, CAPF, State PCS, and Police exams.
  • Question Type: Typically involves calculating remaining time, total time taken, or the number of workers required for a modified task.

🎯 Learning Objectives

  • Understand and apply the concept of variable workforce in Time & Work problems.
  • Master calculations involving workers joining or leaving a task at different intervals.
  • Efficiently solve problems where individuals or groups perform work on an alternating basis.
  • Utilize the MDH rule effectively for dynamic work scenarios.
  • Develop strategies to tackle complex exam-level questions involving multiple changes in workforce.

📝 Prerequisites

  • Basic Time & Work Concepts: Understanding work, time, and efficiency.
  • LCM Method: Ability to find total work using the Least Common Multiple of individual times.
  • MDH Rule: Knowledge of the formula \((M_1D_1H_1)/W_1 = (M_2D_2H_2)/W_2\).
  • Unitary Method: Calculating work done per day/hour by an individual.
  • Fractions & Percentages: Comfort with calculations involving parts of work.

💡 Core Concepts

Variable Workforce: Joining & Leaving

Definition: Problems where the number of workers engaged in a task changes throughout its duration as some workers join or leave.

Intuition: Think of it as phases. Calculate work done in each phase with its respective workforce, then add up or subtract from total work.

  • Key Observations:
    • The total work remains constant unless specified otherwise.
    • Efficiency per person is generally assumed constant unless stated otherwise.
    • Focus on the remaining work after each change in the workforce.
  • Memory Tip: "Phase by Phase, Work it Out." Break the problem into distinct time intervals based on workforce changes.
  • Mini Example: A can do a work in 10 days. B can do it in 15 days. A works for 3 days, then B joins him.
    Solution: A's 1-day work = 1/10. Work by A in 3 days = 3/10. Remaining work = 1 - 3/10 = 7/10. (A+B)'s 1-day work = 1/10 + 1/15 = 1/6. Now find time for (A+B) to complete 7/10 work.

Alternating Work

Definition: Scenarios where two or more individuals/groups work on a task, but they do so in turns, not simultaneously.

Intuition: The total work is completed in cycles. Calculate the work done in one complete cycle (e.g., 2 days for two people alternating) and then find how many cycles are needed.

  • Key Observations:
    • The order of working is crucial.
    • Often, a full cycle (e.g., A works day 1, B works day 2, then A works day 3...) repeats work done over a period.
    • Handle the remaining work carefully after full cycles, as the last few days might not complete a full cycle.
  • Memory Tip: "Cycle & Remainder." Find work per cycle, then tackle the leftover work person-by-person.
  • Mini Example: A can do a work in 10 days, B in 15 days. They work on alternate days, starting with A.
    Solution: A's 1-day work = 1/10. B's 1-day work = 1/15. In 2 days (1 cycle): Work = 1/10 + 1/15 = 1/6.

MDH Rule Adaptation for Mixtures

Definition: Extending the Men-Days-Hours rule to situations where M, D, or H change within the project.

Intuition: The 'work' part in MDH can be an amount, or the completion of a task. When the workforce changes, we apply the rule for specific segments of work or relate efficiencies.

  • Key Observations:
    • The core formula is \((M_1D_1H_1)/W_1 = (M_2D_2H_2)/W_2\).
    • If only part of the work is done, \(W_1\) will be a fraction.
    • Used when comparing work scenarios (e.g., how many more men needed to finish faster).
  • Memory Tip: "Consistent Ratio." The ratio (Man-Days-Hours) / Work remains constant regardless of changes.
  • Mini Example: 10 men can build a wall in 20 days. If 5 men leave after 10 days, how many more days will it take?
    Solution: Total work = 10 men * 20 days = 200 man-days. Work done in 10 days = 10 men * 10 days = 100 man-days. Remaining work = 100 man-days. Remaining men = 5. Days needed = 100/5 = 20 days.

📏 Rules & Properties

Remaining Work Principle

Explanation: When a task is partially completed by one group, and then another group (or a modified group) takes over, focus on the uncompleted portion of work.

Reason: The total work is typically constant. Subtracting work done from total work gives the remaining work that needs to be finished.

Shortcut:
1. Calculate Total Work (often using LCM method).
2. Calculate Work Done in the initial phase.
3. Remaining Work = Total Work - Work Done.
4. Calculate New Efficiency of the changed workforce.
5. Time for Remaining Work = Remaining Work / New Efficiency.

Exception: Not applicable if work is explicitly stated to be increasing or decreasing, or if the "work" itself changes.

Example: A, B, C can do a work in 10, 12, 15 days. A and B start, C joins after 2 days.
Solution: Total work (LCM of 10,12,15) = 60 units. A's eff = 6 u/d, B's eff = 5 u/d. (A+B)'s 2-day work = (6+5)*2 = 22 units. Remaining work = 60 - 22 = 38 units.

Proportionality of Work, Men, Days, Hours

Explanation: The amount of work done is directly proportional to the number of men, days, and hours worked. In simpler terms, more men/days/hours mean more work, or less time needed for the same work.

Reason: This is the fundamental basis of the MDH rule. If one factor increases, work increases proportionally, or if work is constant, another factor must decrease.

Shortcut: For problems where the *type* of work is the same: \(\frac{M_1 D_1 H_1}{W_1} = \frac{M_2 D_2 H_2}{W_2}\).

Exception: Does not hold if efficiency varies between men or if the work itself has different levels of difficulty per unit.

Example: 10 men work 8 hours a day for 15 days to complete 2/3 of a work. How many additional men are required to complete the remaining work in 5 days, working 10 hours a day?
Solution: Apply the MDH formula by setting up the equation for both scenarios, considering \(W_1 = 2/3\) and \(W_2 = 1/3\).

📐 Formula Box

$$ \text{Total Work} = \text{Efficiency} \times \text{Time} $$

Meaning: The fundamental relationship between work, efficiency (rate of work), and time taken.

Variables:

  • \(\text{Total Work}\): The entire task to be completed (often taken as 1 unit or an LCM value).
  • \(\text{Efficiency}\): Work done per unit of time (e.g., per day, per hour).
  • \(\text{Time}\): Total time taken to complete the work.

When to use: To find any one variable when the other two are known, especially when dealing with individual efficiencies or combined efficiencies.

When NOT to use: Directly for comparing different work amounts or different work types without efficiency adjustments.

Memory Trick: "WET" triangle (Work on top, Efficiency and Time at bottom, side-by-side). \(W = E \times T\).

$$ \frac{M_1 D_1 H_1}{W_1} = \frac{M_2 D_2 H_2}{W_2} = \text{Constant} $$

Meaning: The product of Men, Days, and Hours divided by the Work done is a constant for a given efficiency level.

Variables:

  • \(M\): Number of Men (or workers/units of workforce).
  • \(D\): Number of Days.
  • \(H\): Number of Hours per day.
  • \(W\): Amount of Work done.
  • Subscripts 1 and 2 denote two different scenarios or phases.

When to use: Comparing two scenarios involving changes in men, days, hours, or work. Essential for problems with variable workforce.

When NOT to use: If the efficiency of men changes (e.g., A is twice as efficient as B), then M needs to be adjusted for efficiency (e.g., 1 A-man = 2 B-men).

Memory Trick: "MDH over W, for World-class problems!"

🧠 Solved Examples

Easy

Example 1: Workers Joining

A can do a piece of work in 20 days. B can do it in 30 days. A starts the work alone and after 5 days, B joins him. In how many more days will the work be completed?

View Step-by-Step Solution

Step 1: Calculate individual efficiencies and total work.

  • LCM of 20 and 30 is 60 units. Let Total Work = 60 units.
  • A's 1-day efficiency = \(60/20 = 3\) units/day.
  • B's 1-day efficiency = \(60/30 = 2\) units/day.

Step 2: Calculate work done by A alone.

  • A works for 5 days alone.
  • Work done by A in 5 days = \(5 \times 3 = 15\) units.

Step 3: Calculate remaining work.

  • Remaining Work = Total Work - Work done by A = \(60 - 15 = 45\) units.

Step 4: Calculate combined efficiency and time for remaining work.

  • When B joins A, their combined efficiency = A's efficiency + B's efficiency = \(3 + 2 = 5\) units/day.
  • Time taken to complete remaining 45 units = Remaining Work / Combined Efficiency = \(45 / 5 = 9\) days.

Answer: The work will be completed in 9 more days.

Medium

Example 2: Workers Leaving

12 men can complete a work in 36 days. After 24 days, 4 men leave the work. In how many days will the remaining work be completed by the rest of the men?

View Step-by-Step Solution

Step 1: Calculate total work.

  • Total Work = Number of Men \(\times\) Number of Days = \(12 \times 36 = 432\) man-days.

Step 2: Calculate work done in the initial period.

  • Initial number of men = 12.
  • Days worked = 24.
  • Work done in 24 days = \(12 \times 24 = 288\) man-days.

Step 3: Calculate remaining work.

  • Remaining Work = Total Work - Work done = \(432 - 288 = 144\) man-days.

Step 4: Calculate new workforce and time for remaining work.

  • Men who left = 4.
  • Remaining men = \(12 - 4 = 8\) men.
  • Time taken by 8 men to complete 144 man-days = Remaining Work / Remaining Men = \(144 / 8 = 18\) days.

Answer: The remaining work will be completed in 18 days.

Hard

Example 3: Alternating Work with Efficiency

P can complete a work in 15 days, and Q can complete the same work in 20 days. They work on alternate days, starting with P. If they are paid Rs. 4500 for the total work, what is Q's share?

View Step-by-Step Solution

Step 1: Calculate individual efficiencies and total work.

  • LCM of 15 and 20 is 60 units. Let Total Work = 60 units.
  • P's 1-day efficiency = \(60/15 = 4\) units/day.
  • Q's 1-day efficiency = \(60/20 = 3\) units/day.

Step 2: Calculate work done in one cycle.

  • They work on alternate days, starting with P.
  • Day 1: P works = 4 units.
  • Day 2: Q works = 3 units.
  • Work done in 2 days (1 cycle) = \(4 + 3 = 7\) units.

Step 3: Determine number of full cycles and remaining work.

  • Divide Total Work by Work per cycle: \(60 / 7 = 8\) with a remainder of \(4\).
  • So, 8 full cycles are completed. Days for 8 cycles = \(8 \times 2 = 16\) days.
  • Work done in 8 cycles = \(8 \times 7 = 56\) units.
  • Remaining Work = \(60 - 56 = 4\) units.

Step 4: Complete remaining work.

  • After 8 cycles (16 days), it's P's turn (Day 17).
  • P works on Day 17 and completes 4 units (since P's efficiency is 4 units/day).
  • The remaining 4 units are completed by P in 1 day.
  • Total time taken = \(16 + 1 = 17\) days.

Step 5: Calculate individual work done and share.

  • P worked on days 1, 3, 5, 7, 9, 11, 13, 15, 17. So P worked for 9 days.
  • Work done by P = \(9 \times 4 = 36\) units.
  • Q worked on days 2, 4, 6, 8, 10, 12, 14, 16. So Q worked for 8 days.
  • Work done by Q = \(8 \times 3 = 24\) units.
  • Total work = \(36 + 24 = 60\) units (matches total work).
  • Share is proportional to work done.
  • Q's Share = \(\frac{\text{Work done by Q}}{\text{Total Work}} \times \text{Total Payment} = \frac{24}{60} \times 4500 = \frac{2}{5} \times 4500 = 2 \times 900 = \text{Rs. } 1800\).

Answer: Q's share is Rs. 1800.

Exam Level (SSC CGL)

Example 4: Combined Joining & Leaving with MDH

20 men can complete a project in 30 days. They started the work, but after 10 days, 5 men left. After another 10 days, 10 more men joined. In how many total days will the project be completed?

View Step-by-Step Solution

Step 1: Calculate Total Work.

  • Total Work = \(20 \text{ men} \times 30 \text{ days} = 600\) man-days.

Step 2: Work done in Phase 1.

  • Initial men = 20.
  • Days worked = 10.
  • Work done in Phase 1 = \(20 \times 10 = 200\) man-days.
  • Remaining work = \(600 - 200 = 400\) man-days.
  • Total days passed = 10 days.

Step 3: Work done in Phase 2.

  • After 10 days, 5 men left.
  • Men remaining = \(20 - 5 = 15\) men.
  • These 15 men work for "another 10 days".
  • Work done in Phase 2 = \(15 \times 10 = 150\) man-days.
  • Remaining work = \(400 - 150 = 250\) man-days.
  • Total days passed = \(10 \text{ (Phase 1)} + 10 \text{ (Phase 2)} = 20\) days.

Step 4: Work done in Phase 3.

  • After another 10 days (total 20 days passed), 10 more men joined.
  • Men now = \(15 + 10 = 25\) men.
  • Time to complete remaining 250 man-days = Remaining Work / Men = \(250 / 25 = 10\) days.

Step 5: Calculate Total Days.

  • Total Days = Days in Phase 1 + Days in Phase 2 + Days in Phase 3
  • Total Days = \(10 + 10 + 10 = 30\) days.

Answer: The project will be completed in a total of 30 days.

⚡ Exam Tricks & Shortcuts

LCM Method for Efficiency Changes

Trick: When individual times are given, use the LCM to determine total work and per-day efficiency. This allows for quick calculation of work done by varying groups.

How it works: Instead of fractions, you deal with whole numbers (units of work), making calculations faster and less error-prone.

Example: A takes 10 days, B takes 12 days. A works 3 days, B joins.
LCM(10,12) = 60 units. A=6u/d, B=5u/d. A's 3-day work = 18 units. Remaining = 42 units. (A+B) eff = 11u/d. Days for remaining = 42/11 days.

Direct Man-Day Calculation (MDH Extension)

Trick: For problems where only men and days change (without hours/work amount), assume 1 man-day = 1 unit of work. This simplifies the MDH formula.

How it works: Total work = M x D. Calculate work done in phases and subtract from total. Remaining work / new men = remaining days.

Example: 20 men in 30 days. After 10 days, 5 leave.
Total = 600 man-days. 1st 10 days = 20x10 = 200. Remaining = 400. Men left = 15. Days = 400/15.

Cycle Analysis for Alternating Work

Trick: For alternating work, identify the repeating cycle and calculate the work done within one complete cycle. Use this to determine the number of full cycles and then handle the remainder.

How it works: \( \text{No. of Cycles} = \lfloor \text{Total Work} / \text{Work per Cycle} \rfloor \). The remaining work is done by the person next in line.

Example: A (5u/d), B (4u/d) alternate. Total work 47 units, A starts.
1 cycle (A+B, 2 days) = 9 units. Full cycles = \( \lfloor 47/9 \rfloor = 5 \). Work in 5 cycles = 45 units. Days = \(5 \times 2 = 10\) days. Remaining work = 2 units. A does next 2 units. Total days = \(10 + 1 = 11\) days.

⚠️ Common Mistakes & Pitfalls

  • Confusing Total Time vs. Remaining Time: Read the question carefully. Some ask for total days from start, others for additional days.
  • Incorrectly Calculating Remaining Work: Always subtract work done from the *total* work, not from a previous remaining work amount without proper tracking.
  • Mistakes in Alternating Order: In alternating work, ensure you correctly identify whose turn it is to work after each cycle or for the remaining work.
  • Forgetting to Adjust Man-Power: When workers join or leave, remember to update the number of men working for the subsequent phase of work.
  • Ignoring Efficiency Differences: If workers have different efficiencies, simply counting "men" is not enough. Convert them to "equivalent men" or use their individual efficiencies (e.g., A is twice as efficient as B, then 1 A = 2 B).
  • Arithmetic Errors: These problems involve multiple calculations. Double-check subtractions, divisions, and multiplications.

📌 Summary

  • Work = Efficiency \(\times\) Time: Foundation for all problems.
  • LCM Method: Best for finding Total Work and individual efficiencies when times are given.
  • Variable Workforce: Track work done in phases, update men/efficiency, then calculate for remaining work.
  • Alternating Work: Calculate work in one full cycle, determine number of cycles, then handle the remainder. Order matters!
  • MDH Rule: \(\frac{M_1 D_1 H_1}{W_1} = \frac{M_2 D_2 H_2}{W_2}\) is powerful for comparing changing scenarios.
  • Remaining Work: Always focus on the uncompleted portion after a change in workforce.

Quick Revision: Time-based Mixtures in Work Problems

1. Basic Relation: Work = Efficiency × Time

2. Total Work (LCM Method): Find LCM of individual times.
Ex: A=10 days, B=15 days. Total Work = LCM(10,15) = 30 units.
A's eff = 3 u/d, B's eff = 2 u/d.

3. Workers Joining/Leaving:
- Calculate work done in Phase 1 (initial group).
- Remaining Work = Total Work - Work done.
- Adjust workforce (add/subtract men) and calculate new combined efficiency.
- Time for remaining = Remaining Work / New Combined Efficiency.

4. Alternating Work:
- Identify one full cycle (e.g., A then B = 2 days).
- Calculate work done in one cycle.
- Divide Total Work by Work per Cycle to find full cycles and remainder.
- Add days for full cycles, then calculate days for remainder turn-by-turn.

5. MDH Rule for Comparison:
$$ \frac{M_1 D_1 H_1}{W_1} = \frac{M_2 D_2 H_2}{W_2} $$
- Use when Men, Days, Hours, or Work amount changes across scenarios.
- \(W\) can be a fraction (e.g., 1/2 of work).

6. Efficiency Ratios: If A is twice as efficient as B, then A does 2 units of work while B does 1 unit in the same time. Use this to adjust 'men' if needed.

7. Key Mantra: Break down complex problems into simpler phases. Track Total Work, Work Done, Remaining Work, and Current Workforce at each step.

🚀 Key Takeaways

  • Mastering these dynamic problems requires a solid understanding of basic Time & Work principles combined with meticulous tracking of work progress.
  • The LCM method simplifies calculations by converting fractional work into integer units, reducing errors.
  • Always identify the total work, then calculate work done in stages as the workforce changes.
  • For alternating work, think in 'cycles' and then address the leftover work individually.
  • Practice multiple variations, especially those involving efficiency differences and complex joining/leaving scenarios, to build speed and accuracy.
