Dense set

A subset $A$ of a metric space $(X, d)$ is said to be dense in $X$ if its closure equals the entire space, i.e., $\overline{A} = X$, meaning every point in $X$ is either in $A$ or is a limit point of $A$.

Definition and statement

Definition and Characterization of Dense Sets
Let $(X, d)$ be a metric space. A subset $D \subset X$ is dense in $X$ if and only if for every $x \in X$ and for every $\epsilon > 0$, the open ball $B_\epsilon(x)$ contains at least one point of $D$, that is, $B_\epsilon(x) \cap D \neq \emptyset$. Equivalently, $\overline{D} = X$.

📐 Geometric Interpretation

Geometrically, a dense set leaves no 'gaps' or empty patches in the ambient space. No matter how microscopically small an open neighborhood or interval you carve out, it is guaranteed to intersect the dense set.

⚙️ Algebraic & Structural Meaning

Algebraically and analytically, dense sets allow approximation of arbitrary real elements by simpler structured sets (such as rationals or polynomials), forming the backbone of completion and integration theories.

Useful results and shortcuts

Use these identities and results when their conditions apply:

01

Rational Density in $\mathbb{R}$

$$ \forall x, y \in \mathbb{R} \text{ with } x < y, \exists q \in \mathbb{Q} \text{ such that } x < q < y $$

Rule: Between any two distinct real numbers, there lies infinitely many rational and irrational numbers.

Application: Directly tested in UP TGT/PGT to check true/false statements regarding topological properties of $\mathbb{Q}$ and $\mathbb{R} \setminus \mathbb{Q}$.
02

Closure Test for Denseness

$$ D \text{ is dense in } X \iff \text{Int}(X \setminus D) = \emptyset $$

Rule: To prove a set is dense, show that its complement has an empty interior.

Application: Standard elimination trick for advanced topological MCQ options.
03

Countable Dense Subsets (Separability)

$$ \overline{\mathbb{Q}} = \mathbb{R}, \quad \mathbb{Q} \text{ is countable} $$

Rule: $\mathbb{R}$ is separable because it contains $\mathbb{Q}$ as a countable dense subset.

04

Finite Union of Dense Sets

$$ D_1, D_2 \text{ dense open sets} \implies D_1 \cap D_2 \text{ is dense} $$

Rule: By Baire Category Theorem, countable intersections of dense open sets in complete metric spaces are dense.

Application: Advanced PGT level question regarding Baire Category properties.
05

Range of Continuous Functions on Dense Sets

$$ f, g: X \to Y \text{ continuous}, \quad f|_D = g|_D \text{ and } \overline{D} = X \implies f = g $$

Rule: If two continuous functions agree on a dense set, they agree everywhere.

Application: Used in functional analysis extensions and advanced real analysis items.
06

Rapid Elimination Trick

$$ A \subset B \text{ and } A \text{ is dense in } X \implies B \text{ is dense in } X $$

Rule: Any superset of a dense set is automatically dense. Instantly check smaller sets first.

Application: Saves up to 40 seconds on complex multiple-statement assertion questions.

Common errors and counterexamples

These examples show how a conclusion can fail when a condition is missing:

⚠️ COMMON ERROR #01

Confusing Dense Sets with Open Sets

Common Pitfall: Candidates assume dense sets must be open (e.g., $\mathbb{Q}$ is dense in $\mathbb{R}$ but is neither open nor closed).

Counterexample: \mathbb{Q} \text{ in } \mathbb{R}

Why it fails: $\mathbb{Q}$ has empty interior, so it is not open, yet its closure is all of $\mathbb{R}$, making it dense.

🛡️ Exam Defense: Remember: Denseness is a closure property ($\overline{D} = X$), whereas openness is an interior property.
⚠️ COMMON ERROR #02

Intersection of Dense Sets

Common Pitfall: Assuming the intersection of any two dense sets is always dense without topological restrictions.

Counterexample: D_1 = \mathbb{Q}, \; D_2 = \mathbb{R} \setminus \mathbb{Q}

Why it fails: $D_1$ and $D_2$ are both dense in $\mathbb{R}$, but their intersection is $\emptyset$, which is nowhere dense.

🛡️ Exam Defense: Intersection of dense sets is dense only if the sets are open (or by Baire Category theorem under completeness).

Solved examples

Each problem includes a full solution and a shorter method:

CANONICAL PROBLEM 01 Dual-Method Breakdown

Which of the following sets is dense in the metric space $(\mathbb{R}, d_{usual})$?

(A) $\mathbb{Z}$(B) $\mathbb{Q}$(C) $(0, 1)$(D) Finite subsets of $\mathbb{R}$
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Step 1: Check the closure of each option. Step 2: $\overline{\mathbb{Z}} = \mathbb{Z} \neq \mathbb{R}$. Step 3: $\overline{\mathbb{Q}} = \mathbb{R}$. Step 4: $\overline{(0, 1)} = [0, 1] \neq \mathbb{R}$. Thus $\mathbb{Q}$ is dense.
⚡ Method B: 25-Second Exam Shortcut
$\mathbb{Q}$ is the classic canonical example of a countable dense subset in $\mathbb{R}$.
💡 Tip: Always recall that $\mathbb{Q}$ and $\mathbb{R} \setminus \mathbb{Q}$ are both dense in $\mathbb{R}$.
CANONICAL PROBLEM 02 Dual-Method Breakdown

If $A$ and $B$ are dense subsets of a metric space $X$ and $A$ is open, then $A \cap B$ is:

(A) Nowhere dense in $X$(B) Dense in $X$(C) Empty(D) Closed in $X$
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Step 1: Let $U$ be any non-empty open set in $X$. Step 2: Since $A$ is dense and open, $U \cap A$ is a non-empty open set. Step 3: Since $B$ is dense, $(U \cap A) \cap B = U \cap (A \cap B) \neq \emptyset$. Step 4: Hence $A \cap B$ intersects every open set, proving it is dense in $X$.
⚡ Method B: 25-Second Exam Shortcut
Open dense intersected with any dense set yields a dense set.
💡 Tip: Memorize topological lemmas involving open dense sets frequently tested in PGT exams.

Practice questions

Choose an answer to check it and see the solution:

Q1
MCQ 1: Which of the following subsets is dense in $\mathbb{R}$ with usual metric?
A $\mathbb{N}$
B $\mathbb{Z}$
C $\mathbb{Q}$
D $[0, 1]$
Derivation & Analysis:

The set of rational numbers $\mathbb{Q}$ has closure equal to $\mathbb{R}$, making it dense in $\mathbb{R}$, whereas $\mathbb{N}$ and $\mathbb{Z}$ have closures equal to themselves.

Q2
MCQ 2: If $A$ is dense in $B$ and $B$ is dense in $C$, then $A$ is dense in:
A $B$ only
B $C$
C $A$
D Not necessarily $C$
Derivation & Analysis:

Denseness is transitive: $\overline{A} \supset \overline{B} \supset C$ implies $\overline{A} = C$ if $A \subset B \subset C$ with appropriate closure inclusions.

Q3
MCQ 3: The set of irrational numbers $\mathbb{R} \setminus \mathbb{Q}$ in $\mathbb{R}$ is:
A Closed
B Dense
C Nowhere dense
D Compact
Derivation & Analysis:

Between any two reals there is an irrational, and the closure of $\mathbb{R} \setminus \mathbb{Q}$ is $\mathbb{R}$, hence it is dense.

Q4
MCQ 4: A metric space is called separable if it contains:
A A finite dense subset
B A countable dense subset
C An uncountable dense subset
D No dense subset
Derivation & Analysis:

By definition, a metric space is separable if it possesses a countable dense subset (e.g., $\mathbb{Q}$ in $\mathbb{R}$).

Q5
MCQ 5: Which of the following is a nowhere dense set in $\mathbb{R}$?
A $\mathbb{Q}$
B $\mathbb{Z}$
C $(0, 1)$
D $\mathbb{R}$
Derivation & Analysis:

$\mathbb{Z}$ is closed and has empty interior, so its closure is $\mathbb{Z}$, whose interior is empty, making it nowhere dense.

Q6
MCQ 6: If $D$ is dense in $X$, then for every non-empty open set $U \subset X$:
A $U \cap D = \emptyset$
B $U \cap D \neq \emptyset$
C $U \subset D$
D $D \subset U$
Derivation & Analysis:

A set is dense if and only if it intersects every non-empty open set of the ambient space.

Q7
MCQ 7: The closure of an open interval $(a, b)$ in $\mathbb{R}$ is:
A $(a, b)$
B $[a, b]$
C $(a, b]$
D $\mathbb{R}$
Derivation & Analysis:

The smallest closed set containing $(a, b)$ is $[a, b]$, thus its closure is the closed interval.

Q8
MCQ 8: Assertion (A): $\mathbb{Q}$ is dense in $\mathbb{R}$. Reason (R): Between any two distinct real numbers there is a rational number.
A Both (A) and (R) are true and (R) is the correct explanation of (A)
B Both (A) and (R) are true but (R) is not the correct explanation
C (A) is true but (R) is false
D (A) is false but (R) is true
Derivation & Analysis:

The Archimedean property and density of $\mathbb{Q}$ are directly justified by the existence of rationals between reals.

Q9
MCQ 9: Let $X = \mathbb{R}$. Which set is dense-in-itself and closed?
A $\mathbb{Q}$
B $\mathbb{R}$
C $\mathbb{N}$
D Finite set
Derivation & Analysis:

$\mathbb{R}$ is closed and has no isolated points (dense-in-itself).

Q10
MCQ 10: If $A \subset B$ and $A$ is dense in $X$, then $B$ is:
A Nowhere dense in $X$
B Dense in $X$
C Closed in $X$
D Bounded in $X$
Derivation & Analysis:

Since $A \subset B$, $\overline{A} \subset \overline{B}$. If $\overline{A} = X$, then $\overline{B} = X$, so $B$ is also dense in $X$.
