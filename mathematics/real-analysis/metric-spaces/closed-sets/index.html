Closed sets

A closed set in a metric space is one whose complement is open, or equivalently, a set that contains all its limit points. Mastery of closed sets and their topological characterizations forms the cornerstone of real analysis questions in UP PGT/TGT, KVS, and DSSSB examinations.

Pillar 1 Rigorous Definition & Mathematical Statement

Characterization of Closed Sets via Limit Points
A subset $F$ of a metric space $(X, d)$ is closed if and only if every limit point of $F$ belongs to $F$. That is, if $F'$ denotes the derived set of $F$, then $F' \subset F$.

📐 Geometric Interpretation

Geometrically, closed sets contain their boundaries and 'accumulation zones', ensuring that no sequence of points within the set can converge to a point outside the set.

⚙️ Algebraic & Structural Meaning

Algebraically, closed sets are stable under arbitrary intersections and finite unions, serving as the foundational building blocks for defining continuous mappings and compact spaces.

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Finite Unions and Intersections

$$\text{Finite union of closed sets is closed; Arbitrary intersection of closed sets is closed.}$

Exam Rule: Never waste time checking limits for finite unions or arbitrary intersections; apply topological closure laws instantly.

⚡ PYQ Context: Directly tested in UP PGT/TGT for verifying statement correctness.
02

Shortcut 2: Singleton Sets in Metric Spaces

$$ \forall x \in X, \{x\} \text{ is closed in any metric space.} $$

Exam Rule: Every singleton set is closed because its complement is open (or it has no limit points).

⚡ PYQ Context: Used to quickly deduce that finite sets are closed.
03

Shortcut 3: Continuous Image of Closed Sets

$$ f: X \to Y \text{ continuous}, \ F \subset Y \text{ closed} \implies f^{-1}(F) \text{ is closed in } X. $$

Exam Rule: Use inverse images under continuous functions to test closedness without epsilon-delta proofs.

⚡ PYQ Context: Frequently asked in DSSSB PGT and KVS exams.
04

Shortcut 4: Closed Interval Property in $\mathbb{R}$

$$ [a, b], [a, \infty), (-\infty, b], \text{ and } \{a\} \text{ are closed in } \mathbb{R}. $$

Exam Rule: Any interval containing its endpoints in $\mathbb{R}$ with the usual metric is closed.

⚡ PYQ Context: Fundamental baseline for real analysis MCQs.
05

Shortcut 5: Closure Operator Identity

$$ F \text{ is closed} \iff \bar{F} = F. $$

Exam Rule: To prove or test if a set is closed, check if it equals its topological closure.

⚡ PYQ Context: Standard verification technique in competitive examinations.
06

Shortcut 6: Rapid Elimination Trick for Open/Closed Hybrid Sets

$$ (a, b] \text{ is neither open nor closed in } \mathbb{R}. $$

Exam Rule: Sets that are half-open/half-closed are immediately eliminated from purely closed or open options.

⚡ PYQ Context: Saves 30 seconds on classification questions.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Arbitrary Union of Closed Sets

Common Pitfall: Assuming that an infinite (arbitrary) union of closed sets is always closed.

Counterexample: $$\bigcup_{n=1}^{\infty} \left[0, 1 - \frac{1}{n}\right] = [0, 1)$$

Why it fails: The arbitrary union of closed intervals yields a half-open interval $[0, 1)$, which is NOT closed in $\mathbb{R}$.

🛡️ Exam Defense: Remember: Finite union of closed sets is closed, but infinite union can be open, closed, or neither.
⚠️ EXAM TRAP #02

Trap 2: Confusing Closure with Bounddness

Common Pitfall: Assuming bounded sets are closed or closed sets must be bounded.

Counterexample: $$[0, \infty) \text{ is closed in } \mathbb{R} \text{ but unbounded. } (0, 1] \text{ is bounded but not closed.}$

Why it fails: Closedness is a topological property related to limits/complements, whereas boundedness is a metric property.

🛡️ Exam Defense: Never conflate boundedness with closedness.

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

Which of the following sets is closed in the usual metric space $\mathbb{R}$?

(A) \mathbb{Q}(B) (0, 1](C) \{x \in \mathbb{R} : x^2 \le 2\}(D) \{1/n : n \in \mathbb{N}\}
✓ Correct Answer: (C)
📚 Method A: Formal Textbook Derivation
Step 1: Note that $\{x \in \mathbb{R} : x^2 \le 2\} = [-\sqrt{2}, \sqrt{2}]$. Step 2: Since it is a closed interval, it contains all its limit points and is closed. Step 3: $\mathbb{Q}$ is neither open nor closed, $(0, 1]$ is half-open, and $\mathbb{N}^* = \{1/n\}$ lacks 0 which is a limit point.
⚡ Method B: 25-Second Exam Shortcut
Recognize the set as the inverse image of the closed set $[0, 2]$ under the continuous function $f(x) = x^2$.
💡 Key Takeaway: Look for inequalities involving $\le$ or $\ge$ with continuous functions.
CANONICAL PROBLEM 02 Dual-Method Breakdown

Let $S = \left\{ \frac{1}{n} : n \in \mathbb{N} \right}$. In the usual metric space $\mathbb{R}$, the set $S$

(A) is closed(B) is open(C) has 0 as a limit point but is not closed(D) is compact
✓ Correct Answer: (C)
📚 Method A: Formal Textbook Derivation
Step 1: The sequence $\{1/n\}$ converges to $0$. Step 2: Thus $0$ is a limit point of $S$. Step 3: However, $0 \notin S$. Step 4: Since $S'$ contains $0$ but $0 \notin S$, $S$ is not closed.
⚡ Method B: 25-Second Exam Shortcut
A countable set with a single limit point outside the set is a classic non-closed set.
💡 Key Takeaway: Check limit points of sequences of the form $1/n$.

Pillar 7 10 Practice MCQs for Self-Assessment

Q1
MCQ 1: Which of the following is always a closed set in any metric space $(X, d)$?
A The whole space $X$
B Any finite union of open sets
C Any countable intersection of open sets
D Any subset
Derivation & Analysis:

The whole space $X$ and the empty set $\emptyset$ are both open and closed (clopen) in any metric space.

Q2
MCQ 2: In the metric space $\mathbb{R}$ with usual metric, the set of irrational numbers $\mathbb{R} \setminus \mathbb{Q}$ is:
A Closed
B Open
C Neither open nor closed
D Compact
Derivation & Analysis:

$\mathbb{R} \setminus \mathbb{Q}$ is neither open nor closed. Its interior is empty and its closure is $\mathbb{R}$.

Q3
MCQ 3: The intersection of an arbitrary family of closed sets in a metric space is:
A Always open
B Always closed
C Never closed
D Finite
Derivation & Analysis:

By De Morgan's laws, the complement of an arbitrary intersection of closed sets is an arbitrary union of open sets, which is open. Thus, the intersection is closed.

Q4
MCQ 4: Let $F_n = \left[0, 1 + \frac{1}{n}\right]$ for $n \in \mathbb{N}$. Then $\bigcap_{n=1}^{\infty} F_n$ is:
A (0, 1)
B [0, 1]
C [0, 1)
D (0, 1]
Derivation & Analysis:

The intersection of nested closed intervals $[0, 1 + 1/n]$ yields the closed interval $[0, 1]$.

Q5
MCQ 5: Which of the following sets is closed in $\mathbb{R}$?
A (0, \infty)
B \mathbb{Z}
C \mathbb{Q}
D (-\infty, 0) \cup (0, \infty)
Derivation & Analysis:

$\mathbb{Z}$ is closed in $\mathbb{R}$ because its complement $\mathbb{R} \setminus \mathbb{Z}$ is a union of open intervals $(n, n+1)$, which is open.

Q6
MCQ 6: If $A$ and $B$ are closed subsets of a metric space $X$, then $A \cup B$ is:
A Open
B Closed
C Neither open nor closed
D Empty
Derivation & Analysis:

A finite union of closed sets is always closed.

Q7
MCQ 7: The boundary $\partial S$ of any subset $S$ of a metric space is always:
A An open set
B A closed set
C A compact set
D A countable set
Derivation & Analysis:

The boundary of any set $S$, defined as $\bar{S} \setminus S^o$, is always a closed set because it is the intersection of two closed sets (closure and complement of interior).

Q8
MCQ 8: If $f: \mathbb{R} \to \mathbb{R}$ is a continuous function, then the set $\{x \in \mathbb{R} : f(x) = 0\}$ is:
A Open
B Closed
C Bounded
D Compact
Derivation & Analysis:

The set $\{x : f(x) = 0\} = f^{-1}(\{0\})$. Since $\{0\}$ is closed in $\mathbb{R}$ and $f$ is continuous, its inverse image is closed.

Q9
MCQ 9: In the discrete metric space $(X, d)$, every subset is:
A Open only
B Closed only
C Both open and closed (clopen)
D Neither open nor closed
Derivation & Analysis:

In a discrete metric space, every singleton is open, hence every subset (being a union of singletons) is open, and its complement is also open, making every subset closed as well.

Q10
MCQ 10: Which of the following statements is FALSE?
A Every closed set is the complement of an open set.
B The closure of any set is closed.
C The union of infinitely many closed sets is always closed.
D Every singleton set in $\mathbb{R}$ is closed.
Derivation & Analysis:

The union of infinitely many closed sets need not be closed (e.g., $\bigcup [0, 1 - 1/n] = [0, 1)$).
