Real Analysis

Bolzano-Weierstrass theorem

The Bolzano-Weierstrass theorem establishes that every bounded infinite subset of real numbers possesses at least one accumulation point, forming the fundamental topological backbone of real analysis. Its elegant formulation guarantees compactness properties in $\mathbb{R}$, making it a prime testing ground for topological intuition in competitive examinations like UP PGT/TGT and DSSSB.

Pillar 1 Rigorous Definition & Mathematical Statement

Bolzano-Weierstrass Theorem for Sets
Every bounded infinite subset of the set of real numbers $\mathbb{R}$ has at least one limit point (accumulation point) in $\mathbb{R}$. Alternatively, every bounded sequence in $\mathbb{R}$ contains a convergent subsequence.

📐 Geometric Interpretation

Visually, if you drop an infinite number of distinct points inside a finite, bounded interval $[a, b]$, at least one point in $\mathbb{R}$ will be crowded by infinitely many elements of the set, meaning you can zoom in arbitrarily close to it.

⚙️ Algebraic & Structural Meaning

It bridges the gap between boundedness and convergence, serving as the core engine behind the completeness of real numbers and proving foundational results like the Heine-Borel theorem and Cauchy's convergence criterion.

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Bounded Monotonic Subsequence Extraction

$$\text{Every bounded sequence } \{x_n\} \text{ contains a monotonic subsequence, hence converges if bounded.}$$

Exam Rule: Whenever examining a bounded sequence defined by a recurrence relation, immediately check for monotonicity or extract alternating/monotonic sub-chains.

⚡ PYQ Context: Directly tested in UP PGT to determine limit points of complex sequences.
02

Shortcut 2: Nested Interval Principle Link

$$I_1 \supset I_2 \supset I_3 \supset \dots, \quad \bigcap_{n=1}^{\infty} I_n = \{c\}$$

Exam Rule: Use bisection arguments for bounded intervals to locate the accumulation point within 5 seconds for decimal expansion problems.

⚡ PYQ Context: Frequently used in KVS/NVS statements regarding nested closed intervals.
03

Shortcut 3: Limit Superior and Limit Inferior Bound

$$\liminf_{n \to \infty} x_n \le \text{limit points} \le \limsup_{n \to \infty} x_n$$

Exam Rule: The set of all subsequential limits of a bounded sequence is a closed and bounded set whose infimum is $\liminf x_n$ and supremum is $\limsup x_n$.

⚡ PYQ Context: Standard high-level PGT question format for finding the exact set of limit points.
04

Shortcut 4: Periodic and Alternating Sequences

$$x_n = \sin\left(\frac{n\pi}{2}\right) \implies \text{Subsequential limits } \{-1, 0, 1\}$$

Exam Rule: For trigonometric sequence terms involving fractions of $\pi$, identify the periodic cycle length $k$ to instantly list all distinct limit points.

⚡ PYQ Context: Direct repeating pattern in UP TGT/PGT examinations.
05

Shortcut 5: Compactness Equivalence in $\mathbb{R}^n$

$$S \text{ is compact} \iff S \text{ is closed and bounded (Heine-Borel)}$$

Exam Rule: Combine Bolzano-Weierstrass with Heine-Borel to instantly classify subsets of $\mathbb{R}$ as compact.

⚡ PYQ Context: Crucial theoretical deduction tested in DSSSB PGT Mathematics.
06

Shortcut 6: Rapid Option Elimination via Unboundedness

$$x_n = n \text{ or } x_n = (-1)^n n \implies \text{No finite limit points}$$

Exam Rule: Instantly eliminate any option claiming a convergent subsequence or limit point for explicitly unbounded sequences.

⚡ PYQ Context: Saves critical time in 125-question multiple choice formats.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Confusing Bounded Sets with Convergent Sets

Common Pitfall: Candidates assume that because a set is bounded, the sequence itself must converge (confusing Bolzano-Weierstrass with Cauchy/Convergence criteria).

Counterexample: $x_n = (-1)^n$ on $[-1, 1]$

Why it fails: The sequence is bounded and has subsequential limits $\{-1, 1}$, but the sequence itself diverges because the limit does not exist uniquely.

🛡️ Exam Defense: Remember: B.W. guarantees a *subsequence* convergence, not full sequence convergence.
⚠️ EXAM TRAP #02

Trap 2: Applying Bolzano-Weierstrass in $\mathbb{Q}$

Common Pitfall: Assuming Bolzano-Weierstrass holds in the set of rational numbers $\mathbb{Q}$.

Counterexample: The set of rational numbers $q \in [0, 2]$ with $q^2 < 2$

Why it fails: This bounded infinite set of rationals has an accumulation point at $\sqrt{2}$, which is irrational and thus does *not* belong to $\mathbb{Q}$.

🛡️ Exam Defense: Check the underlying space domain; B.W. requires completeness (such as $\mathbb{R}$).

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

Find the set of all limit points of the sequence $x_n = \left(1 + \frac{1}{n}\right)^n \cos(n\pi)$ in $\mathbb{R}$.

(A) $\{e, -e\}$(B) $\{e\}$(C) $\{0, e, -e\}$(D) $\emptyset$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Separate into even and odd terms. For $n = 2k$, $\cos(2k\pi) = 1$ and $(1 + \frac{1}{2k})^{2k} \to e$. For $n = 2k+1$, $\cos((2k+1)\pi) = -1$ and $(1 + \frac{1}{2k+1})^{2k+1} \to e$. Step 2: Combine limits to get $e$ and $-e$. Step 3: Conclude the set of limit points is $\{e, -e\}$.
⚡ Method B: 25-Second Exam Shortcut
Recognize the core term converges to $e$ and the multiplier oscillates between $1$ and $-1$. The products are $e \times 1 = e$ and $e \times (-1) = -e$.
💡 Key Takeaway: Always decompose composite sequences containing alternating trigonometric signs.
CANONICAL PROBLEM 02 Dual-Method Breakdown

Which of the following sets possesses an accumulation point in $\mathbb{R}$?

(A) $\{\frac{1}{n} : n \in \mathbb{N}\}$(B) $\{\mathbb{N}\}$(C) $\{n^2 : n \in \mathbb{N}\}$(D) $\{\tan(n) : n \in \mathbb{N}\}$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Test boundedness and infinitude. Set (A) is infinite and bounded within $[0, 1]$. Step 2: By Bolzano-Weierstrass, it must have a limit point (which is $0$). Step 3: Sets (B), (C), and (D) are unbounded subsets of $\mathbb{R}$.
⚡ Method B: 25-Second Exam Shortcut
Instantly check for bounded subsets: only option (A) is confined to a finite interval while containing infinite elements.
💡 Key Takeaway: Unbounded sets like $\mathbb{N}$ or $\mathbb{Z}$ never have finite accumulation points.

Q1
MCQ 1: According to the Bolzano-Weierstrass theorem, every bounded infinite subset of $\mathbb{R}$ has at least:
A One limit point
B A unique limit point
C No limit point
D A countable limit
Derivation & Analysis:

By definition, the Bolzano-Weierstrass theorem guarantees the existence of at least one accumulation (limit) point in $\mathbb{R}$ for any bounded infinite set.

Q2
MCQ 2: The set of limit points of the sequence $x_n = (-1)^n \left(1 + \frac{1}{n}\right)$ is:
A \{-1, 1\}
B \{1\}
C \{-1\}
D \{0\}
Derivation & Analysis:

For even $n$, $x_n \to 1$. For odd $n$, $x_n \to -1$. Thus, the set of all subsequential limits (limit points) is $\{-1, 1}$.

Q3
MCQ 3: Which of the following sequences has no convergent subsequence?
A $x_n = n$
B $x_n = \sin(n)$
C $x_n = \frac{1}{n}$
D $x_n = (-1)^n$
Derivation & Analysis:

An unbounded sequence like $x_n = n$ cannot have any convergent subsequence in $\mathbb{R}$ because all its subsequences diverge to infinity, violating Bolzano-Weierstrass conditions.

Q4
MCQ 4: The set $S = \left\{ \frac{m}{n} : m, n \in \mathbb{Z}, n \neq 0, 0 \le \frac{m}{n} \le 1 \right}$ has how many accumulation points in $\mathbb{R}$?
A Infinitely many (every point in $[0, 1]$)
B Only rational points in $[0, 1]$
C Exactly two points ($0$ and $1$)
D None
Derivation & Analysis:

The set of rational numbers in $[0, 1]$ is dense in $[0, 1]$, meaning every real number in $[0, 1]$ is an accumulation point of this set.

Q5
MCQ 5: If $S$ is an infinite bounded subset of $\mathbb{R}$, its derived set $S'$ (set of all accumulation points):
A Must be non-empty and bounded
B Must be empty
C Must be finite
D Must equal $S$
Derivation & Analysis:

By Bolzano-Weierstrass, $S'$ is non-empty. Since $S \subset [a, b]$, its limit points must also lie within $[a, b]$, making $S'$ bounded.

Q6
MCQ 6: Consider the sequence $x_n = \sin\left(\frac{n\pi}{4}\right)$. The number of distinct limit points of this sequence is:
A 5
B 4
C 8
D Infinite
Derivation & Analysis:

The values of $\sin(n\pi/4)$ cycle through $0, \frac{1}{\sqrt{2}}, 1, \frac{1}{\sqrt{2}}, 0, -\frac{1}{\sqrt{2}}, -1, -\frac{1}{\sqrt{2}}$. The distinct values (limit points) are $\left\{0, \pm\frac{1}{\sqrt{2}}, \pm 1\}$, totaling 5 distinct points.

Q7
MCQ 7: Which of the following statements is true for Bolzano-Weierstrass theorem in metric spaces?
A It holds in any metric space if it is compact
B It holds in all metric spaces
C It fails in $\mathbb{R}^n$
D It is equivalent to the Intermediate Value Theorem
Derivation & Analysis:

A metric space is compact if and only if it is sequentially compact (i.e., satisfies the Bolzano-Weierstrass property for sequences).

Q8
MCQ 8: Assertion (A): Every bounded sequence in $\mathbb{R}$ has a convergent subsequence. Reason (R): This is a direct consequence of the Bolzano-Weierstrass theorem.
A Both (A) and (R) are true and (R) is the correct explanation of (A)
B Both (A) and (R) are true but (R) is not the correct explanation
C (A) is true but (R) is false
D (A) is false but (R) is true
Derivation & Analysis:

Both statements are standard textbook definitions and theorems in real analysis.

Q9
MCQ 9: If a set $S \subset \mathbb{R}$ has no accumulation points, then $S$ must be:
A Either finite or discrete and unbounded (or closed with no limit points)
B Compact
C Unbounded
D Dense in $\mathbb{R}$
Derivation & Analysis:

If $S$ is bounded and infinite, B.W. guarantees a limit point. Thus, having no limit points implies $S$ is either finite or cannot be both bounded and infinite.

Q10
MCQ 10: The set of limit points of the sequence $x_n = n \sin\left(\frac{n\pi}{2}\right)$ is:
A Empty (no finite limit points)
B $\{0, 1, -1\}$
C $\{0\}$
D $\mathbb{R}$
Derivation & Analysis:

For $n = 4k + 1$, $x_n = 4k + 1 \to \infty$. The sequence is unbounded, hence it has no finite limit points.
