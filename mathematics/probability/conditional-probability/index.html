1. Algebra — Probability

Conditional probability

Conditional probability measures the probability of an event occurring given that another event has already occurred, forming the foundational bedrock for Bayes' theorem and total probability. Mastering its axiomatic definition and multiplicative structure is crucial for securing high-yield marks in UP TGT/PGT, DSSSB, and KVS examinations.

Pillar 1 Rigorous Definition & Mathematical Statement

Definition of Conditional Probability & Multiplication Rule
Let $(\Omega, \mathcal{F}, P)$ be a probability space and let $A, B \in \mathcal{F}$ be two events such that $P(B) > 0$. The conditional probability of $A$ given $B$, denoted by $P(A \mid B)$, is defined as $$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$. Consequently, the finite multiplication rule states that $P(A \cap B) = P(B) P(A \mid B)$ whenever $P(B) > 0$.

📐 Geometric Interpretation

Geometrically, if sample space $\Omega$ is represented by a region of total area $1$, the event $B$ restricts our universe to a sub-region of measure $P(B)$. The conditional probability $P(A \mid B)$ is the ratio of the overlapping area $P(A \cap B)$ to the newly restricted total base area $P(B)$.

⚙️ Algebraic & Structural Meaning

Algebraically, conditional probability defines a new probability measure $P_B(\cdot) = P(\cdot \mid B)$ on the original $\sigma$-algebra, satisfying all Kolmogorov axioms of probability provided the conditioning event has strictly positive measure.

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Independent Events Simplification

$$P(A \mid B) = P(A) \quad \text{and} \quad P(B \mid A) = P(B)$$

Exam Rule: If events $A$ and $B$ are independent, condition dropping is immediate. Never compute the intersection ratio manually.

⚡ PYQ Context: Frequently tested in UP PGT/TGT to test basic definitions of stochastic independence.
02

Shortcut 2: Mutually Exclusive Non-Trivial Events

$$P(A \mid B) = 0 \quad \text{for } P(A \cap B) = 0 \text{ (with } P(B) > 0 \text{)}$$

Exam Rule: If $A$ and $B$ are disjoint and $P(B) > 0$, conditional probability is instantly $0$ without calculation.

⚡ PYQ Context: Direct property checks in DSSSB and KVS exams.
03

Shortcut 3: Subset Inclusion Rule

$$A \subset B \implies P(A \mid B) = \frac{P(A)}{P(B)}$$

Exam Rule: When event $A$ is a subset of $B$, the intersection $A \cap B$ simplifies directly to $A$.

⚡ PYQ Context: Standard problem pattern in set-theoretic probability questions.
04

Shortcut 4: Complementary Conditioning Rule

$$P(A^c \mid B) = 1 - P(A \mid B)$$

Exam Rule: Use the complement rule inside the numerator to bypass complex set intersections.

⚡ PYQ Context: Used in multi-stage coin/dice problems to save calculation time.
05

Shortcut 5: Total Probability Two-Branch Shortcut

$$P(A) = P(A \mid B)P(B) + P(A \mid B^c)P(B^c)$$

Exam Rule: Partition the sample space into $B$ and $B^c$ to decompose complex unconditional probabilities into conditional components.

⚡ PYQ Context: Extensively used in urn-and-ball or disease-testing UP PGT questions.
06

Shortcut 6: Bayes' Theorem Ratio Trick

$$P(B_i \mid A) = \frac{P(A \mid B_i)P(B_i)}{\sum_j P(A \mid B_j)P(B_j)}$$

Exam Rule: Set up a tabular or branch-multiplier format for numerator vs total denominator to eliminate calculation errors in 20 seconds.

⚡ PYQ Context: Core scoring zone for UP TGT/PGT and LT Grade examinations.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Zero Probability Conditioning Fallacy

Common Pitfall: Attempting to compute conditional probability given an event of probability zero (e.g., continuous random variable single point $P(X = c)$ without limits).

Counterexample: $P(X = 2 \mid X \ge 2)$ where $X$ is continuous

Why it fails: Standard conditional probability formula $P(A \cap B)/P(B)$ fails when $P(B) = 0$, requiring Radon-Nikodym derivatives or limits.

🛡️ Exam Defense: Always verify that the conditioning event has strictly positive measure ($P(B) > 0$) before applying the definition.
⚠️ EXAM TRAP #02

Trap 2: Confusing Independence with Mutual Exclusivity

Common Pitfall: Assuming disjoint events are independent.

Counterexample: If $P(A) > 0$ and $P(B) > 0$ and $A \cap B = \emptyset$, then $P(A \mid B) = 0 \neq P(A)$.

Why it fails: Disjoint non-trivial events are maximally dependent because knowing $B$ occurs completely rules out $A$.

🛡️ Exam Defense: Never confuse mutually exclusive ($A \cap B = \emptyset$) with independent ($P(A \cap B) = P(A)P(B)$).

CANONICAL PROBLEM 01 Dual-Method Breakdown

If $A$ and $B$ are two events such that $P(A) = 0.4$, $P(B) = 0.8$, and $P(B \mid A) = 0.5$, then what is the value of $P(A \cup B)$?

(A) $0.9$(B) $0.8$(C) $0.7$(D) $0.6$
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Step 1: Use the multiplication rule to find $P(A \cap B) = P(A) \cdot P(B \mid A) = 0.4 \times 0.5 = 0.2$. Step 2: Use the inclusion-exclusion principle $P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.4 + 0.8 - 0.2 = 1.0 - 0.2 = 0.8$.
⚡ Method B: 25-Second Exam Shortcut
Apply multiplication rule instantly: $P(A \cap B) = 0.4 \times 0.5 = 0.2$. Then $0.4 + 0.8 - 0.2 = 0.8$.
💡 Key Takeaway: Standard UP PGT direct formula application question. Memorize the link between conditional probability and joint intersection.
CANONICAL PROBLEM 02 Dual-Method Breakdown

A bag contains 3 red and 5 black balls. Two balls are drawn at random one after the other without replacement. What is the probability that both balls are red?

(A) $\frac{3}{28}$(B) $\frac{1}{14}$(C) $\frac{3}{16}$(D) $\frac{5}{28}$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Let $R_1$ be the event that the first ball is red ($P(R_1) = \frac{3}{8}$). Step 2: Let $R_2$ be the event that the second ball is red given the first is red ($P(R_2 \mid R_1) = \frac{2}{7}$). Step 3: Compute intersection using multiplication rule $P(R_1 \cap R_2) = P(R_1)P(R_2 \mid R_1) = \frac{3}{8} \times \frac{2}{7} = \frac{6}{56} = \frac{3}{28}$.
⚡ Method B: 25-Second Exam Shortcut
Numerator product over denominator product: $\frac{3 \times 2}{8 \times 7} = \frac{6}{56} = \frac{3}{28}$. Done in 10 seconds.
💡 Key Takeaway: Watch out for 'with' versus 'without' replacement wording in urn problems.

MCQ 1: If $P(A) = 0.6$, $P(B) = 0.3$, and $P(A \cap B) = 0.2$, then $P(A \mid B)$ is equal to:
A $\frac{2}{3}$
B $\frac{1}{3}$
C $\frac{2}{5}$
D $\frac{3}{5}$
Derivation & Analysis:

$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{0.2}{0.3} = \frac{2}{3}$.

Q2
MCQ 2: For any two events $A$ and $B$ with $P(B) > 0$, which of the following is always true?
A $P(A \mid B) = P(A)$
B $P(A \mid B) \le P(A)$
C $P(A \cap B) = P(B)P(A \mid B)$
D $P(A \mid B) = P(B \mid A)$
Derivation & Analysis:

By definition of conditional probability, $P(A \cap B) = P(B)P(A \mid B)$ is always identically true.

Q3
MCQ 3: If $A$ and $B$ are mutually exclusive events with $P(B) > 0$ and $P(A) > 0$, then $P(A \mid B)$ is:
A $1$
B $0$
C $P(A)$
D Undefined
Derivation & Analysis:

Mutual exclusivity implies $A \cap B = \emptyset$, hence $P(A \cap B) = 0$, leading to $P(A \mid B) = 0 / P(B) = 0$.

Q4
MCQ 4: If $P(A \mid B) > P(A)$, then which of the following relationships holds between $P(B \mid A)$ and $P(B)$?
A $P(B \mid A) < P(B)$
B $P(B \mid A) = P(B)$
C $P(B \mid A) > P(B)$
D $P(B \mid A) + P(B) = 1$
Derivation & Analysis:

Since $P(A \cap B) = P(A \mid B)P(B) = P(B \mid A)P(A)$, if $P(A \mid B) > P(A)$, it directly forces $P(B \mid A) > P(B)$ by symmetry.

Q5
MCQ 5: A dice is thrown twice. What is the conditional probability that the sum of numbers appearing is $8$ given that the number $5$ has appeared at least once?
A $\frac{1}{11}$
B $\frac{2}{11}$
C $\frac{2}{36}$
D $\frac{5}{36}$
Derivation & Analysis:

Let $B$ be '5 appears at least once' (11 outcomes). Let $A$ be 'sum is 8' ($ {(2,6), (3,5), (4,4), (5,3), (6,2)} $). Intersection $A \cap B = \{(3,5), (5,3)\}$ (2 outcomes). Thus $P(A \mid B) = \frac{2}{11}$.

Q6
MCQ 6: If $P(A^c) = 0.7$, $P(B) = 0.7$, and $P(B \mid A) = 0.5$, then $P(A \cup B)$ is:
A $0.8$
B $0.85$
C $0.9$
D $0.95$
Derivation & Analysis:

$P(A) = 1 - P(A^c) = 0.3$. $P(A \cap B) = P(A)P(B \mid A) = 0.3 \times 0.5 = 0.15$. $P(A \cup B) = 0.3 + 0.7 - 0.15 = 0.85$.

Q7
MCQ 7: If $A$ and $B$ are independent events with $P(A) = 0.3$ and $P(A \cup B) = 0.6$, then $P(B)$ is:
A $\frac{3}{7}$
B $\frac{4}{7}$
C $\frac{2}{7}$
D $\frac{1}{7}$
Derivation & Analysis:

$P(A \cup B) = P(A) + P(B) - P(A)P(B)$. $0.6 = 0.3 + P(B)(1 - 0.3) \implies 0.3 = 0.7 P(B) \implies P(B) = \frac{3}{7}$.

Q8
MCQ 8: Given two dependent events $A$ and $B$ such that $P(A) = \frac{1}{3}$, $P(B) = \frac{1}{4}$, and $P(A \cup B) = \frac{1}{2}$, what is $P(A \mid B^c)$?
A $\frac{1}{3}$
B $\frac{1}{6}$
C $\frac{2}{3}$
D $\frac{1}{9}$
Derivation & Analysis:

$P(A \cap B) = P(A) + P(B) - P(A \cup B) = \frac{1}{3} + \frac{1}{4} - \frac{1}{2} = \frac{1}{12}$. $P(A \cap B^c) = P(A) - P(A \cap B) = \frac{1}{3} - \frac{1}{12} = \frac{1}{4}$. Also $P(B^c) = 1 - \frac{1}{4} = \frac{3}{4}$. Then $P(A \mid B^c) = \frac{P(A \cap B^c)}{P(B^c)} = \frac{1/4}{3/4} = \frac{1}{3}$.

Q9
MCQ 9: If $P(A \mid B) = 1$, then which of the following is necessarily true?
A $A \subset B$
B $B \subset A$
C $A = B$
D $P(A) = 1$
Derivation & Analysis:

$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = 1 \implies P(A \cap B) = P(B)$, which implies $B \subset A$ is false; wait, $P(A \cap B) = P(B)$ means $B \subseteq A$ (or all probability concentrated there).

Q10
MCQ 10: In a class, $40\%$ of students study Mathematics and $25\%$ study Physics. $15\%$ study both. If a student is chosen at random and studies Mathematics, what is the probability that they also study Physics?
A \frac{3}{8}
B \frac{3}{5}
C \frac{5}{8}
D \frac{1}{4}
Derivation & Analysis:

Let $M$ be Mathematics ($P(M) = 0.4$) and $P$ be Physics ($P(P) = 0.25$). Given $P(M \cap P) = 0.15$. We need $P(P \mid M) = \frac{P(M \cap P)}{P(M)} = \frac{0.15}{0.40} = \frac{15}{40} = \frac{3}{8}$.

Division by zero is undefined in real arithmetic and measure theory. If $P(B) = 0$, the ratio $P(A \cap B)/P(B)$ leads to an indeterminate form, requiring advanced measure-theoretic limits (like conditional expectation with respect to $\sigma$-algebras).

Candidates frequently confuse the conditioning event order, evaluating $P(B \mid A)$ instead of $P(A \mid B)$, or misinterpreting phrases like 'given that' and 'at least one' in multi-stage random experiments.

Probability usually contributes 5 to 8 questions out of 125 in UP PGT/TGT exams, with conditional probability, Bayes' theorem, and binomial distribution forming the core sub-topics.

Pillar 1 Rigorous Definition & Mathematical Statement

Definition of Conditional Probability & Multiplication Rule
Let $(\Omega, \mathcal{F}, P)$ be a probability space and let $A, B \in \mathcal{F}$ be two events such that $P(B) > 0$. The conditional probability of $A$ given $B$, denoted by $P(A \mid B)$, is defined as $$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$. Consequently, the finite multiplication rule states that $P(A \cap B) = P(B) P(A \mid B)$ whenever $P(B) > 0$.

📐 Geometric Interpretation

Geometrically, if sample space $\Omega$ is represented by a region of total area $1$, the event $B$ restricts our universe to a sub-region of measure $P(B)$. The conditional probability $P(A \mid B)$ is the ratio of the overlapping area $P(A \cap B)$ to the newly restricted total base area $P(B)$.

⚙️ Algebraic & Structural Meaning

Algebraically, conditional probability defines a new probability measure $P_B(\cdot) = P(\cdot \mid B)$ on the original $\sigma$-algebra, satisfying all Kolmogorov axioms of probability provided the conditioning event has strictly positive measure.

CANONICAL PROBLEM 01 Dual-Method Breakdown

If $A$ and $B$ are two events such that $P(A) = 0.4$, $P(B) = 0.8$, and $P(B \mid A) = 0.5$, then what is the value of $P(A \cup B)$?

(A) $0.9$(B) $0.8$(C) $0.7$(D) $0.6$
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Step 1: Use the multiplication rule to find $P(A \cap B) = P(A) \cdot P(B \mid A) = 0.4 \times 0.5 = 0.2$. Step 2: Use the inclusion-exclusion principle $P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.4 + 0.8 - 0.2 = 1.0 - 0.2 = 0.8$.
⚡ Method B: 25-Second Exam Shortcut
Apply multiplication rule instantly: $P(A \cap B) = 0.4 \times 0.5 = 0.2$. Then $0.4 + 0.8 - 0.2 = 0.8$.
💡 Key Takeaway: Standard UP PGT direct formula application question. Memorize the link between conditional probability and joint intersection.
CANONICAL PROBLEM 02 Dual-Method Breakdown

A bag contains 3 red and 5 black balls. Two balls are drawn at random one after the other without replacement. What is the probability that both balls are red?

(A) $\frac{3}{28}$(B) $\frac{1}{14}$(C) $\frac{3}{16}$(D) $\frac{5}{28}$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Let $R_1$ be the event that the first ball is red ($P(R_1) = \frac{3}{8}$). Step 2: Let $R_2$ be the event that the second ball is red given the first is red ($P(R_2 \mid R_1) = \frac{2}{7}$). Step 3: Compute intersection using multiplication rule $P(R_1 \cap R_2) = P(R_1)P(R_2 \mid R_1) = \frac{3}{8} \times \frac{2}{7} = \frac{6}{56} = \frac{3}{28}$.
⚡ Method B: 25-Second Exam Shortcut
Numerator product over denominator product: $\frac{3 \times 2}{8 \times 7} = \frac{6}{56} = \frac{3}{28}$. Done in 10 seconds.
💡 Key Takeaway: Watch out for 'with' versus 'without' replacement wording in urn problems.

B $0$
C $P(A)$
D Undefined
Derivation & Analysis:

Mutual exclusivity implies $A \cap B = \emptyset$, hence $P(A \cap B) = 0$, leading to $P(A \mid B) = 0 / P(B) = 0$.

Q4
MCQ 4: If $P(A \mid B) > P(A)$, then which of the following relationships holds between $P(B \mid A)$ and $P(B)$?
A $P(B \mid A) < P(B)$
B $P(B \mid A) = P(B)$
C $P(B \mid A) > P(B)$
D $P(B \mid A) + P(B) = 1$
Derivation & Analysis:

Since $P(A \cap B) = P(A \mid B)P(B) = P(B \mid A)P(A)$, if $P(A \mid B) > P(A)$, it directly forces $P(B \mid A) > P(B)$ by symmetry.

Q5
MCQ 5: A dice is thrown twice. What is the conditional probability that the sum of numbers appearing is $8$ given that the number $5$ has appeared at least once?
A $\frac{1}{11}$
B $\frac{2}{11}$
C $\frac{2}{36}$
D $\frac{5}{36}$
Derivation & Analysis:

Let $B$ be '5 appears at least once' (11 outcomes). Let $A$ be 'sum is 8' ($ {(2,6), (3,5), (4,4), (5,3), (6,2)} $). Intersection $A \cap B = \{(3,5), (5,3)\}$ (2 outcomes). Thus $P(A \mid B) = \frac{2}{11}$.

Q6
MCQ 6: If $P(A^c) = 0.7$, $P(B) = 0.7$, and $P(B \mid A) = 0.5$, then $P(A \cup B)$ is:
A $0.8$
B $0.85$
C $0.9$
D $0.95$
Derivation & Analysis:

$P(A) = 1 - P(A^c) = 0.3$. $P(A \cap B) = P(A)P(B \mid A) = 0.3 \times 0.5 = 0.15$. $P(A \cup B) = 0.3 + 0.7 - 0.15 = 0.85$.

Q7
MCQ 7: If $A$ and $B$ are independent events with $P(A) = 0.3$ and $P(A \cup B) = 0.6$, then $P(B)$ is:
A $\frac{3}{7}$
B $\frac{4}{7}$
C $\frac{2}{7}$
D $\frac{1}{7}$
Derivation & Analysis:

$P(A \cup B) = P(A) + P(B) - P(A)P(B)$. $0.6 = 0.3 + P(B)(1 - 0.3) \implies 0.3 = 0.7 P(B) \implies P(B) = \frac{3}{7}$.

Q8
MCQ 8: Given two dependent events $A$ and $B$ such that $P(A) = \frac{1}{3}$, $P(B) = \frac{1}{4}$, and $P(A \cup B) = \frac{1}{2}$, what is $P(A \mid B^c)$?
A $\frac{1}{3}$
B $\frac{1}{6}$
C $\frac{2}{3}$
D $\frac{1}{9}$
Derivation & Analysis:

$P(A \cap B) = P(A) + P(B) - P(A \cup B) = \frac{1}{3} + \frac{1}{4} - \frac{1}{2} = \frac{1}{12}$. $P(A \cap B^c) = P(A) - P(A \cap B) = \frac{1}{3} - \frac{1}{12} = \frac{1}{4}$. Also $P(B^c) = 1 - \frac{1}{4} = \frac{3}{4}$. Then $P(A \mid B^c) = \frac{P(A \cap B^c)}{P(B^c)} = \frac{1/4}{3/4} = \frac{1}{3}$.

Q9
MCQ 9: If $P(A \mid B) = 1$, then which of the following is necessarily true?
A $A \subset B$
B $B \subset A$
C $A = B$
D $P(A) = 1$
Derivation & Analysis:

$P(A \mid B) = \frac{P(A \cap B)}{P(B)} = 1 \implies P(A \cap B) = P(B)$, which implies $B \subset A$ is false; wait, $P(A \cap B) = P(B)$ means $B \subseteq A$ (or all probability concentrated there).

Q10
MCQ 10: In a class, $40\%$ of students study Mathematics and $25\%$ study Physics. $15\%$ study both. If a student is chosen at random and studies Mathematics, what is the probability that they also study Physics?
A \frac{3}{8}
B \frac{3}{5}
C \frac{5}{8}
D \frac{1}{4}
Derivation & Analysis:

Let $M$ be Mathematics ($P(M) = 0.4$) and $P$ be Physics ($P(P) = 0.25$). Given $P(M \cap P) = 0.15$. We need $P(P \mid M) = \frac{P(M \cap P)}{P(M)} = \frac{0.15}{0.40} = \frac{15}{40} = \frac{3}{8}$.

Pillar 8 Frequently Asked Questions

Division by zero is undefined in real arithmetic and measure theory. If $P(B) = 0$, the ratio $P(A \cap B)/P(B)$ leads to an indeterminate form, requiring advanced measure-theoretic limits (like conditional expectation with respect to $\sigma$-algebras).

Candidates frequently confuse the conditioning event order, evaluating $P(B \mid A)$ instead of $P(A \mid B)$, or misinterpreting phrases like 'given that' and 'at least one' in multi-stage random experiments.

Probability usually contributes 5 to 8 questions out of 125 in UP PGT/TGT exams, with conditional probability, Bayes' theorem, and binomial distribution forming the core sub-topics.

Always translate word statements into set-theoretic notation ($A \cap B$, $A \mid B$) immediately, use tree diagrams or table methods for multi-stage draws, and apply the multiplication rule directly to avoid cumbersome fraction reductions.
