7. Linear Algebra

Linear dependence

Linear dependence determines whether a set of vectors in a vector space can be expressed as a non-trivial linear combination yielding the zero vector. It forms the foundational algebraic backbone for vector dimensions, basis, rank-nullity theorem, and system consistency, making it a high-yield scoring zone in UP TGT/PGT, DSSSB, and KVS examinations.

Target Exams: UP PGT Mathematics UP TGT Mathematics DSSSB PGT / TGT KVS / NVS PGT LT Grade
📖 Self-Study Mastery Status
○ Mark Topic as Mastered

Pillar 1 Rigorous Definition & Mathematical Statement

Definition of Linear Dependence and Independence
Let $V$ be a vector space over a field $\mathbb{F}$. A subset $S = \{v_1, v_2, \dots, v_n\} \subseteq V$ is said to be linearly dependent if there exist scalars $c_1, c_2, \dots, c_n \in \mathbb{F}$, not all zero, such that $$c_1 v_1 + c_2 v_2 + \dots + c_n v_n = 0.$$ If this relation holds exclusively when $c_1 = c_2 = \dots = c_n = 0$, the set $S$ is linearly independent.

📐 Geometric Interpretation

In $\mathbb{R}^2$ or $\mathbb{R}^3$, linear dependence of two vectors means they are collinear (lie on the same line through the origin), and of three vectors means they are coplanar. If any vector in a set can be written as a linear combination of the others, the set is linearly dependent.

⚙️ Algebraic & Structural Meaning

Algebraically, linear dependence implies redundancy in a spanning set. The maximal number of linearly independent vectors defines the dimension of the subspace and corresponds directly to the rank of the associated matrix formed by these vectors.

Shortcut 5: Zero Vector Instant Trap

$$ \text{If } 0 \in \{v_1, v_2, \dots, v_n\}, \text{ then dependent} $$

Shortcut 6: Subset Extension Rule

$$ \text{Subset of Independent is Independent; Super-set of Dependent is Dependent} $$

Exam Rule: If a subset is dependent, any larger set containing it is automatically dependent.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Wronskian Zero vs Linear Independence

Common Pitfall: Assuming that a zero Wronskian $W=0$ everywhere implies linear dependence in all cases.

Counterexample: $f_1(x) = x^3, f_2(x) = |x|^3$

Why it fails: Functions can be linearly independent on an interval even if their Wronskian vanishes at certain points or subintervals if analyticity conditions fail.

🛡️ Exam Defense: Remember that $W=0$ is a necessary condition for linear dependence of differentiable functions, but sufficient only under analytic conditions.
⚠️ EXAM TRAP #02

Trap 2: Field Dependency Confusion

Common Pitfall: Ignoring the underlying field when testing independence (e.g., vectors over $\mathbb{R}$ vs $\mathbb{C}$).

Counterexample: Set $\{1, i\}$ over field $\mathbb{R}$ vs $\mathbb{C}$

Why it fails: $\{1, i\}$ is linearly independent over $\mathbb{R}$, but linearly dependent over $\mathbb{C}$ because $1(i) + (-i)(1) = 0$.

🛡️ Exam Defense: Always check the specified scalar field in the question statement before computing.

CANONICAL PROBLEM 01 Dual-Method Breakdown

If the vectors $(1, 2, 3)$, $(3, m, 7)$, and $(2, 3, 4)$ are linearly dependent, then the value of $m$ is:

(A) 4(B) 5(C) 6(D) 8
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Set up the determinant of the matrix formed by the three vectors and equate it to zero for linear dependence: $$\begin{vmatrix} 1 & 2 & 3 \\ 3 & m & 7 \\ 2 & 3 & 4 \end{vmatrix} = 0.$$ Expanding along the first row: $1(4m - 21) - 2(12 - 14) + 3(9 - 2m) = 0 \implies 4m - 21 - 2(-2) + 27 - 6m = 0 \implies -2m + 10 = 0 \implies m = 5$.
⚡ Method B: 25-Second Exam Shortcut
Observe row 3 and row 1: vector 3 is not directly proportional, but testing determinant via Sarrus rule or row operations $R_3 \to R_3 - 2R_1$ gives quick results.
💡 Key Takeaway: Whenever three 3-tuples are stated as linearly dependent, immediately write their determinant equal to zero.
CANONICAL PROBLEM 02 Dual-Method Breakdown

The set of functions $\{e^x, xe^x, x^2e^x\}$ on $\mathbb{R}$ is:

(A) Linearly dependent over $\mathbb{R}$(B) Linearly independent over $\mathbb{R}$(C) Linearly dependent only for $x = 0$(D) None of these
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Compute the Wronskian $W(e^x, xe^x, x^2e^x)$. $W = \begin{vmatrix} e^x & xe^x & x^2e^x \\ e^x & (x+1)e^x & (x^2+2x)e^x \\ e^x & (x+2)e^x & (x^2+4x+2)e^x \end{vmatrix} = 2e^{3x} \neq 0$ for all $x \in \mathbb{R}$. Thus, the functions are linearly independent.
⚡ Method B: 25-Second Exam Shortcut
Factor out $e^x$ from each column/row and recognize standard exponential-polynomial basis blocks.
💡 Key Takeaway: Sets of the form $x^k e^{rx}$ with distinct polynomials are always linearly independent.
