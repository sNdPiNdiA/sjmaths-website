1. Algebra — Matrices and Determinants

Skew-symmetric matrices

A square matrix $A$ is termed skew-symmetric if its transpose equals its negative, i.e., $A^T = -A$, forcing all its principal diagonal entries to be strictly zero. Because of their unique eigenvalue properties (purely imaginary or zero) and determinant characteristics for odd orders, skew-symmetric matrices form a high-scoring conceptual zone in UP TGT/PGT, KVS, and DSSSB examinations.

Pillar 1 Rigorous Definition & Mathematical Statement

Fundamental Decomposition Theorem for Square Matrices
Every square matrix $A$ can be uniquely expressed as the sum of a symmetric matrix $S$ and a skew-symmetric matrix $K$, given by $$A = \frac{1}{2}(A + A^T) + \frac{1}{2}(A - A^T)$$, where $S = \frac{1}{2}(A + A^T)$ is symmetric and $K = \frac{1}{2}(A - A^T)$ is skew-symmetric.

📐 Geometric Interpretation

In a linear transformation, a skew-symmetric matrix governs the rotational or infinitesimal orthogonal component (antisymmetric tensor field), leaving orthogonal invariants and generating rotations through matrix exponentials.

⚙️ Algebraic & Structural Meaning

The trace of any skew-symmetric matrix is zero, and its determinant for any odd dimension $n \times n$ is identically zero (i.e., $\det(A) = 0$ when $n$ is odd).

Shortcut 2: Eigenvalues of Skew-Symmetric Matrices

$$\text{Eigenvalues of } A \text{ are either } 0 \text{ or purely imaginary } (\pm i\beta)$$

Exam Rule: Real parts of all eigenvalues of a real skew-symmetric matrix are identically zero.

⚡ PYQ Context: Directly tested in DSSSB PGT and LT Grade examinations.
03

Shortcut 3: Trace Property

$$ \text{Tr}(A) = \sum_{i=1}^{n} a_{ii} = 0 $$

Exam Rule: Since all diagonal elements are zero, the trace of any skew-symmetric matrix is always zero.

⚡ PYQ Context: Used for quick elimination in matrix property options.
04

Shortcut 4: Power Properties of Skew-Symmetric Matrices

$$A^{2k} \text{ is symmetric, } A^{2k+1} \text{ is skew-symmetric}$$

Exam Rule: Even powers of a skew-symmetric matrix are symmetric, and odd powers are skew-symmetric.

⚡ PYQ Context: Asked in high-level UP PGT problems involving matrix polynomials.
05

Shortcut 5: Inverse of Skew-Symmetric Matrix (Even Order)

$$A^{-1} \text{ is skew-symmetric if } \det(A) \neq 0$$

Exam Rule: If an even-order skew-symmetric matrix is invertible, its inverse is also skew-symmetric.

⚡ PYQ Context: Standard assertion-reason question pattern.
06

Shortcut 6: Rapid Elimination via Diagonal Check

$$a_{11} = a_{22} = \dots = a_{nn} = 0$$

Exam Rule: Instantly reject any matrix option claiming to be skew-symmetric if any diagonal entry is non-zero.

⚡ PYQ Context: Time-saving elimination technique for 125-question papers.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Assuming Odd-Order Determinant is Non-Zero

Common Pitfall: Candidates spend valuable time calculating the determinant of a $3 \times 3$ skew-symmetric matrix.

Counterexample: For $A = \begin{pmatrix} 0 & 2 & -3 \\ -2 & 0 & 5 \\ 3 & -5 & 0 \end{pmatrix}$, $\det(A) = 0$

Why it fails: By skew-symmetry, $\det(A) = \det(A^T) = \det(-A) = (-1)^n \det(A)$. For odd $n$, $\det(A) = -\det(A) \implies 2\det(A) = 0 \implies \det(A) = 0$.

🛡️ Exam Defense: Never compute determinants of odd-order skew-symmetric matrices; mark 0 instantly.
⚠️ EXAM TRAP #02

Trap 2: Non-Zero Diagonal Entries in Options

Common Pitfall: Accepting matrices with non-zero entries on the main diagonal as skew-symmetric.

Counterexample: $A = \begin{pmatrix} 2 & 3 \\ -3 & 0 \end{pmatrix}$

Why it fails: $a_{11} = 2 \neq 0$, violating the fundamental necessity condition $A = -A^T$.

🛡️ Exam Defense: Scan the principal diagonal first before checking off-diagonal elements.

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

If $A$ is a skew-symmetric matrix of order $3$, what is the value of $\det(A)?$

(A) 1(B) -1(C) 0(D) \det(A)^3
✓ Correct Answer: (C)
📚 Method A: Formal Textbook Derivation
Let $A$ be of order $n$. Then $\det(A^T) = \det(-A) = (-1)^n \det(A)$. Since $A = A^T$, $\det(A) = (-1)^n \det(A)$. For $n = 3$ (odd), $\det(A) = -\det(A) \implies 2\det(A) = 0 \implies \det(A) = 0$.
⚡ Method B: 25-Second Exam Shortcut
Odd order skew-symmetric matrix determinant is always zero. Mark (C) in 2 seconds.
💡 Key Takeaway: Do not expand along rows; use the structural property directly.
CANONICAL PROBLEM 02 Dual-Method Breakdown

If $A = \begin{pmatrix} 0 & 2x & -2 \\ y & 0 & -4 \\ 2 & 4 & 0 \end{pmatrix}$ is a skew-symmetric matrix, find the values of $x$ and $y$.

(A) $x = -1/2, y = 4$(B) $x = -1, y = 2$(C) $x = 1/2, y = -4$(D) $x = 2, y = -2$
✓ Correct Answer: (C)
📚 Method A: Formal Textbook Derivation
For skew-symmetry, $a_{ij} = -a_{ji}$. Here $a_{12} = 2x$ and $a_{21} = y$, so $2x = -y$. Also $a_{13} = -2$ and $a_{31} = 2$ (satisfies $-2 = -2$). Check $a_{23} = -4$ and $a_{32} = 4$ (satisfies $-4 = -(-4)$). Thus $y = -2(2x) = -4x$. If $y = -4$, then $x = 1/2$.
⚡ Method B: 25-Second Exam Shortcut
Use $a_{ij} + a_{ji} = 0$. Hence $y + 2x = 0 \implies y = -2x$. Test options: only (C) gives $y = -4, x = 1/2$.
💡 Key Takeaway: Quickly verify cross-diagonal pairs sum to zero.

Pillar 7 10 Practice MCQs for Self-Assessment

Q1
MCQ 1: If $A$ is a square matrix, then $A - A^T$ is always a:
Derivation & Analysis:

Let $B = A - A^T$. Then $B^T = (A - A^T)^T = A^T - (A^T)^T = A^T - A = -(A - A^T) = -B$. Thus $B$ is skew-symmetric.

Q2
MCQ 2: The determinant of any skew-symmetric matrix of odd order is:
Derivation & Analysis:

For an odd order $n$, $\det(A) = \det(A^T) = \det(-A) = (-1)^n \det(A) = -\det(A)$, which implies $\det(A) = 0$.

Q3
MCQ 3: If $A$ and $B$ are skew-symmetric matrices of the same order, then $AB$ is symmetric if:
Derivation & Analysis:

$(AB)^T = B^T A^T = (-B)(-A) = BA$. For $AB$ to be symmetric, $(AB)^T = AB$, which requires $BA = AB$, meaning they commute under multiplication.

Q4
MCQ 4: All diagonal elements of a skew-symmetric matrix are:
Derivation & Analysis:

For skew-symmetric $A$, $a_{ii} = -a_{ii}$, which implies $2a_{ii} = 0 \implies a_{ii} = 0$ for all $i$.

Q5
MCQ 5: If $A$ is a skew-symmetric matrix, then $A^{2n}$ (where $n \in \mathbb{N}$) is a:
Derivation & Analysis:

$(A^{2n})^T = (A^T)^{2n} = (-A)^{2n} = (-1)^{2n} A^{2n} = A^{2n}$, hence it is symmetric.

Q6
MCQ 6: If $A = \begin{pmatrix} 0 & 1 & -2 \\ -1 & 0 & 3 \\ 2 & -3 & 0 \end{pmatrix}$, then $A$ is:
Derivation & Analysis:

Principal diagonal elements are zero and $a_{ij} = -a_{ji}$ for all $i \neq j$, so $A^T = -A$, confirming it is skew-symmetric.

Q7
MCQ 7: The eigenvalues of a real skew-symmetric matrix are:
Derivation & Analysis:

Real skew-symmetric matrices have eigenvalues that are either zero or purely imaginary numbers.

Q8
MCQ 8: If $A$ is any square matrix, then $A + A^T$ is:
Derivation & Analysis:

$(A + A^T)^T = A^T + (A^T)^T = A^T + A = A + A^T$, which proves $A + A^T$ is symmetric.

Q9
MCQ 9: If $A$ is a skew-symmetric matrix of order $2$, then $\det(A)$ can be expressed as:
Derivation & Analysis:

For order 2, $A = \begin{pmatrix} 0 & a \\ -a & 0 \end{pmatrix}$. Determinant is $0 - (-a^2) = a^2 = a_{12}^2$.

Q10
MCQ 10: Which of the following matrices cannot be skew-symmetric?
Derivation & Analysis:

The determinant of any odd-order skew-symmetric matrix is always 0. A determinant of 5 violates this structural theorem.
