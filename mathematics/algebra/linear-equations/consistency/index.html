Consistency of system of linear equations

The consistency of a system of linear equations determines whether a solution exists by analyzing the ranks and determinants of the coefficient and augmented matrices. Mastering Rouché-Capelli theorem and Cramer's rule is crucial for cracking high-scoring linear algebra problems in UP TGT/PGT, KVS, and DSSSB examinations.

Pillar 1 Rigorous Definition & Mathematical Statement

Rouché-Capelli Theorem (Kronecker-Capelli Theorem)
A system of $m$ linear equations in $n$ unknowns represented matrix-wise as $AX = B$ is consistent (i.e., possesses at least one solution) if and only if the rank of the coefficient matrix $A$ is equal to the rank of the augmented matrix $[A \mid B]$, that is, $\operatorname{rank}(A) = \operatorname{rank}([A \mid B])$. Furthermore, the system has a unique solution if $\operatorname{rank}(A) = \operatorname{rank}([A \mid B]) = n$, and infinitely many solutions if $\operatorname{rank}(A) = \operatorname{rank}([A \mid B]) < n$.

📐 Geometric Interpretation

In a system of linear equations, each equation represents a hyperplane in $\mathbb{R}^n$. Consistency implies that these hyperplanes intersect in at least one common point, line, or subspace. Inconsistent systems correspond to parallel, non-intersecting hyperplanes.

⚙️ Algebraic & Structural Meaning

It translates geometric intersection questions into purely algebraic rank-computation tasks using elementary row operations, Gauss-Jordan elimination, or determinant criteria.

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Cramer's Rule for Unique Solution

$$ \Delta = \det(A) \neq 0 $$

Exam Rule: If the determinant of the coefficient matrix $A$ is non-zero, the system is consistent and possesses a unique solution given by $x_i = \frac{\Delta_i}{\Delta}$.

⚡ PYQ Context: Directly tested in UP PGT to find parameter values for unique solutions.
02

Shortcut 2: Infinite Solutions Condition for Homogeneous System

$$ \det(A) = 0 $$

Exam Rule: A homogeneous system $AX = 0$ of $n$ equations in $n$ variables has non-trivial (infinitely many) solutions if and only if $\det(A) = 0$.

⚡ PYQ Context: Extremely frequent in TGT/PGT for finding values of $k$ where non-trivial solutions exist.
03

Shortcut 3: Inconsistency Condition

$$ \operatorname{rank}(A) \neq \operatorname{rank}([A \mid B]) $$

Exam Rule: If $\det(A) = 0$ but at least one Cramer determinant $\Delta_i \neq 0$, the system is strictly inconsistent (no solution).

⚡ PYQ Context: Used to eliminate options in parameter-based consistency questions.
04

Shortcut 4: Three Variable Plane Intersections

$$ \text{Check } \Delta, \Delta_x, \Delta_y, \Delta_z $$

Exam Rule: For 3 planes: $\Delta \neq 0 \implies$ unique intersection point. $\Delta = 0$ and all $\Delta_i = 0$ with $\operatorname{rank}(A)=2 \implies$ line of intersection (infinite solutions). $\Delta = 0$ and any $\Delta_i \neq 0 \implies$ parallel/no intersection.

⚡ PYQ Context: Standard 3-variable system questions in UP PGT Mathematics.
05

Shortcut 5: Homogeneous Overdetermined / Underdetermined Systems

$$ m < n \implies \text{Infinitely many solutions} $$

Exam Rule: A homogeneous system with fewer equations than variables ($m < n$) always has infinitely many solutions.

⚡ PYQ Context: Quick conceptual check for verbal or theory-based questions.
06

Shortcut 6: Rapid Substitution of Options

$$ \text{Test options for } k $$

Exam Rule: When asked for a value of a parameter $k$ making the system inconsistent, plug the option values into $\det(A)$ and check for vanishing determinants followed by non-zero augmented rank.

⚡ PYQ Context: Saves 2 minutes of full Gaussian elimination during exams.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Assuming $\det(A) = 0$ always means Infinite Solutions

Common Pitfall: Candidates jump to 'infinite solutions' whenever $\det(A) = 0$ for a non-homogeneous system.

Counterexample: $x + y = 1, \; x + y = 2$

Why it fails: Here $\det(A) = 0$, but the system is inconsistent (parallel lines, no solution) because $\operatorname{rank}(A) = 1 \neq \operatorname{rank}([A \mid B]) = 2$.

🛡️ Exam Defense: Always check $\Delta_x, \Delta_y, \Delta_z$ when $\det(A) = 0$ before concluding infinite solutions.
⚠️ EXAM TRAP #02

Trap 2: Ignoring Homogeneous System Consistency

Common Pitfall: Thinking a homogeneous system can be inconsistent.

Counterexample: $AX = 0$

Why it fails: The zero vector $X = 0$ is always a solution (trivial solution). Homogeneous systems are ALWAYS consistent.

🛡️ Exam Defense: Never mark 'inconsistent' for any homogeneous system of linear equations.

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

For what value of $k$ does the system of equations $x + y + z = 1$, $x + 2y + 3z = 2$, $x + 2y + kz = 4$ have no solution?

(A) $k = 3$(B) $k \neq 3$(C) $k = 2$(D) $k = 0$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Write coefficient matrix $A$ and compute $\det(A) = \begin{vmatrix} 1 & 1 & 1 \\ 1 & 2 & 3 \\ 1 & 2 & k \end{vmatrix}$. Step 2: Expand to get $\det(A) = 1(2k - 6) - 1(k - 3) + 1(0) = k - 3$. Step 3: For no solution, $\det(A) = 0 \implies k = 3$. Step 4: Substitute $k = 3$ into the augmented matrix to verify $\operatorname{rank}(A) \neq \operatorname{rank}([A \mid B])$.
⚡ Method B: 25-Second Exam Shortcut
Set $\det(A) = 0 \implies k = 3$. Since substituting $k=3$ creates a contradiction in the third row, $k=3$ yields no solution.
💡 Key Takeaway: Check if setting $\det(A)=0$ gives a unique critical value; if so, that is almost always the answer for 'no solution' or 'infinite solution' questions.
CANONICAL PROBLEM 02 Dual-Method Breakdown

The system of linear equations $kx + y + z = 1$, $x + ky + z = 1$, $x + y + kz = 1$ has no solution if $k$ equals:

(A) $1$(B) $-2$(C) $2$(D) $0$
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Step 1: Calculate $\det(A) = \begin{vmatrix} k & 1 & 1 \\ 1 & k & 1 \\ 1 & 1 & k \end{vmatrix} = (k-1)^2(k+2)$. Step 2: For no solution or infinite solutions, $\det(A) = 0 \implies k = 1$ or $k = -2$. Step 3: Test $k = 1$: all three equations become $x + y + z = 1$, which represents a single plane (infinitely many solutions). Step 4: Test $k = -2$: the sum of the left-hand sides is $-(-2+1+1)x\dots$ leading to a contradiction with the right-hand sides, confirming no solution at $k = -2$.
⚡ Method B: 25-Second Exam Shortcut
Use the determinant factor formula $\det(A) = (k+2)(k-1)^2$. $k=1$ gives identical equations (infinite solutions), hence $k=-2$ must give no solution.
💡 Key Takeaway: Remember that $k=1$ collapses the system to a single equation, yielding infinite solutions, leaving $k=-2$ as the inconsistency condition.

Pillar 7 10 Practice MCQs for Self-Assessment

Q1
MCQ 1: If the system $x + y + z = 0$, $2x + 3y + 2z = 0$, $x + 2y + az = 0$ has a non-trivial solution, then the value of $a$ is:
A $1$
B $2$
C $3$
D $0$
Derivation & Analysis:

For a homogeneous system to have a non-trivial solution, $\det(A) = 0$. $\begin{vmatrix} 1 & 1 & 1 \\ 2 & 3 & 2 \\ 1 & 2 & a \end{vmatrix} = 0 \implies 1(3a - 4) - 1(2a - 2) + 1(4 - 3) = 0 \implies a - 1 = 0 \implies a = 1$.

Q2
MCQ 2: A system of $n$ homogeneous linear equations in $n$ variables $AX = 0$ has a non-trivial solution if:
A $\det(A) \neq 0$
B $\det(A) = 0$
C $\operatorname{rank}(A) = n$
D $A$ is a null matrix
Derivation & Analysis:

A homogeneous system has a non-trivial (non-zero) solution if and only if the coefficient matrix is singular, i.e., $\det(A) = 0$.

Q3
MCQ 3: The system $x - 2y = 3$, $2x - 4y = 6$ has:
A A unique solution
B No solution
C Infinitely many solutions
D Two solutions
Derivation & Analysis:

The second equation is exactly twice the first ($2x - 4y = 6$). They represent the same line, hence the system has infinitely many solutions.

Q4
MCQ 4: If $\operatorname{rank}(A) \neq \operatorname{rank}([A \mid B])$ for the linear system $AX = B$, then the system is:
A Consistent with unique solution
B Consistent with infinite solutions
C Inconsistent (no solution)
D Trivially consistent
Derivation & Analysis:

By the Rouché-Capelli theorem, inequality of ranks ($\operatorname{rank}(A) \neq \operatorname{rank}([A \mid B])$) is the exact condition for system inconsistency.

Q5
MCQ 5: For what value of $\lambda$ does the system $x + y + z = 1$, $x + 2y + 4z = \lambda$, $x + 4y + 10z = \lambda^2$ be consistent?
A $\lambda = 1, 2$
B $\lambda = 2$
C $\lambda = 1$ only
D Any real number
Derivation & Analysis:

Applying consistency condition via determinant of augmented matrix or row reduction yields consistency when $\lambda = 1$ or $\lambda = 2$.

Q6
MCQ 6: If $A$ is a $3 \times 3$ matrix and $\det(A) = 0$, then the system $AX = D$ ($D \neq 0$) can never have:
A No solution
B Infinite solutions
C Unique solution
D Consistent solution
Derivation & Analysis:

Since $\det(A) = 0$, $\operatorname{rank}(A) < 3$, meaning a unique solution is impossible. It can either have no solution or infinitely many solutions.

Q7
MCQ 7: The number of solutions of the system $2x + y = 5$, $x - y = 1$, $3x + 2y = 8$ is:
A 0
B 1
C 2
D Infinite
Derivation & Analysis:

Solving the first two equations gives $x = 2, y = 1$. Substituting into the third: $3(2) + 2(1) = 8$, which satisfies the third equation. Thus, the unique solution is $(2, 1)$.

Q8
MCQ 8: Assertion (A): A homogeneous system of 4 linear equations in 3 variables always has a non-trivial solution. Reason (R): Such a system always has fewer equations than variables.
A Both (A) and (R) are true and (R) is the correct explanation of (A)
B Both (A) and (R) are true but (R) is not the correct explanation of (A)
C (A) is true but (R) is false
D (A) is false but (R) is true
Derivation & Analysis:

A homogeneous system with 4 equations and 3 variables has $m = 4, n = 3$, so $m > n$ (more equations than variables). Thus Reason (R) is false. However, (A) is true because any homogeneous system with $\operatorname{rank}(A) < 3$ (which happens when $\det = 0$ on submatrices) has non-trivial solutions.

Q9
MCQ 9: If the system $kx - y = 2$ and $6x - 2y = 3$ has no solution, then $k =$
A 3
B -3
C 2
D 0
Derivation & Analysis:

For no solution in two variables, $\frac{a_1}{a_2} = \frac{b_1}{b_2} \neq \frac{c_1}{c_2}$. Here $\frac{k}{6} = \frac{-1}{-2} = \frac{1}{2} \implies k = 3$.

Q10
MCQ 10: If $A$ is a non-singular square matrix of order $n$, then the system $AX = B$ has:
A No solution
B Infinitely many solutions
C A unique solution $X = A^{-1}B$
D Dependent solutions
Derivation & Analysis:

If $A$ is non-singular ($\det(A) \neq 0$), $A^{-1}$ exists, and multiplying $AX = B$ by $A^{-1}$ yields the unique solution $X = A^{-1}B$.
