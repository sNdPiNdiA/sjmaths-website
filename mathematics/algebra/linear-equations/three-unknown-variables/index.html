1. Algebra — Matrices and Determinants

Solving linear equations in three variables

Mastering the simultaneous solution of three linear equations using matrices, determinants, and Cramer's Rule is essential for competitive examinations like UP TGT/PGT and DSSSB. Geometrically, this involves analyzing the relative positions of three planes in three-dimensional space $\mathbb{R}^3$ to determine whether they intersect at a unique point, form a sheaf, or have no common intersection.

Pillar 1 Rigorous Definition & Mathematical Statement

Cramer's Rule and Matrix Rank Theorem for Three Variables
Consider a system of three linear equations in three unknowns $x, y, z$: $$a_1x + b_1y + c_1z = d_1$$ $$a_2x + b_2y + c_2z = d_2$$ $$a_3x + b_3y + c_3z = d_3$$ Let $A$ be the coefficient matrix, $X$ the variable column vector, and $B$ the constant column vector. The system has a unique solution if and only if $\det(A) \neq 0$. If $\det(A) = 0$, the system is consistent with infinitely many solutions or inconsistent depending on the ranks of $A$ and the augmented matrix $[A \mid B]$.

📐 Geometric Interpretation

Each linear equation represents a plane in $\mathbb{R}^3$. A unique solution means the three planes intersect at a single distinct point. Infinitely many solutions mean they intersect along a common line or coincide. No solution means the planes are parallel or form a triangular prism with no common intersection.

⚙️ Algebraic & Structural Meaning

Translates geometric intersections of planes into linear algebra through matrix invertibility, determinant non-vanishing, and rank-nullity relations encapsulated by the Kronecker-Capelli theorem.

Pillar 2 Hypotheses & Condition Checklist

Every hypothesis is strictly non-negotiable. Inspect the domain type and the exact consequence if a condition fails:

Hypothesis / Condition Domain / Interval Necessity What Fails If Condition Dropped
Non-zero Determinant (Unique Solution) $\det(A) \neq 0$ Strictly Mandatory / Necessary If $\det(A) = 0$, Cramer's Rule fails completely (division by zero), and the system either has no solution or infinitely many solutions.
Rank Consistency (Kronecker-Capelli Condition) $\text{rank}(A) = \text{rank}([A \mid B]) Strictly Mandatory for Consistency If $\text{rank}(A) \neq \text{rank}([A \mid B])$ (specifically $\text{rank}(A) < \text{rank}([A \mid B])$), the system is inconsistent and possesses zero solutions.
Parameter Dependency for Infinitely Many Solutions $\text{rank}(A) = \text{rank}([A \mid B]) < 3$ Essential condition If rank condition is met but rank equals 3, the solution is unique. If rank is less than 3, degrees of freedom emerge, leading to parametric infinite solutions.

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Cramer's Rule Formulae for $x, y, z$

$$x = \frac{D_x}{D}, \quad y = \frac{D_y}{D}, \quad z = \frac{D_z}{D}$$

Exam Rule: When finding only one variable (e.g., $y$), immediately construct $D_y$ by replacing the $y$-column with $B$, and divide by $D = \det(A)$ without solving the full system.

⚡ PYQ Context: Frequently asked in UP PGT to find the value of a single variable or parameter $k$ for unique solutions.
02

Shortcut 2: Homogeneous System Non-Trivial Solution

$$D = \det(A) = 0$$

Exam Rule: For a homogeneous system ($d_1 = d_2 = d_3 = 0$), a non-trivial (non-zero) solution exists if and only if the determinant of the coefficient matrix vanishes.

⚡ PYQ Context: A staple question type in UP TGT and KVS PGT asking for the value of parameter $\lambda$ for which the system has non-trivial solutions.
03

Shortcut 3: Condition for Infinitely Many Solutions in Homogeneous Systems

$$D = 0 \text{ and at least one } 2 \times 2 minor \neq 0$$

Exam Rule: If $D = 0$ and all $2 \times 2$ determinants of $A$ also vanish, the matrix rank is 1, meaning two equations are scalar multiples of the third.

⚡ PYQ Context: Directly applied in LT Grade and DSSSB exams to classify plane configurations.
04

Shortcut 4: Symmetric Equations Sum Trick

$$x + y + z = \frac{\sum d_i}{\sum a_i} \text{ (when coefficients sum equally)}$$

Exam Rule: If the sum of coefficients of $x, y, z$ in each equation is identical, add all three equations together to instantly get a single linear relation in $(x + y + z)$.

⚡ PYQ Context: Time-saving trick for symmetric cyclic equations often set in competitive exams.
05

Shortcut 5: Determinant Expansion via Sarrus Rule or Properties

$$|A| = a_1(b_2c_3 - b_3c_2) - b_1(a_2c_3 - a_3c_2) + c_1(a_2b_3 - a_3b_2)$$

Exam Rule: Use row/column operations ($R_i \to R_i + kR_j$) to create zeros before expanding to cut calculation time by 70%.

⚡ PYQ Context: Essential speed technique for 125-question exams where time per question is under 50 seconds.
06

Shortcut 6: Option Substitution Method

$$Ax = B$$

Exam Rule: Substitute the given options $(x, y, z)$ directly into the equations. The correct option must satisfy all three equations simultaneously.

⚡ PYQ Context: The ultimate exam-hall hack for numerical systems when determinants are messy.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Assuming $D = 0$ Always Means Infinitely Many Solutions

Common Pitfall: Candidates jump to the conclusion that $\det(A) = 0$ automatically implies infinite solutions, forgetting the inconsistent case (zero solutions).

Counterexample: $x + y + z = 1$, $x + y + z = 2$, $x + y + z = 3$

Why it fails: Here $D = 0$, but the planes are parallel and distinct, resulting in $\text{rank}(A) = 1 \neq \text{rank}([A \mid B]) = 2$. Thus, there are zero solutions.

🛡️ Exam Defense: Always check the augmented matrix rank or consistency check ($D_x, D_y, D_z$ values) when $D = 0$ before declaring infinite solutions.
⚠️ EXAM TRAP #02

Trap 2: Ignoring Sign Errors in Cofactor Expansion

Common Pitfall: Missing the alternating negative sign in the second term during $3 \times 3$ determinant expansion ($-\begin{vmatrix} \cdot \end{vmatrix}$).

Counterexample: $-\begin{vmatrix} a_2 & c_2 \\ a_3 & c_3 \\ \end{vmatrix}$ written as $+ \dots$

Why it fails: Leads to an incorrect determinant sign, yielding a wrong parameter value that is invariably placed as Option (A) or (B).

🛡️ Exam Defense: Use the standard sign checker matrix $\begin{pmatrix} + & - & + \\ - & + & - \\ + & - & + \end{pmatrix}$ mentally during expansion.

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

For what value of $k$ does the system of equations $x + y + z = 1$, $x + 2y + 3z = 2$, $x + 2y + ky^2 = 4$ (Wait, standard exam variant: $x + 2y + 3z = 2$, $x + 2y + kz = 4$) fail to have a unique solution?

(A) $k = 3$(B) $k \neq 3$(C) $k = 0$(D) $k = 1$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Form coefficient matrix $A = \begin{pmatrix} 1 & 1 & 1 \\ 1 & 2 & 3 \\ 1 & 2 & k \end{pmatrix}$. Step 2: Compute $\det(A) = 1(2k - 6) - 1(k - 3) + 1(2 - 2) = 2k - 6 - k + 3 = k - 3$. Step 3: For unique solution, $\det(A) \neq 0 \implies k \neq 3$. Therefore, uniqueness fails when $k = 3$.
⚡ Method B: 25-Second Exam Shortcut
Set determinant equal to zero for non-unique solution: $k - 3 = 0 \implies k = 3$.
💡 Key Takeaway: Look out for wording like 'fails to have a unique solution' vs 'has no solution'. Fails to have unique means $D = 0$.
CANONICAL PROBLEM 02 Dual-Method Breakdown

If the system $kx + y + z = 1$, $x + ky + z = 1$, $x + y + kz = 1$ has no solution, then the value of $k$ is:

(A) $1$(B) $-1$(C) $-2$(D) $2$
✓ Correct Answer: (C)
📚 Method A: Formal Textbook Derivation
Step 1: Find determinant $D = \begin{vmatrix} k & 1 & 1 \\ 1 & k & 1 \\ 1 & 1 & k \end{vmatrix} = (k-1)^2(k+2)$. Step 2: Set $D = 0 \implies k = 1$ or $k = -2$. Step 3: Test $k = 1$. All equations become $x+y+z=1$, which gives infinite solutions. Step 4: Test $k = -2$. The sum of the first three equations gives $-(x+y+z) = 3$, while substituting in $D_x$ reveals inconsistency. Thus $k = -2$ yields no solution.
⚡ Method B: 25-Second Exam Shortcut
Use the property for cyclic symmetric determinants: $D = (k+1+1)(k-1)^2$ or similar factorization. For $k = -2$, $D=0$ and rows create contradiction.
💡 Key Takeaway: When $k=1$, the equations degenerate into a single plane, giving infinite solutions. Always check root multiplicity.

Q1
MCQ 1: The system of linear equations $x + y + z = 3$, $x + 2y + 3z = 4$, $x + 4y + ks^2 z = 6$ (let $kx = 5$) has a unique solution if:
A (A) $k \neq 9$
B (B) $k = 9$
C (C) $k \neq 3$
D (D) $k = 3$
Derivation & Analysis:

Evaluate the determinant of the coefficient matrix and equate it to zero to find the exception for uniqueness.

Q2
MCQ 2: For what value of $\lambda$ do the equations $x + y - z = 1$, $2x + 3y + k z = 2$, $x + 2y + 3z = 3$ fail to have a unique solution?
A (A) $5$
B (B) $-5$
C (C) $3$
D (D) $0$
Derivation & Analysis:

Calculate $\det(A) = 0$ to find the critical parameter value where the determinant vanishes.

Q3
MCQ 3: If the homogeneous system $ax + y + z = 0$, $x + by + z = 0$, $x + y + cz = 0$ has a non-trivial solution, then $\frac{1}{1-a} + \frac{1}{1-b} + \frac{1}{1-c}$ equals:
A (A) $0$
B (B) $1$
C (C) $-1$
D (D) $\frac{1}{abc}$
Derivation & Analysis:

Non-trivial solution requires $D = 0$. Using algebraic manipulation on the determinant yields the required sum identity equal to 1.

Q4
MCQ 4: The number of solutions of the system $x + 2y + 3z = 1$, $2x + 4y + 6z = 3$, $3x + 6y + 9z = 5$ is:
A (A) 0
B (B) 1
C (C) 2
D (D) Infinite
Derivation & Analysis:

Notice that the left-hand sides are proportional while the right-hand sides are not in the same proportion, indicating parallel planes and zero solutions.

Q5
MCQ 5: If the system $x = a(y + z)$, $y = b(z + x)$, $z = c(x + y)$ has a non-trivial solution for $(x, y, z)$, then $\frac{a}{1+a} + \frac{b}{1+b} + \frac{c}{1+c}$ is:
A (A) 0
B (B) 1
C (C) 2
D (D) 3
Derivation & Analysis:

Rewrite as $x - ay - az = 0$, $-bx + y - bz = 0$, $-cx - cy + z = 0$. Set determinant to zero and simplify to get 1.

Q6
MCQ 6: Cramer's rule is applicable to solve a system of three linear equations when the coefficient matrix is:
A (A) Singular
B (B) Non-singular
C (C) Symmetric
D (D) Skew-symmetric
Derivation & Analysis:

Cramer's rule requires division by $D = \det(A)$, which is valid only when $A$ is non-singular ($D \neq 0$).

Q7
MCQ 7: The system $kx + y + z = 0$, $x + ky + z = 0$, $x + y + kz = 0$ has non-trivial solutions for $k =
A (A) 1 or -2
B (B) -1 or 2
C (C) 1 only
D (D) -2 only
Derivation & Analysis:

Determinant is $(k-1)^2(k+2) = 0$, giving $k = 1$ and $k = -2$.

Q8
MCQ 8: If $\det(A) = 0$ and $D_x = D_y = D_z = 0$ for a system of three linear equations, the system necessarily has:
A (A) Unique solution
B (B) No solution
C (C) Infinitely many solutions
D (D) Trivial solution only
Derivation & Analysis:

When $D = 0$ and all numerator determinants vanish, the system is consistent with dependent equations, leading to infinitely many solutions.

Q9
MCQ 9: What is the geometric interpretation of three planes intersecting along a common line?
A (A) Unique solution
B (B) No solution
C (C) Infinitely many solutions
D (D) Inconsistent system
Derivation & Analysis:

An entire line of intersection contains infinitely many points, each representing a valid $(x, y, z)$ solution.

Q10
MCQ 10: For the system $2x + y + z = 1$, $x + 2y + z = 2$, $x + y + 2z = 3$, the value of $x$ is:
A (A) $-1/4$
B (B) $1/4$
C (C) $1/2$
D (D) $3/4$
Derivation & Analysis:

Compute $D = 4$ and $D_x = -1$, hence $x = D_x/D = -1/4$.

Pillar 8 Frequently Asked Questions

Use Cramer's Rule when asked for a single variable or when evaluating parameter conditions ($k$) for unique/non-unique solutions. Use Matrix Inversion or Gaussian Elimination when solving for all variables with fixed numerical coefficients.

Candidates often check only $D = 0$ and stop. When $D = 0$, you must check $D_x, D_y, D_z$. If even one of them is non-zero, the system has zero solutions. If all are zero, it typically has infinite solutions (subject to rank confirmation).

Typically 4 to 6 questions directly test matrices, determinants, and linear equation systems in UP PGT/TGT examinations, making it a high-yield scoring area.

Master row/column operations to create at least two zeros in a row or column before expanding, or practice direct Sarrus expansion to avoid arithmetic errors under exam pressure.
