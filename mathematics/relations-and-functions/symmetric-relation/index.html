1. Algebra — Relations and Functions

Symmetric relation

A symmetric relation on a set $A$ is a binary relation $R$ where the presence of $(a, b) \in R$ universally guarantees the presence of $(b, a) \in R$ for all $a, b \in A$. Because of its clean algebraic reversibility, it is a high-yield conceptual testing zone in UP TGT/PGT, DSSSB, and KVS examinations.

Pillar 1 Rigorous Definition & Mathematical Statement

Definition of Symmetric Relation
Let $A$ be a non-empty set. A relation $R$ on $A$ (i.e., $R \subseteq A \times A$) is said to be symmetric if and only if \forall a, b \in A, \, (a, b) \in R \implies (b, a) \in R.

📐 Geometric Interpretation

On the Cartesian plane $A \times A$, a symmetric relation exhibits complete reflectional symmetry across the principal diagonal line $y = x$. If a point $(x_0, y_0)$ belongs to the relation graph, its mirror point $(y_0, x_0)$ also necessarily lies on the graph.

⚙️ Algebraic & Structural Meaning

Algebraically, symmetry means the inverse relation $R^{-1}$ is identical to $R$ itself ($R = R^{-1}$). In terms of adjacency matrices over a finite set, the boolean matrix representation is a symmetric matrix equal to its transpose ($M_R = M_R^T$).

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Matrix Transpose Test for Finite Sets

$$M_R = M_R^T$$

Exam Rule: Construct the boolean adjacency matrix of the relation. If the matrix is symmetric across its main diagonal, the relation is symmetric instantly without checking pairs one by one.

⚡ PYQ Context: Frequently tested in UP PGT and DSSSB PGT for relations defined on finite sets like $A = \{1, 2, 3\}$.
02

Shortcut 2: Inverse Relation Identity

$$R = R^{-1}$$

Exam Rule: If you can algebraically or logically show that swapping coordinates yields the exact same condition defining the relation, it is symmetric.

⚡ PYQ Context: Standard question format in KVS and NVS exams for relations on $\mathbb{R}$.
03

Shortcut 3: Counting Symmetric Relations

$$2^{\frac{n(n+1)}{2}}$$තික

Exam Rule: For a finite set $A$ containing $n$ elements, the total number of symmetric relations is given by $2^{\frac{n(n+1)}{2}}$, where $\frac{n(n+1)}{2}$ counts the diagonal and upper-triangular positions.

⚡ PYQ Context: Direct formula-based question repeatedly asked in UP TGT/PGT examinations.
04

Shortcut 4: Equality and Congruence Relations

$$xRy \iff x \equiv y \pmod m$$

Exam Rule: Equivalence relations (like congruence modulo $m$, equality, perpendicularity of lines) are automatically symmetric. Never waste time testing $(b, a)$ for them.

⚡ PYQ Context: Time-saving property used across all teaching exams to skip lengthy checks.
05

Shortcut 5: Algebraic Inequality Trap Check

$$x < y \implies y < x \text{ (False)}$$

Exam Rule: Strict inequalities ($<$ or $>$) are never symmetric because $a < b$ does not imply $b < a$. Non-strict inequalities ($\le$ or $\ge$) are antisymmetric, not symmetric.

⚡ PYQ Context: Classic option-elimination trick in state board PGT tests.
06

Shortcut 6: Rapid Elimination via Counterexample

$$ \text{Find } (a,b) \in R \text{ such that } (b,a) \notin R $$

Exam Rule: To disprove symmetry, test integers or small values like $(1, 2)$. If $1$ relates to $2$ but $2$ does not relate to $1$, eliminate the option immediately.

⚡ PYQ Context: Crucial time management strategy in 125-question PGT papers.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Confusing Reflexive with Symmetric

Common Pitfall: Candidates assume that if a relation contains all diagonal elements $(a, a)$, it must be symmetric.

Counterexample: R = \{(1,1), (2,2), (1,2)\} \text{ on } \{1, 2\}

Why it fails: Here $(1, 2) \in R$, but $(2, 1) \notin R$. Hence, the relation is reflexive but NOT symmetric.

🛡️ Exam Defense: Always check off-diagonal pairs independently of diagonal elements.
⚠️ EXAM TRAP #02

Trap 2: Assuming Antisymmetric means Not Symmetric

Common Pitfall: Believing that a relation cannot be both symmetric and antisymmetric.

Counterexample: R = \{(1,1), (2,2)\} \text{ on } \{1, 2\}

Why it fails: This relation is both symmetric and antisymmetric (since $(a,b) \in R \implies a=b$).

🛡️ Exam Defense: Check definitions strictly: symmetry and antisymmetry are mutually exclusive only for distinct elements, but can overlap on diagonal pairs.

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

Let $A = \{1, 2, 3\}$. How many symmetric relations can be defined on set $A$?

(A) 64(B) 32(C) 512(D) 16
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Identify cardinality $n = 3$. Step 2: Apply the formula for the number of symmetric relations $2^{\frac{n(n+1)}{2}}$. Step 3: Compute $2^{\frac{3(4)}{2}} = 2^6 = 64$.
⚡ Method B: 25-Second Exam Shortcut
Direct formula recall: $n=3 \implies 2^{3 \times 4 / 2} = 64$. Mark option (A) in 5 seconds.
💡 Key Takeaway: Memorize values for $n=1, 2, 3, 4$ ($2, 8, 64, 1024$) to save calculation time.
CANONICAL PROBLEM 02 Dual-Method Breakdown

On the set of integers $\mathbb{Z}$, let relation $R$ be defined by $xRy \iff x + y$ is an even integer. Then $R$ is:

(A) Reflexive only(B) Symmetric only(C) Equivalence relation(D) Transitive only
✓ Correct Answer: (C)
📚 Method A: Formal Textbook Derivation
Step 1: Reflexivity: $x + x = 2x$ (even), so reflexive. Step 2: Symmetry: If $x + y$ is even, $y + x$ is also even, so symmetric. Step 3: Transitivity: If $x+y$ and $y+z$ are even, their sum $(x+y)+(y+z) = x+z + 2y$ is even, implying $x+z$ is even, hence transitive.
⚡ Method B: 25-Second Exam Shortcut
Recognize modular arithmetic properties: congruence modulo 2 or parity relations are always equivalence relations.
💡 Key Takeaway: Any relation defined by sum/difference being divisible by a fixed integer $m$ is always an equivalence relation.

Pillar 7 10 Practice MCQs for Self-Assessment

Q1
MCQ 1: If $R$ is a symmetric relation on a set $A$, then $R^{-1}$ is:
A $R^{-1} \neq R$
B $R^{-1} = R$
C $R^{-1} = \emptyset$
D $R^{-1} = A \times A$
Derivation & Analysis:

By definition, symmetry means $(a,b) \in R \iff (b,a) \in R$, which is precisely the definition of the inverse relation being equal to $R$.

Q2
MCQ 2: The number of symmetric relations on a set containing $4$ elements is:
A $64$
B $256$
C $512$
D $1024$
Derivation & Analysis:

Using formula $2^{\frac{n(n+1)}{2}}$ with $n=4$: $2^{\frac{4(5)}{2}} = 2^{10} = 1024$.

Q3
MCQ 3: Let $R = \{(1,2), (2,1), (1,1)\} \n on $A = \{1, 2}$. The relation $R$ is:
A Symmetric only
B Equivalence relation
C Symmetric and Reflexive
D Not symmetric
Derivation & Analysis:

It contains $(1,1)$ but lacks $(2,2)$, so it is NOT reflexive. However, for every $(1,2)$ there is $(2,1)$, and for $(1,1)$ its reverse is $(1,1)$, making it symmetric. It also includes $(1,1)$, so it has reflexive elements for ${1}$ but fails full set reflexivity. Wait, $(2,2)$ is missing, so it is NOT reflexive on $A=\{1,2}$. Let's check options: it is symmetric.

Q4
MCQ 4: Which of the following relations on $\mathbb{R}$ is symmetric?
A $R = \{(x,y) : x \le y\}$
B $R = \{(x,y) : x - y \in \mathbb{Q}\}$
C $R = \{(x,y) : x > 2y\}$
D $R = \{(x,y) : x = 2y\}$
Derivation & Analysis:

If $x - y$ is rational, then $y - x = -(x - y)$ is also rational. Thus $R$ is symmetric. Other options fail symmetry.

Q5
MCQ 5: If $R_1$ and $R_2$ are two symmetric relations on set $A$, then $R_1 \cap R_2$ is:
A Always symmetric
B Never symmetric
C Transitive only
D Reflexive only
Derivation & Analysis:

If $(a,b) \in R_1 \cap R_2$, then $(a,b) \in R_1$ and $(a,b) \in R_2$. By symmetry, $(b,a) \in R_1$ and $(b,a) \in R_2$, so $(b,a) \in R_1 \cap R_2$.

Q6
MCQ 6: The empty relation $\Phi$ on a non-empty set $A$ is:
A Not symmetric
B Symmetric vacuously
C Reflexive
D Equivalence
Derivation & Analysis:

The condition $(a,b) \in \Phi \implies (b,a) \in \Phi$ is vacuously true because the hypothesis $(a,b) \in \Phi$ is never satisfied.

Q7
MCQ 7: Universal relation $U = A \times A$ on a non-empty set $A$ is:
A Symmetric only
B Reflexive only
C An equivalence relation
D Not symmetric
Derivation & Analysis:

The universal relation is always reflexive, symmetric, and transitive, hence an equivalence relation.

Q8
MCQ 8: Let $R$ be a relation on $\mathbb{Z}$ defined by $xRy \iff xy > 0$. Then $R$ is:
A Symmetric and Reflexive
B Symmetric but not Reflexive
C Transitive only
D None of these
Derivation & Analysis:

If $xy > 0$, then $yx > 0$, so symmetric. If $x=0$, $0 \times 0 = 0 \ngtr 0$, so not reflexive. Thus symmetric but not reflexive.

Q9
MCQ 9: If a relation is both symmetric and antisymmetric on a set $A$, then $R$ must be a subset of:
A The diagonal relation $\Delta$
B $A \times A$
C An empty set
D The inverse relation
Derivation & Analysis:

If $(a,b) \in R$, then by symmetry $(b,a) \in R$. By antisymmetry, this implies $a = b$. Thus, $R$ can only contain pairs of the form $(a,a)$, meaning $R \subseteq \Delta$.

Q10
MCQ 10: Let $A = \{1, 2, 3}$. The maximum number of elements in a symmetric relation on $A$ which is not reflexive is:
A 9
B 7
C 6
D 8
Derivation & Analysis:

Total symmetric relations is 64. Reflexive symmetric relations have all 3 diagonal elements fixed, leaving 3 pairs above diagonal, giving $2^3 = 8$ reflexive symmetric relations. Thus non-reflexive symmetric relations = $64 - 8 = 56$. Wait, looking at maximum elements: a symmetric relation on 3 elements can have at most $3 + 2(3) = 9$ elements. If not reflexive, it must omit at least one diagonal element, so maximum elements = $9 - 1 = 8$.
