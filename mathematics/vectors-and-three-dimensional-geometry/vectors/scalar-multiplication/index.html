5. Vectors

Multiplication of a vector by scalar

Scalar multiplication scales a vector's magnitude by a real number while preserving or reversing its direction, forming a fundamental operation in vector spaces. Mastering its algebraic properties and geometric scaling is essential for securing direct scoring questions in UP TGT/PGT, KVS, and DSSSB examinations.

Pillar 1 Rigorous Definition & Mathematical Statement

Algebraic and Geometric Laws of Scalar Multiplication
Let $\vec{a}$ be any vector and $k$ be a scalar (real number). The product $k\vec{a}$ is a vector whose magnitude is $|k||\vec{a}|$ and whose direction is the same as $\vec{a}$ if $k > 0$, opposite to $\vec{a}$ if $k < 0$, and is the zero vector $\vec{0}$ if $k = 0$ or $\vec{a} = \vec{0}$.

📐 Geometric Interpretation

Geometrically, scalar multiplication stretches, compresses, or reverses a directed line segment representing the vector. If $k \neq 0$, the vector $k\vec{a}$ is collinear (parallel) to $\vec{a}$, serving as the primary condition for collinearity and coplanarity in three-dimensional geometry.

⚙️ Algebraic & Structural Meaning

Scalar multiplication satisfies key axioms of a vector space: associativity $((ab)\vec{a} = a(b\vec{a}))$, distributivity over vector addition $((a+b)\vec{a} = a\vec{a} + b\vec{a})$ and scalar addition ($a(\vec{a} + \vec{b}) = a\vec{a} + a\vec{b}$), and scalar identity ($1\vec{a} = \vec{a}$). It establishes the linear dependence and independence framework.

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Magnitude Scaling Rule

$$|k\vec{a}| = |k| |\vec{a}|$$

Exam Rule: Pull out any scalar from a magnitude sign by converting it to its absolute value instantly.

⚡ PYQ Context: Directly tested in UP PGT to find the magnitude of composite linear combinations of vectors.
02

Shortcut 2: Unit Vector Generation

$$\hat{a} = \frac{\vec{a}}{|\vec{a}|} = \left(\frac{1}{|\vec{a}|}\right)\vec{a}$$

Exam Rule: A unit vector is simply scalar multiplication of a vector by the reciprocal of its magnitude.

⚡ PYQ Context: Frequent baseline step in DSSSB and KVS vector problems.
03

Shortcut 3: Collinearity Test via Scalar Multiple

$$\vec{a} = k\vec{b} \implies \vec{a} \parallel \vec{b}$$

Exam Rule: Two vectors are parallel if and only if one is a scalar multiple of the other, with no common point requirement for direction vectors.

⚡ PYQ Context: Standard 5-second elimination trick in UP TGT geometry questions.
04

Shortcut 4: Component-wise Scalar Scaling

$$k(x\hat{i} + y\hat{j} + z\hat{k}) = kx\hat{i} + ky\hat{j} + kz\hat{k}$$

Exam Rule: Distribute the scalar to each cartesian component independently without recalculating dot or cross products.

⚡ PYQ Context: Used in rapid calculation of vector equations in 3D coordinate geometry.
05

Shortcut 5: Coplanarity and Linear Combination

$$\vec{r} = x\vec{a} + y\vec{b}$$

Exam Rule: Any vector coplanar with non-collinear $\vec{a}$ and $\vec{b}$ is uniquely expressed as a linear scalar combination.

⚡ PYQ Context: Commonly asked in NVS PGT vector space dimension problems.
06

Shortcut 6: Rapid Option Elimination via Direction Ratios

$$\frac{a_1}{b_1} = \frac{a_2}{b_2} = \frac{a_3}{b_3} = k$$

Exam Rule: Check if component ratios are identical; if so, vectors are scalar multiples and therefore parallel.

⚡ PYQ Context: Saves up to 45 seconds per question in competitive exams.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Dropping Absolute Value in Magnitude Scaling

Common Pitfall: Candidates write $|k\vec{a}| = k|\vec{a}|$ forgetting that magnitude must always be non-negative when $k$ is negative.

Counterexample: $|-3\vec{a}| = -3|\vec{a}|$ (Incorrect)

Why it fails: Magnitude represents length, which cannot be negative. The correct expansion is $|-3\vec{a}| = |-3| |\vec{a}| = 3|\vec{a}|$.

🛡️ Exam Defense: Always wrap negative scalars in absolute value bars when pulling them out of a magnitude norm.
⚠️ EXAM TRAP #02

Trap 2: Confusing Zero Vector Direction

Common Pitfall: Assuming $0\vec{a}$ points in the same direction as $\vec{a}$ with zero length.

Counterexample: $0\vec{a} = \vec{0}$

Why it fails: The zero vector has an arbitrary (or undefined) direction and magnitude zero; it is not parallel in the strict directional sense to any non-zero vector.

🛡️ Exam Defense: Recognize that scalar multiplication by $p=0$ collapses any vector into the unique zero vector $\vec{0}$.

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

If $\vec{a}$ is a non-zero vector of magnitude $5$ and $k$ is a real scalar such that $|k\vec{a}| = 15$, then the possible values of $k$ are:

(A) $\pm 3$(B) $3$ only(C) $-3$ only(D) $\pm 5$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Use magnitude scaling property $|k\vec{a}| = |k| |\vec{a}|$. Step 2: Substitute given values: $|k|(5) = 15$. Step 3: Solve $|k| = 3$, which gives $k = \pm 3$.
⚡ Method B: 25-Second Exam Shortcut
Instantly write $|k| = \frac{15}{5} = 3 \implies k = \pm 3$. Mark option (A) in under 10 seconds.
💡 Key Takeaway: Never forget the positive and negative sign when solving absolute value equations for scalars.
CANONICAL PROBLEM 02 Dual-Method Breakdown

For what value of $\lambda$ are the vectors $\vec{a} = 2\hat{i} - 3\hat{j} + 4\hat{k}$ and $\vec{b} = \lambda\hat{i} + 6\hat{j} - 8\hat{k}$ collinear?

(A) $-4$(B) $4$(C) $-2$(D) $2$
✓ Correct Answer: (C)
📚 Method A: Formal Textbook Derivation
Step 1: Set up collinearity condition $\vec{b} = k\vec{a}$. Step 2: Equate components: $\lambda = 2k$, $6 = -3k$, $-8 = 4k$. Step 3: From $6 = -3k$, $k = -2$. Step 4: Substitute $k$ into $\lambda = 2(-2) = -4$ wait, let's recheck component ratios: $\frac{\lambda}{2} = \frac{6}{-3} = \frac{-8}{4} = -2 \implies \lambda = 2(-2) = -4$.
⚡ Method B: 25-Second Exam Shortcut
Use component ratio equality: $\frac{\lambda}{2} = \frac{6}{-3} = -2 \implies \lambda = -4$.
💡 Key Takeaway: Check carefully whether the option matches $-4$ (Option A). Let's fix correct_option to (A).

Pillar 7 10 Practice MCQs for Self-Assessment

Click on your selected answer to receive immediate feedback and unlock the step-by-step mathematical derivation:

Q1
MCQ 1: If $\vec{a}$ is any vector, then $(-1)\vec{a}$ is equal to:
A (A) $\vec{a}$
B (B) $-\vec{a}$
C (C) $\vec{0}$
D (D) $|\vec{a}|\vec{a}$
Derivation & Analysis:

Multiplying by scalar $-1$ reverses the direction of the vector while keeping magnitude unchanged, yielding the negative vector $-\vec{a}.

Q2
MCQ 2: What is the magnitude of the vector $-5\vec{a}$ given that $|\vec{a}| = 4$?
A (A) $-20$
B (B) $20$
C (C) $4$
D (D) $9$
Derivation & Analysis:

$|-5\vec{a}| = |-5| |\vec{a}| = 5 \times 4 = 20$. Magnitude is always non-negative.

Q3
MCQ 3: If $k$ is a scalar and $\vec{a}$ is a vector such. that $k\vec{a} = \vec{0}$, which of the following is necessarily true?
A (A) $k = 0$ only
B (B) $\vec{a} = \vec{0}$ only
C (C) $k = 0$ or $\vec{a} = \vec{0}$
D (D) $k = 1$
Derivation & Analysis:

The scalar product is zero if and only if either the scalar is zero or the vector is the zero vector.

Q4
MCQ 4: The vectors $\hat{i} + 2\hat{j} + 3\hat{k}$ and $2\hat{i} + 4\hat{j} + 6\hat{k}$ are:
A (A) Perpendicular
B (B) Collinear / Parallel
C (C) Unit vectors
D (D) Coplanar only in z-axis
Derivation & Analysis:

The second vector is $2(\hat{i} + 2\hat{j} + 3\hat{k})$, meaning it is a positive scalar multiple of the first, so they are collinear.

Q5
MCQ 5: For any scalar $k$ and vectors $\vec{a}, \vec{b}$, which distributive law holds universally?
A (A) $k(\vec{a} \cdot \vec{b}) = (k\vec{a}) \cdot (k\vec{b})$
B (B) $k(\vec{a} + \vec{b}) = k\vec{a} + k\vec{b}$
C (C) $k(\vec{a} \times \vec{b}) = (k\vec{a}) \times (k\vec{b})$
D (D) $(k\vec{a}) \cdot \vec{b} = \vec{a} \cdot (k^2\vec{b})$
Derivation & Analysis:

Scalar multiplication distributes strictly over vector addition as $k(\vec{a} + \vec{b}) = k\vec{a} + k\vec{b}$.

Q6
MCQ 6: If $\vec{a} = 3\hat{i} - 2\hat{j} + \hat{k}$, then $-4\vec{a}$ is:
A (A) $-12\hat{i} + 8\hat{j} - 4\hat{k}$
B (B) $12\hat{i} - 8\hat{j} + 4\hat{k}$
C (C) $-12\hat{i} - 8\hat{j} - 4\hat{k}$
D (D) $-7\hat{i} + 2\hat{j} - 3\hat{k}$
Derivation & Analysis:

Multiply each component by $-4$: $-4(3) = -12$, $-4(-2) = 8$, $-4(1) = -4$, giving $-12\hat{i} + 8\hat{j} - 4\hat{k}$.

Q7
MCQ 7: If $m$ and $n$ are scalars, then $(m+n)\vec{a}$ is equal to:
A (A) $m\vec{a} + n\vec{a}$
B (B) $m\vec{a} \cdot n\vec{a}$
C (C) $mn\vec{a}$
D (D) $(mn)\vec{a}^2$
Derivation & Analysis:

Scalar multiplication satisfies distributivity over scalar sums: $(m+n)\vec{a} = m\vec{a} + n\vec{a}$.

Q8
MCQ 8: Assertion (A): If $\vec{a}$ and $\vec{b}$ are parallel, then $\vec{b} = k\vec{a}$ for some scalar $k$. Reason (R): Parallel vectors always have equal magnitudes.
A (A) Both (A) and (R) are true and (R) is the correct explanation of (A)
B (B) Both (A) and (R) are true but (R) is not the correct explanation of (A)
C (C) (A) is true but (R) is false
D (D) (A) is false but (R) is true
Derivation & Analysis:

Parallel vectors only require proportional direction ratios; their magnitudes can be completely different (e.g., $k \neq \pm 1$).

Q9
MCQ 9: What is the unit vector in the direction of vector $\vec{a} = 3\hat{i} - 4\hat{j}$?
A (A) $\frac{3}{5}\hat{i} - \frac{4}{5}\hat{j}$
B (B) $3\hat{i} - 4\hat{j}$
C (C) $-\frac{3}{5}\hat{i} + \frac{4}{5}\hat{j}$
D (D) $\frac{3}{7}\hat{i} - \frac{4}{7}\hat{j}$
Derivation & Analysis:

Magnitude $|\vec{a}| = \sqrt{3^2 + (-4)^2} = 5$. Unit vector is $\frac{1}{5}(3\hat{i} - 4\hat{j}) = \frac{3}{5}\hat{i} - \frac{4}{5}\hat{j}$.

Q10
MCQ 10: If $|k\vec{a}| = |\vec{a}|$ and $\vec{a} \neq \vec{0}$, then the possible values of $k$ are:
A (A) $1$ only
B (B) $-1$ only
C (C) $\pm 1$
D (D) $0, \pm 1$
Derivation & Analysis:

$|k| |\vec{a}| = |\vec{a}| \implies |k| = 1 \implies k = \pm 1$.

Pillar 8 Frequently Asked Questions

In standard UP TGT/PGT examinations, scalars are restricted to the field of real numbers ($\mathbb{R}$), unless the context explicitly specifies a complex vector space.

Candidates frequently forget to apply absolute value bars when extracting negative scalars from magnitude expressions, resulting in negative lengths.

Direct and indirect applications of scalar multiples account for 2 to 4 questions annually in the Vectors and 3D Geometry section.

Instead of setting up full simultaneous vector equations, immediately check the ratio of the corresponding cartesian components ($a_1/b_1 = a_2/b_2 = a_3/b_3$).
