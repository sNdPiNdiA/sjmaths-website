2. Calculus — Differential Calculus

Decreasing functions

A real-valued function is said to be decreasing on an interval if its graph slopes downward or remains level from left to right, characterized analytically by a non-positive first derivative ($f'(x) \le 0$). Mastering monotonic and decreasing behavior is a high-yield scoring zone in UP TGT/PGT, DSSSB, and KVS examinations, frequently appearing in parameter optimization and interval of monotonicity questions.

Target Exams: UP PGT Mathematics UP TGT Mathematics DSSSB PGT / TGT KVS / NVS PGT LT Grade
📖 Self-Study Mastery Status
○ Mark Topic as Mastered

Pillar 1 Rigorous Definition & Mathematical Statement

Monotonicity Derivative Test (Decreasing Function Criterion)
Let $f: [a, b] \to \mathbb{R}$ be continuous on $[a, b]$ and differentiable on $(a, b)$. \n1. If $f'(x) < 0$ for all $x \in (a, b)$, then $f$ is strictly decreasing on $[a, b]$. \n2. If $f'(x) \le 0$ for all $x \in (a, b)$, then $f$ is decreasing (non-increasing) on $[a, b].$

📐 Geometric Interpretation

Geometrically, the tangent line drawn at any point on the curve of a decreasing function has a non-positive slope ($m = \tan \theta \le 0$, where $\theta \in [\pi/2, \pi)$), implying that as the independent variable $x$ increases along the horizontal axis, the dependent variable $y = f(x)$ moves downward or stays flat along the vertical axis.

⚙️ Algebraic & Structural Meaning

Algebraically, for any two points $x_1, x_2$ in the interval such that $x_1 < x_2$, a decreasing function satisfies $f(x_1) \ge f(x_2)$ (and $f(x_1) > f(x_2)$ for strictly decreasing functions), providing an inequality tool to bound algebraic and transcendental expressions without plotting.

Pillar 2 Hypotheses & Condition Checklist

Every hypothesis is strictly non-negotiable. Inspect the domain type and the exact consequence if a condition fails:

Hypothesis / Condition Domain / Interval Necessity What Fails If Condition Dropped
Continuity on the closed interval [a, b] (Closed interval) Strictly Mandatory / Necessary If $f$ is discontinuous at any interior point, the global monotonicity property between endpoints breaks down, and intermediate values can jump arbitrarily.
Differentiability on the open interval (a, b) (Open interval) Strictly Mandatory If derivative fails to exist (e.g., sharp corners or cusps), standard derivative tests for monotonicity are invalid and must be replaced by direct inequality testing.
Sign of First Derivative (a, b) (Open interval) Essential for conclusion If $f'(x)$ changes sign (both positive and negative values in $(a, b)$), the function is neither increasing nor decreasing on the entire interval, but rather oscillatory or piecewise monotonic.

Pillar 3 High-Yield Exam Results & Direct Shortcuts

Standard 15-to-30 second shortcuts frequently tested in UP TGT/PGT and DSSSB:

01

Shortcut 1: Polynomial Derivative Sign Test

$$f'(x) = a_n x^{n-1} + \dots + a_1 \le 0$$

Exam Rule: For quadratic polynomials $f(x) = ax^2 + bx + c$ with $a > 0$, the function is never decreasing on $\mathbb{R}$. For cubic polynomials $f(x) = ax^3 + bx^2 + cx + d$, find roots of $f'(x) = 0$ as $\alpha, \beta$ ($\alpha < \beta$); the function decreases on $[\alpha, \beta]$ if leading coefficient $a > 0$ and $b^2 - 3ac > 0$.

⚡ PYQ Context: Directly tested in UP PGT to find the interval where a cubic or quartic polynomial is decreasing.
02

Shortcut 2: Trigonometric Monotonicity Intervals

$$f(x) = \sin x \implies f'(x) = \cos x \le 0 \text{ on } \left[\frac{\pi}{2}, \frac{3\pi}{2}\right]$$

Exam Rule: Remember standard reductions: $\sin x$ decreases on $[\pi/2, 3\pi/2]$, $\cos x$ decreases on $[0, \pi]$, and $\tan x$ is strictly increasing wherever continuous (never decreasing on any domain interval).

⚡ PYQ Context: Frequently asked in TGT/PGT matching lists and range-bound questions.
03

Shortcut 3: Exponential and Logarithmic Monotonicity

$$f(x) = a^x \text{ is decreasing if } 0 < a < 1, \quad f(x) = \log_a x \text{ is decreasing if } 0 < a < 1$$

Exam Rule: Exponential and logarithmic functions reverse inequality when the base $a$ lies between $0$ and $1$. Use $a^{-x} = (1/a)^x$ to instantly spot decreasing exponentials.

⚡ PYQ Context: Tested in inequality comparison problems in DSSSB and KVS PGT exams.
04

Shortcut 4: Rational Function Sign Rule

$$f(x) = \frac{P(x)}{Q(x)} \implies f'(x) = \frac{P'(x)Q(x) - P(x)Q'(x)}{[Q(x)]^2} \le 0$$

Exam Rule: Since the denominator $[Q(x)]^2$ is always positive where defined, ignore it and analyze only the sign of the numerator polynomial $P'(x)Q(x) - P(x)Q'(x)$ using Wavy Curve Method.

⚡ PYQ Context: Standard UP PGT question format for rational functions.
05

Shortcut 5: Composite Function Monotonicity Law

$h(x) = f(g(x)) \implies h'(x) = f'(g(x)) \cdot g'(x)$

Exam Rule: If $f$ and $g$ have the same monotonicity (both increasing or both decreasing), their composite $f \circ g$ is increasing. If one is increasing and the other is decreasing, the composite is decreasing.

⚡ PYQ Context: Time-saving shortcut for composite logarithmic/exponential functions.
06

Shortcut 6: Parameter Range via Discriminant

$f'(x) = A x^2 + B x + C \le 0 \quad \forall x \in \mathbb{R} \implies A < 0 \text{ and } B^2 - 4AC \le 0$

Exam Rule: To find values of parameter $k$ for which a quadratic derivative is non-positive for all real $x$, enforce the parabola opening downward ($A < 0$) and having at most one real root ($D \le 0$).

⚡ PYQ Context: Extremely common in UP PGT 5-mark and 4-mark short questions.

Pillar 4 Classic Exam Traps & Counterexamples

Where examiners construct tricky trap options and how to safeguard your marks:

⚠️ EXAM TRAP #01

Trap 1: Strict vs Non-Strict Inequality Confusion

Common Pitfall: Candidates use $f'(x) < 0$ strictly when the question asks for 'decreasing' (which allows $f'(x) = 0$ at isolated points, such as $f(x) = -x^3$ at $x=0$).

Counterexample: $f(x) = -x^3 \implies f'(0) = 0$, yet $f(-1) = 1 > f(1) = -1$ (strictly decreasing on $\mathbb{R}$)

Why it fails: A function can be strictly decreasing even if its derivative vanishes at isolated points where the tangent is horizontal.

🛡️ Exam Defense: Check if equality $f'(x) = 0$ holds only at isolated points; if so, the function remains strictly decreasing on the entire interval.
⚠️ EXAM TRAP #02

Trap 2: Disregarding Domain Restrictions in Rational Functions

Common Pitfall: Including points where the denominator is zero inside the stated decreasing interval.

Counterexample: $f(x) = \frac{1}{x} \implies f'(x) = -\frac{1}{x^2} < 0$

Why it fails: While $f'(x) < 0$ for all $x \neq 0$, the function is NOT decreasing on $(-\infty, \infty)$ because $f(-1) = -1$ is not greater than $f(1) = 1$ across the vertical asymptote at $x = 0$.

🛡️ Exam Defense: Always exclude points of discontinuity and vertical asymptotes when stating intervals of monotonicity.

Pillar 6 Solved Canonical Exam Problems (Dual-Method)

Comparing the formal academic proof against the rapid competitive exam elimination trick:

CANONICAL PROBLEM 01 Dual-Method Breakdown

Find the interval in which the function $f(x) = 2x^3 - 9x^2 + 12x + 1$ is decreasing.

(A) $[1, 2]$(B) $(-\infty, 1] \cup [2, \infty)$(C) $[0, 3]$(D) $(-\infty, 0]$
✓ Correct Answer: (A)
📚 Method A: Formal Textbook Derivation
Step 1: Compute derivative $f'(x) = 6x^2 - 18x + 12$. Step 2: Set $f'(x) < 0 \implies 6(x^2 - 3x + 2) < 0$. Step 3: Factorize $6(x-1)(x-2) < 0$. Step 4: By Wavy Curve Method, $x \in (1, 2)$. Thus, the function is decreasing on $[1, 2]$.
⚡ Method B: 25-Second Exam Shortcut
For $ax^3 + bx^2 + cx + d$ with $a > 0$, the function decreases between the roots of $f'(x)=0$. Roots of $x^2-3x+2=0$ are $1$ and $2$. Answer is $[1, 2]$.
💡 Key Takeaway: Look at the leading coefficient sign; if positive, the middle interval between roots is always the decreasing zone.
CANONICAL PROBLEM 02 Dual-Method Breakdown

The function $f(x) = \frac{\ln x}{x}$ is strictly decreasing on the interval:

(A) $(0, e)$(B) $(e, \infty)$(C) $(0, 1)$(D) $(1, e^2)$
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Step 1: Find $f'(x) = \frac{(1/x)x - \ln x(1)}{x^2} = \frac{1 - \ln x}{x^2}$. Step 2: For strictly decreasing, $f'(x) < 0 \implies \frac{1 - \ln x}{x^2} < 0$. Step 3: Since $x^2 > 0$ for $x \in (0, \infty)$, we need $1 - \ln x < 0 \implies \ln x > 1 \implies x > e$. Step 4: Hence, interval is $(e, \infty)$.
⚡ Method B: 25-Second Exam Shortcut
Evaluate numerator at standard points or recall logarithmic peak at $x = e$, after which derivative becomes negative.
💡 Key Takeaway: Remember that $\frac{\ln x}{x}$ increases on $(0, e]$ and decreases on $[e, \infty)$. This is a standard result frequently memorized by toppers.

Q1
MCQ 1: If $f(x) = x^3 - 3x^2 + 3x - 100$ is strictly decreasing for all $x$ in:
A (A) $(-\infty, \infty)$
B (B) empty set $\phi$
C (C) $(0, 1)$
D (D) $(-\infty, 1)$
Derivation & Analysis:

Here $f'(x) = 3x^2 - 6x + 3 = 3(x-1)^2$. Since $3(x-1)^2 \ge 0$ for all real $x$, $f'(x)$ is never strictly less than zero ($f'(x) < 0$ has no solution). Thus, the function is strictly increasing everywhere and never decreasing; hence the set of such $x$ is the empty set $\phi$.

Q2
MCQ 2: The interval for which $f(x) = \cos x$ is decreasing is:
A (A) $(-\pi/2, \pi/2)$
B (B) $(0, \pi)$
C (C) $(\pi, 2\pi)$
D (D) $(-\pi, 0)$
Derivation & Analysis:

We have $f'(x) = -\sin x$. For $f(x)$ to be decreasing, $-\sin x \le 0 \implies \sin x \ge 0$. In the standard interval $[0, \pi]$, $\sin x \ge 0$, so $\cos x$ is decreasing on $(0, \pi)$.

MCQ 3: The function $f(x) = x^9 + 3x^7 + 64$ is:
A (A) strictly increasing on $\mathbb{R}$
B (B) strictly decreasing on $\mathbb{R}$
C C) decreasing only for $x < 0$
D (D) neither increasing nor decreasing
Derivation & Analysis:

Computing the derivative, $f'(x) = 9x^8 + 21x^6$. Since $x^8 \ge 0$ and $x^6 \ge 0$ for all $x \in \mathbb{R}$, $f'(x) > 0$ for all $x \neq 0$. Thus, $f$ is strictly increasing on $\mathbb{R}$.

MCQ 4: Values of $a$ for which $f(x) = \sin x - a x + b$ is decreasing on $\mathbb{R}$ are:
A (A) $a < 1$
B (B) $a \ge 1$
C (C) $a \le -1$
D (D) $a > 0$
Derivation & Analysis:

We require $f'(x) = \cos x - a \le 0$ for all $x \in \mathbb{R}$. This implies $\cos x \le a$ for all $x$. Since the maximum value of $\cos x$ is $1$, we must have $a \ge 1$.

Q5
MCQ 5: The function $f(x) = x^3 - 3ax^2 + 3ax + 1$ is strictly increasing for all $x \in \mathbb{R}$ if:
A (A) $0 < a < 1$
B (B) $a < 0$ or $a > 1$
C (C) $a = 0$ or $a = 1$
D (D) $0 \le a \le 1$
Derivation & Analysis:

Here $f'(x) = 3x^2 - 6ax + 3a$. For $f$ to be increasing everywhere, $f'(x) \ge 0$ for all $x \in \mathbb{R}$, which requires discriminant $B^2 - 4AC \le 0 \implies 36a^2 - 36a \le 0 \implies a(a-1) \le 0 \implies 0 \le a \le 1$.

MCQ 6: Which of the following functions is strictly decreasing on $(0, \pi/2)$?

Derivation & Analysis:

For $f(x) = \cos x$, $f'(x) = -\sin x$. On $(0, \pi/2)$, $\sin x > 0$, so $-\sin x < 0$, making $\cos x$ strictly decreasing. All other options have positive derivatives on $(0, \pi/2)$.

MCQ 7: If $f(x) = x e^{x(1-x)}$, then $f(x)$ is decreasing in the interval:

For $ax^3 + bx^2 + cx + d$ with $a > 0$, the function decreases between the roots of $f'(x)=0$. Roots of $x^2-3x+2=0$ are $1$ and $2$. Answer is $[1, 2]$.
💡 Key Takeaway: Look at the leading coefficient sign; if positive, the middle interval between roots is always the decreasing zone.
CANONICAL PROBLEM 02 Dual-Method Breakdown

The function $f(x) = \frac{\ln x}{x}$ is strictly decreasing on the interval:

(A) $(0, e)$(B) $(e, \infty)$(C) $(0, 1)$(D) $(1, e^2)$
✓ Correct Answer: (B)
📚 Method A: Formal Textbook Derivation
Step 1: Find $f'(x) = \frac{(1/x)x - \ln x(1)}{x^2} = \frac{1 - \ln x}{x^2}$. Step 2: For strictly decreasing, $f'(x) < 0 \implies \frac{1 - \ln x}{x^2} < 0$. Step 3: Since $x^2 > 0$ for $x \in (0, \infty)$, we need $1 - \ln x < 0 \implies \ln x > 1 \implies x > e$. Step 4: Hence, interval is $(e, \infty)$.
⚡ Method B: 25-Second Exam Shortcut
Evaluate numerator at standard points or recall logarithmic peak at $x = e$, after which derivative becomes negative.
💡 Key Takeaway: Remember that $\frac{\ln x}{x}$ increases on $(0, e]$ and decreases on $[e, \infty)$. This is a standard result frequently memorized by toppers.
