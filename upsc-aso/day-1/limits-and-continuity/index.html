Limits and continuity

Day 1 of 129 Engineering Fundamentals Phase 1: Foundations 60-90 min Master Cycle

1. Understand (5–10 min)

In Aeronautical Engineering and applied mathematics, the concepts of Limits and Continuity form the foundational pillar of real analysis and continuum mechanics. For the UPSC Air Safety Officer (ASO) and GATE examinations, these concepts are evaluated not merely as abstract calculus manipulations, but as critical tools to model physical phenomena such as fluid velocity fields, shock wave discontinuities, structural deflection rates, and flight control actuation stability.

Mathematically, a Limit describes the behavior of a real-valued function $f(x)$ as its independent variable $x$ approaches a specific point $a$, regardless of whether $f(a)$ is defined. Formally, using Cauchy's $ε$-$\delta$ framework, we state:

$$\limx \to a f(x) = L \iff \forall ε > 0, \, \exists \delta > 0 such that 0 < |x - a| < \delta \implies |f(x) - L| < ε$$

The existence of a limit at $x = a$ strictly requires that both the Left-Hand Limit (LHL) and Right-Hand Limit (RHL) exist and are equal:

$$\limx \to a^- f(x) = \limx \to a^+ f(x) = L$$

Continuity extends the limit concept by requiring the function's actual value at $x = a$ to match its limiting value. A function $f(x)$ is continuous at $x = a$ if and only if:

  1. $f(a)$ is defined (i.e., $a$ is in the domain of $f$).
  2. $\limx \to a f(x)$ exists.
  3. $\limx \to a f(x) = f(a)$.

When continuity fails, the function exhibits a Discontinuity. UPSC ASO questions classify these into four precise mathematical categories:

  • Removable Discontinuity: $\limx \to a f(x)$ exists, but $\limx \to a f(x) \neq f(a)$ or $f(a)$ is undefined.
  • Jump (Ordinary) Discontinuity: Both $\limx \to a^- f(x)$ and $\limx \to a^+ f(x)$ exist as finite values, but $\limx \to a^- f(x) \neq \limx \to a^+ f(x)$. The quantity $J = |\limx \to a^+ f(x) - \limx \to a^- f(x)|$ is the magnitude of the jump.
  • Essential / Infinite Discontinuity: At least one of the one-sided limits does not exist or approaches $± ∞$.
  • Oscillatory Discontinuity: The function oscillates indefinitely between bounds as $x \to a$ (e.g., $f(x) = \sin(1/x)$ as $x \to 0$).

2. Learn the Concept (15–20 min)

To master UPSC-level calculus, we build the mathematical framework starting from fundamental theorems through advanced limit evaluation techniques.

1. Rigorous $ε$-$\delta$ Derivation Framework

To prove $\limx \to a f(x) = L$ for a linear or polynomial function, we establish an explicit functional relationship $\delta = g(ε)$. For example, for $f(x) = 3x^2 - 5x + 2$ as $x \to 2$, we set $L = 3(2)^2 - 5(2) + 2 = 4$. We analyze the difference $|f(x) - 4|$:

$$|3x^2 - 5x + 2 - 4| = |3x^2 - 5x - 2| = |(3x + 1)(x - 2)| = |3x + 1| · |x - 2|$$

Assuming a local neighborhood around $a = 2$, say $|x - 2| < 1 \implies 1 < x < 3$, we bound the term $|3x + 1|$:

$$1 < x < 3 \implies 4 < 3x + 1 < 10 \implies |3x + 1| < 10$$

Thus, $|f(x) - L| < 10 |x - 2|$. To ensure $|f(x) - L| < ε$, we require $10 |x - 2| < ε \implies |x - 2| < ε10$. Choosing $\delta = \min(1, ε10)$ completes the proof.

2. The Squeeze (Sandwich) Theorem

Let $g(x) ≤ f(x) ≤ h(x)$ for all $x$ in an open interval containing $a$, except possibly at $a$ itself. If:

$$\limx \to a g(x) = \limx \to a h(x) = L$$

then $\limx \to a f(x) = L$. This is essential for proving standard trigonometric limits like $\limx \to 0 \sin xx = 1$ via geometric unit circle bounds $\cos x < \sin xx < 1$ for $x \in (-π/2, π/2) \setminus \{0\}$.

3. Indeterminate Forms and L'Hôpital's Rule

When evaluating $\limx \to a f(x)g(x)$ yields indeterminate forms $[00]$ or $[∞∞]$, and $f, g$ are differentiable near $a$ with $g'(x) \neq 0$, L'Hôpital's Rule states:

$$\limx \to a f(x)g(x) = \limx \to a f'(x)g'(x)$$

For exponential indeterminate forms $[1^∞]$, $[0^0]$, and $[∞^0]$, we apply logarithmic transformations:

$$L = \limx \to a [f(x)]g(x) \implies \ln L = \limx \to a [ g(x) · \ln(f(x)) ]$$

If $f(x) \to 1$ and $g(x) \to ∞$, the standard reduction identity is:

$$\limx \to a [f(x)]g(x) = \exp[ \limx \to a g(x) · (f(x) - 1) ]$$
$$ \begin{aligned} &Cauchy Definition: \quad \limx \to a f(x) = L \iff |x - a| < \delta \implies |f(x) - L| < ε \\ &Indeterminate Identity [1^∞]: \quad \limx \to a [f(x)]g(x) = e\limx \to a g(x)[f(x) - 1] \\ &Multivariable Path Test: \quad \lim(x,y)\to(0,0) f(x,y) exists \implies Value independent of y = m x^k \end{aligned} $$

4. Uniform Continuity vs. Pointwise Continuity

A function $f$ is pointwise continuous on an interval $I$ if $\delta$ depends on both $ε$ and $x_0 \in I$. A function is uniformly continuous on $I$ if $\delta$ depends only on $ε$ for all $x \in I$:

$$\forall ε > 0, \, \exists \delta > 0 such that \forall x_1, x_2 \in I, \, |x_1 - x_2| < \delta \implies |f(x_1) - f(x_2)| < ε$$

Heine-Cantor Theorem: If $f(x)$ is continuous on a closed and bounded (compact) interval $[a, b]$, then $f(x)$ is uniformly continuous on $[a, b]$.

3. Memorize Important Facts (10 min)

  • Trigonometric Standard Limits: $\limx \to 0 \sin xx = 1$, $\limx \to 0 \tan xx = 1$, $\limx \to 0 1 - \cos xx^2 = 12$.
  • Exponential & Logarithmic Standard Limits: $\limx \to 0 e^x - 1x = 1$, $\limx \to 0 a^x - 1x = \ln a$, $\limx \to 0 \ln(1+x)x = 1$.
  • Power Standard Limit: $\limx \to a x^n - a^nx - a = n an-1$.
  • Asymptotic Log-Exponential Hierarchy: As $x \to ∞$, $(\ln x)^a \ll x^b \ll c^x \ll x! \ll x^x$ for any $a, b, c > 0$ ($c > 1$).
  • Intermediate Value Theorem (IVT): If $f \in C[a, b]$ and $k$ is between $f(a)$ and $f(b)$, then $\exists c \in (a, b)$ such that $f(c) = k$. If $f(a) · f(b) < 0$, at least one real root exists in $(a, b)$.
  • Extreme Value Theorem (EVT): A continuous function on a compact set $[a, b]$ attains its absolute maximum and absolute minimum values.
  • Discontinuity Types Quick Rule:
    • Removable: LHL = RHL $\neq f(a)$
    • Jump: LHL $\neq$ RHL (both finite)
    • Infinite: LHL or RHL $= ±∞$

4. Aviation Application (5–10 min)

In Aeronautical Engineering and Flight Safety Analysis, continuity and limits define critical aerodynamic and flight dynamics parameters:

1. Shock Wave Discontinuities (Gas Dynamics)

Across a normal shock wave in supersonic flight, physical variables such as pressure ($p$), density ($ρ$), and temperature ($T$) exhibit a Jump Discontinuity governed by the Rankine-Hugoniot relations. While the continuous Navier-Stokes equations model the finite shock thickness ($≈ 10-7 m$), classical inviscid compressible flow treats the shock as an absolute spatial discontinuity $x = x_s$:

$$ρ(x_s^+) = ρ_1 ( (γ + 1) M_1^2(γ - 1) M_1^2 + 2 ) \neq ρ(x_s^-) = ρ_1$$

Air safety investigators analyzing flight data recorder (FDR) pitot-static sensor spikes during trans-sonic transitions evaluate these jump conditions to determine shock position and severe dynamic pressure variations.

2. Prandtl-Glauert Singularity at $M_∞ = 1$

The linearized compressible flow correction factor for pressure coefficient $C_p$ is given by:

$$C_p = Cp,0√|1 - M_∞^2|$$

Taking the limit as the free-stream Mach number approaches unity yields an infinite limit:

$$\limM_∞ \to 1^- Cp,0√1 - M_∞^2 = ∞$$

This breakdown (essential singularity) highlights the physical invalidity of linearized potential flow equations near Sonic Speed ($M_∞ = 1$), necessitating non-linear transonic small disturbance (TSD) formulations in aircraft design.

3. Flight Control System Actuator Saturation

Modern Digital Flight Control Systems (DFCS) feature control surface command laws incorporating rate limiters and saturation switches. A control signal defined as $u(t) = sat(K · e(t))$ creates piece-wise continuous control functions:

$$u(t) = \begin{cases} U\max, & e(t) > ethresh \\ K e(t), & -ethresh ≤ e(t) ≤ ethresh \\ -U\max, & e(t) < -ethresh \end{cases}$$

Ensuring $C^0$ continuity across boundary thresholds prevents uncommanded transient forces on control actuators, avoiding pilot-induced oscillations (PIO) and structural flutter.

5. UPSC ASO Focus (10 min)

  • Frequently Asked Facts:
    • $0^0$, $∞^0$, and $1^∞$ are indeterminate forms, whereas $0^∞ = 0$, $∞^∞ = ∞$, and $0∞ = 0$ are fully determined.
    • Differentiability strictly implies continuity, but continuity does not imply differentiability (e.g., $f(x) = |x|$ at $x=0$ is continuous but non-differentiable).
    • For multivariable limits $\lim(x,y)\to(0,0) f(x,y)$, setting $y = mx$ yielding a value independent of $m$ is a necessary condition, but NOT sufficient to prove existence. One must test parabolic paths $y = mx^2$ or use polar coordinates $r \to 0$.
  • Conceptual Traps:
    • Trap 1: Blindly applying L'Hôpital's rule without verifying that the expression is strictly in $[00]$ or $[∞∞]$ form, leading to erroneous derivative calculations.
    • Trap 2: Assuming $\limx \to a [f(x) g(x)] = \lim f(x) · \lim g(x)$ when one of the individual limits is infinite or non-existent.
    • Trap 3: Confusing boundary point continuity on closed domains. For $f(x) = √x$ on $[0, ∞)$, continuity at $x=0$ requires only the right-hand limit $\limx \to 0^+ √x = f(0) = 0$.

6. Practice Questions (10-12 UPSC ASO Standard MCQs)

Q1. Using the formal $ε$-$\delta$ definition of a limit, consider $f(x) = 4x - 5$. If $\limx \to 3 f(x) = 7$, what is the maximum value of $\delta$ corresponding to a given tolerance $ε = 0.02$?
A) 0.020
B) 0.005
C) 0.008
D) 0.010
Step-by-step Solution:
By definition, $|f(x) - L| < ε \implies |(4x - 5) - 7| < ε$.
$|4x - 12| < ε \implies 4|x - 3| < ε \implies |x - 3| < ε4$.
Comparing with $|x - 3| < \delta$, we get $\delta = ε4$.
Given $ε = 0.02$, $\delta = 0.024 = 0.005$.
Correct Option: B
Q2. Evaluate the limit: $$\limx \to 0 ( \sin xx )1x^2$$
A) 1
B) $e-1/2$
C) $e-1/6$
D) $e1/6$
Step-by-step Solution:
This is an indeterminate form of type $1^∞$. Use the identity $\limx \to a [f(x)]g(x) = \exp[\limx \to a g(x)(f(x) - 1)]$.
Exponent $k = \limx \to 0 1x^2 ( \sin xx - 1 ) = \limx \to 0 \sin x - xx^3$.
Using Taylor expansion $\sin x = x - x^36 + O(x^5)$:
$\limx \to 0 (x - x^36) - xx^3 = \limx \to 0 -x^3/6x^3 = -16$.
Therefore, the limit is $e-1/6$.
Correct Option: C
Q3. A piecewise function modeling elevator deflection control law is given by: $$f(x) = \begin{cases} ax + b, & x ≤ 1 \\ x^2 + 3x, & x > 1 \end{cases}$$ If $f(x)$ is continuous and differentiable everywhere on $\mathbb{R}$, determine the pair $(a, b)$.
A) $(5, -1)$
B) $(4, 0)$
C) $(3, 1)$
D) $(5, 1)$
Step-by-step Solution:
1. For continuity at $x = 1$: $\limx \to 1^- f(x) = \limx \to 1^+ f(x) = f(1)$.
$a(1) + b = 1^2 + 3(1) \implies a + b = 4$.
2. For differentiability at $x = 1$: Left derivative = Right derivative.
$\left. ddx(ax + b) |x=1 = \left. ddx(x^2 + 3x) |x=1 \implies a = 2(1) + 3 = 5$.
Substituting $a = 5$ into $a + b = 4 \implies 5 + b = 4 \implies b = -1$.
Thus, $(a, b) = (5, -1)$.
Correct Option: A
Q4. Determine the value of the aerodynamic limit: $$\limx \to 0 \tan x - \sin xx^3$$
A) $1/2$
B) $1/3$
C) $1/6$
D) $1$
Step-by-step Solution:
Rewrite expression: $\tan x - \sin xx^3 = \sin x (1\cos x - 1)x^3 = \sin x (1 - \cos x)x^3 \cos x$.
Split into standard limits:
$\limx \to 0 ( \sin xx ) · ( 1 - \cos xx^2 ) · ( 1\cos x ) = (1) · ( 12 ) · (1) = 12$.
Correct Option: A
Q5. An abrupt boundary layer fluid density field across a shock interface is approximated by $ρ(x) = ρ_1 + Δ ρ1 + e-k x$. As $k \to ∞$, what is the magnitude of the jump discontinuity at $x = 0$?
A) $0$
B) $Δ ρ$
C) $Δ ρ2$
D) $ρ_1 + Δ ρ$
Step-by-step Solution:
Compute one-sided limits as $k \to ∞$:
For $x > 0$: $\limk \to ∞ e-kx = 0 \implies ρ(0^+) = ρ_1 + Δ ρ1 + 0 = ρ_1 + Δ ρ$.
For $x < 0$: $\limk \to ∞ e-kx = ∞ \implies ρ(0^-) = ρ_1 + Δ ρ1 + ∞ = ρ_1$.
Magnitude of jump $J = |ρ(0^+) - ρ(0^-)| = |(ρ_1 + Δ ρ) - ρ_1| = Δ ρ$.
Correct Option: B
Q6. Consider the multivariable fluid velocity potential function $f(x, y) = x^2 yx^4 + y^2$. Evaluate $\lim(x,y) \to (0,0) f(x, y)$.
A) 0
B) 1/2
C) 1
D) Does not exist
Step-by-step Solution:
Test linear paths $y = mx$:
$\limx \to 0 x^2 (mx)x^4 + m^2 x^2 = \limx \to 0 m x^3x^2 (x^2 + m^2) = \limx \to 0 mxx^2 + m^2 = 0$.
Now test parabolic paths $y = m x^2$:
$\limx \to 0 x^2 (m x^2)x^4 + (m x^2)^2 = \limx \to 0 m x^4x^4 (1 + m^2) = m1 + m^2$.
Since the limiting value depends on path parameter $m$, the limit DOES NOT EXIST.
Correct Option: D
Q7. Using the Squeeze Theorem, evaluate $\limx \to 0 x^2 \sin(1x)$.
A) 1
B) 0
C) Does not exist due to oscillation
D) $∞$
Step-by-step Solution:
We know that for all $x \neq 0$: $-1 ≤ \sin(1/x) ≤ 1$.
Multiplying by $x^2 > 0$: $-x^2 ≤ x^2 \sin(1/x) ≤ x^2$.
Taking limits as $x \to 0$: $\limx \to 0 (-x^2) = 0$ and $\limx \to 0 (x^2) = 0$.
By Squeeze Theorem, $\limx \to 0 x^2 \sin(1/x) = 0$.
Correct Option: B
Q8. An aircraft pitching moment curve is given by $C_m(α) = α^3 - 4α + 1$. According to the Intermediate Value Theorem, in which of the following intervals is a trim point ($C_m(α) = 0$) guaranteed to exist?
A) $(0, 1)$
B) $(1, 2)$
C) $(2, 3)$
D) $(-1, 0)$
Step-by-step Solution:
Evaluate $C_m(α)$ at interval endpoints:
At $α = 0$: $C_m(0) = 0^3 - 4(0) + 1 = 1 > 0$.
At $α = 1$: $C_m(1) = 1^3 - 4(1) + 1 = -2 < 0$.
Since $C_m(α)$ is a continuous polynomial and $C_m(0) · C_m(1) < 0$, by IVT there exists at least one root $α_e \in (0, 1)$ where $C_m(α_e) = 0$.
Correct Option: A
Q9. Find the limit: $$\limx \to 0^+ x\sin x$$
A) 1
B) 0
C) $e$
D) $∞$
Step-by-step Solution:
Indeterminate form $0^0$. Let $y = x\sin x \implies \ln y = \sin x · \ln x$.
$\limx \to 0^+ \ln y = \limx \to 0^+ \ln x\csc x = [-∞∞]$.
Applying L'Hôpital's Rule:
$\limx \to 0^+ 1/x-\csc x \cot x = -\limx \to 0^+ \sin^2 xx \cos x = -\limx \to 0^+ (\sin xx) · (\sin x\cos x) = - (1) · (0) = 0$.
Since $\ln y \to 0$, $y \to e^0 = 1$.
Correct Option: A
Q10. Evaluate the left-hand limit containing floor operations: $$\limx \to 2^- ( [x]^2 - [x^2] )$$ where $[t]$ denotes the greatest integer function.
A) 0
B) -1
C) -2
D) 1
Step-by-step Solution:
As $x \to 2^-$, $x$ approaches 2 from values strictly less than 2 (e.g., $x = 1.9$).
1. $[x] = [1.9] = 1 \implies [x]^2 = 1^2 = 1$.
2. $x = 1.9 \implies x^2 = 3.61 \implies [x^2] = [3.61] = 3$.
Substituting: $\limx \to 2^- ([x]^2 - [x^2]) = 1 - 3 = -2$.
Correct Option: C
Q11. What value must be assigned to $f(1)$ to eliminate the removable discontinuity of $f(x) = x^3 - 3x^2 + 4x - 2x - 1$ at $x = 1$?
A) 0
B) 1
C) 2
D) -1
Step-by-step Solution:
Evaluate $\limx \to 1 x^3 - 3x^2 + 4x - 2x - 1$ (Indeterminate form $0/0$).
Factor the numerator using synthetic division with root $x = 1$:
$x^3 - 3x^2 + 4x - 2 = (x - 1)(x^2 - 2x + 2)$.
Therefore, $\limx \to 1 (x - 1)(x^2 - 2x + 2)x - 1 = \limx \to 1 (x^2 - 2x + 2) = 1^2 - 2(1) + 2 = 1$.
Setting $f(1) = 1$ removes the discontinuity.
Correct Option: B
Q12. Evaluate the limit: $$\limx \to ∞ ( x - x^2 \ln(1 + 1x) )$$
A) 0
B) 1
C) 1/2
D) $∞$
Step-by-step Solution:
Let $t = 1/x$. As $x \to ∞$, $t \to 0^+$.
Rewrite: $\limt \to 0^+ ( 1t - 1t^2 \ln(1 + t) ) = \limt \to 0^+ t - \ln(1 + t)t^2$.
Use Maclaurin expansion $\ln(1 + t) = t - t^22 + t^33 - \dots$:
$\limt \to 0^+ t - (t - t^22 + t^33)t^2 = \limt \to 0^+ t^22 - t^33t^2 = 12$.
Correct Option: C

7. Grand Mini Test (Self-Evaluation)

Q1. (Grand Test - Statement Based) Consider the following mathematical assertions regarding functions defined on $\mathbb{R}$:
Statement I: If $f(x)$ is continuous on $[a, b]$, then $f(x)$ is uniformly continuous on $(a, b)$.
Statement II: If $\limx \to a |f(x)|$ exists, then $\limx \to a f(x)$ must also exist.
Statement III: A function $f(x)$ with a jump discontinuity at $x=c$ can satisfy the Intermediate Value Property on an interval containing $c$.
Which of the above statements is/are CORRECT?
A) Statement I only
B) Statements I and II only
C) Statements I and III only
D) Statements II and III only
Detailed Analysis:
- Statement I is CORRECT: By the Heine-Cantor Theorem, if $f$ is continuous on a compact interval $[a, b]$, it is uniformly continuous on $[a, b]$, and consequently on any sub-interval $(a, b)$.
- Statement II is INCORRECT: Counterexample: $f(x) = 1$ for $x > 0$ and $f(x) = -1$ for $x ≤ 0$. Here $|f(x)| = 1 \implies \limx \to 0 |f(x)| = 1$, but $\limx \to 0 f(x)$ does not exist because LHL $= -1 \neq RHL = 1$.
- Statement III is INCORRECT: If $f$ has a jump discontinuity at $c$, it skips a range of values strictly between $\limx \to c^- f(x)$ and $\limx \to c^+ f(x)$, violating the IVP (Darboux's Theorem states derivative functions have IVP without jumps, but general functions with jump discontinuities fail IVP).
Correct Option: A

Q3. (Grand Test - Advanced Multi-Step Calculation) A supersonic wind tunnel contraction nozzle has a non-dimensional velocity ratio $V(x)$ given by: $$V(x) = \limn \to ∞ x^n e^x + 5 x^2 + 2x^n + 3$$ Evaluate $V(x)$ specifically at $x = 0.5$, $x = 1.0$, and $x = 2.0$. Which set of values is correct?
A) $V(0.5) = 1.0, \quad V(1.0) = e+74, \quad V(2.0) = e^2$
B) $V(0.5) = 1312, \quad V(1.0) = e+74, \quad V(2.0) = e^2$

$V(0.5) = (0) e0.5 + 5(0.5)^2 + 20 + 3 = 5(0.25) + 23 = 1.25 + 23 = 3.253 = 1312$.

8. Error Analysis & Common Traps (5 min)

During the UPSC Air Safety Officer mathematical evaluation, candidate scores drop due to specific recurring procedural errors:

1. Non-Verification of Indeterminate Pre-Conditions

Candidates frequently apply L'Hôpital's Rule blindly to non-indeterminate expressions. For instance, evaluating $\limx \to 0 \cos xx + 1$ by differentiating numerator and denominator gives $\limx \to 0 -\sin x1 = 0$, which is INCORRECT. Direct substitution yields $\cos 00 + 1 = 11 = 1$. Always verify $[00]$ or $[∞∞]$ first!

2. Path-Dependent Multivariable Limits

When computing $\lim(x,y) \to (0,0) f(x, y)$, checking only linear paths $y = mx$ is insufficient. If $f(x, y) = x y^2x^2 + y^4$, testing $y = mx$ yields $0$, suggesting existence. However, testing $x = m y^2$ yields $mm^2 + 1$, showing the limit depends on $m$ and does not exist. Always test parabolic paths or convert to polar coordinates.

3. Ignoring One-Sided Domain Restrictions

Functions containing absolute values, square roots, or floor functions (e.g., $|x-a|$, $√x-a$, $[x]$) must be analyzed separately via Left-Hand Limit ($x \to a^-$) and Right-Hand Limit ($x \to a^+$). Combining them directly without splitting sign definitions leads to sign errors.
