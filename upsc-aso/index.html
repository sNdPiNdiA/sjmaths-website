How to use this 100-day plan

  • Normal study day: 90-120 min concepts, 30-40 min worked examples, 35-50 min MCQs, 15-20 min revision/error log.
  • Error codes after every test: C = concept missing, F = fact/formula forgotten, N = numerical error, G = guessing error, S = silly/careless error.
  • Running books: Formula Book, Aircraft Systems and Components Fact Book, Regulations/ICAO/ATC Fact Book, Error Book.
  • Weekly rule: revise previous day 15-20 min daily; reattempt 10-15 Error Book questions every 7th session; revise all formulas every 14 days.
  • From Day 40: add 15-20 mixed old-topic MCQs when time permits. From Day 80: 20 min daily mixed recall.
  • Exam passes (2023 RT had negative marking): Pass 1 certain, Pass 2 solvable, Pass 3 risk-controlled. Avoid blind guesses.
  • Supporting topics strengthened in v2: performance, stability/control, V-n diagram, maintenance philosophies, damage tolerance, autopilot/FMS/EFIS, ADS-B, declared distances, wake-turbulence separation, SID/STAR/holding, ICAO Annex 13/19, SMS and human factors.
  • Not given dedicated blocks unless a future notification restores them: standalone Mathematics, Physics, Electrical/Electronics fundamentals, General Studies, English, Reasoning and Current Affairs. Rebalance the plan if UPSC restores them.
