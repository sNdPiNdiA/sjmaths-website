01 · Start with the story

02 · The central idea

A Weighted Average

For individual observations, mean is their sum divided by their number. In a frequency table, a value repeated many times must count many times.

x̄ = ΣfᵢxᵢΣfᵢ
  • A frequency is a count, so it acts as a weight.
  • For grouped intervals, use the class mark as the representative value.
  • The mean keeps the data's unit and can be affected by extreme values.

04 · Prepare the data

Make Classes Continuous

For continuous classes such as 0–10, 10–20, the common boundary is already clear. If inclusive classes leave a gap, make them continuous before using the distribution.

  • For 10–19, 20–29, the gap is 1; half-gap = 0.5.
  • Adjust to 9.5–19.5, 19.5–29.5.
  • Then calculate each class mark from its boundaries.
Mean reminder: Use a class mark, never the class width, as xᵢ.

05 · Method one

Direct Method

Find every class mark xᵢ, multiply it by its frequency fᵢ, add the products, and divide by the total frequency.

x̄ = Σ fᵢxᵢΣ fᵢ
  • Choose it when the class marks and products are manageable.
  • Keep the columns fᵢ, xᵢ and fᵢxᵢ clear.

07 · Method two

Assumed Mean Method

Choose a convenient class mark a. Subtract it from each xᵢ to get a signed deviation dᵢ, then weight each deviation by its frequency.

dᵢ = xᵢ − a   ·   x̄ = a + ΣfᵢdᵢΣfᵢ
  • Pick a near the centre to keep deviations small.
  • Keep negative signs when xᵢ is below a.

Use the middle class mark as the reference

09 · Method three

Step-Deviation Method

When all classes have the same width h, divide each deviation by h. The resulting uᵢ values are often small integers.

uᵢ = xᵢ − ah   ·   x̄ = a + h ΣfᵢuᵢΣfᵢ
  • Use a common class width h.
  • Remember to multiply the correction by h.
If class widths are unequal, use Direct or Assumed Mean instead.

11 · Choose your method

Choose a Method

Each method calculates the same grouped mean. Choose the one that keeps your working clear and accurate.

  • Direct: class marks and products are small.
  • Assumed Mean: class marks are large, but deviations from a are small.
  • Step-Deviation: intervals share a width h, so deviations reduce to simple steps.
In a board question, follow any method named in the instruction.

14 · Board-answer checklist

Board-Ready Working

For a full solution, show the formula and enough table work for the examiner to follow your method.

  • Write class marks before weighted products or deviations.
  • Show N = Σfᵢ and the required weighted sum.
  • Substitute into the named formula; retain signs and units.
  • For step-deviation, multiply the correction by h.
  • Mean has the same unit as the observations and is sensitive to extreme values.
Common slips: using a class limit instead of xᵢ, dividing by number of classes, or leaving m out of one total.

Before you box the answer

Check the scaleMean should lie between the smallest and largest class marks.
