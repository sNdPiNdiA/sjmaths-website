What is a Quadratic Equation?

Last updated: January 2025 | Author: Sandeep Jaiswal, PGT Maths

Quick Answer: A quadratic equation is a polynomial equation of degree 2 in one variable, written in the form ax² + bx + c = 0, where a, b, c are constants and a ≠ 0. The highest power of the variable is 2.

Understanding Quadratic Equations

A quadratic equation is a fundamental concept in algebra that represents a polynomial of degree 2. The term "quadratic" comes from "quad" meaning square, because the variable gets squared (x²) in the equation.

Standard Form of Quadratic Equation

The general or standard form of a quadratic equation is:

ax² + bx + c = 0 (where a ≠ 0)

Where:

  • a, b, c are real numbers (constants)
  • x is the variable (unknown)
  • a ≠ 0 (if a = 0, it becomes a linear equation)

Key Characteristics

  • Highest power of the variable is 2
  • Can have at most two roots (solutions)
  • Graphically represented as a parabola
  • The discriminant (b² - 4ac) determines the nature of roots

Examples of Quadratic Equations

Example 1: Simple Quadratic

Equation: x² + 5x + 6 = 0

Here, a = 1, b = 5, c = 6

Solution: (x + 2)(x + 3) = 0, so x = -2 or x = -3

Example 2: With Different Coefficients

Equation: 2x² - 3x + 1 = 0

Here, a = 2, b = -3, c = 1

Solution: Using quadratic formula, x = (3 ± √(9-8))/4, so x = 1 or x = 0.5

Example 3: Identifying Quadratic Equations

Is this quadratic? (x + 1)² = 2(x - 3)

Answer: Expanding: x² + 2x + 1 = 2x - 6 → x² + 7 = 0

Yes, it's quadratic with a = 1, b = 0, c = 7.

How to Identify a Quadratic Equation

To determine if an equation is quadratic:

  1. Expand and simplify the equation
  2. Check if the highest power of the variable is 2
  3. Ensure the coefficient of x² is not zero
  4. Arrange in standard form: ax² + bx + c = 0

Why are Quadratic Equations Important?

Quadratic equations appear frequently in real-world applications including physics (projectile motion), engineering (structural analysis), economics (profit optimization), and computer graphics. They form the foundation for understanding higher-degree polynomials.
