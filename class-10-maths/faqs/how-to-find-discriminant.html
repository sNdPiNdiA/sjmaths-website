How to Find the Discriminant?

Last updated: January 2025 | Author: Sandeep Jaiswal, PGT Maths

Quick Answer: To find the discriminant in a quadratic equation ax² + bx + c = 0, use the formula D = b² - 4ac. Identify coefficients a, b, c, then calculate b squared minus 4ac. The discriminant value determines the nature of roots.

Understanding the Discriminant

The discriminant is a critical component in quadratic equations that tells us about the nature of the roots without actually solving the equation. It is represented by the letter D or Δ (delta).

Formula for Discriminant

For any quadratic equation in standard form ax² + bx + c = 0, the discriminant is calculated as:

D = b² - 4ac

Where:

  • a, b, c are coefficients from the quadratic equation
  • b is the coefficient of x
  • a is the coefficient of x²
  • c is the constant term

What the Discriminant Tells Us

The value of discriminant D determines the nature of roots of the quadratic equation:

Value of D Nature of Roots Number of Roots
D > 0 Two distinct real roots 2
D = 0 Two equal real roots 2 (same value)
D < 0 No real roots (imaginary) 0

Step-by-Step: Finding the Discriminant

Step 1: Write in Standard Form

Example: x² - 5x + 6 = 0

Already in standard form ax² + bx + c = 0

Identify: a = 1, b = -5, c = 6

Step 2: Apply the Formula

Formula: D = b² - 4ac

Calculate: D = (-5)² - 4(1)(6)

D = 25 - 24 = 1

Step 3: Interpret the Result

Since D = 1 > 0: Two distinct real roots exist

Actual roots: x = (5 ± √1)/2 = (5 ± 1)/2

x₁ = 3, x₂ = 2

More Examples

Example 1: D = 0 (Equal Roots)

Equation: x² - 4x + 4 = 0

a = 1, b = -4, c = 4

D = (-4)² - 4(1)(4) = 16 - 16 = 0

Result: Two equal real roots (x = 2)

Example 2: D < 0 (No Real Roots)

Equation: x² + 4x + 5 = 0

a = 1, b = 4, c = 5

D = (4)² - 4(1)(5) = 16 - 20 = -4

Result: No real roots (imaginary roots exist)

Example 3: Complex Coefficients

Equation: 2x² - 3x + 1 = 0

a = 2, b = -3, c = 1

D = (-3)² - 4(2)(1) = 9 - 8 = 1

Result: Two distinct real roots

Using formula: x = (3 ± √1)/4 → x = 1 or x = 0.5

Common Board Exam Questions

Board Question Pattern 1: Find Nature of Roots

Question: Find the nature of roots of 2x² - 4x + 3 = 0

Solution: D = (-4)² - 4(2)(3) = 16 - 24 = -8

Answer: D < 0, so no real roots.

Board Question Pattern 2: Find k for Equal Roots

Question: Find k for which kx² - 5x + k = 0 has equal roots

Solution: D = 0 → (-5)² - 4(k)(k) = 0

25 - 4k² = 0 → k² = 25/4 → k = ±5/2

Answer: k = ±2.5

Tips for Solving Discriminant Problems

  • Always write the equation in standard form first: ax² + bx + c = 0
  • Be careful with negative signs when squaring b (remember: (-b)² = b²)
  • If the equation is not in standard form, rearrange before finding D
  • For "k" problems, set D = 0, D > 0, or D < 0 as required
  • Always check conditions: a ≠ 0, and sometimes k ≠ 0

Real-World Application

In physics, the discriminant helps determine if a projectile reaches a certain height. In engineering, it's used to analyze structural stability. In economics, it helps determine break-even points.
