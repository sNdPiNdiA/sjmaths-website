Solution Key (MCQs)

Q1. (b) √7/4

cos A = √(1 - sin² A) = √(1 - 9/16) = √(7/16) = √7/4.

Q2. (c) 0

(1/2 + √3/2) - (√3/2 + 1/2) = 0.

Q3. (c) 90°

tan A = cot B ⇒ tan A = tan(90° - B) ⇒ A = 90° - B ⇒ A + B = 90°.

Q4. (b) 9

9(sec² A - tan² A) = 9(1) = 9.

Q5. (a) 60°

tan θ = 6 / 2√3 = 3/√3 = √3 ⇒ θ = 60°.

Q6. (b) 0

sec θ = 3/2, tan² θ = 9/4 - 1 = 5/4. 2(9/4) + 2(5/4) - 7 = 18/4 + 10/4 - 7 = 7 - 7 = 0.
