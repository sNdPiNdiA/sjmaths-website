Question 1: In a survey of 100 students, the number of students studying distinct subjects were found to be as follows: Mathematics 50, Physics 40, Chemistry 35, Mathematics and Physics 20, Mathematics and Chemistry 15, Physics and Chemistry 10, and 5 studied all three subjects. Find the number of students who study exactly one subject.
    Solution:
    Let M, P, C be the sets for Maths, Physics, Chemistry.
    $n(M)=50, n(P)=40, n(C)=35$.
    $n(M \cap P)=20, n(M \cap C)=15, n(P \cap C)=10, n(M \cap P \cap C)=5$.
    Only Maths = $n(M) - n(M \cap P) - n(M \cap C) + n(M \cap P \cap C) = 50 - 20 - 15 + 5 = 20$.
    Only Physics = $40 - 20 - 10 + 5 = 15$.
    Only Chemistry = $35 - 15 - 10 + 5 = 15$.
    Total exactly one = $20 + 15 + 15 = 50$.
  2. Question 2: Prove that $(A \cup B) - C = (A - C) \cup (B - C)$.
    Solution:
    Let $x \in (A \cup B) - C$.
    $\Leftrightarrow x \in (A \cup B)$ and $x \notin C$.
    $\Leftrightarrow (x \in A \text{ or } x \in B)$ and $x \notin C$.
    $\Leftrightarrow (x \in A \text{ and } x \notin C)$ or $(x \in B \text{ and } x \notin C)$.
    $\Leftrightarrow x \in (A - C)$ or $x \in (B - C)$.
    $\Leftrightarrow x \in (A - C) \cup (B - C)$.
  3. Question 3: Two finite sets have m and n elements. The total number of subsets of the first set is 56 more than the total number of subsets of the second set. Find the values of m and n.
    Solution:
    Let sets A and B have m and n elements.
    $2^m - 2^n = 56$.
    $2^n(2^{m-n} - 1) = 56$.
    Since 56 can be factored as $8 \times 7 = 2^3 \times 7$.
    Comparing factors: $2^n = 2^3 \Rightarrow n = 3$.
    $2^{m-n} - 1 = 7 \Rightarrow 2^{m-3} = 8 = 2^3 \Rightarrow m - 3 = 3 \Rightarrow m = 6$.
    So, $m = 6, n = 3$.
  4. Question 4: Show that $A \subset B \Leftrightarrow B' \subset A'$.
    Solution:
    ($\Rightarrow$) Let $A \subset B$. Let $x \in B'$. Then $x \notin B$.
    Since $A \subset B$, if $x \notin B$, then $x \notin A$. So $x \in A'$. Hence $B' \subset A'$.
    ($\Leftarrow$) Let $B' \subset A'$. Let $x \in A$. Then $x \notin A'$.
    Since $B' \subset A'$, if $x \notin A'$, then $x \notin B'$. So $x \in B$. Hence $A \subset B$.
  5. Question 5: If A and B are sets, prove that $A \cap B' = \phi \Rightarrow A \subset B$.
    Solution:
    Suppose $A \cap B' = \phi$. This means there is no element strictly in A but not in B.
    Let $x \in A$. If $x \notin B$, then $x \in B'$. So $x \in A \cap B'$, which contradicts $A \cap B' = \phi$.
    Thus, every element of A must be in B.
    Therefore, $A \subset B$.
  6. Question 6: In a town of 10,000 families, it was found that 40% buy newspaper A, 20% buy newspaper B and 10% buy newspaper C. 5% buy A and B, 3% buy B and C, and 4% buy A and C. If 2% buy all three, find the number of families which buy none of A, B, or C.
    Solution:
    $n(U) = 100$. (Working in %).
    $n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(A \cap C) + n(A \cap B \cap C)$
    $= 40 + 20 + 10 - 5 - 3 - 4 + 2 = 60$.
    Percentage buying none = $100 - 60 = 40\%$.
    Number of families = $40\%$ of 10,000 = 4000.
  7. Question 7: Let A, B, and C be sets such that $A \cup B = A \cup C$ and $A \cap B = A \cap C$. Show that $B = C$.
    Solution:
    $B = B \cap (A \cup B)$ (Absorption law)
    $= B \cap (A \cup C)$ (Given)
    $= (B \cap A) \cup (B \cap C)$ (Distributive)
    $= (C \cap A) \cup (B \cap C)$ (Given $A \cap B = A \cap C$)
    $= C \cap (A \cup B)$ (Distributive)
    $= C \cap (A \cup C)$ (Given)
    $= C$ (Absorption law). Hence, $B = C$.
  8. Question 8: If $P(A) = P(B)$, show that $A = B$.
    Solution:
    Let $x \in A$. Then $\{x\} \subset A$, so $\{x\} \in P(A)$.
    Since $P(A) = P(B)$, $\{x\} \in P(B)$, which implies $\{x\} \subset B$.
    So, $x \in B$. Therefore $A \subset B$.
    Similarly, we can show $B \subset A$.
    Hence $A = B$.
  9. Question 9: For any sets A and B, show that $P(A \cap B) = P(A) \cap P(B)$.
    Solution:
    Let $X \in P(A \cap B) \Leftrightarrow X \subset (A \cap B)$.
    $\Leftrightarrow X \subset A \text{ and } X \subset B$.
    $\Leftrightarrow X \in P(A) \text{ and } X \in P(B)$.
    $\Leftrightarrow X \in P(A) \cap P(B)$.
    Thus, $P(A \cap B) = P(A) \cap P(B)$.
  10. Question 10: Write the set $A = \{\frac{1}{2}, \frac{2}{3}, \frac{3}{4}, \frac{4}{5}, \frac{5}{6}, \frac{6}{7}\}$ in set-builder form.
    Solution:
    Observe the pattern: numerator is $n$, denominator is $n+1$.
    $A = \{x : x = \frac{n}{n+1}, n \in N \text{ and } 1 \le n \le 6\}$.
