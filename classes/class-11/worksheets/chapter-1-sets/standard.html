Chapter 1: Sets

Overview

This page provides an Overview of Chapter 1 Sets for CBSE Class 11. Topics covered include key concepts, formulas, and problem-solving techniques. All content is aligned with the NCERT syllabus for Board Exam preparation.

Standard Level Worksheet

Back to Worksheets
  1. Question 1: Write the set $\{x : x \in R, -4 < x \le 6\}$ as an interval.
    Solution:
    The set contains real numbers greater than -4 but less than or equal to 6.
    Using interval notation, this is $(-4, 6]$.
  2. Question 2: If $A = \{1, 2, 3, 4, 5, 6\}$, $B = \{2, 4, 6, 8\}$, find $A - B$ and $B - A$.
    Solution:
    $A - B = \{x : x \in A, x \notin B\} = \{1, 3, 5\}$.
    $B - A = \{x : x \in B, x \notin A\} = \{8\}$.
  3. Question 3: Represent $(A \cup B)'$ using a Venn diagram description.
    Solution:
    $(A \cup B)'$ represents the complement of the union of sets A and B.
    In a Venn diagram with a universal set U (rectangle) and two intersecting circles A and B, $(A \cup B)'$ is the region outside both circles A and B but within the rectangle.
  4. Question 4: If $n(A) = 17$, $n(B) = 23$ and $n(A \cup B) = 38$, find $n(A \cap B)$.
    Solution:
    Using the formula $n(A \cup B) = n(A) + n(B) - n(A \cap B)$:
    $38 = 17 + 23 - n(A \cap B)$
    $38 = 40 - n(A \cap B)$
    $n(A \cap B) = 40 - 38 = 2$.
  5. Question 5: Write down the power set of $A = \{1, 2\}$.
    Solution:
    The subsets of $A$ are $\phi, \{1\}, \{2\}, \{1, 2\}$.
    Power Set $P(A) = \{\phi, \{1\}, \{2\}, \{1, 2\}\}$.
  6. Question 6: If $U = \{1, 2, 3, 4, 5, 6, 7, 8, 9\}$, $A = \{2, 4, 6, 8\}$ and $B = \{2, 3, 5, 7\}$. Verify that $(A \cup B)' = A' \cap B'$.
    Solution:
    $A \cup B = \{2, 3, 4, 5, 6, 7, 8\}$. So, $(A \cup B)' = \{1, 9\}$.
    $A' = \{1, 3, 5, 7, 9\}$, $B' = \{1, 4, 6, 8, 9\}$.
    $A' \cap B' = \{1, 9\}$.
    Hence, verified.
  7. Question 7: Let $A$ and $B$ be two sets such that $A \subset B$. What is $A \cup B$?
    Solution:
    Since all elements of A are in B ($A \subset B$), the union of A and B will simply be the set B itself.
    Therefore, $A \cup B = B$.
  8. Question 8: Are the sets $A = \{x : x \text{ is an even integer}\}$ and $B = \{x : x \text{ is an odd integer}\}$ disjoint?
    Solution:
    Yes.
    Even integers are of the form $2k$, odd integers are $2k+1$. No integer can be both even and odd.
    $A \cap B = \phi$, so they are disjoint sets.
  9. Question 9: In a group of 400 people, 250 can speak Hindi and 200 can speak English. How many people can speak both Hindi and English? (Assume every person speaks at least one language).
    Solution:
    Let H be the set of Hindi speakers, E be English speakers.
    $n(H \cup E) = 400$, $n(H) = 250$, $n(E) = 200$.
    $n(H \cap E) = n(H) + n(E) - n(H \cup E)$
    $= 250 + 200 - 400 = 450 - 400 = 50$.
    50 people can speak both.
  10. Question 10: Show that $A \cap B = A$ implies $A \subset B$.
    Solution:
    Given $A \cap B = A$.
    Let $x$ be an arbitrary element of $A$.
    Since $x \in A$ and $A = A \cap B$, then $x \in A \cap B$.
    By definition of intersection, $x \in A$ and $x \in B$.
    Since every element $x$ of A is also in B, $A \subset B$.
