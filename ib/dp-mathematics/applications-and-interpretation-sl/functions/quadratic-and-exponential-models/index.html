Quadratic & Exponential Models

Modelling real-world phenomena: parabolic trajectories, maximum/minimum vertex coordinates, exponential population growth, radioactive half-life, Newton's law of cooling, and horizontal asymptotes.

AI SL 2.4 / 2.5 Growth & Decay Vertex Trajectory ~6 Study Hours
2.4A

Quadratic Models & Projectile Motion

Quadratic models represent processes featuring an optimum turning point (maximum or minimum) or gravitational projectile trajectories:

$$f(x) = ax^2 + bx + c \quad (a \ne 0)$$ $$\text{Axis of symmetry / Vertex } x\text{-coordinate: } x = -\frac{b}{2a}$$ $$\text{Vertex Form: } f(x) = a(x - h)^2 + k \implies \text{Vertex at } (h, k)$$

In projectile motion under Earth gravity ($g \approx 9.8\text{ m/s}^2$):

$$h(t) = -4.9t^2 + v_0 t + h_0$$ $$\text{Max height occurs at } t = \frac{v_0}{9.8}, \quad \text{Flight duration solved by setting } h(t) = 0$$
2.5A

Exponential Growth and Decay ($f(x) = ka^x + c$)

Exponential functions model quantities whose rate of increase or decrease is proportional to the current amount:

$$f(x) = ka^x + c \quad (a > 0, a \ne 1)$$ $$\text{Growth: } a > 1 \qquad \text{Decay: } 0 < a < 1$$ $$\text{Horizontal Asymptote: } y = c$$

Horizontal Asymptote Interpretation: As $x \to \infty$ in decay models ($a < 1$), $ka^x \to 0$, so $f(x) \to c$. In cooling models, $c$ represents the ambient room temperature that an object approaches asymptotically but never falls below.

2.5B

Half-Life and Doubling Time Workflows

Key time constants in IB AI applications:

  • Doubling Time ($T_d$): The time needed for population or investment to double ($f(t) = 2f(0)$).
  • Half-Life ($T_{1/2}$): The time needed for radioactive material to decay to half of its initial amount ($f(t) = 0.5f(0)$).
  • On your GDC, graph $Y_1 = f(t)$ and $Y_2 = \text{target value}$ and find the point of intersection using 2nd CALC > Intersect.

Model comparison and shifted growth

  • Compare residuals on the same observations and validation data, not just visual appearance. A quadratic adds curvature but extra parameters can fit noise. State the fitted interval and units.
  • For $f(t)=ka^t+c$, the quantity following constant percentage change is f−c. Half-life/doubling applies to this excess above c, not generally to f itself. The asymptote is approached from above if k>0 and from below if k<0.
  • Example cooling80°Cto20°Cwith excess halving every10minutes: $T(t)=20+60(1/2)^{t/10}$. After10minutesT50, not40.
Exercise 1 [4 marks]

A ball is kicked into the air. Its height in meters after $t$ seconds is modeled by $h(t) = -4.9t^2 + 19.6t + 1.5$.

  1. Find the maximum height reached by the ball.
  2. Find the time at which the ball reaches this maximum height.

Solution:

(b) Time of maximum occurs at vertex: $t = -\frac{b}{2a} = -\frac{19.6}{2(-4.9)} = \frac{19.6}{9.8} = 2.0\text{ seconds}$. [M1][A1]

(a) Maximum height $= h(2) = -4.9(2)^2 + 19.6(2) + 1.5$ [M1]

$= -19.6 + 39.2 + 1.5 = 21.1\text{ meters}$. [A1]

Exercise 2 [3 marks]

Using the model from Exercise 1, find the total time the ball remains in the air before hitting the ground.

Solution:

Set $h(t) = 0 \implies -4.9t^2 + 19.6t + 1.5 = 0$ [M1]

Using quadratic formula or GDC polynomial solver: [M1]

$t = \frac{-19.6 \pm \sqrt{19.6^2 - 4(-4.9)(1.5)}}{-9.8} \implies t \approx 4.075\text{ s}$ (reject negative root $t \approx -0.075$). [A1]

Total time in air is $4.08\text{ seconds}$ (to 3 s.f.).

Exercise 3 [3 marks]

A population of bacteria is modeled by $P(t) = 450(1.08)^t$, where $t$ is measured in hours.

  1. State the initial bacteria population.
  2. Find the hourly percentage growth rate.

Solution:

(a) When $t = 0$: $P(0) = 450(1.08)^0 = 450$ bacteria. [A1]

(b) Base $a = 1.08 = 1 + 0.08$. [M1]

The hourly growth rate is $8\%$ per hour. [A1]

Exercise 4 [4 marks]

For the bacteria population in Exercise 3 ($P(t) = 450(1.08)^t$), calculate the doubling time in hours.

Solution:

Double initial population: $P(t) = 2 \times 450 = 900$. [M1]

$450(1.08)^t = 900 \implies 1.08^t = 2$ [M1]

$t = \frac{\ln(2)}{\ln(1.08)}$ [M1]

$t = \frac{0.693147}{0.076961} \approx 9.006... \approx 9.01\text{ hours}$. [A1]

Exercise 5 [4 marks]

A cup of coffee cools according to the model $T(t) = 65(0.92)^t + 22$, where $T$ is temperature in $^\circ\text{C}$ and $t$ is time in minutes.

  1. Find the temperature of the coffee immediately after brewing ($t = 0$).
  2. Write down the equation of the horizontal asymptote of $T(t)$, and state its physical meaning.

Solution:

(a) $T(0) = 65(0.92)^0 + 22 = 65(1) + 22 = 87^\circ\text{C}$. [A1]

(b) Horizontal asymptote: $y = 22$ (or $T = 22$). [A1]

Physical meaning: Ambient room temperature ($22^\circ\text{C}$), which the coffee approaches as time progresses. [R2]

Exercise 6 [4 marks]

A radioactive isotope decays according to $M(t) = M_0 e^{-0.035t}$, where $t$ is in years. Find the half-life of the substance.

Solution:

Set $M(t) = 0.5M_0 \implies M_0 e^{-0.035t} = 0.5M_0$ [M1]

$e^{-0.035t} = 0.5 \implies -0.035t = \ln(0.5)$ [M1]

$t = \frac{\ln(0.5)}{-0.035} = \frac{-0.69315}{-0.035}$ [M1]

$t \approx 19.80... \approx 19.8\text{ years}$. [A1]

Exercise 7 [4 marks]

A farmer has $120\text{ meters}$ of fencing to enclose a rectangular paddock against a straight river bank (no fencing needed on the river side). Find the dimensions of the paddock that maximize the enclosed area.

Solution:

Let width perpendicular to river be $x$. Length along river is $L = 120 - 2x$. [M1]

Area $A(x) = x(120 - 2x) = 120x - 2x^2 = -2x^2 + 120x$. [A1]

Maximum area occurs at vertex: $x = -\frac{b}{2a} = -\frac{120}{2(-2)} = \frac{120}{4} = 30\text{ meters}$. [M1]

Dimensions: width $x = 30\text{ m}$, length $L = 120 - 2(30) = 60\text{ m}$. [A1]

Exercise 8 [3 marks]

Explain why an exponential growth model $P(t) = P_0 (1.05)^t$ cannot realistically model human city population growth indefinitely over centuries.

Solution:

Exponential growth assumes unlimited resources and constant growth rate without bound. [R1]

In reality, environmental carrying capacity, land availability, water, food supply, and social factors constrain growth, leading to a logistic S-curve plateau rather than unbounded exponential growth. [A2]

Exercise 9 [4 marks]

A quadratic function has vertex at $(4, 18)$ and passes through $(2, 10)$. Find the equation of the function in expanded standard form $f(x) = ax^2 + bx + c$.

Solution:

Vertex form: $f(x) = a(x - 4)^2 + 18$. [M1]

Substitute $(2, 10)$: $10 = a(2 - 4)^2 + 18 \implies 10 = 4a + 18 \implies 4a = -8 \implies a = -2$. [M1]

$f(x) = -2(x^2 - 8x + 16) + 18 = -2x^2 + 16x - 32 + 18$. [M1]

$f(x) = -2x^2 + 16x - 14$. [A1]

Exercise 10 [4 marks]

The value of a car depreciates according to $V(t) = 32000(0.85)^t$, where $t$ is time in years. Find the time taken for the car's value to drop below $10,000$.

Solution:

Set $V(t) = 10000 \implies 32000(0.85)^t = 10000$ [M1]

$0.85^t = \frac{10000}{32000} = 0.3125$ [M1]

$t = \frac{\ln(0.3125)}{\ln(0.85)} = \frac{-1.16315}{-0.16252} \approx 7.157...$ [M1]

$7.16\text{ years}$ (or during the 8th year). [A1]

Core Formulas (Topic 2.4 & 2.5)

Quadratic Axis of Symmetry $$x = -\frac{b}{2a}$$
Quadratic Vertex Form $$f(x) = a(x - h)^2 + k \quad \implies \text{Vertex at } (h, k)$$
Exponential Model Form $$f(x) = ka^x + c \quad \text{with asymptote } y = c$$
Doubling Time / Half-Life $$T_d = \frac{\ln(2)}{\ln(a)}, \qquad T_{1/2} = \frac{\ln(0.5)}{\ln(a)}$$

Top 5 IB Exam Traps to Avoid

  • Trap 1: Confusing vertex $x$ with vertex $y$: The question "find the maximum height" asks for $y$ ($k$), whereas "find when maximum height is reached" asks for $t$ ($h$).
  • Trap 2: Forgetting the horizontal asymptote in $ka^x + c$: The asymptote is $y = c$, not $y = 0$. In cooling models, $T \to \text{room temp}$, not $0^\circ\text{C}$.
  • Trap 3: Sign error in $a(x - h)^2$: If $f(x) = 3(x + 5)^2 + 4$, the vertex is $(-5, 4)$, not $(+5, 4)$.
  • Trap 4: Discarding context-negative roots without explanation: When finding flight time $h(t) = 0$, explicitly state "reject negative root $t < 0$ as $t$ represents elapsed time".
  • Trap 5: Using degrees instead of logarithms on GDC: Ensure log base or natural log calculations are evaluated correctly.
