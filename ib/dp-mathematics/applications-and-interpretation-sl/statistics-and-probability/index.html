Exam insights

Key ideas & Hypothesis Testing Decision Rules

  • The $p$-value Decision Rule:
    • If $p < \alpha$ (significance level, usually $0.05$), reject $H_0$. There is significant evidence of an association.
    • If $p \ge \alpha$, do not reject $H_0$. There is insufficient evidence of an association.
  • Test Statistic Rule: If $\chi^2_{\text{calc}} > \chi^2_{\text{crit}}$, reject $H_0$.
  • Expected Frequencies Condition: The $\chi^2$ test is only valid if all expected frequencies $f_e \ge 5$.
