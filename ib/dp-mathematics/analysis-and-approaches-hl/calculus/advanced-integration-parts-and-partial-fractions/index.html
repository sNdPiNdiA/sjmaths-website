Advanced Integration: Parts & Partial Fractions

Expand your integration repertoire. Master integration by parts $\int u\,dv = uv - \int v\,du$ using the LIATE hierarchy, conquer cyclic looping integrals, and integrate rational expressions via partial fraction decompositions.

Syllabus AHL 5.13 Paper 1 & Paper 2 Skill 4 Interactive Tabs 10 Tiered Problems + Mini Test

Figure 5.3: Geometric Representation of Integration by Parts: $uv = \int u\,dv + \int v\,du$

1. Integration by Parts Formula

Integration by parts is derived from the product rule of differentiation:

$$\frac{d}{dx}[uv] = u\frac{dv}{dx} + v\frac{du}{dx} \implies u\frac{dv}{dx} = \frac{d}{dx}[uv] - v\frac{du}{dx}$$

Integrating both sides gives the fundamental formula:

$$\int u \frac{dv}{dx}\,dx = uv - \int v \frac{du}{dx}\,dx \quad \iff \quad \int u\,dv = uv - \int v\,du$$

For definite integrals with limits $a$ to $b$:

$$\int_a^b u\,dv = [uv]_a^b - \int_a^b v\,du$$

2. Choosing $u$ with the LIATE Rule

Select $u$ to be the function that appears first in the LIATE acronym:

  1. L: Logarithmic functions ($\ln x, \log_a x$)
  2. I: Inverse trigonometric functions ($\arcsin x, \arctan x$)
  3. A: Algebraic / polynomial functions ($x^n, x^2 + 1$)
  4. T: Trigonometric functions ($\sin x, \cos x$)
  5. E: Exponential functions ($e^x, 2^x$)

3. Special Integration by Parts Techniques

  • Integrating $\ln x$ or $\arctan x$ alone: Write as $\int 1 \cdot \ln x\,dx$, letting $u = \ln x$ and $dv = 1\,dx$.
  • Repeated Integration by Parts: For $\int x^2 e^x\,dx$ or $\int x^2 \cos x\,dx$, apply parts twice to reduce the power of $x$ until a standard integral is reached.
  • Cyclic (Looping) Integrals: For $\int e^{ax}\sin(bx)\,dx$, applying parts twice reproduces the original integral $I$. Solve for $I$ algebraically: $$I = (\dots) - k I \implies (1 + k)I = (\dots) \implies I = \frac{\dots}{1 + k}$$

4. Integration via Partial Fractions

Decomposing rational functions simplifies them into standard integrals:

$$\int \frac{1}{ax + b}\,dx = \frac{1}{a}\ln|ax + b| + C$$ $$\int \frac{1}{(ax + b)^2}\,dx = -\frac{1}{a(ax + b)} + C$$ $$\int \frac{1}{x^2 + a^2}\,dx = \frac{1}{a}\arctan\left(\frac{x}{a}\right) + C$$

5. Worked Examples

Worked Example 1: Repeated Integration by Parts

Evaluate $\int x^2 e^x\,dx$.

Solution:

By LIATE, choose $u = x^2$ (Algebraic) and $dv = e^x\,dx$ (Exponential):

$$du = 2x\,dx, \quad v = e^x$$ $$\int x^2 e^x\,dx = x^2 e^x - \int 2x e^x\,dx = x^2 e^x - 2\int x e^x\,dx$$

Apply parts a second time to $\int x e^x\,dx$ with $u_1 = x, dv_1 = e^x\,dx$ ($du_1 = dx, v_1 = e^x$):

$$\int x e^x\,dx = x e^x - \int e^x\,dx = x e^x - e^x$$

Substitute back:

$$\int x^2 e^x\,dx = x^2 e^x - 2(x e^x - e^x) + C = (x^2 - 2x + 2)e^x + C$$

Worked Example 2: Cyclic Looping Integral

Evaluate $I = \int e^x \cos x\,dx$.

Solution:

Let $u = \cos x, dv = e^x\,dx \implies du = -\sin x\,dx, v = e^x$:

$$I = e^x \cos x - \int e^x(-\sin x)\,dx = e^x \cos x + \int e^x \sin x\,dx$$

Apply parts again to $\int e^x \sin x\,dx$ with $u = \sin x, dv = e^x\,dx \implies du = \cos x\,dx, v = e^x$:

$$\int e^x \sin x\,dx = e^x \sin x - \int e^x \cos x\,dx = e^x \sin x - I$$

Substitute back into the expression for $I$:

$$I = e^x \cos x + e^x \sin x - I$$ $$2I = e^x(\cos x + \sin x) \implies I = \frac{e^x(\cos x + \sin x)}{2} + C$$

Worked Example 3: Integration by Partial Fractions

Evaluate $\int_2^3 \frac{5x - 3}{(x - 1)(x + 1)}\,dx$.

Solution:

Partial fraction decomposition: $\frac{5x - 3}{(x - 1)(x + 1)} = \frac{A}{x - 1} + \frac{B}{x + 1}$.
$5x - 3 = A(x + 1) + B(x - 1)$.
• $x = 1$: $2 = 2A \implies A = 1$.
• $x = -1$: $-8 = -2B \implies B = 4$.

$$\int_2^3 \left( \frac{1}{x - 1} + \frac{4}{x + 1} \right)\,dx = \left[ \ln|x - 1| + 4\ln|x + 1| \right]_2^3$$ $$= [ \ln(2) + 4\ln(4) ] - [ \ln(1) + 4\ln(3) ] = \ln(2) + 4\ln(2^2) - 0 - 4\ln(3)$$ $$= \ln(2) + 8\ln(2) - 4\ln(3) = 9\ln(2) - 4\ln(3) = \ln\left(\frac{2^9}{3^4}\right) = \ln\left(\frac{512}{81}\right) \approx 1.844$$

Practice Exercises (10 Tiered Questions)

Work through these 10 examination-style exercises progressing from core algorithmic competence to advanced IB distinction problems. Click each toggle to reveal detailed algebraic solutions.

Exercise 1 (Foundational: Standard Integration by Parts)

Evaluate $\int x \sin x\,dx$.

Show Full Solution

LIATE: $u = x \implies du = dx$; $dv = \sin x\,dx \implies v = -\cos x$. [M1]
$\int x \sin x\,dx = -x\cos x - \int (-\cos x)\,dx = -x\cos x + \sin x + C$. [A1]

Exercise 2 (Foundational: Integrating Natural Log)

Evaluate $\int \ln x\,dx$.

Show Full Solution

Write as $\int 1 \cdot \ln x\,dx$. $u = \ln x \implies du = \frac{1}{x}dx$; $dv = 1\,dx \implies v = x$. [M1]
$\int \ln x\,dx = x\ln x - \int x\left(\frac{1}{x}\right)dx = x\ln x - \int 1\,dx = x\ln x - x + C$. [A1]

Exercise 3 (Foundational: Linear Partial Fraction Integral)

Evaluate $\int \frac{3}{2x + 5}\,dx$.

Show Full Solution

$\frac{3}{2}\int \frac{2}{2x + 5}\,dx = \frac{3}{2}\ln|2x + 5| + C$. [A1]

Exercise 4 (Intermediate: Definite Integral by Parts)

Evaluate $\int_0^1 x e^{2x}\,dx$.

Show Full Solution

$u = x, dv = e^{2x}dx \implies du = dx, v = \frac{1}{2}e^{2x}$. [M1]
$= \left[\frac{1}{2}x e^{2x}\right]_0^1 - \int_0^1 \frac{1}{2}e^{2x}\,dx = \frac{1}{2}e^2 - \left[\frac{1}{4}e^{2x}\right]_0^1$ [M1]
$= \frac{1}{2}e^2 - \left(\frac{1}{4}e^2 - \frac{1}{4}\right) = \frac{1}{4}e^2 + \frac{1}{4} = \frac{e^2 + 1}{4}$. [A1]

Exercise 5 (Intermediate: Inverse Tangent Integration)

Find $\int \arctan x\,dx$.

Show Full Solution

$u = \arctan x \implies du = \frac{1}{1+x^2}dx$; $dv = 1\,dx \implies v = x$. [M1]
$\int \arctan x\,dx = x\arctan x - \int \frac{x}{1+x^2}\,dx$. [M1]
$= x\arctan x - \frac{1}{2}\ln(1 + x^2) + C$. [A1]

Exercise 6 (Intermediate: Partial Fractions with Repeated Factor)

Evaluate $\int \frac{x + 2}{(x + 1)^2}\,dx$.

Show Full Solution

$\frac{x + 2}{(x + 1)^2} = \frac{(x + 1) + 1}{(x + 1)^2} = \frac{1}{x + 1} + \frac{1}{(x + 1)^2}$. [M1]
$\int \left(\frac{1}{x + 1} + (x + 1)^{-2}\right)dx = \ln|x + 1| - \frac{1}{x + 1} + C$. [A1]

Exercise 7 (Exam Standard: Definite Integral with Partial Fractions)

Evaluate $\int_0^1 \frac{2x^2 + 5x + 1}{(x + 1)(x + 2)}\,dx$.

Show Full Solution

Degree numerator = degree denominator = 2. Divide polynomials first: [M1]
$\frac{2x^2 + 5x + 1}{x^2 + 3x + 2} = 2 + \frac{-x - 3}{x^2 + 3x + 2} = 2 - \frac{x + 3}{(x + 1)(x + 2)}$. [A1]
Decompose $\frac{x + 3}{(x + 1)(x + 2)} = \frac{A}{x + 1} + \frac{B}{x + 2}$: $A = 2, B = -1$.
Integral: $\int_0^1 \left(2 - \frac{2}{x + 1} + \frac{1}{x + 2}\right)dx = [2x - 2\ln(x+1) + \ln(x+2)]_0^1$ [M1]
$= [2 - 2\ln 2 + \ln 3] - [0 - 0 + \ln 2] = 2 - 3\ln 2 + \ln 3 = 2 + \ln(3/8)$. [A1]

Exercise 8 (Advanced: Cyclic Integral with Exponential and Sine)

Find $\int e^{2x}\sin x\,dx$.

Show Full Solution

Let $I = \int e^{2x}\sin x\,dx$. $u = \sin x, dv = e^{2x}dx \implies du = \cos x\,dx, v = \frac{1}{2}e^{2x}$. [M1]
$I = \frac{1}{2}e^{2x}\sin x - \frac{1}{2}\int e^{2x}\cos x\,dx$.
For $\int e^{2x}\cos x\,dx$: $u = \cos x, dv = e^{2x}dx \implies du = -\sin x\,dx, v = \frac{1}{2}e^{2x}$. [M1]
$= \frac{1}{2}e^{2x}\cos x + \frac{1}{2}\int e^{2x}\sin x\,dx = \frac{1}{2}e^{2x}\cos x + \frac{1}{2}I$.
Substitute back: $I = \frac{1}{2}e^{2x}\sin x - \frac{1}{2}\left(\frac{1}{2}e^{2x}\cos x + \frac{1}{2}I\right) = \frac{1}{2}e^{2x}\sin x - \frac{1}{4}e^{2x}\cos x - \frac{1}{4}I$. [M1]
$\frac{5}{4}I = \frac{1}{4}e^{2x}(2\sin x - \cos x) \implies I = \frac{e^{2x}(2\sin x - \cos x)}{5} + C$. [A1]

Exercise 9 (Advanced: Reduction Formula for Powers of Natural Log)

Let $I_n = \int (\ln x)^n\,dx$. Show that $I_n = x(\ln x)^n - n I_{n-1}$, and hence evaluate $\int (\ln x)^2\,dx$.

Show Full Solution

$u = (\ln x)^n, dv = dx \implies du = n(\ln x)^{n-1}\frac{1}{x}dx, v = x$. [M1]
$I_n = x(\ln x)^n - \int x \cdot n(\ln x)^{n-1}\frac{1}{x}dx = x(\ln x)^n - n\int (\ln x)^{n-1}\,dx = x(\ln x)^n - n I_{n-1}$. [A1]
For $n = 2$: $I_2 = x(\ln x)^2 - 2I_1$.
Since $I_1 = \int \ln x\,dx = x\ln x - x$:
$I_2 = x(\ln x)^2 - 2(x\ln x - x) + C = x(\ln x)^2 - 2x\ln x + 2x + C$. [A1]

Exercise 10 (Advanced: Partial Fraction with Irreducible Quadratic)

Evaluate $\int \frac{2x^2 - x + 4}{x(x^2 + 4)}\,dx$.

Show Full Solution

$\frac{2x^2 - x + 4}{x(x^2 + 4)} = \frac{A}{x} + \frac{Bx + C}{x^2 + 4}$. [M1]
$2x^2 - x + 4 = A(x^2 + 4) + (Bx + C)x$.
• $x = 0$: $4 = 4A \implies A = 1$. [A1]
• Compare $x^2$: $2 = A + B \implies 2 = 1 + B \implies B = 1$.
• Compare $x$: $-1 = C \implies C = -1$.
Integral: $\int \left( \frac{1}{x} + \frac{x - 1}{x^2 + 4} \right)dx = \int \frac{1}{x}\,dx + \frac{1}{2}\int \frac{2x}{x^2 + 4}\,dx - \int \frac{1}{x^2 + 4}\,dx$. [M1]
$= \ln|x| + \frac{1}{2}\ln(x^2 + 4) - \frac{1}{2}\arctan\left(\frac{x}{2}\right) + C$. [A1]

Examination Pitfalls & Examiner Tips

Sign Errors in Cyclic Integrals

When applying parts twice, watch double and triple negative signs: $-(-(-I)) = -I$. Always write out parentheses carefully.

Forgetting $\frac{1}{a}$ in Arctan

$\int \frac{1}{x^2 + 9}\,dx = \frac{1}{3}\arctan\left(\frac{x}{3}\right) + C$. Forgetting the leading $\frac{1}{3}$ factor is a classic error.

Question 5 (Paper 1 Style · 6 marks)

Consider the integral $I = \int_1^e x^2 \ln x\,dx$.
(a) Use integration by parts to show that $I = \left[ \frac{x^3}{3}\ln x \right]_1^e - \int_1^e \frac{x^2}{3}\,dx$. [3 marks]
(b) Hence evaluate the exact value of $I$ in terms of $e$. [3 marks]

Show Full Markscheme

(a) Parts set up: [3 marks]
$u = \ln x \implies du = \frac{1}{x}dx$ [M1].
$dv = x^2 dx \implies v = \frac{x^3}{3}$ [M1].
$I = \left[ \frac{x^3}{3}\ln x \right]_1^e - \int_1^e \frac{x^3}{3}\left(\frac{1}{x}\right)dx = \left[ \frac{x^3}{3}\ln x \right]_1^e - \int_1^e \frac{x^2}{3}\,dx$ [A1].

(b) Evaluation: [3 marks]
First term: $\left( \frac{e^3}{3}\ln e \right) - \left( \frac{1}{3}\ln 1 \right) = \frac{e^3}{3} - 0 = \frac{e^3}{3}$ [A1].
Second term: $\int_1^e \frac{x^2}{3}\,dx = \left[ \frac{x^3}{9} \right]_1^e = \frac{e^3 - 1}{9}$ [A1].
$I = \frac{e^3}{3} - \frac{e^3 - 1}{9} = \frac{3e^3 - e^3 + 1}{9} = \frac{2e^3 + 1}{9}$ [A1].

Question 6 (Paper 2 Style · 7 marks)

A curve has gradient $\frac{dy}{dx} = \frac{x + 7}{(x - 1)(x + 3)}$.
(a) Express $\frac{dy}{dx}$ in partial fractions. [3 marks]
(b) Given that the curve passes through $(2, 5)$, find the equation of the curve in the form $y = f(x)$. [4 marks]

Show Full Markscheme

(a) Partial fractions: [3 marks]
$\frac{x + 7}{(x - 1)(x + 3)} = \frac{A}{x - 1} + \frac{B}{x + 3}$ [M1].
$x + 7 = A(x + 3) + B(x - 1)$.
• $x = 1$: $8 = 4A \implies A = 2$ [A1].
• $x = -3$: $4 = -4B \implies B = -1$ [A1].
$\frac{dy}{dx} = \frac{2}{x - 1} - \frac{1}{x + 3}$.

(b) Integration & Particular Solution: [4 marks]
$y = \int \left(\frac{2}{x - 1} - \frac{1}{x + 3}\right)dx = 2\ln|x - 1| - \ln|x + 3| + C$ [M1][A1].
Substitute $(2, 5)$:
$5 = 2\ln(1) - \ln(5) + C = 0 - \ln 5 + C \implies C = 5 + \ln 5$ [M1].
$y = 2\ln|x - 1| - \ln|x + 3| + 5 + \ln 5 = \ln\left( \frac{5(x - 1)^2}{|x + 3|} \right) + 5$ [A1].
