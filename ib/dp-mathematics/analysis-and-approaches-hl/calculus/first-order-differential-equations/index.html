First-Order Differential Equations & Euler’s Method

Solve analytical and numerical first-order differential equations: separation of variables $\frac{dy}{dx} = g(x)h(y)$, integrating factor $I(x) = e^{\int P(x)dx}$ for linear ODEs, and Euler’s step-by-step approximation $y_{n+1} = y_n + h f(x_n, y_n)$.

1. Separation of Variables (Topic 5.16)

A first-order ordinary differential equation (ODE) is separable if it can be expressed in the form:

$$\frac{dy}{dx} = g(x) \, h(y) \quad \Longleftrightarrow \quad \frac{1}{h(y)} \, dy = g(x) \, dx$$

Integrating both sides yields the general solution:

$$\int \frac{1}{h(y)} \, dy = \int g(x) \, dx + C$$
Examiner Tip: Always add the constant of integration $C$ immediately upon performing the indefinite integration, before applying algebraic transformations such as taking exponentials or square roots.

2. Linear Differential Equations & Integrating Factor Method (Topic 5.16)

A linear first-order differential equation has standard form:

$$\frac{dy}{dx} + P(x)\,y = Q(x)$$

To solve, multiply every term by the integrating factor $I(x)$ defined as:

$$I(x) = e^{\int P(x) \, dx}$$

By the product rule, the left-hand side collapses into the exact derivative of a single product:

$$\frac{d}{dx}\left[ y \cdot I(x) \right] = Q(x) \cdot I(x)$$

Integrating with respect to $x$ gives the closed-form general solution:

$$y \cdot I(x) = \int Q(x) \, I(x) \, dx + C \quad \implies \quad y = \frac{1}{I(x)}\left( \int Q(x) \, I(x) \, dx + C \right)$$

3. Euler’s Method for Numerical Solutions (Topic 5.17)

When an ODE $\frac{dy}{dx} = f(x, y)$ cannot be solved analytically in elementary functions, Euler’s Method provides a first-order numerical approximation over successive discrete increments of step size $h$:

$$\begin{cases} x_{n+1} = x_n + h \\ y_{n+1} = y_n + h \cdot f(x_n, y_n) \end{cases}$$
Error Analysis & Concavity:
  • If $y''(x) > 0$ (curve is concave up), the tangent lines lie below the curve $\implies$ Euler’s method yields an underestimate.
  • If $y''(x) < 0$ (curve is concave down), the tangent lines lie above the curve $\implies$ Euler’s method yields an overestimate.

Core Algorithmic Exercise 1

Find the general solution of the differential equation $\frac{dy}{dx} = 2x(y^2 + 1)$.

View Full Algebraic Solution

Step 1: Separate variables:

$$\frac{1}{y^2 + 1}\,dy = 2x\,dx$$

Step 2: Integrate both sides:

$$\int \frac{1}{y^2 + 1}\,dy = \int 2x\,dx \implies \arctan(y) = x^2 + C$$

Step 3: Solve explicitly for $y$:

$$y = \tan(x^2 + C)$$
Core Algorithmic Exercise 2

Solve the initial value problem $\frac{dy}{dx} = \frac{e^{2x}}{y}$, with initial condition $y(0) = -3$.

View Full Algebraic Solution

Step 1: Separate variables and integrate:

$$y\,dy = e^{2x}\,dx \implies \int y\,dy = \int e^{2x}\,dx \implies \frac{1}{2}y^2 = \frac{1}{2}e^{2x} + C$$

Multiply by 2: $y^2 = e^{2x} + K$, where $K = 2C$.

Step 2: Apply initial condition $y(0) = -3$:

$$(-3)^2 = e^0 + K \implies 9 = 1 + K \implies K = 8$$

Step 3: Choose the correct sign branch:

Since $y(0) = -3 < 0$, we choose the negative square root:

$$y = -\sqrt{e^{2x} + 8}$$
Standard Exam Exercise 3

Find the general solution of the linear differential equation $\frac{dy}{dx} + \frac{2}{x}y = 5x^2$, for $x > 0$.

View Full Algebraic Solution

Step 1: Identify standard form:

Here $P(x) = \frac{2}{x}$ and $Q(x) = 5x^2$.

Step 2: Compute integrating factor $I(x)$:

$$I(x) = e^{\int \frac{2}{x}\,dx} = e^{2\ln x} = e^{\ln(x^2)} = x^2$$

Step 3: Multiply the ODE by $I(x) = x^2$:

$$\frac{d}{dx}\left[ x^2 y \right] = x^2(5x^2) = 5x^4$$

Step 4: Integrate with respect to $x$:

$$x^2 y = \int 5x^4\,dx = x^5 + C$$

Step 5: Solve for $y$:

$$y = x^3 + \frac{C}{x^2}$$
Standard Exam Exercise 4

Solve the initial value problem $\frac{dy}{dx} + y\tan x = \cos^2 x$, given that $y(0) = 2$, for $-\frac{\pi}{2} < x < \frac{\pi}{2}$.

View Full Algebraic Solution

Step 1: Find integrating factor $I(x)$:

$$I(x) = e^{\int \tan x\,dx} = e^{\ln|\sec x|} = \sec x$$

Step 2: Apply the product rule integration:

$$\frac{d}{dx}\left[ y\sec x \right] = \sec x \cos^2 x = \cos x$$ $$y\sec x = \int \cos x\,dx = \sin x + C$$

Step 3: Substitute $x=0, y=2$:

$$2\sec(0) = \sin(0) + C \implies 2(1) = 0 + C \implies C = 2$$

Step 4: Solve for $y$:

$$y = \frac{\sin x + 2}{\sec x} = \sin x \cos x + 2\cos x = \frac{1}{2}\sin 2x + 2\cos x$$
Standard Exam Exercise 5

Given the differential equation $\frac{dy}{dx} = x + y^2$ with $y(0) = 1$, use Euler’s method with step size $h = 0.1$ to approximate $y(0.2)$ to 4 decimal places.

View Full Algebraic Solution

Step 1: First iteration from $x_0 = 0$ to $x_1 = 0.1$:

$$f(x_0, y_0) = f(0, 1) = 0 + 1^2 = 1$$ $$y_1 = y_0 + h\cdot f(x_0, y_0) = 1 + 0.1(1) = 1.1$$

Step 2: Second iteration from $x_1 = 0.1$ to $x_2 = 0.2$:

$$f(x_1, y_1) = f(0.1, 1.1) = 0.1 + (1.1)^2 = 0.1 + 1.21 = 1.31$$ $$y_2 = y_1 + h\cdot f(x_1, y_1) = 1.1 + 0.1(1.31) = 1.1 + 0.131 = 1.231$$

Therefore, the approximation is $y(0.2) \approx 1.2310$.

Extended Problem Exercise 6

A hot cup of coffee with initial temperature $90^\circ\text{C}$ is placed in a room at constant temperature $20^\circ\text{C}$. Newton’s law of cooling gives $\frac{dT}{dt} = -k(T - 20)$. After 5 minutes, $T = 60^\circ\text{C}$. Find the temperature after 15 minutes.

View Full Algebraic Solution

Step 1: Separate variables:

$$\frac{1}{T - 20}\,dT = -k\,dt \implies \ln(T - 20) = -kt + C \implies T - 20 = A e^{-kt}$$

Step 2: Use initial condition $T(0) = 90$:

$$90 - 20 = A e^0 \implies A = 70 \implies T(t) = 20 + 70e^{-kt}$$

Step 3: Find decay constant $k$ using $T(5) = 60$:

$$60 = 20 + 70e^{-5k} \implies 40 = 70e^{-5k} \implies e^{-5k} = \frac{4}{7}$$

Step 4: Evaluate temperature at $t = 15$:

Notice that $e^{-15k} = (e^{-5k})^3 = \left(\frac{4}{7}\right)^3 = \frac{64}{343}$.

$$T(15) = 20 + 70\left(\frac{64}{343}\right) = 20 + \frac{10 \times 64}{49} = 20 + \frac{640}{49} \approx 20 + 13.06 = 33.1^\circ\text{C}$$
Extended Problem Exercise 7

Find the particular solution to $x\frac{dy}{dx} - y = x^3 e^x$ satisfying $y(1) = 0$, for $x > 0$.

View Full Algebraic Solution

Step 1: Convert to standard linear form:

Divide by $x$:

$$\frac{dy}{dx} - \frac{1}{x}y = x^2 e^x$$

Step 2: Determine integrating factor $I(x)$:

$$I(x) = e^{\int -\frac{1}{x}\,dx} = e^{-\ln x} = \frac{1}{x}$$

Step 3: Multiply and integrate:

$$\frac{d}{dx}\left[ \frac{y}{x} \right] = \frac{1}{x}(x^2 e^x) = x e^x$$ $$\frac{y}{x} = \int x e^x\,dx$$

Using integration by parts with $u = x, dv = e^x dx$:

$$\int x e^x\,dx = x e^x - e^x + C = e^x(x - 1) + C$$

Step 4: Apply $y(1) = 0$:

$$\frac{0}{1} = e^1(1 - 1) + C \implies C = 0$$

Step 5: Final solution:

$$y = x^2 e^x - x e^x = x(x - 1)e^x$$
Extended Problem Exercise 8

Consider the differential equation $\frac{dy}{dx} = 2x - y$ with $y(0) = 1$. Use Euler’s method with step $h = 0.5$ to estimate $y(1)$. Determine whether this estimate is an overestimate or an underestimate by evaluating the second derivative $y''$.

View Full Algebraic Solution

Step 1: Euler iteration:

$x_0 = 0, y_0 = 1$:

$$y_1 = y_0 + 0.5(2(0) - 1) = 1 - 0.5 = 0.5 \quad (x_1 = 0.5)$$

$x_1 = 0.5, y_1 = 0.5$:

$$y_2 = y_1 + 0.5(2(0.5) - 0.5) = 0.5 + 0.5(0.5) = 0.5 + 0.25 = 0.75 \quad (x_2 = 1)$$

So the Euler estimate is $y(1) \approx 0.75$.

Step 2: Second derivative analysis:

$$y'' = \frac{d}{dx}[2x - y] = 2 - y' = 2 - (2x - y) = 2 - 2x + y$$

On the interval $[0, 1]$, $2 - 2x \ge 0$ and $y(x) > 0$, so $y''(x) > 0$.

Since the curve is concave up ($y'' > 0$), the tangent lines lie below the actual solution, meaning Euler’s method yields an underestimate.

HL Distinction Exercise 9

A tank initially contains $100\text{ L}$ of pure water. Brine containing $0.5\text{ kg/L}$ of salt flows in at $4\text{ L/min}$, and the thoroughly mixed solution drains out at $4\text{ L/min}$. Set up and solve the differential equation for the mass of salt $S(t)$ in the tank at time $t$, and find the limiting salt mass as $t \to \infty$.

View Full Algebraic Solution

Step 1: Rate of change equation:

$$\frac{dS}{dt} = \text{Rate In} - \text{Rate Out}$$ $$\text{Rate In} = 4\text{ L/min} \times 0.5\text{ kg/L} = 2\text{ kg/min}$$ $$\text{Rate Out} = 4\text{ L/min} \times \frac{S(t)}{100}\text{ kg/L} = \frac{S}{25}\text{ kg/min}$$ $$\frac{dS}{dt} = 2 - \frac{S}{25} = \frac{50 - S}{25}$$

Step 2: Separate variables:

$$\frac{1}{50 - S}\,dS = \frac{1}{25}\,dt \implies -\ln|50 - S| = \frac{t}{25} + C$$ $$50 - S = A e^{-t/25}$$

Step 3: Initial condition $S(0) = 0$ (pure water):

$$50 - 0 = A e^0 \implies A = 50$$ $$S(t) = 50\left(1 - e^{-t/25}\right)$$

Step 4: Limiting salt mass:

$$\lim_{t \to \infty} S(t) = 50(1 - 0) = 50\text{ kg}$$
HL Distinction Exercise 10

A falling object of mass $m$ experiences downward gravity $mg$ and air resistance proportional to velocity $kv$. Starting from rest ($v(0) = 0$), solve $m\frac{dv}{dt} = mg - kv$. Then show that as $t \to \infty$, the terminal velocity is $v_T = \frac{mg}{k}$.

View Full Algebraic Solution

Step 1: Rewrite as standard linear ODE:

$$\frac{dv}{dt} + \frac{k}{m}v = g$$

Step 2: Integrating factor:

$$I(t) = e^{\int (k/m)dt} = e^{kt/m}$$

Step 3: Multiply and integrate:

$$\frac{d}{dt}\left[ v e^{kt/m} \right] = g e^{kt/m}$$ $$v e^{kt/m} = \int g e^{kt/m}\,dt = \frac{mg}{k}e^{kt/m} + C$$ $$v(t) = \frac{mg}{k} + C e^{-kt/m}$$

Step 4: Apply $v(0) = 0$:

$$0 = \frac{mg}{k} + C \implies C = -\frac{mg}{k}$$ $$v(t) = \frac{mg}{k}\left(1 - e^{-kt/m}\right)$$

Step 5: Limit as $t \to \infty$:

Since $k, m > 0$, $\lim_{t \to \infty} e^{-kt/m} = 0$, giving $v_T = \frac{mg}{k}$.

Common Errors & Exam Tips

Pitfall: Dropping the Constant $+ C$

In $\ln|y| = \int g(x)dx + C$, students frequently write $y = e^{\int g(x)dx} + C$. The exponentiation must apply to the entire sum: $y = e^{\int g(x)dx + C} = A e^{\int g(x)dx}$ where $A = \pm e^C$.

Pitfall: Sign in Integrating Factor

Ensure the ODE is in standard form $\frac{dy}{dx} + P(x)y = Q(x)$ before taking $P(x)$. If the equation is $\frac{dy}{dx} - \frac{2}{x}y = 1$, then $P(x) = -\frac{2}{x}$, giving $I(x) = e^{-2\ln x} = x^{-2} = \frac{1}{x^2}$.

Examination Paper 1/2 Question 5 (FRQ) · Linear Differential Equation with Boundary Condition

Consider the differential equation $(x + 1)\frac{dy}{dx} + 2y = (x + 1)^3$ for $x > -1$, with $y(0) = 1$.
(a) Show that the integrating factor is $(x + 1)^2$. [2 marks]
(b) Find the explicit particular solution $y(x)$. [5 marks]

View Official IB Markscheme

(a) Standard form and integrating factor:

$$\frac{dy}{dx} + \frac{2}{x + 1}y = (x + 1)^2 \quad \text{[M1]}$$ $$I(x) = e^{\int \frac{2}{x + 1}dx} = e^{2\ln(x + 1)} = (x + 1)^2 \quad \text{[A1]}$$

(b) Multiply and integrate:

$$\frac{d}{dx}\left[ (x + 1)^2 y \right] = (x + 1)^2 (x + 1)^2 = (x + 1)^4 \quad \text{[M1]}$$ $$(x + 1)^2 y = \int (x + 1)^4 dx = \frac{1}{5}(x + 1)^5 + C \quad \text{[M1][A1]}$$

Apply $x=0, y=1$:

$$(1)^2(1) = \frac{1}{5}(1)^5 + C \implies 1 = \frac{1}{5} + C \implies C = \frac{4}{5} \quad \text{[M1]}$$ $$y = \frac{1}{5}(x + 1)^3 + \frac{4}{5(x + 1)^2} \quad \text{[A1]}$$
Examination Paper 1/2 Question 6 (FRQ) · Euler’s Method vs Exact Solution

Consider $\frac{dy}{dx} = 2x - y$ with $y(0) = 2$.
(a) Use Euler’s method with step size $h = 0.1$ to approximate $y(0.2)$. [3 marks]
(b) Solve the ODE analytically to find the exact value of $y(0.2)$. [4 marks]
(c) Calculate the percentage error of the Euler approximation. [2 marks]

View Official IB Markscheme

(a) Euler iterations:

$x_0 = 0, y_0 = 2 \implies f(0, 2) = -2$

$$y_1 = 2 + 0.1(-2) = 1.8 \quad (x_1 = 0.1) \quad \text{[M1]}$$

$f(0.1, 1.8) = 2(0.1) - 1.8 = 0.2 - 1.8 = -1.6$

$$y_2 = 1.8 + 0.1(-1.6) = 1.8 - 0.16 = 1.64 \quad \text{[A1]}$$

(b) Analytical solution:

$$\frac{dy}{dx} + y = 2x \implies I(x) = e^x \quad \text{[M1]}$$ $$\frac{d}{dx}[y e^x] = 2x e^x \implies y e^x = 2(x e^x - e^x) + C = 2e^x(x - 1) + C \quad \text{[M1]}$$

Apply $y(0) = 2 \implies 2 = 2(-1) + C \implies C = 4$

$$y(x) = 2(x - 1) + 4e^{-x} = 2x - 2 + 4e^{-x} \quad \text{[A1]}$$

At $x = 0.2$: $y(0.2) = 2(0.2) - 2 + 4e^{-0.2} = -1.6 + 4(0.81873) = 1.6749$ [A1]

(c) Percentage error:

$$\text{Error} = \left|\frac{1.6749 - 1.6400}{1.6749}\right| \times 100\% = \frac{0.0349}{1.6749} \times 100\% \approx 2.08\% \quad \text{[M1][A1]}$$
