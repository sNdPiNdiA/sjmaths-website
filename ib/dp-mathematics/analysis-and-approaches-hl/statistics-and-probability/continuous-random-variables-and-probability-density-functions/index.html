Continuous Random Variables & PDFs

Study probability density functions (PDF) $f(x)$ satisfying $\int f(x)\,dx = 1$, integrate to compute interval probabilities $P(a \le X \le b)$, derive cumulative distribution functions (CDF) $F(x)$, and calculate medians and percentiles.

Syllabus AHL 4.13 Paper 1 & Paper 2 Skill 4 Interactive Tabs 10 Tiered Problems + Mini Test

Figure 4.1: PDF $f(x)$ with Probability Area vs CDF $F(x)$

1. Continuous Random Variables & PDFs

A continuous random variable $X$ can take any real value in a continuous interval $[a, b]$ (or $(-\infty, \infty)$). It is described by its probability density function (PDF) $f(x)$ satisfying two mandatory conditions:

  1. Non-negativity: $f(x) \ge 0$ for all $x \in \mathbb{R}$.
  2. Total Probability normalization: $$\int_{-\infty}^\infty f(x)\,dx = 1$$

Fundamental Principle: Probability is represented by area under the curve:

$$P(a \le X \le b) = \int_a^b f(x)\,dx$$

Note: The probability of any single exact exact value is zero: $P(X = c) = \int_c^c f(x)\,dx = 0$. Consequently, strict and non-strict inequalities have identical probabilities:

$$P(a \le X \le b) = P(a < X \le b) = P(a \le X < b) = P(a < X < b)$$

2. Cumulative Distribution Function (CDF)

The cumulative distribution function (CDF) $F(x)$ represents the accumulated probability up to $x$:

$$F(x) = P(X \le x) = \int_{-\infty}^x f(t)\,dt$$
  • Fundamental Theorem of Calculus: The PDF is the derivative of the CDF: $$f(x) = F'(x) = \frac{d}{dx}F(x)$$
  • Interval probability via CDF: $P(a \le X \le b) = F(b) - F(a)$.
  • Boundary conditions: $\lim_{x \to -\infty} F(x) = 0$ and $\lim_{x \to \infty} F(x) = 1$.

3. Median, Quartiles, and Percentiles

Quantiles are determined by setting the CDF equal to the desired accumulated probability:

  • Median ($m$): The 50th percentile: $F(m) = 0.5 \iff \int_{-\infty}^m f(x)\,dx = 0.5$.
  • Lower Quartile ($Q_1$): The 25th percentile: $F(Q_1) = 0.25$.
  • Upper Quartile ($Q_3$): The 75th percentile: $F(Q_3) = 0.75$.
  • Interquartile Range (IQR): $\text{IQR} = Q_3 - Q_1$.

2. For conditional: use $P(A \mid B) = \frac{P(A \cap B)}{P(B)} = \frac{P(X \ge d)}{P(X \ge c)}$.		 Assuming $P(X \le c) \ne P(X < c)$ (for continuous RVs, point probability $P(X = c) = 0$). Failing to intersect events correctly in the numerator.

2. Integrate and evaluate from $t = a$ to $t = x$.
3. Formally specify all three regions: $0$ for $x < a$, $F(x)$ for $a \le x \le b$, and $1$ for $x > b$.		 Omitting the outer intervals $x < a \implies F(x) = 0$ and $x > b \implies F(x) = 1$. Using $x$ as both the dummy variable and the upper limit.
4. Quantiles: Median, Quartiles, IQR Determine the median $m$, lower quartile $Q_1$, upper quartile $Q_3$, or 90th percentile. 1. Set $F(m) = 0.5$ (or $\int_a^m f(t)\,dt = 0.5$).
2. Solve the algebraic or polynomial equation for $m$.
3. Verify that the root lies strictly within the domain $[a, b]$.		 Selecting an extraneous algebraic root outside $[a, b]$. Confusing median ($F(m) = 0.5$) with mean ($E(X) = \int x f(x)\,dx$).
5. Mode & Maximum Density via Calculus Find the mode of the distribution with PDF $f(x)$ on $[a, b]$. 1. Find $f'(x)$ and solve $f'(x) = 0$ for critical points.
2. Apply the second derivative test ($f''(x) < 0$) or first derivative sign test.
3. Check boundary endpoints $f(a)$ and $f(b)$ if the PDF is monotonic.		 Stating the maximum value of $f(x)$ rather than the $x$-value (the mode is the location $x$, not the height $f(x)$). Omitting the justification ($f'' < 0$).
6. Piecewise Defined / Triangular Distributions PDF given in two intervals: $f_1(x)$ on $[a, c]$ and $f_2(x)$ on $[c, b]$. 1. Split normalization: $\int_a^c f_1(x)\,dx + \int_c^b f_2(x)\,dx = 1$.
2. For CDF when $x > c$: $F(x) = F(c) + \int_c^x f_2(t)\,dt$.
3. Determine which interval contains the median before setting $F(m) = 0.5$.		 Forgetting the accumulated area $F(c)$ from the first interval when integrating in the second interval. Geometric checks (triangle area $=\frac{1}{2}bh$) catch algebraic errors.

4. Worked Exemplars (5 Authentic IB Exam Questions with Full Markschemes)

Worked Exemplar 1: Determining Normalization Constant & Interval Probability

A continuous random variable $X$ has probability density function defined by:

$$f(x) = \begin{cases} k x(2 - x) & \text{for } 0 \le x \le 2 \\ 0 & \text{otherwise} \end{cases}$$

(a) Show that $k = \frac{3}{4}$. [3 marks]
(b) Calculate $P(0.5 \le X \le 1.5)$. [3 marks]

Full Markscheme Solution:

(a) Normalization Condition:

For any valid probability density function, the total integral over its support must equal $1$:

$$\int_0^2 f(x)\,dx = 1 \implies \int_0^2 k(2x - x^2)\,dx = 1 \quad [M1]$$

Integrate term-by-term:

$$k \left[ x^2 - \frac{x^3}{3} \right]_0^2 = 1 \quad [A1]$$

Substitute the limits:

$$k \left[ \left(2^2 - \frac{2^3}{3}\right) - 0 \right] = 1 \implies k \left( 4 - \frac{8}{3} \right) = 1 \implies k \left(\frac{4}{3}\right) = 1$$ $$k = \frac{3}{4} \quad [AG]$$

(b) Interval Probability:

$$P(0.5 \le X \le 1.5) = \int_{0.5}^{1.5} \frac{3}{4}(2x - x^2)\,dx \quad [M1]$$ $$= \frac{3}{4}\left[ x^2 - \frac{x^3}{3} \right]_{0.5}^{1.5} \quad [A1]$$

Evaluating at upper limit $x = 1.5 = \frac{3}{2}$:

$$\left(\frac{3}{2}\right)^2 - \frac{(3/2)^3}{3} = \frac{9}{4} - \frac{27/8}{3} = \frac{9}{4} - \frac{9}{8} = \frac{9}{8}$$

Evaluating at lower limit $x = 0.5 = \frac{1}{2}$:

$$\left(\frac{1}{2}\right)^2 - \frac{(1/2)^3}{3} = \frac{1}{4} - \frac{1/8}{3} = \frac{1}{4} - \frac{1}{24} = \frac{5}{24}$$

Subtracting:

$$P(0.5 \le X \le 1.5) = \frac{3}{4} \left( \frac{9}{8} - \frac{5}{24} \right) = \frac{3}{4} \left( \frac{27 - 5}{24} \right) = \frac{3}{4} \left( \frac{22}{24} \right) = \frac{3}{4} \cdot \frac{11}{12} = \frac{11}{16} = 0.6875 \quad [A1]$$

Examiner Commentary: In "Show that" questions, the substitution of limits $\left(4 - \frac{8}{3}\right)$ must be shown explicitly before stating $k = \frac{3}{4}$ to earn the $[AG]$ mark. Note that because $f(x)$ is symmetric about $x = 1$, students could also compute $2 \int_{0.5}^1 f(x)\,dx$ for an equally valid alternative method.

Worked Exemplar 2: Piecewise Cumulative Distribution Function & Exact Median

For the continuous random variable $X$ with PDF $f(x) = \frac{3}{4}(2x - x^2)$ for $0 \le x \le 2$:
(a) Find the cumulative distribution function $F(x)$, defining it for all $x \in \mathbb{R}$. [4 marks]
(b) Determine the exact median of $X$. [3 marks]

Full Markscheme Solution:

(a) Deriving $F(x)$:

• For $x < 0$, no probability mass has accumulated: $F(x) = 0$ $[A1]$.
• For $0 \le x \le 2$, use dummy variable of integration $t$:

$$F(x) = \int_0^x f(t)\,dt = \int_0^x \frac{3}{4}(2t - t^2)\,dt \quad [M1]$$ $$= \frac{3}{4}\left[ t^2 - \frac{t^3}{3} \right]_0^x = \frac{3}{4}\left( x^2 - \frac{x^3}{3} \right) = \frac{3}{4}x^2 - \frac{1}{4}x^3 = \frac{x^2(3 - x)}{4} \quad [A1]$$

• For $x > 2$, all probability mass has accumulated: $F(x) = 1$ $[A1]$.

Complete piecewise definition:

$$F(x) = \begin{cases} 0 & x < 0 \\ \frac{3x^2 - x^3}{4} & 0 \le x \le 2 \\ 1 & x > 2 \end{cases}$$

(b) Finding the Median $m$:

By definition, the median satisfies $F(m) = 0.5$ $[M1]$:

$$\frac{3m^2 - m^3}{4} = \frac{1}{2} \implies 3m^2 - m^3 = 2 \implies m^3 - 3m^2 + 2 = 0 \quad [A1]$$

Test integer factors of $2$ ($\pm 1, \pm 2$):

$$1^3 - 3(1)^2 + 2 = 1 - 3 + 2 = 0 \implies (m - 1) \text{ is a factor.}$$

Polynomial division: $m^3 - 3m^2 + 2 = (m - 1)(m^2 - 2m - 2) = 0$.
Roots of the quadratic: $m = \frac{2 \pm \sqrt{4 - 4(1)(-2)}}{2} = 1 \pm \sqrt{3}$.
Since $1 + \sqrt{3} \approx 2.732 > 2$ and $1 - \sqrt{3} \approx -0.732 < 0$, both quadratic roots lie outside the support $[0, 2]$.
Therefore, the unique median is $m = 1$ $[A1]$.

Alternative Pathway: $f(x) = \frac{3}{4}x(2-x)$ is a downward parabola with line of symmetry at $x = \frac{0 + 2}{2} = 1$. Since $f(x)$ is continuous and perfectly symmetric about $x = 1$, the median and mean must both equal the axis of symmetry: $m = 1$ $[R1][A1]$.

Worked Exemplar 3: Conditional Probability with Continuous Distributions

The continuous random variable $T$ represents the waiting time (in hours) at a hospital clinic, with PDF:

$$f(t) = \begin{cases} 2e^{-2t} & t \ge 0 \\ 0 & t < 0 \end{cases}$$

(a) Find an expression for $P(T > k)$ where $k > 0$. [2 marks]
(b) A patient has already been waiting for $1$ hour. Find the probability that their total wait exceeds $3$ hours. [3 marks]
(c) Interpret this result in relation to the memoryless property. [1 mark]

Full Markscheme Solution:

(a) Survival / Exceedance Probability:

$$P(T > k) = \int_k^\infty 2e^{-2t}\,dt = \lim_{b \to \infty} \left[ -e^{-2t} \right]_k^b \quad [M1]$$ $$= \lim_{b \to \infty} (-e^{-2b}) - (-e^{-2k}) = 0 + e^{-2k} = e^{-2k} \quad [A1]$$

(b) Conditional Probability:

We require $P(T > 3 \mid T > 1)$:

$$P(T > 3 \mid T > 1) = \frac{P(T > 3 \cap T > 1)}{P(T > 1)} \quad [M1]$$

Since the event $\{T > 3\}$ is a subset of $\{T > 1\}$, their intersection is simply $\{T > 3\}$:

$$= \frac{P(T > 3)}{P(T > 1)} = \frac{e^{-2(3)}}{e^{-2(1)}} = \frac{e^{-6}}{e^{-2}} \quad [A1]$$ $$= e^{-6 - (-2)} = e^{-4} \approx 0.0183 \text{ (to 3 s.f.)} \quad [A1]$$

(c) Interpretation:

Notice that $P(T > 1 + 2 \mid T > 1) = e^{-2(2)} = P(T > 2)$. The exponential distribution is memoryless: the probability of waiting an additional $2$ hours is completely independent of how long the patient has already waited $[R1]$.

Worked Exemplar 4: Calculus Determination of Mode & Quartiles

A continuous random variable $X$ has probability density function:

$$f(x) = \begin{cases} 12x^2(1 - x) & 0 \le x \le 1 \\ 0 & \text{otherwise} \end{cases}$$

(a) Find the mode of $X$, fully justifying your answer. [3 marks]
(b) Determine the maximum value of the probability density function $f(x)$. [1 mark]
(c) Show that the lower quartile $Q_1$ satisfies the equation $4Q_1^3 - 3Q_1^4 = 0.25$, and hence find $Q_1$ to 3 significant figures. [3 marks]
(d) Calculate $P(X \ge 0.5 \mid X \le 0.8)$. [3 marks]

Full Markscheme Solution:

(a) Mode Determination:

The mode is the value of $x$ where $f(x)$ attains its global maximum. Expand $f(x) = 12x^2 - 12x^3$ and differentiate:

$$f'(x) = 24x - 36x^2 = 12x(2 - 3x) \quad [M1]$$

Setting $f'(x) = 0 \implies x = 0$ or $x = \frac{2}{3}$.
Second derivative test:

$$f''(x) = 24 - 72x$$ $$f''\left(\frac{2}{3}\right) = 24 - 72\left(\frac{2}{3}\right) = 24 - 48 = -24 < 0 \implies \text{local and global maximum} \quad [R1]$$

At the boundaries: $f(0) = 0$ and $f(1) = 0$.
Therefore, the mode is $x = \frac{2}{3}$ $[A1]$.

(b) Maximum Probability Density:

$$f_{\max} = f\left(\frac{2}{3}\right) = 12\left(\frac{2}{3}\right)^2\left(1 - \frac{2}{3}\right) = 12\left(\frac{4}{9}\right)\left(\frac{1}{3}\right) = \frac{48}{27} = \frac{16}{9} \approx 1.78 \quad [A1]$$

(c) Lower Quartile Equation & Value:

The CDF for $0 \le x \le 1$ is:

$$F(x) = \int_0^x 12(t^2 - t^3)\,dt = 12\left[ \frac{t^3}{3} - \frac{t^4}{4} \right]_0^x = 4x^3 - 3x^4 \quad [M1]$$

By definition of lower quartile, $F(Q_1) = 0.25$:

$$4Q_1^3 - 3Q_1^4 = 0.25 \quad [AG]$$

Using a GDC numerical polynomial solver on $3Q_1^4 - 4Q_1^3 + 0.25 = 0$ in the interval $[0, 1]$:

$$Q_1 \approx 0.456 \quad [A1]$$

(d) Conditional Probability:

$$P(X \ge 0.5 \mid X \le 0.8) = \frac{P(0.5 \le X \le 0.8)}{P(X \le 0.8)} = \frac{F(0.8) - F(0.5)}{F(0.8)} \quad [M1]$$ $$F(0.8) = 4(0.8)^3 - 3(0.8)^4 = 4(0.512) - 3(0.4096) = 2.048 - 1.2288 = 0.8192$$ $$F(0.5) = 4(0.5)^3 - 3(0.5)^4 = 4(0.125) - 3(0.0625) = 0.5 - 0.1875 = 0.3125$$ $$\text{Probability} = \frac{0.8192 - 0.3125}{0.8192} = \frac{0.5067}{0.8192} \approx 0.619 \text{ (or } \frac{5067}{8192}) \quad [A1]$$

Examiner Commentary: Candidates often confuse the mode (the value on the $x$-axis where density peaks, $x = \frac{2}{3}$) with the maximum density value ($f(2/3) = \frac{16}{9}$). Always state the $x$-value for the mode!

Worked Exemplar 5: Piecewise Linear / Triangular Distribution & Upper Quartile

A continuous random variable $X$ has a triangular probability density function defined by:

$$f(x) = \begin{cases} \frac{1}{4}x & 0 \le x \le 2 \\ 1 - \frac{1}{4}x & 2 < x \le 4 \\ 0 & \text{otherwise} \end{cases}$$

(a) Verify that $\int_0^4 f(x)\,dx = 1$. [2 marks]
(b) Derive the cumulative distribution function $F(x)$ for the branch $2 < x \le 4$. [3 marks]
(c) Find the exact value of the upper quartile $Q_3$. [3 marks]

Full Markscheme Solution:

(a) Verifying Total Probability:

Split the integral at the transition boundary $x = 2$:

$$\int_0^4 f(x)\,dx = \int_0^2 \frac{1}{4}x\,dx + \int_2^4 \left(1 - \frac{1}{4}x\right)\,dx \quad [M1]$$ $$= \left[ \frac{x^2}{8} \right]_0^2 + \left[ x - \frac{x^2}{8} \right]_2^4 = \left( \frac{4}{8} - 0 \right) + \left[ (4 - 2) - \left(2 - \frac{4}{8}\right) \right] = \frac{1}{2} + \left( 2 - 1.5 \right) = \frac{1}{2} + \frac{1}{2} = 1 \quad [A1]$$

(b) Cumulative Distribution Function for $2 < x \le 4$:

The accumulated probability up to $x$ equals the area accumulated up to $x = 2$ plus the integral from $2$ to $x$:

$$F(x) = F(2) + \int_2^x \left(1 - \frac{1}{4}t\right)\,dt \quad [M1]$$

Since $F(2) = \frac{1}{2}$:

$$F(x) = \frac{1}{2} + \left[ t - \frac{t^2}{8} \right]_2^x = \frac{1}{2} + \left( x - \frac{x^2}{8} \right) - \left( 2 - \frac{4}{8} \right) \quad [A1]$$ $$= \frac{1}{2} + x - \frac{x^2}{8} - \frac{3}{2} = x - \frac{x^2}{8} - 1 \quad [A1]$$

Check: When $x = 2$, $F(2) = 2 - \frac{4}{8} - 1 = \frac{1}{2}$. When $x = 4$, $F(4) = 4 - \frac{16}{8} - 1 = 1$. The CDF is continuous!

(c) Exact Upper Quartile $Q_3$:

Since $F(2) = 0.5$, the upper quartile ($F(Q_3) = 0.75$) must lie in the second branch $2 < x \le 4$:

$$Q_3 - \frac{Q_3^2}{8} - 1 = \frac{3}{4} \implies 8Q_3 - Q_3^2 - 8 = 6 \implies Q_3^2 - 8Q_3 + 14 = 0 \quad [M1]$$

Apply the quadratic formula:

$$Q_3 = \frac{8 \pm \sqrt{(-8)^2 - 4(1)(14)}}{2} = \frac{8 \pm \sqrt{64 - 56}}{2} = \frac{8 \pm \sqrt{8}}{2} = 4 \pm \sqrt{2} \quad [A1]$$

Since $Q_3$ must lie in $(2, 4]$, we reject the positive root $4 + \sqrt{2} \approx 5.414$:

$$Q_3 = 4 - \sqrt{2} \approx 2.586 \quad [A1]$$

Alternative Geometric Pathway: By symmetry, the area in the upper tail above $Q_3$ must equal $1 - 0.75 = 0.25$. This upper tail is a right triangle with base $(4 - Q_3)$ and height $f(Q_3) = 1 - \frac{1}{4}Q_3 = \frac{4 - Q_3}{4}$.
$\text{Area} = \frac{1}{2} \times \text{base} \times \text{height} = \frac{1}{2}(4 - Q_3)\left(\frac{4 - Q_3}{4}\right) = \frac{(4 - Q_3)^2}{8} = 0.25 \implies (4 - Q_3)^2 = 2 \implies 4 - Q_3 = \sqrt{2} \implies Q_3 = 4 - \sqrt{2}$ $[R1][A1]$.

Practice Exercises (10 Tiered Questions)

Try these 10 exam-style questions, from core skills to harder problems. Open each question to view its solution.

Exercise 1 (Foundational: Normalization Constant)

A random variable $X$ has PDF $f(x) = c x^2$ for $0 \le x \le 3$. Find the value of $c$.

Show Full Solution

$\int_0^3 c x^2\,dx = 1 \implies c\left[\frac{x^3}{3}\right]_0^3 = 1$. [M1]
$c\left(\frac{27}{3}\right) = 9c = 1 \implies c = \frac{1}{9}$. [A1]

Exercise 2 (Foundational: Probability from PDF)

Given $f(x) = \frac{1}{9}x^2$ for $0 \le x \le 3$, find $P(1 \le X \le 2)$.

Show Full Solution

$P(1 \le X \le 2) = \int_1^2 \frac{1}{9}x^2\,dx = \frac{1}{9}\left[\frac{x^3}{3}\right]_1^2 = \frac{1}{27}(8 - 1) = \frac{7}{27}$. [A1]

Exercise 3 (Foundational: Point Probability)

For a continuous random variable $X$, what is $P(X = 2)$? Explain why.

Show Full Solution

$P(X = 2) = 0$. [A1]
For any continuous random variable, probability is represented by area under the density curve. A single point has width zero, so $\int_2^2 f(x)\,dx = 0$. [R1]

Exercise 4 (Intermediate: CDF from Piecewise PDF)

Let $f(x) = \begin{cases} \frac{1}{2}x & 0 \le x \le 2 \\ 0 & \text{otherwise} \end{cases}$. Find the CDF $F(x)$ for $0 \le x \le 2$.

Show Full Solution

$F(x) = \int_0^x \frac{1}{2}t\,dt = \left[\frac{t^2}{4}\right]_0^x = \frac{x^2}{4}$. [M1][A1]
Complete piecewise: $F(x) = 0$ for $x < 0$, $\frac{x^2}{4}$ for $0 \le x \le 2$, and $1$ for $x > 2$.

Exercise 5 (Intermediate: Finding the Median)

Find the median of the distribution with CDF $F(x) = \frac{x^2}{4}$ for $0 \le x \le 2$.

Show Full Solution

Set $F(m) = 0.5$: [M1]
$\frac{m^2}{4} = 0.5 \implies m^2 = 2 \implies m = \sqrt{2} \approx 1.414$ (since $m \in [0, 2]$). [A1]

Exercise 6 (Intermediate: Finding PDF from Given CDF)

The CDF of $Y$ is $F(y) = 1 - \frac{16}{y^2}$ for $y \ge 4$. Find the PDF $f(y)$.

Show Full Solution

$f(y) = F'(y) = \frac{d}{dy}\left(1 - 16y^{-2}\right)$ [M1]
$= 0 - 16(-2y^{-3}) = \frac{32}{y^3}$ for $y \ge 4$ (and 0 otherwise). [A1]

Exercise 7 (Exam Standard: Interquartile Range)

For $F(x) = \frac{x^3}{8}$ for $0 \le x \le 2$, find the interquartile range (IQR).

Show Full Solution

Lower quartile $Q_1$: $F(Q_1) = 0.25 \implies \frac{Q_1^3}{8} = \frac{1}{4} \implies Q_1^3 = 2 \implies Q_1 = \sqrt[3]{2} \approx 1.260$. [M1]
Upper quartile $Q_3$: $F(Q_3) = 0.75 \implies \frac{Q_3^3}{8} = \frac{3}{4} \implies Q_3^3 = 6 \implies Q_3 = \sqrt[3]{6} \approx 1.817$. [M1]
$\text{IQR} = Q_3 - Q_1 = \sqrt[3]{6} - \sqrt[3]{2} \approx 1.817 - 1.260 = 0.557$. [A1]

Exercise 8 (Advanced: Piecewise PDF with Two Intervals)

A random variable $X$ has PDF $f(x) = \begin{cases} k x & 0 \le x \le 1 \\ k(2 - x) & 1 < x \le 2 \\ 0 & \text{otherwise} \end{cases}$.
(a) Find $k$.
(b) Find $P(0.5 \le X \le 1.5)$.

Show Full Solution

(a) Normalization: $\int_0^1 kx\,dx + \int_1^2 k(2-x)\,dx = 1$. [M1]
$k\left[\frac{x^2}{2}\right]_0^1 + k\left[2x - \frac{x^2}{2}\right]_1^2 = k(1/2) + k[(4 - 2) - (2 - 1/2)] = \frac{k}{2} + \frac{k}{2} = k = 1$. [A1]

(b) Probability:
By symmetry about $x = 1$, $P(0.5 \le X \le 1.5) = 2\int_{0.5}^1 x\,dx = 2\left[\frac{x^2}{2}\right]_{0.5}^1 = 1^2 - 0.5^2 = 1 - 0.25 = 0.75$. [A1]

Exercise 9 (Advanced: Infinite Domain Exponential Distribution)

The lifetime $T$ (in years) of an electronic component has PDF $f(t) = 0.5e^{-0.5t}$ for $t \ge 0$. Find the 90th percentile of component lifetime.

Show Full Solution

CDF $F(t) = \int_0^t 0.5e^{-0.5u}\,du = \left[-e^{-0.5u}\right]_0^t = 1 - e^{-0.5t}$. [M1]
90th percentile $p_{90}$: $F(p_{90}) = 0.90$. [M1]
$1 - e^{-0.5p_{90}} = 0.90 \implies e^{-0.5p_{90}} = 0.10$.
Take natural logs: $-0.5p_{90} = \ln(0.10) = -\ln(10) \implies p_{90} = 2\ln(10) \approx 4.61$ years. [A1]

Exercise 10 (Advanced: Mode of Continuous Distribution)

Find the mode of the distribution with PDF $f(x) = 12(x^2 - x^3)$ for $0 \le x \le 1$.

Show Full Solution

The mode is the value of $x$ where $f(x)$ attains its global maximum. [M1]
$f'(x) = 12(2x - 3x^2) = 12x(2 - 3x)$. [M1]
Setting $f'(x) = 0 \implies x = 0$ or $x = \frac{2}{3}$.
$f''(x) = 12(2 - 6x)$. At $x = 2/3$, $f''(2/3) = 12(2 - 4) = -24 < 0$ (local/global maximum).
Mode $= \frac{2}{3}$. [A1]

$$P(a \le X \le b) = \int_a^b f(x)\,dx$$ $$\int_{-\infty}^\infty f(x)\,dx = 1$$

Must-Memorize Principles (Not in Booklet)

1. Relationship between CDF and PDF

$$F(x) = \int_{-\infty}^x f(t)\,dt, \quad f(x) = F'(x) = \frac{d}{dx}F(x)$$

By the Fundamental Theorem of Calculus, the probability density function is the exact derivative of the cumulative distribution function.

2. Quantile & Percentile Equations

$$F(m) = 0.5 \text{ (Median)}, \quad F(Q_1) = 0.25 \text{ (Lower Quartile)}, \quad F(Q_3) = 0.75 \text{ (Upper Quartile)}$$ $$\text{Interquartile Range: } \text{IQR} = Q_3 - Q_1$$

3. Piecewise CDF Accumulation Rule

If $f(x)$ is defined piecewise with boundary at $x = c$, then for $x > c$:

$$F(x) = F(c) + \int_c^x f_2(t)\,dt \quad \text{where } F(c) = \int_a^c f_1(t)\,dt$$

4. Mode & Maximum Density

The mode is the location $x$ where $f(x)$ attains its global maximum. For interior stationary points: solve $f'(x) = 0$ with $f''(x) < 0$. If $f(x)$ is monotonic, the mode occurs at one of the boundary endpoints $x = a$ or $x = b$.

Examination Pitfalls & Examiner Tips

Dummy Variable in CDF Integral

Always write $F(x) = \int_a^x f(t)\,dt$ using a dummy variable $t$. Writing $\int f(x)\,dx$ with upper limit $x$ leads to circular notation, confusing integration constants, and penalty marks in Section B questions.

P(X = c) = 0 in Continuous Distributions

In continuous probability, $P(X \le c)$ is IDENTICAL to $P(X < c)$ because the area under a curve above a single point is zero ($\int_c^c f(x)\,dx = 0$). Do not treat continuous random variables like discrete distributions where $\le$ and $<$ differ.

Specifying the Complete Domain for CDF $F(x)$

When an exam question states "Find the cumulative distribution function $F(x)$", you MUST state the complete function piecewise across all $\mathbb{R}$: specifying $F(x) = 0$ for $x < a$ and $F(x) = 1$ for $x > b$. Omitting these boundary intervals routinely costs $1$ or $2$ marks.

Extraneous Roots when Solving for Quantiles

Polynomial equations like $m^3 - 3m^2 + 2 = 0$ or quadratic equations often produce multiple mathematical roots. Always reject roots that lie outside the valid domain $[a, b]$ of the continuous random variable.

Question 5 (Paper 1 Style · 6 marks)

The continuous random variable $X$ has PDF $f(x) = \begin{cases} \frac{3}{8}x^2 & 0 \le x \le 2 \\ 0 & \text{otherwise} \end{cases}$.
(a) Find the cumulative distribution function $F(x)$ for $0 \le x \le 2$. [2 marks]
(b) Determine the median of $X$. [2 marks]
(c) Find $P(X > 1 \mid X < 1.5)$. [2 marks]

Show Full Markscheme

(a) CDF: [2 marks]
$F(x) = \int_0^x \frac{3}{8}t^2\,dt = \frac{3}{8}\left[\frac{t^3}{3}\right]_0^x = \frac{x^3}{8}$ for $0 \le x \le 2$ [A1].

(b) Median: [2 marks]
$F(m) = 0.5 \implies \frac{m^3}{8} = \frac{1}{2} \implies m^3 = 4 \implies m = \sqrt[3]{4} \approx 1.587$ [A1].

(c) Conditional probability: [2 marks]
$P(X > 1 \mid X < 1.5) = \frac{P(1 < X < 1.5)}{P(X < 1.5)} = \frac{F(1.5) - F(1)}{F(1.5)}$ [M1].
$F(1.5) = \frac{1.5^3}{8} = \frac{3.375}{8} = 0.421875$.
$F(1) = \frac{1}{8} = 0.125$.
Probability $= \frac{0.421875 - 0.125}{0.421875} = \frac{0.296875}{0.421875} = \frac{19}{27} \approx 0.704$ [A1].

Question 6 (Paper 2 Style · 7 marks)

A random variable $X$ has PDF $f(x) = k\sin x$ for $0 \le x \le \pi$.
(a) Find the value of $k$. [2 marks]
(b) Find the CDF $F(x)$. [2 marks]
(c) Show that the median is $\frac{\pi}{2}$ and find the lower quartile $Q_1$. [3 marks]

Show Full Markscheme

(a) Constant $k$: [2 marks]
$\int_0^\pi k\sin x\,dx = 1 \implies k[-\cos x]_0^\pi = k(1 - (-1)) = 2k = 1 \implies k = \frac{1}{2}$ [A1].

(b) CDF $F(x)$: [2 marks]
$F(x) = \int_0^x \frac{1}{2}\sin t\,dt = \frac{1}{2}[-\cos t]_0^x = \frac{1}{2}(1 - \cos x) = \frac{1 - \cos x}{2}$ for $0 \le x \le \pi$ [A1].

(c) Median & Lower Quartile: [3 marks]
$F(m) = 0.5 \implies \frac{1 - \cos m}{2} = 0.5 \implies 1 - \cos m = 1 \implies \cos m = 0 \implies m = \frac{\pi}{2}$ [A1].
Lower quartile: $F(Q_1) = 0.25 \implies \frac{1 - \cos Q_1}{2} = 0.25 \implies 1 - \cos Q_1 = 0.5 \implies \cos Q_1 = 0.5$ [M1].
$Q_1 = \arccos(0.5) = \frac{\pi}{3}$ [A1].
