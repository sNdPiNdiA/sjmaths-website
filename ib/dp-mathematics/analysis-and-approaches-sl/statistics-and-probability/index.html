Learn the ideas

Key ideas and methods

Sampling, displays and summary statistics

  • A sample should represent the population relevant to the question. A convenience sample may be biased even when it is large; describe how data were selected before drawing conclusions.
  • Tables, histograms and cumulative-frequency displays organize data differently. In a histogram with unequal class widths, compare frequency density (frequency divided by class width), not bar height alone.
  • The mean uses every value and is sensitive to extremes; the median is resistant to extreme values. Measures of spread such as the interquartile range and standard deviation describe variability, so report a suitable centre and spread together.

Correlation, regression and probability

  • A correlation coefficient summarizes the strength and direction of a linear relationship. Correlation does not establish that one variable causes the other.
  • The regression line of y on x predicts y from x; the regression line of x on y predicts x from y. These are different fits and should be used for the variable being predicted.
  • For events A and B, P(A|B) = P(A ∩ B)/P(B), provided P(B) > 0. Independence means P(A ∩ B) = P(A)P(B), equivalently P(A|B) = P(A) when defined.
  • Tree diagrams, Venn diagrams and tables help keep conditional and combined probabilities organized. Label branches with conditional probabilities where appropriate.

Random variables and distributions

  • A discrete random variable X takes countable values with probabilities that sum to 1. Its expectation is E(X) = ΣxP(X = x), a long-run average rather than a promise about one trial.
  • A binomial model requires a fixed number n of independent trials, two outcomes per trial and a constant success probability p. Then P(X = k) = ⁿCₖpᵏ(1 − p)ⁿ⁻ᵏ.
  • A normal model is described by its mean μ and standard deviation σ. Standardize x using z = (x − μ)/σ, then use the normal distribution or the permitted calculator function to find probabilities.

Follow the reasoning

Worked examples

These original examples show common reasoning steps. They are not copied from IB examination papers.

Worked example 1

Find a binomial probability

Question. A component is defective with probability 0.1, independently for each component. In a sample of 5, find the probability that exactly one is defective.

  1. X is binomial with n = 5 and p = 0.1 because the trials are independent and p is constant.
  2. P(X = 1) = ⁵C₁(0.1)(0.9)⁴ = 5(0.1)(0.6561) = 0.32805.

Answer: The probability is 0.32805 (about 0.328).

Worked example 2

Standardize a normal value

Question. A normal variable has mean 70 and standard deviation 8. Find the z-value for x = 82.

  1. Use z = (x − μ)/σ.
  2. z = (82 − 70)/8 = 12/8 = 1.5.

Answer: The value 82 is 1.5 standard deviations above the mean.

Worked example 3

Use conditional probability

Question. In a group, 60% study French, 40% study Spanish, and 25% study both. Find P(French | Spanish).

  1. P(French | Spanish) = P(French ∩ Spanish)/P(Spanish).
  2. Substitute: 0.25/0.40 = 0.625.

Answer: P(French | Spanish) = 0.625.

Try it yourself

Practice with worked answers

  1. Question 1. A fair coin is tossed 6 times. Find the probability of exactly 4 heads.

    Show worked answer

    X ~ B(6, 0.5). P(X = 4) = ⁶C₄(0.5)⁶ = 15/64 ≈ 0.2344.

  2. Question 2. Exam scores are modelled by N(68, 10²). Find the z-value for a score of 83.

    Show worked answer

    z = (83 − 68)/10 = 1.5.

  3. Question 3. If P(A) = 0.3, P(B) = 0.4 and A and B are independent, find P(A ∩ B) and P(A | B).

    Show worked answer

    P(A ∩ B) = 0.3(0.4) = 0.12. Independence gives P(A | B) = P(A) = 0.3.

Avoid these slips

Common mistakes

  • Assuming correlation proves a causal relationship.
  • Using the regression line in the wrong direction for the variable being predicted.
  • Confusing P(A | B) with P(B | A).
  • Applying a binomial model when trials are dependent or the probability changes.
  • Using σ rather than σ² in a calculator field that asks for variance.

Before you move on

Revision checklist

  • Can I explain whether a sample is likely to represent its population?
  • Can I choose an appropriate centre and spread and interpret them in context?
  • Can I distinguish correlation, regression and causation?
  • Can I identify when a binomial or normal model is appropriate and interpret calculator output?
