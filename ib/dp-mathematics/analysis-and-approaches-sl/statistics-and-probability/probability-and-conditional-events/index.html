Probability and Conditional Events

Probability diagrams organize combined events. Conditional probability changes the reference group, while independence describes when learning one event does not change another’s probability.

Learn the ideas

Key ideas and methods

  • For events A and B, P(A|B)=P(A∩B)/P(B), provided P(B)>0.
  • Independence means P(A∩B)=P(A)P(B), equivalently P(A|B)=P(A) when defined.
  • Use a tree, Venn diagram or table to show the event structure. Label conditional branch probabilities after the preceding event has occurred.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Find a conditional probability

Question. P(French)=0.6, P(Spanish)=0.4 and P(both)=0.25. Find P(French|Spanish).

  1. Use P(French|Spanish)=P(both)/P(Spanish).
  2. Substitute 0.25/0.4=0.625.

Answer: 0.625.

Try it yourself

Practice with worked answers

  1. If P(A)=0.3, P(B)=0.4 and A,B are independent, find P(A∩B).

    Show worked answer

    P(A∩B)=0.3×0.4=0.12.

  2. If P(A∩B)=0.18 and P(B)=0.6, find P(A|B).

    Show worked answer

    P(A|B)=0.18/0.6=0.3.

Avoid these slips

Common mistakes

  • Reversing P(A|B) and P(B|A).
  • Assuming events are independent because they are different events.
  • Adding overlapping event probabilities without subtracting the intersection.
