Learn the ideas

Key ideas and methods

Standard form and sensible precision

  • Write a non-zero number as a × 10ⁿ, where 1 ≤ |a| < 10 and n is an integer. Normalize the leading number after multiplying or dividing so it returns to the required range.
  • When a result describes a measurement or estimate, keep precision consistent with the information given. A calculator display does not by itself determine the appropriate number of significant figures.

Arithmetic and geometric sequences

  • An arithmetic sequence has a constant difference d: uₙ = u₁ + (n − 1)d. Its first n terms sum to Sₙ = n/2[2u₁ + (n − 1)d].
  • A geometric sequence has a constant ratio r: uₙ = u₁rⁿ⁻¹. For r ≠ 1, Sₙ = u₁(1 − rⁿ)/(1 − r). The order of terms matters: identify u₁, d or r before substituting.
  • A repeated percentage change is geometric. If an amount P grows by rate i each period, its value after n periods is P(1 + i)ⁿ. Depreciation by rate i uses P(1 − i)ⁿ.

Exponents and logarithms

  • For positive bases, use aᵐaⁿ = aᵐ⁺ⁿ, aᵐ/aⁿ = aᵐ⁻ⁿ, (aᵐ)ⁿ = aᵐⁿ and a⁻ⁿ = 1/aⁿ. Rational exponents give roots, for example a¹ᐟ² = √a when the real square root is defined.
  • A logarithm answers an exponential question: logₐx = y means aʸ = x, with a > 0, a ≠ 1 and x > 0. The product, quotient and power laws are logₐ(xy) = logₐx + logₐy, logₐ(x/y) = logₐx − logₐy and logₐ(xᵏ) = k logₐx.
  • Check the domain before accepting a logarithmic solution. The argument of each real logarithm must be positive.

Proof, infinite sums and the binomial theorem

  • A simple proof uses a valid definition or known result to establish a statement for every permitted value. State the domain and show the logical step; several confirming examples do not prove a general claim.
  • An infinite geometric series converges only when |r| < 1. Its sum is S∞ = u₁/(1 − r). If |r| ≥ 1, this formula does not give a finite sum.
  • For a natural number n, (a + b)ⁿ = Σᵣ₌₀ⁿ (ⁿCᵣ)aⁿ⁻ʳbʳ. Each coefficient comes from the binomial coefficient, and the exponents in every term add to n.

Follow the reasoning

Worked examples

These original examples show common reasoning steps. They are not copied from IB examination papers.

Worked example 1

Find a term and a partial sum

Question. An arithmetic sequence begins 7, 11, 15, … Find u₁₂ and the sum of the first 12 terms.

  1. The first term is u₁ = 7 and the common difference is d = 4.
  2. u₁₂ = 7 + 11(4) = 51.
  3. S₁₂ = 12/2[2(7) + 11(4)] = 6(58) = 348.

Answer: u₁₂ = 51 and S₁₂ = 348.

Worked example 2

Model compound growth

Question. ₹5,000 is invested at 4% compound interest per year. Find its value after 3 years, to the nearest rupee.

  1. The growth factor per year is 1 + 0.04 = 1.04.
  2. A₃ = 5000(1.04)³ = 5,624.32.
  3. Round only at the end because the question asks for the nearest rupee.

Answer: The value is ₹5,624.

Worked example 3

Solve an exponential equation

Question. Solve 3²ˣ⁻¹ = 27.

  1. Write 27 as 3³.
  2. The bases are equal and positive, so 2x − 1 = 3.
  3. Therefore 2x = 4 and x = 2.

Answer: x = 2.

Try it yourself

Practice with worked answers

  1. Question 1. An arithmetic sequence has u₁ = 9 and d = 5. Find u₂₀ and S₂₀.

    Show worked answer

    u₂₀ = 9 + 19(5) = 104. S₂₀ = 20/2[2(9) + 19(5)] = 10(113) = 1,130.

  2. Question 2. Find the sum to infinity of 12 + 6 + 3 + … .

    Show worked answer

    Here u₁ = 12 and r = 1/2. Since |r| < 1, S∞ = 12/(1 − 1/2) = 24.

  3. Question 3. Expand (x + 2)³.

    Show worked answer

    Using the binomial coefficients 1, 3, 3, 1 gives x³ + 6x² + 12x + 8.

Avoid these slips

Common mistakes

  • Using n rather than n − 1 in the nth-term formula.
  • Applying the infinite-sum formula without checking |r| < 1.
  • Treating log(a + b) as log a + log b; the product law applies to log(ab), not a sum inside the logarithm.
  • Rounding intermediate values in a financial model and accumulating avoidable error.

Before you move on

Revision checklist

  • Can I identify whether a sequence is arithmetic or geometric and justify the choice?
  • Can I select the nth-term or sum formula that matches the question?
  • Can I solve exponential and logarithmic equations while checking restrictions?
  • Can I explain why an infinite geometric series converges before finding its sum?
