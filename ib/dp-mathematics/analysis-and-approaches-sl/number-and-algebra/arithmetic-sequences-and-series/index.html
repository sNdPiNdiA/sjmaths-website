  1. 1.2Arithmetic sequences and series

Learn the ideas

Key ideas and methods

  • The common difference is d = uₙ₊₁ − uₙ. The nth term is uₙ = u₁ + (n − 1)d.
  • The first n terms sum to Sₙ = n/2[2u₁ + (n − 1)d], or n(u₁ + uₙ)/2 when the last term is known.
  • Check whether the question asks for a term, a number of terms, or a sum; those are different quantities.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Find a term and a partial sum

Question. An arithmetic sequence starts 4, 9, 14, … Find u₁₅ and S₁₅.

  1. u₁ = 4 and d = 5.
  2. u₁₅ = 4 + 14(5) = 74.
  3. S₁₅ = 15/2[2(4) + 14(5)] = 585.

Answer: u₁₅ = 74 and S₁₅ = 585.

Try it yourself

Practice with worked answers

  1. For 12, 8, 4, … find u₂₀.

    Show worked answer

    Here d = −4. u₂₀ = 12 + 19(−4) = −64.

  2. An arithmetic series has 18 terms, first term 3 and last term 54. Find its sum.

    Show worked answer

    S₁₈ = 18(3 + 54)/2 = 513.

Avoid these slips

Common mistakes

  • Using n rather than n − 1 in the nth-term formula.
  • Using the nth-term formula to find a sum.
  • Dropping a negative common difference when a sequence decreases.
