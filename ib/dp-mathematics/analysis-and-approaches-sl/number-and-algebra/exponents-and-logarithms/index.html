Learn the ideas

Key ideas and methods

  • For a non-zero base, aᵐaⁿ = aᵐ⁺ⁿ, aᵐ/aⁿ = aᵐ⁻ⁿ, and (aᵐ)ⁿ = aᵐⁿ. A negative exponent means a⁻ⁿ = 1/aⁿ.
  • For positive a, a¹/ⁿ is an nth root when defined. A logarithm is the inverse operation: logₐx = y exactly when aʸ = x.
  • Use logₐ(xy) = logₐx + logₐy and logₐ(xʳ) = r logₐx. For real logarithms require a > 0, a ≠ 1 and each argument x > 0.

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Solve an equation with logarithms

Question. Solve log₂(x − 1) + log₂(x − 3) = 3.

  1. The domain requires x > 3.
  2. Combine logs: log₂[(x − 1)(x − 3)] = 3, so (x − 1)(x − 3) = 8.
  3. Solving gives x² − 4x − 5 = 0, so x = 5 or −1. Only x = 5 satisfies the domain.

Answer: x = 5.

Try it yourself

Practice with worked answers

  1. Simplify (x⁵x⁻²)/x for x ≠ 0.

    Show worked answer

    Add and subtract exponents: x⁵⁻²⁻¹ = x².

  2. Solve 5ˣ = 17, giving an exact logarithmic expression.

    Show worked answer

    Take logarithms: x = log₅17 = ln(17)/ln(5). The approximate value is about 1.760.

Avoid these slips

Common mistakes

  • Using log(a + b) = log a + log b; there is no such general addition law.
  • Keeping a logarithmic solution that makes its argument zero or negative.
  • Applying rational exponent rules without checking whether the real root exists.
