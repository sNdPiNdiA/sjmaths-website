Geometric Sequences and Infinite Sums

A geometric sequence changes by a constant multiplier. An infinite geometric sum has a finite value only when its terms shrink quickly enough.

Learn the ideas

Key ideas and methods

  • The common ratio is r = uₙ₊₁/uₙ. The nth term is uₙ = u₁rⁿ⁻¹.
  • For r ≠ 1, Sₙ = u₁(1 − rⁿ)/(1 − r). Equivalent forms are valid when numerator and denominator signs are changed together.
  • The infinite sum S∞ = u₁/(1 − r) applies only if |r| < 1. State or check this condition before using the formula.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Find a convergent infinite sum

Question. Find the sum to infinity of 81 + 27 + 9 + … .

  1. u₁ = 81 and r = 27/81 = 1/3.
  2. Since |1/3| < 1, the series converges.
  3. S∞ = 81/(1 − 1/3) = 81 × 3/2 = 243/2.

Answer: S∞ = 243/2.

Try it yourself

Practice with worked answers

  1. For a geometric sequence with u₁ = 5 and r = 2, find u₆.

    Show worked answer

    u₆ = 5 × 2⁵ = 160.

  2. Does 7 + 3.5 + 1.75 + … converge, and what is its sum?

    Show worked answer

    r = 1/2, so |r| < 1. S∞ = 7/(1 − 1/2) = 14.

Avoid these slips

Common mistakes

  • Using the arithmetic formula when the ratio, not the difference, is constant.
  • Applying S∞ when |r| ≥ 1.
  • Using the first term as u₀ in a formula that defines the first term as u₁.
