Limits and First Derivatives

Learn the ideas

Key ideas and methods

  • The derivative f′(a) is the limit of [f(a+h)−f(a)]/h as h approaches 0, when that limit exists.
  • For f(x)=axⁿ, f′(x)=anxⁿ⁻¹. Apply this term by term to a polynomial.
  • A derivative’s units are output units divided by input units; interpret its value as an instantaneous rate when variables have context.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Differentiate a polynomial

Question. Differentiate f(x)=3x⁴−2x²+5 and find f′(1).

  1. Apply the power rule to each non-constant term: f′(x)=12x³−4x.
  2. Substitute x=1: f′(1)=12−4.

Answer: f′(x)=12x³−4x and f′(1)=8.

Try it yourself

Practice with worked answers

    15x²−7.

  2. Find the gradient of y=x² at x=3.

    Show worked answer

    dy/dx=2x, so the gradient is 6.

Avoid these slips

Common mistakes

  • Reducing the exponent but forgetting to multiply by the original exponent.
  • Differentiating a constant as if it had a variable factor.
  • Confusing average gradient with instantaneous gradient.
