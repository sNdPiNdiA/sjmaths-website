Increasing, Decreasing and Stationary Points

The first derivative describes whether a function rises or falls; the second derivative describes how the gradient changes. Together they help classify critical points.

Learn the ideas

Key ideas and methods

  • Where f′(x)>0, f is increasing; where f′(x)<0, it is decreasing. Solve f′(x)=0 to find stationary candidates.
  • At a stationary point, f″(x)<0 indicates a local maximum and f″(x)>0 a local minimum. If f″=0, use sign changes or other evidence.
  • An inflection point requires a change in concavity. For optimization, define the objective, use constraints to reduce variables, find candidates and check endpoints/domain.

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Classify stationary points

Question. For f(x)=x³−6x²+9x, find and classify stationary points.

  1. f′(x)=3x²−12x+9=3(x−1)(x−3), so x=1 or 3.
  2. f(1)=4, f(3)=0. Also f″(x)=6x−12.
  3. f″(1)=−6 gives a local maximum; f″(3)=6 gives a local minimum.

Answer: Local maximum (1,4); local minimum (3,0).

Try it yourself

Practice with worked answers

  1. For f(x)=x²−4x, find the stationary point and classify it.

    Show worked answer

    f′=2x−4=0 at x=2; f(2)=−4 and f″=2>0, so (2,−4) is a minimum.

  2. If f′ is negative on (0,2) and positive on (2,5), what happens at x=2?

    Show worked answer

    The function changes from decreasing to increasing, so x=2 is a local minimum if f is defined and continuous there.

Avoid these slips

Common mistakes

  • Calling every stationary point a maximum or minimum.
  • Using f″=0 alone to claim an inflection point.
  • Ignoring boundary values in an optimization problem on a closed interval.
