  1. 3.8Solving trigonometric equations graphically and analytically

Learn the ideas

Key ideas and methods

  • Isolate the trigonometric function and identify its reference angle.
  • Use quadrant signs and the function’s period to generate all candidates, then retain only values in the requested interval.
  • A graph or technology can give approximate roots. State exact values when the question and angle allow them.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Solve a cosine equation on one revolution

Question. Solve 2cos x=1 for 0≤x<2π.

  1. Divide by 2: cos x=1/2.
  2. The reference angle is π/3; cosine is positive in quadrants I and IV.
  3. List the values in the half-open interval.

Answer: x=π/3 or x=5π/3.

Try it yourself

Practice with worked answers

  1. Solve sin x=−1/2 for 0≤x<2π.

    Show worked answer

    The reference angle is π/6; sine is negative in quadrants III and IV, so x=7π/6 or 11π/6.

  2. Solve tan x=1 for 0≤x<π.

    Show worked answer

    tan x=1 at reference angle π/4, and tangent’s period is π, so x=π/4.

Avoid these slips

Common mistakes

  • Giving only one root in an interval containing multiple roots.
  • Including an excluded endpoint or missing a permitted endpoint.
  • Using degrees for an interval stated in radians.
