Function Graphs, Features and Intersections

A graph displays how a function behaves. Intercepts, turning points, symmetry and asymptotes can help answer questions and check algebraic solutions.

Learn the ideas

Key ideas and methods

  • Label axes and important coordinates. A sketch should show the features needed to interpret the function, not just a vague curve.
  • Roots are x-intercepts; a y-intercept is f(0). A maximum or minimum is a turning value on the stated domain.
  • An intersection of f and g solves f(x)=g(x). Graphs give useful estimates; algebra can give exact values when the equations allow it.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Read features and solve an intersection

Question. For f(x)=x²−4x+1, find its vertex and roots, then solve f(x)=1.

  1. Complete the square: f(x)=(x−2)²−3, so the vertex is (2,−3).
  2. Set f(x)=0: (x−2)²=3, so x=2±√3.
  3. For f(x)=1, (x−2)²−3=1, so (x−2)²=4.

Answer: Vertex (2,−3); roots 2±√3; intersection solutions x=0 or x=4.

Try it yourself

Practice with worked answers

  1. For y=−(x−3)²+2, state the vertex and maximum value.

    Show worked answer

    The vertex is (3,2). Since the coefficient is negative, the maximum value is 2.

  2. Solve graphically/analytically the intersection x²=2x+3.

    Show worked answer

    x²−2x−3=0=(x−3)(x+1), so x=−1 or 3; these are the intersection x-coordinates.

Avoid these slips

Common mistakes

  • Leaving axes, units or key points unlabeled.
  • Giving only one intersection when the graphs cross twice.
