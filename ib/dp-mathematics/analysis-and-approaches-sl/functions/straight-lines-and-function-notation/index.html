Straight Lines and Function Notation

A linear rule describes a constant rate of change. Function notation makes the input-output relationship explicit and helps track domain restrictions.

Learn the ideas

Key ideas and methods

  • The gradient through (x₁,y₁) and (x₂,y₂) is (y₂ − y₁)/(x₂ − x₁), provided x₂ ≠ x₁.
  • A line through (a,b) with gradient m satisfies y − b = m(x − a).
  • A function assigns one output to every input in its domain. The range contains the outputs that actually occur; it may be smaller than the codomain.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Find a line through two points

Question. Find the equation of the line through (2, −1) and (6, 7).

  1. m = (7 − (−1))/(6 − 2) = 2.
  2. Use point-slope form with (2, −1): y + 1 = 2(x − 2).
  3. Rearrange to slope-intercept form.

Answer: y = 2x − 5.

Try it yourself

Practice with worked answers

  1. Evaluate f(−2) for f(x)=x²−3x.

    Show worked answer

    f(−2)=4+6=10.

  2. Find the gradient of the line through (−3,2) and (1,−6).

    Show worked answer

    m=(−6−2)/(1−(−3))=−8/4=−2.

Avoid these slips

Common mistakes

  • Reversing the order of subtraction in only one part of the gradient formula.
  • Treating an input outside the domain as a valid function value.
