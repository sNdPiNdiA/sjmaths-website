Composite, Identity and Inverse Functions

Composition applies one function after another. An inverse reverses a function’s mapping on a domain where each output comes from only one input.

  1. 2.5Composite, identity and inverse functions

Learn the ideas

Key ideas and methods

  • (f∘g)(x)=f(g(x)); apply g first, then f. In general f∘g and g∘f differ.
  • The identity function maps x to x. If f has an inverse, f⁻¹(f(x))=x for inputs in the suitable domain.
  • Find an inverse by setting y=f(x), swapping x and y, and solving for y. A restricted domain may be needed to make a non-one-to-one function invertible.

Follow the reasoning

Worked example

This original example shows the method step by step; it is not copied from an IB examination paper.

Worked example 1

Compose and invert linear functions

Question. Let f(x)=2x+3 and g(x)=x². Find (f∘g)(x) and f⁻¹(x).

  1. (f∘g)(x)=f(g(x))=f(x²).
  2. Substitute x² into f: 2x²+3.
  3. For the inverse, y=2x+3; swap x and y, then solve x=2y+3 for y.

Answer: (f∘g)(x)=2x²+3 and f⁻¹(x)=(x−3)/2.

Try it yourself

Practice with worked answers

  1. For f(x)=x−4 and g(x)=3x, find (g∘f)(x).

    Show worked answer

    g(f(x))=3(x−4)=3x−12.

  2. Find the inverse of h(x)=5x−7.

    Show worked answer

    Set y=5x−7, swap, and solve x=5y−7: h⁻¹(x)=(x+7)/5.

Avoid these slips

Common mistakes

  • Reversing the order in a composite function.
  • Confusing f⁻¹(x) with 1/f(x).
  • Finding an inverse without checking one-to-one behavior or the domain.
