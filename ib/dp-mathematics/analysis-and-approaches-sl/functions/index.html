Learn the ideas

Key ideas and methods

Inputs, outputs and domain

  • A function assigns exactly one output to each input in its domain. Use function notation such as f(3) to mean the output when the input is 3.
  • The domain is the set of allowed inputs; the range is the set of resulting outputs. For rational functions, exclude inputs that make a denominator zero. For real logarithmic functions, require a positive argument.
  • A straight line with gradient m through (x₁, y₁) can be written y − y₁ = m(x − x₁). A graph communicates solutions and key features, but an algebraic method can give exact values.

Compositions, identity and inverse functions

  • A composite function applies one function after another: (f ∘ g)(x) = f(g(x)). The order matters; f(g(x)) is not generally equal to g(f(x)).
  • The identity function maps x to x. An inverse reverses the mapping: f⁻¹(f(x)) = x on the appropriate domain. To find an inverse, write y = f(x), swap x and y, then solve for y.
  • A function must be one-to-one on the chosen domain to have an inverse that is itself a function. Graphically, it must pass the horizontal-line test.

Quadratics and other graph families

  • A quadratic can be read in expanded form ax² + bx + c, factorized form a(x − p)(x − q), or vertex form a(x − h)² + k. These forms reveal different features of the same function.
  • The discriminant Δ = b² − 4ac determines the number of distinct real roots: positive gives two, zero gives one repeated root, and negative gives no real roots.
  • Reciprocal and rational functions can have excluded inputs and asymptotes. Exponential and logarithmic functions are inverses; their graphs reflect across y = x when domains and ranges are matched.
  • A transformation such as y = f(x − h) + k shifts the graph h units horizontally and k units vertically. A negative multiplier outside the function reflects it in the x-axis; a negative inside reflects it in the y-axis.

Solving graphically and analytically

  • An intersection of y = f(x) and y = g(x) solves f(x) = g(x). Read an approximate solution from a graph when appropriate; use algebra when an exact solution is required and available.
  • Label axes and important points clearly when drawing or sketching. A sketch should show the features needed to communicate the function, such as intercepts, turning points and asymptotes.

Follow the reasoning

Worked examples

These original examples show common reasoning steps. They are not copied from IB examination papers.

Worked example 1

Read a quadratic in vertex form

Question. For f(x) = (x − 2)² − 3, state the vertex, axis of symmetry and roots.

  1. The form (x − h)² + k gives vertex (h, k), so the vertex is (2, −3).
  2. The axis of symmetry is x = 2.
  3. Set f(x) = 0: (x − 2)² = 3, so x = 2 ± √3.

Answer: Vertex (2, −3), axis x = 2, roots x = 2 ± √3.

Worked example 2

Find an inverse

Question. Find the inverse of f(x) = 3x − 5.

  1. Write y = 3x − 5.
  2. Swap x and y: x = 3y − 5.
  3. Solve for y: y = (x + 5)/3.

Answer: f⁻¹(x) = (x + 5)/3.

Worked example 3

Solve a quadratic inequality

Question. Solve x² − 4 ≤ 0.

  1. Factor: (x − 2)(x + 2) ≤ 0. The critical values are −2 and 2.
  2. The parabola opens upward, so it is at or below the x-axis between the roots, including both roots.

Answer: −2 ≤ x ≤ 2.

Try it yourself

Practice with worked answers

  1. Question 1. Find the gradient of the line through (−1, 4) and (3, 12), then write its equation.

    Show worked answer

    m = (12 − 4)/(3 − (−1)) = 2. Using (−1, 4), y − 4 = 2(x + 1), so y = 2x + 6.

  2. Question 2. For g(x) = −(x + 1)² + 4, give the vertex and maximum value.

    Show worked answer

    The vertex form gives vertex (−1, 4). The negative coefficient makes it open downward, so the maximum value is 4.

  3. Question 3. Solve x² − 5x + 6 = 0 and state the discriminant.

    Show worked answer

    Factor to (x − 2)(x − 3) = 0, giving x = 2 or 3. The discriminant is 25 − 24 = 1, so there are two distinct real roots.

Avoid these slips

Common mistakes

  • Confusing f⁻¹(x), the inverse function, with 1/f(x), the reciprocal.
  • Changing the sign incorrectly in a horizontal transformation: f(x − h) shifts right by h.
  • Giving a root without checking whether it satisfies a domain restriction.
  • Using a graph estimate where the question asks for an exact answer, or giving too many digits for an approximate answer.

Before you move on

Revision checklist

  • Can I move between a function rule, a table and a labelled graph?
  • Can I identify domain, range, intercepts, turning points and asymptotes where relevant?
  • Can I compose functions and find an inverse on a stated domain?
  • Can I explain whether an equation has zero, one or two real roots using the discriminant?
