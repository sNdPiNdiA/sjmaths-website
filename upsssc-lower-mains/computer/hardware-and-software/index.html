Introduction to Computer Hardware and Software

Hardware Overview

Hardware refers to the physical components of a computer system that can be touched and seen. It includes input devices, output devices, storage, and internal circuitry.

हार्डवेयर का परिचय

हार्डवेयर कंप्यूटर सिस्टम के उन भौतिक घटकों को संदर्भित करता है जिन्हें छुआ और देखा जा सकता है। इसमें इनपुट डिवाइस, आउटपुट डिवाइस, स्टोरेज और आंतरिक सर्किट शामिल हैं।

Classification of Software

Software Types

Software is a set of programs that instructs the hardware. It is broadly classified into System Software (OS, Drivers), Application Software (MS Office, Web Browsers), and Utility Software.

सॉफ्टवेयर के प्रकार

सॉफ्टवेयर प्रोग्रामों का एक समूह है जो हार्डवेयर को निर्देश देता है। इसे व्यापक रूप से सिस्टम सॉफ्टवेयर (OS, ड्राइवर्स), एप्लिकेशन सॉफ्टवेयर (MS ऑफिस, वेब ब्राउज़र) और यूटिलिटी सॉफ्टवेयर में वर्गीकृत किया गया है।

Key Hardware Components

CPU (Central Processing Unit) is the 'Brain' of the computer, consisting of ALU, CU, and Registers. RAM is volatile, while ROM is non-volatile.

CPU कंप्यूटर का 'मस्तिष्क' है, जिसमें ALU, CU और रजिस्टर्स होते हैं। RAM अस्थिर (volatile) होती है, जबकि ROM स्थिर (non-volatile) होती है।

BIOS and Firmware

BIOS/Firmware

BIOS (Basic Input/Output System) is a type of firmware used to perform hardware initialization during the booting process. It is stored on a ROM chip.

BIOS/फर्मवेयर

BIOS एक प्रकार का फर्मवेयर है जिसका उपयोग बूटिंग प्रक्रिया के दौरान हार्डवेयर इनिशियलाइजेशन करने के लिए किया जाता है। यह ROM चिप पर संग्रहीत होता है।
