1. Evolution and Core Concept of Internet1. इंटरनेट का विकास और मूल अवधारणा

The Internet is a global network of interconnected computers communicating via standardized protocol suites. It originated from ARPANET (Advanced Research Projects Agency Network), funded by the US Department of Defense in 1969. The transition to TCP/IP in 1983 marked the official birth of the modern Internet.इंटरनेट मानकीकृत प्रोटोकॉल सूट के माध्यम से संचार करने वाले जुड़े हुए कंप्यूटरों का एक वैश्विक नेटवर्क है। इसकी उत्पत्ति 1969 में अमेरिकी रक्षा विभाग द्वारा वित्त पोषित ARPANET (एडवांस्ड रिसर्च प्रोजेक्ट्स एजेंसी नेटवर्क) से हुई थी। 1983 में TCP/IP में संक्रमण ने आधुनिक इंटरनेट के आधिकारिक जन्म को चिह्नित किया।

Milestones: 1969: ARPANET launched | 1983: TCP/IP adopted | 1989: Tim Berners-Lee invents World Wide Web (WWW) | 1995: Internet commercialized in India (Videsh Sanchar Nigam Limited - VSNL on 15th August).महत्वपूर्ण मील के पत्थर: 1969: ARPANET लॉन्च | 1983: TCP/IP अपनाया गया | 1989: टिम बर्नर्स-ली ने वर्ल्ड वाइड वेब (WWW) का आविष्कार किया | 1995: भारत में इंटरनेट का व्यवसायीकरण (15 अगस्त को विदेश संचार निगम लिमिटेड - VSNL द्वारा)।

3. IP Addressing: IPv4 vs IPv63. आईपी एड्रेसिंग: IPv4 बनाम IPv6

An IP address is a unique numerical identifier assigned to every device participating in a computer network.आईपी एड्रेस कंप्यूटर नेटवर्क में भाग लेने वाले प्रत्येक डिवाइस को दिया जाने वाला एक अद्वितीय संख्यात्मक पहचानकर्ता है।

IPv4 (Internet Protocol Version 4): 32-bit address, represented in dotted-decimal format (e.g., 192.168.1.1). Total addresses: ~4.3 billion. Divided into 5 classes: Class A (1-126), Class B (128-191), Class C (192-223), Class D (224-239 for Multicast), Class E (240-254 for Experimental).IPv4 (इंटरनेट प्रोटोकॉल संस्करण 4): 32-बिट एड्रेस, डॉटेड-डेसिमल प्रारूप में प्रदर्शित (जैसे, 192.168.1.1)। कुल पते: ~4.3 बिलियन। 5 वर्गों में विभाजित: क्लास A (1-126), क्लास B (128-191), क्लास C (192-223), क्लास D (224-239 मल्टीकास्ट के लिए), क्लास E (240-254 प्रयोगात्मक के लिए)।

IPv6 (Internet Protocol Version 6): 128-bit address, represented in hexadecimal format separated by colons (e.g., 2001:db8::ff00:42:8329). Developed to solve IPv4 address exhaustion.IPv6 (इंटरनेट प्रोटोकॉल संस्करण 6): 128-बिट एड्रेस, कोलन द्वारा अलग किए गए हेक्साडेसिमल प्रारूप में प्रदर्शित (जैसे, 2001:db8::ff00:42:8329)। IPv4 पते की कमी को हल करने के लिए विकसित किया गया।

4. Domain Name System (DNS) & URL Structure4. डोमेन नेम सिस्टम (DNS) और URL संरचना

DNS: Often referred to as the phonebook of the Internet. It translates human-readable domain names (like www.upsssc.gov.in) into machine-readable IP addresses (like 164.100.181.141).DNS: इसे अक्सर इंटरनेट की फोनबुक कहा जाता है। यह मानव-पठनीय डोमेन नामों (जैसे www.upsssc.gov.in) को मशीन-पठनीय आईपी पते (जैसे 164.100.181.141) में अनुवादित करता है।

5. Key Web Technologies & E-mail Protocols5. प्रमुख वेब प्रौद्योगिकियां और ई-मेल प्रोटोकॉल

Understanding how email transmission and web rendering work is critical for UPSSSC exams.यूपीएसएसएससी परीक्षाओं के लिए ईमेल ट्रांसमिशन और वेब रेंडरिंग कैसे काम करते हैं, यह समझना महत्वपूर्ण है।

  • SMTP (Simple Mail Transfer Protocol): Used exclusively for sending emails from client to server or between servers. Port: 25 (non-secure), 587 (secure).SMTP (सिंपल मेल ट्रांसफर प्रोटोकॉल): इसका उपयोग केवल क्लाइंट से सर्वर या सर्वर के बीच ईमेल भेजने के लिए किया जाता है। पोर्ट: 25 (गैर-सुरक्षित), 587 (सुरक्षित)।
  • POP3 (Post Office Protocol v3): Downloads emails from the server to local device and deletes them from server (by default). Port: 110.POP3 (पोस्ट ऑफिस प्रोटोकॉल v3): सर्वर से स्थानीय डिवाइस पर ईमेल डाउनलोड करता है और सर्वर से उन्हें हटा देता है (डिफ़ॉल्ट रूप से)। पोर्ट: 110।
  • IMAP (Internet Message Access Protocol): Syncs emails across multiple devices; emails remain on server. Port: 143.IMAP (इंटरनेट मैसेज एक्सेस प्रोटोकॉल): एकाधिक उपकरणों पर ईमेल सिंक करता है; ईमेल सर्वर पर बने रहते हैं। पोर्ट: 143।
  • Search Engines vs Web Browsers: A browser is software used to access information (e.g., Chrome, Edge, Firefox). A search engine is a website used to search information on the WWW (e.g., Google, Bing, DuckDuckGo).खोज इंजन बनाम वेब ब्राउज़र: ब्राउज़र जानकारी तक पहुँचने के लिए उपयोग किया जाने वाला सॉफ़्टवेयर है (जैसे, क्रोम, एज, फ़ायरफ़ॉक्स)। खोज इंजन एक वेबसाइट है जिसका उपयोग WWW पर जानकारी खोजने के लिए किया जाता है (जैसे, गूगल, बिंग, डकडकगो)।
