Introduction to IP Addressआईपी एड्रेस का परिचय

Definition

परिभाषा

An IP (Internet Protocol) address is a unique numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.आईपी (इंटरनेट प्रोटोकॉल) पता एक विशिष्ट संख्यात्मक लेबल है जो इंटरनेट प्रोटोकॉल का उपयोग करने वाले कंप्यूटर नेटवर्क से जुड़े प्रत्येक डिवाइस को दिया जाता है।

It functions like a postal address for digital devices.यह डिजिटल उपकरणों के लिए एक डाक पते की तरह कार्य करता है।

IP Address Classesआईपी एड्रेस क्लास

IPv4 is divided into classes based on the network size:IPv4 को नेटवर्क आकार के आधार पर वर्गों में विभाजित किया गया है:

Class A (0-127), Class B (128-191), Class C (192-223), Class D (Multicast), Class E (Experimental).क्लास A (0-127), क्लास B (128-191), क्लास C (192-223), क्लास D (मल्टीकास्ट), क्लास E (प्रायोगिक)।

Static vs Dynamic IPस्टेटिक बनाम डायनामिक आईपी

Static IPs are manually configured and permanent. Dynamic IPs are assigned by a DHCP server and change periodically.स्टेटिक आईपी को मैन्युअल रूप से कॉन्फ़िगर किया जाता है और यह स्थायी होते हैं। डायनामिक आईपी को DHCP सर्वर द्वारा असाइन किया जाता है और ये समय-समय पर बदलते रहते हैं।
