Type 1: The x + 1/x to Square Shortcutटाइप 1: x + 1/x से वर्ग शॉर्टकट

💡 Trick to Solve: If x + 1/x = k, then x² + 1/x² = k² - 2. If x - 1/x = k, then x² + 1/x² = k² + 2.💡 हल करने की ट्रिक: यदि x + 1/x = k है, तो x² + 1/x² = k² - 2। यदि x - 1/x = k है, तो x² + 1/x² = k² + 2।

Example: If x + 1/x = 5, find the value of x² + 1/x². उदाहरण: यदि x + 1/x = 5 है, तो x² + 1/x² का मान ज्ञात कीजिए।

🕵️‍♂️ Step 1: Identify k = 5.🕵️‍♂️ चरण 1: k = 5 की पहचान करें।
🛠️ Step 2: Apply formula: k² - 2.🛠️ चरण 2: सूत्र लागू करें: k² - 2।
✅ Step 3: Calculate: 5² - 2 = 25 - 2 = 23.✅ चरण 3: गणना करें: 5² - 2 = 25 - 2 = 23।

Type 2: The x + 1/x to Cube Shortcutटाइप 2: x + 1/x से घन शॉर्टकट

💡 Trick to Solve: If x + 1/x = k, then x³ + 1/x³ = k³ - 3k. If x - 1/x = k, then x³ - 1/x³ = k³ + 3k.💡 हल करने की ट्रिक: यदि x + 1/x = k है, तो x³ + 1/x³ = k³ - 3k। यदि x - 1/x = k है, तो x³ - 1/x³ = k³ + 3k।

Example: If x + 1/x = 4, find x³ + 1/x³. उदाहरण: यदि x + 1/x = 4 है, तो x³ + 1/x³ ज्ञात कीजिए।

🕵️‍♂️ Step 1: Identify k = 4.🕵️‍♂️ चरण 1: k = 4 की पहचान करें।
🛠️ Step 2: Formula: k³ - 3k.🛠️ चरण 2: सूत्र: k³ - 3k।
✅ Step 3: Calculate: 4³ - 3(4) = 64 - 12 = 52.✅ चरण 3: गणना करें: 4³ - 3(4) = 64 - 12 = 52।

If x + 1/x = 3, find the value of x² + 1/x².

यदि x + 1/x = 3 है, तो x² + 1/x² का मान ज्ञात कीजिए।

Show Answer & Solution उत्तर और समाधान देखें

✔ Correct: A

✔ सही उत्तर: A

⚡ Shortcut: If x + 1/x = k, then x² + 1/x² = k² - 2.
🕵️‍♂️ Step 1: k = 3.
🛠️ Step 2: k² - 2 = 3² - 2 = 9 - 2.
✅ Step 3: Value = 7.
⚡ शॉर्टकट: यदि x + 1/x = k, तो x² + 1/x² = k² - 2।
🕵️‍♂️ चरण 1: k = 3।
🛠️ चरण 2: k² - 2 = 3² - 2 = 9 - 2 की गणना करें।
✅ चरण 3: मान = 7।
