1. Linear and Quadratic Equations 🧮1. रैखिक और द्विघात समीकरण 🧮

Linear equations represent degree 1 equations. Quadratic equations are of degree 2: ax² + bx + c = 0. The discriminant (b² - 4ac) determines root nature. रैखिक समीकरण डिग्री 1 के समीकरणों का प्रतिनिधित्व करते हैं। द्विघात समीकरण डिग्री 2 के होते हैं: ax² + bx + c = 0। विविक्तकर (b² - 4ac) मूलों की प्रकृति निर्धारित करता है।

Type 1: Nature of Rootsटाइप 1: मूलों की प्रकृति

💡 Trick to Solve: Evaluate D = b² - 4ac. D > 0 (Real & Distinct), D = 0 (Real & Equal), D < 0 (Imaginary).💡 हल करने की ट्रिक: D = b² - 4ac का मूल्यांकन करें। D > 0 (वास्तविक और भिन्न), D = 0 (वास्तविक और समान), D < 0 (काल्पनिक)।

Example: Determine the nature of roots for 2x² - 4x + 3 = 0. उदाहरण: 2x² - 4x + 3 = 0 के मूलों की प्रकृति निर्धारित कीजिए।

🕵️‍♂️ Step 1: Identify a = 2, b = -4, c = 3.🕵️‍♂️ चरण 1: a = 2, b = -4, c = 3 की पहचान करें।
🛠️ Step 2: Calculate D = (-4)² - 4*2*3 = 16 - 24 = -8.🛠️ चरण 2: D = (-4)² - 4*2*3 = 16 - 24 = -8 की गणना करें।
✅ Step 3: Since D = -8 < 0, roots are imaginary.✅ चरण 3: चूंकि D = -8 < 0 है, मूल काल्पनिक हैं।

For the quadratic equation x² - 4x + 3 = 0, find the sum and product of the roots.

द्विघात समीकरण x² - 4x + 3 = 0 के लिए, मूलों का योग और गुणनफल ज्ञात कीजिए।

Show Answer & Solution उत्तर और समाधान देखें

✔ Correct: A

✔ सही उत्तर: A

⚡ Shortcut: Sum = -b/a, Product = c/a.
🕵️‍♂️ Step 1: b = -4, c = 3, a = 1.
🛠️ Step 2: Sum = -(-4)/1 = 4.
✅ Step 3: Product = 3/1 = 3.
⚡ शॉर्टकट: योग = -b/a, गुणनफल = c/a।
🕵️‍♂️ चरण 1: b = -4, c = 3, a = 1।
🛠️ चरण 2: योग = 4।
✅ चरण 3: गुणनफल = 3।
