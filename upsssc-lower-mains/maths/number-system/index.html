Type 1: Finding Unit Digit of Powersटाइप 1: घातों का इकाई अंक ज्ञात करना

💡 Trick to Solve: Divide power by 4. Use the remainder as new power of the unit digit. If remainder is 0, use power 4.💡 हल करने की ट्रिक: घात को 4 से विभाजित करें। शेषफल को इकाई अंक की नई घात के रूप में उपयोग करें। यदि शेषफल 0 है, तो घात 4 का उपयोग करें।

Example: Find unit digit of 23^57. उदाहरण: 23^57 का इकाई अंक ज्ञात कीजिए।

🕵️‍♂️ Step 1: Base unit digit is 3. Power is 57.🕵️‍♂️ चरण 1: आधार का इकाई अंक 3 है। घात 57 है।
🛠️ Step 2: Divide 57 by 4: remainder = 1.🛠️ चरण 2: 57 को 4 से विभाजित करें: शेषफल = 1।
✅ Step 3: Calculate 3^1 = 3. Unit digit is 3.✅ चरण 3: 3^1 = 3 की गणना करें। इकाई अंक 3 है।
