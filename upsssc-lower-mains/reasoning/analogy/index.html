1

Doctor : Hospital :: Teacher : ?

डॉक्टर : अस्पताल :: शिक्षक : ?

Show Answer उत्तर देखें

✔ Correct: A

✔ सही उत्तर: A

This is a 'Worker : Workplace' analogy. A doctor works in a hospital; similarly, a teacher performs their professional duties in a school. This is a fundamental type of analogy based on professional relationships.

यह 'कार्यकर्ता : कार्यस्थल' सादृश्यता है। एक डॉक्टर अस्पताल में काम करता है; इसी प्रकार, एक शिक्षक अपना पेशेवर कार्य विद्यालय में करता है।

यह 'उपकरण : मापन' सादृश्यता है। घड़ी का उपयोग समय मापने के लिए किया जाता है, और थर्मामीटर का उपयोग तापमान मापने के लिए किया जाता है।

12

State True/False: (1) 2:4 :: 3:9 is a square relationship. (2) 5:125 :: 6:216 is a cube relationship.

सत्य/असत्य बताएं: (1) 2:4 :: 3:9 एक वर्ग संबंध है। (2) 5:125 :: 6:216 एक घन संबंध है।

Show Answer उत्तर देखें

✔ Correct: A

✔ सही उत्तर: A

Both are mathematical analogies. 2^2=4 and 3^2=9 (Square). 5^3=125 and 6^3=216 (Cube). Both statements are accurate.

दोनों गणितीय सादृश्यता हैं। 2^2=4 और 3^2=9 (वर्ग)। 5^3=125 और 6^3=216 (घन)। दोनों कथन सटीक हैं।

17

Assertion (A): 16:64 :: 25:125 is a correct analogy. Reason (R): Both pairs follow n^2 : n^3 pattern.

अभिकथन (A): 16:64 :: 25:125 एक सही सादृश्यता है। कारण (R): दोनों युग्म n^2 : n^3 पैटर्न का पालन करते हैं।

Show Answer उत्तर देखें

✔ Correct: A

✔ सही उत्तर: A

16 is 4^2, 64 is 4^3. 25 is 5^2, 125 is 5^3. The logic is consistent, making the assertion and reason both true.

16, 4 का वर्ग है, 64, 4 का घन है। 25, 5 का वर्ग है, 125, 5 का घन है। तर्क सुसंगत है, जिससे अभिकथन और कारण दोनों सत्य हैं।

18

Assertion (A): Fire : Ashes :: Event : Memory. Reason (R): The second item is the remnant of the first.

अभिकथन (A): आग : राख :: घटना : स्मृति। कारण (R): दूसरी वस्तु पहली वस्तु का अवशेष है।

Show Answer उत्तर देखें

✔ Correct: A

✔ सही उत्तर: A

When fire consumes something, ash remains. When an event passes, memory remains. The logic 'Effect : Remnant' is perfectly applied.

जब आग किसी चीज को जलाती है, तो राख बच जाती है। जब कोई घटना बीत जाती है, तो स्मृति बच जाती है। 'प्रभाव : अवशेष' का तर्क पूरी तरह से लागू होता है।
