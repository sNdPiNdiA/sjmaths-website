यण संधियण संधि

इ/ई, उ/ऊ, या ऋ के बाद कोई भिन्न स्वर आए तो इ का 'य', उ का 'व' और ऋ का 'र' हो जाता है।इ/ई, उ/ऊ, या ऋ के बाद कोई भिन्न स्वर आए तो इ का 'य', उ का 'व' और ऋ का 'र' हो जाता है।

उदाहरण: अति + अधिक = अत्यधिक, सु + आगत = स्वागत, पितृ + आज्ञा = पित्राज्ञा।उदाहरण: अति + अधिक = अत्यधिक, सु + आगत = स्वागत, पितृ + आज्ञा = पित्राज्ञा।

अयादि संधिअयादि संधि

व्यंजन संधि के मुख्य नियमव्यंजन संधि के मुख्य नियम

वर्ग के पहले वर्ण का तीसरे में परिवर्तन: दिक + गज = दिग्गज, अच + अंत = अजंत।वर्ग के पहले वर्ण का तीसरे में परिवर्तन: दिक + गज = दिग्गज, अच + अंत = अजंत।

वर्ग के पहले वर्ण का पांचवें में: वाक् + मय = वाङ्मय, जगत् + नाथ = जगन्नाथ।वर्ग के पहले वर्ण का पांचवें में: वाक् + मय = वाङ्मय, जगत् + नाथ = जगन्नाथ।

उदाहरण: मनः + अनुकूल = मनोनुकूल, निः + छल = निश्चल, दुः + शासन = दुःशासन।उदाहरण: मनः + अनुकूल = मनोनुकूल, निः + छल = निश्चल, दुः + शासन = दुःशासन।
