Which expression is a rational number?

  1. √2
  2. π
  3. −7/4
  4. √3
Show step-wise answer

(c) −7/4

  2. A non-terminating, non-repeating decimal
  3. 0.272727…

  2. If x = 0.272727…, then 100x − x = 27, so x = 27/99 = 3/11.

Question 8

Describe how to mark −3/4 and 5/4 on a number line. State which point is closer to 0.

Show step-wise answer

−3/4 is three quarter-steps left of 0; 5/4 is five quarter-steps right. −3/4 is closer.

  1. Divide each unit interval into four equal parts.
  2. Count three parts to the left for −3/4 and five to the right for 5/4.
  3. Distances from zero are 3/4 and 5/4; compare their magnitudes.

Show step-wise answer

For example 6/15, 7/15, 8/15, 9/15; no smallest rational above 1/3 exists.

  2. Choose the four fractions with numerators 6, 7, 8 and 9.
  3. For any rational r > 1/3, the rational (r + 1/3)/2 lies strictly between them.

Decimal representations and algorithms · 3 practice marks

Question 10

Convert 0.125 and 0.1666… to fractions. Explain how long division detects an eventually repeating decimal.

Show step-wise answer

0.125 = 1/8; 0.1666… = 1/6.

  1. 125/1000 reduces to 1/8.
  2. For x = 0.1666…, 10x = 1.666… and 100x = 16.666…; subtract to obtain 90x = 15.
  3. In long division record each remainder. A zero remainder terminates; a repeated remainder repeats the subsequent digits.

Square root spiral and visual construction · 3 practice marks

Question 11

Give ordered construction steps for the first three hypotenuses of a square root spiral. What lengths do they represent?

Show step-wise answer

√2, √3 and √4 = 2 units.

  1. Begin with a unit segment from O. At its end construct a perpendicular unit segment; join its end to O to get √2.
  2. At the new endpoint construct a unit segment perpendicular to the latest radius; the next radius is √3.
  3. Repeat once more. By Pythagoras the new squared radius is 3 + 1 = 4.

Question 12

Describe how to locate √5 on the number line using a right triangle. Explain why the construction is valid.

Show step-wise answer

Construct a right triangle with legs 2 and 1; transfer its hypotenuse to the positive number line.

  1. Mark O = 0 and A = 2. At A draw AB perpendicular to OA with AB = 1.
  2. Pythagoras gives OB² = 2² + 1² = 5, so OB = √5.
  3. With centre O and radius OB draw an arc meeting the positive number line. Its intersection represents √5.

Question 14

A student claims that a rational number plus an irrational number is rational. Disprove the claim in general.

Show step-wise answer

The sum of a rational number and an irrational number is irrational.

  1. Let r be rational and s irrational.
  2. If r + s were rational, then (r + s) − r would be rational because rationals are closed under subtraction.
  3. But this difference equals s, a contradiction.

Recurring decimal · 3 practice marks

Question 15

Use long division to find the decimal expansion of 1/12. Identify its non-repeating and repeating parts.

Show step-wise answer

1/12 = 0.083333…; 08 is the non-repeating part and 3 repeats.

  1. Divide 10 by 12: the first decimal digit is 0 and the remainder is 10.
  2. Divide 100 by 12: digit 8, remainder 4.
  3. Every subsequent step divides 40 by 12: digit 3, remainder 4 again. Therefore 3 repeats.

Question 16

Prove that √2 is irrational using a fraction in lowest terms.

Show step-wise answer

√2 is irrational.

  1. Assume √2 = p/q, where p and q are coprime integers and q ≠ 0.
  2. Then p² = 2q², so p² is even. An odd integer has odd square, hence p is even.
  3. Put p = 2k. Then q² = 2k², so q is also even.
  4. Both p and q are divisible by 2, contradicting lowest terms. The assumption is false.

Density and finding intermediate rationals · 4 practice marks

Question 17

Prove density of rational numbers using the midpoint of two rational numbers a < b. Explain how to generate infinitely many different rationals between them.

Show step-wise answer

(a + b)/2 is rational and lies strictly between a and b; repeat midpoint selection.

  1. Sums of rationals and division by 2 preserve rationality.
  2. a < b implies 2a < a + b < 2b, so a < (a + b)/2 < b.
  3. Set r₁ = (a + b)/2 and rₙ₊₁ = (a + rₙ)/2.
  4. Each rₙ₊₁ lies strictly between a and rₙ, so the sequence produces infinitely many distinct intermediate rationals.

Irrationality of square roots of 2 and 3 · 4 practice marks

Question 18

Prove √3 is irrational. Justify the implication that if 3 divides p², then 3 divides p.

Show step-wise answer

√3 is irrational.

  1. Squares of integers with remainders 0, 1, 2 on division by 3 have remainders 0, 1, 1 respectively.
  2. Assume √3 = p/q in lowest terms. Then p² = 3q²; the remainder argument gives p = 3k.
  3. Substitution gives q² = 3k², so 3 also divides q.
  4. This contradicts coprimality. Therefore √3 is irrational.

Closure and contradiction · 4 practice marks

Question 19

Prove that 2 + √3 is irrational. State precisely which known result your proof uses.

Show step-wise answer

2 + √3 is irrational, using the irrationality of √3.

  1. Suppose 2 + √3 is rational.
  2. Subtract the rational number 2. Closure of rationals under subtraction would make √3 rational.
  3. This contradicts the proved irrationality of √3.
  4. Therefore the supposition is false. The worksheet includes a separate proof of the required √3 result.
