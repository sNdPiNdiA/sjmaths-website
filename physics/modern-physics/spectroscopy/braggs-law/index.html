Bragg's Law of X-ray Diffraction

Bragg's law gives the condition for constructive interference of X-rays scattered from parallel atomic planes in a crystal lattice. It relates the X-ray wavelength and lattice spacing to the angles of incidence and diffraction.

Prerequisites

Physical Origin of X-ray Diffraction

  • Crystals act as three-dimensional diffraction gratings for electromagnetic radiation with wavelengths comparable to interatomic distances (approx. 1 angstrom).
  • When parallel monochromatic X-rays strike a crystal, each atom acts as a scattering center, re-emitting the radiation in all directions.
  • Constructive interference occurs only in specific directions where the path difference between waves scattered from adjacent planes is an integral multiple of the wavelength.

Bragg's Condition Formulation

  • W.L. Bragg and W.H. Bragg modeled crystal diffraction as 'reflection' of X-rays from sets of parallel atomic planes.
  • The angle of incidence theta is measured between the incident beam and the crystal plane, distinct from optics where angles are measured from the normal.
  • The path difference arises because rays reflecting from deeper planes travel a slightly longer distance than rays reflecting from upper planes.

Order of Diffraction (n)

  • The integer n represents the order of diffraction, corresponding to the number of wavelengths in the total path difference between adjacent planes.
  • For a given lattice spacing d and wavelength lambda, multiple diffraction angles (theta_1, theta_2, etc.) can satisfy Bragg's law for n = 1, 2, 3...
  • Higher-order reflections correspond to smaller net intensity due to atomic scattering factors and thermal vibrations (Debye-Waller factor).

Limitations on Wavelength and Interplanar Spacing

  • Since sin(theta) cannot exceed unity, the maximum possible wavelength that can be diffracted by a set of planes with spacing d is lambd$a_max = 2d$.
  • If lambda > 2d, no diffraction maxima can be observed regardless of the angle of incidence.
  • This condition explains why visible light cannot be diffracted by standard crystal lattices and requires X-rays or gamma rays.

Derivations

Derivation of Bragg's Law

Conditions: Monochromatic parallel beam of X-rays incident at angle theta on parallel crystal planes separated by distance d.

  • Consider two parallel X-ray wavefronts incident on two consecutive atomic planes, A1 and A2, separated by interplanar distance d at glancing angle theta.
  • Draw perpendiculars from the point of reflection on the second plane to the incident ray and the reflected ray to determine the extra path traveled by the second ray.
  • The extra distance traveled by the lower ray is given by the sum of the path segments in and out of the crystal: path differenc$e = BX + XC$.
  • In the right-angled triangle formed by the normal and the atomic planes, the length BX equals d sin(theta) and XC also equals d sin(theta).
  • Total path differenc$e = d \sin(\theta) + d \sin(\theta) = 2d \sin(\theta)$.
  • For constructive interference to occur, this path difference must be equal to an integral multiple of the wavelength (n lambda).

Result: 2d sin(theta) = n lambda

Bragg's Law in Terms of Interplanar Spacing for Cubic Crystals

Conditions: Cubic crystal system with lattice parameter a and Miller indices (hkl).

  • For a cubic crystal, the interplanar spacing d for a set of planes with Miller indices (hkl) is given by $d = a / \sqrt(h^2 + k^2 + l^2)$.
  • Substitute this expression for d into the standard Bragg's law equation: 2 (a / sqrt(h^2 + k^2 + l^2)) sin(theta) = n lambda.
  • Rearrange the equation to express the sine of the glancing angle in terms of the crystal parameters: sin(theta) = (n lambda sqrt(h^2 + k^2 + l^2)) / (2a).

Result: 2 a sin(theta) / sqrt(h^2 + k^2 + $l^2) = n \lambda$

Solved numericals

TGT core

X-rays of wavelength 0.15 nm are diffracted by a crystal plane with interplanar spacing 0.30 nm. Calculate the glancing angle for the first-order diffraction maximum.

  • Identify given values: lambda = 0.15 nm, d = 0.30 nm, n = 1.
  • Write Bragg's law formula: 2d sin(theta) = n lambda.
  • Substitute values into the equation: 2 * (0.30 nm) * sin(theta) = 1 * (0.15 nm).
  • Simplify: 0.60 * sin(theta) = 0.15.
  • Calculate sin(theta): sin(theta) = 0.15 / 0.60 = 0.25.
  • Find theta: theta = arcsin(0.25) = 14.48 degrees.

Answer: 14.48 degrees

TGT core

Find the maximum wavelength of X-rays that can be diffracted by a crystal plane having a separation of 0.2 nm.

  • Identify the condition for maximum wavelength: lambd$a_max = 2d$ for n = 1 and sin(theta) = 1.
  • Substitute the given interplanar spacing d = 0.2 nm into the relation.
  • Calculate lambd$a_max = 2 * 0.2 nm = 0.4 nm$.

Answer: 0.4 nm

PGT extension

For a cubic crystal, first-order diffraction from the (110) planes is observed at a glancing angle of 30 degrees with X-rays of wavelength 0.2 nm. Determine the lattice parameter a of the crystal.

  • Identify Miller indices h = 1, k = 1, l = 0, n = 1, theta = 30 degrees, lambda = 0.2 nm.
  • Calculate the interplanar spacing d using Bragg's law: 2d sin(30) = 1 * 0.2 -> 2d * $0.5 = 0.2 -> d = 0.2 nm$.
  • Relate interplanar spacing to lattice parameter for cubic crystal: $d = a / \sqrt(h^2 + k^2 + l^2)$.
  • Substitute h=1, k=1, $l=0: d = a / \sqrt(1^2 + 1^2 + 0^2) = a / \sqrt(2)$.
  • Calculate lattice parameter a: $a = d * \sqrt(2) = 0.2 nm * 1.414 = 0.2828 nm$.

Answer: 0.2828 nm

Assumptions and limitations

  • Assumes X-rays undergo specular reflection from continuous atomic planes, which is a simplified conceptual model compared to true scattering by discrete electron clouds.
  • Neglects secondary extinction and multiple scattering effects within thick crystals.
  • Assumes a rigid, static lattice at absolute zero temperature, ignoring thermal vibrations (which are accounted for via the Debye-Waller temperature factor).

Common misconceptions

Common error: The glancing angle theta is measured between the incident X-ray beam and the normal to the crystal plane.

Correct: The glancing angle theta is measured between the incident X-ray beam and the plane of the crystal itself.

Confusing optical reflection conventions (angle from normal) with X-ray crystallography conventions (angle from plane).

Common error: Bragg's law only holds for cubic crystal systems.

Correct: Bragg's law is universal and applies to all crystal systems (monoclinic, triclinic, hexagonal, etc.).

The expression relating d to the lattice parameter (like a) depends on the crystal system, but the core law 2d sin(theta) = n lambda is universal.

Common error: Higher-order diffraction peaks always have higher intensity than lower-order peaks.

Correct: Intensity generally decreases for higher-order reflections due to atomic form factors and thermal agitation.

Constructive interference condition is purely geometric, but actual diffracted intensity depends on electron density distribution within the unit cell.

Quick revision

  • Bragg's Law equation is 2d sin(theta) = n lambda, governing constructive interference in X-ray diffraction.
  • Bragg's Law: 2d \sin(\theta) = n\lambda
  • Interplanar Spacing for Cubic System: $d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$

Must remember

  • Bragg's Law is formulated as $2d \sin(\theta) = n\lambda$, where $\theta$ is measured between the incident beam and the crystal plane.
  • The maximum possible wavelength that can be diffracted by a set of planes with spacing $d$ is $\lambda_{max} = 2d$.
  • For a cubic crystal system, the interplanar spacing is given by $d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$.
  • The glancing angle $\theta$ in X-ray crystallography is distinct from optical reflection conventions where angles are measured from the normal.
  • Higher-order reflections ($n = 2, 3, \dots$) correspond to smaller net intensities due to atomic scattering factors and thermal vibrations.

Practice Quiz

Choose an option to reveal the explanation.

1. What is the correct mathematical expression for Bragg's Law of X-ray diffraction?

Explanation: Bragg's law states that constructive interference occurs when the path difference equals an integer multiple of the wavelength, yielding $2d \sin(\theta) = n\lambda$.

2. In X-ray crystallography, how is the glancing angle $\theta$ defined?

Explanation: Unlike classical optics where angles are measured from the normal, in X-ray crystallography the glancing angle $\theta$ is measured between the incident beam and the crystal plane.

3. What is the maximum possible wavelength $\lambda_{max}$ that can be diffracted by a set of planes with spacing $d$?

Explanation: Since $\sin(\theta) \le 1$, for the first order ($n=1$), $2d(1) = 1\lambda_{max}$, which gives $\lambda_{max} = 2d$.

4. For a cubic crystal system, what is the interplanar spacing $d_{hkl}$ in terms of lattice parameter $a$ and Miller indices $h, k, l$?

Explanation: The geometric relation for interplanar spacing in a cubic crystal is $d_{hkl} = \frac{a}{\sqrt{h^2 + k^2 + l^2}}$.

5. Why are visible light photons unable to produce diffraction peaks from standard atomic crystal lattices?

Explanation: Standard crystal lattice spacings are on the order of $1$ angstrom ($10^{-10}$ m), whereas visible light has wavelengths around $4000-7000$ angstroms, violating the condition $\lambda \le 2d$.

6. What does the integer $n$ represent in Bragg's Law $2d \sin(\theta) = n\lambda$?

Explanation: The integer $n$ denotes the order of diffraction, corresponding to the number of wavelengths in the total path difference between adjacent planes.

7. If the interplanar spacing $d = 2.0 \text{ \AA}$ and first-order diffraction ($n=1$) of monochromatic X-rays occurs at a glancing angle of $30^\circ$, what is the wavelength $\lambda$?

Explanation: Using Bragg's law: $\lambda = \frac{2d \sin(30^\circ)}{1} = 2(2.0 \text{ \AA})(0.5) = 2.0 \text{ \AA}$.

8. Which of the following statements about higher-order reflections is correct?

Explanation: While geometric condition permits higher orders, their actual intensity decreases due to atomic form factors and the Debye-Waller thermal vibration factor.

9. What is the path difference between X-ray waves reflected from two adjacent atomic planes separated by distance $d$ at glancing angle $\theta$?

Explanation: The geometric path difference contributed by both the descent and ascent to the adjacent plane is equal to $2d \sin(\theta)$.

10. Does Bragg's law hold exclusively for cubic crystal systems?

Explanation: Bragg's law $2d \sin(\theta) = n\lambda$ is universal; the formula relating $d$ to lattice parameters depends on the crystal system, but the law itself does not.

11. What is the maximum order of diffraction $n_{max}$ possible for X-rays of wavelength $\lambda$ reflecting from planes with spacing $d$?

Explanation: Since $\sin(\theta) \le 1$, $n = \frac{2d \sin(\theta)}{\lambda} \le \frac{2d}{\lambda}$, hence $n_{max} = \lfloor \frac{2d}{\lambda} \rfloor$.

12. In reciprocal lattice space, what does the Laue-Bragg diffraction condition represent?

Explanation: In reciprocal space, Bragg's law is elegantly expressed as $\Delta \vec{k} = \vec{G}$, meaning the scattering vector matches a reciprocal lattice vector.

13. For a cubic crystal, combining Bragg's Law ($n=1$) and interplanar spacing yields $\sin^2(\theta)$ proportional to which term?

Explanation: Since $\sin(\theta) = \frac{\lambda}{2d_{hkl}} = \frac{\lambda \sqrt{h^2+k^2+l^2}}{2a}$, squaring both sides gives $\sin^2(\theta) \propto (h^2 + k^2 + l^2)$.

14. Why do atoms in a crystal act as scattering centers for X-rays rather than visible light?

Explanation: X-ray wavelengths are comparable to atomic dimensions (~1 Å), allowing electrons within atoms to scatter the radiation coherently to produce observable interference patterns.

15. If a crystal has a lattice parameter $a = 3.0 \text{ \AA}$, what is the interplanar spacing $d_{110}$?

Explanation: For Miller indices $(110)$, $h^2+k^2+l^2 = 1^2+1^2+0^2 = 2$. Thus, $d_{110} = \frac{3.0}{\sqrt{2}} \text{ \AA}$.

Timed Topic Test

Attempt these questions under a ten-minute limit using a separate timer.

1. In an X-ray diffraction experiment using a cubic crystal, the first-order reflection from $(111)$ planes is observed at $\theta = 30^\circ$. If $a = 3.464 \text{ \AA}$, what is the wavelength of the X-rays?

Explanation: For $(111)$, $\sqrt{h^2+k^2+l^2} = \sqrt{3}$. Spacing $d = \frac{3.464}{\sqrt{3}} = \frac{3.464}{1.732} = 2.0 \text{ \AA}$. From Bragg's law: $\lambda = 2d \sin(30^\circ) = 2(2.0)(0.5) = 2.0 \text{ \AA}$.

2. What is the physical reason why higher-order diffraction peaks show a decrease in intensity?

Explanation: While pure geometry satisfies Bragg's law, real crystal intensities drop at higher orders due to finite electron cloud size and thermal oscillations of atoms.

3. A monochromatic X-ray beam of unknown wavelength is incident on a NaCl crystal ($d = 2.82 \text{ \AA}$). The first-order reflection occurs at $\theta = 8^\circ$. What is the wavelength approximately? (Given $\sin(8^\circ) \approx 0.139$)

Explanation: $\lambda = 2d \sin(\theta) = 2(2.82 \text{ \AA})(0.139) \approx 0.784 \text{ \AA}$.

4. If the interplanar spacing $d$ is equal to the wavelength $\lambda$, what is the maximum possible order of diffraction $n_{max}$?

Explanation: Using $n_{max} = \lfloor \frac{2d}{\lambda} \rfloor$. Since $d = \lambda$, $n_{max} = \lfloor 2 \rfloor = 2$.

5. How does the glancing angle $\theta$ change for higher-order reflections ($n=1, 2, 3$) given constant $d$ and $\lambda$?

Explanation: Since $\sin(\theta) = \frac{n\lambda}{2d}$, as $n$ increases, $\sin(\theta)$ increases, meaning the glancing angle $\theta$ must increase.

6. Which crystal plane in a simple cubic lattice has the largest interplanar spacing $d$?

Explanation: Interplanar spacing is $d = \frac{a}{\sqrt{h^2+k^2+l^2}}$. The denominator is smallest for $(100)$ where $\sqrt{1^2+0^2+0^2} = 1$, yielding the maximum $d$-spacing ($a$).

7. What happens to the diffraction angle $\theta$ if the interplanar spacing $d$ of a crystal is decreased while keeping $\lambda$ and $n$ constant?

Explanation: From $\sin(\theta) = \frac{n\lambda}{2d}$, $\sin(\theta)$ is inversely proportional to $d$. Decreasing $d$ increases $\sin(\theta)$, and thus increases $\theta$.

8. In the reciprocal lattice formulation, the condition for constructive interference is given by vector dot product or vector difference. Which vector represents the scattering vector?

Explanation: The scattering vector $\Delta \vec{k}$ is defined as the difference between the scattered wave vector $\vec{k}$ and the incident wave vector $\vec{k}_0$ (i.e., $\vec{k} - \vec{k}_0$).

9. A student measures the glancing angle from the normal instead of the crystal plane, obtaining an angle $\phi = 60^\circ$. What is the correct glancing angle $\theta$ to use in Bragg's law?

Explanation: The glancing angle $\theta$ is measured from the plane, which is complementary to the angle measured from the normal: $\theta = 90^\circ - \phi = 90^\circ - 60^\circ = 30^\circ$.
