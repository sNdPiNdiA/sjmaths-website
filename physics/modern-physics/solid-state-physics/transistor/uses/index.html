Uses and Applications of Transistors in Modern Physics

A transistor is a semiconductor device used to amplify or switch electrical signals and power, serving as the fundamental building block of modern electronic devices. It operates by controlling the flow of current through a solid crystal medium via minority and majority charge carriers.

Transistor as an Amplifier

  • Amplification is the process of increasing the amplitude of a weak electrical signal without distortion.
  • In a Common Emitter (CE) configuration, a small change in base current (ΔIB) produces a large change in collector current (ΔIC) due to the large current gain (β).
  • The voltage gain is determined by the product of the current gain and the ratio of the load resistance to the input resistance.

Transistor as a Switch

  • In digital electronics, a transistor operates in two extreme regions: cutoff (off state) and saturation (on state).
  • In the cutoff region, both junctions are reverse-biased, resulting in zero collector current, meaning the switch is open (output voltage equals VCC).
  • In the saturation region, both junctions are forward-biased, maximizing collector current, meaning the switch is closed (output voltage approaches 0 V).

Transistor as an Oscillator

  • An oscillator is an electronic circuit that generates continuous periodic waveforms, such as sine waves, without an external input signal.
  • Barkhausen criterion requires the loop gain AB to be equal to unity (|AB| = 1) and the total phase shift around the loop to be 0° or an integral multiple of 360°.
  • Positive feedback is employed to feed a fraction of the output energy back into the input in phase with the original signal.

Transistor Configurations and Characteristics

  • Common Base (CB): Provides voltage gain but current gain is less than unity (α < 1); input resistance is very low, output resistance is very high.
  • Common Emitter (CE): Provides both high current gain (β > 1) and high voltage gain; moderate input and output resistances; most widely used configuration.
  • Common Collector (CC) / Emitter Follower: Provides high current gain, voltage gain is approximately unity (≈ 1); high input resistance and low output resistance, used for impedance matching.

Derivations

Relation between Current Gains alpha and beta

Conditions: Steady-state dc operation in active region

  • Write the fundamental relation between emitter current, collector current, and base current: IE = IC + IB.
  • Define dc current gain in Common Base configuration as α = IC / IE and in Common Emitter configuration as β = IC / IB.
  • Substitute IB = IC / β and IE = IC / α into the fundamental current equation: (IC / α) = IC + (IC / β).
  • Divide throughout by IC and simplify to obtain the reciprocal relation: (1 / α) = 1 + (1 / β).

Result: beta = \frac{\alpha}{1 - \alpha} \text{ and } \alpha = \frac{\beta}{1 + \beta}

AC Voltage Gain of a Common Emitter Amplifier

Conditions: Linear small-signal operation with load resistance R<sub>L</sub> and input resistance r<sub>i</sub>

  • Express the output voltage as Vo = -ΔIC RL, where the negative sign indicates a 180° phase reversal.
  • Express the input voltage as Vi = ΔIB ri.
  • Write the voltage gain Av as the ratio of output voltage to input voltage: Av = (Vo / Vi) = -(ΔIC / ΔIB) × (RL / ri).
  • Substitute the ac current gain βac = (ΔIC / ΔIB) into the equation.

Result: A_v = -\beta_{ac} \left(\frac{R_L}{r_i}\right)

Draw: A straight line drawn on the output characteristics connecting the saturation point (V<sub>CC</sub> / R<sub>L</sub> on the y-axis) and the cutoff point (V<sub>CC</sub> on the x-axis).

Solved numericals

TGT core

In a transistor circuit, the collector current is 4.8 mA and the base current is 0.2 mA. Calculate the emitter current and the current gain beta.

  • Use the fundamental current relation: IE = IC + IB.
  • Substitute the given values: IE = 4.8 mA + 0.2 mA = 5.0 mA.
  • Calculate current gain beta using β = IC / IB.
  • Substitute values: β = 4.8 mA / 0.2 mA = 24.

Answer: Emitter current I_E = 5.0 mA, Current gain beta = 24

PGT extension

A transistor has a common base current gain alpha of 0.98. If the emitter current changes by 2 mA, find the corresponding change in collector current and base current.

  • Use the definition of alpha: α = (ΔIC / ΔIE).
  • Calculate change in collector current: ΔIC = α × ΔIE = 0.98 × 2 mA = 1.96 mA.
  • Use the current relation for changes: ΔIE = ΔIC + ΔIB.
  • Calculate change in base current: ΔIB = ΔIE - ΔIC = 2 mA - 1.96 mA = 0.04 mA.

Answer: Delta I_C = 1.96 mA, Delta I_B = 0.04 mA (or 40 microampere)

PGT extension

For a common emitter amplifier, the load resistance is 2 k&Omega; and the input resistance is 500 &Omega;. If the current gain beta is 50, calculate the voltage gain and the power gain of the amplifier.

  • Use the voltage gain formula: Av = -β × (RL / ri).
  • Substitute the values: Av = -50 × (2000 / 500) = -50 × 4 = -200 (magnitude is 200).
  • Use the power gain formula: Ap = Av × β (or Av2 / β depending on impedance ratio).
  • Calculate power gain: Ap = 200 × 50 = 10000.

Answer: Voltage gain magnitude = 200, Power gain = 10000

Assumptions and limitations

  • Assumes linear operation over the small signal range, which fails if input signals are excessively large, causing clipping and nonlinear distortion.
  • Collector leakage currents are assumed negligible in basic dc calculations, though they are temperature-dependent and can cause thermal runaway in power transistors.

Common misconceptions

Common error: The current gain beta can be less than unity in a common emitter configuration.

Correct: Beta is always much greater than unity (&beta; >> 1) in a common emitter configuration.

Because collector current is controlled by a very small base current, making I<sub>C</sub> > I<sub>B</sub>.

Common error: A transistor acts as a source of electrical energy.

Correct: A transistor does not generate energy; it controls the flow of power from a DC power supply using a weak input signal.

Conservation of energy holds; amplification is power transfer control, not energy creation.

Common error: The emitter and collector terminals of a transistor are interchangeable because both are heavily doped or made of the same semiconductor material.

Correct: Emitter and collector are not interchangeable.

The emitter is heavily doped to inject carriers, the base is very thin and lightly doped, and the collector is moderately doped and larger in area to dissipate heat.

Quick revision

  • I_E = I_C + I_B and beta = alpha / (1 - alpha) are the foundational relations for all transistor calculations.
  • Transistor Current Relation: I_E = I_C + I_B
  • Common Base Current Gain (alpha): \alpha = \frac{I_C}{I_E}

Must remember

  • In any transistor, the emitter current is the sum of collector and base currents: $I_E = I_C + I_B$.
  • The Common Emitter (CE) configuration is the most widely used configuration because it provides both high current gain ($\beta > 1$) and high voltage gain.
  • Barkhausen criteria for sustained oscillations require the loop gain to be magnitude unity ($|A\beta| = 1$) and the total phase shift to be $0^\circ$ or $360^\circ$.
  • As a switch, a transistor operates in two extreme regions: cutoff (off state, open switch) and saturation (on state, closed switch).
  • The relation between current gains is given by $\beta = \frac{\alpha}{1 - \alpha}$.

Practice Quiz

Choose an option to reveal the explanation.

1. Which of the following relations correctly connects the emitter current ($$I_{E}$$), collector current ($$I_{C}$$), and base current ($$I_{B}$$)?

Explanation: Total current entering the transistor equals the sum of currents leaving it, hence $$I_{E}$ = $I_{C}$ + $I_{B}$$.

2. What is the value of the Common Base current gain ($\$\alpha$$) if the Common Emitter current gain ($\$\beta$$) is $99$?

Explanation: Using the formula $\$\alpha$ = \frac{\$\beta$}{1 + \$\beta$} = \frac{99}{100} = 0.99$.

3. In a Common Emitter configuration, a transistor acts as an amplifier because:

Explanation: Due to high current gain ($\$\beta$$), a small variation in $\Delta $I_{B}$$ causes a significantly large variation in $\Delta $I_{C}$$.

4. When a transistor operates as an electronic switch in the cutoff region:

Explanation: In cutoff, both emitter and collector junctions are reverse-biased, resulting in zero collector current, meaning the switch is open.

5. What is the primary requirement for a feedback circuit to function as an oscillator according to Barkhausen criterion?

Explanation: Barkhausen criterion requires loop gain magnitude $|A\$\beta$| = 1$ and total phase shift of $0^\circ$ or an integral multiple of $360^\circ$.

6. Which transistor configuration is typically used for impedance matching because of its high input resistance and low output resistance?

Explanation: The Common Collector (Emitter Follower) configuration has high input resistance and low output resistance, making it ideal for impedance matching.

7. If the current gain $\$\alpha$$ of a transistor is $0.98$, what is the value of current gain $\$\beta$$?

Explanation: Using $\$\beta$ = \frac{\$\alpha$}{1 - \$\alpha$} = \frac{0.98}{1 - 0.98} = \frac{0.98}{0.02} = 49$.

8. In the saturation region of a transistor switch:

Explanation: In saturation, both junctions are forward-biased, collector current is maximized, and output voltage approaches zero.

9. What type of feedback is used in transistor oscillator circuits?

Explanation: Positive feedback is employed to feed a fraction of output energy back in phase with the original signal to sustain oscillations.

10. The emitter of a transistor is heavily doped because:

Explanation: The emitter is heavily doped so that it can inject a high concentration of majority charge carriers into the thin base region.

11. Which parameter describes the leakage current in a Common Base configuration with an open emitter?

Explanation: $I_{CBO}$ represents the collector-to-base leakage current with an open emitter.

12. What is the approximate voltage gain of a Common Collector configuration?

Explanation: The Common Collector amplifier provides high current gain, but its voltage gain is approximately unity ($\approx 1$).

13. A transistor does not generate electrical energy on its own; instead, it:

Explanation: Conservation of energy holds; amplification is power transfer control from a DC source, not energy creation.

14. In small-signal operation, the total AC power gain $A_p$ is given by:

Explanation: AC power gain is the product of voltage gain ($A_v$) and AC current gain ($\beta_{ac}$).

15. Why are the emitter and collector terminals of a transistor not interchangeable?

Explanation: Emitter is heavily doped for injection and collector is larger and moderately doped to dissipate heat effectively.

PYQ Patterns

These are pattern-based practice questions. Authentic year labels are only used when verified from a source.

1. In a transistor, the collector current is $0.98\text{ mA}$ and base current is $0.02\text{ mA}$. The emitter current is:

Explanation: Using $$I_{E}$ = $I_{C}$ + $I_{B}$ = 0.98\text{ mA} + 0.02\text{ mA} = 1.00\text{ mA}$.

2. The current gain $\$\alpha$$ of a transistor in common base mode is $0.95$. Calculate the change in collector current if the emitter current changes by $2\text{ mA}$.

Explanation: Since $\$\alpha$ = \frac{\Delta $I_{C}$}{\Delta $I_{E}$}$, $\Delta $I_{C}$ = \$\alpha$ \times \Delta $I_{E}$ = 0.95 \times 2\text{ mA} = 1.9\text{ mA}$.

3. For a transistor circuit, if $\$\beta$ = 50$ and base current $$I_{B}$ = 20\text{ }\mu\text{A}$, what is the collector current $$I_{C}$$ (neglecting leakage current)?

Explanation: $$I_{C}$ = \$\beta$ $I_{B}$ = 50 \times 20\text{ }\mu\text{A} = 1000\text{ }\mu\text{A} = 1\text{ mA}$.

4. Which of the following configurations provides a phase reversal of $180^\circ$ between input and output AC signals?

Explanation: The Common Emitter configuration introduces a $180^\circ$ phase shift between the input base voltage/current and the output collector voltage.

5. If the loop gain of an amplifier with feedback is $|A\$\beta$| = 1$ and phase shift is $360^\circ$, the circuit will:

Explanation: These conditions satisfy the Barkhausen criterion for sustained oscillations.

6. In a transistor operating as a switch, when it is driven deep into saturation, the collector-emitter voltage $V_{CE}$ is:

Explanation: In saturation, the transistor acts like a closed switch, meaning $V_{CE}$ drops to nearly $0\text{ V}$ (saturation voltage).

Timed Topic Test

Attempt these questions under a ten-minute limit using a separate timer.

1. What happens to the collector current if the base current increases in a Common Emitter amplifier?

Explanation: Collector current $$I_{C}$ = \$\beta$ $I_{B}$$; thus, an increase in base current results in a significant increase in collector current.

2. The input resistance of a Common Base transistor configuration is:

Explanation: The emitter-base junction is forward-biased with a low resistance, giving the CB configuration a very low input resistance.

3. What is the value of $\$\beta$$ when $\$\alpha$ = 0.8$?

Explanation: $\$\beta$ = \frac{\$\alpha$}{1 - \$\alpha$} = \frac{0.8}{1 - 0.8} = \frac{0.8}{0.2} = 4$.

4. An oscillator produces:

Explanation: An oscillator is an electronic circuit that generates continuous periodic waveforms without an external input signal.

5. Which terminal is common in a Common Emitter amplifier circuit?

Explanation: In a Common Emitter configuration, the emitter terminal is common to both the input and output circuits.

6. In digital logic circuits, a transistor switch in cutoff region represents which binary state (assuming positive logic)?

Explanation: In cutoff, output voltage equals $V_{CC}$ (which corresponds to Logic 1 in some definitions, but collector current is zero, representing the 'off' state / Logic 0 output depending on pull-up/pull-down conventions).

7. Calculate $$I_{C}$$ if $\$\alpha$ = 0.98$, $$I_{E}$ = 5\text{ mA}$, and $I_{CBO} = 10\text{ }\mu\text{A}$.

Explanation: Using $$I_{C}$ = \$\alpha$ $I_{E}$ + I_{CBO} = 0.98 \times 5\text{ mA} + 0.01\text{ mA} = 4.90\text{ mA} + 0.01\text{ mA} = 4.91\text{ mA}$.

8. Which of the following describes the Common Collector configuration correctly?

Explanation: Common Collector provides high input resistance and a voltage gain of approximately unity ($\approx 1$).

9. Positive feedback in an oscillator circuit ensures that:

Explanation: Positive feedback feeds energy back in phase with the original signal to overcome losses and maintain sustained oscillations.

10. Why is the base region of a bipolar junction transistor made very thin and lightly doped?

Explanation: A thin and lightly doped base minimizes electron-hole recombination so that most injected carriers reach the collector.
