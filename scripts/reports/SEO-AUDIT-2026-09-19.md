## Top 3 fixes (do these first)

1. `npm run generate:sitemaps` — clears 308 duplicates (english/geography listed in
   both sitemap-main.xml and their subject sitemaps) and picks up the 25 missing
   hub pages (art/*, agriculture/, home-science/). Note `sitemap.xml` (index)
   is only half-regenerated: english/geography entries lack `SITEMAP_ORDER` entries
   in `scripts/seo-policy.cjs` (audit flags them as `sitemap-index-unmanaged-file`).
2. Restore a `/commerce/` hub page (or add a `_redirects`/`firebase.json` rewrite);
   383 commerce pages breadcrumb-link to it and the link 404s.
3. Repair breadcrumbs on hindi pages pointing at the missing `hindi/bhashavigyan/`
   hub (restore page, or point breadcrumbs at an existing parent) — 105 schema errors.

## Secondary items

- Add `og:image` (e.g. `/assets/icons/icon-512x512.png`) to the 491 commerce pages.
- Trim long titles/descriptions (generator templates add boilerplate suffixes:
  "Study Notes, MCQs, Revision & Topic Test | <Subject> | SJ Maths").
- Deduplicate H1s in ahc-ro-aro templates (section heading + content H1).
- sitemap.xml contains entries with `lastmod` on only 2 of 23 children — harmless
  but inconsistent; `generate-sitemaps.cjs` never emits child lastmod.
- Remove legacy `meta name="keywords"` (4,099 pages; ignored by engines, minor weight).
- Delete repo debris that risks deployment: `debug.log`, `english-gen.err.log`,
  `english-gen.log`, `admin-data-viewer.html` (570 KB tool page; robots-blocked but
  still deployed), stale `content-generation-status*.json` trackers.
- GA4 replaces UA (`gtag.js` referenced but absent) — analytics, not ranking.

## Non-issues (verified, no action)

- 404 page: noindexed ✅; ensure host serves real HTTP 404 status for unknown paths.
- Site is static & prerendered — no client-side-only content risk.
- Clean URLs via `firebase.json cleanUrls` + Cloudflare `_redirects` — consistent
  with extensionless canonicals.
- `llms.txt`, IndexNow script, PWA manifest all present and well-formed.
