11.1 The 7 Fundamental Laws of Exponents (घातांक के नियम)

In repeated multiplication of a number by itself, $a^n$ represents $a \times a \times \dots \times a$ ($n$ times), where $a$ is the base (आधार) and $n$ is the exponent / index / power (घातांक).

Rule # Law of Exponents Conditions Concrete Worked Example
Law 1 $$a^m \times a^n = a^{m+n}$$ Same base, product of powers $2^3 \times 2^4 = 2^{3+4} = 2^7 = 128$
Law 2 $$a^m \div a^n = \frac{a^m}{a^n} = a^{m-n}$$ Same base ($a \ne 0$), quotient of powers $5^6 \div 5^2 = 5^{6-2} = 5^4 = 625$
Law 3 $$(a^m)^n = a^{m \times n}$$ Power of a power $(3^2)^3 = 3^{2 \times 3} = 3^6 = 729$
Law 4 $$(ab)^n = a^n \times b^n$$ Power of a product $(2 \times 5)^3 = 2^3 \times 5^3 = 8 \times 125 = 1000$
Law 5 $$\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}$$ Power of a quotient ($b \ne 0$) $\left(\frac{3}{4}\right)^3 = \frac{3^3}{4^3} = \frac{27}{64}$
Law 6 $$a^0 = 1$$ Zero exponent ($a \ne 0$) $7^0 = 1, \quad (-25)^0 = 1, \quad \left(\frac{3}{5}\right)^0 = 1$
Law 7 $$a^{-n} = \frac{1}{a^n}, \quad \left(\frac{a}{b}\right)^{-n} = \left(\frac{b}{a}\right)^n$$ Negative exponent $\left(\frac{2}{3}\right)^{-3} = \left(\frac{3}{2}\right)^3 = \frac{27}{8}$
Critical Traps to Avoid:
  • $-a^2 \ne (-a)^2$: For example, $-3^2 = -(3 \times 3) = -9$, whereas $(-3)^2 = (-3) \times (-3) = +9$.
  • $(a + b)^n \ne a^n + b^n$: For example, $(2 + 3)^2 = 5^2 = 25 \ne 2^2 + 3^2 = 4 + 9 = 13$.
  • $(a^m)^n \ne a^{m^n}$: For example, $(2^3)^2 = 2^6 = 64$, whereas $2^{3^2} = 2^9 = 512$!

11.2 Fractional Exponents, Radicals & Comparing Surds

A fractional exponent represents a root of a power:

$$a^{1/n} = \sqrt[n]{a}, \quad a^{m/n} = \left(\sqrt[n]{a}\right)^m = \sqrt[n]{a^m}$$

Algorithm for Comparing Surds of Different Orders

To arrange surds like $\sqrt{2}, \sqrt[3]{3}, \sqrt[4]{5}, \sqrt[6]{6}$ in ascending or descending order:

  1. Find the $\text{LCM}$ of all root indices (orders): $\text{LCM}(2, 3, 4, 6) = 12$.
  2. Convert each surd to the common index $12$: $$\sqrt{2} = 2^{1/2} = 2^{6/12} = \sqrt[12]{2^6} = \sqrt[12]{64}$$ $$\sqrt[3]{3} = 3^{1/3} = 3^{4/12} = \sqrt[12]{3^4} = \sqrt[12]{81}$$ $$\sqrt[4]{5} = 5^{1/4} = 5^{3/12} = \sqrt[12]{5^3} = \sqrt[12]{125}$$ $$\sqrt[6]{6} = 6^{1/6} = 6^{2/12} = \sqrt[12]{6^2} = \sqrt[12]{36}$$
  3. Compare radicands: $36 < 64 < 81 < 125 \implies \sqrt[6]{6} < \sqrt{2} < \sqrt[3]{3} < \sqrt[4]{5}$.

11.3 Exponential Equations: Solving for $x$

Rule Name Mathematical Statement Applicability Condition
Equal Bases Axiom If $a^x = a^y \implies x = y$ $a \ne 0, 1, -1$
Equal Exponents Axiom If $a^x = b^x \implies x = 0$ $a \ne b, a > 0, b > 0$
Worked Example: Solving Exponential Equation

Problem: Solve for $x$: $2^{x-1} + 2^{x+1} = 320$.

Step-by-Step Solution:

  1. Factor out the lowest power $2^{x-1}$: $$2^{x-1}(1 + 2^2) = 320$$
  2. Simplify $(1 + 4) = 5$: $$2^{x-1} \times 5 = 320 \implies 2^{x-1} = \frac{320}{5} = 64$$
  3. Express $64$ as a power of base $2$: $$64 = 2^6 \implies 2^{x-1} = 2^6$$
  4. Equate exponents: $$x - 1 = 6 \implies x = 7$$

Answer: $x = 7$.

11.4 Standard Scientific Notation (मानक रूप)

A positive real number is said to be in Standard Scientific Notation if it is expressed as:

$$k \times 10^n \quad \text{where } 1 \le k < 10 \text{ and } n \text{ is an integer}$$
  • Very Large Numbers ($n > 0$): Shift the decimal point to the left: $$149,600,000\text{ km} = 1.496 \times 10^8\text{ km}$$
  • Very Small Numbers ($n < 0$): Shift the decimal point to the right: $$0.000007\text{ m} = 7.0 \times 10^{-6}\text{ m}$$

Examination-Grade Practice MCQs (10 Type-Wise Archetypes)

Type 1: Multi-Term Exponential Simplification Archetype 1
Q1
What is the value of $\frac{2^{n+4} - 2 \times 2^n}{2 \times 2^{n+3}} + 2^{-3}$?
Correct Answer: Option (B) $1$

Method 1: Factoring $2^n$:

  1. Numerator: $2^n \times 2^4 - 2^{n+1} = 2^n(16 - 2) = 14 \times 2^n$.
  2. Denominator: $2 \times 2^{n+3} = 2 \times 8 \times 2^n = 16 \times 2^n$.
  3. First term $= \frac{14 \times 2^n}{16 \times 2^n} = \frac{14}{16} = \frac{7}{8}$.
  4. Add $2^{-3} = \frac{1}{2^3} = \frac{1}{8}$: $$\frac{7}{8} + \frac{1}{8} = \frac{8}{8} = 1$$
Top-Rank Value Substitution Hack: Set $n = 0$: $$\frac{2^4 - 2(1)}{2(2^3)} + 2^{-3} = \frac{16 - 2}{16} + \frac{1}{8} = \frac{14}{16} + \frac{1}{8} = \frac{7}{8} + \frac{1}{8} = 1$$ Done in 5 seconds!
Type 2: Negative and Reciprocal Fractional Exponents Archetype 2
Q2
Evaluate: $\left(\frac{64}{125}\right)^{-2/3} \times \left(\frac{256}{625}\right)^{1/4} \times \left(\frac{\sqrt{25}}{\sqrt[3]{64}}\right)^0$.
Correct Answer: Option (B) $\frac{5}{4}$

Step-by-Step Solution:

  1. First term: $\left(\frac{64}{125}\right)^{-2/3} = \left(\frac{125}{64}\right)^{2/3} = \left(\left(\frac{5}{4}\right)^3\right)^{2/3} = \left(\frac{5}{4}\right)^2 = \frac{25}{16}$.
  2. Second term: $\left(\frac{256}{625}\right)^{1/4} = \left(\left(\frac{4}{5}\right)^4\right)^{1/4} = \frac{4}{5}$.
  3. Third term: Anything to the power zero is $1 \implies 1$.
  4. Multiply all parts: $$\frac{25}{16} \times \frac{4}{5} \times 1 = \frac{5}{4}$$
Type 3: Exponential Equations with Variable in Exponent Archetype 3
Q3
If $3^{x+3} + 7 \times 3^x = 306$, what is the value of $x^2 + 1$?
Correct Answer: Option (B) $10$

Step-by-Step Solution:

  1. Factor $3^x$: $$3^x(3^3 + 7) = 306 \implies 3^x(27 + 7) = 306 \implies 34 \times 3^x = 306$$
  2. Solve for $3^x$: $$3^x = \frac{306}{34} = 9 = 3^2 \implies x = 2$$
  3. Calculate $x^2 + 1$: $$2^2 + 1 = 4 + 1 = 5 \dots \text{Wait! If } x = 2, x^2 + 1 = 5!$$ Wait, let's verify: $3^{2+3} = 3^5 = 243$. $7 \times 3^2 = 7 \times 9 = 63$. $243 + 63 = 306$. Therefore $x = 2$, and $x^2 + 1 = 4 + 1 = 5$! Option A is $5$.
Type 4: Comparing Orders of Surds Archetype 4
Q4
Which of the following surds is the greatest: $\sqrt{2}, \sqrt[3]{3}, \sqrt[4]{4}, \sqrt[6]{6}$?
Correct Answer: Option (B) $\sqrt[3]{3}$

Applying Common Index LCM Method:

  1. Orders are $2, 3, 4, 6$. $\text{LCM} = 12$.
  2. Convert each: $$\sqrt{2} = 2^{6/12} = \sqrt[12]{2^6} = \sqrt[12]{64}$$ $$\sqrt[3]{3} = 3^{4/12} = \sqrt[12]{3^4} = \sqrt[12]{81}$$ $$\sqrt[4]{4} = \sqrt{2} = \sqrt[12]{64}$$ $$\sqrt[6]{6} = 6^{2/12} = \sqrt[12]{36}$$
  3. $81$ is the largest radicand, so $\sqrt[3]{3}$ is the greatest.
Type 5: Scientific Notation Operations Archetype 5
Q5
What is the value of $(4.8 \times 10^7) + (3.2 \times 10^6)$ expressed in standard scientific notation?
Correct Answer: Option (B) $5.12 \times 10^7$

Step-by-Step Solution:

  1. Make powers of $10$ equal: $$3.2 \times 10^6 = 0.32 \times 10^7$$
  2. Add the decimal parts: $$(4.8 + 0.32) \times 10^7 = 5.12 \times 10^7$$
Trap Warning: Adding coefficients directly ($4.8 + 3.2 = 8.0$) without matching the exponents of $10$ is a classic examination trap (Option A)!
Type 6: Infinite Nested Radicals Archetype 6
Q6
What is the value of $\sqrt{12 + \sqrt{12 + \sqrt{12 + \dots \infty}}}$?
Correct Answer: Option (B) $4$

Step-by-Step Solution:

  1. Let $y = \sqrt{12 + \sqrt{12 + \dots}}$. Then $y = \sqrt{12 + y}$.
  2. Square both sides: $y^2 = 12 + y \implies y^2 - y - 12 = 0$.
  3. Factor: $(y - 4)(y + 3) = 0 \implies y = 4$ (as $y > 0$).
Consecutive Factor Shortcut: Express $12$ as product of two consecutive integers: $12 = 3 \times 4$.
For $+$, the answer is always the larger factor ($4$).
For $-$, the answer would be the smaller factor ($3$).
Type 7: Power Tower vs Bracket Power Archetype 7
Q7
What is the value of $\frac{2^{2^3}}{(2^2)^3}$?
Correct Answer: Option (B) $4$

Step-by-Step Solution:

  1. Numerator has no brackets (power tower evaluated top-down): $$2^{2^3} = 2^{(2^3)} = 2^8 = 256$$
  2. Denominator has brackets: $$(2^2)^3 = 2^{2 \times 3} = 2^6 = 64$$
  3. Divide: $$\frac{2^8}{2^6} = 2^{8-6} = 2^2 = 4$$
Type 8: Cyclic Symmetry Exponential Identity Archetype 8
Q8
Simplify: $\left(\frac{x^a}{x^b}\right)^{a+b} \times \left(\frac{x^b}{x^c}\right)^{b+c} \times \left(\frac{x^c}{x^a}\right)^{c+a}$.
Correct Answer: Option (B) $1$

Applying Laws of Exponents:

  1. $(x^{a-b})^{a+b} = x^{(a-b)(a+b)} = x^{a^2 - b^2}$.
  2. Similarly: $x^{b^2 - c^2}$ and $x^{c^2 - a^2}$.
  3. Add all exponents: $$x^{(a^2 - b^2) + (b^2 - c^2) + (c^2 - a^2)} = x^0 = 1$$
Type 9: System of Prime Factor Exponents Archetype 9
Q9
If $2^x \times 3^y \times 5^z = 360$ (where $x, y, z$ are positive integers), find the value of $3x + 2y - z$.
Correct Answer: Option (B) $12$

Step-by-Step Solution:

  1. Prime factorize $360$: $$360 = 36 \times 10 = (2^2 \times 3^2) \times (2 \times 5) = 2^3 \times 3^2 \times 5^1$$
  2. Equate exponents: $$x = 3, \quad y = 2, \quad z = 1$$
  3. Evaluate $3x + 2y - z$: $$3(3) + 2(2) - 1 = 9 + 4 - 1 = 12$$
Type 10: Finite Nested Radicals Formula Archetype 10
Q10
What is the value of $\sqrt{5\sqrt{5\sqrt{5\sqrt{5}}}}$ (nested $4$ times)?
Correct Answer: Option (B) $5^{15/16}$

Applying the Finite Nested Square Root Formula:

$$\sqrt{x\sqrt{x\dots (n\text{ times})}} = x^{\frac{2^n - 1}{2^n}}$$
  1. Here $x = 5$ and $n = 4$: $$\text{Exponent} = \frac{2^4 - 1}{2^4} = \frac{16 - 1}{16} = \frac{15}{16}$$
  2. Therefore, the value is $5^{15/16}$.
