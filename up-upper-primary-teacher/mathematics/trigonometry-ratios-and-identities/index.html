23.2 Fundamental Identities & Reciprocal Conjugate Hacks

Pythagorean Identity Transformed Equivalent Forms Super Exam Speed Hack
$\sin^2 \theta + \cos^2 \theta = 1$ $\sin^2 \theta = 1 - \cos^2 \theta$
$\cos^2 \theta = 1 - \sin^2 \theta$		 $|\sin \theta| \le 1, \; |\cos \theta| \le 1$
$\sec^2 \theta - \tan^2 \theta = 1$ $\sec^2 \theta = 1 + \tan^2 \theta$
$\tan^2 \theta = \sec^2 \theta - 1$		 $\mathbf{\sec \theta + \tan \theta = k \iff \sec \theta - \tan \theta = \frac{1}{k}}$
$\csc^2 \theta - \cot^2 \theta = 1$ $\csc^2 \theta = 1 + \cot^2 \theta$
$\cot^2 \theta = \csc^2 \theta - 1$		 $\mathbf{\csc \theta + \cot \theta = m \iff \csc \theta - \cot \theta = \frac{1}{m}}$
The Golden sec/tan Value Hack:
$$\text{If } \sec \theta + \tan \theta = k \implies \sec \theta = \frac{k^2 + 1}{2k}, \quad \tan \theta = \frac{k^2 - 1}{2k}, \quad \sin \theta = \frac{k^2 - 1}{k^2 + 1}$$

Example: If $\sec \theta + \tan \theta = 3$, immediately $\cos \theta = \frac{2k}{k^2 + 1} = \frac{6}{10} = \frac{3}{5}$, and $\sin \theta = \frac{8}{10} = \frac{4}{5}$. Solved in 5 seconds without writing any quadratic equation!

Type 1: Ratio Finding via Pythagorean Triplet Archetype 1
Q1
If $\sin \theta = \frac{3}{5}$ (where $\theta$ is an acute angle), what is the value of $\frac{\tan \theta + \sec \theta}{\cot \theta}$?
Correct Answer: Option (B) $\frac{3}{2}$

Step-by-Step Solution:

  1. $\sin \theta = \frac{P}{H} = \frac{3}{5}$. By Pythagorean triplet $(3, 4, 5)$, base $B = 4$.
  2. $\tan \theta = \frac{P}{B} = \frac{3}{4}$, $\sec \theta = \frac{H}{B} = \frac{5}{4}$, $\cot \theta = \frac{B}{P} = \frac{4}{3}$.
  3. Numerator: $\tan \theta + \sec \theta = \frac{3}{4} + \frac{5}{4} = \frac{8}{4} = 2$.
  4. Expression: $\frac{2}{\cot \theta} = \frac{2}{4/3} = 2 \times \frac{3}{4} = \frac{3}{2}$.
Type 2: Standard Angle Evaluation Archetype 2
Q2
Evaluate: $\frac{5\cos^2 60^\circ + 4\sec^2 30^\circ - \tan^2 45^\circ}{\sin^2 30^\circ + \cos^2 30^\circ}$.
Correct Answer: Option (B) $\frac{67}{12}$

Step-by-Step Solution:

  1. Denominator: $\sin^2 30^\circ + \cos^2 30^\circ = 1$ (by Pythagorean identity).
  2. Numerator: $$5\left(\frac{1}{2}\right)^2 + 4\left(\frac{2}{\sqrt{3}}\right)^2 - 1^2 = 5\left(\frac{1}{4}\right) + 4\left(\frac{4}{3}\right) - 1 = \frac{5}{4} + \frac{16}{3} - 1$$ $$= \frac{15 + 64 - 12}{12} = \frac{67}{12}$$
Type 3: $\sec \theta + \tan \theta$ Reciprocal Shortcut Archetype 3
Q3
If $\sec \theta + \tan \theta = 5$, what is the value of $\sin \theta$?
Correct Answer: Option (B) $\frac{12}{13}$

Top-Rank Speed Hack:

$$\sec \theta + \tan \theta = k \implies \sin \theta = \frac{k^2 - 1}{k^2 + 1}$$ $$\sin \theta = \frac{5^2 - 1}{5^2 + 1} = \frac{25 - 1}{25 + 1} = \frac{24}{26} = \frac{12}{13}$$

Solved in 3 seconds!

Type 4: $\csc \theta + \cot \theta$ Reciprocal Shortcut Archetype 4
Q4
If $\csc \theta - \cot \theta = \frac{1}{3}$, what is the value of $\cos \theta$?
Correct Answer: Option (B) $\frac{4}{5}$

Step-by-Step Solution:

  1. Given $\csc \theta - \cot \theta = \frac{1}{3} \implies \csc \theta + \cot \theta = 3$.
  2. Add both equations: $2\csc \theta = 3 + \frac{1}{3} = \frac{10}{3} \implies \csc \theta = \frac{5}{3} \implies \sin \theta = \frac{3}{5}$.
  3. By Pythagorean triplet $(3, 4, 5)$, $\cos \theta = \frac{4}{5}$.
Type 5: Complementary Angle Pair Simplification Archetype 5
Q5
Find the value of: $\frac{\sin 35^\circ}{\cos 55^\circ} + \frac{\cos 55^\circ}{\sin 35^\circ} - 2\cos 60^\circ$.
Correct Answer: Option (B) $1$

Step-by-Step Solution:

  1. $\cos 55^\circ = \sin(90^\circ - 55^\circ) = \sin 35^\circ$.
  2. Therefore, $\frac{\sin 35^\circ}{\cos 55^\circ} = 1$ and $\frac{\cos 55^\circ}{\sin 35^\circ} = 1$.
  3. $2\cos 60^\circ = 2\left(\frac{1}{2}\right) = 1$.
  4. $\text{Expression} = 1 + 1 - 1 = 1$.
Type 6: Chain Product of Tangents Archetype 6
Q6
What is the value of $\tan 10^\circ \cdot \tan 25^\circ \cdot \tan 45^\circ \cdot \tan 65^\circ \cdot \tan 80^\circ$?
Correct Answer: Option (B) $1$

Top-Rank Speed Hack:

  • $\tan 10^\circ \cdot \tan 80^\circ = \tan 10^\circ \cdot \cot 10^\circ = 1$
  • $\tan 25^\circ \cdot \tan 65^\circ = \tan 25^\circ \cdot \cot 25^\circ = 1$
  • $\tan 45^\circ = 1$
$$\text{Product} = 1 \times 1 \times 1 = 1$$
Type 7: Complementary Squared Sine Chain Archetype 7
Q7
Evaluate: $\sin^2 10^\circ + \sin^2 20^\circ + \sin^2 30^\circ + \dots + \sin^2 80^\circ$.
Correct Answer: Option (B) $4$

Pairing Complementary Sines:

  • $\sin^2 10^\circ + \sin^2 80^\circ = \sin^2 10^\circ + \cos^2 10^\circ = 1$
  • $\sin^2 20^\circ + \sin^2 70^\circ = 1$
  • $\sin^2 30^\circ + \sin^2 60^\circ = 1$
  • $\sin^2 40^\circ + \sin^2 50^\circ = 1$
$$\text{Total Sum} = 1 + 1 + 1 + 1 = 4$$
Type 8: Identity Simplification Archetype 8
Q8
Simplify: $\frac{\sin \theta}{1 + \cos \theta} + \frac{1 + \cos \theta}{\sin \theta}$.
Correct Answer: Option (B) $2\csc \theta$

Step-by-Step Simplification:

$$\text{LHS} = \frac{\sin^2 \theta + (1 + \cos \theta)^2}{\sin \theta(1 + \cos \theta)} = \frac{\sin^2 \theta + 1 + 2\cos \theta + \cos^2 \theta}{\sin \theta(1 + \cos \theta)}$$ $$= \frac{(\sin^2 \theta + \cos^2 \theta) + 1 + 2\cos \theta}{\sin \theta(1 + \cos \theta)} = \frac{1 + 1 + 2\cos \theta}{\sin \theta(1 + \cos \theta)} = \frac{2(1 + \cos \theta)}{\sin \theta(1 + \cos \theta)} = \frac{2}{\sin \theta} = 2\csc \theta$$
Type 9: Heights & Distances (Shadow Problem) Archetype 9
Q9
If the length of the shadow of a vertical pole is $\sqrt{3}$ times its height, what is the angle of elevation of the sun?
Correct Answer: Option (B) $30^\circ$

Top-Rank Speed Hack:

$$\tan \theta = \frac{\text{Height}}{\text{Shadow}} = \frac{h}{h\sqrt{3}} = \frac{1}{\sqrt{3}} \implies \theta = 30^\circ$$
Type 10: Maximum and Minimum Values Archetype 10
Q10
What is the maximum value of the expression $3\sin \theta + 4\cos \theta$?
Correct Answer: Option (B) $5$

Universal Max/Min Formula:

For any linear combination $a\sin \theta + b\cos \theta$:

$$\text{Maximum Value} = +\sqrt{a^2 + b^2} = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$ $$\text{Minimum Value} = -\sqrt{a^2 + b^2} = -5$$

Examiner Trap: Blindly adding $3 + 4 = 7$ (Option A)! Sine and cosine cannot reach their peak value of $1$ simultaneously at the same angle.
