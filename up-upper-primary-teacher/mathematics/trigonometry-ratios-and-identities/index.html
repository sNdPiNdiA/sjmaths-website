1. Fundamental Axioms, Definitions & Foundational Properties

Right-Angled Triangle Axiom: Trigonometric ratios are defined exclusively for acute angles $ heta$ within a right-angled triangle $ riangle ABC$ where $angle B = 90^circ$, establishing a direct link between side lengths and angle measures.
Sine Ratio Definition ($sin heta$): The ratio of the length of the side opposite to angle $ heta$ to the length of the hypotenuse: $sin heta = rac{ ext{Opposite}}{ ext{Hypotenuse}} = rac{BC}{AC}$.
Cosine Ratio Definition ($cos heta$): The ratio of the length of the side adjacent to angle $ heta$ to the length of the hypotenuse: $cos heta = rac{ ext{Adjacent}}{ ext{Hypotenuse}} = rac{AB}{AC}$.
Tangent Ratio Definition ($ an heta$): The ratio of the sine of angle $ heta$ to the cosine of angle $ heta$, equivalently expressed as $ an heta = rac{sin heta}{cos heta} = rac{ ext{Opposite}}{ ext{Adjacent}} = rac{BC}{AB}$.
Reciprocal Ratios: Cosecant ($csc heta = rac{1}{sin heta}$), Secant ($sec heta = rac{1}{cos heta}$), and Cotangent ($cot heta = rac{1}{ an heta}$) complete the six fundamental trigonometric ratios.
Exam Pro-Tip: Always sketch a quick right triangle on your rough sheet and label the given sides before applying ratios to prevent numerator-denominator inversion errors.
Memory Mnemonic: PBM-HBH — Pandit Badri Prasad / Har Har Bole (Sine = P/H, Cosine = B/H, Tangent = P/B).

3. Word Problem Modeling & Practical Applications

Problem Type 1 (Height and Distance - Elevation): Modeling tower heights using $ an heta = rac{ ext{Height}}{ ext{Distance}}$. If shadow length equals pole height, angle of elevation is $45^circ$.
Problem Type 2 (Ladder against Wall): Modeling a ladder sliding or leaning against a vertical wall using $cos heta = rac{ ext{Distance from Wall}}{ ext{Ladder Length}}$.
Problem Type 3 (Composite Expression Simplification): Evaluating algebraic combinations of trigonometric ratios by substituting numerical values of standard angles directly without complex factorization.
Problem Type 4 (Identity Verification): Proving algebraic identities by converting all secant, cosecant, tangent, and cotangent terms into sine and cosine forms.
UP Exam High-Yield Tip: In questions featuring $sin 30^circ$, $cos 60^circ$, or complementary angle pairs like $ rac{sin 37^circ}{cos 53^circ}$, immediately check if the angle sum is $90^circ$ to instantly simplify the fraction to $1$.

4. Mathematical Edge Cases, Sign Conventions & Common Traps

Critical Distinction: $sin^2 heta$ represents $(sin heta)^2$, whereas $sin heta^2$ represents $sin( heta^2)$. Never confuse squaring the trigonometric ratio with squaring the angle argument.
Edge Case / Exception: $ an 90^circ$ and $sec 90^circ$ are undefined (approaching infinity) because $cos 90^circ = 0$, resulting in division by zero.
Common Calculation Trap: Assuming $sin(A + B) = sin A + sin B$. This is a severe algebraic fallacy; expansion requires compound angle formulas $sin A cos B + cos A sin B$.
Trap Prevention Trick: When solving identity proofs, always start with the more complex side (LHS or RHS) and simplify using $sin^2 heta + cos^2 heta = 1$ rather than working backwards from the conclusion.
Memory Mnemonic: CAST — Coordinate quadrant sign rule: All positive in Q1, Sine positive in Q2, Tan positive in Q3, Cosine positive in Q4.

1. What is the exact numerical value of the expression $ rac{sin 30^circ + an 45^circ - csc 60^circ}{sec 30^circ + cos 60^circ + cot 45^circ}$?

Correct Answer: Option A

Substitute standard values: $sin 30^circ = rac{1}{2}$, $ an 45^circ = 1$, $csc 60^circ = rac{2}{sqrt{3}}$, $sec 30^circ = rac{2}{sqrt{3}}$, $cos 60^circ = rac{1}{2}$, $cot 45^circ = 1$. Numerator = $ rac{1}{2} + 1 - rac{2}{sqrt{3}} = rac{3}{2} - rac{2}{sqrt{3}} = rac{3sqrt{3}-4}{2sqrt{3}}$. Denominator = $ rac{2}{sqrt{3}} + rac{1}{2} + 1 = rac{3}{2} + rac{2}{sqrt{3}} = rac{3sqrt{3}+4}{2sqrt{3}}$. Dividing numerator by denominator yields $ rac{3sqrt{3}-4}{3sqrt{3}+4}$. Option 0 is correct.

Question 2 of 10 Super TET Junior Mathematics

2. If $sin heta + cos heta = sqrt{2}cos heta$, what is the exact value of $ an heta$?

Correct Answer: Option A

Given $sin heta + cos heta = sqrt{2}cos heta$. Subtract $cos heta$ from both sides: $sin heta = (sqrt{2}-1)cos heta$. Divide both sides by $cos heta$: $ rac{sin heta}{cos heta} = sqrt{2}-1$. Therefore, $ an heta = sqrt{2}-1$. Option 0 is correct.

Question 3 of 10 Super TET Junior Mathematics

3. If $5 an heta = 4$, what is the value of $ rac{5sin heta - 3cos heta}{5sin heta + 3cos heta}$?

Correct Answer: Option A

Given $5 an heta = 4 implies an heta = rac{4}{5}$. Divide every term in the expression by $cos heta$: $ rac{5(sin heta/cos heta) - 3}{5(sin heta/cos heta) + 3} = rac{5 an heta - 3}{5 an heta + 3}$. Substitute $ an heta = rac{4}{5}$: $ rac{5(4/5) - 3}{5(4/5) + 3} = rac{4 - 3}{4 + 3} = rac{1}{7}$. Option 0 is correct.

Question 4 of 10 Super TET Junior Mathematics

4. Simplify the trigonometric expression: $sin^2 25^circ + sin^2 65^circ$.

Correct Answer: Option A

Since $25^circ + 65^circ = 90^circ$, the angles are complementary. Rewrite $sin 65^circ$ as $sin(90^circ - 25^circ) = cos 25^circ$. Thus, $sin^2 25^circ + sin^2 65^circ = sin^2 25^circ + cos^2 25^circ = 1$ using the fundamental identity $sin^2 heta + cos^2 heta = 1$. Option 0 is correct.

Question 5 of 10 Super TET Junior Mathematics

5. What is the value of $ an 1^circ an 2^circ an 3^circ dots an 89^circ$?

Correct Answer: Option A

Pair the terms using complementary relations: $ an 1^circ = cot 89^circ = rac{1}{ an 89^circ}$, $ an 2^circ = rac{1}{ an 88^circ}$, and so on. Middle term is $ an 45^circ = 1$. All paired terms cancel out to 1. Option 0 is correct.

Question 6 of 10 Super TET Junior Mathematics

6. If $sec heta + an heta = x$, what is the value of $sec heta - an heta$?

Correct Answer: Option A

We know the fundamental identity $sec^2 heta - an^2 heta = 1$, which factors as $(sec heta + an heta)(sec heta - an heta) = 1$. Substituting $x$ for $(sec heta + an heta)$ gives $x(sec heta - an heta) = 1$, so $(sec heta - an heta) = rac{1}{x}$. Option 0 is correct.

Question 7 of 10 Super TET Junior Mathematics

7. Evaluate: $ rac{cos 45^circ}{sec 30^circ + csc 30^circ}$.

Correct Answer: Option A

Substitute values: $cos 45^circ = rac{1}{sqrt{2}}$, $sec 30^circ = rac{2}{sqrt{3}}$, $csc 30^circ = 2$. Denominator = $ rac{2}{sqrt{3}} + 2 = rac{2 + 2sqrt{3}}{sqrt{3}}$. Expression becomes $ rac{1}{sqrt{2}} imes rac{sqrt{3}}{2(1+sqrt{3})} = rac{sqrt{3}}{2sqrt{2}(1+sqrt{3})}$. Rationalizing gives $ rac{sqrt{6}-sqrt{2}}{8}$. Option 0 is correct.

Question 8 of 10 Super TET Junior Mathematics

8. If $x = a sec heta$ and $y = b an heta$, what is the value of $ rac{x^2}{a^2} - rac{y^2}{b^2}$?

Correct Answer: Option A

From the given equations, $ rac{x}{a} = sec heta$ and $ rac{y}{b} = an heta$. Squaring both gives $ rac{x^2}{a^2} = sec^2 heta$ and $ rac{y^2}{b^2} = an^2 heta$. Subtracting them yields $sec^2 heta - an^2 heta = 1$. Option 0 is correct.

Question 9 of 10 Super TET Junior Mathematics

9. What is the maximum value of $ rac{1}{sec heta}$ for $0^circ le heta le 90^circ$?

Correct Answer: Option A

Notice that $ rac{1}{sec heta} = cos heta$. For the interval $0^circ le heta le 90^circ$, the cosine function ranges from $1$ (at $ heta = 0^circ$) down to $0$ (at $ heta = 90^circ$). Thus, the maximum value is $1$. Option 0 is correct.

High-Yield Rapid Recall Formulas & Laws (Must-Remember Pointers)

#1
Fundamental Pythagorean identity: $sin^2 heta + cos^2 heta = 1$ applies universally for all real acute angles.
#2
Secant-tangent identity: $1 + an^2 heta = sec^2 heta$ is derived by dividing $sin^2 heta + cos^2 heta = 1$ by $cos^2 heta$.
#3
Cosecant-cotangent identity: $1 + cot^2 heta = csc^2 heta$ is derived by dividing $sin^2 heta + cos^2 heta = 1$ by $sin^2 heta$.
#4
Complementary angle transformation: $sin(90^circ - heta) = cos heta$ and $ an(90^circ - heta) = cot heta$.
#5
Standard angle values for tangent: $ an 0^circ = 0$, $ an 30^circ = rac{1}{sqrt{3}}$, $ an 45^circ = 1$, $ an 60^circ = sqrt{3}$, $ an 90^circ = ext{Undefined}$.
#6
Reciprocal relationship rule: $sin heta cdot csc heta = 1$, $cos heta cdot sec heta = 1$, and $ an heta cdot cot heta = 1$.
#7
The maximum value of both $sin heta$ and $cos heta$ is exactly $1$, and their minimum value in real ranges is $-1$ (or $0$ for acute angles).
#8
Never confuse $sin^2 heta$ with $sin( heta^2)$; the exponent on trigonometric functions applies to the entire ratio value.
