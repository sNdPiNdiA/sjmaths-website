12.1 Variables (Literals) & Constants (चर एवं अचर राशियाँ)

In algebra, we use letters of the alphabet ($x, y, z, a, b, c$) in addition to real numbers to express mathematical relationships in generalized, universal forms.

Quantity Type Definition Standard Mathematical Symbol Real-World Example
Constants (अचर राशियाँ) A symbol having a fixed, immutable numerical value across all situations. $5, -12, \frac{3}{4}, \sqrt{2}, \pi$ Number of sides of a triangle ($3$); acceleration due to gravity ($9.8\text{ m/s}^2$).
Variables / Literals (चर राशियाँ) A symbol that can be assigned different numerical values depending on the context. $x, y, z, t, \theta$ Temperature of a city during the day; speed of a moving vehicle; age of a student.
The Fundamental Axiom of Algebra: Literal numbers obey all the arithmetic axioms of real numbers:
  • Commutative Property: $a + b = b + a$ and $a \times b = b \times a$.
  • Associative Property: $(a + b) + c = a + (b + c)$ and $(ab)c = a(bc)$.
  • Distributive Property: $a(b + c) = ab + ac$.

12.2 Powers of Literal Quantities (चर की घात)

When a literal number is multiplied by itself multiple times, the repeated product is written compactly using exponential notation:

$$x \times x \times x \times \dots \times x \quad (n\text{ times}) = x^n$$

In $x^n$, $x$ is the base (आधार) and $n$ is the exponent / power / index (घातांक).

Examiner's Favorite Trap: Coefficient vs Power!
  • $x + x + x = 3x$ (Multiplication: $3$ is the coefficient).
  • $x \times x \times x = x^3$ (Exponentiation: $3$ is the power).
  • $3x \ne x^3$: If $x = 2$, then $3(2) = 6$, but $2^3 = 8$!

12.3 Terms, Factors & Coefficients (पद, गुणनखण्ड एवं गुणांक)

1. Terms of an Algebraic Expression (बीजीय व्यंजक के पद)

The parts of an algebraic expression separated by $+$ or $-$ signs are called the terms of the expression. (Multiplication and division do NOT create separate terms; $4xy$ is a single term, and $\frac{a}{b}$ is a single term).

2. Numerical vs Literal Coefficients

In the term $-7x^2 y$:

  • Numerical Coefficient (संख्यात्मक गुणांक): $-7$. (Always include the negative sign!).
  • Literal Coefficient of $-7$: $x^2 y$.
  • Coefficient of $y$: $-7x^2$.
  • Coefficient of $x^2$: $-7y$.
Silent Coefficients: In the term $x$, the numerical coefficient is $+1$ ($1 \times x$). In $-x$, the numerical coefficient is $-1$ ($-1 \times x$). Never write coefficient as $0$!

12.4 Value of an Algebraic Expression by Substitution

To find the numerical value of an algebraic expression, replace each variable with its given numerical value and follow the standard BODMAS order of operations.

Worked Example: Substitution with Negative Powers

Problem: If $x = -2, y = 3, z = -1$, find the value of $3x^2 y - 2xy^2 + 4z^3$.

Step-by-Step Solution:

  1. Calculate powers first: $$x^2 = (-2)^2 = +4$$ $$y^2 = 3^2 = 9$$ $$z^3 = (-1)^3 = -1$$
  2. Evaluate each individual term: $$\text{Term 1: } 3x^2 y = 3(4)(3) = 36$$ $$\text{Term 2: } -2xy^2 = -2(-2)(9) = +36$$ $$\text{Term 3: } 4z^3 = 4(-1) = -4$$
  3. Sum all terms: $$36 + 36 - 4 = 72 - 4 = 68$$

Answer: $68$.

Examination-Grade Practice MCQs (10 Type-Wise Archetypes)

Type 1: Verbal to Algebraic Expression Translation Archetype 1
Q1
Which algebraic expression correctly represents the statement: "Five times the square of $x$ is decreased by the product of $3$ and the cube of $y$"?
Correct Answer: Option (B) $5x^2 - 3y^3$

Step-by-Step Translation:

  1. "Square of $x$" $= x^2$.
  2. "Five times the square of $x$" $= 5x^2$ (notice $5$ is outside the power, unlike $(5x)^2 = 25x^2$).
  3. "Cube of $y$" $= y^3$. "Product of $3$ and cube of $y$" $= 3y^3$.
  4. "Decreased by" indicates subtraction: $5x^2 - 3y^3$.
Type 2: Numerical and Literal Coefficients Archetype 2
Q2
In the algebraic expression $-\frac{3}{5} a^2 b c^3$, what is the numerical coefficient, and what is the coefficient of $a^2 c^3$?
Correct Answer: Option (B) $-\frac{3}{5}$ and $-\frac{3}{5}b$

Step-by-Step Analysis:

  1. The constant multiplier of the term is $-\frac{3}{5}$, so the numerical coefficient is $-\frac{3}{5}$.
  2. To find the coefficient of $a^2 c^3$, remove $a^2 c^3$ from the term: $$\left(-\frac{3}{5} b\right) \times (a^2 c^3) \implies \text{Coefficient is } -\frac{3}{5}b$$
Type 3: Like and Unlike Terms Identification Archetype 3
Q3
Which pair of algebraic terms represents like terms (सजातीय पद)?
Correct Answer: Option (B) $-5 p^2 q$ and $\frac{3}{4} q p^2$

Definition of Like Terms:

Terms are "like" if and only if their literal factors with corresponding exponents are strictly identical, regardless of their numerical coefficients or the order of variables ($p^2 q = q p^2$).

Type 4: Exponent and Power Operations on Literals Archetype 4
Q4
Simplify: $(-2x^2 y)^3 \times (3x y^3)^2$.
Correct Answer: Option (B) $-72 x^8 y^9$

Step-by-Step Solution:

  1. Evaluate first bracket: $$(-2x^2 y)^3 = (-2)^3 \times (x^2)^3 \times y^3 = -8 x^6 y^3$$
  2. Evaluate second bracket: $$(3xy^3)^2 = 3^2 \times x^2 \times (y^3)^2 = 9 x^2 y^6$$
  3. Multiply the two results: $$(-8 \times 9) \times (x^6 \times x^2) \times (y^3 \times y^6) = -72 x^{6+2} y^{3+6} = -72 x^8 y^9$$
Type 5: Multi-Variable Expression Evaluation Archetype 5
Q5
If $a = 1, b = -2, c = 3$, what is the numerical value of $a^3 + b^3 + c^3 - 3abc$?
Correct Answer: Option (B) $38$

Step-by-Step Solution:

  1. Calculate individual terms: $$a^3 = 1^3 = 1$$ $$b^3 = (-2)^3 = -8$$ $$c^3 = 3^3 = 27$$ $$-3abc = -3(1)(-2)(3) = +18$$
  2. Sum terms: $$1 + (-8) + 27 + 18 = 1 - 8 + 45 = 38$$
Identity Verification Hack: $a^3 + b^3 + c^3 - 3abc = (a+b+c)(a^2+b^2+c^2 - ab - bc - ca)$
$a+b+c = 1 - 2 + 3 = 2$.
$a^2+b^2+c^2 = 1 + 4 + 9 = 14$.
$-(ab+bc+ca) = -(-2 - 6 + 3) = -(-5) = +5$.
$\text{Value} = 2 \times (14 + 5) = 2 \times 19 = 38$!
Type 6: Sign Handling with Negative Literal Bases Archetype 6
Q6
What is the value of $(-1)^{101} + (-1)^{102} - (-1)^{103} + (-1)^{104}$?
Correct Answer: Option (B) $2$

Applying Sign Rules:

  • $(-1)^{101} = -1$ (since $101$ is odd).
  • $(-1)^{102} = +1$ (since $102$ is even).
  • $-(-1)^{103} = -(-1) = +1$ (since $103$ is odd).
  • $(-1)^{104} = +1$ (since $104$ is even).
$$\text{Sum} = (-1) + 1 + 1 + 1 = 2$$
Type 7: Combining and Grouping Like Terms Archetype 7
Q7
Simplify: $5a - [2b - (3a - \overline{4b - 2a})]$.
Correct Answer: Option (B) $10a - 6b$

Applying Vinculum and Bracket Simplification:

  1. Remove vinculum (bar bracket): $$-(4b - 2a) = -4b + 2a$$
  2. Inside parenthesis: $$3a - (4b - 2a) = 3a - 4b + 2a = 5a - 4b$$
  3. Inside square bracket: $$2b - (5a - 4b) = 2b - 5a + 4b = 6b - 5a$$
  4. Final subtraction: $$5a - (6b - 5a) = 5a - 6b + 5a = 10a - 6b$$
Type 8: Symmetrical Variable Evaluation Archetype 8
Q8
If $\frac{x}{y} = \frac{4}{5}$, what is the value of $\frac{5x - 2y}{7x + 2y}$?
Correct Answer: Option (B) $\frac{5}{19}$

Top-Rank Direct Substitution Hack:

Since the degree of every term in numerator and denominator is $1$ (homogeneous), directly substitute $x = 4$ and $y = 5$:

$$\text{Numerator} = 5(4) - 2(5) = 20 - 10 = 10$$ $$\text{Denominator} = 7(4) + 2(5) = 28 + 10 = 38$$ $$\text{Fraction} = \frac{10}{38} = \frac{5}{19}$$

Done in 5 seconds!

Type 9: Geometric Formulas Formulated as Literals Archetype 9
Q9
The side of an equilateral triangle is represented by $(2x - 3)\text{ cm}$. What algebraic expression represents its perimeter, and what is its perimeter when $x = 5.5$?
Correct Answer: Option (B) $6x - 9\text{ cm}; 24\text{ cm}$

Step-by-Step Solution:

  1. Perimeter of equilateral triangle $= 3 \times \text{side} = 3(2x - 3) = 6x - 9\text{ cm}$.
  2. For $x = 5.5$: $$\text{Perimeter} = 6(5.5) - 9 = 33 - 9 = 24\text{ cm}$$
Type 10: Examination Pitfall: Signs and Parentheses Archetype 10
Q10
What is the value of $-x^2 - (-x)^2 + (-x^3)$ when $x = -2$?
Correct Answer: Option (B) $0$

Meticulous Step-by-Step Evaluation:

  1. First term: $-x^2 = -((-2)^2) = -(4) = -4$.
  2. Second term: $-(-x)^2 = -(-(-2))^2 = -(2^2) = -4$.
  3. Third term: $+(-x^3) = -((-2)^3) = -(-8) = +8$.
  4. Sum: $-4 - 4 + 8 = -8 + 8 = 0$.
Trap Warning: Notice that $-x^2$ means $-(x^2)$. A negative sign in front of a variable is applied AFTER evaluating the exponent!
