1. Fundamental Axioms, Definitions & Foundational Properties

Constant Axiom: A constant is a fixed numerical value that does not change under any mathematical operation, represented by numbers like $5$, $-\frac{3}{7}$, $\pi$, or $e$.
Variable Axiom: A variable is a symbol, typically represented by letters like $x, y, z, a, b, c$, that can take various numerical values within a specified domain.
Algebraic Expression: A combination of constants and variables connected by fundamental arithmetic operations ($+, -, \times, \div$) with a finite number of terms, such as $3x^2 - 5xy + 7$.
Degree of a Polynomial: The highest power of the variable present in a non-zero polynomial expression in a single variable. For $4x^5 - 3x^2 + 7$, the degree is $5$.
Exam Pro-Tip: Always check if a given expression is a polynomial; variables cannot have negative exponents, fractional exponents, or appear inside radicals in polynomial terms.
Memory Mnemonic: CVP — Constants are Value-fixed, Parameters/Variables are Plastic.

2. Formulas, Standard Theorems & Algorithmic Procedures

Category / CaseFormula / Mathematical RuleTopper Calculation Shortcut
Product Rule of Exponents$a^m \times a^n = a^{m+n}$Add exponents directly when bases are identical.
Quotient Rule of Exponents$\frac{a^m}{a^n} = a^{m-n}$ ($a \neq 0$)Subtract denominator exponent from numerator exponent.
Power of a Power Rule: $(a^m)^n = a^{m \times n}$. Multiply the exponents when raising a power to another power.
Zero Exponent Property: $a^0 = 1$ for any non-zero real number $a \neq 0$. Note that $0^0$ is an indeterminate form.
Negative Exponent Law: $a^{-n} = \frac{1}{a^n}$ and $\frac{1}{a^{-n}} = a^n$, enabling reciprocal shifting of terms.
15-Second Speed-Math Trick: When evaluating expressions like $\frac{2^{15} \times 2^5}{2^{18}}$, combine exponents using $15 + 5 - 18 = 2$, yielding $2^2 = 4$ instantly without expanding large powers.

3. Word Problem Modeling & Practical Applications

Translating Sentences to Algebra: 'Five times a number decreased by seven' translates directly to $5x - 7$. 'The sum of consecutive integers' translates to $x, (x+1), (x+2)$.
Age Problems Modeling: If Father's age is 3 times son's age, and after 10 years it becomes twice, set up equation: $3x + 10 = 2(x + 10)$, solving for $x = 10$.
Perimeter and Area Expressions: Rectangular garden with length $l = 2x + 3$ and breadth $b = x - 1$ has perimeter $P = 2((2x+3) + (x-1)) = 6x + 4$.
SCERT UP Textbook Standard: Class 8 algebra problems frequently test substitution. Given $x = -2$, evaluate $3x^3 - 4x^2 + 2x - 5$ by plugging in values systematically.
UP Exam High-Yield Tip: In word problems asking for 'how much more', always subtract the smaller algebraic expression from the larger one, wrapping the subtracted expression in parentheses to avoid sign errors.

4. Mathematical Edge Cases, Sign Conventions & Common Traps

Like vs Unlike Terms: Only like terms (terms with identical variable parts and exact corresponding powers) can be combined via addition or subtraction ($3x^2y$ and $-5x^2y$ are like; $3x^2y$ and $3xy^2$ are unlike).
Division by Variable Trap: Never cancel a variable term $x$ from both sides of an equation unless you establish that $x \neq 0$, otherwise you lose the root $x = 0$.
Negative Sign Distribution: When a minus sign precedes a parenthesis, e.g., $-(3x - 5)$, every term inside changes sign: $-3x + 5$. Failing to distribute is a prime negative-marking trap.
Trap Prevention Trick: Always substitute a simple test value like $x = 1$ or $x = 2$ into both your simplified algebraic expression and the original expression to verify equivalence before marking your answer.
Memory Mnemonic: SIGN — Subtracting/Substituting Inside Gives Negation changes.

Question 1 of 10 Super TET Junior Mathematics

1. What is the degree of the algebraic expression $5x^4y^2 - 3x^6 + 7xy^7 - 9$?

Correct Answer: Option C

The degree of a term is the sum of its variable exponents. The four term degrees are 4+2=6, 6, 1+7=8, and 0. The greatest is 8, so the answer is Option C.

Question 2 of 10 Super TET Junior Mathematics

2. If $2^{x-1} + 2^{x+1} = 320$, what is the value of $x$?

Correct Answer: Option C

Rewrite the equation using exponent rules: $2^x \cdot 2^{-1} + 2^x \cdot 2^1 = 320$. Factor out $2^x$: $2^x (\frac{1}{2} + 2) = 320$. Simplify inside parenthesis: $2^x (\frac{5}{2}) = 320$. Multiply by $\frac{2}{5}$: $2^x = 320 \times \frac{2}{5} = 64 \times 2 = 128$. Since $128 = 2^7$, $x = 7$. Thus, The answer is Option C.

Question 3 of 10 Super TET Junior Mathematics

3. Simplify the expression: $3x - [y - {2x - (y - 3x)} + 2y]$

Correct Answer: Option A

First, 2x - (y - 3x) = 5x - y. The square bracket becomes y - (5x - y) + 2y = 4y - 5x. Therefore, 3x - (4y - 5x) = 8x - 4y. The answer is Option A.

Question 4 of 10 Super TET Junior Mathematics

4. If $\frac{x}{y} = \frac{3}{4}$, find the value of $\frac{4x + 2y}{4x - 2y}$.

Correct Answer: Option C

Let x=3k and y=4k. Then the fraction is (12k+8k)/(12k-8k)=20k/4k=5. The answer is Option C.

Question 5 of 10 Super TET Junior Mathematics

5. What is the coefficient of $x^2$ in the product $(2x - 3)(x^2 - 4x + 5)$?

Correct Answer: Option A

Multiply terms that yield $x^2$: $2x \times (-4x) = -8x^2$, and $-3 \times x^2 = -3x^2$. Summing these coefficients: $-8 + (-3) = -11$. The answer is Option A.

Question 6 of 10 Super TET Junior Mathematics

6. If $x + \frac{1}{x} = 5$, what is the value of $x^3 + \frac{1}{x^3}$?

Correct Answer: Option A

Use formula $x^3 + \frac{1}{x^3} = (x + \frac{1}{x})^3 - 3(x + \frac{1}{x})$. Substitute $5$: $5^3 - 3(5) = 125 - 15 = 110$. The answer is Option A.

Question 7 of 10 Super TET Junior Mathematics

7. Which of the following is a polynomial in one variable?

Correct Answer: Option C

A polynomial in one variable must have non-negative integer exponents and only one variable type. Option 0 has $\frac{2}{x^2} = 2x^{-2}$ (negative exponent). Option 1 has $\sqrt{x} = x^{1/2}$ (fractional exponent). Option 3 has two variables ($x$ and $y$). Option 2 ($x^3 - 5x^2 + 7x - 2$) satisfies all polynomial criteria in variable $x$. The answer is Option C.

Question 8 of 10 Super TET Junior Mathematics

8. If $3^{x} = 81$ and $2^{y} = 32$, what is the value of $x + y$?

Correct Answer: Option B

Solve for $x$: $3^x = 81 = 3^4 \implies x = 4$. Solve for $y$: $2^y = 32 = 2^5 \implies y = 5$. Calculate $x + y = 4 + 5 = 9$. The answer is Option B.

Question 9 of 10 Super TET Junior Mathematics

9. What must be subtracted from $4x^3 - 2x^2 + 5x - 6$ to get $2x^3 + x^2 - 3x + 4$?

Correct Answer: Option A

Let the required expression be $P$. Then $(4x^3 - 2x^2 + 5x - 6) - P = 2x^3 + x^2 - 3x + 4$. Rearranging: $P = (4x^3 - 2x^2 + 5x - 6) - (2x^3 + x^2 - 3x + 4) = (4-2)x^3 + (-2-1)x^2 + (5-(-3))x + (-6-4) = 2x^3 - 3x^2 + 8x - 10$. The answer is Option A.

Question 10 of 10 Super TET Junior Mathematics

10. If $a + b + c = 0$, what is the value of $\frac{a^2}{bc} + \frac{b^2}{ca} + \frac{c^2}{ab}$?

Correct Answer: Option C

Find common denominator $abc$. Expression becomes $\frac{a^3 + b^3 + c^3}{abc}$. Since $a + b + c = 0$, it is a standard algebraic identity that $a^3 + b^3 + c^3 = 3abc$. Substituting this gives $\frac{3abc}{abc} = 3$. The answer is Option C.
