15.1 Definitions, Standard Forms & Transposition Rules

A linear equation is an algebraic equation in which each term has an exponent of $1$ (degree is $1$) and no terms have products of variables.

Equation Type Standard Form Conditions Number of Solutions
Linear Equation in One Variable $ax + b = 0$ $a \ne 0, \; a, b \in \mathbb{R}$ Exactly 1 Unique Root: $x = -\frac{b}{a}$
Linear Equation in Two Variables $ax + by + c = 0$ $a^2 + b^2 \ne 0$ Infinitely Many Solutions (Represents a straight line in $\mathbb{R}^2$)

The Four Golden Rules of Transposition (पक्षांतरण के नियम)

  • Addition Transposition: $+c$ on LHS transposes to $-c$ on RHS ($x + c = d \implies x = d - c$).
  • Subtraction Transposition: $-c$ on LHS transposes to $+c$ on RHS ($x - c = d \implies x = d + c$).
  • Multiplication Transposition: $\times a$ on LHS transposes to $\div a$ on RHS ($ax = d \implies x = \frac{d}{a}$).
  • Division Transposition: $\div b$ on LHS transposes to $\times b$ on RHS ($\frac{x}{b} = d \implies x = b \cdot d$).
The Cross-Multiplication Theorem for Rational Linear Equations:
$$\text{If } \frac{ax + b}{cx + d} = \frac{p}{q}, \quad \text{then } q(ax + b) = p(cx + d)$$ $$\implies (qa - pc)x = pd - qb \implies x = \frac{pd - qb}{qa - pc}$$

Cross-multiplication removes fractions immediately in a single line without computing cumbersome denominators!

15.2 Master Archetypes of Word Problems (शाब्दिक प्रश्न मॉडल)

In the UP Upper Primary examination, word problems test your ability to convert verbal statements into mathematical linear equations. Here are the 4 most tested models:

Word Problem Model Algebraic Formulation Examination Golden Invariant
Two-Digit Numbers Original Number $= 10x + y$
Reversed Number $= 10y + x$		 $(10x+y) - (10y+x) = 9(x-y)$ (Always multiple of $9$)
$(10x+y) + (10y+x) = 11(x+y)$ (Always multiple of $11$)
Age Problems Present Age $= x$
$n$ years ago $= x - n$
$n$ years hence $= x + n$		 The difference between ages of two persons remains constant across any point in time!
Fraction Modifications Fraction $= \frac{N}{D}$
$\frac{N + k_1}{D + k_2} = \text{New Fraction}$		 Express both $N$ and $D$ in terms of a single variable $x$ first (e.g., $D = x+3$).
Boats & Streams / Upstream & Downstream Speed in still water $= u$
Speed of stream $= v$		 $\text{Downstream Speed } = u + v$
$\text{Upstream Speed } = u - v$
$u = \frac{S_{\text{down}} + S_{\text{up}}}{2}, \; v = \frac{S_{\text{down}} - S_{\text{up}}}{2}$
Top-Rank Exam Secret: Option Back-Substitution

For word problems on ages, digits, and fractions, solving from the options is 3x to 5x faster than writing quadratic or fractional equations! Always test the given conditions directly on the four options first.

15.3 Special Cases: Infinite Solutions vs No Solution

When simplifying $ax = b$:

  • Unique Solution ($a \ne 0$): One unique root $x = b/a$.
  • Infinite Solutions / Identity ($a = 0, b = 0$): Form $0x = 0$. Holds true for every real value of $x$.
  • No Solution / Inconsistent ($a = 0, b \ne 0$): Form $0x = b$ ($b \ne 0$). Impossible in mathematics (no value of $x$ can satisfy $0 = b$).

Type 1: Multi-Step Linear Equation with Parentheses Archetype 1
Q1
Solve for $x$: $3(2x - 1) - 2(x - 4) = 4(x + 2) - 3$.
Correct Answer: Option (C) Infinitely Many Solutions

Method 1: Step-by-Step Standard Solution

  1. Expand the LHS: $$\text{LHS} = 6x - 3 - 2x + 8 = (6x - 2x) + (-3 + 8) = 4x + 5$$
  2. Expand the RHS: $$\text{RHS} = 4x + 8 - 3 = 4x + 5$$
  3. Set LHS equal to RHS: $$4x + 5 = 4x + 5 \implies 4x - 4x = 5 - 5 \implies 0x = 0$$
  4. Since $0x = 0$ is true for every real number $x$, the equation has infinitely many solutions (it is an identity).

Examiner Trap: Many candidates reflexively try to isolate $x$ and get confused when variables cancel out, picking "No Solution" or "$x=0$". Remember: $0x = 0 \implies$ Infinite solutions; $0x = k \; (k \ne 0) \implies$ No solution.

Type 2: Rational Linear Equation via Cross-Multiplication Archetype 2
Q2
Solve for $x$: $\frac{3x + 4}{2 - 6x} = -\frac{2}{5}$.
Correct Answer: Option (B) $x = -8$

Step-by-Step Cross-Multiplication:

$$5(3x + 4) = -2(2 - 6x)$$ $$15x + 20 = -4 + 12x$$ $$15x - 12x = -4 - 20$$ $$3x = -24 \implies x = \frac{-24}{3} = -8$$

Top-Rank Check: Plug $x = -8$ into LHS: $\frac{3(-8)+4}{2-6(-8)} = \frac{-20}{50} = -\frac{2}{5}$. Verified instantly!

Type 3: Two-Digit Number & Digit Reversal Archetype Archetype 3
Q3
The sum of the digits of a two-digit number is $9$. If $27$ is added to the number, its digits are reversed. What is the original number?
Correct Answer: Option (B) $36$

Method 1: Step-by-Step Algebraic Solution

  1. Let tens digit be $x$ and units digit be $y$. Given: $x + y = 9 \implies y = 9 - x$.
  2. Original Number $= 10x + y = 10x + (9 - x) = 9x + 9$.
  3. Reversed Number $= 10y + x = 10(9 - x) + x = 90 - 9x$.
  4. Condition: Original $+ 27 =$ Reversed: $$9x + 9 + 27 = 90 - 9x \implies 18x = 54 \implies x = 3$$
  5. Tens digit $x = 3 \implies$ units digit $y = 9 - 3 = 6$. Original number is $36$.

Method 2: Top-Rank Exam Speed Hack (Backsolving Options - 5 Seconds)

  • Test Option A ($63$): $63 + 27 = 90 \ne 36$ (Wrong).
  • Test Option B ($36$): $36 + 27 = 63$ (Digits $3$ and $6$ reversed!). Directly mark (B)!
Type 4: Age-Based Linear Equation Archetype Archetype 4
Q4
A father is $30$ years older than his son. In $5$ years, the father's age will be three times the age of his son. What is the present age of the son?
Correct Answer: Option (A) $10\text{ years}$

Method 1: Step-by-Step Algebraic Solution

  1. Let son's present age be $x$. Father's age is $x + 30$.
  2. In $5$ years: Son will be $x + 5$, Father will be $(x + 30) + 5 = x + 35$.
  3. Condition: Father's age $= 3 \times$ Son's age: $$x + 35 = 3(x + 5)$$ $$x + 35 = 3x + 15 \implies 2x = 20 \implies x = 10$$

Method 2: Top-Rank Exam Speed Hack (Age Difference Invariance)

The difference between their ages is always $30$ years.

In $5$ years, father is $3$ units and son is $1$ unit $\implies$ difference is $3 - 1 = 2$ units.

$$2\text{ units} = 30\text{ years} \implies 1\text{ unit} = 15\text{ years}$$

Son's age in $5$ years $= 15$ years $\implies$ Son's present age $= 15 - 5 = 10$ years!

Type 5: Fraction Modification Model Archetype 5
Q5
The denominator of a rational number is greater than its numerator by $8$. If the numerator is increased by $17$ and the denominator is decreased by $1$, the number becomes $\frac{3}{2}$. What was the original rational number?
Correct Answer: Option (B) $\frac{13}{21}$

Step-by-Step Algebraic Solution:

  1. Let numerator be $x$. Denominator is $x + 8$. Rational number is $\frac{x}{x + 8}$.
  2. New numerator $= x + 17$. New denominator $= (x + 8) - 1 = x + 7$.
  3. Given: $\frac{x + 17}{x + 7} = \frac{3}{2}$.
  4. Cross-multiply: $$2(x + 17) = 3(x + 7) \implies 2x + 34 = 3x + 21 \implies x = 13$$
  5. Numerator $x = 13$, Denominator $= 13 + 8 = 21$. Original fraction $= \frac{13}{21}$.

Speed Hack: Test option $\frac{13}{21}$: $\frac{13 + 17}{21 - 1} = \frac{30}{20} = \frac{3}{2}$. Confirmed in 5 seconds!

Type 6: Geometry & Perimeter Linear Formulation Archetype 6
Q6
The length of a rectangle is $5\text{ cm}$ more than twice its breadth. If the perimeter of the rectangle is $58\text{ cm}$, what is its area?
Correct Answer: Option (B) $168\text{ cm}^2$

Step-by-Step Solution:

  1. Let breadth be $b$. Then length $l = 2b + 5$.
  2. Perimeter $= 2(l + b) = 58 \implies l + b = 29$.
  3. Substitute $l = 2b + 5$: $$(2b + 5) + b = 29 \implies 3b + 5 = 29 \implies 3b = 24 \implies b = 8\text{ cm}$$
  4. Length $l = 2(8) + 5 = 21\text{ cm}$.
  5. $\text{Area} = l \times b = 21 \times 8 = 168\text{ cm}^2$.
Type 7: Money, Coin Denominations & Purse Archetype Archetype 7
Q7
A bag contains ₹$1$ and ₹$2$ coins having a total value of ₹$115$. If the total number of coins in the bag is $80$, find the number of ₹$2$ coins.
Correct Answer: Option (B) $35$

Method 1: Linear Equation in One Variable

  1. Let number of ₹$2$ coins be $x$.
  2. Then number of ₹$1$ coins is $80 - x$.
  3. Total value equation: $$2(x) + 1(80 - x) = 115 \implies 2x + 80 - x = 115 \implies x = 115 - 80 = 35$$
  4. Number of ₹$2$ coins is $35$.

Method 2: Top-Rank Exam Speed Hack (All-or-Nothing Allegation)

Assume all $80$ coins were ₹$1$ coins $\implies$ Total value would be $80 \times 1 = \text{₹}80$.

Actual total is ₹$115$, which is $115 - 80 = \text{₹}35$ extra.

Each ₹$2$ coin provides an extra ₹$(2 - 1) = \text{₹}1$.

$$\text{Number of ₹2 coins} = \frac{\text{Extra Amount}}{\text{Difference in Denomination}} = \frac{35}{1} = 35$$

Solved in 5 seconds in your head!

Type 8: Boats & Streams Linear Equations Archetype 8
Q8
A boat travels downstream from port A to port B in $4\text{ hours}$, and returns upstream from B to A in $5\text{ hours}$. If the speed of the stream is $2\text{ km/h}$, find the speed of the boat in still water.
Correct Answer: Option (B) $18\text{ km/h}$

Step-by-Step Solution:

  1. Let speed of boat in still water be $u\text{ km/h}$.
  2. $\text{Downstream speed} = u + 2$. $\text{Distance} = \text{Speed} \times \text{Time} = 4(u + 2)$.
  3. $\text{Upstream speed} = u - 2$. $\text{Distance} = 5(u - 2)$.
  4. Since the distance between A and B is identical: $$4(u + 2) = 5(u - 2)$$ $$4u + 8 = 5u - 10 \implies u = 18\text{ km/h}$$

Top-Rank Speed Hack:

$$u = v \times \frac{t_{\text{up}} + t_{\text{down}}}{t_{\text{up}} - t_{\text{down}}} = 2 \times \frac{5 + 4}{5 - 4} = 2 \times 9 = 18\text{ km/h}$$
Type 9: Fixed and Variable Charge Model Archetype 9
Q9
A lending library has a fixed charge for the first $3$ days and an additional charge for each day thereafter. Saritha paid ₹$27$ for a book kept for $7$ days, while Susy paid ₹$21$ for the book kept for $5$ days. Find the fixed charge ($F$) and charge per extra day ($x$).
Correct Answer: Option (B) $F = \text{₹}15, \; x = \text{₹}3$

Step-by-Step Solution:

  1. Saritha kept book for $7$ days $\implies 3\text{ days fixed} + 4\text{ extra days}$: $$F + 4x = 27 \quad \text{--- (Equation 1)}$$
  2. Susy kept book for $5$ days $\implies 3\text{ days fixed} + 2\text{ extra days}$: $$F + 2x = 21 \quad \text{--- (Equation 2)}$$
  3. Subtract Equation 2 from Equation 1: $$2x = 6 \implies x = 3$$
  4. Substitute $x = 3$ into Equation 2: $$F + 2(3) = 21 \implies F = 21 - 6 = 15$$
  5. Fixed charge is ₹$15$ and daily charge is ₹$3$.
Type 10: Inconsistent / No Solution Condition Archetype 10
Q10
For what value of $k$ does the equation $5(2x - 3) - kx = 7$ have NO solution for $x$?
Correct Answer: Option (B) $k = 10$

Step-by-Step Analysis:

  1. Expand and rearrange the equation into standard form $Ax = B$: $$10x - 15 - kx = 7$$ $$(10 - k)x = 7 + 15$$ $$(10 - k)x = 22$$
  2. An equation of the form $Ax = B$ has NO solution if and only if $A = 0$ and $B \ne 0$: $$10 - k = 0 \implies k = 10$$
  3. When $k = 10$, the equation becomes $0 \cdot x = 22$, which is impossible for any real number $x$.
