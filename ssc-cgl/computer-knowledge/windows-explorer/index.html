Quick Overviewत्वरित अवलोकन

This module covers Windows Explorer (File Explorer), its user interface components, file management operations, and essential keyboard shortcuts. In SSC CGL Tier 2, questions frequently test navigation paths, shortcut keys, file extensions, and window management commands.

यह मॉड्यूल विंडोज एक्सप्लोरर (फाइल एक्सप्लोरर), इसके यूजर इंटरफेस घटकों, फाइल प्रबंधन संचालन और आवश्यक कीबोर्ड शॉर्टकट को कवर करता है। एसएससी सीजीएल टियर 2 में, नेविगेशन पथ, शॉर्टकट कुंजियाँ, फाइल एक्सटेंशन और विंडो प्रबंधन कमांड से संबंधित प्रश्न अक्सर पूछे जाते हैं।

Concept Introductionमूल अवधारणा परिचय

Windows Explorer, officially renamed File Explorer in Windows 8 and later versions, is the file management application that provides a graphical user interface for accessing the file systems. Think of it as a digital filing cabinet where folders are drawers and files are documents, managed seamlessly through mouse clicks or quick keyboard shortcuts.

विंडोज एक्सप्लोरर, जिसे विंडोज 8 और बाद के संस्करणों में आधिकारिक तौर पर फाइल एक्सप्लोरर नाम दिया गया है, फाइल प्रबंधन एप्लिकेशन है जो फाइल सिस्टम तक पहुंचने के लिए एक ग्राफिकल यूजर इंटरफेस प्रदान करता है। इसे एक डिजिटल फाइलिंग कैबिनेट के रूप में समझें जहाँ फोल्डर दराज हैं और फाइलें दस्तावेज हैं, जिन्हें माउस क्लिक या त्वरित कीबोर्ड शॉर्टकट के माध्यम से प्रबंधित किया जाता है।

यदि आप अपनी प्रॉपर्टीज विंडो खोले बिना किसी चयनित फाइल या फोल्डर के सटीक पथ को टेक्स्ट के रूप में विंडोज क्लिपबोर्ड पर कॉपी करना चाहते हैं, तो किस आधुनिक फाइल एक्सप्लोरर शॉर्टकट का उपयोग किया जाता है?

Correct Answer: Option Dसही उत्तर: विकल्प D

Both `Ctrl + Shift + C` (introduced in recent Windows 11 updates) and holding `Shift + Right Click` to choose 'Copy as path' copy the full file system path to the clipboard.

हालिया विंडोज 11 अपडेट में पेश किया गया `Ctrl + Shift + C` और 'कॉपी एज पाथ' चुनने के लिए `Shift + राइट क्लिक` दोनों पूर्ण फाइल सिस्टम पथ को क्लिपबोर्ड पर कॉपी करते हैं।

Q28प्रश्न 28 HARDकठिन

Examine the effect of navigating inside Windows Explorer: What does pressing the `Backspace` key do when you are currently typing a search query inside the search box vs when the focus is on the file list view?

विंडोज एक्सप्लोरर के अंदर नेविगेट करने के प्रभाव की जांच करें: जब आप वर्तमान में सर्च बॉक्स के अंदर सर्च क्वेरी टाइप कर रहे हों बनाम जब फोकस फाइल सूची दृश्य पर हो, तब `Backspace` कुंजी दबाने पर क्या होता है?

Correct Answer: Option Aसही उत्तर: विकल्प A

Context awareness is crucial: Backspace deletes text if typing in an input field (search box/address bar), but when focus is on items/folders, Backspace serves as a shortcut to go back/up in folder history.

संदर्भ जागरूकता महत्वपूर्ण है: यदि इनपुट फ़ील्ड (सर्च बॉक्स/एड्रेस बार) में टाइपिंग कर रहे हैं तो बैकस्पेस टेक्स्ट को हटा देता है, लेकिन जब फोकस आइटम/फोल्डर पर होता है, तो बैकस्पेस फोल्डर इतिहास में वापस/ऊपर जाने के लिए शॉर्टकट के रूप में कार्य करता है।

Q29प्रश्न 29 HARDकठिन

Which key combination in Windows Explorer expands all subfolders and folders recursively in the left navigation pane when a master folder is selected?

विंडोज एक्सप्लोरर में कौन सा कुंजी संयोजन बाएं नेविगेशन फलक में सभी सबफोल्डर और फोल्डर को पुनरावर्ती रूप से विस्तारित करता है जब कोई मास्टर फोल्डर चुना जाता है?

Correct Answer: Option Aसही उत्तर: विकल्प A

Pressing the asterisk (*) key on the numeric keypad expands all sub-branches under the selected folder in the navigation pane tree view.

नेविगेशन पेन ट्री व्यू में चयनित फोल्डर के तहत सभी सब-ब्रंच का विस्तार करने के लिए संख्यात्मक कीपैड पर तारा चिह्न (*) कुंजी दबाएं।

Q30प्रश्न 30 HARDकठिन

What happens when you use `Ctrl + Shift + Drag-and-Drop` with a file in Windows Explorer?

विंडोज एक्सप्लोरर में किसी फाइल के साथ `Ctrl + Shift + Drag-and-Drop` (ड्रैग-एंड-ड्रॉप) का उपयोग करने पर क्या होता है?

Correct Answer: Option Aसही उत्तर: विकल्प A

Dragging a file while holding `Ctrl + Shift` (or `Alt + Drag` in some contexts) creates a desktop or folder shortcut pointing to the original file. (Note: Ctrl alone copies, Shift alone moves, Ctrl+Shift creates a shortcut).

Ctrl + Shift को दबाकर रखते हुए फाइल को खींचने से मूल फाइल की ओर इशारा करने वाला एक शॉर्टकट बनता है।
