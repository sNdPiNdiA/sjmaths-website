Network Devices & Protocols

Complete study notes, interactive preparation checklists, core formulas, and practice questions for Network Devices & Protocols under SSC CGL Tier 1 and Tier 2.

Network Devices & Protocols: Complete Study Notesनेटवर्क डिवाइस और प्रोटोकॉल: संपूर्ण अध्ययन नोट्स

Quick Overviewत्वरित अवलोकन

This module covers essential networking hardware (devices) that establish connections and the standardized sets of rules (protocols) that govern data communication across networks. In SSC CGL Tier 2, questions from this topic are direct, high-scoring, and test the OSI layer operation, default port numbers, and specific functions of devices like routers, switches, and gateways.

यह मॉड्यूल आवश्यक नेटवर्किंग हार्डवेयर (डिवाइस) को कवर करता है जो कनेक्शन स्थापित करते हैं और मानकीकृत नियमों के सेट (प्रोटोकॉल) को कवर करता है जो नेटवर्क पर डेटा संचार को नियंत्रित करते हैं। एसएससी सीजीएल टियर 2 में, इस विषय के प्रश्न सीधे, उच्च स्कोरिंग वाले होते हैं और ओएसआई लेयर संचालन, डिफ़ॉल्ट पोर्ट नंबर और राउटर, स्विच और गेटवे जैसे उपकरणों के विशिष्ट कार्यों का परीक्षण करते हैं।

Learning Objectives for SSC CGLएसएससी सीजीएल के लिए अध्ययन उद्देश्य

  • Understand the precise OSI layer and functions of core network hardware like Hub, Switch, Router, and Gateway.हब, स्विच, राउटर और गेटवे जैसे कोर नेटवर्क हार्डवेयर की सटीक ओएसआई परत और कार्यों को समझें।
  • Memorize standard network protocols, their OSI layers, and default port numbers (TCP/UDP).मानक नेटवर्क प्रोटोकॉल, उनकी ओएसआई परतें और डिफ़ॉल्ट पोर्ट नंबर (टीसीपी/यूडीपी) याद रखें।
  • Differentiate between routing algorithms, switching techniques, and transmission media types.राउटिंग एल्गोरिदम, स्विचिंग तकनीकों और ट्रांसमिशन मीडिया प्रकारों के बीच अंतर करें।
  • Master previous years' trend questions frequently asked in SSC examinations.एसएससी परीक्षाओं में बार-बार पूछे जाने वाले पिछले वर्षों के रुझान वाले प्रश्नों में महारत हासिल करें।

Concept Introductionमूल अवधारणा परिचय

Think of a computer network like a modern postal and transportation system. Network devices are the physical post offices, sorting facilities, and delivery vehicles (like trucks and sorting hubs) that handle parcels. Network protocols are the universal rules and addressing formats (like postal codes, envelope standards, and language rules) ensuring that a letter sent from one city reaches the correct recipient without confusion.

कंप्यूटर नेटवर्क को एक आधुनिक डाक और परिवहन प्रणाली की तरह समझें। नेटवर्क डिवाइस भौतिक डाकघर, छंटाई सुविधाएं और वितरण वाहन हैं जो पार्सल संभालते हैं। नेटवर्क प्रोटोकॉल सार्वभौमिक नियम और पते के प्रारूप हैं जो यह सुनिश्चित करते हैं कि एक शहर से भेजा गया पत्र बिना किसी भ्रम के सही प्राप्तकर्ता तक पहुँचे।

Essential Network Hardware Devicesआवश्यक नेटवर्क हार्डवेयर डिवाइस

Network devices operate at various layers of the OSI model to connect segments, filter traffic, and route packets efficiently across local and wide-area networks.

नेटवर्क डिवाइस सेगमेंट को जोड़ने, ट्रैफ़िक फ़िल्टर करने और स्थानीय और वाइड-एरिया नेटवर्क पर पैケット को कुशलतापूर्वक रूट करने के लिए OSI मॉडल की विभिन्न परतों पर काम करते हैं।

Repeater / Hubरिपीटर / हब
Operates at Physical Layer (Layer 1). A repeater regenerates weakened signals, while a dumb hub broadcasts incoming data to all ports regardless of the destination.फिजिकल लेयर (लेयर 1) पर काम करता है। रिपीटर कमजोर संकेतों को पुनर्जीवित करता है, जबकि एक डब हब गंतव्य की परवाह किए बिना सभी पोर्ट पर आने वाले डेटा को प्रसारित करता है।
Switch / Bridgeस्विच / ब्रिज
Operates at Data Link Layer (Layer 2). Uses MAC addresses to forward data to the specific destination port, reducing network traffic compared to hubs.डेटा लिंक लेयर (लेयर 2) पर काम करता है। हब की तुलना में नेटवर्क ट्रैफ़िक को कम करते हुए, विशिष्ट गंतव्य पोर्ट पर डेटा अग्रेषित करने के लिए MAC पते का उपयोग करता है।
Routerराऊटर
Operates at Network Layer (Layer 3). Uses IP addresses and routing tables to determine the best path for packet forwarding across different networks.नेटवर्क लेयर (लेयर 3) पर काम करता है। विभिन्न नेटवर्क पर पैケット अग्रेषित करने के लिए सबसे अच्छा रास्ता तय करने के लिए आईपी पते और राउटिंग टेबल का उपयोग करता है।
Gatewayगेटवे
Operates across all layers up to Application Layer. Acts as a protocol converter enabling communication between completely different network architectures.एप्लिकेशन लेयर तक सभी परतों पर काम करता है। पूरी तरह से अलग नेटवर्क आर्किटेक्चर के बीच संचार को सक्षम करने वाले प्रोटोकॉल कनवर्टर के रूप में कार्य करता है।

Core Network Protocols & Port Numbersकोर नेटवर्क प्रोटोकॉल और पोर्ट नंबर

Protocols are standardized rules governing data transmission. SSC CGL frequently tests the full forms, OSI layer placements, and default port numbers of these protocols.

प्रोटोकॉल डेटा ट्रांसमिशन को नियंत्रित करने वाले मानकीकृत नियम हैं। एसएससी सीजीएल अक्सर इन प्रोटोकॉल के फुल फॉर्म, ओएसआई लेयर प्लेसमेंट और डिफ़ॉल्ट पोर्ट नंबर का परीक्षण करता है।

HTTP / HTTPSHTTP / HTTPS
HyperText Transfer Protocol used for web browsing. Operates on Application Layer. Ports: HTTP uses 80, HTTPS uses 443 (secure via SSL/TLS).वेब ब्राउज़िंग के लिए प्रयुक्त हाइपरटेक्स्ट ट्रांसफर प्रोटोकॉल। एप्लिकेशन लेयर पर काम करता है। पोर्ट: HTTP 80 का उपयोग करता है, HTTPS 443 का उपयोग करता है (SSL/TLS के माध्यम से सुरक्षित)।
FTPFTP
File Transfer Protocol used for transferring files between client and server. Uses TCP ports 20 (data) and 21 (control).क्ला라이언트 और सर्वर के बीच फाइल ट्रांसफर करने के लिए प्रयुक्त फाइल ट्रांसफर प्रोटोकॉल। TCP पोर्ट 20 (डेटा) और 21 (कंट्रोल) का उपयोग करता है।
DNSDNS
Domain Name System translates human-readable domain names into IP addresses. Uses UDP/TCP Port 53.डोमेन नाम सिस्टम मानव-पठनीय डोमेन नामों को आईपी पते में अनुवादित करता है। UDP/TCP पोर्ट 53 का उपयोग करता है।
DHCPDHCP
Dynamic Host Configuration Protocol automatically assigns IP addresses to devices on a network. Uses UDP Ports 67 and 68.डायनेमिक होस्ट कॉन्फ़िगरेशन प्रोटोकॉल नेटवर्क पर उपकरणों को स्वचालित रूप से आईपी पते निर्दिष्ट करता है। UDP पोर्ट 67 और 68 का उपयोग करता है।

Email & Remote Access Protocolsईमेल और रिमोट एक्सेस प्रोटोकॉल

Email communication and remote server administration rely on dedicated protocols that handle sending, receiving, and secure terminal control.

ईमेल संचार और रिमोट सर्वर प्रशासन समर्पित प्रोटोकॉल पर भरोसा करते हैं जो भेजने, प्राप्त करने और सुरक्षित टर्मिनल नियंत्रण को संभालते हैं।

SMTPSMTP
Simple Mail Transfer Protocol is used to send emails from client to server or between servers. Uses Port 25 (or 587).सिंपल मेल ट्रांसफर प्रोटोकॉल का उपयोग क्लाइंट से सर्वर या सर्वर के बीच ईमेल भेजने के लिए किया जाता है। पोर्ट 25 (या 587) का उपयोग करता है।
POP3 / IMAPPOP3 / IMAP
Post Office Protocol 3 downloads emails and deletes from server (Port 110). Internet Message Access Protocol keeps emails on server and syncs across devices (Port 143).पोस्ट ऑफिस प्रोटोकॉल 3 ईमेल डाउनलोड करता है और सर्वर से हटाता है (पोर्ट 110)। इंटरनेट मैसेज एक्सेस प्रोटोकॉल ईमेल को सर्वर पर रखता है और उपकरणों पर सिंक करता है (पोर्ट 143)।
SSH & TelnetSSH और Telnet
Secure Shell (SSH) provides secure encrypted remote login on Port 22. Telnet provides unencrypted text-based remote login on Port 23.सिक्योर शेल (SSH) पोर्ट 22 पर सुरक्षित एन्क्रिप्टेड रिमोट लॉगिन प्रदान करता है। टेलनेट पोर्ट 23 पर अनएन्क्रिप्टेड टेक्स्ट-आधारित रिमोट लॉगिन प्रदान करता है।

SSC CGL High-Yield Pattern:एसएससी सीजीएल हाई-यील्ड पैटर्न: Expect direct matching or multiple-choice questions matching protocols with their default ports (e.g., HTTPS = 443, DNS = 53, SMTP = 25) and matching network devices with their corresponding OSI layers. प्रोटोकॉल को उनके डिफ़ॉल्ट पोर्ट (जैसे HTTPS = 443, DNS = 53, SMTP = 25) के साथ मिलान करने और नेटवर्क उपकरणों को उनकी संबंधित OSI परतों के साथ मिलान करने वाले सीधे मिलान या बहु-विकल्प प्रश्नों की अपेक्षा करें।

Golden Rule for Email Protocols:ईमेल प्रोटोकॉल के लिए स्वर्ण नियम: Remember the acronym 'S' for Send = SMTP (Simple Mail Transfer Protocol), and 'P/I' for Receive = POP3 / IMAP. भेजने के लिए 'S' = SMTP (सिंपल मेल ट्रांसफर प्रोटोकॉल) और प्राप्त करने के लिए 'P/I' = POP3 / IMAP संक्षिप्त नाम याद रखें।

Hub vs Switch Confusion:हब बनाम स्विच भ्रम: Students often confuse hubs and switches. A Hub operates at Layer 1 and blindly broadcasts data everywhere creating network congestion, whereas a Switch operates at Layer 2 using MAC addresses to send data only to the intended recipient. छात्र अक्सर हब और स्विच में भ्रमित हो जाते हैं। एक हब लेयर 1 पर काम करता है और नेटवर्क भीड़भाड़ पैदा करते हुए अंधेधुंध डेटा प्रसारित करता है, जबकि एक स्विच लेयर 2 पर केवल इच्छित प्राप्तकर्ता को डेटा भेजने के लिए MAC पतों का उपयोग करके काम करता है।

Key Takeaways (High-Yield Summary)मुख्य निष्कर्ष (त्वरित पुनरीक्षण)

  • Routers operate at Layer 3 (Network Layer) and use IP addresses to route packets between different networks.राउटर लेयर 3 (नेटवर्क लेयर) पर काम करते हैं और विभिन्न नेटवर्क के बीच पैケット को रूट करने के लिए आईपी पते का उपयोग करते हैं।
  • Switches operate at Layer 2 (Data Link Layer) and use MAC addresses to forward frames intelligently.स्विच लेयर 2 (डेटा लिंक लेयर) पर काम करते हैं और बुद्धिमानी से फ्रेम अग्रेषित करने के लिए MAC पते का उपयोग करते हैं।
  • HTTP operates on TCP Port 80, while secure HTTPS operates on TCP Port 443 using SSL/TLS encryption.HTTP, TCP पोर्ट 80 पर काम करता है, जबकि सुरक्षित HTTPS, SSL/TLS एन्क्रिप्शन का उपयोग करके TCP पोर्ट 443 पर काम करता है।
  • DNS translates domain names to IP addresses and functions on UDP/TCP Port 53.DNS डोमेन नामों को आईपी पते में अनुवादित करता है और UDP/TCP पोर्ट 53 पर कार्य करता है।
  • SMTP is strictly used for sending emails (Port 25/587), whereas POP3 and IMAP are used for receiving emails.SMTP का उपयोग विशेष रूप से ईमेल भेजने के लिए किया जाता है (पोर्ट 25/587), जबकि POP3 और IMAP का उपयोग ईमेल प्राप्त करने के लिए किया जाता है।
  • A Gateway acts as a translator between two completely different network architectures across all OSI layers.एक गेटवे सभी OSI परतों पर दो पूरी तरह से अलग नेटवर्क आर्किटेक्चर के बीच अनुवादक के रूप में कार्य करता है।

Q1प्रश्न 1 EASYसरल

Which network device operates at the Physical Layer of the OSI model and simply amplifies or regenerates the incoming electrical signal?

कौन सा नेटवर्क डिवाइस OSI मॉडल की फिजिकल लेयर पर काम करता है और आने वाले विद्युत सिग्नल को केवल प्रवर्धित (amplifies) या पुनर्जीवित (regenerates) करता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

A repeater operates at the physical layer and is used to regenerate signals to extend the transmission distance over networks.

एक रिपीटर फिजिकल लेयर पर काम करता है और नेटवर्क पर ट्रांसमिशन दूरी बढ़ाने के लिए सिग्नलों को पुनर्जीवित करने के लिए उपयोग किया जाता है।

Q2प्रश्न 2 EASYसरल

What does TCP stand for in computer networking?

कंप्यूटर नेटवर्किंग में TCP का पूरा नाम क्या है?

Correct Answer: Option Aसही उत्तर: विकल्प A

TCP stands for Transmission Control Protocol, which is a standard protocol that enables application programs and computing devices to exchange messages over a network.

TCP का अर्थ ट्रांसमिशन कंट्रोल प्रोटोकॉल है, जो एक मानक प्रोटोकॉल है जो एप्लिकेशन प्रोग्राम और कंप्यूटिंग उपकरणों को नेटवर्क पर संदेशों का आदान-प्रदान करने में सक्षम बनाता है।

Q3प्रश्न 3 EASYसरल

Which device connects multiple computers within a single local area network (LAN) and uses MAC addresses to forward data frames?

कौन सा डिवाइस एक ही लोकल एरिया नेटवर्क (LAN) के भीतर कई कंप्यूटरों को जोड़ता है और डेटा फ्रेम को आगे बढ़ाने के लिए MAC पते का उपयोग करता है?

Correct Answer: Option Cसही उत्तर: विकल्प C

A network switch operates at the Data Link Layer and uses MAC addresses to filter and forward data to the specific destination device.

एक नेटवर्क स्विच डेटा लिंक लेयर पर काम करता है और विशिष्ट गंतव्य डिवाइस तक डेटा को फ़िल्टर और अग्रेषित करने के लिए MAC पतों का उपयोग करता है।

Q4प्रश्न 4 EASYसरल

Which protocol is primarily used for securely accessing remote computers and servers over an unsecured network?

असुरक्षित नेटवर्क पर रिमोट कंप्यूटर और सर्वर को सुरक्षित रूप से एक्सेस करने के लिए मुख्य रूप से किस प्रोटोकॉल का उपयोग किया जाता है?

UDP पोर्ट नंबरों के माध्यम से मल्टीप्लेक्सिंग का समर्थन करता है, लेकिन TCP नहीं। 3. प्रति हेडर TCP ओवरहेड न्यूनतम 20 बा이트 है, जबकि UDP हेडर ओवरहेड 8 बाइट पर तय है। उपरोक्त में से कौन से कथन सही हैं?

Correct Answer: Option Aसही उत्तर: विकल्प A

Statement 1 is correct (TCP is reliable/connection-oriented; UDP is best-effort). Statement 2 is incorrect because both TCP and UDP support port-based multiplexing. Statement 3 is correct (TCP header is min 20 bytes; UDP header is fixed 8 bytes).

कथन 1 सही है (TCP विश्वसनीय/कनेक्शन-ओरिएंटेड है; UDP बेस्ट-इफर्ट है)। कथन 2 गलत है क्योंकि TCP और UDP दोनों पोर्ट-आधारित मल्टीप्लेक्सिंग का समर्थन करते हैं। कथन 3 सही है (TCP हेडर न्यूनतम 20 बाइट है; UDP हेडर निश्चित 8 बाइट है)।

Q24प्रश्न 24 HARDकठिन

Which routing protocol uses the Dijkstra algorithm to calculate the shortest path tree and operates within an Autonomous System (Interior Gateway Protocol)?

कौन सा रूटिंग प्रोटोकॉल सबसे छोटे रास्ते के पेड़ (shortest path tree) की गणना करने के लिए डijkstra एल्गोरिथ्म का उपयोग करता है और एक स्वायत्त प्रणाली (इंटीरियर गेटवे प्रोटोकॉल) के भीतर काम करता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

OSPF is a link-state routing protocol that uses Dijkstra's algorithm to compute the shortest path to each router within an Interior Gateway System.

OSPF एक लिंक-स्टेट रूटिंग प्रोटोकॉल है जो इंटीरियर गेटवे सिस्टम के भीतर प्रत्येक राउटर के लिए सबसे छोटे रास्ते की गणना करने के लिए डijkstra के एल्गोरिथ्म का उपयोग करता है।

Q25प्रश्न 25 HARDकठिन

What is the primary vulnerability or issue associated with a Network Hub compared to a Switch or Bridge, from a network security perspective?

नेटवर्क सुरक्षा के दृष्टिकोण से, स्विच या ब्रिज की तुलना में नेटवर्क हब से जुड़ी प्राथमिक कमज़ोरी या समस्या क्या है?

Correct Answer: Option Bसही उत्तर: विकल्प B

Because a hub broadcasts every incoming frame to all other ports (acting like an open wire), any connected device can capture and inspect all network traffic passing through it using promiscuous mode.

चूंकि एक हब प्रत्येक आने वाले फ्रेम को अन्य सभी पोर्ट पर प्रसारित करता है (एक खुले तार की तरह काम करता है), इसलिए कोई भी जुड़ा हुआ उपकरण प्रॉमिसक्यूअस मोड का उपयोग करके इससे गुजरने वाले सभी नेटवर्क ट्रैफिक को कैप्चर और निरीक्षण कर सकता है।

Q26प्रश्न 26 HARDकठिन

In the context of the Domain Name System (DNS), what is a recursive DNS resolver's primary responsibility?

डोमेन नेम सिस्टम (DNS) के संदर्भ में, रिकर्सिव DNS रिजॉल्वर की प्राथमिक जिम्मेदारी क्या है?

Correct Answer: Option Bसही उत्तर: विकल्प B

A recursive resolver handles the client's full request, querying root servers, TLD servers, and authoritative name servers step-by-step until the final IP address is returned to the client.

एक रिकर्सिव रिजॉल्वर क्लाइंट के पूर्ण अनुरोध को संभालता है, अंतिम IP पता क्लाइंट को लौटाए जाने तक चरण-दर-चरण रूट सर्वर, TLD सर्वर और प्राधिकारी नाम सर्वर से पूछताछ करता है।

Q27प्रश्न 27 HARDकठिन

What happens when a Network Bridge encounters a frame whose destination MAC address is already listed in its bridging table on the same interface segment from which the frame originated?

जब किसी नेटवर्क ब्रिज को ऐसा फ्रेम मिलता है जिसका गंतव्य MAC पता पहले से ही उसी इंटरफेस सेगमेंट पर उसकी ब्रिजिंग टेबल में सूचीबद्ध है जहाँ से फ्रेम उत्पन्न हुआ था?

Correct Answer: Option Bसही उत्तर: विकल्प B

Bridges use filtering logic: if the source and destination MAC addresses reside on the same network segment, forwarding the frame is unnecessary, so the bridge filters (drops) it to conserve bandwidth.

ब्रिज फ़िल्टरिंग तर्क का उपयोग करते हैं: यदि स्रोत और गंतव्य MAC पते एक ही नेटवर्क सेगमेंट पर हैं, तो फ्रेम को अग्रेषित करना अनावश्यक है, इसलिए बैंडविड्थ बचाने के लिए ब्रिज इसे फ़िल्टर (ड्रॉप) कर देता है।

Q28प्रश्न 28 HARDकठिन

Which of the following protocols operate securely using TLS/SSL encryption by default on distinct secure ports (e.g., ports 443, 465, or 993)?

निम्नलिखित में से कौन सा प्रोटोकॉल अलग सुरक्षित पोर्ट (जैसे, पोर्ट 443, 465, या 993) पर डिफ़ॉल्ट रूप से TLS/SSL एन्क्रिप्शन का उपयोग करके सुरक्षित रूप से काम करता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

HTTPS (Port 443), SMTPS (Secure SMTP, e.g., Port 465), and IMAPS (Secure IMAP, e.g., Port 993) are secure variants of standard protocols wrapped in SSL/TLS encryption.

HTTPS (पोर्ट 443), SMTPS (सिक्योर SMTP, जैसे पोर्ट 465), और IMAPS (सिक्योर IMAP, जैसे पोर्ट 993) SSL/TLS एन्क्रिप्शन में लिपटे मानक प्रोटोकॉल के सुरक्षित रूप हैं।

Q29प्रश्न 29 HARDकठिन

What is the primary function of Spanning Tree Protocol (STP) in switched Ethernet local area networks?

स्विच किए गए ईथरनेट लोकल एरिया नेटवर्क में स्पैनिंग ट्री प्रोटोकॉल (STP) का प्राथमिक कार्य क्या है?

Correct Answer: Option Bसही उत्तर: विकल्प B

STP operates at Layer 2 to create a loop-free logical topology by placing redundant data paths into a blocking state, preventing catastrophic broadcast storms.

STP रिडंडेंट डेटा पथों को ब्लॉकिंग स्टेट में रखकर लूप-मुक्त तार्किक टोपोलॉजी बनाने के लिए लेयर 2 पर काम करता है, जिससे विनाशकारी ब्रॉडकास्ट स्टॉर्म रुकते हैं।

Q30प्रश्न 30 HARDकठिन

Which network device is specifically designed to perform deep packet inspection (DPI), enforce corporate security policies, detect intrusions, and provide stateful firewall filtering at network perimeters?

कौन सा नेटवर्क डिवाइस विशेष रूप से डीप पैकेट इंस्पेक्शन (DPI) करने, कॉर्पोरेट सुरक्षा नीतियों को लागू करने, घुसपैठ का पता लगाने और नेटवर्क परिधि पर स्टेटफुल फ़ायरवॉल फ़िल्टरिंग प्रदान करने के लिए डिज़ाइन किया गया है?

Correct Answer: Option Cसही उत्तर: विकल्प C

Next-Generation Firewalls (NGFWs) go beyond traditional packet filtering by offering deep packet inspection, intrusion prevention systems (IPS), and application awareness.

नेक्स्ट-जेनरेशन फ़ायरवॉल (NGFWs) डीप पैकेट इंस्पेक्शन, घुसपैठ रोकथाम प्रणाली (IPS), और एप्लिकेशन जागरूकता प्रदान करके पारंपरिक पैकेट फ़िल्टरिंग से आगे जाते हैं।
