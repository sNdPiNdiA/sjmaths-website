CPU Architecture & Input/Output Devices

Complete study notes, interactive preparation checklists, core concepts, and practice questions for CPU Architecture & Input/Output Devices under SSC CGL.

CPU Architecture & Input/Output Devices: Complete Study Notesसीपीयू वास्तुकला और इनपुट/आउटपुट उपकरण: संपूर्ण अध्ययन नोट्स

Quick Overviewत्वरित अवलोकन

This topic covers the internal structure of the Central Processing Unit (CPU), its sub-components (ALU, CU, Registers), instruction execution cycles, and the hardware peripherals used for data entry and presentation (I/O devices). For SSC CGL Tier-2, this is a core scoring module where direct theoretical and conceptual questions are asked frequently.

यह विषय सेंट्रल प्रोसेसिंग यूनिट (CPU) की आंतरिक संरचना, उसके उप-घटक (ALU, CU, रजिस्टर), निर्देश निष्पादन चक्र और डेटा प्रविष्टि तथा प्रस्तुति के लिए उपयोग किए जाने वाले हार्डवेयर बाह्य उपकरणों (I/O डिवाइस) को कवर करता है। एसएससी सीजीएल टियर -2 के लिए, यह एक मुख्य स्कोरिंग मॉड्यूल है जहाँ सीधे सैद्धांतिक और वैचारिक प्रश्न बार-बार पूछे जाते हैं।

Learning Objectives for SSC CGLएसएससी सीजीएल के लिए अध्ययन उद्देश्य

  • Understand the detailed architecture of a CPU including ALU, Control Unit, and Register organization.ALU, कंट्रोल यूनिट और रजिस्टर संगठन सहित CPU की विस्तृत वास्तुकला को समझें।
  • Master the classification and technical specifications of various Input and Output devices.विभिन्न इनपुट और आउटपुट उपकरणों के वर्गीकरण और तकनीकी विनिर्देशों में महारत हासिल करें।
  • Learn about cache memory hierarchies, buses (Data, Address, Control), and instruction cycles.कैश मेमोरी पदानुक्रम, बस (डेटा, एड्रेस, कंट्रोल) और निर्देश चक्र के बारे में जानें।
  • Identify port types, connectivity standards, and standard peripheral interfaces.पोर्ट प्रकार, कनेक्टिविटी मानक और मानक परिधीय इंटरफेस की पहचान करें।

Concept Introductionमूल अवधारणा परिचय

Think of the computer as a human body: the CPU is the brain that processes thoughts and makes decisions, while Input/Output devices are the sensory organs (eyes, ears, hands) that interact with the outside world. The CPU processes data using electronic signals guided by clock pulses, fetching instructions from memory, decoding them, and executing them sequentially.

कंप्यूटर को एक मानव शरीर के रूप में सोचें: सीपीयू वह मस्तिष्क है जो विचारों को संसाधित करता है और निर्णय लेता है, जबकि इनपुट/आउटपुट डिवाइस संवेदी अंग (आँखें, कान, हाथ) हैं जो बाहरी दुनिया के साथ बातचीत करते हैं। सीपीयू घड़ी दालों द्वारा निर्देशित इलेक्ट्रॉनिक संकेतों का उपयोग करके डेटा को संसाधित करता है, मेमोरी से निर्देश प्राप्त करता है, उन्हें डिकोड करता है और उन्हें क्रमिक रूप से निष्पादित करता है।

Internal Components of the CPUसीपीयू के आंतरिक घटक

The Central Processing Unit is the primary component of a computer that executes instructions. It is broadly divided into three main units that work in tandem to process user commands.

सेंट्रल प्रोसेसिंग यूनिट कंप्यूटर का प्राथमिक घटक है जो निर्देशों को निष्पादित करता है। इसे मोटे तौर पर तीन मुख्य इकाइयों में विभाजित किया गया है जो उपयोगकर्ता आदेशों को संसाधित करने के लिए मिलकर काम करती हैं।

Arithmetic Logic Unit (ALU)अंकगणित तर्क इकाई (ALU)
Performs all arithmetic operations (addition, subtraction, multiplication, division) and logical operations (AND, OR, NOT, comparisons).सभी अंकगणितीय संचालन (जोड़, घटाव, गुणा, भाग) और तार्किक संचालन (AND, OR, NOT, तुलना) करता है।
Control Unit (CU)कंट्रोल यूनिट (CU)
Acts as the 'nervous system' of the computer, directing the operation of the processor, interpreting instructions, and coordinating data flow between memory and ALU.कंप्यूटर के 'तंत्रिका तंत्र' के रूप में कार्य करता है, प्रोसेसर के संचालन को निर्देशित करता है, निर्देशों की व्याख्या करता है, और मेमोरी और ALU के बीच डेटा प्रवाह का समन्वय करता है।
Registers / Processor Memoryरजिस्टर / प्रोसेसर मेमोरी
High-speed temporary storage locations inside the CPU (e.g., Accumulator, Program Counter, Memory Address Register, Instruction Register).सीपीयू के अंदर उच्च गति के अस्थायी भंडारण स्थान (जैसे, एक्युमलेटर, प्रोग्राम काउंटर, मेमोरी एड्रेस रजिस्टर, इंस्ट्रक्शन रजिस्टर)।

System Buses and Machine Cycleसिस्टम बस और मशीन चक्र

Communication inside the computer happens over physical wires called buses. The execution of a single instruction follows a strict machine cycle.

कंप्यूटर के अंदर संचार बस नामक भौतिक तारों के माध्यम से होता है। एक ही निर्देश का निष्पादन एक कड़े मशीन चक्र का पालन करता है।

Data Busडेटा बस
Bi-directional pathway that carries actual data between the CPU, memory, and peripherals.द्वि-दिशात्मक मार्ग जो CPU, मेमोरी और परिधीय उपकरणों के बीच वास्तविक डेटा ले जाता है।
Address Busएड्रेस बस
Uni-directional bus that carries memory addresses from the processor to other components.एक-दिशात्मक बस जो प्रोसेसर से अन्य घटकों तक मेमोरी पते ले जाती है।
Control Busकंट्रोल बस
Carries control signals, read/write commands, and timing pulses across the system.पूरे सिस्टम में नियंत्रण संकेत, रीड/राइट कमांड और टाइमिंग पल्स ले जाता है।
Fetch-Decode-Execute Cycleफेच-डिकोड-निष्पादन चक्र
The fundamental operational loop of a CPU: fetches instruction from memory, decodes it in the CU, and executes it using the ALU.CPU का मौलिक संचालन लूप: मेमोरी से निर्देश प्राप्त करता है, CU में इसे डिकोड करता है, और ALU का उपयोग करके इसे निष्पादित करता है।

Input and Output Devices Classificationइनपुट और आउटपुट डिवाइस वर्गीकरण

Peripherals allow humans to interface with the digital machine. They are categorized based on the direction of data flow.

परिधीय उपकरण मनुष्यों को डिजिटल मशीन के साथ इंटरफेस करने की अनुमति देते हैं। उन्हें डेटा प्रवाह की दिशा के आधार पर वर्गीकृत किया जाता है।

Input Devicesइनपुट डिवाइस
Convert physical user data into digital electrical signals (e.g., Keyboard, Mouse, Scanner, MICR, OMR, Barcode Reader, Joystick).भौतिक उपयोगकर्ता डेटा को डिजिटल विद्युत संकेतों में परिवर्तित करते हैं (जैसे, कीबोर्ड, माउस, स्कैनर, MICR, OMR, बारकोड रीडर, जॉयस्टिक)।
Output Devicesआउटपुट डिवाइस
Convert processed digital data into human-readable form (e.g., Monitor, Printer, Speaker, Plotter, Projector).संकेतित डिजिटल डेटा को मानव-पठनीय रूप में परिवर्तित करते हैं (जैसे, मॉनिटर, प्रिंटर, स्पीकर, प्लॉटर, प्रोजेक्टर)।
Hybrid/I/O Devicesहाइब्रिड/I/O डिवाइस
Devices that perform both input and output functions (e.g., Touchscreens, Modems, Network Cards, Headsets).वे उपकरण जो इनपुट और आउटपुट दोनों कार्य करते हैं (जैसे, टचस्क्रीन, मॉडेम, नेटवर्क कार्ड, हेडसेट)।

High-Yield SSC CGL Fact:उच्च-उपज वाला एसएससी सीजीएल तथ्य: Always remember that MICR (Magnetic Ink Character Recognition) is extensively used in banking for processing cheques, while OMR (Optical Mark Recognition) reads shaded circles on objective exam sheets. हमेशा याद रखें कि MICR (मैग्नेटिक इंक कैरेक्टर रिकग्निशन) का उपयोग बैंक में चेक संसाधित करने के लिए बड़े पैमाने पर किया जाता है, जबकि OMR (ऑप्टिकल मार्क रिकग्निशन) वस्तुनिष्ठ परीक्षा शीट पर छायांकित गोलों को पढ़ता है।

CPU Register Acronyms:सीपीयू रजिस्टर संक्षिप्त नाम: PC stands for Program Counter (holds the address of the next instruction), and MAR stands for Memory Address Register. Do not confuse them! PC का मतलब प्रोग्राम काउंटर है (अगले निर्देश का पता रखता है), और MAR का मतलब मेमोरी एड्रेस रजिस्टर है। उन्हें भ्रमित मत करो!

Touchscreen Classification Trap:टचस्क्रीन वर्गीकरण का जाल: Students often classify Touchscreens strictly as Input devices. In modern computers and smartphones, touchscreens are classified as Hybrid / I/O devices because they accept touch input and display visual output simultaneously. छात्र अक्सर टचस्क्रीन को सख्ती से इनपुट डिवाइस के रूप में वर्गीकृत करते हैं। आधुनिक कंप्यूटरों और स्मार्टफ़ोन में, टचस्क्रीन को हाइब्रिड / I/O डिवाइस के रूप में वर्गीकृत किया जाता है क्योंकि वे एक साथ टच इनपुट स्वीकार करते हैं और दृश्य आउटपुट प्रदर्शित करते हैं।

Key Takeaways (High-Yield Summary)मुख्य निष्कर्ष (त्वरित पुनरीक्षण)

  • The CPU consists of the Arithmetic Logic Unit (ALU), Control Unit (CU), and internal registers.CPU में अंकगणित तर्क इकाई (ALU), नियंत्रण इकाई (CU) और आंतरिक रजिस्टर होते हैं।
  • System buses include Data Bus (bi-directional), Address Bus (uni-directional), and Control Bus.सिस्टम बस में डेटा बस (द्वि-दिशात्मक), एड्रेस बस (एक-दिशात्मक) और कंट्रोल बस शामिल हैं।
  • MICR is used for cheque clearance in banks using magnetic iron oxide ink characters.मैग्नेटिक आयरन ऑक्साइड इंक कैरेक्टर का उपयोग करके बैंकों में चेक क्लीयरेंस के लिए MICR का उपयोग किया जाता है।
  • Laser printers use dry toner powder and heat fusion, making them the fastest for text printing.लेजर प्रिंटर सूखे टोनर पाउडर और हीट फ्यूजन का उपयोग करते हैं, जिससे वे टेक्स्ट प्रिंटिंग के लिए सबसे तेज हो जाते हैं।
  • A Barcode Reader utilizes light patterns (UPC standards) to read retail product codes.बारकोड रीडर खुदरा उत्पाद कोड पढ़ने के लिए प्रकाश पैटर्न (UPC मानकों) का उपयोग करता है।
  • The Program Counter (PC) register tracks the memory address of the next instruction to be executed.प्रोग्राम काउंटर (PC) रजिस्टर निष्فيذित होने वाले अगले निर्देश के मेमोरी पते को ट्रैक करता है।

Which of the following is considered the 'brain' of the computer?

Correct Answer: Option Bसही उत्तर: विकल्प B

The Central Processing Unit (CPU) is known as the brain of the computer because it handles all major calculations, data processing, and instruction execution.

सेंट्रल प्रोसेसिंग यूनिट (CPU) को कंप्यूटर का मस्तिष्क कहा जाता है क्योंकि यह सभी प्रमुख गणनाओं, डेटा प्रोसेसिंग और निर्देश निष्पादन को संभालता है।

Q2प्रश्न 2 EASYसरल

Which of the following is an input device?

निम्नलिखित में से कौन सा एक इनपुट डिवाइस है?

A keyboard is an input device used to enter data and commands into a computer. Monitor, printer, and speakers are output devices.

कीबोर्ड एक इनपुट डिवाइस है जिसका उपयोग कंप्यूटर में डेटा और कमांड दर्ज करने के लिए किया जाता है। मॉनिटर, प्रिंटर और स्पीकर आउटपुट डिवाइस हैं।

Q3प्रश्न 3 EASYसरल

What does ALU stand for in CPU architecture?

CPU आर्किटेक्चर में ALU का पूर्ण रूप क्या है?

Correct Answer: Option Aसही उत्तर: विकल्प A

ALU stands for Arithmetic Logic Unit. It performs all mathematical calculations and logical comparisons within the CPU.

ALU का पूर्ण रूप अरिथमेटिक लॉजिक यूनिट है। यह CPU के भीतर सभी गणितीय गणनाओं और तार्किक तुलनाओं को निष्पादित करता है।

Q4प्रश्न 4 EASYसरल

Which device is used to produce a hard copy of a document?

किसी दस्तावेज़ की हार्ड कॉपी प्राप्त करने के लिए किस डिवाइस का उपयोग किया जाता है?

Correct Answer: Option Dसही उत्तर: विकल्प D

Both printers and plotters produce hard copies. Printers output text/graphics on paper, while plotters produce vector graphics drawings.

प्रिंटर और प्लॉटर दोनों हार्ड कॉपी उत्पन्न करते हैं। प्रिंटर कागज पर टेक्स्ट/ग्राफिक्स आउटपुट करते हैं, जबकि प्लॉटर वेक्टर ग्राफिक्स ड्राइंग बनाते हैं।

Q5प्रश्न 5 EASYसरल

Which component of the CPU coordinates all the activities of the computer system?

CPU का कौन सा घटक कंप्यूटर सिस्टम की सभी गतिविधियों को समन्वित करता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

The Control Unit (CU) directs the operation of the processor, fetching instructions from memory and interpreting them to coordinate system activities.

कंट्रोल यूनिट (CU) प्रोसेसर के संचालन को निर्देशित करती है, मेमोरी से निर्देश प्राप्त करती है और सिस्टम गतिविधियों को समन्वित करने के लिए उनकी व्याख्या करती है।

Q6प्रश्न 6 EASYसरल

A joystick is an input device consisting of a stick that pivots on a base, widely used for controlling video games and simulations.

जॉयस्टिक एक इनपुट डिवाइस है जिसमें एक बेस पर घूमने वाली छड़ी होती है, जिसका उपयोग व्यापक रूप से वीडियो गेम और सिमुलेशन को नियंत्रित करने के लिए किया जाता है।

फ्लैटबेड स्कैनर पूरे दस्तावेजों को डिजिटल छवियों में ऑप्टिकल रूप से डिजिटाइज़ करते हैं, जबकि बारकोड स्कैनर मानकीकृत मशीन-पठनीय बारकोड लाइनों या QR मैट्रिसेस को पढ़ने के लिए प्रकाश सेंसर का उपयोग करते हैं।

In modern multi-core CPU architectures, what is 'Cache Coherency'?

आधुनिक मल्टी-कोर CPU आर्किटेक्चर में, 'कैश कोहेरेंसी' (Cache Coherency) क्या है?

Correct Answer: Option Aसही उत्तर: विकल्प A

Cache coherency ensures that data stored in multiple local core caches (e.g., L1/L2) remains consistent, preventing data conflicts when multiple cores access the same memory address.

कैश कोहेरेंसी यह सुनिश्चित करती है कि कई स्थानीय कोर कैश (जैसे L1/L2) में संग्रहीत डेटा सुसंगत बना रहे, जब कई कोर एक ही मेमोरी पते तक पहुँचते हैं तो डेटा संघर्ष को रोकता है।
