Concept Introductionमूल अवधारणा परिचय

The World Wide Web (WWW) functions on a Client-Server architecture where a Web Browser (client) requests web pages from a Web Server using protocols. Searching allows users to discover information across billions of indexed pages via Search Engines, while file transfer protocols enable data exchange between local and remote systems.

वर्ल्ड वाइड वेब (WWW) क्लाइंट-सर्वर आर्किटेक्चर पर काम करता है जहाँ एक वेब ब्राउज़र (क्लाइंट) प्रोटोकॉल का उपयोग करके वेब सर्वर से वेब पेज का अनुरोध करता है। सर्च इंजन के माध्यम से उपयोगकर्ता अरबों अनुक्रमित पृष्ठों पर जानकारी खोज सकते हैं, जबकि फ़ाइल ट्रांसफर प्रोटोकॉल स्थानीय और दूरस्थ प्रणालियों के बीच डेटा विनिमय को सक्षम करते हैं।

Web Browsers and Anatomy of a URLवेब ब्राउज़र और URL की संरचना

A web browser is application software used to access the World Wide Web. Popular examples include Google Chrome, Mozilla Firefox, Microsoft Edge, and Apple Safari. Every resource on the internet has a unique address known as a Uniform Resource Locator (URL).

वेब ब्राउज़र एप्लिकेशन सॉफ्टवेयर है जिसका उपयोग वर्ल्ड वाइड वेब तक पहुँचने के लिए किया जाता है। लोकप्रिय उदाहरणों में Google Chrome, Mozilla Firefox, Microsoft Edge और Apple Safari शामिल हैं। इंटरनेट पर प्रत्येक संसाधन का एक अनूठा पता होता है जिसे यूनिफॉर्म रिसोर्स लोकेटर (URL) कहा जाता है।

Search Engines and Web Crawlingसर्च इंजन और वेब क्रॉलिंग

Search engines are software systems designed to carry out web searches. They use automated programs called spiders, crawlers, or bots to fetch web pages, which are then indexed to deliver fast results matching user queries.

सर्च इंजन सॉफ़्टवेयर सिस्टम हैं जिन्हें वेब खोज करने के लिए डिज़ाइन किया गया है। वे स्पाइडर, क्रॉलर या बॉट नामक स्वचालित कार्यक्रमों का उपयोग करते हैं जो वेब पेज लाते हैं, जिन्हें बाद में उपयोगकर्ता के प्रश्नों से मेल खाने वाले तेज़ परिणाम देने के लिए अनुक्रमित (index) किया जाता है।

Web Crawlingवेब क्रॉलिंग

Indexingइंडेक्सिंग

File Transfer Protocols: Downloading and Uploadingफ़ाइल ट्रांसफर प्रोटोकॉल: डाउनलोडिंग और अपलोडिंग

Downloading refers to receiving data or files from a remote server to a local computer, whereas uploading means transmitting data or files from a local computer to a remote server. FTP (File Transfer Protocol) and SFTP are primary protocols governing these transfers.

डाउनलोडिंग का तात्पर्य किसी दूरस्थ सर्वर से स्थानीय कंप्यूटर पर डेटा या फ़ाइलें प्राप्त करने से है, जबकि अपलोडिंग का अर्थ स्थानीय कंप्यूटर से दूरस्थ सर्वर पर डेटा या फ़ाइलें भेजना है। FTP (फ़ाइल ट्रांसफर प्रोटोकॉल) और SFTP इन हस्तांतरणों को नियंत्रित करने वाले प्राथमिक प्रोटोकॉल हैं।

Download vs Upload Speed Asymmetry:डाउनलोड बनाम अपलोड गति विषमता: Students often confuse download bandwidth with upload bandwidth. Key Takeaways (High-Yield Summary)मुख्य निष्कर्ष (त्वरित पुनरीक्षण)

  • A Web Browser acts as a client requesting web pages, while Search Engines index and retrieve web content based on user queries.एक वेब ब्राउज़र वेब पेजों का अनुरोध करने वाले क्लाइंट के रूप में कार्य करता है, जबकि सर्च इंजन उपयोगकर्ता के प्रश्नों के आधार पर वेब सामग्री को अनुक्रमित और पुनर्प्राप्त करते हैं।
  • HTTPS uses SSL/TLS encryption protocol operating securely on TCP Port 443.HTTPS TCP पोर्ट 443 पर सुरक्षित रूप से काम करने वाले SSL/TLS एन्क्रिप्शन प्रोटोकॉल का उपयोग करता है।
  • FTP utilizes two separate ports: Port 20 for data connection and Port 21 for control connection.FTP दो अलग-अलग पोर्ट का उपयोग करता है: डेटा कनेक्शन के लिए पोर्ट 20 और नियंत्रण कनेक्शन के लिए पोर्ट 21।
  • Essential browser shortcut Ctrl+Shift+N opens an Incognito/Private browsing window which does not save local history.आवश्यक ब्राउज़र शॉर्टकट Ctrl+Shift+N एक इनकॉग्निटो/प्राइवेट ब्राउज़िंग विंडो खोलता है जो स्थानीय इतिहास को सहेजता नहीं है।
  • Web crawlers (spiders) automatically navigate the internet to discover, read, and index web pages for search engines.वेब क्रॉलर (स्पाइडर) सर्च इंजन के लिए वेब पेजों की खोज, पढ़ने और अनुक्रमण करने के लिए स्वचालित रूप से इंटरनेट पर नेविगेट करते हैं।

Q26प्रश्न 26 HARDकठिन

Which of the following describes 'Chunked Transfer Encoding' in HTTP, often used when downloading or streaming large web files?

HTTP में 'चंक्ड ट्रांसफर एन्कोडिंग' का वर्णन निम्नलिखित में से कौन करता है, जिसका उपयोग अक्सर बड़ी वेब फ़ाइलों को डाउनलोड या स्ट्रीम करते समय किया जाता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

Chunked transfer encoding allows data to be streamed from server to client in dynamically generated chunks, eliminating the need for the server to calculate the `Content-Length` header in advance.

चंक्ड ट्रांसफर एन्कोडिंग डेटा को गतिशील रूप से उत्पन्न चंक में सर्वर से क्लाइंट तक स्ट्रीम करने की अनुमति देती है, जिससे सर्वर को अग्रिम रूप से `Content-Length` हेडर की गणना करने की आवश्यकता समाप्त हो जाती है।

Q27प्रश्न 27 HARDकठिन

What is the primary vulnerability or limitation associated with HTTP compared to HTTPS during web browsing?

वेब ब्राउज़िंग के दौरान HTTPS की तुलना में HTTP से जुड़ी प्राथमिक कमज़ोरी या सीमा क्या है?

Correct Answer: Option Bसही उत्तर: विकल्प B

HTTP transmits data unencrypted (plaintext), meaning anyone intercepting network traffic can read sensitive information like passwords and credit card numbers, which HTTPS prevents via TLS encryption.

HTTP डेटा को बिना एन्क्रिप्ट किए (प्लेनटेक्स्ट) प्रसारित करता है, जिसका अर्थ है कि नेटवर्क ट्रैफ़िक को रोकने वाला कोई भी व्यक्ति पासवर्ड और क्रेडिट कार्ड नंबर जैसी संवेदनशील जानकारी पढ़ सकता है, जिसे HTTPS TLS एन्क्रिप्शन के माध्यम से रोकता है।

Q28प्रश्न 28 HARDकठिन

In the context of web browsers, what is a 'Browser Extension' or 'Add-on', and how does it interact with web pages?

वेब ब्राउज़र के संदर्भ में, 'ब्राउज़र एक्सटेंशन' या 'ऐड-ऑन' क्या है, और यह वेब पेजों के साथ कैसे इंटरैक्ट करता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

Browser extensions are modular software programs using web technologies that run inside the browser context, allowing them to customize the user interface, block ads, or modify webpage content via content scripts.

ब्राउज़र एक्सटेंशन वेब तकनीकों का उपयोग करने वाले मॉड्यूलर सॉफ्टवेयर प्रोग्राम हैं जो ब्राउज़र संदर्भ के भीतर चलते हैं, जिससे उन्हें यूजर इंटरफेस को अनुकूलित करने, विज्ञापनों को ब्लॉक करने या सामग्री स्क्रिप्ट के माध्यम से वेबपेज सामग्री को संशोधित करने की अनुमति मिलती है।

Q29प्रश्न 29 HARDकठिन

What does a search engine's 'Boolean SEARCH operator NOT (often represented by the minus sign `-` or `NOT` keyword)' accomplish?

सर्च इंजन का 'बूलियन सर्च ऑपरेटर NOT (जिसे अक्सर माइनस चिन्ह `-` या `NOT` कीवर्ड द्वारा दर्शाया जाता है)' क्या पूरा करता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

The NOT operator (or minus sign `-` with no space before it) tells the search engine to omit any search results that contain the keyword following the operator.

NOT ऑपरेटर (या इसके पहले बिना किसी स्थान के माइनस चिह्न `-`) सर्च इंजन को उन खोज परिणामों को छोड़ने के लिए कहता है जिनमें ऑपरेटर के बाद का कीवर्ड होता है।

Q30प्रश्न 30 HARDकठिन

Which of the following accurately explains how a web browser manages multiple concurrent HTTP/1.1 requests to a single domain?

निम्नलिखित में से कौन सा सटीक रूप से बताता है कि एक वेब ब्राउज़र किसी एकल डोमेन पर कई समवर्ती HTTP/1.1 अनुरोधों को कैसे प्रबंधित करता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

To prevent overwhelming web servers and routers, HTTP/1.1 specifications and modern browsers enforce a limit of around 6 simultaneous TCP connections per hostname, queueing excess requests.

वेब सर्वर और राउटर पर अत्यधिक भार डालने से रोकने के लिए, HTTP/1.1 विनिर्देश और आधुनिक ब्राउज़र प्रति होस्टनाम लगभग 6 समवर्ती TCP कनेक्शन की सीमा लागू करते हैं, जिससे अतिरिक्त अनुरोध कतारबद्ध हो जाते हैं।
