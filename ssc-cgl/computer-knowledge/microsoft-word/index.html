Microsoft Word

Complete study notes, interactive preparation checklists, core formulas, and practice questions for Microsoft Word under SSC CGL Tier 1 and Tier 2.

Microsoft Word: Complete Study Notesमाइक्रोसॉफ्ट वर्ड: संपूर्ण अध्ययन नोट्स

Quick Overviewत्वरित अवलोकन

Microsoft Word is a premier graphical word processing program developed by Microsoft, allowing users to type, edit, format, save, and print documents. For SSC CGL Tier 2, this module carries immense weight, focusing heavily on file extensions, default ribbon tabs, editing and formatting shortcuts, table manipulations, mail merge features, and advanced document views. Candidates are tested on both theoretical facts and practical application shortcuts.

माइक्रोसॉफ्ट वर्ड माइक्रोसॉफ्ट द्वारा विकसित एक प्रमुख ग्राफिकल वर्ड प्रोसेसिंग प्रोग्राम है, जो उपयोगकर्ताओं को दस्तावेज़ों को टाइप, संपादित, प्रारूपित, सहेजने और प्रिंट करने की अनुमति देता है। एसएससी सीजीएल टीयर 2 के लिए, इस मॉड्यूल का अत्यधिक महत्व है, जो फ़ाइल एक्सटेंशन, डिफ़ॉल्ट रिबन टैब, संपादन और स्वरूपण शॉर्टकट, तालिका हेरफेर, मेल मर्ज सुविधाओं और उन्नत दस्तावेज़ दृश्यों पर भारी ध्यान केंद्रित करता है।

  • Memorize high-yield keyboard shortcuts for text alignment, formatting, navigation, and ribbon commands frequently asked in exams.परीक्षाओं में बार-बार पूछे जाने वाले टेक्स्ट एलाइनमेंट, फॉर्मेटिंग, नेविगेशन और रिबन कमांड के लिए उच्च-उपज वाले कीबोर्ड शॉर्टकट याद रखें।
  • Understand the structure of the MS Word interface, including tabs, groups, the Quick Access Toolbar, and the Status Bar.टैब, समूहों, त्वरित पहुँच टूलबार और स्थिति पट्टी सहित MS Word इंटरफ़ेस की संरचना को समझें।
  • Comprehend advanced utility features such as Mail Merge, Track Changes, Macros, and Document Views.मेल मर्ज, ट्रैक चेंजेस, मैक्रोज़ और दस्तावेज़ दृश्यों जैसी उन्नत उपयोगिता सुविधाओं को समझें।

Concept Introductionमूल अवधारणा परिचय

Think of Microsoft Word as a digital typewriter combined with an advanced printing press and a publishing studio. Instead of physically typing on paper where mistakes require liquid paper or starting over, MS Word keeps your text in a flexible electronic buffer memory. Just as a physical office desk has specific tools organized neatly in drawers (staplers, paper clips, letterheads), MS Word organizes its tools into a Ribbon interface consisting of Tabs, Groups, and Commands, designed for rapid access during professional document creation.

माइक्रोसॉफ्ट वर्ड को एक डिजिटल टाइपराइटर के रूप में सोचें जो एक उन्नत प्रिंटिंग प्रेस और एक प्रकाशन स्टूडियो के साथ संयुक्त है। कागज पर भौतिक रूप से टाइप करने के बजाय जहाँ गलतियों के लिए करेक्शन फ्लूइड या फिर से शुरू करने की आवश्यकता होती है, MS Word आपके पाठ को एक लचीली इलेक्ट्रॉनिक बफर मेमोरी में रखता है। जिस तरह एक भौतिक कार्यालय की मेज पर दराज में बड़े करीने से व्यवस्थित विशिष्ट उपकरण होते हैं (स्टेप्लेर, पेपर क्लिप, लेटरहेड), वैसे ही MS Word अपने उपकरणों को रिबन इंटरफ़ेस में व्यवस्थित करता है जिसमें पेशेवर दस्तावेज़ निर्माण के दौरान त्वरित पहुँच के लिए टैब, समूह और कमांड शामिल होते हैं।

MS Word Interface & Ribbon ArchitectureMS Word इंटरफ़ेस और रिबन वास्तुकला

The MS Word application window consists of several standard components that facilitate navigation and document management. The Ribbon is the primary command center located right below the Title Bar, organized into tabs like Home, Insert, Design, Layout, References, Mailings, Review, and View.

MS Word एप्लिकेशन विंडो में कई मानक घटक होते हैं जो नेविगेशन और दस्तावेज़ प्रबंधन की सुविधा प्रदान करते हैं। रिबन शीर्षक पट्टी के ठीक नीचे स्थित प्राथमिक कमांड सेंटर है, जो होम, इंसर्ट, डिज़ाइन, लेआउट, रेफरेंस, मेलिंग, रिव्यू और व्यू जैसे टैब में व्यवस्थित है।

Title Barशीर्षक पट्टी (Title Bar)
Displays the active document name followed by the program name (e.g., 'Document1 - Word') and houses the Quick Access Toolbar and Window control buttons.प्रोग्राम नाम के बाद सक्रिय दस्तावेज़ का नाम प्रदर्शित करता है (जैसे, 'Document1 - Word') और इसमें त्वरित पहुँच टूलबार और विंडो नियंत्रण बटन होते हैं।
Status Barस्थिति पट्टी (Status Bar)
Located at the bottom of the window, it displays page numbers, word count, spelling/grammar check indicators, view shortcuts, and the zoom slider.विंडो के निचले भाग में स्थित, यह पृष्ठ संख्या, शब्द गणना, वर्तनी/व्याकरण जाँच संकेतक, दृश्य शॉर्टकट और ज़ूम स्लाइडर प्रदर्शित करता है।
Quick Access Toolbar (QAT)त्वरित पहुँच टूलबार (QAT)
A customizable toolbar placed typically above the Ribbon that houses frequently used commands like Save, Undo, and Redo regardless of the active tab.एक अनुकूलन योग्य टूलबार जिसे आमतौर पर रिबन के ऊपर रखा जाता है जो सक्रिय टैब की परवाह किए बिना सहेजें, पूर्ववत करें और फिर से करें जैसे अक्सर उपयोग किए जाने वाले कमांड रखता है।

File Formats, Extensions, and Document Statesफ़ाइल प्रारूप, एक्सटेंशन और दस्तावेज़ स्थिति

Every document saved in MS Word carries a specific extension that dictates its encoding and macro capabilities. Understanding these extensions is a high-yield area for SSC CGL questions.

MS Word में सहेजे गए प्रत्येक दस्तावेज़ में एक विशिष्ट एक्सटेंशन होता है जो इसके एन्कोडिंग और मैक्रो क्षमताओं को तय करता है। इन एक्सटेंशन को समझना एसएससी सीजीएल प्रश्नों के लिए एक उच्च-उपज वाला क्षेत्र है।

.docx.docx
The default file format for MS Word 2007 and later versions, based on OpenXML standards.OpenXML मानकों पर आधारित MS Word 2007 और बाद के संस्करणों के लिए डिफ़ॉल्ट फ़ाइल प्रारूप।
.doc.doc
The legacy binary file format used exclusively in MS Word 2003 and earlier versions.MS Word 2003 और उससे पहले के संस्करणों में विशेष रूप से उपयोग किया जाने वाला पुराना बाइनरी फ़ाइल प्रारूप।
.docm.docm
An XML-based Word document format that enables and saves VBA (Visual Basic for Applications) macros.एक XML-आधारित Word दस्तावेज़ प्रारूप जो VBA (विजुअल बेसिक फॉर एप्लीकेशन) मैक्रोज़ को सक्षम और सहेजता है।
.dotx.dotx
The standard template file format used to store predefined styles, layouts, and settings for new documents.नए दस्तावेज़ों के लिए पूर्व-परिभाषित शैलियों, लेआउट और सेटिंग्स को संग्रहीत करने के लिए उपयोग किया जाने वाला मानक टेम्पलेट फ़ाइल प्रारूप।

Advanced Utilities: Mail Merge & Macrosउन्नत उपयोगिताएँ: मेल मर्ज और मैक्रोज़

MS Word includes powerful professional tools designed to automate repetitive tasks and handle mass communications efficiently.

MS Word में दोहराए जाने वाले कार्यों को स्वचालित करने और बड़े पैमाने पर संचार को कुशलता से संभालने के लिए डिज़ाइन किए गए शक्तिशाली पेशेवर टूल शामिल हैं।

Mail Mergeमेल मर्ज (Mail Merge)
Combines a main document (form letter) with a data source (recipient list containing names and addresses) to generate personalized bulk letters, emails, labels, and envelopes.व्यक्तिगत थोक पत्र, ईमेल, लेबल और लिफाफे उत्पन्न करने के लिए एक मुख्य दस्तावेज़ (फॉर्म पत्र) को डेटा स्रोत (नाम और पते वाली प्राप्तकर्ता सूची) के साथ जोड़ता है।
Macrosमैक्रोज़ (Macros)
A sequence of instructions or keystrokes recorded using VBA to automate complex, repetitive multi-step editing or formatting tasks.जटिल, दोहराए जाने वाले बहु-चरण संपादन या स्वरूपण कार्यों को स्वचालित करने के लिए VBA का उपयोग करके रिकॉर्ड किए गए निर्देशों या कीस्ट्रोक्स का एक क्रम।
Track Changesट्रैक चेंजेस (Track Changes)
A review feature that marks every addition, deletion, and formatting change made by an editor, allowing the primary author to accept or reject revisions.एक समीक्षा सुविधा जो किसी संपादक द्वारा किए गए प्रत्येक जोड़, विलोपन और स्वरूपण परिवर्तन को चिह्नित करती है, जिससे प्राथमिक लेखक को संशोधनों को स्वीकार या अस्वीकार करने की अनुमति मिलती है।

SSC CGL Question Pattern:एसएससी सीजीएल प्रश्न पैटर्न: Examiners frequently ask questions combining keyboard shortcuts with specific formatting tasks (e.g., Ctrl + Shift + > for increasing font size or Ctrl + E for center alignment). Memorize shortcut keys and default font names (Calibri in Office 2007+, Times New Roman previously) along with default font sizes (11 pt for Calibri). परीक्षक अक्सर कीबोर्ड शॉर्टकट को विशिष्ट स्वरूपण कार्यों (जैसे, फ़ॉन्ट आकार बढ़ाने के लिए Ctrl + Shift + > या केंद्र संरेखण के लिए Ctrl + E) के साथ मिलाकर प्रश्न पूछते हैं। डिफ़ॉल्ट फ़ॉन्ट आकार (Calibri के लिए 11 pt) के साथ शॉर्टकट कुंजियों और डिफ़ॉल्ट फ़ॉन्ट नामों (Office 2007+ में Calibri, पहले Times New Roman) को याद रखें।

Golden Rule of Mail Merge Components:मेल मर्ज घटकों का स्वर्ण नियम: Mail Merge strictly requires two essential files: the Main Document (containing the constant text and layout) and the Data Source (containing variable recipient records like Excel sheets or Access databases). मेल मर्ज के लिए सख्ती से दो आवश्यक फ़ाइलों की आवश्यकता होती है: मुख्य दस्तावेज़ (स्थिर पाठ और लेआउट युक्त) और डेटा स्रोत (चर प्राप्तकर्ता रिकॉर्ड जैसे Excel शीट या Access डेटाबेस युक्त)।

Common Trap: .docx vs .docm:सामान्य भ्रम: .docx बनाम .docm: Students often assume standard `.docx` files can save macros. Remember that `.docx` files strip out macros for security reasons. To save a document containing VBA macros, you must explicitly save it as `.docm` (Word Macro-Enabled Document). छात्र अक्सर यह मान लेते हैं कि मानक `.docx` फ़ाइलें मैक्रोज़ सहेज सकती हैं। याद रखें कि सुरक्षा कारणों से `.docx` फ़ाइलें मैक्रोज़ को हटा देती हैं। VBA मैक्रोज़ वाले दस्तावेज़ को सहेजने के लिए, आपको इसे स्पष्ट रूप से `.docm` (Word मैक्रो-सक्षम दस्तावेज़) के रूप में सहेजना होगा।

Key Takeaways (High-Yield Summary)मुख्य निष्कर्ष (त्वरित पुनरीक्षण)

  • The default extension for Word documents starting from MS Office 2007 is .docx, based on OpenXML architecture.MS Office 2007 से शुरू होने वाले Word दस्तावेज़ों के लिए डिफ़ॉल्ट एक्सटेंशन .docx है, जो OpenXML आर्किटेक्चर पर आधारित है।
  • The default font family in MS Word 2007+ is Calibri with a default size of 11 points.MS Word 2007+ में डिफ़ॉल्ट फ़ॉन्ट परिवार Calibri है जिसका डिफ़ॉल्ट आकार 11 पॉइंट है।
  • Mail Merge consists of two primary components: Main Document and Data Source.मेल मर्ज में दो प्राथमिक घटक होते हैं: मुख्य दस्तावेज़ और डेटा स्रोत।
  • Shortcuts: Ctrl + J for Justify alignment, Ctrl + L for Left alignment, Ctrl + R for Right alignment, and Ctrl + E for Center alignment.शॉर्टकट: जस्टिफ़ाई एलाइनमेंट के लिए Ctrl + J, लेफ्ट एलाइनमेंट के लिए Ctrl + L, राइट एलाइनमेंट के लिए Ctrl + R, और सेंटर एलाइनमेंट के लिए Ctrl + E।
  • Print Layout is the default viewing mode that displays exact margins, headers, footers, and page breaks.प्रिंट लेआउट डिफ़ॉल्ट देखने का मोड है जो सटीक मार्जिन, हेडर, फुटर और पेज ब्रेक प्रदर्शित करता है।
  • Track Changes tool allows collaborative editing by recording insertions, deletions, and format changes.ट्रैक चेंजेस टूल प्रविष्टि, विलोपन और प्रारूप परिवर्तन को रिकॉर्ड करके सहयोगात्मक संपादन की अनुमति देता है।

Q1प्रश्न 1 EASYसरल

What is the default file extension for documents created in Microsoft Word 2016 and later versions?

माइक्रोसॉफ्ट वर्ड 2016 और बाद के संस्करणों में बनाई गई फाइलों के लिए डिफ़ॉल्ट फ़ाइल एक्सटेंशन क्या है?
