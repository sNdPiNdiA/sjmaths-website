Quick Overviewत्वरित अवलोकन

Microsoft Excel is a powerful electronic spreadsheet program developed by Microsoft, used for data organization, mathematical calculations, statistical analysis, and graphical visualization. For the SSC CGL Tier-2 Computer Knowledge module, mastery of MS Excel is crucial as it constitutes a major share of questions involving workbook architecture, formula syntax, function categories, cell referencing, and essential keyboard shortcuts.

माइक्रोसॉफ्ट एक्सेल माइक्रोसॉफ्ट द्वारा विकसित एक शक्तिशाली इलेक्ट्रॉनिक स्प्रेडशीट प्रोग्राम है, जिसका उपयोग डेटा संगठन, गणितीय गणना, सांख्यिकी विश्लेषण और ग्राफिकल विज़ुअलाइज़ेशन के लिए किया जाता है। एसएससी सीजीएल टीयर-2 कंप्यूटर ज्ञान मॉड्यूल के लिए, एमएस एक्सेल में महारत हासिल करना महत्वपूर्ण है क्योंकि इसमें वर्कबुक आर्किटेक्चर, फॉर्मूला सिंटैक्स, फ़ंक्शन श्रेणियां, सेल संदर्भ और आवश्यक कीबोर्ड शॉर्टकट से जुड़े प्रश्नों का एक बड़ा हिस्सा शामिल होता है।

Concept Introductionमूल अवधारणा परिचय

Imagine a digital ledger book where every page is a 'Worksheet' divided into a grid of intersecting horizontal rows and vertical columns. The intersection of a row and column creates a 'Cell', which serves as the fundamental container for data. Just like a physical ledger automatically recalculates totals when numbers change, Excel instantly updates outputs across dependent cells using mathematical formulas and functions, serving as the backbone of modern corporate and government data management.

एक डिजिटल बहीखाता (ledger book) की कल्पना करें जहाँ प्रत्येक पृष्ठ क्षैतिज पंक्तियों और ऊर्ध्वाधर कॉलम के चौराहे की एक ग्रिड में विभाजित 'वर्कशीट' है। एक पंक्ति और कॉलम का चौराहा एक 'सेल' बनाता है, जो डेटा के लिए बुनियादी कंटेनर के रूप में कार्य करता है। जिस प्रकार एक भौतिक बहीखाता संख्याएं बदलने पर कुल योग की स्वतः गणना करता है, उसी तरह एक्सेल गणितीय सूत्रों और कार्यों का उपयोग करके निर्भर सेल में आउटपुट को तुरंत अपडेट करता है, जो आधुनिक कॉर्पोरेट और सरकारी डेटा प्रबंधन की रीढ़ के रूप में कार्य करता है।

Workbook Architecture and Grid Limitsवर्कबुक आर्किटेक्चर और ग्रिड सीमाएं

An Excel file is known as a Workbook, saved with the default extension .xlsx (introduced in Excel 2007). Each workbook contains one or more worksheets. Understanding the exact dimensional limits of an Excel sheet is a favorite area for SSC CGL examiners.

Formulas, Functions, and Cell Referencingफॉर्मूला, फ़ंक्शन और सेल रेफरेंसिंग

All formulas in Excel must begin with an equal sign (=). Without it, Excel treats the entry as plain text. Functions are predefined formulas that perform calculations using specific arguments in a structured syntax.

एक्सेल में सभी फॉर्मूला एक बराबर चिह्न (=) से शुरू होने चाहिए। इसके बिना, एक्सेल प्रविष्टि को सादे पाठ के रूप में मानता है। फ़ंक्शन पूर्व-परिभाषित फॉर्मूला हैं जो एक संरचित सिंटैक्स में विशिष्ट तर्कों का उपयोग करके गणना करते हैं।

Relative Referenceसापेक्ष संदर्भ (Relative Reference)
Standard references like A1 that change automatically when the formula is copied to another cell.A1 जैसे मानक संदर्भ जो फॉर्मूला को दूसरे सेल में कॉपी करने पर स्वचालित रूप से बदल जाते हैं।
Absolute Referenceपूर्ण संदर्भ (Absolute Reference)
Uses dollar signs ($A$1) to lock both row and column references so they remain constant during copy operations.पंक्ति और कॉलम दोनों संदर्भों को लॉक करने के लिए डॉलर चिन्ह ($A$1) का उपयोग करता है ताकि कॉपी संचालन के दौरान वे स्थिर रहें।
Mixed Referenceमिश्रित संदर्भ (Mixed Reference)
Locks either the row or the column using a single dollar sign, such as $A1 or A$1.एक ही डॉलर चिन्ह का उपयोग करके या तो पंक्ति या कॉलम को लॉक करता है, जैसे $A1 या A$1।

Remember This: Order of Operations:इसे याद रखें: संचालन का क्रम (BODMAS): Excel evaluates formulas using standard mathematical precedence: Parentheses (), Exponents (^), Multiplication and Division (* and /), and Addition and Subtraction (+ and -). Use parentheses to explicitly control calculation order. एक्सेल मानक गणितीय प्राथमिकता का उपयोग करके फॉर्मूला का मूल्यांकन करता है: कोष्ठक (), घातांक (^), गुणा और भाग (* और /), और जोड़ और घटाव (+ और -)। गणना क्रम को स्पष्ट रूप से नियंत्रित करने के लिए कोष्ठक का उपयोग करें।

Common Mistake: Missing Equal Sign:सामान्य गलती: बराबर चिह्न छोड़ना: Students often type 'SUM(A1:A5)' instead of '=SUM(A1:A5)'. Without the leading equal sign, Excel treats the expression as plain text rather than executing the formula. छात्र अक्सर '=SUM(A1:A5)' के बजाय 'SUM(A1:A5)' टाइप करते हैं। अग्रणी बराबर चिह्न के बिना, एक्सेल फॉर्मूला निष्पादित करने के बजाय अभिव्यक्ति को सादे पाठ के रूप में मानता है।

Q1प्रश्न 1 EASYसरल

What is the default file extension for a workbook saved in Microsoft Excel 2016 and later versions?

माइक्रोसॉफ्ट एक्सेल 2016 और बाद के संस्करणों में सहेजी गई वर्कबुक के लिए डिफ़ॉल्ट फ़ाइल एक्सटेंशन क्या है?

Correct Answer: Option Bसही उत्तर: विकल्प B

The default file extension for Excel workbooks from Excel 2007 onwards is .xlsx, which is based on the OpenXML standard. .xls was used in older versions up to Excel 2003.

Which symbol must always begin a formula in Microsoft Excel?

Q3प्रश्न 3 EASYसरल

What is the intersection of a row and a column in an Excel worksheet called?

एक्सेल वर्कशीट में एक पंक्ति (row) और एक कॉलम के प्रतिच्छेदन (intersection) को क्या कहा जाता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

The intersection of a row and a column is called a cell, which is the basic unit for storing data in a worksheet.

एक पंक्ति और एक कॉलम के प्रतिच्छेदन को सेल कहा जाता है, जो वर्कशीट में डेटा संग्रहीत करने की मूल इकाई है।

Q4प्रश्न 4 EASYसरल

Which of the following shortcuts is used to save an active workbook in Excel?

एक्सेल में एक सक्रिय वर्कबुक को सहेजने (save) के लिए निम्नलिखित में से किस शॉर्टकट का उपयोग किया जाता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

Ctrl + S is the universal shortcut for saving the current file. Ctrl + N opens a new workbook, and Ctrl + O opens an existing one.

Ctrl + S वर्तमान फ़ाइल को सहेजने के लिए सार्वभौमिक शॉर्टकट है। Ctrl + N एक नई वर्कबुक खोलता है, और Ctrl + O एक मौजूदा वर्कबुक खोलता है।

What is the function used to find the sum of a range of cells in Excel?

The formula =SUMPRODUCT(1/COUNTIF(A1:A10, A1:A10 & "")) is a classic advanced Excel technique to count unique items while gracefully handling blank cells without producing a #DIV/0! error.

फॉर्मूला =SUMPRODUCT(1/COUNTIF(A1:A10, A1:A10 & "")) #DIV/0! त्रुटि उत्पन्न किए बिना खाली सेल को सुचारू रूप से संभालते हुए अद्वितीय वस्तुओं की गिनती करने के लिए एक क्लासिक उन्नत एक्सेल तकनीक है।

What will be the output of the formula: =CHOOSE(3, "Apple", "Banana", "Cherry", "Date")?

फॉर्मूला का आउटपुट क्या होगा: =CHOOSE(3, "Apple", "Banana", "Cherry", "Date")?

Correct Answer: Option Cसही उत्तर: विकल्प C

The CHOOSE function returns a value from a list of values based on the index number specified as the first argument. Since index_num is 3, it returns the 3rd item: "Cherry".

CHOOSE फ़ंक्शन पहले तर्क के रूप में निर्दिष्ट सूचकांक संख्या के आधार पर मानों की सूची से एक मान लौटाता है। चूंकि index_num 3 है, यह तीसरी वस्तु लौटाता है: "Cherry"।

Which of the following describes the behavior of Flash Fill in Microsoft Excel?

निम्नलिखित में से कौन सा माइक्रोसॉफ्ट एक्सेल में फ्लैश फिल (Flash Fill) के व्यवहार का वर्णन करता है?

Flash Fill (Ctrl + E) senses patterns in data entry (such as splitting first and last names) and automatically fills the remaining cells when a pattern is established.

What error value is returned by Excel when a formula or function contains numeric values that are invalid for the operation (e.g., SQRT(-1))?

जब किसी फॉर्मूला या फ़ंक्शन में संख्यात्मक मान होते हैं जो ऑपरेशन के लिए अमान्य हैं (उदा. SQRT(-1)), तो एक्सेल द्वारा कौन सी त्रुटि मान लौटाया जाता है?

Correct Answer: Option Aसही उत्तर: विकल्प A

#NUM! error occurs when a formula or function has invalid numeric values, such as taking the square root of a negative number or exceeding Excel's calculation limits.

#NUM! त्रुटि तब होती है जब किसी फॉर्मूला या फ़ंक्शन में अमान्य संख्यात्मक मान होते हैं, जैसे कि ऋणात्मक संख्या का वर्गमूल निकालना या एक्सेल की गणना सीमाओं से अधिक होना।
