MS Office: MS Word, MS Excel, MS PowerPoint

Complete study notes, interactive preparation checklists, core concepts, and practice questions for MS Office: MS Word, MS Excel, MS PowerPoint under SSC CGL.

MS Office: MS Word, MS Excel, MS PowerPoint: Complete Study Notesएमएस ऑफिस: एमएस वर्ड, एमएस एक्सेल, एमएस पावरपॉइंट: संपूर्ण अध्ययन नोट्स

Quick Overviewत्वरित अवलोकन

This module covers the core productivity applications of Microsoft Office suite: MS Word for word processing, MS Excel for spreadsheet calculations and data analysis, and MS PowerPoint for professional presentations. For the SSC CGL Tier-2 Computer Proficiency Module, this topic holds supreme weightage, with questions frequently testing file extensions, shortcut keys, formula syntax, formatting options, and interface components.

यह मॉड्यूल माइक्रोसॉफ्ट ऑफिस सूट के मुख्य उत्पादकता अनुप्रयोगों को कवर करता है: वर्ड प्रोसेसिंग के लिए एमएस वर्ड, स्प्रेडशीट गणना और डेटा विश्लेषण के लिए एमएस एक्सेल, और पेशेवर प्रस्तुतियों के लिए एमएस पावरपॉइंट। एसएससी सीजीएल टियर-2 कंप्यूटर प्रवीणता मॉड्यूल के लिए, इस विषय का अत्यधिक महत्व है, जिसमें फाइल एक्सटेंशन, शॉर्टकट कुंजियाँ, फॉर्मूला सिंटैक्स, फॉर्मेटिंग विकल्प और इंटरफेस घटकों से संबंधित प्रश्न बार-बार पूछे जाते हैं।

Concept Introductionमूल अवधारणा परिचय

Microsoft Office applications act as the digital desk of a modern professional. Just as a physical office requires a notepad for writing, a ledger for calculations, and a whiteboard for presentations, MS Office provides MS Word, MS Excel, and MS PowerPoint respectively. SSC CGL questions evaluate your practical awareness of these tools, testing whether you know how data flows, how formatting is applied, and what specific technical limits or defaults govern these applications.

माइक्रोसॉफ्ट ऑफिस एप्लिकेशन एक आधुनिक पेशेवर के डिजिटल डेस्क के रूप में कार्य करते हैं। जैसे एक भौतिक कार्यालय को लिखने के लिए पैड, गणना के लिए बहीखाता और प्रस्तुतियों के लिए व्हाइटबोर्ड की आवश्यकता होती है, वैसे ही एमएस ऑफिस क्रमशः एमएस वर्ड, एमएस एक्सेल और एमएस पावरपॉइंट प्रदान करता है। एसएससी सीजीएल प्रश्न इन उपकरणों के बारे में आपकी व्यावहारिक जागरूकता का मूल्यांकन करते हैं, यह परीक्षण करते हैं कि क्या आप जानते हैं कि डेटा कैसे प्रवाहित होता है, फॉर्मेटिंग कैसे लागू होती है, और कौन सी विशिष्ट तकनीकी सीमाएं या डिफ़ॉल्ट इन अनुप्रयोगों को नियंत्रित करते हैं।

MS Word: Word Processing & Document Managementएमएस वर्ड: वर्ड प्रोसेसिंग और डॉक्यूमेंट मैनेजमेंट

MS Word is a powerful word processor used to create professional documents, reports, letters, and resumes. It provides advanced formatting, spelling and grammar check, mail merge, and tracking features.

एमएस वर्ड एक शक्तिशाली वर्ड प्रोसेसर है जिसका उपयोग पेशेवर दस्तावेजों, रिपोर्टों, पत्रों और बायोडाटा को बनाने के लिए किया जाता है। यह उन्नत फॉर्मेटिंग, स्पेलिंग और ग्रामर चेक, मेल मर्ज और ट्रैकिंग सुविधाएं प्रदान करता है।

File Extensionsफाइल एक्सटेंशन
Default modern format is .docx (XML-based since Office 2007). Legacy format is .doc. Macro-enabled template uses .dotm.डिफ़ॉल्ट आधुनिक फॉर्मेट .docx (Office 2007 से XML-आधारित) है। पुराना फॉर्मेट .doc है। मैक्रो-सक्षम टेम्पलेट .dotm का उपयोग करता है।
Mail Mergeमेल मर्ज
Combines a main document (letter) with a data source (recipient list) to generate personalized bulk letters, labels, or emails.व्यक्तिगत थोक पत्र, लेबल या ईमेल जनरेट करने के लिए मुख्य दस्तावेज़ (पत्र) को डेटा स्रोत (प्राप्तकर्ता सूची) के साथ जोड़ता है।
Formatting Limitsफॉर्मेटिंग सीमाएं
Default font size drop-down ranges from 8 to 72 points, but manual entry allows 1 to 1638 points.डिफ़ॉल्ट फ़ॉन्ट साइज़ ड्रॉप-डाउन 8 से 72 पॉइंट तक होता है, लेकिन मैन्युअल प्रविष्टि 1 से 1638 पॉइंट की अनुमति देती है।

MS Excel: Spreadsheets, Formulas & Data Analysisएमएस एक्सेल: स्प्रेडशीट, फॉर्मूला और डेटा विश्लेषण

MS Excel is an electronic spreadsheet application organized into rows and numbers, and columns represented by alphabets. Intersection of a row and column forms a Cell.

एमएस एक्सेल एक इलेक्ट्रॉनिक स्प्रेडशीट एप्लिकेशन है जो पंक्तियों (संख्याओं द्वारा) और स्तंभों (वर्णमाला द्वारा दर्शाए गए) में व्यवस्थित होता है। पंक्ति और स्तंभ का प्रतिच्छेदन एक सेल बनाता है।

Cell Addressing & Formulasसेल एड्रेसिंग और फॉर्मूला
All formulas must begin with an equals sign (=). Absolute referencing uses dollar signs ($A$1), while relative referencing changes when copied (A1).सभी फॉर्मूला की शुरुआत बराबर चिह्न (=) से होनी चाहिए। एब्सोल्यूट रेफरेंसिंग डॉलर चिन्ह ($A$1) का उपयोग करती है, जबकि रिलेटिव रेफरेंसिंग कॉपी करने पर बदल जाती है (A1)।
Error Codesएरर कोड
#DIV/0! (division by zero), #VALUE! (wrong data type), #REF! (invalid cell reference), #NAME? (unrecognized text in formula), #NUM! (invalid numeric values).#DIV/0! (शून्य से विभाजन), #VALUE! (गलत डेटा प्रकार), #REF! (अमान्य सेल संदर्भ), #NAME? (फॉर्मूला में अनपहचाना टेक्स्ट), #NUM! (अमान्य संख्यात्मक मान)।
Grid Dimensionsग्रिड आयाम
Excel worksheet contains 1,048,576 rows and 16,384 columns (ending at column XFD) in modern versions.आधुनिक संस्करणों में एक्सेल वर्कशीट में 1,048,576 पंक्तियाँ और 16,384 कॉलम (स्तंभ XFD पर समाप्त) होते हैं।

MS PowerPoint: Presentations & Slide Masterएमएस पावरपॉइंट: प्रस्तुतियाँ और स्लाइड मास्टर

MS PowerPoint is a presentation program used to create multimedia slide decks. It incorporates text, graphics, audio, video, and animation effects.

एमएस पावरपॉइंट मल्टीमीडिया स्लाइड डेक बनाने के लिए उपयोग किया जाने वाला एक प्रस्तुति प्रोग्राम है। इसमें टेक्स्ट, ग्राफिक्स, ऑडियो, वीडियो और एनिमेशन प्रभाव शामिल होते हैं।

Slide Masterस्लाइड मास्टर
Controls the global formatting, fonts, logos, and background design across all slides in a presentation.एक प्रस्तुति में सभी स्लाइडों में वैश्विक फॉर्मेटिंग, फ़ॉन्ट, लोगो और पृष्ठभूमि डिज़ाइन को नियंत्रित करता है।
Slide Viewsस्लाइड व्यू
Normal View, Slide Sorter View (displays thumbnail grid for reordering), Reading View, and Slide Show View (F5).नॉर्मल व्यू, स्लाइड सॉर्टर व्यू (पुनः व्यवस्थित करने के लिए थंबनेल ग्रिड प्रदर्शित करता है), रीडिंग व्यू, और स्लाइड शो व्यू (F5)।
File Formatsफाइल फॉर्मेट
Standard presentation (.pptx), PowerPoint Show (.ppsx - opens directly in presentation mode), and Template (.potx).मानक प्रस्तुति (.pptx), पावरपॉइंट शो (.ppsx - सीधे प्रस्तुति मोड में खुलता है), और टेम्पलेट (.potx)।

SSC CGL Shortcut Frequency:एसएससी सीजीएल शॉर्टकट आवृत्ति: SSC frequently asks function keys and shortcut combinations. Remember Ctrl+K (Hyperlink), Ctrl+F (Find), Ctrl+H (Replace), F7 (Spelling & Grammar), and F12 (Save As). एसएससी अक्सर फंक्शन कीज़ और शॉर्टकट संयोजन पूछता है। Ctrl+K (हाइपरलिंक), Ctrl+F (ढूंढें), Ctrl+H (बदलें), F7 (स्पेलिंग और ग्रामर), और F12 (सेव एज) को याद रखें।

Excel Formula Prefix Rule:एक्सेल फॉर्मूला उपसर्ग नियम: Always remember that typing text like SUM(A1:A5) without an equals sign (=) treats it as plain text, not a formula. The '=' sign is mandatory to trigger calculation. हमेशा याद रखें कि बिना बराबर चिह्न (=) के SUM(A1:A5) जैसा टेक्स्ट टाइप करने पर इसे सादे टेक्स्ट के रूप में माना जाता है, फॉर्मूला के रूप में नहीं। गणना शुरू करने के लिए '=' चिह्न अनिवार्य है।

Confusing .xlsx and .xls:.xlsx और .xls में भ्रम: Do not confuse modern Office XML extensions (.docx, .xlsx, .pptx) introduced in Office 2007 with older binary formats (.doc, .xls, .ppt). The 'x' signifies XML architecture. Office 2007 में पेश किए गए आधुनिक Office XML एक्सटेंशन (.docx, .xlsx, .pptx) को पुराने बाइनरी फॉर्मेट (.doc, .xls, .ppt) के साथ भ्रमित न करें। 'x' XML आर्किटेक्चर को दर्शाता है।

  • Excel formulas always begin with an equals sign (=).एक्सेल फॉर्मूला हमेशा बराबर चिह्न (=) से शुरू होते हैं।
  • F5 starts a PowerPoint slide show from the beginning; Shift+F5 starts from the current slide.F5 शुरुआत से पावरपॉइंट स्लाइड शो शुरू करता है; Shift+F5 वर्तमान स्लाइड से शुरू करता है।
  • F7 is the universal shortcut for Spelling and Grammar check in MS Office applications.F7 एमएस ऑफिस अनुप्रयोगों में स्पेलिंग और ग्रामर चेक के लिए सार्वभौमिक शॉर्टकट है।
  • Excel grid consists of 1,048,576 rows and 16,384 columns.एक्सेल ग्रिड में 1,048,576 पंक्तियाँ और 16,384 कॉलम होते हैं।
  • Slide Master controls global layout properties across all presentation slides.स्लाइड मास्टर सभी प्रस्तुति स्लाइडों में वैश्विक लेआउट गुणों को नियंत्रित करता है।

What is the default extension of a file created in MS Word 2016 and later versions?

MS Word 2016 और बाद के संस्करणों में बनाई गई फ़ाइल का डिफ़ॉल्ट एक्सटेंशन क्या है?

Correct Answer: Option Bसही उत्तर: विकल्प B

Starting from MS Word 2007, the default file extension was changed from .doc to .docx, which stands for Document in XML format.

MS Word 2007 से शुरू होकर, डिफ़ॉल्ट फ़ाइल एक्सटेंशन .doc से बदलकर .docx कर दिया गया, जिसका अर्थ XML प्रारूप में दस्तावेज़ है।

Which of the following components is used to display the current status and page number in MS Word?

The Status Bar is located at the bottom of the MS Word window and displays information like page number, word count, and zoom level.

स्थिति पट्टी MS Word विंडो के निचले भाग में स्थित होती है और पृष्ठ संख्या, शब्द गणना और ज़ूम स्तर जैसी जानकारी प्रदर्शित करती है।

In MS Excel, a collection of worksheets is known as what?

Q4प्रश्न 4 EASYसरल

What is the intersection of a row and a column in MS Excel called?

MS Excel में एक पंक्ति (row) और एक स्तम्भ (column) के प्रतिच्छेदन को क्या कहा जाता है?

Correct Answer: Option Bसही उत्तर: विकल्प B

The intersection of a row and a column in a worksheet is called a cell, which is identified by a unique cell address (e.g., A1).

वर्कशीट में एक पंक्ति और एक कॉलम के प्रतिच्छेदन को सेल कहा जाता है, जिसकी पहचान एक अद्वितीय सेल पते (जैसे, A1) द्वारा की जाती है।

F12 MS Office अनुप्रयोगों में सीधे 'Save As' संवाद बॉक्स खोलता है। (नोट: Ctrl + S फ़ाइल को सहेजता है, लेकिन F12 विशेष रूप से Save As लाता है)।

In MS PowerPoint, what is the default view called where you create and edit individual slides?

MS PowerPoint में, उस डिफ़ॉल्ट दृश्य को क्या कहा जाता है जहाँ आप व्यक्तिगत स्लाइड बनाते और संपादित करते हैं?

What is the output of the MS Excel formula `=MOD(MOD(17, 3), 2)`?

MS Excel सूत्र `=MOD(MOD(17, 3), 2)` का आउटपुट क्या होगा?

Correct Answer: Option Aसही उत्तर: विकल्प A

First evaluate inner MOD: `MOD(17, 3)` returns the remainder of 17 divided by 3, which is 2. Then evaluate outer MOD: `MOD(2, 2)` returns the remainder of 2 divided by 2, which is 0... wait, let's recalculate: 17 = 3*5 + 2, so MOD(17,3) = 2. Then MOD(2, 2) = 0. Let's check options: A=2, B=1, C=0, D=5. The answer is 0, which corresponds to option C.

पहले आंतरिक MOD का मूल्यांकन करें: `MOD(17, 3)` 17 को 3 से भाग देने पर शेषफल 2 देता है। फिर बाहरी MOD का मूल्यांकन करें: `MOD(2, 2)` 2 को 2 से भाग देने पर शेषफल 0 देता है। सही उत्तर 0 (विकल्प C) है।
