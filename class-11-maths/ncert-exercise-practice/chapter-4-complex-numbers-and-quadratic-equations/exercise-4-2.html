Find the modulus and the argument of the complex number $z = -1 - i\sqrt{3}$.
Let $z = r(\cos \theta + i \sin \theta)$. Here $x = -1, y = -\sqrt{3}$.
Modulus $r = \sqrt{x^2 + y^2} = \sqrt{(-1)^2 + (-\sqrt{3})^2} = \sqrt{1+3} = \sqrt{4} = 2$.
Let $\alpha$ be the acute angle such that $\tan \alpha = |\frac{y}{x}| = |\frac{-\sqrt{3}}{-1}| = \sqrt{3}$. So $\alpha = \frac{\pi}{3}$.
Since $x < 0$ and $y < 0$, the point lies in the third quadrant.
Argument $\theta = -(\pi - \alpha) = -(\pi - \frac{\pi}{3}) = -\frac{2\pi}{3}$.
Modulus = 2, Argument = $-\frac{2\pi}{3}$

Find the modulus and the argument of the complex number $z = -\sqrt{3} + i$.
Let $z = r(\cos \theta + i \sin \theta)$. Here $x = -\sqrt{3}, y = 1$.
Modulus $r = \sqrt{(-\sqrt{3})^2 + 1^2} = \sqrt{3+1} = 2$.
Let $\alpha$ be acute angle: $\tan \alpha = |\frac{1}{-\sqrt{3}}| = \frac{1}{\sqrt{3}}$. So $\alpha = \frac{\pi}{6}$.
Since $x < 0, y > 0$, point is in second quadrant.
Argument $\theta = \pi - \alpha = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$.
Modulus = 2, Argument = $\frac{5\pi}{6}$

Convert the complex number $1 - i$ to polar form.
Let $z = 1 - i$. $r = \sqrt{1^2 + (-1)^2} = \sqrt{2}$.
$\tan \alpha = |\frac{-1}{1}| = 1 \Rightarrow \alpha = \frac{\pi}{4}$.
Since $x > 0, y < 0$, point is in fourth quadrant. $\theta = -\alpha = -\frac{\pi}{4}$.
Polar form: $z = r(\cos \theta + i \sin \theta) = \sqrt{2}(\cos(-\frac{\pi}{4}) + i \sin(-\frac{\pi}{4}))$.
$= \sqrt{2}(\cos \frac{\pi}{4} - i \sin \frac{\pi}{4})$.
$\sqrt{2}(\cos \frac{\pi}{4} - i \sin \frac{\pi}{4})$

Convert the complex number $-1 + i$ to polar form.
Let $z = -1 + i$. $r = \sqrt{(-1)^2 + 1^2} = \sqrt{2}$.
$\tan \alpha = |\frac{1}{-1}| = 1 \Rightarrow \alpha = \frac{\pi}{4}$.
Since $x < 0, y > 0$, point is in second quadrant. $\theta = \pi - \frac{\pi}{4} = \frac{3\pi}{4}$.
Polar form: $\sqrt{2}(\cos \frac{3\pi}{4} + i \sin \frac{3\pi}{4})$.
$\sqrt{2}(\cos \frac{3\pi}{4} + i \sin \frac{3\pi}{4})$

$\sqrt{2}(\cos \frac{3\pi}{4} - i \sin \frac{3\pi}{4})$

Let $z = -3 + 0i$. $r = \sqrt{(-3)^2} = 3$.

Argument $\theta = \pi$.
Polar form: $3(\cos \pi + i \sin \pi)$.

Convert the complex number $i$ to polar form.
Let $z = 0 + i$. $r = 1$.
Point $(0, 1)$ lies on the positive imaginary axis.
Argument $\theta = \frac{\pi}{2}$.
Polar form: $1(\cos \frac{\pi}{2} + i \sin \frac{\pi}{2}) = \cos \frac{\pi}{2} + i \sin \frac{\pi}{2}$.
$\cos \frac{\pi}{2} + i \sin \frac{\pi}{2}$
