Exercise 9.3

Long Answer Questions

Q1
If the equation of the base of an equilateral triangle is x + y = 2 and the vertex is (2, – 1), then find the length of the side of the triangle.
The length of the altitude from the vertex (2, -1) to the base x + y - 2 = 0 is p = |2 + (-1) - 2| / √(1² + 1²) = |-1| / √2 = 1/√2. For an equilateral triangle with side 'a', the altitude is (√3/2)a. So, (√3/2)a = 1/√2. This gives a = (2/√3) * (1/√2) = √2/√3 = √(2/3).
$√(2/3)$
Q2
A variable line passes through a fixed point P. The algebraic sum of the perpendiculars drawn from the points (2, 0), (0, 2) and (1, 1) on the line is zero. Find the coordinates of the point P.
Let the line be ax + by + c = 0. The sum of perpendiculars is (2a+c)/√(a²+b²) + (2b+c)/√(a²+b²) + (a+b+c)/√(a²+b²) = 0. This implies 2a+c + 2b+c + a+b+c = 0 (assuming the points are on different sides, the algebraic sum is taken). 3a + 3b + 3c = 0 => a + b + c = 0. This means the line ax+by+c=0 always passes through the point (1, 1) because a(1)+b(1)+c = a+b+c=0. So the fixed point P is (1, 1).
$(1, 1)$
Q3
In what direction should a line be drawn through the point (1, 2) so that its point of intersection with the line x + y = 4 is at a distance √6/3 from the given point.
Let the line be y-2 = m(x-1). The intersection with x+y=4 is found by substituting y = m(x-1)+2 into x+y=4. x + m(x-1)+2 = 4 => x(1+m) = m+2 => x = (m+2)/(m+1). Then y = 4-x = (3m+2)/(m+1). The distance between (1,2) and this point is √6/3. (x-1)²+(y-2)² = 6/9 = 2/3. [((m+2)/(m+1))-1]² + [((3m+2)/(m+1))-2]² = 2/3. [1/(m+1)]² + [m/(m+1)]² = 2/3. (1+m²)/(m+1)² = 2/3. 3+3m² = 2(m²+2m+1) = 2m²+4m+2. m²-4m+1=0. m = (4±√(16-4))/2 = 2±√3. tan(θ) = 2±√3. So θ = 75° or θ = 15°.
$15° or 75° with the x-axis$
Q4
A straight line moves so that the sum of the reciprocals of its intercepts made on axes is constant. Show that the line passes through a fixed point. Find the coordinates of the fixed point.
Let the equation of the line be x/a + y/b = 1. Given that 1/a + 1/b = k (constant). We can write this as (1/k)/a + (1/k)/b = 1. Comparing this with the line equation x/a + y/b = 1, we can see that the line passes through the fixed point (1/k, 1/k).
$The line passes through a fixed point (1/k, 1/k).$
Q5
Find the equation of the line which passes through the point (– 4, 3) and the portion of the line intercepted between the axes is divided internally in the ratio 5 : 3 by this point.
Let the intercepts be (a, 0) and (0, b). The point (-4, 3) divides the segment joining (a, 0) and (0, b) in the ratio 5:3. Using section formula: -4 = (5*0 + 3*a)/(5+3) => -4 = 3a/8 => a = -32/3. And 3 = (5*b + 3*0)/(5+3) => 3 = 5b/8 => b = 24/5. The equation is x/(-32/3) + y/(24/5) = 1 => -3x/32 + 5y/24 = 1. LCM of 32 and 24 is 96. Multiply by 96: -9x + 20y = 96, or 9x - 20y + 96 = 0.
$9x - 20y + 96 = 0$
Q6
Find the equations of the two straight lines which pass through the point (0, a) and are at a distance of 'a' from the point (2a, 2a).
Let the slope be m. The line is y - a = m(x - 0) => mx - y + a = 0. Distance from (2a, 2a) is 'a'. |m(2a) - 2a + a| / √(m²+1) = a. |2am - a| = a√(m²+1). Assuming a≠0, |2m-1| = √(m²+1). Squaring both sides: (2m-1)² = m²+1 => 4m² - 4m + 1 = m² + 1 => 3m² - 4m = 0 => m(3m-4) = 0. So m=0 or m=4/3. If m=0, the line is y=a. If m=4/3, the line is y-a = 4/3 x => 3y-3a=4x => 4x-3y+3a=0.
$y = a and 4x - 3y + 3a = 0$
Q7
Find the equation of the straight line passing through the point (α, β) and perpendicular to the straight line lx + my + n = 0.
The slope of the given line lx + my + n = 0 is -l/m. The slope of the perpendicular line is m/l. The equation of the required line passing through (α, β) is y - β = (m/l)(x - α). This gives l(y - β) = m(x - α) => ly - lβ = mx - mα => mx - ly + lβ - mα = 0.
$mx - ly + lβ - mα = 0$
Q8
Find the equation of the line passing through the intersection of 2x – 3y + 1 = 0 and x + y – 2 = 0 and distant 7/√13 from the origin.
First find the intersection. x = 2 - y. 2(2-y) - 3y + 1 = 0 => 4 - 2y - 3y + 1 = 0 => 5 - 5y = 0 => y = 1. Then x = 2 - 1 = 1. The point is (1, 1). Any line through (1,1) is y-1=m(x-1) or mx-y-m+1=0. Its distance from origin is |-m+1|/√(m²+1). Equating this to 7/√13 leads to a quadratic equation for m with no real solutions. This suggests the data in the question is inconsistent.
$Question data seems inconsistent.$
Q9
If p is the length of perpendicular from the origin on the line x/a + y/b = 1 and a², p², b² are in AP, then show that a⁴ + b⁴ = 0.
The line is bx + ay - ab = 0. The perpendicular distance p from origin is |b(0)+a(0)-ab|/√(b²+a²) = |ab|/√(a²+b²). So p² = a²b²/(a²+b²). Given a², p², b² are in AP, so 2p² = a² + b². Substitute p²: 2(a²b²/(a²+b²)) = a² + b². 2a²b² = (a²+b²)(a²+b²) = (a²+b²)². 2a²b² = a⁴ + b⁴ + 2a²b². This implies a⁴ + b⁴ = 0. This is only possible if a=0 and b=0, which is not possible for a line with intercepts. However, the algebraic manipulation proves the required relation based on the given conditions.
$Proven.$

Fill in the Blanks

Q10
If a, b, c are in AP, then the straight lines ax + by + c = 0 will always pass through ____.
If a, b, c are in AP, then 2b = a + c, or a - 2b + c = 0. Comparing this with ax + by + c = 0, we can see that if we substitute x=1 and y=-2, we get a(1) + b(-2) + c = a - 2b + c, which is 0. So the line always passes through (1, -2).
$(1, -2)$
Q11
The line which cuts off equal intercept from the axes and pass through the point (1, –2) is ____.
This is the same as Short Answer Question 1. The equation is x + y + 1 = 0.
$x + y + 1 = 0$
Q12
Equations of the lines through the point (3, 2) and making an angle of 45° with the line x – 2y = 3 are ____.
The slope of x - 2y = 3 is 1/2. Let the required slope be m. tan(45°) = |(m - 1/2) / (1 + m/2)|. 1 = |(2m-1)/(2+m)|. So, 2+m = 2m-1 or 2+m = -(2m-1). Case 1: m=3. Eq: y-2=3(x-3) => 3x-y-7=0. Case 2: 2+m = -2m+1 => 3m=-1 => m=-1/3. Eq: y-2=-1/3(x-3) => 3y-6=-x+3 => x+3y-9=0.
$3x - y - 7 = 0 and x + 3y - 9 = 0$
Q13
The points (3, 4) and (2, – 6) are situated on the ____ of the line 3x – 4y – 8 = 0.
Substitute the points into the expression 3x - 4y - 8. For (3, 4): 3(3) - 4(4) - 8 = 9 - 16 - 8 = -15. For (2, -6): 3(2) - 4(-6) - 8 = 6 + 24 - 8 = 22. Since the signs are opposite (-15 and 22), the points lie on opposite sides of the line.
$opposite sides$
Q14
A point moves so that square of its distance from the point (3, –2) is numerically equal to its distance from the line 5x – 12y = 3. The equation of its locus is ____.
Let the point be (x, y). The square of its distance from (3, -2) is (x-3)² + (y+2)². Its distance from 5x - 12y - 3 = 0 is |5x - 12y - 3| / √(5²+12²) = |5x - 12y - 3|/13. So, (x-3)² + (y+2)² = |5x - 12y - 3|/13. 13(x²-6x+9 + y²+4y+4) = ±(5x-12y-3). 13(x²+y²-6x+4y+13) = ±(5x-12y-3).
$13(x² + y² - 6x + 4y + 13) = ±(5x - 12y - 3)$
Q15
Locus of the mid-points of the portion of the line x sinθ + y cosθ = p intercepted between the axes is ____.
The intercepts are a = p/sinθ and b = p/cosθ. Let the midpoint be (h, k). h = a/2 = p/(2sinθ) and k = b/2 = p/(2cosθ). So sinθ = p/(2h) and cosθ = p/(2k). Since sin²θ + cos²θ = 1, we have (p/2h)² + (p/2k)² = 1. p²/4h² + p²/4k² = 1. p²(1/h² + 1/k²) = 4. 1/h² + 1/k² = 4/p². The locus is 1/x² + 1/y² = 4/p², or x⁻² + y⁻² = 4p⁻².
$x⁻² + y⁻² = 4p⁻²$

True or False

Q16
If the vertices of a triangle have integral coordinates, then the triangle can not be equilateral.
The area of a triangle with integral vertices (x1, y1), (x2, y2), (x3, y3) is given by (1/2)|x1(y2-y3) + ...|, which is always a rational number. The area of an equilateral triangle with side 'a' is (√3/4)a². The square of the side length, a², would be an integer if vertices are integers ((x2-x1)²+(y2-y1)²). So the area would be (integer) * √3 / 4, which is irrational. An irrational number cannot equal a rational number. Hence, a triangle with integral vertices cannot be equilateral.
$True$
Q17
The points A (– 2, 1), B (0, 5), C (– 1, 2) are collinear.
Slope of AB = (5-1)/(0-(-2)) = 4/2 = 2. Slope of BC = (2-5)/(-1-0) = -3/-1 = 3. Since the slopes are not equal, the points are not collinear.
$False$
Q18
Equation of the line passing through the point (a cos³θ, a sin³θ) and perpendicular to the line x secθ + y cosecθ = a is x cosθ – y sinθ = a cos2θ.
The given line is x/cosθ + y/sinθ = a. Slope is -sinθ/cosθ = -tanθ. The perpendicular slope is cotθ = cosθ/sinθ. The equation of the required line is y - a sin³θ = (cosθ/sinθ)(x - a cos³θ). y sinθ - a sin⁴θ = x cosθ - a cos⁴θ. x cosθ - y sinθ = a(cos⁴θ - sin⁴θ) = a(cos²θ - sin²θ)(cos²θ + sin²θ) = a cos2θ. The statement is correct.
$True$
Q19
The straight line 5x + 4y = 0 passes through the point of intersection of the straight lines x + 2y – 10 = 0 and 2x + y + 5 = 0.
Intersection of x+2y=10 and 2x+y=-5. Multiply first by 2: 2x+4y=20. Subtract second: 3y=25 => y=25/3. Then x = 10 - 2(25/3) = (30-50)/3 = -20/3. The point is (-20/3, 25/3). Check if it lies on 5x+4y=0. 5(-20/3) + 4(25/3) = -100/3 + 100/3 = 0. Yes, it passes through the intersection.
$True$
Q20
The vertex of an equilateral triangle is (2, 3) and the equation of the opposite side is x + y = 2. Then the other two sides are y – 3 = (2 ± √3)(x – 2).
The slope of the base is -1. The altitude from (2,3) has slope 1. The angle between the base and a side is 60°. Let the slope of a side be m. tan(60°) = |(m - (-1)) / (1 + m(-1))|. √3 = |(m+1)/(1-m)|. So, √3(1-m) = m+1 or √3(1-m) = -(m+1). Case 1: √3-√3m=m+1 => √3-1 = m(1+√3) => m=(√3-1)/(√3+1) = (√3-1)²/2 = (3+1-2√3)/2 = 2-√3. Case 2: √3-√3m=-m-1 => √3+1 = m(√3-1) => m=(√3+1)/(√3-1) = (√3+1)²/2 = (3+1+2√3)/2 = 2+√3. The slopes are 2±√3. The equations are y-3 = (2±√3)(x-2). The statement is true.
$True$
Q21
The equation of the line joining the point (3, 5) to the point of intersection of the lines 4x + y – 1 = 0 and 7x – 3y – 35 = 0 is equidistant from the points (0, 0) and (8, 34).
Intersection: y=1-4x. 7x-3(1-4x)-35=0 => 7x-3+12x-35=0 => 19x=38 => x=2. Then y=1-4(2)=-7. Point is (2,-7). Line joins (3,5) and (2,-7). Slope = (5-(-7))/(3-2) = 12. Eq: y-5=12(x-3) => 12x-y-31=0. Distance from (0,0) is |-31|/√(144+1) = 31/√145. Distance from (8,34) is |12(8)-34-31|/√(145) = |96-65|/√145 = 31/√145. The distances are equal. The statement is true.
$True$
Q22
The line x/a + y/b = 1 moves in such a way that 1/a² + 1/b² = 1/c², where c is a constant. The locus of the foot of the perpendicular from the origin on the given line is x² + y² = c².
Let the foot of the perpendicular from (0,0) to x/a + y/b = 1 be (h,k). The slope of the line is -b/a. The slope of the perpendicular (line joining (0,0) and (h,k)) is k/h. So, (k/h) * (-b/a) = -1 => k/h = a/b => a=kb/h. Also (h,k) lies on the line, so h/a + k/b = 1. h/(kb/h) + k/b = 1 => h²/kb + k/b = 1 => (h²+k²)/kb = 1 => b = (h²+k²)/k. Then a = k/h * (h²+k²)/k = (h²+k²)/h. Now use 1/a² + 1/b² = 1/c². h²/(h²+k²)² + k²/(h²+k²)² = 1/c². (h²+k²)/(h²+k²)² = 1/c². 1/(h²+k²) = 1/c². h²+k²=c². The locus is x²+y²=c².
$True$
Q23
The lines ax + 2y + 1 = 0, bx + 3y + 1 = 0 and cx + 4y + 1 = 0 are concurrent if a, b, c are in GP.
For the lines to be concurrent, the determinant of the coefficients must be zero. |a 2 1| |b 3 1| |c 4 1| = 0. a(3-4) - 2(b-c) + 1(4b-3c) = 0. -a - 2b + 2c + 4b - 3c = 0. -a + 2b - c = 0. 2b = a + c. This is the condition for a, b, c to be in an Arithmetic Progression (AP), not a Geometric Progression (GP).
$False$
Q24
Line joining the points (3, – 4) and (– 2, 6) is perpendicular to the line joining the points (–3, 6) and (9, –18).
Slope of the first line m1 = (6 - (-4)) / (-2 - 3) = 10 / -5 = -2. Slope of the second line m2 = (-18 - 6) / (9 - (-3)) = -24 / 12 = -2. Since m1 = m2, the lines are parallel, not perpendicular.
$False$
