Exercise 4.1

Objective Type Questions (MCQs)

Q1
The complex numbers $z = \sin x + i \cos 2x$ and $w = \cos x - i \sin 2x$ are conjugate to each other for:
Given $z = \bar{w}$. $\sin x + i \cos 2x = \overline{\cos x - i \sin 2x} = \cos x + i \sin 2x$ Comparing real and imaginary parts: $\sin x = \cos x \implies \tan x = 1 \implies x = n\pi + \frac{\pi}{4}$ $\cos 2x = \sin 2x \implies \tan 2x = 1 \implies 2x = m\pi + \frac{\pi}{4} \implies x = \frac{m\pi}{2} + \frac{\pi}{8}$ There is no common value of $x$ satisfying both conditions simultaneously.
$No value of $x$$
Q2
The real value of $\alpha$ for which the expression $\frac{1-i\sin\alpha}{1+2i\sin\alpha}$ is purely real is:
Let $z = \frac{1-i\sin\alpha}{1+2i\sin\alpha}$. Multiply numerator and denominator by $1-2i\sin\alpha$: $z = \frac{(1-i\sin\alpha)(1-2i\sin\alpha)}{1+4\sin^2\alpha} = \frac{1-2\sin^2\alpha - 3i\sin\alpha}{1+4\sin^2\alpha}$ For $z$ to be purely real, the imaginary part must be zero: $-3\sin\alpha = 0 \implies \sin\alpha = 0 \implies \alpha = n\pi$.
$n\pi$
Q3
If $z = x + iy$ lies in the third quadrant, then $\frac{\bar{z}}{z}$ also lies in the third quadrant if:
Given $z$ is in 3rd quadrant, so $x < 0, y < 0$. $\frac{\bar{z}}{z} = \frac{x-iy}{x+iy} = \frac{(x-iy)^2}{x^2+y^2} = \frac{x^2-y^2-2ixy}{x^2+y^2}$ For $\frac{\bar{z}}{z}$ to be in 3rd quadrant: Real part $< 0 \implies x^2 - y^2 < 0 \implies x^2 < y^2 \implies |x| < |y|$. Since $x,y$ are negative, this means $y < x$. Imaginary part $< 0 \implies -2xy < 0 \implies xy > 0$, which is true since $x,y$ are both negative. Thus, $y < x < 0$.
$y < x < 0$
Q4
The value of $(z+3)(\bar{z}+3)$ is equivalent to:
$(z+3)(\bar{z}+3) = (z+3)(\overline{z+3}) = |z+3|^2$.
$|z+3|^2$
Q5
If $\left(\frac{1+i}{1-i}\right)^x = 1$, then:
$\frac{1+i}{1-i} = \frac{(1+i)^2}{1^2+1^2} = \frac{1-1+2i}{2} = i$. So, $i^x = 1$. This implies $x$ must be a multiple of 4, i.e., $x = 4n$.
$x = 4n$
Q6
If $x^2 + y^2 = 1$, then the value of $\frac{1+x+iy}{1+x-iy}$ is:
Since $x^2+y^2=1$, let $z = x+iy$, then $|z|=1$ and $\bar{z} = 1/z$. The expression is $\frac{1+z}{1+\bar{z}} = \frac{1+z}{1+\frac{1}{z}} = \frac{1+z}{\frac{z+1}{z}} = z = x+iy$.
$x+iy$
Q7
The point represented by the complex number $2-i$ is rotated about origin through an angle $\pi/2$ in the clockwise direction, the new position of point is:
Clockwise rotation by $\pi/2$ corresponds to multiplication by $e^{-i\pi/2} = -i$. New position $z' = (2-i)(-i) = -2i + i^2 = -1-2i$.
$-1-2i$
Q8
If $x, y \in R$, then $x+iy$ is a non-real complex number if:
A complex number is non-real if its imaginary part is non-zero. Hence $y \neq 0$.
$y \neq 0$
Q9
If $a+ib = c+id$, then:
If two complex numbers are equal, their moduli are equal. $|a+ib| = |c+id| \implies \sqrt{a^2+b^2} = \sqrt{c^2+d^2} \implies a^2+b^2 = c^2+d^2$.
$a^2+b^2 = c^2+d^2$
Q10
The complex number $z$ which satisfies the condition $|\frac{i+z}{i-z}| = 1$ lies on:
$|i+z| = |i-z| \implies |z - (-i)| = |z - i|$. This represents the locus of points equidistant from $i$ (0, 1) and $-i$ (0, -1). The perpendicular bisector of the segment joining $(0,1)$ and $(0,-1)$ is the x-axis ($y=0$).
$the x-axis$
Q11
If $z$ is a complex number, then:
We know that $|z^n| = |z|^n$. For $n=2$, $|z^2| = |z|^2$.
$|z^2| = |z|^2$
Q12
If $|z+4| \le 3$, then the maximum value of $|z+1|$ is:
$|z+1| = |z+4-3| \le |z+4| + |-3| \le 3 + 3 = 6$.
$6$
Q13
The value of $\arg(x)$, when $x < 0$ is:
If $x$ is a negative real number, it lies on the negative real axis. The principal argument is $\pi$.
$\pi$
Q14
If $f(z) = \frac{7-z}{1-z^2}$, where $z = 1+2i$, then $|f(z)|$ is:
This is a standard result check. Let's calculate: $|z| = \sqrt{1+4} = \sqrt{5}$. $z^2 = (1+2i)^2 = 1 - 4 + 4i = -3 + 4i$. $1-z^2 = 1 - (-3+4i) = 4 - 4i$. $7-z = 7 - (1+2i) = 6 - 2i$. $|f(z)| = \frac{|6-2i|}{|4-4i|} = \frac{\sqrt{36+4}}{\sqrt{16+16}} = \frac{\sqrt{40}}{\sqrt{32}} = \sqrt{\frac{5}{4}} = \frac{\sqrt{5}}{2} = \frac{|z|}{2}$.
$|z|/2$
Q15
The equation $|z+1-i| = |z-1+i|$ represents a:
$|z - (-1+i)| = |z - (1-i)|$. This is the locus of a point equidistant from two fixed points $(-1, 1)$ and $(1, -1)$. This represents the perpendicular bisector of the segment joining these points, which is a straight line.
$straight line$
Q16
If a complex number $z$ lies in the interior or on the boundary of a circle of radius 3 units and centre $(-4,0)$, the greatest and least values of $|z+1|$ are:
Given $|z - (-4)| \le 3 \implies |z+4| \le 3$. We need extrema of $|z+1|$. $|z+1| = |z+4-3|$. Max value: $|z+4| + 3 = 3+3 = 6$. Min value: $||z+4| - 3|$. Since center is at -4, distance to -1 is 3. The point -1 lies on the boundary of the circle $|z+4|=3$. So $z=-1$ is possible, giving $|-1+1|=0$. Thus, greatest is 6 and least is 0.
$6 and 0$
