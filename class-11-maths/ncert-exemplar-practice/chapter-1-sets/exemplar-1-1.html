Q1
Suppose \(A_1, A_2, \dots, A_{30}\) are thirty sets each having 5 elements and \(B_1, B_2, \dots, B_n\) are \(n\) sets each with 3 elements, let \(\bigcup_{i=1}^{30} A_i = \bigcup_{j=1}^{n} B_j = S\) and each element of \(S\) belongs to exactly 10 of the \(A_i\)'s and exactly 9 of the \(B_j\)'s. Then \(n\) is equal to
Let \(n(S)\) be the number of elements in \(S\).
Since each element of \(S\) is in exactly 10 of the \(A_i\)'s, we have \(10 \cdot n(S) = \sum n(A_i) = 30 \times 5 = 150\).
So, \(n(S) = 15\).
Since each element of \(S\) is in exactly 9 of the \(B_j\)'s, we have \(9 \cdot n(S) = \sum n(B_j) = n \times 3 = 3n\).
Substitute \(n(S) = 15\): \(9 \times 15 = 3n\).
\(135 = 3n \implies n = 45\).

Q2
Two finite sets have \(m\) and \(n\) elements. The number of subsets of the first set is 112 more than that of the second set. The values of \(m\) and \(n\) are, respectively
Number of subsets of first set = \(2^m\).
Number of subsets of second set = \(2^n\).
Given: \(2^m - 2^n = 112\).
\(2^n(2^{m-n} - 1) = 112 = 16 \times 7 = 2^4 \times 7\).
Comparing factors: \(2^n = 2^4 \implies n = 4\).
And \(2^{m-n} - 1 = 7 \implies 2^{m-4} = 8 = 2^3\).
\(m - 4 = 3 \implies m = 7\).
$(b)$
Q3
The set \((A \cap B')' \cup (B \cap C)\) is equal to
Using De Morgan's Law: \((A \cap B')' = A' \cup (B')' = A' \cup B\).
So the expression becomes \((A' \cup B) \cup (B \cap C)\).
Since \((B \cap C) \subset B\), the union with \(B\) absorbs it.
\(A' \cup B \cup (B \cap C) = A' \cup B\).

\(F_1\) (parallelograms) includes \(F_2\) (rectangles), \(F_3\) (rhombuses), and \(F_4\) (squares).
Therefore, \(F_2 \subset F_1\), \(F_3 \subset F_1\), \(F_4 \subset F_1\).
The union \(F_2 \cup F_3 \cup F_4 \cup F_1\) is simply \(F_1\).

Q5
Let \(S =\) set of points inside the square, \(T =\) set of points inside the triangle and \(C =\) set of points inside the circle. If the triangle and circle intersect each other and are contained in a square. Then
Since the triangle (T) and circle (C) are contained in the square (S), we have \(T \subset S\) and \(C \subset S\).
Therefore, the union of all three sets is just the largest set, \(S\).

Q6
If \(R\) be the set of points inside a rectangle of sides \(a\) and \(b\) (\(a, b > 1\)) with two sides along the positive direction of \(x\)-axis and \(y\)-axis. Then
The set of points *inside* a rectangle does not include the boundary.
Therefore, strict inequalities (\(<\)) are used.
\(R = \{(x, y) : 0 < x < a, 0 < y < b\}\).

Q7
In a class of 60 students, 25 students play cricket and 20 students play tennis, and 10 students play both the games. Then, the number of students who play neither is
Let \(C\) be cricket players, \(T\) be tennis players.
\(n(U) = 60, n(C) = 25, n(T) = 20, n(C \cap T) = 10\).
\(n(C \cup T) = n(C) + n(T) - n(C \cap T) = 25 + 20 - 10 = 35\).
Number playing neither = \(n(U) - n(C \cup T) = 60 - 35 = 25\).
$(b)$
Q8
In a town of 840 persons, 450 persons read Hindi, 300 read English and 200 read both. Then, the number of person who read neither, is
\(n(U) = 840, n(H) = 450, n(E) = 300, n(H \cap E) = 200\).
\(n(H \cup E) = n(H) + n(E) - n(H \cap E) = 450 + 300 - 200 = 550\).
Number reading neither = \(n(U) - n(H \cup E) = 840 - 550 = 290\).
$(b)$
Q9
If \(X = \{ 8^n - 7n - 1 | n \in N \}\) and \(Y = \{ 49(n - 1) | n \in N \}\), then
For \(n=1\), \(X: 8^1 - 7(1) - 1 = 0\); \(Y: 49(0) = 0\).
For \(n=2\), \(X: 64 - 14 - 1 = 49\); \(Y: 49(1) = 49\).
For \(n=3\), \(X: 512 - 21 - 1 = 490\); \(Y: 49(2) = 98\).
Using binomial expansion, \(8^n - 7n - 1 = (1+7)^n - 7n - 1\) is divisible by \(49\).
\(X\) contains multiples of 49, but not all (e.g., 98 is in \(Y\) but not \(X\)).
Thus, \(X \subset Y\).
$(a)$
Q10
A survey shows that 63% of the people watch a news channel whereas 76% watch another channel. If \(x\)% of the people watch both channel, then
\(n(A) = 63, n(B) = 76, n(A \cap B) = x\).
Max value of intersection is \(\min(n(A), n(B)) = 63\). So \(x \le 63\).
Min value: \(n(A \cup B) \le 100\).
\(n(A) + n(B) - n(A \cap B) \le 100\).
\(63 + 76 - x \le 100 \implies 139 - x \le 100 \implies x \ge 39\).
Therefore, \(39 \le x \le 63\).
$(c)$
Q11
If sets A and B are defined as \(A = \{(x,y) | y = \frac{1}{x}, 0 \neq x \in R\}\) and \(B = \{(x,y) | y = -x, x \in R\}\), then
Intersection requires \(\frac{1}{x} = -x\).
\(x^2 = -1\).
There is no real number \(x\) satisfying this.
Thus, \(A \cap B = \phi\).

Since \(A \subset (A \cup B)\), the intersection with \(A\) is just \(A\).

Q13
If A and B are two sets, then \(A \cap (A \cup B)'\) equals to
\(A \cap (A \cup B)' = A \cap (A' \cap B')\) (De Morgan's).
\(= (A \cap A') \cap B' = \phi \cap B' = \phi\).

Q14
If A and B are finite sets, such that \(A \subset B\), then \(n(A \cup B)\) is equal to
If \(A \subset B\), then \(A \cup B = B\).
Therefore, \(n(A \cup B) = n(B)\).

\(= (X \cap X') \cap Y' = \phi \cap Y' = \phi\).
