Exercise 1.2

Short Answer Type Questions (1-4)

Q1
Write the following sets in the roster form:
(i) \(A = \{x : x \in R, 2x + 11 = 15\}\)
(ii) \(B = \{x | x^2 = x, x \in R\}\)
(iii) \(C = \{x | x \text{ is a positive factor of a prime number } p\}\)
(i) \(2x + 11 = 15 \implies 2x = 4 \implies x = 2\). Since \(2 \in R\), \(A = \{2\}\).
(ii) \(x^2 = x \implies x^2 - x = 0 \implies x(x - 1) = 0 \implies x = 0, 1\). Both are real. \(B = \{0, 1\}\).
(iii) The positive factors of a prime number \(p\) are 1 and \(p\) itself. \(C = \{1, p\}\).
$(i) {2}
(ii) {0, 1}
(iii) {1, p}$
Q2
Write the following sets in the roster form:
(i) \(D = \{t | t^3 = t, t \in R\}\)
(ii) \(E = \{w | \frac{w-2}{w+3} = 3, w \in R\}\)
(iii) \(F = \{x | x^4 - 5x^2 + 6 = 0, x \in R\}\)
(i) \(t^3 = t \implies t^3 - t = 0 \implies t(t^2 - 1) = 0 \implies t(t-1)(t+1) = 0\). \(t = 0, 1, -1\). \(D = \{-1, 0, 1\}\).
(ii) \(\frac{w-2}{w+3} = 3 \implies w - 2 = 3(w + 3) \implies w - 2 = 3w + 9 \implies -11 = 2w \implies w = -5.5\). \(E = \{-5.5\}\).
(iii) \(x^4 - 5x^2 + 6 = 0\). Let \(y = x^2\). \(y^2 - 5y + 6 = 0 \implies (y-2)(y-3) = 0\). \(x^2 = 2\) or \(x^2 = 3\). \(x = \pm\sqrt{2}, \pm\sqrt{3}\). \(F = \{-\sqrt{3}, -\sqrt{2}, \sqrt{2}, \sqrt{3}\}\).
$(i) {-1, 0, 1}
(ii) {-5.5}
(iii) {-√3, -√2, √2, √3}$
Q3
If \(X = \{1, 2, 3\}\), if \(n\) represents any member of \(X\), write the following sets containing all numbers represented by
(i) \(4n\)
(ii) \(n+6\)
(iii) \(\frac{n}{2}\)
Given \(X = \{1, 2, 3\}\).
(i) \(4n\): \(\{4(1), 4(2), 4(3)\} = \{4, 8, 12\}\).
(ii) \(n+6\): \(\{1+6, 2+6, 3+6\} = \{7, 8, 9\}\).
(iii) \(\frac{n}{2}\): \(\{\frac{1}{2}, \frac{2}{2}, \frac{3}{2}\} = \{0.5, 1, 1.5\}\).
$(i) {4, 8, 12}
(ii) {7, 8, 9}
(iii) {0.5, 1, 1.5}$
Q4
If \(Y = \{1, 2, 3, \dots, 10\}\), and \(a\) represents any element of \(Y\), write the following sets, containing all the elements satisfying the given conditions.
(i) \(a \in Y\) but \(a^2 \notin Y\)
(ii) \(a+1 \in Y\) and \(a-1 \in Y\)
(i) \(a \in Y\) such that \(a^2 > 10\). Elements are 4 (16), 5 (25), ..., 10 (100). Set = \{4, 5, 6, 7, 8, 9, 10\}.
(ii) \(a+1 \le 10 \implies a \le 9\) and \(a-1 \ge 1 \implies a \ge 2\). So \(a \in \{2, 3, \dots, 9\}\).
$(i) {4, 5, 6, 7, 8, 9, 10}
(ii) {2, 3, ..., 9}$

Fill in the Blanks (5-13)

Q5
The set \(\{x \in R : 1 \le x < 2\}\) can be written as ________.
Use interval notation. Square bracket for inclusive, parenthesis for exclusive.
Q6
When \(A = \phi\), then the number of elements in \(P(A)\) is ________.
\(n(A) = 0\). Number of elements in power set = \(2^{n(A)} = 2^0 = 1\).
$1$
Q7
If \(A\) and \(B\) are finite sets, such that \(A \subset B\), then \(n(A \cup B)\) is equal to ________.
If A is inside B, their union is just B.
Q8
If \(A\) and \(B\) are finite sets, such that \(A \subset B\), then \(n(A \cap B)\) is equal to ________.
If A is inside B, their intersection is just A.
Q9
If \(A\) and \(B\) are any two finite sets, then \(n(A \cup B)\) is equal to ________.
Q10
\(A \cup B = A \cap B\) implies ________.
Union and intersection are equal only when the sets are identical.
Q11
\((A \cup B)' = \) ________.
De Morgan's Law.
Q12
\((A \cap B)' = \) ________.
De Morgan's Law.
Q13
\((A \cup B) \cap (A \cup B') = \) ________.
Distributive Law: \(A \cup (B \cap B') = A \cup \phi = A\).
$A$

True or False (14-19)

Q14
If \(A\) is any set, then \(A \subset A\).
Every set is a subset of itself.
Q15
If \(M = \{1, 2, 3, 4, 5, 6, 7, 8, 9\}\) and \(B = \{1, 2, 3, 4, 5, 6, 7, 8, 9\}\), then \(B \not\subset M\).
Since every element of B is in M, \(B \subset M\). The statement says \(B \not\subset M\), which is false.
$False$
Q16
The sets \(\{1, 2, 3, 4\}\) and \(\{3, 4, 5, 6\}\) are equal.
Equal sets must have exactly the same elements.
Q17
The sets \(Q = \{1, 2, 3\}\) and \(S = \{2, 3, 1\}\) are equal.
Order of elements does not matter in a set.
Q18
The set \(P = \{x | x \in Z, x \text{ is a multiple of } 3\}\) is a subset of \(T = \{x | x \in Z, x \text{ is a multiple of } 6\}\).
3 is in P but not in T. So P is not a subset of T. (Note: If the question was T subset P, it would be True).
$False$
Q19
Given \(A = \{0, 1, 2\}\), \(B = \{x \in R | 0 \le x \le 2\}\). Then \(A = B\).
A contains only integers 0, 1, 2. B contains all real numbers between 0 and 2 (infinite elements).
$False$

True or False (20-24)

Q20
For all sets \(A\) and \(B\), \((A - B) \cup (A \cap B) = A\).
LHS = \((A \cap B') \cup (A \cap B)\)
By Distributive Law: \(A \cap (B' \cup B)\)
\(= A \cap U = A = \) RHS.
$True$
Q21
For all sets \(A, B\) and \(C\), \(A - (B - C) = (A - B) - C\).
LHS = \(A - (B \cap C') = A \cap (B \cap C')' = A \cap (B' \cup C) = (A \cap B') \cup (A \cap C)\).
RHS = \((A \cap B') - C = A \cap B' \cap C'\).
LHS \(\neq\) RHS. Example: \(A=B=C=\{1\}\). LHS=\{1\}, RHS=\(\phi\).
$False$
Q22
For all sets \(A, B\) and \(C\), if \(A \subset B\), then \(A \cap C \subset B \cap C\).
Let \(x \in A \cap C\). Then \(x \in A\) and \(x \in C\).
Since \(A \subset B\), \(x \in A \implies x \in B\).
So \(x \in B\) and \(x \in C\), which means \(x \in B \cap C\).
Thus \(A \cap C \subset B \cap C\).
$True$
Q23
For all sets \(A, B\) and \(C\), if \(A \subset B\), then \(A \cup C \subset B \cup C\).
Let \(x \in A \cup C\). Then \(x \in A\) or \(x \in C\).
If \(x \in A\), then \(x \in B\) (since \(A \subset B\)), so \(x \in B \cup C\).
If \(x \in C\), then \(x \in B \cup C\).
In both cases, \(x \in B \cup C\).
$True$
Q24
For all sets \(A, B\) and \(C\), if \(A \subset C\) and \(B \subset C\), then \(A \cup B \subset C\).
Let \(x \in A \cup B\). Then \(x \in A\) or \(x \in B\).
If \(x \in A\), then \(x \in C\) (since \(A \subset C\)).
If \(x \in B\), then \(x \in C\) (since \(B \subset C\)).
Thus \(x \in C\).
$True$

Short Answer Type Questions (25-29)

Q25
For all sets \(A\) and \(B\), prove that \(A \cup (B - A) = A \cup B\).
LHS = \(A \cup (B \cap A')\)
\(= (A \cup B) \cap (A \cup A')\) (Distributive Law)
\(= (A \cup B) \cap U\)
\(= A \cup B = \) RHS.
$Proof$
Q26
For all sets \(A\) and \(B\), prove that \(A - (A - B) = A \cap B\).
LHS = \(A - (A \cap B')\)
\(= A \cap (A \cap B')'\)
\(= A \cap (A' \cup B)\) (De Morgan's Law)
\(= (A \cap A') \cup (A \cap B)\) (Distributive Law)
\(= \phi \cup (A \cap B)\)
\(= A \cap B = \) RHS.
$Proof$
Q27
For all sets \(A\) and \(B\), prove that \(A - (A \cap B) = A - B\).
LHS = \(A \cap (A \cap B)'\)
\(= A \cap (A' \cup B')\)
\(= (A \cap A') \cup (A \cap B')\)
\(= \phi \cup (A \cap B')\)
\(= A \cap B' = A - B = \) RHS.
$Proof$
Q28
For all sets \(A\) and \(B\), prove that \((A \cup B) - B = A - B\).
LHS = \((A \cup B) \cap B'\)
\(= (A \cap B') \cup (B \cap B')\)
\(= (A - B) \cup \phi\)
\(= A - B = \) RHS.
$Proof$
Q29
Let \(T = \{x | \frac{x+5}{x-7} - 5 = \frac{4x-40}{13-x}\}\). Is \(T\) an empty set? Justify your answer.
Equation: \(\frac{x+5}{x-7} - 5 = \frac{4x-40}{13-x}\)
\(\frac{x+5 - 5(x-7)}{x-7} = \frac{4(x-10)}{13-x}\)
\(\frac{x+5-5x+35}{x-7} = \frac{4(x-10)}{13-x}\)
\(\frac{40-4x}{x-7} = \frac{4(x-10)}{13-x}\)
\(\frac{4(10-x)}{x-7} = \frac{4(x-10)}{13-x}\)
\((10-x) [\frac{4}{x-7} + \frac{4}{13-x}] = 0\)
\(x = 10\) or \(\frac{1}{x-7} + \frac{1}{13-x} = 0\)
If \(x \neq 10\), \(\frac{13-x + x-7}{(x-7)(13-x)} = 0 \implies \frac{6}{(x-7)(13-x)} = 0\) (Impossible).
So \(x = 10\). Check denominators: \(10-7=3 \neq 0\), \(13-10=3 \neq 0\).
\(T = \{10\}\). It is not empty.
$No, T = {10}$
