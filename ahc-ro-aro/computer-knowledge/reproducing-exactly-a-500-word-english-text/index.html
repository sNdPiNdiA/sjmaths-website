Reproducing Exactly A 500 Word English Text Core Study Notes

Part-B of the Allahabad High Court RO/ARO examination features a mandatory Computer Knowledge and Typing Test. Candidates must reproduce a given 500-word English text on a computer within 20 minutes, requiring a minimum speed of 25 WPM with high accuracy, where evaluation strictly penalizes formatting and spelling errors.

Typing Test Parameters & Error Evaluation

Understanding the exact scoring mechanism, speed calculation, and error classification is critical to scoring the minimum qualifying 17 marks out of 50.

  • Minimum Speed Requirement: Candidates must achieve a minimum typing speed of 25 Words Per Minute (WPM) in English on the computer to avoid automatic disqualification.
  • Word Definition in Typing: A standard 'word' is defined as 5 keystrokes (including spaces and punctuation marks). Formula: Gross WPM = (Total Keystrokes / 5) / Time (Minutes).
  • Net Speed Calculation: Net WPM = Gross WPM - (Errors / Time). Only Net WPM and accuracy percentage determine the final merit score out of 50 marks.
  • Formatting Fidelity: The reproduced text must exactly match the source text's indentations, paragraph breaks, bold/italic stylings, and capitalizations.
Error Type Description Penalty/Deduction
Full Mistake (पूर्ण त्रुटि) Omission of a word, substitution of a word, or addition of an extra word not in the text. 0.1 Marks deducted per occurrence from the total 50 marks.
Half Mistake (अर्ध त्रुटि) Spelling errors, wrong capitalization, punctuation errors, or spacing errors between words. 0.05 Marks deducted per occurrence from the total 50 marks.
Incomplete Text (अपूर्ण पाठ) Failing to type the complete 500-word passage within the 20-minute limit. Proportional deduction + penalty for untyped words; high risk of scoring below 17.

Computer Architecture & CPU Registers

Theoretical computer knowledge is tested alongside practical skills. Understanding CPU operations and memory hierarchy is fundamental.

  • Program Counter (PC): A CPU register that holds the memory address of the next instruction to be fetched and executed. It increments automatically after fetching.
  • Accumulator (AC): A primary register in the ALU (Arithmetic Logic Unit) used to store intermediate arithmetic and logical results during computation.
  • Memory Address Register (MAR): Holds the memory location of data that needs to be accessed (read from or written to) by the CPU.
  • Instruction Register (IR): Stores the instruction currently being decoded and executed by the control unit of the CPU.

MS Word Formatting & Keyboard Shortcuts

Exact text reproduction requires rapid formatting. Mastery of MS Word shortcuts prevents time loss during the exam.

  • Paragraph Alignment: Ctrl + L (Left), Ctrl + R (Right), Ctrl + E (Center), and Ctrl + J (Justify). Justify alignment is highly common in official court judgments.
  • Line Spacing Shortcuts: Ctrl + 1 for Single Spacing, Ctrl + 2 for Double Spacing, and Ctrl + 5 for 1.5 Line Spacing.
  • Font Formatting: Ctrl + B (Bold), Ctrl + I (Italic), Ctrl + U (Underline). Use Ctrl + Shift + D for double underline and Ctrl + Shift + W to underline words only.
  • Non-Breaking Space: Ctrl + Shift + Spacebar creates a space that prevents an automatic line break at that specific position, keeping words together.

Internet Protocols & Email Architecture

Networking and email transmission concepts are frequently tested in the theoretical section of the AHC RO/ARO computer paper.

  • SMTP (Simple Mail Transfer Protocol): Used for sending emails from a client to a server or between servers. It operates on TCP Port 25 (non-encrypted) or Port 587 (encrypted/TLS).
  • POP3 (Post Office Protocol v3): Downloads emails from the server to a single local device and deletes them from the server by default. Operates on Port 110.
  • IMAP (Internet Message Access Protocol): Allows synchronization of emails across multiple devices; emails remain stored on the server. Operates on Port 143.
  • OSI Model Layers: A 7-layer conceptual framework: Physical, Data Link, Network, Transport, Session, Presentation, and Application. Routers operate at Layer 3 (Network).
