Target Typing Speed 25 Wpm & Computer Fundamentals Core Study Notes

This module covers essential computer knowledge and the mandatory 25 WPM typing speed requirement for the Allahabad High Court RO/ARO examination. Mastery over computer architecture, MS Office operations, and ergonomic keyboard proficiency is crucial for clearing the practical typing test and computer-based objective papers.

Computer Architecture & Memory Hierarchy

Fundamental concepts regarding CPU components, registers, RAM, ROM, and secondary storage essential for objective tests.

  • CPU Registers: Fastest volatile storage inside the CPU processor including Accumulator (ACC), Program Counter (PC), and Memory Address Register (MAR).
  • Primary Memory: RAM (Random Access Memory) is volatile and stores data currently in use, whereas ROM (Read Only Memory) is non-volatile and stores boot firmware like BIOS/UEFI.
  • Cache Memory: Extremely fast SRAM placed between CPU and main memory to reduce data access latency (Levels: L1, L2, L3).
  • Secondary Storage: Non-volatile storage devices including Hard Disk Drives (HDD), Solid State Drives (SSD), and Optical Discs (CD/DVD/Blu-ray).
  • Input/Output Interfaces: Devices bridging human-machine interaction, with keyboards and mice serving as primary input and monitors and printers as primary output.

Operating Systems & MS Office Suite

Core competencies in OS functions, file management, and productivity applications (Word, Excel, PowerPoint).

  • OS Kernel & Shell: The kernel is the core component managing hardware resources, while the shell acts as the user interface interface interpreter.
  • MS Word Shortcuts: Essential shortcuts include Ctrl+C (Copy), Ctrl+V (Paste), Ctrl+Z (Undo), Ctrl+Y (Redo), and F12 (Save As).
  • MS Excel Formulas: Functions begin with '=' such as =SUM(A1:A10), =AVERAGE(B1:B5), and =COUNT(C1:C20) which are heavily tested.
  • MS PowerPoint Presentations: F5 key starts slide show from the beginning, while Shift+F5 starts from the current slide.

Networking, Internet & Email Protocols

Understanding LAN/WAN topologies, IP addressing, web navigation, and standard mail transfer protocols.

  • Network Topologies: Bus, Star, Ring, Mesh, and Tree topologies define how network nodes are interconnected physically and logically.
  • Email Protocols: SMTP (Port 25) sends emails, POP3 (Port 110) downloads and removes server mail, and IMAP (Port 143) syncs mail across multiple devices.
  • IP Addressing: IPv4 uses a 32-bit address scheme with dotted-decimal notation, whereas IPv6 uses a 128-bit address scheme with hexadecimal notation.

Cyber Security & Typing Speed Standards (25 WPM)

Core malware types, firewalls, and specific technical parameters for achieving the 25 WPM typing speed requirement.

  • Malware & Viruses: Viruses replicate by attaching to files, Trojans disguise as legitimate software, and Ransomware encrypts files demanding a ransom.
  • Target Typing Speed (25 WPM): The AHC RO/ARO typing test mandates a minimum speed of 25 Words Per Minute (WPM) in English on a computer keyboard with high accuracy.
  • Calculation of WPM: Standard word length is considered as 5 characters including spaces. Gross WPM = (Total characters typed / 5) / Time in minutes.
  • Keyboard Ergonomics: Proper finger placement on the home row (ASDF for left hand, JKL; for right hand) is essential to cross the 25 WPM threshold without looking at keys.

MS Office Suite & Document Processing

Core functionalities of MS Word, Excel, and PowerPoint required for official noting, drafting, and data management.

  • MS Word Shortcuts: Frequent shortcuts include Ctrl+B (Bold), Ctrl+I (Italic), Ctrl+U (Underline), and Ctrl+S (Save).
  • MS Excel Formulas: Essential functions include SUM, AVERAGE, COUNT, VLOOKUP, and IF conditions for tabular data analysis.
  • MS PowerPoint Presentations: Used for creating slide shows; F5 starts a presentation from the beginning, and Shift+F5 starts from the current slide.
  • File Extensions: Modern Office formats use XML extensions: .docx for Word, .xlsx for Excel, and .pptx for PowerPoint.

Networking, Internet & Email Protocols

Fundamental concepts of LAN, WAN, network topologies, TCP/IP, and secure electronic communication.

  • Network Topologies: Arrangement of devices in a network including Star, Bus, Ring, Mesh, and Tree topologies.
  • IP Addressing: IPv4 uses 32-bit addresses (dotted decimal), while IPv6 uses 128-bit addresses (hexadecimal).
  • Email Protocols: SMTP (Simple Mail Transfer Protocol) sends emails; POP3 and IMAP receive and retrieve emails from mail servers.
  • Cyber Security & Malware: Protection against malicious software including viruses, worms, trojan horses, ransomware, and phishing attacks.

Target Typing Speed 25 WPM & Accuracy Standards

Guidelines, software mechanics, and techniques for mastering 25 WPM speed with high accuracy in Allahabad High Court exams.

  • WPM Calculation Formula: Words Per Minute is calculated based on standard words (5 characters including spaces) divided by total time in minutes.
  • Accuracy Benchmark: Examinations require a minimum speed of 25 WPM with permissible error margins; excessive mistakes lead to negative score adjustments or disqualification.
  • Hindi Layouts (Kruti Dev / Mangal): Aspirants must practice on designated Hindi fonts such as Kruti Dev 010 (Typewriter-based) or Mangal (Unicode Inscript-based) as notified by the court.
  • Touch Typing Technique: Typing without looking at the keyboard using home row positioning (ASDF JKL;) to maximize speed and minimize strain.

Computer Architecture & Memory Hierarchy

A deep dive into the hardware components, CPU registers, and memory systems that form the backbone of computer operations.

  • CPU Registers: High-speed storage locations inside the CPU. Key registers include the Program Counter (PC) which holds the address of the next instruction, and the Accumulator (AC) which stores intermediate arithmetic results.
  • Cache Memory: Extremely fast SRAM-based memory located close to the CPU. It stores frequently accessed data to reduce access time. Divided into L1, L2, and L3 levels based on speed and proximity.
  • RAM vs ROM: RAM (Random Access Memory) is volatile, temporary storage used for active processes. ROM (Read-Only Memory) is non-volatile and contains the BIOS (Basic Input/Output System) required to boot the computer.
  • Secondary Storage: Non-volatile storage devices like HDD (Hard Disk Drive) and SSD (Solid State Drive). SSDs use flash memory and are significantly faster than magnetic HDDs due to the absence of moving parts.

MS Office Suite & Keyboard Shortcuts

Mastering MS Word, Excel, and PowerPoint along with keyboard shortcuts is essential for both the written exam and daily administrative tasks as a Review Officer.

  • MS Word Formatting: Key features include Mail Merge (for bulk mailing), Page Setup (margins, orientation), and Paragraph formatting. Shortcuts like Ctrl+L (Left Align), Ctrl+E (Center Align), and Ctrl+J (Justify) are frequently tested.
  • MS Excel Formulas: Excel uses formulas starting with '='. Crucial functions include VLOOKUP (vertical search), SUMIF (conditional sum), and absolute cell referencing using the '#039; symbol (e.g., $A$1).
  • MS PowerPoint Views: PowerPoint offers views like Normal, Slide Sorter (for reorganizing slides), and Reading View. F5 starts the slideshow from the beginning, while Shift+F5 starts it from the current slide.
  • Universal Shortcuts: Essential shortcuts for speed: Ctrl+Z (Undo), Ctrl+Y (Redo), Ctrl+K (Insert Hyperlink), and Alt+Tab (Switch between open applications).

Networking, Internet & Email Protocols

A comprehensive overview of network topologies, the OSI model, and the protocols that govern internet communication and email transmission.

  • Network Topologies: The physical layout of a network. Star topology uses a central hub/switch. Mesh topology offers high redundancy as every node is connected to every other node.
  • OSI Model Layers: A conceptual framework of 7 layers: Physical, Data Link, Network, Transport, Session, Presentation, and Application. Routers operate at the Network Layer (Layer 3).
  • SMTP vs POP3 vs IMAP: SMTP (Simple Mail Transfer Protocol) is used to send emails. POP3 (Post Office Protocol) downloads emails to a single device and deletes them from the server. IMAP (Internet Message Access Protocol) syncs emails across multiple devices.
  • IP Addressing: IPv4 addresses are 32-bit (written in decimal, e.g., 192.168.1.1), whereas IPv6 addresses are 128-bit (written in hexadecimal) to accommodate the growing number of internet devices.
