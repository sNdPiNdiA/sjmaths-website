Lan Wan Networking Basics Lan Wan Core Study Notes

This topic covers the fundamental concepts of computer networks, focusing on Local Area Networks (LAN) and Wide Area Networks (WAN), their architectures, topologies, protocols, and hardware. Mastery of these concepts is highly critical for the Allahabad High Court RO/ARO exam, where networking and internet basics form a substantial part of the computer knowledge section.

Classification of Networks by Geographical Scale

Computer networks are primarily classified based on the geographical area they span, ranging from a few meters to global coverage.

  • PAN (Personal Area Network): Centred around an individual person within a range of 10 meters. Examples include Bluetooth (IEEE 802.15.1) connections between smartphones, smartwatches, and wireless headphones.
  • LAN (Local Area Network): Spans a small geographical area such as an office, home, or school. It features high data transfer rates (up to 10 Gbps), low propagation delay, and low error rates. Primarily uses Ethernet (IEEE 802.3) or Wi-Fi (IEEE 802.11).
  • MAN (Metropolitan Area Network): Covers a larger geographic area than a LAN, typically a city or town (range 5 to 50 km). A classic example is a cable television network or campus-wide connectivity across a city.
  • WAN (Wide Area Network): Spans across countries, continents, or the entire globe. The Internet is the largest public WAN. It has lower data transfer speeds compared to LAN, higher propagation delays, and uses routers, satellites, and fiber-optic undersea cables.

Network Topologies and Architectures

Network topology defines the physical or logical arrangement of nodes, links, and devices in a network.

  • Star Topology: All nodes are connected to a central hub or switch. If the central device fails, the entire network goes down. However, individual cable failure only affects that specific node. It is the most common topology in modern LANs.
  • Bus Topology: Uses a single central cable (backbone) to connect all devices. Terminators are required at both ends to prevent signal bounce. If the main cable breaks, the entire network fails.
  • Ring Topology: Devices are connected in a circular loop. Data travels in one direction (unidirectional) or both (bidirectional) using a token-passing mechanism. A single node failure can disrupt the entire network.
  • Mesh Topology: Every node is connected to every other node (Full Mesh) or some other nodes (Partial Mesh). Highly redundant and fault-tolerant. The formula for the number of physical links in a full mesh of 'n' nodes is n(n-1)/2.

Networking Hardware Devices

Different hardware components operate at various layers of the OSI model to facilitate data transmission across LANs and WANs.

  • Hub: A non-intelligent Physical Layer (Layer 1) device that broadcasts incoming data packets to all connected ports, leading to high network traffic and collision risks.
  • Switch: An intelligent Data Link Layer (Layer 2) device. It uses MAC addresses to forward data packets specifically to the destination node (unicast), reducing unnecessary traffic.
  • Router: A Network Layer (Layer 3) device that connects different networks (e.g., connecting a LAN to a WAN). It routes data packets based on IP addresses using routing tables.
  • Gateway: A device or software that connects two completely heterogeneous networks with different protocols. It operates across all layers of the OSI model.

IP Addressing and Network Protocols

Protocols and addressing schemes ensure that data is accurately addressed and delivered across complex networks.

  • IPv4 vs IPv6: IPv4 uses a 32-bit address (e.g., 192.168.1.1) divided into 4 octets, supporting ~4.3 billion addresses. IPv6 uses a 128-bit hexadecimal address (e.g., 2001:db8::ff00:42:8329) to accommodate the massive growth of internet-connected devices.
  • MAC Address: A Media Access Control address is a unique 48-bit (6 bytes) physical address burned into the Network Interface Card (NIC) by the manufacturer. It is represented in hexadecimal format (e.g., 00:1A:2B:3C:4D:5E).
  • DNS (Domain Name System): Acts as the phonebook of the Internet. It translates human-readable domain names (like www.allahabadhighcourt.in) into machine-readable IP addresses. It primarily uses UDP port 53.
  • DHCP (Dynamic Host Configuration Protocol): Automatically assigns IP addresses, subnet masks, default gateways, and DNS server details to client devices on a network, eliminating manual configuration errors.
