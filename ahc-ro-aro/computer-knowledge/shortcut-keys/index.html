Shortcut Keys Core Study Notes

Keyboard shortcut keys are critical for maximizing operational efficiency in the Allahabad High Court RO/ARO exams. Mastery of these shortcuts is essential for clearing both the objective computer knowledge section and the mandatory 25+ WPM Hindi/English computer typing test.

MS Office Suite Shortcuts (Word & Excel)

MS Word and MS Excel shortcuts are highly targeted in the AHC RO/ARO exam to test candidates' document processing and spreadsheet management skills.

  • Ctrl + K (Insert Hyperlink): Opens the 'Insert Hyperlink' dialog box in both MS Word and Excel, allowing users to link text or cells to external files, web pages, or document locations.
  • Ctrl + H (Find and Replace): Launches the 'Find and Replace' dialog box. In MS Word, it defaults to the Replace tab, whereas Ctrl+F opens the Navigation pane in newer versions.
  • Ctrl + Enter (Page Break): Inserts a hard page break at the cursor position in MS Word, forcing the subsequent text to start on a new page immediately.
  • Shift + F3 (Change Case): Toggles selected text in MS Word through three case options: UPPERCASE, lowercase, and Title Case (Capitalize Each Word).
  • F7 (Spelling & Grammar): Launches the Spelling and Grammar check tool across MS Office applications (Word, Excel, PowerPoint) to identify and correct linguistic errors.

Windows OS & File Explorer Shortcuts

System-level shortcuts in Windows operating systems are frequently tested to evaluate a candidate's ability to navigate the OS environment rapidly.

  • Win + D (Show Desktop): Instantly minimizes all open windows to display the desktop. Pressing it again restores the windows to their original state.
  • Win + E (Open File Explorer): Launches a new instance of Windows File Explorer, allowing quick access to drives, folders, and files without using the mouse.
  • Ctrl + Shift + Esc (Task Manager): Directly opens the Windows Task Manager without the intermediate screen triggered by the traditional Ctrl + Alt + Delete combination.
  • Win + L (Lock Computer): Locks the computer workstation immediately, securing active sessions and prompting for password/PIN re-entry.
  • Alt + F4 (Close Active Window): Closes the currently active application or window. If pressed on the desktop with no active windows, it opens the Windows Shutdown dialog box.

Web Browser & Internet Navigation Shortcuts

With the increasing reliance on web-based administrative portals, browser shortcuts are essential for efficient online research and data entry.

  • Ctrl + T (New Tab): Opens a new tab in almost all modern web browsers (Chrome, Firefox, Edge), allowing parallel browsing sessions.
  • Ctrl + Shift + T (Reopen Closed Tab): Restores the last closed browser tab. It can be pressed repeatedly to reopen multiple previously closed tabs in chronological reverse order.
  • Ctrl + H (Browser History): Opens the History panel or page in the active browser, showing a chronological list of recently visited websites.
  • Ctrl + Shift + N (Incognito/Private Window): Opens a new Incognito window in Google Chrome (Ctrl+Shift+P in Firefox/Edge) for private browsing without saving history or cookies.

Typing Test & Special Character Alt Codes

For the AHC RO/ARO typing test (especially Hindi typing in Mangal or Kruti Dev fonts), special Alt codes are critical for typing complex characters.

  • Alt + 0161 (Kruti Dev Special Character): Used in Kruti Dev 010 font to type the character 'द्व' (dva), which is highly frequent in Hindi administrative vocabulary.
  • Alt + 0216 (Kruti Dev 'क्र'): Generates the conjunct character 'क्र' (kra) in Kruti Dev, essential for typing words like 'क्रम' (order) or 'क्रय' (purchase).
  • Ctrl + Backspace (Delete Whole Word): Deletes the entire word to the left of the cursor instead of a single character, significantly increasing correction speed during typing tests.
  • Ctrl + Delete (Delete Word to Right): Deletes the entire word to the right of the cursor, helping in quick text editing and alignment adjustments.
