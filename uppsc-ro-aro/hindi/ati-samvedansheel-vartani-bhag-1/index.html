विशेष परीक्षा जाल (Top Negative Traps)

'उज्ज्वल' vs 'प्रज्वलित'
उज्ज्वल में दो बार आधा 'ज्' आता है (उत् + ज्वल = उज्ज्वल)।
किंतु प्रज्वलित में केवल एक बार आधा 'ज्' आता है (प्र + ज्वलित = प्रज्वलित)। परीक्षा में 'प्रज्ज्वलित' देकर फंसाया जाता है जो सर्वथा अशुद्ध है।
'शृंगार' की सही लिखावट
'श' में 'ऋ' की मात्रा लगने पर 'शृ' बनता है। कंप्यूटर या फोंट में प्रायः 'श्रृ' छप जाता है, जो अशुद्ध है क्योंकि इसमें 'र' और 'ऋ' दोनों एक साथ लग जाते हैं। शुद्ध रूप 'शृंगार' है।
गोल्डन मंत्र कवयित्री ('कव' याद रखें, 'कवि' नहीं)। उज्ज्वल (दो आधा ज), प्रज्वलित (एक आधा ज)। ज्योत्स्ना (आधा त + आधा स)।

अनाधिकारअनधिकारअन + अधिकार = अनधिकार (अन् में अ मिलने पर 'ना' नहीं बनता)।
दुरावस्थादुरवस्थादुर् + अवस्था = दुरवस्था (दुर् में अ मिलने पर 'रा' नहीं बनता)।
निरपराधीनिरपराधनिर् + अपराध = निरपराध (विशेषण रूप निरपराध है, ई प्रत्यय अतिरिक्त है)।
निरहंकारीनिरहंकारनिर् + अहंकार = निरहंकार (निरहंकारी अशुद्ध है)।
निरपेक्ष / निरपेक्ष्यनिरपेक्षनिर् + अपेक्षा = निरपेक्ष।
राजनैतिकराजनीतिकनीति में इक जुड़ने से नैतिक बनता है, परन्तु राजनीति में सीधे इक जोड़ने पर 'राजनीतिक' ही मानक है।
प्रफुल्लितप्रफुल्लप्रफुल्ल स्वयं विशेषण है, इसमें 'इत' प्रत्यय लगाना पुनरुक्ति दोष है।
सदृश्यसदृशस + दृश् = सदृश (समान)। 'सदृश्य' अशुद्ध रूप है।
कृशांगिनीकृशांगीकृश + अंगी = कृशांगी (दुबली-पतली स्त्री)। अंगिनी प्रत्यय अशुद्ध है।
कोमलांगीनीकोमलांगीकोमल + अंगी = कोमलांगी।
शुश्रुषा / सुश्रूषासुश्रूषाप्रथम दंत्य 'सु', द्वितीय तालव्य दीर्घ 'श्रू', तृतीय मूर्धन्य 'षा' (रोगी की सेवा)।
शमशान / स्मशानश्मशानतालव्य आधा 'श्' + म + तालव्य 'शा' + न = श्मशान।
कलेशक्लेशआधा 'क्' + 'ले' + तालव्य 'श' = क्लेश (कलेश लोकबोली का अशुद्ध रूप है)।
जिजीविषा / जीजिविषाजीजीविषाप्रथम 'जी' (दीर्घ), द्वितीय 'जी' (दीर्घ), तृतीय 'वि' (ह्रस्व) = जीजीविषा (जीने की प्रबल इच्छा)।
मुमूर्षु / मुमूर्षामुमूर्षुप्रथम 'मु' (ह्रस्व), द्वितीय 'मूर्' (दीर्घ रेफ युक्त), तृतीय 'षु' (ह्रस्व) = मुमूर्षु (मरने का इच्छुक)।
विभीषिका / विभीषीकाविभीषिकावि (ह्रस्व), भी (दीर्घ), षि (ह्रस्व), का = विभीषिका।
दधीचि / दधीचीदधीचिदधी (दीर्घ), चि (ह्रस्व) = दधीचि (महर्षि जिन्होंने अस्थि दान की)।
युधिष्ठिर / युधिष्ठिरयुधिष्ठिरयुधि (युद्ध में) + स्थिर = युधिष्ठिर (ष् के बाद 'ठि' मूर्धन्य)।
जाह्नवी / जाह्नविजाह्नवीजा + ह्लन्त 'ह्' के भीतर 'न' + वी (दीर्घ) = जाह्नवी (गंगा)।
भागीरथी / भागीरथीभागीरथीभगीरथ + ई = भागीरथी (आदि-स्वर वृद्धि 'भा' और पदान्त दीर्घ 'थी')।
उच्छ्वास / उच्चवासउच्छ्वासउत् + श्वास = उच्छ्वास (च् के साथ छ् और व का संयोग)।
स्रोत / स्त्रोतस्रोतदंत्य 'स्' में 'र' का योग = 'स्र' (स्रोत)। 'स्त्रोत' (स्+त्+र) सर्वथा अशुद्ध है।
चिन्ह / चिह्न्चिह्नह्लन्त 'ह्' के पेट में 'न' = चिह्न (चि-ह्-न, न कि चि-न्-ह)।
ब्रम्हा / ब्राह्माब्रह्माब में र = ब्र, फिर ह्लन्त 'ह्' + 'मा' = ब्रह्मा।
आह्वान / आहवानआह्वानआ + ह्लन्त 'ह्' + वान = आह्वान।

जिह्वा / जीभ्वाजिह्वाजि + ह्लन्त 'ह्' + वा = जिह्वा।
सौहार्द्र / सौहार्द्यसौहार्दसुहृद् + अण् = सौहार्द (द के ऊपर केवल रेफ, नीचे '्र' नहीं)।
वैमनस्यतावैमनस्यविमना + ष्यञ् = वैमनस्य (य के साथ ता लगाना दोहरा भाववाचक दोष है)।
पारलौकिक / परलौकिकपारलौकिकपरलोक + इक = पारलौकिक (आदि-स्वर वृद्धि 'पा')।

स्तरानुरूप 15 प्रश्नों का परीक्षण: स्तर 1 (तथ्यात्मक), स्तर 2 (मध्यम/सुमेलन), स्तर 3 (कथन-कारण व विश्लेषणात्मक):

UPPSC RO/ARO मुख्य परीक्षा (Mains Format) — प्रारूप एवं आदर्श उत्तर

मुख्य परीक्षा प्रश्नपत्र-2 (सामान्य हिन्दी एवं आलेखन) तथा प्रश्नपत्र-1 (वस्तुनिष्ठ) के मानक अनुरूप मॉडल प्रश्न व उत्तर:

UPPSC RO/ARO मुख्य परीक्षा प्रारूप 5 अंक
1. आयोग के 5 सबसे संवेदनशील वर्तनी शब्दों का शुद्ध रूप एवं कारण लिखिए।
आदर्श उत्तर (Examiner Standard)

1. कवयित्री (कव + यित्री)
2. उज्ज्वल (उत् + ज्वल = दो आधा ज)
3. प्रज्वलित (प्र + ज्वलित = एक आधा ज)
4. शृंगार (श + ऋ = शृ)
5. अहल्या (संस्कृत तत्सम, अहिल्या अशुद्ध)

परीक्षा कक्ष त्वरित रिवीज़न — मुख्य बिंदु एवं ट्रैप्स (Exam Traps)

महत्वपूर्ण परीक्षा बिंदु (Must-Remember Points)

  • कवयित्री शुद्ध है (कवियत्री अशुद्ध)।
  • उज्ज्वल (दो आधा ज), प्रज्वलित (एक आधा ज)।
  • शृंगार शुद्ध है (श्रृंगार अशुद्ध)।
  • ज्योत्स्ना (आधा त + आधा स)।
  • अहल्या, वाल्मीकि, कालिदास, अनुगृहीत शुद्ध।

सामान्य भ्रांतियां एवं आयोग के ट्रैप्स (Common Pitfalls)

  • सजातीयता का उल्लंघन कदापि न करें (तत्सम का विलोम तत्सम, तद्भव का तद्भव)।
  • विकल्पों में मिलते-जुलते भ्रामक वर्तनी वाले शब्दों से सतर्क रहें।
