UPPSC RO/ARO मुख्य परीक्षा (Mains Format) — प्रारूप एवं आदर्श उत्तर

मुख्य परीक्षा प्रश्नपत्र-2 (सामान्य हिन्दी एवं आलेखन) तथा प्रश्नपत्र-1 (वस्तुनिष्ठ) के मानक अनुरूप मॉडल प्रश्न व उत्तर:

UPPSC RO/ARO मुख्य परीक्षा प्रारूप 5 अंक
1. रसोई के पाँच प्रमुख मसालों एवं पाँच खाद्यान्नों के तत्सम-तद्भव रूपों की तुलनात्मक तालिका बनाइए।
आदर्श उत्तर (Examiner Standard)

1. पाँच प्रमुख मसाले:

  • हरिद्रा -> हल्दी
  • जीरक -> जीरा
  • लवंग -> लौंग
  • एला -> इलायची
  • आर्द्रक -> अदरक

2. पाँच प्रमुख खाद्यान्न / दलहन:

  • गोधूम -> गेहूँ
  • यव -> जौ
  • चणक -> चना
  • तन्दुल -> चावल
  • माष -> उड़द

परीक्षा कक्ष त्वरित रिवीज़न — मुख्य बिंदु एवं ट्रैप्स (Exam Traps)

महत्वपूर्ण परीक्षा बिंदु (Must-Remember Points)

  • हरिद्रा = हल्दी; एला = इलायची; लवंग = लौंग; आर्द्रक = अदरक।
  • गोधूम = गेहूँ; यव = जौ; चणक = चना; सक्तु = सत्तू।
  • नारिकेल = नारियल; आमलक = आँवला; कदली = केला; दाड़िम = अनार।
  • कूष्मांड = कुम्हड़ा/पेठा; वार्ताक = बैंगन; तक्र = मट्ठा; नवनीत = मक्खन।

सामान्य भ्रांतियां एवं आयोग के ट्रैप्स (Common Pitfalls)

  • नारिकेल (नारियल) और आमलक (आँवला) की वर्तनी ध्यान रखें।
  • आर्द्रक में दोनों "र" (रेफ और पदेन) होते हैं: "आर्द्रक"।
