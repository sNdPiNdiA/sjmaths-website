महत्वपूर्ण परीक्षा बिंदु (Must-Remember Points)

  • उपाध्याय -> ओझा; पंडित -> पाँड़े; श्रेष्ठी -> सेठ।
  • द्विवेदी -> दूबे; त्रिवेदी -> तिवारी; चतुर्वेदी -> चौबे।
  • दीपावली -> दिवाली; होलिका -> होली; रक्षाबंधन -> राखी।
  • कपाट -> किवाड़; करपट -> कपड़ा; प्रस्तर -> पत्थर; शिला -> सिल।
  • एकादशी -> ग्यारस; पूर्णिमा -> पूनम; अमावस्या -> अमावस।

सामान्य भ्रांतियां एवं आयोग के ट्रैप्स (Common Pitfalls)

  • कपाट (किवाड़) और करपट (कपड़ा) में भ्रमित न हों।
  • प्रस्तर (पत्थर) और पाषाण (पाहन) के तद्भव रूप भिन्न हैं।
