'इक' व 'य' प्रत्यय: आदि-स्वर वृद्धि (Vowel Gradation) का अकाट्य नियम

जब किसी मूल शब्द में 'इक' अथवा 'य' तद्धित प्रत्यय जुड़ता है, तो वह शब्द के प्रथम स्वर (आदि-स्वर) में अनिवार्य रूप से दीर्घीकरण या वृद्धि विकार उत्पन्न करता है। संस्कृत व्याकरण का यह सूत्र 'किति च' / 'ञ्णिति च' कहलाता है।

आदि-स्वर वृद्धि के 4 सूत्र

  • अ → आ: समाज + इक = सामाजिक (न कि समाजिक)। प्रमाण + इक = प्रामाणिक (न कि प्रमाणिक)।
  • इ / ई / ए → ऐ: इतिहास + इक = ऐतिहासिक। दिन + इक = दैनिक। वेद + इक = वैदिक।
  • उ / ऊ / ओ → औ: भूगोल + इक = भौगोलिक। उपन्यास + इक = औपन्यासिक। योग + इक = यौगिक।
  • ऋ → आर्: गृहस्थ + इक = गार्हस्थ्य / गार्हस्थिक। हृदय + इक = हार्दिक।

'य' प्रत्यय का अंतिम वर्ण लोप नियम

  • 'य' प्रत्यय जुड़ने पर न केवल आदि स्वर बढ़ता है, बल्कि अंतिम स्वर का लोप होकर व्यंजन आधा हो जाता है:
  • सुंदर + य = सौंदर्य (सु → सौ, र् आधा)।
  • मधुर + य = माधुर्य (म → मा, र् आधा)।
  • उदार + य = औदार्य (उ → औ, र् आधा)।
  • एक + य = ऐक्य (ए → ऐ, क आधा)।

2. दो भाववाचक प्रत्ययों का एक साथ प्रयोग निषेध (Double Suffix Error)

सर्वोच्च व्याकरणिक नियम: हिन्दी एवं संस्कृत में किसी शब्द में एक साथ दो भाववाचक प्रत्यय (जैसे: 'य' + 'ता' अथवा 'त्व' + 'ता') जोड़ना गंभीर व्याकरणिक दोष है। या तो केवल 'य' प्रत्यय लगेगा, या केवल 'ता' प्रत्यय लगेगा—दोनों एक साथ कभी नहीं आ सकते!

आयोग के घातक ट्रैप्स (Negative Marking Traps)

'सौंदर्यता' और 'माधुर्यता' का वाक्य प्रयोग
UPPSC RO/ARO में वाक्य शुद्धि में प्रायः आता है: "उसकी सौंदर्यता अनुपम है।" → यह वाक्य अशुद्ध है! शुद्ध वाक्य होगा: "उसका सौंदर्य अनुपम है" अथवा "उसकी सुंदरता अनुपम है।"
'पूज्य' बनाम 'पूजनीय'
या तो 'पूज्य' लिखिए या 'पूजनीय'। 'पूज्यनीय' (पूज्य + अनीय) शब्द हिन्दी में पूरी तरह अशुद्ध है।
वृद्धि मंत्र अ का आ, इ/ई का ऐ, उ/ऊ का औ। प्रमाण → प्रामाणिक, इतिहास → ऐतिहासिक, भूगोल → भौगोलिक।
दो प्रत्यय निषेध सूत्र सौंदर्यता, माधुर्यता, औदार्यता, ऐक्यता, धैर्यता — इन पाँचों में 'ता' जहर है! केवल सौंदर्य, माधुर्य, औदार्य, ऐक्य, धैर्य लिखें।

1. 'इक' प्रत्यय वृद्धि नियम तथा दो भाववाचक प्रत्यय निषेध को सोदाहरण समझाइए।

1. 'इक' प्रत्यय जुड़ने पर प्रथम स्वर दीर्घ हो जाता है: प्रमाण → प्रामाणिक, इतिहास → ऐतिहासिक, भूगोल → भौगोलिक।
2. एक शब्द में दो भाववाचक प्रत्यय वर्जित हैं: सुंदर से या तो 'सौंदर्य' बनेगा या 'सुंदरता'। 'सौन्दर्यता' अशुद्ध है।
