1. पृथ्वी वर्ग के 18 प्रामाणिक पर्यायवाची एवं व्युत्पत्ति

पृथ्वी के पर्यायवाची शब्दों पर आयोग लगभग प्रत्येक वर्ष 1-2 प्रश्न अवश्य पूछता है। विशेष रूप से 'इला', 'रसा', 'मेदिनी', 'अचला' जैसे शब्दों पर सर्वाधिक ट्रैप बनाए जाते हैं।

पर्यायवाची शब्द व्युत्पत्ति एवं शास्त्रीय अर्थ UPPSC परीक्षा संदर्भ एवं विशेष ध्यान देने योग्य तथ्य
धरा / धरणी / धरित्रीधृ (धारण करना) + अच्/अनि = जो समस्त चराचर जगत को धारण करती है।सामान्य और शास्त्रीय दोनों रूपों में मान्य। तत्सम रूप 'धरित्री' है।
वसुंधरा / वसुधा / वसुमतीवसु (रत्न/धन) + धरा = जो अपने गर्भ में विपुल रत्न और खनिज संजोए हुए है।'वसु' का अर्थ रत्न अथवा धन होता है।
मेदिनीमधु-कैटभ दैत्यों के 'मेद' (वसा/मांस) से निर्मित होने के पौराणिक आख्यान से।आयोग का सर्वाधिक पसंदीदा कठिन पर्याय। मेदिनी = पृथ्वी।
अचलान चलति इति अचला = जो चलायमान नहीं है, स्थिर है।चेतावनी: 'अचल' (पुंल्लिंग) पर्वत का पर्याय है, जबकि 'अचला' (स्त्रीलिंग) पृथ्वी का पर्याय है।
महीमह् (पूजित होना / विशाल होना) = विशाल पूज्य भूमि।महीधर = पर्वत; महीपति = राजा; महीप = राजा।
इलाइल् (अन्न देना / प्रेरणा) = अन्नदायिनी पृथ्वी; सरस्वती व गाय का भी पर्याय।ट्रैप: 'इला' पृथ्वी का पर्याय है, जबकि 'अलि' भौंरा/सखी है। इला सरस्वती का भी अनेकार्थी है।
उर्वीउरु (विशाल/विस्तृत) = अत्यंत विस्तीर्ण भूपटल।उर्वीधर = पर्वत; उर्वीपति = राजा।
क्षितिक्षि (निवास करना) = जहाँ समस्त प्राणी निवास करते हैं।क्षितिज = जहाँ पृथ्वी और आकाश मिलते प्रतीत हों (क्षितौ जायते इति)।
रसारस (जल/खनिज) से परिपूर्ण अथवा रसातल से सम्बद्ध भूभाग।ट्रैप: रसा = पृथ्वी। रसज्ञा = जीभ। रसाल = आम।
अवनीअव् (रक्षा करना) = जो संतानों की रक्षा करती है।अवनि का विलोम 'अम्बर' होता है। अवनिपति = राजा।
जगत / जगतीगम् धातु से = निरंतर परिवर्तनशील संसार/भूमि।जगती = पृथ्वी; जगतीतले = पृथ्वी तल पर।
काश्यपीमहर्षि कश्यप द्वारा परशुराम से दान में प्राप्त करने के कारण।पौराणिक पर्याय, आयोग द्वारा उच्च-स्तरीय प्रश्नों में पूछा गया।
बीजप्रसूबीजानां प्रसूतिः यस्याः = बीजों को अंकुरित करने वाली माता।लाक्षणिक पर्याय।
अनंताजिसका कोई पार या अंत न हो।अनंत = आकाश/विष्णु/शेषनाग (पुंल्लिंग); अनंता = पृथ्वी (स्त्रीलिंग)।

2. आकाश वर्ग के प्रामाणिक पर्यायवाची

आकाश के पर्यायवाची शब्दों में 'व्योम', 'पुष्कर', 'फलक', 'दिव' प्रमुख हैं:

शब्द शास्त्रीय अर्थ व व्युत्पत्ति परीक्षा ट्रैप एवं विशिष्ट प्रयोग
व्योमवि + अव् + मन् = जो अंतरिक्ष में शून्यवत् सर्वत्र व्याप्त है।व्योमकेश = शिव (जिनके बाल आकाश रूपी हों)। व्योमचारी = पक्षी/देवता।
गगनगम् धातु = विशाल शून्य विस्तार।गगनचुंबी = आकाश को छूने वाला।
नभन + भा (जहाँ कोई सीमा नहीं चमकती) / नभस्।नभश्चर = पक्षी, खेचर = पक्षी/तारे।
अम्बरअम्ब् (आच्छादित करना) = जिसने पूरी सृष्टि को वस्त्रवत् ढक रखा है।अनेकार्थी: अम्बर = आकाश, वस्त्र, एक सुगंधित द्रव्य। पीताम्बर = पीला वस्त्र/विष्णु।
अंतरिक्षअन्तः + ईक्ष् = दो लोकों (द्यौ व पृथ्वी) के मध्य का अवकाश।ऋग्वैदिक त्रि-भुवन वर्गीकरण: पृथ्वी, अंतरिक्ष, द्यौः।
पुष्करपोषयति इति पुष्करम् = जो जल धारण करता है।ट्रैप: पुष्कर = आकाश, तालाब, कमल, तीर्थराज (अजमेर), युद्ध। आयोग का अति-महत्वपूर्ण अनेकार्थी।
फलकविस्तृत आकाशीय शामियाना (उर्दू/फारसी प्रभाव से हिन्दी में गृहीत)।शायरी एवं प्रशासनिक साहित्य में आकाश के अर्थ में प्रयुक्त।
द्यौ / दिवदिव् (प्रकाशित होना) = प्रकाशमान आकाशीय लोक।दिवंगत = जो आकाश/स्वर्ग सिधार गया हो। दिवाकर = सूर्य।
अनंतजिसका कोई अंत न हो = असीम शून्य आकाश।अनंत = आकाश, विष्णु, शेषनाग।
शून्यपदार्थ-रहित विशाल अवकाश।बौद्ध दर्शन एवं गणित में प्रयुक्त।

3. जल वर्ग के प्रामाणिक पर्यायवाची एवं विशेष प्रयोग

जल के पर्यायवाची अत्यंत मूलभूत हैं क्योंकि इन्हीं में 'द' जोड़कर बादल, 'ज' जोड़कर कमल और 'धि' जोड़कर समुद्र के सैकड़ों शब्द बनते हैं:

शब्द शास्त्रीय व्युत्पत्ति परीक्षोपयोगी तथ्य
सलिलसल् (गतिशील होना) = बहने वाला निर्मल जल।सलिलक्रीड़ा = जलक्रीड़ा। शुद्ध वर्तनी 'सलिल' (ल पर ह्रस्व इ)।
वारिवृ (ढकना) = जो भूमि को आच्छादित करे।वारिद = बादल; वारिज = कमल; वारिधि = समुद्र।
नीरनी (ले जाना) = जीवन को आगे बढ़ाने वाला द्रव्य।नीरद = बादल; नीरज = कमल; नीरधि = समुद्र।
तोयतु (संतुष्ट करना) = प्यास बुझाकर तृप्त करने वाला।तोयद = बादल; तोयज = कमल; तोयधि = समुद्र।
अंबुअम्ब् (ध्वनि करना) = कलकल ध्वनि करता हुआ जल।अंबुद = बादल; अंबुज = कमल; अंबुधि = समुद्र।
पयपा (पीना) = पीने योग्य पेय, दूध अथवा जल।अनेकार्थी: पय = जल, दूध। पयोधर = स्तन, बादल। पयोधि = समुद्र।
उदकउन्द् (गीला करना) = जो तरलता प्रदान करे।उदधि = समुद्र (उदक + धि)। प्रेतोदक = तर्पण का जल।
आप / अप्आप् (व्याप्त होना) = सर्वव्यापी मूल तत्त्व।सदा बहुवचनांत: 'आपः' (संस्कृत)। अप्सरा = अप्सु सरति इति (जल में विचरण करने वाली)।
जीवनजीवयति इति = जो समस्त जीवों के प्राणों का आधार है।"जल ही जीवन है"। अनेकार्थी: जीवन = जल, प्राण, पुत्र, आजीविका।
पाथपा (रक्षा करना/पीना) से निर्मित वैदिक शब्द।पाथोद = बादल; पाथोज = कमल। पाथेय = मार्ग का भोजन।
अंभअम्ब् से विकसित रूप।अंभोज = कमल; अंभोद = बादल; अंभोधि = समुद्र।
मेघपुष्पमेघस्य पुष्पम् इव = बादलों से बरसने वाला पुष्प रूपी जल।अति-विशिष्ट वैदिक पर्याय: मेघपुष्प = जल।

UPPSC परीक्षा ट्रैप्स: पृथ्वी, आकाश व जल

  • अचल vs अचला: 'अचल' = पर्वत (न चलति यः); 'अचला' = पृथ्वी (न चलति या)। आयोग लिंग भेद से प्रश्न पूछता है।
  • पुष्कर का बहुआयामी अर्थ: पुष्कर = आकाश भी है, तालाब भी है, और कमल भी है। यदि विकल्प में आकाश और तालाब दोनों हों तो संदर्भ देखें।
  • रसा vs रसज्ञा vs रसाल: रसा = पृथ्वी; रसज्ञा = जीभ (स्वाद लेने वाली); रसाल = आम (अत्यधिक रसीला फल)।
  • इला vs अलि: इला = पृथ्वी / सरस्वती; अलि = भ्रमर (भौंरा); अली = सखी।
  • वारि vs वाजि: वारि = जल; वाजि = घोड़ा (अश्व)।

1. निम्नलिखित में से कौन-सा शब्द 'पृथ्वी' का पर्यायवाची नहीं है?
A इला
B अचला
C अचल
D अवनी
उत्तर एवं प्रामाणिक व्याख्या देखें

सही उत्तर: C

'अचल' पर्वत का पर्यायवाची है (पुंल्लिंग)। पृथ्वी के पर्यायवाची अचला, इला, अवनी, मेदिनी, उर्वी, मही, क्षिति, रसा आदि हैं।

2. 'मेदिनी' निम्नलिखित में से किसका पर्यायवाची शब्द है?
A आकाश
B पृथ्वी
C बिजली
D रात्रि
उत्तर एवं प्रामाणिक व्याख्या देखें

सही उत्तर: B

मेदिनी पृथ्वी का पर्यायवाची है। पौराणिक मान्यतानुसार मधु-कैटभ के मेद से बनने के कारण पृथ्वी को मेदिनी कहा गया।

3. निम्नलिखित में से कौन-सा शब्द 'आकाश' का पर्यायवाची नहीं है?
A नभ
B अंबर
C विप्र
D पुष्कर
उत्तर एवं प्रामाणिक व्याख्या देखें

सही उत्तर: C

'विप्र' ब्राह्मण का पर्यायवाची है। नभ, अंबर, पुष्कर, व्योम, फलक, अंतरिक्ष आकाश के पर्यायवाची हैं।

4. निम्नलिखित में से कौन-सा शब्द 'जल' का पर्यायवाची नहीं है?
A पय
B अंबु
C भव
D तोय
उत्तर एवं प्रामाणिक व्याख्या देखें

सही उत्तर: C

'भव' संसार या शिव का पर्यायवाची है (भव = संसार, भवतारिणी = दुर्गा)। पय, अंबु, तोय, सलिल, वारि, उदक जल के पर्यायवाची हैं।

5. 'रसा' निम्नलिखित में से किसका पर्यायवाची शब्द है?
A रसभरी
B पृथ्वी
C जीभ
D चंचला

A अद्रि
B उर्वी
C अर्णव
D अशनि

सही उत्तर: B

उर्वी पृथ्वी का पर्याय है। अद्रि = पर्वत, अर्णव = समुद्र, अशनि = बिजली/वज्र।

परीक्षा कक्ष त्वरित रिवीज़न — मुख्य बिंदु एवं ट्रैप्स (Exam Traps)

महत्वपूर्ण परीक्षा बिंदु (Must-Remember Points)

  • पृथ्वी: धरा, धरणी, वसुंधरा, मेदिनी, अचला, मही, इला, उर्वी, क्षिति, रसा, अवनी, काश्यपी।
  • आकाश: गगन, नभ, व्योम, अंबर, अंतरिक्ष, फलक, पुष्कर, दिव, द्यौ, शून्य।
  • जल: वारि, नीर, तोय, सलिल, अंबु, पय, आप, उदक, जीवन, पाथ, मेघपुष्प।
  • अचल = पर्वत (पुंल्लिंग); अचला = पृथ्वी (स्त्रीलिंग)।
  • रसा = पृथ्वी; रसज्ञा = जीभ; रसाल = आम।

सामान्य भ्रांतियां एवं आयोग के ट्रैप्स (Common Pitfalls)

  • पुष्कर को केवल तालाब न समझें, यह आकाश और कमल का भी पर्याय है।
  • अलि (भौंरा) और इला (पृथ्वी/सरस्वती) में वर्तनी भ्रम से बचें।
