सन्धि, समास एवं उपसर्ग जनित वर्तनी दोष: शास्त्रीय परिप्रेक्ष्य

हिन्दी वर्तनी में सर्वाधिक गंभीर त्रुटियाँ सन्धि नियमों के अज्ञान, उपसर्गों के अनुचित प्रयोग तथा सामासिक पदों के गलत संयोजन से होती हैं। छात्र बोलचाल के आधार पर शब्द लिख देते हैं, जबकि व्याकरण के अनुसार वर्णों के मेल में कठोर वैज्ञानिक नियम कार्य करते हैं।

उदाहरण के लिए: 'मिष्ठान्न' (मिष्ट + अन्न), 'संन्यासी' (सम् + न्यासी), 'अनधिकार' (अन् + अधिकार), तथा 'दुरवस्था' (दुर् + अवस्था)।

1. शीर्ष 20 सन्धि-जनित वर्तनी दोष तालिका

शुद्ध मानक वर्तनीअशुद्ध प्रचलित रूपसन्धि विच्छेद एवं नियमपरीक्षा टिप्पणी
मिष्ठान्नमिष्ठान / मिष्ठानमिष्ट (मीठा) + अन्न = मिष्ठान्न (दीर्घ स्वर संधि)।दुकानों पर 'मिष्ठान' लिखा होता है जो अशुद्ध है।
संन्यासीसन्यासी / सन्यासिसम् + न्यासी = संन्यासी (अनुस्वार और आधा 'न' दोनों)।UPPSC में बार-बार पूछा गया।
अनधिकारअनाधिकारअन् + अधिकार = अनधिकार ('अ' स्वर है, 'आ' नहीं)।'अनाधिकार' लिखना घोर अशुद्धि है।
दुरवस्थादुरावस्थादुर् + अवस्था = दुरवस्था (र् + अ = र)।'दुरावस्था' में अकारण दीर्घ 'रा' गलत है।
निरपराधनिरपराधीनिर् + अपराध = निरपराध। (निरपराधी अशुद्ध विशेषण)।वाक्य शुद्धि में बार-बार पूछा जाता है।
गत्यवरोधगत्यावरोधगति + अवरोध = गत्यवरोध (यण संधि: इ + अ = य)।'गत्यावरोध' अशुद्ध है।
तदुपरांततदोपरांततत् + उपरांत = तदुपरांत (त् → द् + उ = दु)।'तदोपरांत' अशुद्ध है।
मनोयोगमनयोगमनः + योग = मनोयोग (विसर्ग संधि)।विसर्ग का 'ओ' हो जाता है।
उज्ज्वलउज्वलउत् + ज्वल = उज्ज्वल (व्यंजन संधि)।त् का ज् में परिवर्तन।
यशोभिलाषीयशअभिलाषीयशः + अभिलाषी = यशोभिलाषी।विसर्ग का ओकार।

2. उपसर्ग एवं समास सम्बन्धी महत्वपूर्ण शब्द

शुद्ध शब्दअशुद्ध रूपउपसर्ग / समास सूत्र
अन्तर्साक्षीयअन्तरसाक्षीयअन्तः + साक्षीय = अन्तर्साक्षीय।
प्रत्युपकारप्रत्योपकारप्रति + उपकार = प्रत्युपकार (यण संधि)।
अतिशयोक्तिअतिश्योक्तिअतिशय + उक्ति = अतिशयोक्ति (पूरा 'श')।
स्वावलंबनस्वावलम्बनस्व + अवलंबन = स्वावलंबन।
निरोगनीरोगनिः + रोग = निरोग (ह्रस्व 'नि' शुद्ध)।
निरपेक्षनिरापेक्षनिर् + अपेक्षा = निरपेक्ष।
अहोरात्रअहोरात्रिअहन् + रात्रि = अहोरात्र (समास में 'रात्र' होता है)।
नवरात्रनवरात्रिनव + रात्रि = नवरात्र (शुद्ध सामासिक रूप)।
दिवाणिशदिवानिशिदिवा + निशि = दिवानिश।
सकुशलसकुशलपूर्वक'सकुशल' में 'स' स्वयं कुशल सहित है, 'पूर्वक' व्यर्थ है।

विशेष परीक्षा जाल

'अतिशयोक्ति' में 'श' पूरा होता है!
अधिकांश छात्र 'अतिश्योक्ति' (आधा श) लिखते हैं। संधि नियम: अतिशय (पूरा शब्द) + उक्ति = अतिशयोक्ति। अतः 'श' पूरा ही रहेगा।
'नवरात्र' बनाम 'नवरात्रि'
द्विगु समास में जब 'रात्रि' उत्तरपद बनता है, तो वह 'रात्र' में बदल जाता है (नवरात्र, अहोरात्र, द्विरात्र)। 'नवरात्रि' लोक-प्रचलित अशुद्ध रूप है।
सन्धि सूत्र मिष्ठान्न (मिष्ट + अन्न), संन्यासी (बिंदी + आधा न), अनधिकार (अन् + अधिकार), दुरवस्था (दुर् + अवस्था)।
समास सूत्र नवरात्र, अहोरात्र (रात्रि नहीं, रात्र शुद्ध है)।

संधि व उपसर्ग जनित वर्तनी अशुद्धियों का वर्गीकरण चार्ट

संधि का प्रकार परीक्षार्थी की सामान्य भूल (अशुद्ध) शुद्ध प्रामाणिक रूप संधि विच्छेद एवं सूत्र
दीर्घ स्वर संधिरविन्द्र / मुनिन्द्ररवीन्द्र / मुनीन्द्ररवि + इन्द्र = रवीन्द्र (इ + इ = ई)
दीर्घ स्वर संधिभानुदय / विधुदयभानूदय / विधूदयभानु + उदय = भानूदय (उ + उ = ऊ)
दीर्घ स्वर संधिलघुत्तर / वधुत्सवलघूत्तर / वधूत्सवलघु + उत्तर = लघूत्तर, वधू + उत्सव = वधूत्सव
यण् स्वर संधिअत्याधिक / यद्यापिअत्यधिक / यद्यपिअति + अधिक = अत्यधिक (इ का य्, अ मिलकर य)
यण् स्वर संधिगत्यानुसार / रीत्यानुसारगत्यनुसार / रीत्यनुसारगति + अनुसार = गत्यनुसार (आ नहीं बनेगा)
यण् स्वर संधिप्रत्यूष / प्रत्यूत्तरप्रत्युत्तर / प्रत्यूषप्रति + उत्तर = प्रत्युत्तर (ह्रस्व उ), प्रति + ऊष = प्रत्यूष
गुण स्वर संधिमहार्षि / सप्तार्षिमहर्षि / सप्तर्षिमहा + ऋषि = महर्षि (आ + ऋ = अर्)
वृद्धि स्वर संधिएकैक / एकएकएकैकएक + एक = एकैक (अ + ए = ऐ)
व्यंजन संधि (श्चुत्व)उज्वल / समुज्वलउज्ज्वल / समुज्ज्वलउत् + ज्वल = उज्ज्वल (दो बार आधा ज)
व्यंजन संधि (छ-नियम)उछ्वास / विछेदउच्छ्वास / विच्छेदउत् + श्वास = उच्छ्वास, वि + छेद = विच्छेद (च् का आगम)
व्यंजन संधि (पंचम वर्ण)वांग्मय / दिगंगजवाङ्मय / दिग्गजवाक् + मय = वाङ्मय (क् का ङ् में परिवर्तन)
व्यंजन संधि (त-नियम)तडित्ज्योति / शरद्चन्द्रतड़िज्ज्योति / शरच्चंद्रतड़ित् + ज्योति = तड़िज्ज्योति, शरत् + चंद्र = शरच्चंद्र
विसर्ग संधि (ओ-कार)मनोरथ / यशोदामनोरथ / यशोदामनः + रथ = मनोरथ, यशः + दा = यशोदा (घोष वर्ण परे)
विसर्ग संधि (यथावत)मनोकामना / अधोपतनमनःकामना / अधःपतनक, ख, प, फ परे होने पर विसर्ग सुरक्षित रहता है।
विसर्ग संधि (ष्-कार)दुष्कर / निष्फलदुष्कर / निष्फलदुः + कर = दुष्कर, निः + फल = निष्फल (इ/उ उपधा विसर्ग)

सामान्य भ्रांतियां एवं आयोग के ट्रैप्स (Common Pitfalls)

  • सजातीयता का उल्लंघन कदापि न करें (तत्सम का विलोम तत्सम, तद्भव का तद्भव)।
  • विकल्पों में मिलते-जुलते भ्रामक वर्तनी वाले शब्दों से सतर्क रहें।

60/60 शत-प्रतिशत स्कोर सूत्र

सामान्य हिन्दी में 60 में से 55+ अंक प्राप्त करना ही समीक्षा अधिकारी अंतिम चयन की गारंटी है। प्रतिदिन 30 मिनट नियम स्मरण एवं 20 प्रश्नों का अभ्यास अनिवार्य रूप से करें।
