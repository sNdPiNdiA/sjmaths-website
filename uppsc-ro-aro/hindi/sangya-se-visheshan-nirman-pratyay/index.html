संज्ञा से विशेषण निर्माण: प्रत्यय विज्ञान एवं आदि-स्वर वृद्धि नियम

संज्ञा पदों में तद्धित प्रत्ययों का योग करके विशेषण बनाने की प्रक्रिया हिन्दी व्याकरण का अत्यंत समृद्ध खंड है। इसमें सबसे महत्वपूर्ण एवं जटिल नियम 'इक' प्रत्यय का आदि-स्वर वृद्धि नियम है, जिससे UPPSC RO/ARO में प्रतिवर्ष 2-3 प्रश्न सीधे पूछे जाते हैं:

'इक' प्रत्यय का अचूक आदि-स्वर वृद्धि नियम (Vowel Lengthening):
जब किसी शब्द में 'इक' प्रत्यय जुड़ता है, तो शब्द के प्रथम स्वर (Initial Vowel) में निम्नानुसार अनिवार्य वृद्धि होती है:
1. अ / आ -> आ (उदा. धर्म -> धार्मिक, समाज -> सामाजिक, प्रमाण -> प्रामाणिक)
2. इ / ई / ए -> ऐ (उदा. इतिहास -> ऐतिहासिक, दिन -> दैनिक, वेद -> वैदिक, देव -> दैविक)
3. उ / ऊ / ओ -> औ (उदा. भूगोल -> भौगोलिक, उद्योग -> औद्योगिक, उपन्यास -> औपन्यासिक)
4. ऋ -> आर् (उदा. ऋषि -> आर्ष, गृह -> गार्हस्थ/गार्हस्थ्य)।

'इक' प्रत्यय से निर्मित 25 उच्च-आवृत्ति प्रामाणिक शब्द

प्रत्यय विज्ञान: UPPSC RO/ARO वर्तनी ट्रैप्स

1. 'प्रमाणिक' अशुद्ध है: 'प्रमाण + इक' से आदि-स्वर वृद्धि होकर प्रामाणिक बनता है (प्रमाणिक वर्तनी अशुद्ध है)।

2. 'व्यवसायिक' अशुद्ध है: 'व्यवसाय + इक' से व्यावसायिक बनता है।

3. 'ऐतिहासिक' vs 'इतिहासिक': 'इतिहास + इक' से ऐतिहासिक शुद्ध है, 'इतिहासिक' अशुद्ध है।

4. 'औपन्यासिक' vs 'उपन्यासिक': 'उपन्यास + इक' से औपन्यासिक शुद्ध रूप है।

3-स्तरीय ऑनलाइन मिनी टेस्ट (कठिनाई स्तर 1, 2 व 3 — 1/3 नकारात्मक अंकन)

UPPSC RO/ARO मुख्य परीक्षा (Mains Format) — प्रारूप एवं आदर्श उत्तर

मुख्य परीक्षा प्रश्नपत्र-2 (सामान्य हिन्दी एवं आलेखन) तथा प्रश्नपत्र-1 (वस्तुनिष्ठ) के मानक अनुरूप मॉडल प्रश्न व उत्तर:

UPPSC RO/ARO मुख्य परीक्षा प्रारूप 5 अंक
1. 'इक' प्रत्यय जोड़ने पर होने वाले 'आदि-स्वर वृद्धि' नियम को स्पष्ट करते हुए 5 उदाहरण दीजिए।
आदर्श उत्तर (Examiner Standard)

नियम: जब किसी संज्ञा शब्द में 'इक' प्रत्यय जुड़ता है, तो शब्द के प्रथम स्वर (आदि-स्वर) में निम्नलिखित वृद्धि होती है—

  • अ -> आ: समाज -> सामाजिक; अर्थ -> आर्थिक
  • इ / ई / ए -> ऐ: इतिहास -> ऐतिहासिक; नीति -> नैतिक; वेद -> वैदिक
  • उ / ऊ / ओ -> औ: भूगोल -> भौगोलिक; भूत -> भौतिक; लोक -> लौकिक
  • ऋ -> आर्: हृदय -> हार्दिक; प्रकृति -> प्राकृतिक

परीक्षा कक्ष त्वरित रिवीज़न — मुख्य बिंदु एवं ट्रैप्स (Exam Traps)

महत्वपूर्ण परीक्षा बिंदु (Must-Remember Points)

  • इतिहास -> ऐतिहासिक; भूगोल -> भौगोलिक; समाज -> सामाजिक।
  • ऋषि -> आर्ष; चक्षु -> चाक्षुष; निशा -> नैश।
  • उत्कर्ष -> उत्कृष्ट; आलस्य -> आलसी; हृदय -> हार्दिक।
  • -इक प्रत्यय से आदि-स्वर वृद्धि होती है (अ->आ, इ->ऐ, उ->औ, ऋ->आर्)।

सामान्य भ्रांतियां एवं आयोग के ट्रैप्स (Common Pitfalls)

  • ऋषि का विशेषण "आर्ष" होता है, इसे रट लें (UPPSC का क्लासिक ट्रैप)।
  • निशा का विशेषण "नैश" होता है, "निशीथ" नहीं (निशीथ आधी रात की संज्ञा है)।
