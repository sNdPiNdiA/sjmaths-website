Official Bluebook Grid-In Rules

Rule 1 Official Bluebook Rule

No Mixed Numbers

Mixed numbers are interpreted as multiplication by the scoring system.

✓ DO THIS:
Convert to an improper fraction (e.g., 7/2) or a decimal (e.g., 3.5).
✗ NEVER DO THIS:
Never enter a mixed number like 3 1/2, as it is read as 31/2.
Example: For 3 1/2, enter 3.5 or 7/2.
Rule 2 Official Bluebook Rule

Fractional Precision

Fractions do not need to be simplified, but they must fit within the character limit.

✓ DO THIS:
Enter the fraction as is, provided it fits in the 6-character limit.
✗ NEVER DO THIS:
Do not round fractions unless the question explicitly asks for a decimal approximation.
Example: If the answer is 4/12, 4/12 is accepted, as is 1/3.
Rule 3 Official Bluebook Rule

Decimal Truncation

If a decimal does not terminate, you must fill all available grid spaces.

✓ DO THIS:
Use as many digits as the grid allows (e.g., .666 or .667).
✗ NEVER DO THIS:
Do not round prematurely or truncate to fewer digits than the space allows.
Example: For 2/3, enter .666 or .667.
Rule 4 Official Bluebook Rule

Negative Signs

Negative values must include the negative sign.

✓ DO THIS:
Place the negative sign in the first available box.
✗ NEVER DO THIS:
Do not omit the negative sign or use parentheses.
Example: For -5, enter -5.

Common Grid-In Traps That Cost Points

⚠️ Trap #1: Premature Rounding

Calculating a multi-step problem where the intermediate result is 1/3.

✗ Flawed Input: .3 (0 Points)
✓ Correct Input: .333 (1 Point)
Explanation: Rounding to one decimal place introduces significant error; always use at least three decimal places.
⚠️ Trap #2: Trailing Zeros

An answer of 5.00.

✗ Flawed Input: 5.00 (0 Points)
✓ Correct Input: 5 (1 Point)
Explanation: While 5.00 is technically correct, it wastes space; 5 is the most efficient input.
⚠️ Trap #3: Multiple Answers

An equation with two solutions, e.g., x = 3 or x = -3.

✗ Flawed Input: 3, -3 (0 Points)
✓ Correct Input: 3 (1 Point)
Explanation: The system only accepts one numerical value; providing a list will result in an error.
⚠️ Trap #4: Percentage Conversion

The question asks for a value as a percentage.

✗ Flawed Input: 50% (0 Points)
✓ Correct Input: .5 (1 Point)
Explanation: The grid does not accept the percent symbol; convert percentages to decimals or fractions.
⚠️ Trap #5: Character Limit

An answer like 12345/6.

✗ Flawed Input: 12345/6 (0 Points)
✓ Correct Input: 2057.5 (1 Point)
Explanation: The grid has a maximum of 6 characters; if a fraction exceeds this, convert to a decimal.
