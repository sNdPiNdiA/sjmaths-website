Official Bluebook Grid-In Rules

Rule 1 Official Bluebook Rule

No Mixed Numbers Allowed

The grid-in system cannot interpret mixed numbers; it will read them as multiplication.

✓ DO THIS:
Convert to an improper fraction (e.g., 7/2) or a decimal (e.g., 3.5).
✗ NEVER DO THIS:
Never type 3 1/2, as the system interprets this as 31/2.
Example: If the answer is 2 and 1/3, enter 7/3 or 2.333.
Rule 2 Official Bluebook Rule

Repeating Decimals & Truncation

If a decimal repeats, you must fill as many grid spaces as possible.

✓ DO THIS:
Enter .666 or .667 for 2/3.
✗ NEVER DO THIS:
Never round prematurely or truncate to only one decimal place.
Example: For 1/3, enter .333.
Rule 3 Official Bluebook Rule

Equivalent Fractions

Any mathematically equivalent fraction is accepted.

✓ DO THIS:
Enter 2/4, 4/8, or 1/2.
✗ NEVER DO THIS:
Do not worry about simplifying fractions unless the prompt specifies.
Example: If the answer is 0.5, 1/2 is perfectly acceptable.
Rule 4 Official Bluebook Rule

Negative Signs

Negative signs must be placed in the first available column.

✓ DO THIS:
Type -1/2 or -.5.
✗ NEVER DO THIS:
Do not place the negative sign in the middle or end of the entry.
Example: For -0.75, enter -.75.

Common Grid-In Traps That Cost Points

⚠️ Trap #1: Premature Rounding

Calculating a multi-step problem where the result is 1/7.

✗ Flawed Input: .14 (0 Points)
✓ Correct Input: .142 (1 Point)
Explanation: Rounding to two decimal places is insufficient for precision; use at least three digits.
⚠️ Trap #2: Trailing Zeros

The answer is 0.50.

✗ Flawed Input: 0.50 (0 Points)
✓ Correct Input: .5 (1 Point)
Explanation: While 0.50 is technically correct, it is safer to use the simplest form to avoid grid space limitations.
⚠️ Trap #3: Improper Fraction vs Decimal

The answer is 11/3.

✗ Flawed Input: 3.66 (0 Points)
✓ Correct Input: 11/3 (1 Point)
Explanation: If the decimal is non-terminating, the fraction is always the safest and most accurate input.
⚠️ Trap #4: Leading Zeros

The answer is 0.75.

✗ Flawed Input: 0.75 (0 Points)
✓ Correct Input: .75 (1 Point)
Explanation: Both are accepted, but omitting the leading zero saves grid space.
⚠️ Trap #5: Misinterpreting Division

Solving for x in 3x = 5.

✗ Flawed Input: 3/5 (0 Points)
✓ Correct Input: 5/3 (1 Point)
Explanation: Students often flip the fraction; ensure the numerator and denominator are correctly placed.

Interactive Grid-In Practice Simulator (5 Questions)

Grid-In Question #1 Easy

If $\frac{2}{3}x = 10$, what is the value of $x$?

Digital SAT Grid-In Simulator
Official Bluebook rules apply: integers, terminating or rounded decimals, and improper fractions accepted. No mixed numbers.
Hint: Multiply both sides by the reciprocal of 2/3.

Official Step-by-Step Solution

Step 1
Multiply both sides by 3/2.
Step 2
x = 10 * (3/2).
Step 3
x = 30/2 = 15.

Digital SAT Grid-In Simulator

Grid-In Question #3 Hard

If $\frac{x}{y} = \frac{3}{4}$ and $x+y = 21$, what is the value of $y$?

Digital SAT Grid-In Simulator
Official Bluebook rules apply: integers, terminating or rounded decimals, and improper fractions accepted. No mixed numbers.
Hint: Use substitution: x = 3/4y.

Official Step-by-Step Solution

Step 1
Substitute x = 0.75y into x+y=21.
Step 2
0.75y + y = 21.
Step 3
1.75y = 21.
Step 4
y = 21 / 1.75 = 12.
Grid-In Question #4 Medium

Digital SAT Grid-In Simulator
Official Bluebook rules apply: integers, terminating or rounded decimals, and improper fractions accepted. No mixed numbers.
Hint: Multiply by the reciprocal of the divisor.

Official Step-by-Step Solution

Step 1
Change to 5/6 * 3/2.
Step 2
Multiply numerators: 5 * 3 = 15.
Step 3
Multiply denominators: 6 * 2 = 12.
Step 4
Simplify 15/12 to 5/4.
