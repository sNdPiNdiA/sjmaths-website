Official Bluebook Grid-In Rules

Rule 1 Official Bluebook Rule

No Mixed Numbers

The grid-in interface does not support mixed numbers. Entering a space between an integer and a fraction will be interpreted as multiplication.

✓ DO THIS:
Convert to an improper fraction (e.g., 7/2) or a decimal (e.g., 3.5).
✗ NEVER DO THIS:
Never enter 3 1/2, as the system reads it as 31/2.
Example: For 3 1/2, enter 3.5 or 7/2.
Rule 2 Official Bluebook Rule

Repeating Decimals

If a decimal repeats, you must fill the entire grid or provide a rounded/truncated value that fits within the 4-character limit.

✓ DO THIS:
Use the fraction form (e.g., 1/3) to ensure absolute precision.
✗ NEVER DO THIS:
Never provide a truncated decimal that is not equivalent to the exact value if the grid space is insufficient.
Example: For 0.333..., enter 1/3.
Rule 3 Official Bluebook Rule

Decimal Precision

You must use all available grid spaces if the decimal is long, or provide an equivalent fraction.

✓ DO THIS:
If the answer is 0.125, enter 0.125. If it is 0.12345, enter 0.123 or 0.124.
✗ NEVER DO THIS:
Do not round prematurely; use the fraction if the decimal exceeds 4 characters.
Example: For 0.6666..., enter 2/3.
Rule 4 Official Bluebook Rule

Leading and Trailing Zeros

Leading zeros are optional, but trailing zeros are unnecessary.

✓ DO THIS:
Enter .5 or 0.5; both are accepted.
✗ NEVER DO THIS:
Do not add unnecessary trailing zeros that exceed the grid length.
Example: 0.5 is the same as .5.

Common Grid-In Traps That Cost Points

⚠️ Trap #1: Premature Rounding

Calculating a value like 1/3 + 1/3 + 1/3.

✗ Flawed Input: 0.33 (0 Points)
✓ Correct Input: 1 (1 Point)
Explanation: Rounding 1/3 to 0.33 results in 0.99, which is incorrect. Always keep fractions until the final step.
⚠️ Trap #2: Negative Sign Placement

Entering a negative result.

✗ Flawed Input: 5- (0 Points)
✓ Correct Input: -5 (1 Point)
Explanation: The negative sign must be placed in the first available column.
⚠️ Trap #3: Fractional Overflow

Entering a fraction that is too long for the grid.

✗ Flawed Input: 1234/5678 (0 Points)
✓ Correct Input: 0.217 (1 Point)
Explanation: If the fraction exceeds the character limit, convert it to a decimal and round/truncate to fit.
⚠️ Trap #4: Misinterpreting Repeating Decimals

The answer is 0.1666...

✗ Flawed Input: 0.16 (0 Points)
✓ Correct Input: 1/6 (1 Point)
Explanation: 0.16 is not equal to 0.1666...; the system will mark it wrong. Use the fraction.
⚠️ Trap #5: Decimal Point Misplacement

Entering 1.25 as 12.5.

✗ Flawed Input: 12.5 (0 Points)
✓ Correct Input: 1.25 (1 Point)
Explanation: The grid-in system is sensitive to decimal placement; check your magnitude.

Interactive Grid-In Practice Simulator (3 Questions)

Grid-In Question #1 Easy

If $x = 0.75$, what is the value of $4x$?

Digital SAT Grid-In Simulator
Official Bluebook rules apply: integers, terminating or rounded decimals, and improper fractions accepted. No mixed numbers.
Hint: Multiply 0.75 by 4 directly.

Official Step-by-Step Solution

Step 1
0.75 is equal to 3/4.
Step 2
4 * (3/4) = 3.
Grid-In Question #2 Medium

What is the value of $\frac{1}{8} + 0.125$?

Digital SAT Grid-In Simulator
Official Bluebook rules apply: integers, terminating or rounded decimals, and improper fractions accepted. No mixed numbers.
Hint: Convert the fraction to a decimal first.

Official Step-by-Step Solution

Step 1
1/8 = 0.125.
Step 2
0.125 + 0.125 = 0.25.
Grid-In Question #3 Hard

If $3y = 0.5$, what is the value of $y$?

Digital SAT Grid-In Simulator
Official Bluebook rules apply: integers, terminating or rounded decimals, and improper fractions accepted. No mixed numbers.
Hint: Divide 0.5 by 3. Since it repeats, use a fraction.

Official Step-by-Step Solution

Step 1
y = 0.5 / 3.
Step 2
y = (1/2) / 3 = 1/6.
