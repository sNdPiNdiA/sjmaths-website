Question 1 · Algebra Easy

If $7x - 4 = 3x + 52$, what is the value of $x$?

Grid-In Simulator
Rules: Integers, decimals, or fractions allowed. No spaces.
Hint: Subtract $3x$ from both sides, then add 4.

Step-by-Step Solution

Step 1
$7x - 3x = 52 + 4 \implies 4x = 56$.
Step 2
$x = 56 / 4 = 14$. Answer is 14.

Question 3 · Advanced Math Medium

If $x^2 + 14x + c = (x + d)^2$ for all real values of $x$, where $c$ and $d$ are positive constants, what is the value of $c$?

Grid-In Simulator
Hint: Complete the square: $(x + d)^2 = x^2 + 2dx + d^2$. Match coefficients.

Step-by-Step Solution

Step 1
$2d = 14 \implies d = 7$.
Step 2
$c = d^2 = 7^2 = 49$. Answer is 49.
Question 4 · Data Analysis Medium

In a group of 60 participants, 45% are enrolled in biology. How many participants are NOT enrolled in biology?

Grid-In Simulator
Hint: If 45% are enrolled, $100\% - 45\% = 55\%$ are not enrolled.

Step-by-Step Solution

Step 1
Percentage not enrolled: $55\% = 0.55$.
Step 2
Count: $60 \times 0.55 = 33$. Answer is 33.
Question 5 · Geometry & Trig Hard

A right cylinder has radius 3 and height 8. A second similar cylinder has radius 9. What is the height of the second cylinder?

Grid-In Simulator
Hint: For similar figures, all linear dimensions scale by the same factor $k = \frac{r_2}{r_1}$.

Step-by-Step Solution

Step 1
Linear scale factor: $k = 9 / 3 = 3$.
Step 2
New height: $h_2 = 8 \times 3 = 24$. Answer is 24.
