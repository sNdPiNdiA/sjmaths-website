Desmos Syntax & Core Techniques

Exponential Regression for Data Points

When the problem provides a table of (x, y) values and asks for the function equation.
y1 ~ a * b^x1

Use the tilde (~) operator to find the base and initial value of an exponential function when given a table of values.

💡 Pro-Tip: Always check the 'r^2' value; if it's 1, your model is perfect.

Slider-Based Parameter Matching

When you have two points and need to find the specific exponential equation.
f(x) = a * b^x

Define a function with variables 'a' and 'b', then click 'add all sliders' to adjust them until the graph passes through given points.

💡 Pro-Tip: Use the 'step' feature on sliders to quickly snap to integer values.

Intersection of Two Functions

When solving for the value of x where two exponential growth/decay models meet.
y = f(x) and y = g(x)

Graph both equations and click the gray dot at the intersection point to find the solution.

💡 Pro-Tip: If the intersection is off-screen, use the wrench icon to adjust the window.

Evaluating Functions at Specific Inputs

When asked for the value of a population or amount after a specific time t.
f(x) = ... then type f(number)

Define the function once, then type 'f(5)' to instantly evaluate the function at x=5.

💡 Pro-Tip: Use function notation f(x) instead of y= to keep your workspace organized.

Vertical/Horizontal Asymptote Visualization

When asked for the range of an exponential function or the long-term behavior.
y = a * b^x + k

The constant 'k' represents the horizontal asymptote. Graphing it helps visualize the limit of the function.

💡 Pro-Tip: Type 'y = k' as a dashed line to clearly see the boundary.

Speed Walkthroughs: 15s Desmos Hack vs 2-Min Algebra

Walkthrough #1 ⚡ 70s Saved (10s vs 80s)

The population of a bacteria colony doubles every 3 hours. If the initial population is 50, which function models the population $P$ after $t$ hours?

⏳ Traditional 2-Minute Method
Step 1
Identify formula P(t) = a(b)^(t/d)
Step 2
Plug in a=50, b=2, d=3
Step 3
Write P(t) = 50(2)^(t/3)
⚡ Desmos 15-Second Hack
Step 1
Type 'y = 50 * 2^(x/3)'
Step 2
Check the y-intercept at (0, 50)
Step 3
Check the point (3, 100) to confirm doubling
Target Answer: P(t) = 50(2)^(t/3)
