Desmos Syntax & Core Techniques

Interactive Sliders for Unknown Constants

When a problem asks for a constant that makes a parabola pass through specific points or have a specific vertex.
y = ax^2 + bx + c

Define an equation with variables like 'a', 'b', or 'k'. Desmos will create 'add slider' buttons. Adjust sliders to match the graph to given points or conditions.

💡 Pro-Tip: Click the slider value to type exact numbers for precision.

Regression Formula for Best Fit

When given a table of (x, y) values and asked for the quadratic model.
y1 ~ ax1^2 + bx1 + c

Input a table of values and use the tilde (~) operator to find the quadratic equation that fits the data perfectly.

💡 Pro-Tip: Use the 'residuals' plot to verify if the fit is perfect (residuals should be 0).

Finding Intersections with Clickable Points

Solving systems of equations involving a parabola and a line.
y = [Equation 1], y = [Equation 2]

Graph both equations; Desmos automatically highlights intersection points in grey. Click them to see coordinates.

💡 Pro-Tip: If points don't appear, zoom out or check if the equations are entered correctly.

Vertex and Intercept Identification

Questions asking for the maximum/minimum value, zeros, or roots.
y = ax^2 + bx + c

Graph the function; click the graph to see the grey dots representing the vertex and x-intercepts.

💡 Pro-Tip: The y-intercept is always (0, c).

Evaluating Expressions with Variables

When asked to find the value of a quadratic expression for a specific input.
f(x) = ax^2 + bx + c, f(n)

Define the function using f(x), then type f(n) to evaluate the quadratic at any value n.

💡 Pro-Tip: Use this to quickly check if an answer choice matches the function value.

Speed Walkthroughs: 15s Desmos Hack vs 2-Min Algebra

Walkthrough #1 ⚡ 45s Saved (10s vs 55s)

The function $f(x) = x^2 - 6x + 8$ is graphed in the $xy$-plane. What is the $x$-coordinate of the vertex?

⏳ Traditional 2-Minute Method
Step 1
Use the formula x = -b / (2a).
Step 2
Identify a=1, b=-6.
Step 3
Calculate x = -(-6) / (2*1) = 3.
⚡ Desmos 15-Second Hack
Step 1
Type 'y = x^2 - 6x + 8'.
Step 2
Click the grey dot at the bottom of the parabola.
Step 3
Read the x-coordinate from the coordinate pair.
Target Answer: 3

Targeted Calculator Drills (2 Questions)

Drill #1 ⚡ Calculator Drill

Which of the following is equivalent to $2x^2 + 8x + 6$?

Desmos Entry: y = 2x^2 + 8x + 6, y = 2(x+1)(x+3)

Desmos Walkthrough & Verification

Step 1
Graph the original expression.
Step 2
Graph each option one by one.
Step 3
The option that perfectly overlaps the original graph is the equivalent expression.

Desmos Walkthrough & Verification

Step 2

Step 3
Identify the positive value among the intercepts.
