Desmos Syntax & Core Techniques

Variable Substitution with Sliders

When a problem provides specific values for variables and asks for the result of an expression.
a = 5, b = 3, a + b

Define variables as constants to evaluate complex expressions instantly without manual arithmetic.

💡 Pro-Tip: Type the expression exactly as it appears in the prompt; Desmos will output the value immediately.

Intersection Point Finder

Systems of equations or finding where two lines/curves meet.
y = f(x), y = g(x)

Graph two functions and click the point where they cross to find the solution (x, y).

💡 Pro-Tip: Click the grey dot that appears at the intersection to see the coordinates.

Table-Based Regression

Linear modeling or finding the equation of a line given two or more points.
y1 ~ mx1 + b

Input data points into a table and use the tilde (~) operator to find the line of best fit.

💡 Pro-Tip: Use the 'y1' and 'x1' syntax exactly as shown in the table headers.

Solving Equations via X-Intercepts

Any equation where you need to find the value of x.
f(x) - g(x) = 0

Set an equation to zero and find the x-intercepts to solve for x.

💡 Pro-Tip: If the equation is complex, move everything to one side so it equals zero, then graph.

Evaluating Functions at Points

Function notation problems (e.g., find f(3)).
f(x) = 2x + 3, f(5)

Define a function using f(x) notation, then type f(number) to evaluate.

💡 Pro-Tip: You can define multiple functions like f(x) and g(x) and perform operations like f(x) + g(x).

Speed Walkthroughs: 15s Desmos Hack vs 2-Min Algebra

Walkthrough #1 ⚡ 45s Saved (5s vs 50s)

If $3x + 4 = 19$, what is the value of $x$?

⏳ Traditional 2-Minute Method
Step 1
Subtract 4 from both sides: 3x = 15
Step 2
Divide by 3: x = 5
⚡ Desmos 15-Second Hack
Step 1
Type '3x + 4 = 19' into the expression bar
Step 2
Click the vertical line that appears at x = 5
Target Answer: 5
