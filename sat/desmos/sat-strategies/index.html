Desmos Syntax & Core Techniques

Regression Formula for Coefficients

When given a table of values and asked to find a specific constant or the value of a function at a point.
y1 ~ ax1^2 + bx1 + c

Use the tilde (~) operator to force Desmos to find the best-fit parameters for any function type. Perfect for finding constants in quadratic or exponential models.

💡 Pro-Tip: Always check the R^2 value; if it is 1, your model is a perfect fit.

Interactive Sliders for Unknowns

When solving for a constant that makes two lines intersect at a specific point or satisfy a condition.
y = ax + b

Type an equation with variables like 'a' or 'k' and click 'add slider'. Adjust the slider until the graph matches given constraints.

💡 Pro-Tip: Click the slider value to manually type in precise numbers.

Intersection Point Finder

Any equation with one variable (e.g., 3(x-2) = 5x + 1).
f(x) = g(x)

Graph both sides of an equation as separate functions. Click the point where the lines cross to see the solution.

💡 Pro-Tip: If the lines are parallel, the intersection is undefined; if they overlap, there are infinite solutions.

Evaluating Functions at Points

When asked to evaluate complex expressions or find the value of a function at a specific input.
f(x) = ... then f(5)

Define a function f(x) and then type f(number) in a new line to get the output instantly.

💡 Pro-Tip: Use this to check answer choices by plugging them into the function.

System of Inequalities Shading

When asked which point (x, y) is a solution to a system of inequalities.
y > 2x + 1 {x > 0}

Graph inequalities and look for the overlapping shaded region. Use curly brackets {} to restrict domains.

💡 Pro-Tip: Type the point as (x, y) in a new line to see if it lands in the shaded region.
