Desmos Syntax & Core Techniques

Direct Inequality Plotting

When asked to identify a graph or determine if a point (x, y) is a solution.
y > ax + b

Type the inequality exactly as it appears in the question. Desmos automatically shades the solution region.

💡 Pro-Tip: Use the keypad to toggle between dashed and solid lines if the inequality is strict (<, >) vs inclusive (≤, ≥).

Testing Points in Regions

When asked 'Which of the following points is a solution to the system?'
(x_1, y_1)

Convert answer choices into coordinate points and plot them. See if they land in the shaded region.

💡 Pro-Tip: Use a table for multiple points to see them all at once.

Slider Constants for Unknowns

When the question asks for the value of a constant that satisfies a specific condition (e.g., 'no solution').
y < ax + k

If an inequality contains a variable constant (e.g., 'k'), type it into Desmos. Desmos will offer to add a slider for 'k'.

💡 Pro-Tip: Adjust the slider range to match the answer choices provided.

Intersection of Systems

When finding the feasible region of a system of linear inequalities.
y > f(x) {y < g(x)}

Use curly brackets to restrict domains or find the overlap of two inequalities.

💡 Pro-Tip: The darkest shaded region is the intersection of all inequalities.

Regression for Boundary Lines

When given data points and asked to find the inequality that describes the relationship.
y1 ~ mx1 + b

If given a table of values, use regression to find the boundary line equation.

💡 Pro-Tip: Check the R-squared value to ensure the fit is perfect.

Speed Walkthroughs: 15s Desmos Hack vs 2-Min Algebra

Walkthrough #1 ⚡ 70s Saved (20s vs 90s)

Which of the following points $(x, y)$ is a solution to the system of inequalities: $y > 2x + 1$ and $y < -x + 4$?

⏳ Traditional 2-Minute Method
Step 1
Substitute each point into both inequalities.
Step 2
Check if the first inequality holds true.
Step 3
Check if the second inequality holds true.
Step 4
Repeat until a point satisfies both.
⚡ Desmos 15-Second Hack
Step 1
Type 'y > 2x + 1' and 'y < -x + 4'.
Step 2
Plot the points provided in the answer choices as (x, y).
Step 3
Identify which point lies in the overlapping shaded region.
Target Answer: The point in the overlapping region.

Drill #1 ⚡ Calculator Drill

Which point $(x, y)$ is a solution to $y \leq 3x - 2$ and $y > -x + 1$?

Desmos Entry: y <= 3x - 2; y > -x + 1; (0,0), (2,2), (1,2), (3,0)

Desmos Walkthrough & Verification

Step 1
Enter both inequalities into Desmos.
Step 2
Plot the four points.
Step 3
Observe which point falls in the shaded overlap.
Drill #2 (SPR) ⚡ Calculator Drill

What is the largest integer $x$ such that $2x + 5 < 18$?

Desmos Calculator Grid-In
Desmos Entry: y = 2x + 5; y = 18

Desmos Walkthrough & Verification

Step 1
Graph the lines y = 2x + 5 and y = 18.
Step 2
Find the intersection point (6.5, 18).
Step 3
Since x must be less than 6.5, the largest integer is 6.
