Desmos Syntax & Core Techniques

Interactive Sliders for Unknown Constants

When a problem asks for a constant that makes a line pass through specific coordinates.
y = ax + b

Define equations with variables like 'a' or 'b' instead of numbers. Desmos automatically creates sliders, allowing you to manipulate the graph until it passes through given points.

💡 Pro-Tip: Click the slider value to manually type in specific numbers for faster precision.

Regression Formula for Best Fit

When given a table of values and asked for the linear equation or a value at a specific x.
y1 ~ mx1 + b

Input data points into a table and use the tilde (~) operator to find the slope (m) and y-intercept (b) instantly.

💡 Pro-Tip: Use the 'plot' button on the table to visualize the points before running the regression.

Intersection Point Analysis

Systems of linear equations questions.
y = [Eq1], y = [Eq2]

Graph two linear equations and click the intersection point to reveal the (x, y) solution.

💡 Pro-Tip: If lines are parallel, Desmos will show no intersection; if they are the same line, it will show an infinite number of points.

Solving for x in Linear Equations

Complex linear equations with fractions or parentheses.
y = [Left Side], y = [Right Side]

Set the left side of the equation as one line and the right side as another. The x-coordinate of the intersection is your solution.

💡 Pro-Tip: If the lines don't appear, zoom out or click the 'home' icon to reset the view.

Evaluating Functions at Specific Values

When asked to find f(x) for a given x.
f(x) = [Expression], f(number)

Define the function and simply type f(number) in a new line to get the output.

💡 Pro-Tip: Use this to check your work on word problems involving linear growth.

Speed Walkthroughs: 15s Desmos Hack vs 2-Min Algebra

Walkthrough #1 ⚡ 70s Saved (20s vs 90s)

If $3x + 4y = 12$ and $2x - y = 5$, what is the value of $x + y$?

⏳ Traditional 2-Minute Method
Step 1
Multiply second equation by 4: 8x - 4y = 20
Step 2
Add to first equation: 11x = 32
Step 3
x = 32/11
Step 4
Substitute back to find y
Step 5
Add x and y
⚡ Desmos 15-Second Hack
Step 1
Type '3x + 4y = 12' in row 1
Step 2
Type '2x - y = 5' in row 2
Step 3
Click the intersection point (2.909, 0.818)
Step 4
Add the coordinates: 2.909 + 0.818 = 3.727
Target Answer: 41/11
