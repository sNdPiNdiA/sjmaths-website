Desmos Syntax & Core Techniques

Table Regression for Linear/Exponential Models

When given a set of data points and asked to predict a value or find the equation of the model.
y1 ~ mx1 + b or y1 ~ ab^x1

Input data points into a table and use the tilde (~) operator to force Desmos to find the line of best fit or exponential curve.

💡 Pro-Tip: Always check the R^2 value; if it is 1, the model is a perfect fit.

Mean and Median Calculation

When asked to compare means/medians of two datasets or calculate the effect of adding a new data point.
mean(L) or median(L)

Define a list L = [x1, x2, ...] and use built-in functions to find central tendency instantly.

💡 Pro-Tip: Use the 'stats' menu in the keypad to quickly insert these functions.

Standard Deviation and Range

When questions ask about the impact of outliers on standard deviation or range.
stdev(L) or max(L) - min(L)

Calculates the spread of data instantly without manual formula application.

💡 Pro-Tip: Remember that adding a constant to every value in a set does not change the standard deviation.

Scatter Plot Visualization

When asked to describe the relationship between two variables (positive, negative, or no correlation).
(x1, y1)

Plotting points directly to visualize trends, outliers, or correlation direction.

💡 Pro-Tip: Click the wrench icon to adjust the axes if your points are not visible.

Weighted Average Calculation

When given a frequency table and asked for the mean value.
total(L1 * L2) / total(L2)

Use list multiplication to find weighted averages for frequency tables.

💡 Pro-Tip: Define L1 as the values and L2 as the frequencies.

Speed Walkthroughs: 15s Desmos Hack vs 2-Min Algebra

Walkthrough #1 ⚡ 45s Saved (10s vs 55s)

The table shows the number of hours 5 students studied. What is the mean number of hours studied? Data: {2, 4, 5, 7, 12}

⏳ Traditional 2-Minute Method
Step 1
Add all numbers: 2+4+5+7+12 = 30
Step 2
Divide by count: 30 / 5 = 6
⚡ Desmos 15-Second Hack
Step 1
Type 'mean([2, 4, 5, 7, 12])'
Target Answer: 6

Desmos Walkthrough & Verification

Step 2
Calculate stdev.
Step 3

Step 4
Observe that the value remains unchanged.
