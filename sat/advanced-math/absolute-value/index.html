Key Concepts & Worked Archetypes

Concept 1

Concept 1: Definition & Key Properties

The absolute value $|x|$ represents the distance of a number from zero on a number line, ensuring the result is always non-negative.

  • If $|x| = a$ (where $a > 0$), then $x = a$ or $x = -a$.
  • If $|x| = 0$, then $x = 0$.
  • If $|x| = a$ (where $a < 0$), there is no real solution.
📘 Traditional Algebraic Method

Isolate the absolute value expression, split into two separate linear equations, solve both, and verify for extraneous solutions.

⚡ SAT Speed Trick & Desmos Hack

Graph the left side as $y_1$ and the right side as $y_2$ in Desmos. The x-coordinates of the intersection points are your solutions.

💡 Worked SAT Archetype Example

Problem: What is the sum of all solutions to $|2x - 5| = 7$?

📘 Step-by-Step Textbook Solution:
Step 1
Set up the two cases for the absolute value equation $|2x - 5| = 7$:
Case 1
$2x - 5 = 7$
Case 2
$2x - 5 = -7$
Step 2
Solve each linear equation separately:
Case 1
$2x = 12 \implies x = 6$
Case 2
$2x = -2 \implies x = -1$
Step 3
Calculate the sum of all solutions:
Calc
$\text{Sum} = 6 + (-1) = 5$
⚡ Speed / Desmos Tactic:
Step 1
In Desmos, type $y_1 = |2x - 5|$ and $y_2 = 7$.
Step 2
Click the intersection points on the graph: $(-1, 7)$ and $(6, 7)$.
Step 3
Sum the x-coordinates: $6 + (-1) = 5$ (solved in under 15 seconds).
Concept 2

Concept 2: Absolute Value Inequalities

Inequalities involving absolute value represent a range of values rather than specific points.

  • $|x| < a$ is equivalent to $-a < x < a$ (Intersection).
  • $|x| > a$ is equivalent to $x > a$ or $x < -a$ (Union).
  • Always flip the inequality sign when multiplying or dividing by a negative number.
📘 Traditional Algebraic Method

Rewrite the inequality as a compound inequality, solve for $x$, and graph the solution set on a number line.

⚡ SAT Speed Trick & Desmos Hack

Use Desmos to graph the inequality. Look for the shaded region on the x-axis that satisfies the condition.

Concept 3

Concept 3: Extraneous Solutions

Algebraic manipulation can sometimes produce solutions that do not satisfy the original equation.

  • Always check if the result of an absolute value expression is negative.
  • If $|f(x)| = g(x)$, ensure $g(x) \geq 0$ for any valid solution.
  • Substitution is the ultimate safety net.
📘 Traditional Algebraic Method

Plug potential solutions back into the original equation to verify equality.

⚡ SAT Speed Trick & Desmos Hack

If you solve algebraically and get two answers, plug both into the original equation in Desmos to see which one yields a 'False' statement.

Concept 4

Concept 4: Transformations of Absolute Value Functions

The parent function $f(x) = |x|$ can be shifted, stretched, or reflected.

  • $y = a|x - h| + k$ where $(h, k)$ is the vertex.
  • If $a > 0$, the graph opens upward; if $a < 0$, it opens downward.
  • The slope of the right branch is $a$, and the left branch is $-a$.
📘 Traditional Algebraic Method

Identify the vertex $(h, k)$ and use a test point to find the vertical stretch factor $a$.

⚡ SAT Speed Trick & Desmos Hack

Use Desmos sliders for $a, h,$ and $k$ to match the graph provided in the question.
