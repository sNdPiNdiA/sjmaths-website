Formulas and shortcuts for trains crossing poles, platforms, bridges, moving persons, and opposite/same direction relative speed problems.

Overview: Average Speed & Train Motion Mechanics अवलोकन: औसत चाल एवं रेलगाड़ी संबंधी प्रश्न

Train problems apply classical relative velocity principles:
1. Crossing Stationary Point Object (pole, tree, standing man): Distance covered = Length of the train (L). Time = L / S.
2. Crossing Extended Object (platform, bridge, tunnel): Distance covered = Length of train (L) + Length of platform (P). Time = (L + P) / S.
3. Two Trains Crossing Each Other: Total distance = L₁ + L₂.
• In Opposite Directions: Relative Speed = S₁ + S₂.
• In Same Direction: Relative Speed = |S₁ - S₂|.
4. Unit Conversion: 1 km/h = 5/18 m/s and 1 m/s = 18/5 km/h.

Essential Formula / Rule:
Time to cross pole/man = L / S | Time to cross platform = (L + P) / S | Relative Speed (Opposite: S1 + S2, Same: |S1 - S2|)
