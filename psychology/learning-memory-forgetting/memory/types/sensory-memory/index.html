Sensory Memory

Sensory memory acts as the initial ultra-short repository for incoming environmental stimuli, maintaining raw sensory information for a fraction of a second before decay or selective attention.

UP PGT Psychology • Code 13 UNIT IV • Learning, Memory, Forgetting

1. Definitional Framework and Foundational Theories

Sensory memory is defined as the extremely brief, modality-specific memory store that buffers physical energy from sensory receptors before high-level cognitive processing occurs. Historically categorized within the Modal Model of Memory proposed by Richard Atkinson and Richard Shiffrin (1968), sensory memory forms the first gatekeeper of human information processing.

  • Iconic Memory: Visual sensory memory, first rigorously investigated by George Sperling (1960). It retains a high-capacity, photographic representation of visual stimuli for approximately 250 to 500 milliseconds.
  • Echoic Memory: Auditory sensory memory, investigated by Darwin, Turvey, and Crowder (1972). It preserves acoustic traces for a considerably longer duration than iconic memory, typically lasting between 3 to 4 seconds, facilitating speech perception and sentence parsing.
  • Haptic and Other Modalities: Haptic (touch), gustatory (taste), and olfactory (smell) sensory registers also exist, though visual and auditory systems have received the most extensive psychophysical mapping.

2. Neurocognitive Mechanisms & Methodological Paradigms

Empirical investigation into sensory memory shifted dramatically with George Sperling’s 1960 doctoral dissertation at Harvard University, which introduced the Whole Report versus Partial Report paradigms.

In the whole report procedure, participants were presented with a 3x3 matrix of letters for 50 milliseconds and could only report an average of 4 to 5 items due to rapid trace decay. Sperling resolved this limitation with the partial report procedure by introducing a high, medium, or low tone immediately after matrix offset to signal which specific row to recall. This ingenious maneuver proved that the entire visual array (approx. 9-12 items) was momentarily available in iconic memory, but faded faster than participants could verbally report them.

Neurobiologically, sensory memory relies heavily on the peripheral nervous system and primary sensory cortices—such as the striate cortex (V1) for iconic memory and the superior temporal gyrus / Heschl's gyrus for echoic memory. Physiological persistence of neural firing and receptor-level persistence (phototransduction adaptation in rods and cones, basilar membrane resonance in the cochlea) sustain these traces.

3. Clinical, Educational & Practical Applications

Understanding sensory memory has vital implications for educational psychology, multimedia instructional design, and clinical neuropsychology. Sweller's Cognitive Load Theory leverages sensory memory constraints: overloading the visual or auditory sensory registers with extraneous instructional noise impedes transition to working memory.

In clinical contexts, deficits in sensory memory processing are observed in schizophrenia (specifically iconic memory degradation and deficient sensory gating, e.g., P50 auditory gating suppression deficits), dyslexia (auditory echoic temporal processing deficits), and traumatic brain injury (TBI). Clinicians utilize continuous performance tasks (CPTs) and event-related potentials (ERPs) like the mismatch negativity (MMN) to assess pre-attentive sensory memory registers.

High-Yield Exam Points for UP PGT Psychology

  • George Sperling (1960) developed the partial-report technique to demonstrate the existence of high-capacity iconic memory.
  • Iconic memory duration is approximately 250-500 milliseconds; Echoic memory lasts 3-4 seconds.
  • Atkinson and Shiffrin (1968) positioned sensory memory as the first stage in the Modal Model of Memory.
  • Auditory sensory memory allows for 'backward masking' and the retention of speech sounds for syntactic parsing.
  • Mismatch Negativity (MMN), an ERP component, is widely used to measure pre-attentive echoic memory functioning.
  • Sensory memory operates automatically outside conscious control and is characterized by verbatim, modality-specific representation.

Common Misconceptions & Exam Traps

  • Misconception 1: Confusing sensory memory capacity with working memory capacity (Miller's Magical Number 7±2 applies to short-term memory, not sensory memory, which holds vast amounts of raw data instantaneously).
  • Misconception 2: Believing echoic memory is shorter than iconic memory because sounds fade quickly in real life. In reality, echoic memory lasts up to 4 seconds, whereas iconic memory vanishes within half a second.

Q1 Who pioneered the partial-report technique to study iconic memory?
    Correct Option: B

    George Sperling (1960) designed the partial-report matrix experiment with high, medium, and low tones to demonstrate that human iconic memory holds a large amount of visual information for a brief moment before it decays.

    Q2 What is the approximate duration of echoic memory?
    • A 250 milliseconds
    • B 1 second
    • C 3 to 4 seconds
    • D 30 seconds
    Correct Option: C (3 to 4 seconds)

    Echoic memory (auditory sensory memory) lasts significantly longer than iconic memory, typically persisting for 3 to 4 seconds to enable the perception of continuous speech.

    Q3 Which model of memory famously conceptualized sensory memory as the initial entry point of information processing?
    • A Atkinson-Shiffrin Modal Model
    • B Baddeley-Hitch Working Memory Model
    • C Craik and Lockhart Levels of Processing
    • D Tulving's Episodic Memory Model
    Correct Option: A (Atkinson-Shiffrin Modal Model)

    The Modal Model of Memory, proposed by Richard Atkinson and Richard Shiffrin in 1968, outlines information flowing sequentially from sensory memory to short-term memory and then long-term memory.

    Q4 In Sperling's partial-report experiment, participants were instructed to report items based on:
    • A Color of the letters
    • B An auditory tone played immediately after the visual stimulus offset
    • C Semantic category of the words
    • D The experimenter's verbal command 5 seconds later
    Correct Option: B (An auditory tone played immediately after the visual stimulus offset)

    Sperling used an immediate auditory tone (high, medium, or low) corresponding to the top, middle, or bottom row of a visual letter matrix, prompting partial report.

    Q5 What is the primary characteristic of sensory memory?
    • A Semantic coding and permanent storage
    • B Modality-specific storage with massive capacity and rapid decay
    • C Unlimited duration and conscious manipulation
    • D Executive control over attention
    Correct Option: B (Modality-specific storage with massive capacity and rapid decay)

    Sensory memory holds raw, unanalyzed sensory data in a modality-specific format (visual, auditory) with high capacity, but traces decay within fractions of a second.

    Q6 Which brain structure and cortical area is primarily implicated in the early processing of iconic memory traces?
    • A Hippocampus
    • B Primary Visual Cortex (Striate Cortex / V1)
    • C Broca's Area
    • D Amygdala
    Correct Option: B (Primary Visual Cortex (Striate Cortex / V1))

    Iconic memory relies heavily on early visual processing pathways, including the retina, lateral geniculate nucleus, and primary visual cortex (V1).

    Q7 The three-eared man paradigm was used by Darwin, Turvey, and Crowder to investigate:
    • A Iconic memory capacity
    • B Echoic memory persistence
    • C Haptic touch sensitivity
    • D Long-term semantic consolidation
    Correct Option: B (Echoic memory persistence)

    Darwin, Turvey, and Crowder (1972) adapted Sperling's paradigm into an auditory 'three-eared man' procedure to study echoic memory.

    Q8 Why is sensory memory adaptive from an evolutionary perspective?
    • A It allows us to permanently store every environmental detail
    • B It provides a stable, seamless perceptual world despite interruptions or rapid eye movements (saccades)
    • C It replaces the need for long-term memory consolidation
    • D It bypasses attentional bottlenecks completely
    Correct Option: B (It provides a stable, seamless perceptual world despite interruptions or rapid eye movements (saccades))

    Sensory memory bridges micro-gaps in perception, ensuring a continuous stream of consciousness and stable perceptual processing despite rapid saccadic eye movements.

    Q9 Which clinical electrophysiological measure is frequently used to study echoic memory pre-attentive processing?
    • A P300
    • B Mismatch Negativity (MMN)
    • C GABA receptor binding assay
    • D Functional MRI blood-oxygen-level dependent signal
    Correct Option: B (Mismatch Negativity (MMN))

    Mismatch Negativity (MMN), an event-related potential (ERP) component, indexes the brain's pre-attentive detection of deviant acoustic stimuli, reflecting echoic memory trace comparison.

    Q10 What happens to unattended information in sensory memory?
    • A It is transferred to long-term memory automatically
    • B It decays rapidly and is permanently lost
    • C It remains in sensory memory indefinitely
    • D It is converted into phonological loops
    Correct Option: B (It decays rapidly and is permanently lost)

    Information in sensory memory that is not selected by attention undergoes rapid trace decay and is lost from the cognitive system.

    Frequently Asked Questions

    What is the main difference between sensory memory and short-term memory?

    Sensory memory is pre-categorical, modality-specific, holds vast amounts of raw physical data, and decays within fractions of a second to 4 seconds. Short-term memory (working memory) has a strictly limited capacity (7±2 items or 4 chunks), involves conscious cognitive processing, and lasts up to 30 seconds without rehearsal.

    Why did George Sperling use tones in his partial-report experiment instead of asking participants to recall all letters?

    When asked to recall all letters (whole report), participants could only recall 4 to 5 items because iconic memory fades faster than speech output. By using a post-exposure tone, Sperling demonstrated that participants actually perceived nearly all items momentarily, proving high capacity.

    Can sensory memory be improved through training or rehearsal?

    No. Sensory memory is an automatic, bottom-up physiological and psychophysical buffer tied to sensory receptor persistence. Unlike working memory, it cannot be expanded through deliberate mnemonics or rehearsal strategies.

    How does sensory memory relate to clinical conditions like schizophrenia?

    Patients with schizophrenia often exhibit deficits in iconic memory span and auditory sensory gating (e.g., failure to inhibit P50 evoked potentials). This impairs early filtering of environmental stimuli, leading to sensory flooding and cognitive fragmentation.

    संवेदी स्मृति आने वाले पर्यावरणीय उद्दीपकों के लिए एक प्रारंभिक अति-लघु भंडार के रूप में कार्य करती है, जो क्षय (decay) या चयनात्मक ध्यान (selective attention) से पहले कच्चे संवेदी डेटा को एक सेकंड के एक अंश के लिए बनाए रखती है।

    1. सैद्धांतिक रूपरेखा एवं शास्त्रीय अवधारणाएं (Definitional Framework and Foundational Theories)

    संवेदी स्मृति को अत्यंत संक्षिप्त, तौर-तरीके-विशिष्ट (modality-specific) स्मृति भंडार के रूप में परिभाषित किया गया है, जो उच्च-स्तरीय संज्ञानात्मक प्रसंस्करण से पहले संवेदी रिसेप्टर्स से प्राप्त भौतिक ऊर्जा को बफर करता है। ऐतिहासिक रूप से, रिचर्ड एटकिंसन और रिचर्ड शिफ्रिन (1968) द्वारा प्रस्तावित मेमोरी के मोडल मॉडल (Modal Model of Memory) के भीतर वर्गीकृत, संवेदी स्मृति मानव सूचना प्रसंस्करण का पहला द्वारपाल है।

    • आइकोनिक स्मृति (Iconic Memory): दृश्य संवेदी स्मृति, जिसकी पहली बार जॉर्ज स्पर्लिंग (1960) द्वारा कठोरता से जांच की गई थी। यह लगभग 250 से 500 मिलीसेकंड के लिए दृश्य उद्दीपकों का एक उच्च-क्षमता वाला, फोटोग्राफिक प्रतिनिधित्व बनाए रखती है।
    • इकोइक स्मृति (Echoic Memory): श्रवण संवेदी स्मृति, जिसकी जांच डार्विन, टर्वी और क्राउडर (1972) द्वारा की गई थी। यह आइकोनिक स्मृति की तुलना में काफी लंबी अवधि के लिए ध्वनिक निशानों को संरक्षित करती है, जो आमतौर पर 3 से 4 सेकंड तक रहती है, जिससे भाषण धारणा और वाक्य पार्सिंग में सुविधा होती है।
    • हैप्टिक और अन्य तौर-तरीके: हैप्टिक (स्पर्श), गस्टेटरी (स्वाद), और ओल्फैक्ट्री (गंध) संवेदी रजिस्टर भी मौजूद हैं, हालांकि दृश्य और श्रवण प्रणालियों को सबसे व्यापक मनोभौतिक मानचित्रण प्राप्त हुआ है।

    2. तंत्रिका-संज्ञानात्मक प्रक्रियाएं एवं प्रयोगात्मक पद्धतियां (Neurocognitive Mechanisms & Methodological Paradigms)

    संवेदी स्मृति में अनुभवजन्य जांच हार्वर्ड विश्वविद्यालय में जॉर्ज स्पर्लिंग के 1960 के डॉक्टरेट शोध प्रबंध के साथ नाटकीय रूप से बदल गई, जिसने होल रिपोर्ट (Whole Report) बनाम पार्शियल रिपोर्ट (Partial Report) प्रतिमानों को पेश किया।

    होल रिपोर्ट प्रक्रिया में, प्रतिभागियों को 50 मिलीसेकंड के लिए अक्षरों का 3x3 मैट्रिक्स प्रस्तुत किया गया था और वे तेजी से निशान क्षय (trace decay) के कारण औसतन केवल 4 से 5 आइटम ही बता सके। स्पर्लिंग ने मैट्रिक्स ऑफसेट के तुरंत बाद एक उच्च, मध्यम या निम्न स्वर (tone) पेश करके इस सीमा को हल किया, जो यह संकेत देता था कि किस विशिष्ट पंक्ति को याद करना है। इस चतुर युक्ति ने साबित कर दिया कि संपूर्ण दृश्य सरणी (लगभग 9-12 आइटम) क्षण भर के लिए आइकोनिक स्मृति में उपलब्ध थी, लेकिन प्रतिभागियों द्वारा मौखिक रूप से रिपोर्ट करने से पहले ही लुप्त हो गई।

    तंत्रिका-जैविक रूप से, संवेदी स्मृति परिधीय तंत्रिका तंत्र और प्राथमिक संवेदी प्रांतस्था (primary sensory cortices) पर बहुत अधिक निर्भर करती है—जैसे आइकोनिक स्मृति के लिए स्ट्रिएट कॉर्टेक्स (V1) और इकोइक स्मृति के लिए सुपीरियर टेम्पोरल गाइरस / हेस्चल गाइरस। तंत्रिका फायरिंग की शारीरिक दृढ़ता और रिसेप्टर-स्तर की दृढ़ता (रॉड्स और कोन्स में फोटो-ट्रांसडक्शन अनुकूलन, कोक्लीआ में बेसिलर झिल्ली अनुनाद) इन निशानों को बनाए रखती है।

    3. व्यावहारिक, नैदानिक एवं शैक्षणिक अनुप्रयोग (Clinical, Educational & Practical Applications)

    संवेदी स्मृति को समझने का शैक्षिक मनोविज्ञान, मल्टीमीडिया निर्देशात्मक डिजाइन और नैदानिक न्यूरोसाइकोलॉजी के लिए महत्वपूर्ण निहितार्थ है। स्वेलर का संज्ञानात्मक भार सिद्धांत (Sweller's Cognitive Load Theory) संवेदी स्मृति बाधाओं का लाभ उठाता है: बाहरी निर्देशात्मक शोर के साथ दृश्य या श्रवण संवेदी रजिस्टरों को ओवरलोड करना कार्यशील स्मृति (working memory) में संक्रमण को बाधित करता है।

    नैदानिक संदर्भों में, संवेदी स्मृति प्रसंस्करण में कमियां सिज़ोफ्रेनिया (विशेष रूप से आइकोनिक स्मृति गिरावट और दोषपूर्ण संवेदी गेटिंग, उदा. P50 श्रवण गेटिंग दमन कमियां), डिस्लेक्सिया (श्रवण इकोइक अस्थायी प्रसंस्करण कमियां), और दर्दनाक मस्तिष्क चोट (TBI) में देखी जाती हैं। चिकित्सक प्री-अटेंटिव संवेदी स्मृति रजिस्टरों का आकलन करने के लिए निरंतर प्रदर्शन कार्यों (CPTs) और इवेंट-रिलेटेड पोटेंशियल्स (ERPs) जैसे मिसमैच नेगेटिविटी (MMN) का उपयोग करते हैं।

    • संवेदी स्मृति स्वचालित रूप से सचेत नियंत्रण के बाहर संचालित होती है और शब्दशः, तौर-तरीके-विशिष्ट प्रतिनिधित्व द्वारा विशेषता होती है।

    सामान्य भ्रांतियां एवं परीक्षा के जाल (Common Traps)

    • भ्रांति 1: संवेदी स्मृति क्षमता को कार्यशील स्मृति क्षमता के साथ भ्रमित करना (मिलर की जादुई संख्या 7±2 अल्पकालिक स्मृति पर लागू होती है, संवेदी स्मृति पर नहीं, जो तात्कालिक रूप से भारी मात्रा में कच्चा डेटा रखती है)।
    • भ्रांति 2: यह मानना कि इकोइक स्मृति आइकोनिक स्मृति से छोटी होती है क्योंकि वास्तविक जीवन में ध्वनियाँ जल्दी लुप्त हो जाती हैं। वास्तव में, इकोइक स्मृति 4 सेकंड तक रहती है, जबकि आइकोनिक स्मृति आधे सेकंड के भीतर गायब हो जाती है।

    अभ्यास परीक्षा प्रश्न (10 बहुविकल्पीय प्रश्न)

    अपनी अवधारणात्मक समझ का परीक्षण करें। उत्तर चुनें और विस्तृत शैक्षणिक व्याख्या देखें।

    प्रश्न 1 आइकोनिक स्मृति का अध्ययन करने के लिए पार्शियल-रिपोर्ट तकनीक का बीड़ा किसने उठाया?
    • क रिचर्ड एटकिंसन
    • ख जॉर्ज स्पर्लिंग
    • ग डार्विन
    • घ स्वेलर
    सही उत्तर: विकल्प ख (जॉर्ज स्पर्लिंग)

    जॉर्ज स्पर्लिंग (1960) ने यह प्रदर्शित करने के लिए कि मानव आइकोनिक स्मृति क्षय होने से पहले एक संक्षिप्त क्षण के लिए दृश्य जानकारी की एक बड़ी मात्रा रखती है, उच्च, मध्यम और निम्न स्वरों के साथ पार्शियल-रिपोर्ट मैट्रिक्स प्रयोग तैयार किया।

    प्रश्न 2 इकोइक स्मृति की अनुमानित अवधि क्या है?
    • क 250 मिलीसेकंड
    • ख 1 सेकंड
    • ग 3 से 4 सेकंड
    • घ 30 सेकंड
    सही उत्तर: विकल्प ग (3 से 4 सेकंड)

    इकोइक स्मृति (श्रवण संवेदी स्मृति) आइकोनिक स्मृति की तुलना में काफी लंबी होती है, जो आमतौर पर निरंतर भाषण की धारणा को सक्षम करने के लिए 3 से 4 सेकंड तक बनी रहती है।

    प्रश्न 3 स्मृति के किस मॉडल ने संवेदी स्मृति को सूचना प्रसंस्करण के प्रारंभिक प्रवेश बिंदु के रूप में अवधारणाबद्ध किया?
    • क एटकिंसन-शिफ्रिन मोडल मॉडल
    • ख बैडली-हिच वर्किंग मेमोरी मॉडल
    • ग क्रेक और लॉकहार्ट प्रोसेसिंग स्तर
    • घ तुलविंग का एपिसोडिक मेमोरी मॉडल
    सही उत्तर: विकल्प क (एटकिंसन-शिफ्रिन मोडल मॉडल)

    रिचर्ड एटकिंसन और रिचर्ड शिफ्रिन द्वारा 1968 में प्रस्तावित मेमोरी का मोडल मॉडल, संवेदी स्मृति से अल्पकालिक स्मृति और फिर दीर्घकालिक स्मृति तक सूचना के क्रमिक प्रवाह को रेखांकित करता है।

    प्रश्न 4 स्पर्लिंग के पार्शियल-रिपोर्ट प्रयोग में, प्रतिभागियों को किस आधार पर आइटम रिपोर्ट करने का निर्देश दिया गया था?
    • क अक्षरों का रंग
    • ख दृश्य उद्दीपक ऑफसेट के तुरंत बाद बजाया गया एक श्रवण स्वर
    • ग शब्दों की अर्थपूर्ण श्रेणी
    • घ 5 सेकंड बाद प्रयोगकर्ता का मौखिक आदेश
    सही उत्तर: विकल्प ख (दृश्य उद्दीपक ऑफसेट के तुरंत बाद बजाया गया एक श्रवण स्वर)

    स्पर्लिंग ने दृश्य अक्षर मैट्रिक्स की शीर्ष, मध्य या निचली पंक्ति के अनुरूप एक तत्काल श्रवण स्वर (उच्च, मध्यम या निम्न) का उपयोग किया, जिससे पार्शियल रिपोर्ट को बढ़ावा मिला।

    प्रश्न 5 संवेदी स्मृति की प्राथमिक विशेषता क्या है?
    • क अर्थपूर्ण कोडिंग और स्थायी भंडारण
    • ख तेजी से क्षय और विशाल क्षमता के साथ तौर-तरीके-विशिष्ट भंडारण
    • ग असीमित अवधि और सचेत हेरफेर
    • घ ध्यान पर कार्यकारी नियंत्रण
    सही उत्तर: विकल्प ख (तेजी से क्षय और विशाल क्षमता के साथ तौर-तरीके-विशिष्ट भंडारण)

    संवेदी स्मृति कच्चे, बिना विश्लेषण किए गए संवेदी डेटा को तौर-तरीके-विशिष्ट प्रारूप (दृश्य, श्रवण) में उच्च क्षमता के साथ रखती है, लेकिन निशान सेकंड के अंशों में क्षय हो जाते हैं।

    प्रश्न 6 कौन सी मस्तिष्क संरचना और कॉर्टिकल क्षेत्र मुख्य रूप से आइकोनिक स्मृति निशानों के प्रारंभिक प्रसंस्करण में शामिल है?
    • क हिप्पोकैम्पस
    • ख प्राथमिक दृश्य कॉर्टेक्स (स्ट्रिएट कॉर्टेक्स / V1)
    • ग ब्रोका का क्षेत्र
    • घ अमिगडाला
    सही उत्तर: विकल्प ख (प्राथमिक दृश्य कॉर्टेक्स (स्ट्रिएट कॉर्टेक्स / V1))

    आइकोनिक स्मृति रेटिना, लेटरल जेनिकुलेट न्यूक्लियस और प्राथमिक दृश्य कॉर्टेक्स (V1) सहित प्रारंभिक दृश्य प्रसंस्करण मार्गों पर बहुत अधिक निर्भर करती है।

    प्रश्न 7 थ्री-ईयर्ड मैन प्रतिमान का उपयोग डार्विन, टर्वी और क्राउडर द्वारा किसकी जांच के लिए किया गया था?
    • क आइकोनिक स्मृति क्षमता
    • ख इकोइक स्मृति दृढ़ता
    • ग हैप्टिक स्पर्श संवेदनशीलता
    • घ दीर्घकालिक अर्थपूर्ण समेकन
    सही उत्तर: विकल्प ख (इकोइक स्मृति दृढ़ता)

    डार्विन, टर्वी और क्राउडर (1972) ने इकोइक स्मृति का अध्ययन करने के लिए स्पर्लिंग के प्रतिमान को एक श्रवण 'थ्री-ईयर्ड मैन' प्रक्रिया में अनुकूलित किया।

    प्रश्न 8 विकासवादी दृष्टिकोण से संवेदी स्मृति अनुकूली क्यों है?
    • क यह हमें हर पर्यावरणीय विवरण को स्थायी रूप से संग्रहीत करने की अनुमति देती है
    • ख यह रुकावटों या तेजी से आंखों की गतिविधियों (सैकैड्स) के बावजूद एक स्थिर, निर्बाध अवधारणात्मक दुनिया प्रदान करती है
    • ग यह दीर्घकालिक स्मृति समेकन की आवश्यकता को प्रतिस्थापित करती है
    • घ यह ध्यान संबंधी बाधाओं को पूरी तरह से बायपास करती है
    सही उत्तर: विकल्प ख (यह रुकावटों या तेजी से आंखों की गतिविधियों (सैकैड्स) के बावजूद एक स्थिर, निर्बाध अवधारणात्मक दुनिया प्रदान करती है)

    संवेदी स्मृति धारणा में सूक्ष्म-अंतरालों को पाटती है, जिससे तेजी से सैकैडिक आंखों की गतिविधियों के बावजूद चेतना की एक निरंतर धारा और स्थिर अवधारणात्मक प्रसंस्करण सुनिश्चित होता है।

    प्रश्न 9 इकोइक स्मृति प्री-अटेंटिव प्रसंस्करण का अध्ययन करने के लिए किस नैदानिक इलेक्ट्रोफिजियोलॉजिकल माप का अक्सर उपयोग किया जाता है?
    • क P300
    • ख मिसमैच नेगेटिविटी (MMN)
    • ग GABA रिसेप्टर बाइंडिंग परख
    • घ कार्यात्मक MRI रक्त-ऑक्सीजन-स्तर पर निर्भर संकेत
    सही उत्तर: विकल्प ख (मिसमैच नेगेटिविटी (MMN))

    मिसमैच नेगेटिविटी (MMN), एक इवेंट-रिलेटेड पोटेंशियल (ERP) घटक, विचलित ध्वनिक उद्दीपकों का पता लगाने के लिए मस्तिष्क की प्री-अटेंटिव क्षमता को अनुक्रमित करता है, जो इकोइक स्मृति निशान तुलना को दर्शाता है।

    प्रश्न 10 संवेदी स्मृति में बिना ध्यान दिए गए जानकारी का क्या होता है?
    • क यह स्वचालित रूप से दीर्घकालिक स्मृति में स्थानांतरित हो जाती है
    • ख यह तेजी से क्षय हो जाती है और स्थायी रूप से खो जाती है
    • ग यह अनिश्चित काल तक संवेदी स्मृति में बनी रहती है
    • घ यह फोनोलॉजिकल लूप में परिवर्तित हो जाती है
    सही उत्तर: विकल्प ख (यह तेजी से क्षय हो जाती है और स्थायी रूप से खो जाती है)

    संवेदी स्मृति में जो जानकारी ध्यान द्वारा नहीं चुनी जाती है, वह तेजी से निशान क्षय से गुजरती है और संज्ञानात्मक प्रणाली से खो जाती है।

    अक्सर पूछे जाने वाले प्रश्न (FAQs)

    संवेदी स्मृति और अल्पकालिक स्मृति के बीच मुख्य अंतर क्या है?

    संवेदी स्मृति पूर्व-श्रेणीबद्ध, तौर-तरीके-विशिष्ट है, भारी मात्रा में कच्चा भौतिक डेटा रखती है, और सेकंड के अंशों से 4 सेकंड के भीतर क्षय हो जाती है। अल्पकालिक स्मृति (कार्यशील स्मृति) की क्षमता सख्ती से सीमित (7±2 आइटम या 4 चंक्स) होती है, इसमें सचेत संज्ञानात्मक प्रसंस्करण शामिल होता है, और यह रिहर्सल के बिना 30 सेकंड तक रहती है।

    जॉर्ज स्पर्लिंग ने अपने पार्शियल-रिपोर्ट प्रयोग में प्रतिभागियों से सभी अक्षरों को याद करने के लिए कहने के बजाय स्वरों का उपयोग क्यों किया?

    जब सभी अक्षरों को याद करने के लिए कहा गया (होल रिपोर्ट), तो प्रतिभागी केवल 4 से 5 आइटम ही याद कर सके क्योंकि आइकोनिक स्मृति भाषण आउटपुट से अधिक तेजी से लुप्त हो जाती है। पोस्ट-एक्सपोज़र टोन का उपयोग करके, स्पर्लिंग ने प्रदर्शित किया कि प्रतिभागियों ने वास्तव में क्षण भर के लिए लगभग सभी आइटम देखे थे, जो उच्च क्षमता को साबित करता है।

    क्या प्रशिक्षण या रिहर्सल के माध्यम से संवेदी स्मृति में सुधार किया जा सकता है?

    नहीं। संवेदी स्मृति एक स्वचालित, बॉटम-अप शारीरिक और मनोभौतिक बफर है जो संवेदी रिसेप्टर दृढ़ता से जुड़ी हुई है। कार्यशील स्मृति के विपरीत, इसे जानबूझकर निमोनिक्स या रिहर्सल रणनीतियों के माध्यम से विस्तारित नहीं किया जा सकता है।

    संवेदी स्मृति सिज़ोफ्रेनिया जैसी नैदानिक स्थितियों से कैसे संबंधित है?

    सिज़ोफ्रेनिया के रोगियों में अक्सर आइकोनिक स्मृति अवधि और श्रवण संवेदी गेटिंग (उदा. P50 इवोक्ड पोटेंशियल्स को रोकने में विफलता) में कमियां दिखाई देती हैं। यह पर्यावरणीय उद्दीपकों की प्रारंभिक फिल्टरिंग को बाधित करता है, जिससे संवेदी बाढ़ और संज्ञानात्मक विखंडन होता है।
