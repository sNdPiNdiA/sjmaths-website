Types of Memory

Memory is the cognitive faculty of encoding, storing, and retrieving information across varying temporal and functional frameworks.

UP PGT Psychology • Code 13 UNIT IV • Learning, Memory, Forgetting

1. Definitional Framework and Foundational Theories

Memory is structurally and functionally fractionated rather than being a unitary psychological construct. Early pioneers like Hermann Ebbinghaus (1885) initiated empirical investigation using nonsense syllables, while William James (1890) famously distinguished between Primary Memory (immediate consciousness, precursor to Short-Term Memory) and Secondary Memory (permanent, dormant storage, precursor to Long-Term Memory).

  • Atkinson-Shiffrin Modal Model (1968): Proposes a stage-based architecture consisting of Sensory Memory (iconic/echoic), Short-Term Memory (STM), and Long-Term Memory (LTM). Information passes serially through these stages via attention and rehearsal.
  • Craik & Lockhart’s Levels of Processing Model (1972): Rejects structural boxes in favor of processing depth (structural, phonemic, and semantic). Deeper semantic processing yields more durable memory traces.
  • Baddeley & Hitch Working Memory Model (1974): Replaces the passive STM box with an active workspace comprising the Central Executive, Phonological Loop, Visuospatial Sketchpad, and Episodic Buffer.

2. Neurocognitive / Empirical Mechanisms & Methodological Paradigms

The neurobiology of memory spans multiple brain networks and biochemical cascades. Long-Term Potentiation (LTP)—discovered by Bliss and Lomo (1973)—in the hippocampus and amygdala serves as the cellular basis of learning and memory consolidation.

  • Declarative (Explicit) Memory: Dependent on the medial temporal lobes, hippocampus, subiculum, and entorhinal cortex. It mediates conscious recollection of facts and events.
  • Non-Declarative (Implicit) Memory: Dependent on the basal ganglia, cerebellum (motor skills), and amygdala (emotional conditioning). It operates outside conscious awareness (e.g., procedural skills, priming, classical conditioning).
  • Tulving’s Taxonomic Expansion (1972, 1983): Divided LTM into Episodic Memory (autobiographical events tagged in time and space) and Semantic Memory (general world knowledge, decontextualized facts). Later added Procedural and Perceptual Representation System (PRS).

3. Clinical, Educational & Practical Applications

Understanding memory taxonomies underpins clinical neuropsychology and educational psychology. Amnesia dissociations validate the multi-store and multiple-memory systems frameworks.

  • Retrograde vs. Anterograde Amnesia: Retrograde amnesia involves the inability to retrieve old memories predating brain trauma (often sparing remote childhood memories per Ribot's Law), whereas anterograde amnesia (seen in H.M., Korsakoff's syndrome) reflects an inability to encode new explicit memories.
  • Educational Implications: Utilizing elaborative rehearsal, semantic encoding, chunking, and distributed practice optimizes encoding and retrieval in classroom instruction.

High-Yield Exam Points for UP PGT Psychology

  • Atkinson & Shiffrin proposed the classic Modal Model of Memory in 1968 featuring three distinct stages.
  • Endel Tulving distinguished between Episodic Memory (autobiographical) and Semantic Memory (factual) in 1972.
  • Patient H.M. (Henry Molaison) suffered from severe anterograde amnesia after bilateral medial temporal lobectomy, proving the separation of declarative and procedural memory.
  • Long-Term Potentiation (LTP), the strengthening of synapses based on recent patterns of activity, was discovered by Bliss and Lomo in 1973.
  • Baddeley and Hitch introduced the Working Memory model in 1974, replacing the passive STM concept with an active multicomponent system.
  • Craik and Lockhart (1972) proposed the Levels of Processing framework, asserting that semantic encoding produces superior memory retention over structural or phonemic encoding.

Common Misconceptions & Exam Traps

  • Misconception 1: Students often confuse Working Memory with Short-Term Memory. Scientifically, STM is a passive storage container, whereas Working Memory involves active manipulation and processing of information via the central executive.
  • Misconception 2: Assuming all procedural memory tasks rely on the hippocampus. Procedural motor skills depend heavily on the basal ganglia and cerebellum, allowing amnesic patients to acquire new motor skills without conscious recollection of practicing them.

Practice Examination Questions (10 MCQs)

Test your conceptual understanding. Select an answer and check the detailed pedagogical rationale.

Q1 Who proposed the distinction between Episodic and Semantic memory systems within Long-Term Memory?
  • A Endel Tulving
  • B Baddeley and Hitch
  • C Atkinson and Shiffrin
  • D Craik and Lockhart
Correct Option: A (Endel Tulving)

Endel Tulving (1972) famously divided declarative memory into episodic memory (autobiographical, temporally dated events) and semantic memory (generalized factual knowledge).

Q2 Which brain structure is primarily responsible for the consolidation of declarative memories?
  • A Cerebellum
  • B Hippocampus
  • C Basal Ganglia
  • D Amygdala
Correct Option: B (Hippocampus)

The hippocampus, located in the medial temporal lobe, is critical for consolidating short-term declarative memories into long-term storage. Damage here results in anterograde amnesia.

Q3 According to Craik and Lockhart’s Levels of Processing model, which type of encoding leads to the longest-lasting memory trace?
  • A Structural (visual appearance)
  • B Phonemic (sound)
  • C Semantic (meaning)
  • D Sensory (iconic)
Correct Option: C (Semantic (meaning))

Semantic encoding involves processing the meaning of words or concepts, leading to deeper cognitive processing and superior retention compared to shallow structural or phonemic processing.

Q4 Which of the following components was added later by Baddeley to his original Working Memory model in 2000?
  • A Phonological Loop
  • B Visuospatial Sketchpad
  • C Central Executive
  • D Episodic Buffer
Correct Option: D (Episodic Buffer)

Baddeley added the Episodic Buffer in 2000 to integrate information from the phonological loop, visuospatial sketchpad, and long-term memory into a coherent multidimensional representation.

Q5 Patient H.M. demonstrated intact procedural learning despite severe anterograde amnesia. This neuropsychological finding proved the distinction between:
  • A Sensory and Short-Term memory
  • B Declarative and Non-declarative memory
  • C Episodic and Semantic memory
  • D Iconic and Echoic memory
Correct Option: B (Declarative and Non-declarative memory)

H.M.'s ability to learn motor tasks (like mirror-drawing) without conscious memory of ever having performed them provided definitive clinical evidence separating explicit (declarative) and implicit (non-declarative) memory systems.

Q6 What is the primary function of sensory memory in the Atkinson-Shiffrin model?
  • A Long-term permanent storage
  • B Active manipulation of ideas
  • C Holding vast sensory impressions for a fraction of a second
  • D Conscious problem solving
Correct Option: C (Holding vast sensory impressions for a fraction of a second)

Sensory memory holds an exact copy of environmental stimuli for a brief duration (iconic memory lasts ~0.5 seconds, echoic memory lasts 3-4 seconds) before decay or selective attention occurs.

Q7 The cellular mechanism underlying memory formation, characterized by persistent strengthening of synapses, is known as:
  • A Synaptic Pruning
  • B Long-Term Potentiation (LTP)
  • C Neural Retrograde Decay
  • D Cortical Spreading Depression
Correct Option: B (Long-Term Potentiation (LTP))

Long-Term Potentiation (LTP), discovered by Bliss and Lomo in 1973, refers to the persistent strengthening of synapses based on recent patterns of activity, serving as the neurobiological foundation of learning and memory.

Q8 Ribot's Law of retrograde amnesia states that:
  • A Recent memories are more resistant to trauma than remote memories.
  • B Remote memories are more vulnerable to trauma than recent memories.
  • C Recent memories are more vulnerable to trauma than remote memories.
  • D Implicit memories are lost before explicit memories.
Correct Option: C (Recent memories are more vulnerable to trauma than remote memories.)

Ribot's Law dictates that temporally graded retrograde amnesia affects recent memories more severely than remote childhood memories, as older memories have undergone more extensive cortical consolidation.

Q9 Which component of Baddeley's Working Memory model coordinates attentional control and delegates tasks to slave systems?
  • A Phonological Loop
  • B Visuospatial Sketchpad
  • C Episodic Buffer
  • D Central Executive
Correct Option: D (Central Executive)

The Central Executive is the attentional control system that monitors and coordinates the slave systems (phonological loop and visuospatial sketchpad) and the episodic buffer.

Q10 Memory for how to ride a bicycle or tie shoelaces is classified under which type of memory?
  • A Episodic Memory
  • B Semantic Memory
  • C Procedural Memory
  • D Declarative Memory
Correct Option: C (Procedural Memory)

Procedural memory is a subtype of non-declarative (implicit) memory responsible for knowing how to perform actions, motor skills, and habits without conscious thought.

Frequently Asked Questions

What is the difference between declarative and non-declarative memory?

Declarative (explicit) memory involves conscious recollection of facts and events (divided into episodic and semantic), whereas non-declarative (implicit) memory involves procedural skills, priming, and classical conditioning that operate without conscious awareness.

How does Working Memory differ from Short-Term Memory?

While traditional short-term memory refers to a passive storage box holding information for roughly 15-30 seconds, working memory is an active, multi-component workspace that holds and manipulates information simultaneously for complex cognitive tasks like reasoning and comprehension.

What are iconic and echoic memories?

Iconic memory is the brief sensory memory store for visual information (lasting less than a second), while echoic memory is the sensory store for auditory information (lasting up to 3-4 seconds).

Why is patient H.M. so important in the study of memory?

Patient H.M. underwent bilateral medial temporal lobe resection to treat epilepsy, resulting in profound anterograde amnesia. His case proved that memory is fractionated: he could no longer form new explicit declarative memories, but his implicit procedural memory remained completely intact.

1. परिभाषात्मक रूपरेखा एवं आधारभूत सिद्धांत

स्मृति एक एकात्मक मनोवैज्ञानिक संरचना होने के बजाय संरचनात्मक और कार्यात्मक रूप से विभाजित है। हरमन एबिंगहॉस (1885) जैसे शुरुआती अग्रदूतों ने निरर्थक शब्दांशों (nonsense syllables) का उपयोग करके अनुभवजन्य जांच शुरू की, जबकि विलियम जेम्स (1890) ने प्रसिद्ध रूप से प्राथमिक स्मृति (तत्काल चेतना, अल्पकालिक स्मृति का अग्रदूत) और द्वितीयक स्मृति (स्थायी, निष्क्रिय भंडारण, दीर्घकालिक स्मृति का अग्रदूत) के बीच अंतर किया।

  • एटकिंसन-शिफ्रिन मॉडल (1968): यह एक चरण-आधारित वास्तुकला का प्रस्ताव करता है जिसमें संवेदी स्मृति (आइकॉनिक/इकोइक), अल्पकालिक स्मृति (STM), और दीर्घकालिक स्मृति (LTM) शामिल हैं। सूचना ध्यान और पूर्वाभ्यास के माध्यम से इन चरणों से क्रमिक रूप से गुजरती है।
  • क्रेक और लॉकहार्ट का प्रसंस्करण स्तर मॉडल (1972): यह संरचनात्मक बक्सों को अस्वीकार करता है और प्रसंस्करण की गहराई (संरचनात्मक, ध्वन्यात्मक और अर्थगत) पर जोर देता है। गहरा अर्थगत प्रसंस्करण अधिक टिकाऊ स्मृति निशान बनाता है।
  • बैडली और हिच का कार्यशील स्मृति मॉडल (1974): यह निष्क्रिय STM बॉक्स को एक सक्रिय कार्यक्षेत्र से बदल देता है जिसमें केंद्रीय कार्यकारी (Central Executive), ध्वन्यात्मक लूप (Phonological Loop), दृश्य-स्थानिक स्केचपैड (Visuospatial Sketchpad), और प्रासंगिक बफर (Episodic Buffer) शामिल हैं।

2. तंत्रिका-संज्ञानात्मक प्रक्रियाएं एवं प्रयोगात्मक पद्धतियां

स्मृति का तंत्रिका विज्ञान कई मस्तिष्क नेटवर्क और जैव रासायनिक कैस्केड में फैला हुआ है। हिप्पोकैम्पस और एमिग्डाला में ब्लिस और लोमो (1973) द्वारा खोजी गई दीर्घकालिक क्षमता (Long-Term Potentiation - LTP) सीखने और स्मृति समेकन का कोशिकीय आधार है।

  • घोषणात्मक (स्पष्ट) स्मृति: यह मेडियल टेम्पोरल लोब, हिप्पोकैम्पस, सबिकुलम और एंटोरहिनल कॉर्टेक्स पर निर्भर करती है। यह तथ्यों और घटनाओं के सचेत स्मरण को नियंत्रित करती है।
  • गैर-घोषणात्मक (निहित) स्मृति: यह बेसल गैन्ग्लिया, सेरिबैलम (मोटर कौशल), और एमिग्डाला (भावनात्मक कंडीशनिंग) पर निर्भर करती है। यह सचेत जागरूकता के बाहर कार्य करती है (जैसे, प्रक्रियात्मक कौशल, प्राइमिंग, शास्त्रीय कंडीशनिंग)।
  • टुलविंग का वर्गीकरण विस्तार (1972, 1983): इन्होंने LTM को प्रासंगिक स्मृति (समय और स्थान में अंकित आत्मकथात्मक घटनाएं) और शब्दार्थ स्मृति (सामान्य विश्व ज्ञान, संदर्भहीन तथ्य) में विभाजित किया। बाद में प्रक्रियात्मक और प्रत्यक्ष प्रतिनिधित्व प्रणाली (PRS) को जोड़ा।

3. नैदानिक, शैक्षणिक एवं व्यावहारिक अनुप्रयोग

स्मृति वर्गीकरणों को समझना नैदानिक न्यूरोसाइकोलॉजी और शैक्षिक मनोविज्ञान का आधार है। स्मृति लोप (Amnesia) के पृथक्करण बहु-भंडारण और बहु-स्मृति प्रणाली के ढांचे को मान्य करते हैं।

  • प्रतिगामी बनाम अग्रगामी स्मृति लोप: प्रतिगामी स्मृति लोप में मस्तिष्क की चोट से पहले की पुरानी यादों को पुनः प्राप्त करने में असमर्थता शामिल है (अक्सर रिबॉट के नियम के अनुसार दूरस्थ बचपन की यादें सुरक्षित रहती हैं), जबकि अग्रगामी स्मृति लोप (एच.एम., कोर्साकोफ सिंड्रोम में देखा गया) नई स्पष्ट यादों को कूटबद्ध करने में असमर्थता को दर्शाता है।
  • शैक्षणिक निहितार्थ: विस्तृत पूर्वाभ्यास, अर्थगत कूटबद्धीकरण, चंकिंग और वितरित अभ्यास का उपयोग कक्षा निर्देश में कूटबद्धीकरण और पुनर्प्राप्ति को अनुकूलित करता है।

सामान्य भ्रांतियां एवं परीक्षा के जाल (Common Traps)

  • भ्रांति 1: छात्र अक्सर कार्यशील स्मृति (Working Memory) को अल्पकालिक स्मृति (STM) के साथ भ्रमित करते हैं। वैज्ञानिक रूप से, STM एक निष्क्रिय भंडारण कंटेनर है, जबकि कार्यशील स्मृति में केंद्रीय कार्यकारी के माध्यम से जानकारी का सक्रिय हेरफेर और प्रसंस्करण शामिल है।
  • भ्रांति 2: यह मान लेना कि सभी प्रक्रियात्मक स्मृति कार्य हिप्पोकैम्पस पर निर्भर करते हैं। प्रक्रियात्मक मोटर कौशल बेसल गैन्ग्लिया और सेरिबैलम पर निर्भर करते हैं, जिससे स्मृति लोप वाले रोगी अभ्यास की सचेत याद के बिना नए मोटर कौशल प्राप्त कर सकते हैं।

अभ्यास परीक्षा प्रश्न (10 बहुविकल्पीय प्रश्न)

अपनी अवधारणात्मक समझ का परीक्षण करें। उत्तर चुनें और विस्तृत शैक्षणिक व्याख्या देखें।

प्रश्न 1 दीर्घकालिक स्मृति के भीतर प्रासंगिक और शब्दार्थ स्मृति प्रणालियों के बीच अंतर किसने प्रस्तावित किया?
  • क एंडेल टुलविंग
  • ख बैडली और हिच
  • ग एटकिंसन और शिफ्रिन
  • घ क्रेक और लॉकहार्ट
सही उत्तर: विकल्प क (एंडेल टुलविंग)

एंडेल टुलविंग (1972) ने घोषणात्मक स्मृति को प्रासंगिक स्मृति (आत्मकथात्मक, समयबद्ध घटनाएं) और शब्दार्थ स्मृति (सामान्यीकृत तथ्यात्मक ज्ञान) में विभाजित किया।

प्रश्न 2 कौन सी मस्तिष्क संरचना घोषणात्मक यादों के समेकन के लिए मुख्य रूप से जिम्मेदार है?
  • क सेरिबैलम
  • ख हिप्पोकैम्पस
  • ग बेसल गैन्ग्लिया
  • घ एमिग्डाला
सही उत्तर: विकल्प ख (हिप्पोकैम्पस)

मेडियल टेम्पोरल लोब में स्थित हिप्पोकैम्पस, अल्पकालिक घोषणात्मक यादों को दीर्घकालिक भंडारण में समेकित करने के लिए महत्वपूर्ण है। यहाँ क्षति होने पर अग्रगामी स्मृति लोप होता है।

प्रश्न 3 क्रेक और लॉकहार्ट के प्रसंस्करण स्तर मॉडल के अनुसार, किस प्रकार का कूटबद्धीकरण सबसे लंबे समय तक चलने वाला स्मृति निशान बनाता है?
  • क संरचनात्मक (दृश्य उपस्थिति)
  • ख ध्वन्यात्मक (ध्वनि)
  • ग अर्थगत (अर्थ)
  • घ संवेदी (आइकॉनिक)
सही उत्तर: विकल्प ग (अर्थगत (अर्थ))

अर्थगत कूटबद्धीकरण में शब्दों या अवधारणाओं के अर्थ को संसाधित करना शामिल है, जो उथले संरचनात्मक या ध्वन्यात्मक प्रसंस्करण की तुलना में गहरी संज्ञानात्मक प्रसंस्करण और बेहतर प्रतिधारण की ओर ले जाता है।

प्रश्न 4 बैडली ने 2000 में अपने मूल कार्यशील स्मृति मॉडल में बाद में कौन सा घटक जोड़ा?
  • क फोनोलॉजिकल लूप
  • ख विजुओस्पेशियल स्केचपैड
  • ग सेंट्रल एग्जीक्यूटिव
  • घ एपिसोडिक बफर
सही उत्तर: विकल्प घ (एपिसोडिक बफर)

बैडली ने 2000 में एपिसोडिक बफर को जोड़ा ताकि फोनोलॉजिकल लूप, विजुओस्पेशियल स्केचपैड और दीर्घकालिक स्मृति से जानकारी को एक सुसंगत बहुआयामी प्रतिनिधित्व में एकीकृत किया जा सके।

प्रश्न 5 रोगी एच.एम. ने गंभीर अग्रगामी स्मृति लोप के बावजूद बरकरार प्रक्रियात्मक शिक्षण का प्रदर्शन किया। इस न्यूरोसाइकोलॉजिकल खोज ने किसके बीच अंतर को सिद्ध किया?
  • क संवेदी और अल्पकालिक स्मृति
  • ख घोषणात्मक और गैर-घोषणात्मक स्मृति
  • ग प्रासंगिक और शब्दार्थ स्मृति
  • घ आइकॉनिक और इकोइक स्मृति
सही उत्तर: विकल्प ख (घोषणात्मक और गैर-घोषणात्मक स्मृति)

एच.एम. की मोटर कार्यों को सीखने की क्षमता (जैसे मिरर-ड्राइंग) ने स्पष्ट (घोषणात्मक) और निहित (गैर-घोषणात्मक) स्मृति प्रणालियों को अलग करने का निर्णायक नैदानिक प्रमाण प्रदान किया।

प्रश्न 6 एटकिंसन-शिफ्रिन मॉडल में संवेदी स्मृति का प्राथमिक कार्य क्या है?
  • क दीर्घकालिक स्थायी भंडारण
  • ख विचारों का सक्रिय हेरफेर
  • ग एक सेकंड के एक अंश के लिए विशाल संवेदी छापों को धारण करना
  • घ सचेत समस्या समाधान
सही उत्तर: विकल्प ग (एक सेकंड के एक अंश के लिए विशाल संवेदी छापों को धारण करना)

संवेदी स्मृति क्षय या चयनात्मक ध्यान से पहले एक संक्षिप्त अवधि के लिए पर्यावरणीय उत्तेजनाओं की एक सटीक प्रतिलिपि रखती है (आइकॉनिक स्मृति ~0.5 सेकंड तक रहती है, इकोइक स्मृति 3-4 सेकंड तक रहती है)।

प्रश्न 7 स्मृति निर्माण के अंतर्निहित कोशिकीय तंत्र को, जो सिनैप्स के निरंतर सुदृढ़ीकरण की विशेषता है, किस रूप में जाना जाता है?
  • क सिनैप्टिक प्रूनिंग
  • ख दीर्घकालिक क्षमता (LTP)
  • ग न्यूरल रेट्रोग्रेड डिके
  • घ कॉर्टिकल स्प्रेडिंग डिप्रेशन
सही उत्तर: विकल्प ख (दीर्घकालिक क्षमता (LTP))

दीर्घकालिक क्षमता (LTP), जिसे 1973 में ब्लिस और लोमो द्वारा खोजा गया था, हालिया गतिविधि पैटर्न के आधार पर सिनैप्स के निरंतर सुदृढ़ीकरण को संदर्भित करता है, जो सीखने और स्मृति का न्यूरोबायोलॉजिकल आधार है।

प्रश्न 8 प्रतिगामी स्मृति लोप का रिबॉट का नियम क्या कहता है?
  • क हाल की यादें दूरस्थ यादों की तुलना में आघात के प्रति अधिक प्रतिरोधी हैं।
  • ख दूरस्थ यादें हाल की यादों की तुलना में आघात के प्रति अधिक संवेदनशील हैं।
  • ग हाल की यादें दूरस्थ यादों की तुलना में आघात के प्रति अधिक संवेदनशील हैं।
  • घ निहित यादें स्पष्ट यादों से पहले खो जाती हैं।
सही उत्तर: विकल्प ग (हाल की यादें दूरस्थ यादों की तुलना में आघात के प्रति अधिक संवेदनशील हैं।)

रिबॉट का नियम बताता है कि अस्थायी रूप से वर्गीकृत प्रतिगामी स्मृति लोप हाल की यादों को दूरस्थ बचपन की यादों की तुलना में अधिक गंभीर रूप से प्रभावित करता है, क्योंकि पुरानी यादों ने अधिक व्यापक कॉर्टिकल समेकन किया है।

प्रश्न 9 बैडली के कार्यशील स्मृति मॉडल का कौन सा घटक ध्यान नियंत्रण का समन्वय करता है और दास प्रणालियों को कार्य सौंपता है?
  • क फोनोलॉजिकल लूप
  • ख विजुओस्पेशियल स्केचपैड
  • ग एपिसोडिक बफर
  • घ सेंट्रल एग्जीक्यूटिव
सही उत्तर: विकल्प घ (सेंट्रल एग्जीक्यूटिव)

सेंट्रल एग्जीक्यूटिव ध्यान नियंत्रण प्रणाली है जो दास प्रणालियों (फोनोलॉजिकल लूप और विजुओस्पेशियल स्केचपैड) और एपिसोडिक बफर की निगरानी और समन्वय करती है।

प्रश्न 10 साइकिल चलाना या जूते के फीते बांधने की स्मृति को किस प्रकार की स्मृति के अंतर्गत वर्गीकृत किया गया है?
  • क प्रासंगिक स्मृति
  • ख शब्दार्थ स्मृति
  • ग प्रक्रियात्मक स्मृति
  • घ घोषणात्मक स्मृति
सही उत्तर: विकल्प ग (प्रक्रियात्मक स्मृति)

प्रक्रियात्मक स्मृति गैर-घोषणात्मक (निहित) स्मृति का एक उपप्रकार है जो सचेत विचार के बिना कार्यों, मोटर कौशल और आदतों को करने के तरीके को जानने के लिए जिम्मेदार है।

अक्सर पूछे जाने वाले प्रश्न (FAQs)

घोषणात्मक और गैर-घोषणात्मक स्मृति में क्या अंतर है?

घोषणात्मक (स्पष्ट) स्मृति में तथ्यों और घटनाओं का सचेत स्मरण शामिल है (प्रासंगिक और शब्दार्थ में विभाजित), जबकि गैर-घोषणात्मक (निहित) स्मृति में प्रक्रियात्मक कौशल, प्राइमिंग और शास्त्रीय कंडीशनिंग शामिल हैं जो सचेत जागरूकता के बिना कार्य करते हैं।

कार्यशील स्मृति अल्पकालिक स्मृति से कैसे भिन्न है?

जबकि पारंपरिक अल्पकालिक स्मृति लगभग 15-30 सेकंड के लिए जानकारी रखने वाले एक निष्क्रिय भंडारण बॉक्स को संदर्भित करती है, कार्यशील स्मृति एक सक्रिय, बहु-घटक कार्यक्षेत्र है जो तर्क और समझ जैसे जटिल संज्ञानात्मक कार्यों के लिए एक साथ जानकारी रखती और हेरफेर करती है।

आइकॉनिक और इकोइक यादें क्या हैं?

आइकॉनिक स्मृति दृश्य जानकारी के लिए संक्षिप्त संवेदी स्मृति भंडार है (एक सेकंड से कम समय तक चलने वाली), जबकि इकोइक स्मृति श्रवण जानकारी के लिए संवेदी भंडार है (3-4 सेकंड तक चलने वाली)।

स्मृति के अध्ययन में रोगी एच.एम. इतने महत्वपूर्ण क्यों हैं?

रोगी एच.एम. ने मिर्गी के इलाज के लिए द्विपक्षीय मेडियल टेम्पोरल लोब रिसेक्शन करवाया, जिसके परिणामस्वरूप गंभीर अग्रगामी स्मृति लोप हुआ। उनके मामले ने साबित कर दिया कि स्मृति विभाजित है: वह नई स्पष्ट घोषणात्मक यादें नहीं बना सकते थे, लेकिन उनकी निहित प्रक्रियात्मक स्मृति पूरी तरह से बरकरार थी।
